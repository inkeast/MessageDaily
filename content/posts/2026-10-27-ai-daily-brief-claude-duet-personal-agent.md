# 主动干活，还是记住一切：NLW 实测 Claude Duet 与他的整套 AI 分工

> 信源说明：本文基于 The AI Daily Brief 2026-10-26 发布的一期节目（视频 ID HyEfRBW10Kk，标题 How I'm Actually Using Claude Duet，时长约 32 分钟，转写覆盖至 1920 秒）整理，主持人为频道常任主播 NLW，与[本博 10-26 性格之争篇](/posts/2026-10-26-ai-daily-brief-personality-beats-intelligence/)、[10-27 泡沫辩论篇](/posts/2026-10-27-ai-daily-brief-bubble-signals/)同一主播，且本文可视为性格之争篇（Muse 与 Dots 的人格卡位）的续篇。依据英文转写整理；全部说法均为 NLW 自述或其转述，本文未做独立核实，归属按「NLW 认为／节目引用」分层；ASR 存疑词以「转写疑作」标注。节目内插播的广告口播（KPMG、Robots and Pencils、CData、Blitzy）按本系列惯例略过。

## 先说结论

Anthropic 的 Claude Duet 本周上线，成为个人代理（personal agent）赛道最新的入场者。NLW 没有做常规产品评测，而是借实测 Duet 之交出了一份约 32 分钟的「AI 使用全栈自白」——用他自己的话说，要讲清自己怎么用 Duet，就不得不先交代自己每天到底怎么用 AI。整期节目围绕一个他自认尚无答案的矛盾展开：**个人代理到底是统管一切的「幕僚长」（chief of staff），还是一个不等吩咐、自己找活干的「主动代理」（proactive proxy）？** 他的暂定答案是：这一代产品既不是与 AI 交互方式的大转向，也不是厂商爱演示的订机票、代购物，而更像「一个易配置的、微型版本的自己，替你做一堆你不想做的事」——有价值，但是否「行业未来级」的价值，尚待观察。此外他给出两个元判断：其一，功能层竞争已趋同到「一家跑通、数天到数周内全行业跟进」，用户不必纠结押注哪个生态，真正的差异化回到基础模型能力本身；其二，dots 的教训说明「持有你的全部上下文」与「会用你的全部上下文」是两回事，这正是他对 dots 失望、对 Duet 相对乐观的分水岭。

## 一位重度用户的分工全景：六个场景、三组模型

NLW 的工作横跨 The AI Daily Brief（内容）与 Superintelligent（面向企业的 AI 教育，偏商业策略），他把自己的日常 AI 用例拆成六类，并强调每个新模型发布时，他问的都不是「能否一比一替换现有工具」，而是「它进我的技术栈的哪一层」。

**战略外化（strategic externalization）是他按纯时间计占比最高的用例——历次 AI 会话约 60% 在这个领域**（按 token 消耗计则大头是写代码）。他不是安静思考型的人，而是在 Notion 里囤了大量「walk notes」——走路、开车、静坐时把想法讲出来的记录。对这个场景，模型最关键也最难的能力是**敢反驳（pushback）而不是谄媚（sycophancy）**：早期模型「和写在纸上差不多」，什么点子都夸成金子；他理想中的模型要 dynamic、creative、confident，且反驳要「有依据，而不是因为被训练成爱反驳」。他自称不持 AI 拟人论，但这些拟人词是唯一能准确描述需求的词。他的现任最优是 Opus 5.5——「很久以来我最喜欢的战略模型」；之前用 Fable 5.1（他觉得还行），再往前是 OpenAI 的模型，但他认为今年大部分时间 GPT 系显得 flat、不够 dynamic——这个评价也预示了他后面对 dots 的失望。

**研究**是第二块：既服务 AIDB 与下文将说的新节目，也服务他妻子主持、他参与制作的罪案播客 Love Murder。因为研究成果最终会由他或妻子公开说出，模型必须信源可靠、不幻觉、懂信源分级。他的做法是 **Astra 与 Opus 各用一半，重要题目让两个模型互相审阅对方的产出**（Astra 审 Opus、Opus 审 Astra），在内容公开前多加一层置信度。（按：转写中同一模型疑被识别为 Astra 与 Atlas 两种写法，本文统一作 Astra。）

**文案（copywriting）每日必用但刻意留在 GPT 系**：节目描述、社交帖由 AI 起草；标题则是他对半开——一半维持原题，一半与 AI 来回后换新。他选 Astra 的理由有二：多年使用积累的记忆让模型「知道我喜欢什么、不喜欢什么」，换模型的调教成本不值；且不少人认为 OpenAI 模型的简洁（concision）更适合短文案。这里他顺带揭秘了 AIDB 的制作流程：每晚他做一至两小时的当日 AI 新闻与舆论盘点，澳大利亚的研究员 Scott 在他的夜里做同样的事（一个让团队 24 小时运转的时差 hack），美东晚 8-9 点定次日选题，Scott 通宵准备含关键信源与社交媒体评论的材料包（dossier）；他醒来后据此排屏幕素材，然后开录。他自嘲常被观众评论「AI 谈 AI」，实际这个流程里 AI 用得惊人地少。

**图像生成**已基本收敛到 GPT 图像模型——不是确信它最强，而是封面图在锁定标题后立刻要做、留在同一线程最顺。他仍保留 Ideogram 订阅（一次出四图、可调差异度，适合迭代）和 Midjourney（「有自己的怪品味」，在「不知道要什么、只想要它够酷够抓眼」时反而更强）。**数据分析**（如延期报税季把一堆财务数据倒进去整理提取）几乎全用 Codex 里的 Astra。**构建（building）**是 token 消耗大头：今年试过 OpenClaw（转写疑作 OpenCL/Open Claw）、Codex、Claude Code 的应用与 CLI 版本、Cursor 等，最终稳定在 **Claude Code + Opus 5.5、effort 调到 high 或 extra**；视觉类配套常在 Codex 里用 Astra 做（为原生访问图像模型），组织、叙事架构与编排则全在 Claude Code。

## 从「完成能量」到生产管线：内容基础设施的 AI 化

NLW 认为今年模型进步的一个关键叙事，是 Fable 把「完成能量（completion energy）」大幅拉低：此前项目常挂在 80-90% 完成度——启动的激活能量够低、做完的能量太高；Fable 把两者拉平，「把东西做完」变得和「开始做」一样容易。AIDB 整个网站就是证据：他知道旧版 90 年代复古风网站不好用已数月，需求也明确——节目信息密度高、入坑门槛也高，很多听众想要更容易地分享节目片段。于是他做的不是「一个网站」而是一条**生产管线**：上传节目转写 → 自动提取信息 → 组织成可分享的网络资产。整个第一版在**他拿到 Fable 的第一个下午完成——赶巧的是，第二天 Fable 就因与白宫的出口管制风波下线**。之后同一管线继续生长：社交侧，每集完成后卡片自动再生成一组推文与 LinkedIn 帖、经 Typefully 排期发布（比直连各家 API 省事）；视频侧，他认为 Opus 5.5 这代模型让视频剪辑能力突飞猛进（「即使你觉得现在没理由用视频，也值得去试」），于是让 Claude Code 建了视频管线：喂入转写 → 模型自己判断最抓人、可独立成段的 60-90 秒 → 抽取剪辑、配视觉资产、打包待发。

这套管线正好接住了他在节目里预告的新节目 **How We Got Here**（10 月 26 日周一首发，每周一期、每期 45-60 分钟）：看今天的大新闻、大现象背后的社会、文化、技术与经济成因——他给了前三期的样子：美国如何不再爱上科技行业；东西为什么变便宜了、而生活中重要的事越来越贵；预测市场与我们开始对一切下注。流程比 AIDB 更进一步：Claude 上迭代选题与分发策略 → Claude 加 Astra 建研究材料包 → 一轮反馈后 Claude 列论证节点（key beats）→ 他自己找视觉素材、对着讲 40-60 分钟 → 录完把原始转写加原始研究交回 Opus 5.5 写**配套长文（companion essay）初稿**——同一套论证、更丰富的视觉呈现、面向爱读的人、带全部信源链接，一小时节目对应五六千字 → 再到 Codex 配 GPT 图像做整体视觉 → 他本人做一轮「累人的编辑」（前三期重写约一半）→ 人类剪辑师做第一遍，AI 补动画并直接接入剪辑管线。

## 两次主动代理浪潮：变的不是「主动性」，是设置成本

很多人从 AI 获得价值的场景——收件箱监控、邮件自动草拟、Slack 值守、主动汇总——恰恰是 NLW 一直没做的，原因坦率：「juice wasn't worth the squeeze（汁水不值挤它的力气）」。他并非没试过：OpenClaw 爆火的今年早些时候，他配置过多个用 heartbeat 和定时任务（cron job）值守特定事项的 claw，一个跨协调它们的「幕僚长」代理，以及一个持续监控学术研究与 AI 采纳调查的研究代理。结局：研究代理随项目结束而停用；幕僚长「坦率讲，增加的价值抵不上维护成本」。他承认这与个人习惯有关——他 90% 的通话不预约、日历管得极紧，邮件就是标星、隔几天清一次（自称 internet boomer 式用法）。所以他连 Hermes agent 都没在节目里谈过：「我认为它是优秀的产品，只是不适合我的工作方式。」

对个人用途他更不乐观：他曾公开 diss 厂商爱演示的订机票、代购物、订餐厅。以机票为例——他几乎永远订里程所在的航司（或另一家有里程的航司），实际操作困在单一航司的订票界面里，**把所有变量和例外解释给代理听的时间，约等于直接看网页的时间**。于是真正的问题变成：新一代个人代理能否把设置与维护成本压到「它提供的主动性终于值得」的程度？这引出他对两条路线的区分——**净新增（net new，替你值守邮件、提醒待办、草拟可批准的回复）还是更好协调（better coordination，接管你与 AI 的日常交互方式）**。

## monothread 与 dots 的教训：上下文容器 ≠ 上下文调用

「更好协调」这条路线，NLW 认为更接近节目近几月讨论的**单线程范式（monothread paradigm）**：不是把工作摊在几十个各自只记得局部上下文的聊天窗口里，而是单一主线持有你的全部上下文、按需调取、随时切换任务、需要时再派生子代理。文件夹式组织有助于整理大脑，单线程的好处是把这份认知负荷省掉、让用户直接意识流（stream of consciousness）。他认为这之所以现在才可能，是因为各家实验室在后台的上下文压缩（compaction）与续传进步明显——2026 年早期的教育课程里还有整课在教「交接文档（handoff documents）」的写法，现在已经不必离开单个聊天了。他自己已在把 Claude Code 和 Codex 往「少分块、单一主导线程」的方向推。

工具盘点上他给出清晰的优先级：第三方新工具 Instinct 与 Town（转写如此）口碑很好但对他优先级低——能力与需求错配，且他不愿把全部工作上下文从 ChatGPT 与 Claude 迁走；Muse 因偏个人用途兴趣较低，「但 Zuckerberg 和 Alex Wang 的野心显然不止于此」；Grokbot 他保有全部 ultra 订阅、看重其与 X 的集成（内容生产视角很有价值），策略是「保持刚好足够的参与，万一哪天有不得不切换的理由，不至于从零开始」；Google「很抱歉地说」目前不值得重仓投入——但他乐观认为会随其回过神来而改变，眼下落后反倒少一个负担；Microsoft 因播客与 Superintelligent 的企业受众而保持专业跟踪，但单人作业者天然偏向更 nimble、非企业向的工具——不对它做价值判断，只是不在那个生态里玩。

于是到了 dots（OpenAI 的个人代理）。他给自己的 dot 取名 Quasar——Dungeon Crawler Carl 里的 Nullian 律师——并用它承担 ChatGPT 侧重要专业工作的单线程组织：研究、播客数据都在 Quasar 名下；随手查询和每日文案仍照旧。但用下来：数据工作「不确定是不是在 Codex 里做更好」；战略工作更没有搬过去的冲动——**dot 的性格 flat 到几乎「挡住（stonewall）战略互动」**，倒一大段上下文给 Quasar、「像拔牙一样」才能让它接话。最有说服力的轶事：某天他花约六小时边走边徒步与 Claude（Opus 5.5）做战略规划，之后把整段对话转给 Quasar，只是为了让它掌握最新信息——Quasar 没有接住六小时内容里的任何一条线头，回复字面是「Great, this information has been saved for the future.（好，这些信息已保存供未来使用）」。dot 也不够主动，没多久他就「基本不再有理由搭理它」。他的小结（强调完全可能变化、且不因此对未来悲观）：**dots 作为 ChatGPT 内的一个 feature 没有真正增加什么——作为被动响应之地无增益、主动工作很弱；唯一看到的价值是「上下文总管（master holder of context）」：把相关背景一股脑倒给它同步，省得日后在多个聊天里重复交代。**

## Duet 实测：为工作而生、连接即用

Duet 是几大个人代理里**最不关心人设与性格的一个**：没有 Muse 那样的毛绒 logo，也不像 dot 让你给它起名——明显延续 Anthropic 专注工作的路线，NLW 认为这可能与他的需求对味。上手第一件事是连接 Slack、Gmail、Drive；还没等他做别的，Duet 就递来一摞可主动执行的项目选项——而 **Duet 偏向主动到会高估某些工作的价值**。例：它从收件箱里两封「给两个赞助商标了同一可用日期」的邮件推断出「广告位可能重复售卖」的风险，反复提醒了约四次，直到 NLW 告诉它那天本来就有多组位置、这个工作流他根本不在乎——他形容 Duet 在这件事上「抽风（spasm）」。但另一些主动工作价值明显：几次出现「正是他会标星、过两天再回」的邮件，Duet 直接拟好回复，可编辑也可授权直发；他试过几次直接放行，最实质、最有创意的一次提案虽没立即发，但「把我带到 90%，不用回头再想」。这让他对 Duet 的主动性谨慎乐观。

产品形态上：Duet 主推 iOS 应用，但他更喜欢其网页版——主时间线「Everything stream」之外可建单独频道（channel），给想保留一定层级组织的人留了出口；它复用 Claude 的 artifacts 基础设施，能造出可直接交互编辑的东西而不必跳转其他界面；还会自动把事项归组成 active / up next / scheduled / resolved 四态任务，在主聊天里或直接添加任务都能修改。边界也很清楚：一个 UI 与品牌视觉设计任务在 Duet 里做得**远差于** Claude 原生设计体验（后者按他的了解今年晚些会并入 artifacts）——所以对他而言 Duet 的定位仍是「主动性 + 上下文总管」，不是万能入口。

## 这意味着什么：三条机制链与观察指标

把 NLW 的自白抽成机制链，至少有三条值得读者带走（证据均为其自述，推断处已标明）：

**其一，个人代理的价值公式 = 主动性收益 −（设置 + 维护 + 打扰）成本。** OpenClaw 时代主动代理的设置维护成本高到 NLW 这样的重度用户也放弃；Duet 把设置成本压到「连三个账号」的程度，让曾弃用者重新入场。但公式右边还有「打扰成本」——赞助库存误报连催四次就是它在扣分，邮件回复草拟 90% 到位就是它在加分。观察指标：各家 agent 的误报与打断频率，以及用户三十日后的留存（dot 被 NLW 冷落即前车之鉴）。

**其二，上下文容器是护城河，上下文调用才是产品。** 单线程范式让「持有用户全部上下文」成为各家竞争焦点（dot、Duet 的 Everything stream 皆然），但 dots 的「已保存供未来使用」轶事说明持有≠会用。NLW 对 Duet 乐观的部分，恰恰是它在正确的地方调用了上下文（读了邮件、动了任务）。观察指标：各产品从「存了什么」到「主动用对了什么」的差距。

**其三，功能趋同把差异化压回基础模型。** NLW 断言「某个功能在一家跑通后，数天到数周内会成为所有家的」——dots 不够主动 OpenAI 会调、Duet 受欢迎的 UI 别家会抄，所以用户不必焦虑押注哪个生态；他真正的选型标准全部落在基础模型能力上：战略场景的 pushback、文案的 concision、把项目做完的 completion energy。这也是他不愿迁出 ChatGPT 与 Claude 两个生态的真实原因——Grokbot、Muse 再热闹，差的不是功能层（此段为本文从其自述归纳的推断）。

最后回到他给自己留的问题：个人代理目前更像「易配置的微型自己，替我做一堆我不想做的事」——这对个人已有价值；但它是否构成「行业未来级」的交互转移，他明说「尚待观察」。从他这期节目的信息密度看，一个务实的中间结论或许是：在基础模型的性格与主动性真正调对之前，个人代理最稳的价值就是 dots 已做到的那一半——当一个忠实的上下文总管；至于主动干活的那一半，Duet 的邮件草拟给出了第一份像样的答卷，而全行业都坐在同一张考卷前。
