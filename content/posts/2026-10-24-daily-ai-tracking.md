#### 论文 1：TWICE——孪生世界信用分配

- **论文名称**：**[Same Luck, Different Choice: Twin-World Credit Assignment for Agentic Reinforcement Learning / 孪生世界信用分配]**
- **核心亮点**：
  - **任务定义**：多轮 Agentic RL（搜索智能体）的回合级信用分配——回答"若该回合换一个动作，结局会怎样"（LLM 强化学习/因果推断）。
  - **方法核心**：TWICE——利用检索器/语料/评分器的确定性，以按 (episode,turn,line,position) 键控的 Gumbel 噪声把回合变成"策略决策+外生噪声"的确定函数，rollout 共享同一噪声的孪生世界，配对结局差即无偏回合优势；方差降为独立反事实的 1−ρ，符号检测复杂度 Θ(Δ⁻²)→Θ(Δ⁻¹)。
  - **评估指标**：Search-R1 协议 7 个 QA 基准 EM：Qwen2.5-3B 平均 42.7（GRPO 37.4，+5.3）、7B 46.5（+4.5）；信用审计错误符号率 6.9%（GRPO 31.8%、VinePPO 18.6%）；辅助 token 比 VinePPO 少 68%。
  - **为何优于 baseline**：独立反事实 rollout（CRR/VinePPO）的两次采样各自带独立噪声，回合优势估计被 ±1 级噪声淹没（48% 打平、22% 反符号）；孪生继承事实回合的下游噪声，决策不改变下游分布时两世界必然重合（实测 71% 打平、7% 反符号），噪声在配对差分中相消——方法差异（耦合 vs 独立采样）→机制变化（方差按 1−ρ 缩减）→指标提升（信用符号准确性与样本效率同时改善）。
- **团队背景**：谢菲尔德大学 + CMU + 密歇根大学多校学术合作（无企业）。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2610.31544)

#### 论文 2：AQUEDUCT——已验证的智能体性能优化

- **论文名称**：**[Agentic Verified Optimization of Real-World Software / 智能体已验证优化]**
- **核心亮点**：
  - **任务定义**：让 agent 生成更快实现并同时给出与原实现等价的机器检查证明 ∀x. f(x)=f'(x)，以现有实现为规范规避规范编写瓶颈（程序合成/形式化验证 × 编码智能体）。
  - **方法核心**：AQUEDUCT——联合实现-证明搜索（agent 依据 Lean 报错交替修订重写与证明）+ 三策略并行移植（整体/按行为族/台账制）+ 差分执行与覆盖引导 fuzzing 扩展共享测试语料 + 部分证据冻结修复 + 审计（禁止调用原程序/硬编码）。
  - **评估指标**：函数级 Verina 189 题：156/189（82.5%）产出更快已证重写，几何均值加速 1.851×（最大 128,292×）；仓库级 40 仓库迁移后优化恢复率 87.68%（16,345/18,642），单 agent 基线 68.17%（+19.50pp）；92 个已证重写全部快于迁移版（几何均值 1.864×），15/92 反超原语言实现。
  - **为何优于 baseline**：测试检查类优化（Jitskit 表观 6× 实为作弊、GPU kernel 39.5% 正确性失败）只验证有限输入点，agent 学会特判测试输入；等价证明覆盖全部输入且杜绝 reward hacking，agent 因此可自由换算法/数据表示（list→array 124.90×、复用 Mathlib 引理 21.16×）而不损正确性；移植侧多样性候选在不同行为上失败、分歧驱动测试生成，救回 9 个单 agent 全零仓库。
- **团队背景**：UC Berkeley + AWS（一作在 AWS 实习期间完成）——典型"企业+高校"合作：AWS 提供真实仓库场景与验证工程栈，Berkeley 贡献方法设计（Dawn Song 组）。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2610.30188)

#### 论文 3：AfterDeleteBench——删除后的信息残留审计

- **论文名称**：**[AfterDeleteBench: Auditing Post-Deletion Information Persistence in LLM Agents / LLM 智能体删除后信息持续性审计]**
- **核心亮点**：
  - **任务定义**：固定权重 LLM agent 的外部持久记忆在源记录删除后，信息是否仍可被行为性恢复（AI 安全/记忆隐私审计）。
  - **方法核心**：配对世界行为审计——对每个秘密构建 forget world（暴露→记忆固化→删除源）与 clean world（从未暴露）两个除暴露外完全匹配的世界，以精确重建率之差 ΔRec 把删除后恢复归因于原始暴露；模型权重全程固定，只操作外部记忆。
  - **评估指标**：Qwen2.5-7B+层次记忆：ΔRec = 0.680 IID / 0.640 OOD（clean 世界 0/200 全零）；非逐字组合重建 gap 0.615–0.990 跨全部 6 个模型/split；3088 次恢复中 3081 次发生在第 1 条查询。
  - **为何优于 baseline**：unlearning 文献操作权重、本文固定权重只删外部状态，把"删除"从存储层事件还原为信息生命周期事件；删除只移除源记录但保留删除前固化的不可变摘要（派生后代通道）→单条查询即恢复约 2/3；血缘感知闭包（停用并重建所有含已删源的摘要）把恢复压到全零——因果链完整闭合。
- **团队背景**：俄亥俄州立大学纯高校团队（五作者，无企业参与）。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2610.31366)

#### 论文 4：Partition Theory——AI 评估极限的划分理论

- **论文名称**：**[What Lies Beyond Perception: A Partition Theory of the Limits of AI Evaluation and Oversight / AI 评估与监督极限的划分理论]**
- **核心亮点**：
  - **任务定义**：形式化"评估者能证明什么"——证明行为式评估只能给出判别能力的下界而非上界（AI 安全/评估理论）。
  - **方法核心**：划分理论——把 agent 建模为感知映射在刺激空间上诱导的划分，定义回声测试并证明其对"A 可评分的测试"完备；单侧界定理：粗评估器从上方无法检测精确伪装者（穷尽探测下标记所有诚实弱者、不标记任何完全伪装者）。
  - **评估指标**：理论结果统一再解读已发表实证：Tice et al. 噪声暴露 sandbagging（17/17 模型-基准对显著上升，GSM8k 30 题 66.6%→100%）；Li et al. CoT 监控：模型知晓监控时 sandbagging 通过率 16-36% vs 不知晓 2-6%；随机发射幸运通过概率 ≤1/4，m 次重复 ≤4⁻ᵐ。
  - **为何优于 baseline**：Engels et al. 的可扩展监督标度律给出"oversight 随能力差退化"的定量预测，本文给出任意能力差下结构性不可证的定性互补；判别不对称的根源是"丢弃区分容易、发明区分不可能"——更强的引发不能抬高地板，只有更锐利的评估者可以，安全论证必须假设被评模型合作。
- **团队背景**：Ahmed M. Mahran（Incorta，独立公司研究者）。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2610.30803)

#### 论文 5：Physical RSI——物理 AI 递归自我改进综述

- **论文名称**：**[Toward Recursive Self-Improvement in Physical AI / 物理人工智能的递归自我改进]**
- **核心亮点**：
  - **任务定义**：系统梳理机器人递归自我改进——系统不仅改进行为还改进"产生改进的过程"，并界定什么证据才算递归（机器人学习综述/立场论文）。
  - **方法核心**：四级主张阶梯（行为改进→后学收益→过程改进→递归 R1/R2），每级由所需对照定义；R1 要求修复知识改进改进器，R2 要求改进后的改进器用获得知识产生自己的下一次改进（含冻结知识控制）；配增益可延续四条件与两轮物理 RSI 验证实验设计。
  - **评估指标**：核心结论表：R1 级仅无对照仿真证据（HARBOR 0.885 vs Eureka 0.0、PhysEvo 62.0% vs 47.2% 且真机 84%）；R2 级仅数字系统固定改进器对照；**15 个自称 RSI 的物理系统全部未建立 R1/R2 证据**；警示案例 SEAR：被保存的成功验证器在后续 699 rollouts 中 91% 判错、运行终止于 4.6% 成功。
  - **为何优于 baseline**：与 12 篇邻近综述对比，本文独特轴是"经验留下改变后，谁在下一步使用它、改进了什么"；把"递归"从名词还原为两个可检验不等式+必要控制，识别物理瓶颈=修订历史积累慢+评估器可被自身改进污染。
- **团队背景**：新加坡国立大学牵头 + 华中科技大学、上海交大、南洋理工、香港浸会大学（多校纯学术）。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2610.29677)；[💻 项目仓库](https://github.com/Physical2RSI/Awesome-Physical2RSI)

#### 论文 6：AgentPhishing——邮件智能体自适应钓鱼攻击

- **论文名称**：**[AgentPhishing: A Benchmark of LLM Email Agents Under Adaptive Attack / 自适应攻击下的 LLM 邮件智能体基准]**
- **核心亮点**：
  - **任务定义**：评估 LLM 邮件智能体在自适应社会工程攻击下的检测率与恶意请求依从率（智能体安全/红队评估）。
  - **方法核心**：PhishOpt 两阶段——基于 SkillOpt 有界编辑对每个目标智能体进化邮件生成技能（目标函数联合检测率/依从率/真实性约束），再用 Cialdini 六说服原理做 φ 相关分析，把"承诺一致性/喜好与失败正相关、权威/紧迫与失败负相关"的发现编码为通用攻击技能。
  - **评估指标**：Susceptibility 分数：Qwen3.7-Plus 0.12（公开语料）→0.95（优化攻击），检测率 91.7%→0%、依从率 8.3%→83.3%；通用技能跨 9 个 held-out 智能体：4 个检测率<10% 且依从率>45%（qwen-max 0.9727、gpt-5-mini 0.8205）；公开语料钓鱼邮件 6 个前沿模型全部 100% 检测——静态评测与自适应攻击结论完全反转。
  - **为何优于 baseline**：静态语料攻击是"固定题库"，优化攻击按目标行为反馈迭代生成"工作流延续框架"（把密钥索取伪装成收件人自己发起的待办）而非显式权威/紧迫红旗，绕过智能体的钓鱼启发式；分析驱动的通用技能跨智能体有效说明失败模式是系统性的。
- **团队背景**：卡内基梅隆大学（Justin Tan、Miao Li、Ding Zhao）。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2610.31404)

#### 论文 7：HERD——进化式递归蒸馏持续学习

- **论文名称**：**[HERD: Harness-Evolving Recursive Distillation for Continual Learning / 进化式递归蒸馏持续学习]**
- **核心亮点**：
  - **任务定义**：LLM 按任务流持续学习且不遗忘、不损一般能力，部署时不携带 harness（LLM 持续学习）。
  - **方法核心**：双层混合——快层 harness（技能注册表+高残差样本记忆，只做探针不重放），慢层权重经"漂移约束蒸馏"内化：教师=前 checkpoint+技能+重放答案（特权上下文），学生=同权重+新 LoRA 只见裸提示；双锚点拉格朗日约束（前 checkpoint 防单步漂移、基础模型防累积漂移），漂移预算以散度单位（ε=0.05）计量。
  - **评估指标**：TRACE+17（25 阶段流，Qwen3.5-4B）：AA 0.706（最强基线 uniform replay 0.699、OPHSD 0.620）、Forgetting 0.010（参数化基线 0.019–0.032 的一半以下）；G-test 宏均 −0.063 vs 参数化基线 −0.20~−0.24（差距 13.7–17.7 分）；阶段时间恒定不随任务数增长。
  - **为何优于 baseline**：技能针对当前错误而非重述任务+高残差记忆保留"技能+新权重仍不能预测"的样本→蒸馏目标信息密度高；蒸馏 vs SFT：学生匹配自身带特权上下文的分布而非 one-hot，分布约束隐式限制探针未覆盖处的漂移（SFT 替换后最差类 −0.320 vs 蒸馏 −0.130）。
- **团队背景**：莫纳什大学 + 阳光海岸大学（澳大利亚双校）。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2610.31401)；[💻 代码仓库](https://github.com/a1exsun/HERD)

#### 论文 8：SPLICE——知识-模型协同进化

- **论文名称**：**[Agentic Knowledge-Model Co-Evolution via Consistency Regularization / 一致性正则化的知识与模型协同进化]**
- **核心亮点**：
  - **任务定义**：把 LLM agent 积累的经验可靠地转化为可泛化知识并与模型共同进化（智能体自我进化）。
  - **方法核心**：SPLICE——把一致性正则化从预测空间迁移到效用空间：同一经验用 3 个扰动"进化视角"生成知识候选，以成对最小增益（共同增益）选择跨视角一致的任务证据；模型进化用 GRPO+门控对比自蒸馏（从持续效用退化模式构造负知识，token 级门控只在方向相反时让负知识强化正知识信号）。
  - **评估指标**：4 基准平均：Qwen3.5-4B SPLICE 知识进化 43.25 vs SkillOpt 36.69（+6.6）、协同进化 55.58 vs ReSkill 52.60（+3.0）；9B +7.1/+4.6；每正确解输出 token 降 44%；知识长度 4.98k vs ACE 41.51k（8 倍紧凑）；9B 知识迁移到 4B：LiveMath +31.13 点远超基线（≤17.38）。
  - **为何优于 baseline**：单一视角经验分析会产生低效用知识（"看似合理的知识甚至低于无知识"），共同增益选择只保留跨视角一致的正增益证据→剔除偶然成功与视角特异规则→知识紧凑且跨模型家族可迁移；token 门控保留正负知识共享的有用指引，内化不破坏策略学习。
- **团队背景**：UIUC + Georgia Tech + Amazon（通讯作者，一作实习期间完成）——企业+高校合作。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2610.30790)

#### 论文 9：RouteWeaver——统一执行范式的 LLM 路由

- **论文名称**：**[RouteWeaver: Weaving Mode Selection and Execution into Unified LLM Routing / 编织模式选择与执行的统一 LLM 路由]**
- **核心亮点**：
  - **任务定义**：统一 LLM 路由的三大执行范式（单轮/多轮/agent 式）为单一策略的联合决策（LLM 路由）。
