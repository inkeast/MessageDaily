**三篇为何合读**：Agent 的记忆系统正在从"能不能记住"走向"该怎么治理"。这三篇论文恰好覆盖治理的三个正交维度——**价值**（一条记忆值不值得信，MemTrial）、**安全**（一条记忆该不该进入上下文，What to Admit）、**容量**（历史压成摘要后丢了什么、怎么补，REMORY）。三者都指向同一个新共识：记忆不是越多越好，也不是越少越好，而是需要在正确的位置做正确的决策。

## 一、论文背景

### 1.1 Agent 记忆：从"记什么"到"怎么管"

先用一个类比建立直觉。把 LLM Agent 想象成一位新入职的员工：

- **工作记忆**是桌面上摊开的文件——当前对话的上下文窗口，容量有限但随时可查；
- **持久记忆**是抽屉里的笔记本——Agent 把过往决策的经验教训写进去，之后按需取用。

主流做法（Reflexion、ExpeL、FinMem、MemGPT、Mem0 等）围绕笔记本做文章：什么时候写（反思失败决策）、怎么组织（分层、图谱）、怎么取（按相似度检索）。但 2026 年的研究前沿发现，真正的问题不在记什么，而在**治理**：一条记忆被写下来之后，谁决定它值多少分、能不能用、以什么形式用、以及压缩后还剩多少？这三篇论文分别把其中一个决策点变成了独立的研究问题。

### 1.2 金融场景的特殊困境：结果混淆（MemTrial 的动机）

在投资组合管理这类金融任务里，一个决策的收益主要由**市场整体走势**决定，而不是 Agent 的选择。某天大盘涨了 3%，几乎所有持仓都跟着涨。此时如果 Agent 用"用了这条经验的决策赚钱了"来给经验记功，它实际上是在给**市场**记功，不是给经验。

这就像没有对照组的临床试验：病人吃了药好了，可能是药效，也可能是自愈。MemTrial 论文用数据实证了这一点：在 PortBench、InvestorBench、ClassAlloc 三个真实基准上，outcome credit（结果信用）与 1/N 等权基准收益的 Spearman 相关系数高达 **0.91-0.97**（完全跟着市场走），而它与经验真实贡献的相关性只有 **-0.02 到 0.07**（几乎无关）。更糟的是，经验在 56 个月中仅有 2-4 个月对决策产生可检测的影响。结果是：所有现存的经验学习 Agent 在这些基准上全部跑输简单的 1/N 等权组合，落后 15-38%。

### 1.3 记忆的两面性：谄媚与泄漏（What to Admit 的动机）

个人助手场景下，持久记忆是把双刃剑。论文开篇举了一个精确的例子：记忆条目"用户自 2013 年起购买并自托管比特币"——

- 用户问"我该怎么买比特币？"→ 这是**专业经验信号**，可以给出更进阶的解释；
- 用户问"我该投资什么？"→ 这只是背景，既不构成当前投资偏好，也不证明比特币适合新投资；
- 用户问"简历怎么写？"→ 完全无关。

正确的回答取决于两个当前记忆系统不做区分的决策：这条记忆**要不要进入**本次生成的工作上下文（admission，准入），以及进入后**如何组织表述**（presentation，呈现）。现状是把检索到的记忆逐字（verbatim）注入，把两个问题都甩给生成模型隐式处理——结果往往默认滑向**谄媚式迎合**（顺着用户偏好说话）或**跨域泄漏**（把 A 场景的偏好带进 B 场景）。此前 PersistBench 的测量显示：18 个前沿 LLM 的记忆诱导谄媚失败率中位数高达 97.8%，跨域泄漏中位数 53%。

### 1.4 摘要丢信息：压缩后的预测缺口（REMORY 的动机）

长程 Agent（浏览、终端操作、自动化工作流）在有限上下文窗口内工作，必须周期性压缩历史。主流做法是文本摘要——Claude Code 和 Codex CLI 的 /compact 命令就是典型：把之前的交互压成一份摘要检查点，Agent 从检查点继续。输入长度呈锯齿状：增长、压缩、再增长。

问题在于：**保住了主线不等于摘要能支撑后续所有决策**。摘要者无法预知任务后续需要哪些细节。有趣的是，REMORY 从人类认知找到类比：人类工作记忆只能同时持有约 4 个组块，却能维持数月数年的复杂项目，靠的是海马索引理论描述的机制——部分线索激活一个索引，索引重新激活分散在大脑皮层的早期经验表征。摘要像"陈述性检查点"，而压缩时丢失的预测性细节需要另一种可学习的载体。

## 二、论文定位和关联工作

### 2.1 MemTrial：经验学习的信用分配革命

**前序谱系一：金融 LLM Agent**。FinMem 按相似度/新近度/重要性排序记忆（重要性由交易反馈强化）；FinCon 用言语强化更新多 Agent 投资信念；FinAgent、CryptoTrade 反思过往交易；TradingAgents 模拟交易公司角色；InvestorBench、PortBench 提供评测基准。共同缺陷：全部用决策结果给记忆记功，而结果被市场主导，且从不检验学到的东西能否泛化到未来日期。

**前序谱系二：通用经验学习**。Reflexion 把失败反馈转为言语反思；ExpeL 从成败轨迹蒸馏洞见；Voyager 维护技能库；MemGPT、MemoryBank、Generative Agents 按新近度/重要性/相关性决定存取。这些方法在游戏、编码等"结果反映自身选择"的环境有效，但在"共享冲击主导结果"的金融市场失效。

**前序谱系三：数据估值与因果方法**。Data Shapley、Beta Shapley、DataBanzhaf 用边际贡献估值数据点；影响函数近似删除一点的效果；提升建模（uplift modelling）与反事实学习从观测数据估效应。这些方法为固定模型和固定测试集估值，而 MemTrial 要在每天只有一次、且是付费带噪 LLM 调用的场景下估值，并把估值与"何时可信"绑定——这是方法论移植的关键差异。

**定位结论**：MemTrial 不是发明 Banzhaf 值（1964 年就有了），而是**首次指出并实证"LLM 金融 Agent 的记忆信用被市场混淆"**，然后把实验设计（因子设计）、小区域估计（Fay-Herriot 模型）、prequential 检验、收缩锚定四件统计工具组合成闭环，移植到 Agent 记忆信任决策上。

### 2.2 What to Admit：记忆安全治理的杠杆解耦

**前序谱系一：记忆系统与风险测量**。Generative Agents 引入记忆流；MemGPT 适配分页；后续系统加遗忘曲线、压缩、多层存储。风险侧：PersistBench 形式化记忆诱导谄媚与泄漏；MemSyco-Bench 扩展到五类受控任务。本文以 PersistBench 为开发面、MemSyco-Bench 为外部面，研究缓解而非测量。

**前序谱系二：三阶段防御**。存储侧准入（写入前打分，优化记忆库质量而非后续使用）；检索层防御（查询时二元相关性决策）；最接近的 MemGate 学习查询条件神经门控。呈现层：结构化分区在推理时降低泄漏但谄媚基本不变；指令级引导（standing prompt）只做呈现不做准入；删除中心方法（认证移除、遗忘）与本文正交。

**定位结论**：据作者所知，这是**首个在同一记忆系统上把 admission 与 presentation 两个杠杆解耦并分别度量**的工作。关键对照：由于谄媚/泄漏记忆在构造上就是主题相关的，相似度门控（Gate 复现）无法把它们与有益记忆分开（ofj 客观事实判断失败率 45.2%→45.5%，p=1.0，零改善）——这是与所有相似度类方法的根本区别。

### 2.3 REMORY：压缩表示学习的"残差转向"

**前序谱系一：摘要+检索路线**。ReadAgent 把 episode 要点与原文段落配对；MemGPT 分离工作/归档记忆；ReSum 用周期摘要支撑长程搜索；AgentFold 在轨迹内做多尺度上下文管理。这些方法保留文本检查点与检索接口。REMORY 同样保留两者，额外学习一个以检查点为条件的连续表示。

**前序谱系二：连续压缩表示**。AutoCompressors、Gist Tokens、ICAE 学习更长文本的连续表示；LCLM 规模化编码器-解码器压缩；分布匹配为提示压缩提供行为准则（Wingate 2022）；递归与记忆 token 跨段保留信息（Transformer-XL、Recurrent Memory Transformer）。REMORY 的关键限定：把上述压缩目标**收窄到"摘要之后的剩余预测缺口"**，并通过冻结 actor 训练——摘要已覆盖的内容不需要软记忆重构。

**三篇定位对比表**：

| 维度 | 之前的主流路线 | 本组论文的突破 |
|---|---|---|
| 记忆价值评估 | outcome credit：赚钱即功臣 | 同日对照实验分离市场项，先预测住未来再信任 |
| 记忆安全治理 | 相似度门控 / 指令引导，准入呈现混为一谈 | 属性-策略分离的情境裁决，准入呈现解耦度量 |
| 上下文压缩 | 文本摘要（可读但丢信息）或全软压缩（不可读） | 摘要（检查点）+ 软记忆（残差）互补构造 |

## 三、问题定义

### 3.1 MemTrial：把"经验值多少"变成受控实验

**具体问题**：金融 LLM Agent 检索 4 条经验做决策，如何知道每条经验到底改变了什么？

**核心洞察**：经验的边际贡献 ≈ 临床试验的处理效应。同一决策日、同一市场路径下，"用了经验 h 的草稿"与"没用经验 h 的草稿"的效用之差，就是 h 的净效应——两者共享的市场项在差分中相消。

**形式化**：给定决策日 t、检索集 R_t = (h_1,...,h_4)、市场状态 s_t，Agent 输出权重 x_t 经投影 P_θ 满足投资者约束后持有，效用 u_t(x) = R_t − (γ/2)V_t(x)（确定性等价收益）。目标是最大化累计效用 Σ_t u_t(x_t)，手段是学习每条经验的反事实贡献 c_{t,j}（Banzhaf 值）并在其可泛化时才据此行动。

**精妙之处**：两个挑战直指现有方法的结构性盲区——CH1（测量贵且噪：每次评估是付费 LLM 调用，日期一去不返）与 CH2（泛化未知：过去日期的贡献不预测未来日期）分别被"因子设计+贝叶斯汇聚"和"prequential 信任检验+锚定行动"回应。论文诚实地把问题定义为"何时可以信任记忆"而非"如何用好记忆"——后者在真实市场上尚未被证明可行。

### 3.2 What to Admit：治理 = 两个映射

**具体问题**：生成时检索到 top-k 条记忆，如何避免谄媚与泄漏同时保留个性化收益？

**核心洞察**：治理可分解为两个映射——准入映射 A（每条检索记忆 m 映射为类型化单元 U(m)，选择哪些进入工作上下文）与呈现映射 P（进入的单元以什么表面形式编码进提示）。两杠杆成本不同、失败模式不同、效果量差异巨大。

**形式化**：默认部署是全部逐字注入。FC 设计判整条（U(m)={m}），PS 设计拆类型化单元（如"我喜欢 A 品牌因为电池耐用"拆成偏好单元+事实声明单元，同一句话的不同部分可获不同资格）。两杠杆都在推理时操作：不重训、不删除、不编辑存储内容。

**精妙之处**：属性与行动分离——裁决器只输出属性（类型/主体/认识论状态/时态性），确定性策略把属性编译为资格判断，裁决器从不决定答案该怎么做。这让"判断"可审计、"策略"可确定性地改。

### 3.3 REMORY：摘要之外的残差学习

**具体问题**：历史压缩成摘要后，如何让冻结 LLM 逼近"持有完整历史时的续写"？

**核心洞察**：软记忆 token ≈ 序列维度的残差连接。摘要 S_i 是主干（可读检查点），软记忆 M_i 是残差补偿（可学习的连续向量），拼接 [S_i; M_i] 之后接新交互。数学上 M_i = C_φ(H_i; S_i)，|M_i| ≤ m（有界，4096 槽）。

**形式化**：教师（冻结 actor p_θ）见完整历史 C_full，学生（同一冻结 actor）见摘要+软记忆 C_mem，两者预测同一后续回复，优化学生到教师的反向 KL：L(φ) = Σ_j w_j·D_KL(q_j‖p_j) / Σ_j w_j，只更新记忆网络参数 φ。

**精妙之处**：训练目标被限定为"摘要之后的剩余预测缺口"——记忆允许与摘要内容重叠，不需要重构每个被省略的事实。这与 Gist/ICAE 对全文做压缩的目标有本质区别：残差只补摘要补不上的部分。

## 四、问题解法

### 4.1 MemTrial 四步闭环

**类比**：像法庭审案——举证（反事实归因）、合议（价值估计）、宣判（信任检验）、执行（锚定行动）。每一步都为上一步的噪声和不确定性兜底。

**步骤一：反事实归因（Section 3.2）**
- 输入：决策日 t、检索的 4 条经验、市场状态；
- 做法：用 2^(4-1) 半分数因子设计（resolution IV）选出 8 个子集（含空集与全集，每条经验出现在一半草稿中，任何两条不与其他两条的交互混淆），并行生成 8 份决策草稿；经验 j 的贡献 = 用它的草稿均值效用 − 没用它的草稿均值效用；
- 直觉：所有草稿面对同一市场，共享项相消；在 16 个全子集上该主效应等于经验的 Banzhaf 值，半分数设计只多承担 13-17% 的噪声方差（与三阶交互混叠的代价）；
- 输出：每日每经验的中心化贡献 y_{t,j}（减去 4 条均值，去掉"所有经验的共性"）。

**步骤二：分层贝叶斯价值估计（Section 3.3）**
- 类比：小区域估计——用几个问卷响应估小镇收入，靠"相似城镇"借力；
- 做法：Fay-Herriot 型模型，m_h = v_h + ε_h（经验 h 的观测均值 = 真实值 + 噪声），v_h = z_h^T·β + b_h（真实值 = 内容回归 + 经验自身偏差），z_h 是检索嵌入的前 8 个标准化主成分；后验均值给出收缩估计：测量少的经验向内容预测值收缩，新经验直接用 z_h^T·β 预测；
- 输出：跨日期、跨相似经验汇聚的价值估计 v̂_h，两模型（按经验/按内容）按前向分数择优。

**步骤三：信任检验（Section 3.4）**
- 类比：天气预报员按"预测明天的准确度"考核，而非"拟合昨天的好坏"（prequential 分析）；
- 做法：每个日期前，模型只用已知结果的日期拟合，预测当日检索经验的价值；结果揭晓后打前向分数（预测值与实测贡献的 Pearson 相关）；单边 t 检验（n≥10，α=0.05）通过才信任；
- 直觉：检验的是"学到的价值是否预测了未来"，不是"经验过去是否有差异"。

**步骤四：锚定行动（Section 3.5）**
- 做法：不信任时部署 x_t(q) = q·x_ref + (1−q)·x̄_t（保守参考 1/N 与草稿均值的在线混合），q 由带 KL 正则的 follow-the-regularized-leader 在线学习（先验 α_0=0.9 重押参考，正则随证据累积以 1/√n 减弱）；信任时部署预测总价值最高且为正的设计草稿（该草稿已生成过，零额外成本）；
- 成本：8 份草稿并行，LLM 成本为单草稿 Agent 的 8 倍（PortBench 约 $0.05/决策）；价值模型拟合毫秒级。

### 4.2 What to Admit：情境裁决 + 双准入设计 + 双呈现

**核心机制：情境裁决（situated adjudication，Section 3.2）**——一次批量裁决调用同时看：查询、近期对话、基准提供的证据、全部 top-k 记忆（可做跨记忆冲突检测）。三个固定属性：(1) 属性评估与策略决策分离（裁决器只判属性，确定性代码编译资格）；(2) 情境感知（先判答案目标——关于用户/第三方/世界，与任务模式——事实/推荐/规划/支持，再判单元，同一记忆对不同查询可不同资格）；(3) 物理排除（不合格单元从生成提示中删除——是"不在场"而非"标注不在场"）。

**准入设计一：FC（因子编译准入）**——整条评估，赋予类型化影响因子（范围/主体匹配/角色/认识论支持/时态/效用），确定性编译到 5 类频道：需遵循的约束、个性化信号、非权威用户观点、支持性上下文、不确定上下文。策略**非对称失效**：约束与当前偏好 fail-open（不确定则保留到支持频道），信念与未验证事实 fail-closed（不确定则排除）。

**准入设计二：PS（权限语义准入）**——先把条目拆成类型化单元，属性映射到 6 类权限（5 类许可使用 + deny），deny 单元从提示物理删除。颗粒度从"条"细化到"义素"。

**呈现层两变体（Section 3.3）**——PN（权限注记头：每节声明本节信息可用于本次回答的什么）vs CH（类型频道头：按信息类型分组）。两者编码相同的权限语义、相同的准入内容，只差分节标签与组织——这正是 verdict-shared 对照能隔离呈现效应的原因。

**严谨性设计**：预注册（三份文档在数据收集前冻结）、资产冻结（提示/频道头/权限模式固定）、verdict 共享机制（PN 臂先跑、写裁决到账本，CH 臂读账本不重判，保证准入决策完全相同）、独立审计脚本从原始逐样本标签重算所有统计量。

### 4.3 REMORY：两阶段训练穿过冻结 Actor

**架构（Section 2.1）**：记忆网络以（历史+摘要）为输入。冻结 actor 特征 + 学习查询并行预测记忆向量，对摘要做门控交叉注意力（摘要条件化）。每 1024 个源位置产 64 个软 token，分层压缩至 4096 槽上限并保留源序。Qwen3.8-27B 版采用 DFlash 架构（1.94B 可训参数），GLM-5.3-Flash 版用 DFlash-2 分组动态卷积（1.502B 可训参数）。输出是连续记忆而非词表 token；梯度穿过冻结 actor 训练接口而不动 actor。

**阶段 I：重构（Section 2.2）**
- 类比：老师看原文复述，学生只看软记忆复述，两人复述同一份原文；
- 教师（冻结 actor）收源段落 + 复述指令；学生（同一 actor）把段落换成软记忆 + 同一指令；都预测源文本；训练数据：MMFineReason-Full-2.3M 的文本字段；
- 作用：教记忆网络保留源信息，为阶段 II 提供初始化（图 3d 显示重构初始化在残差目标下显著优于随机初始化）。

**阶段 II：摘要条件化续写**
- 教师（冻结 actor）见原始交互历史；学生见对应固定摘要 + 从该历史构造的记忆；两者预测同一后续助手回复；记忆编码器永远看不到未来响应；
- 优化学生到教师反向 KL（等式 3），损失覆盖全词表与完整回复，正权重轻微强调早期位置；
- 数据：推理与编码轨迹（Open-PerfectBlend 提示词，预计算摘要 + Qwen 生成响应），按前置上下文长度排序的课程学习；
- 作用：摘要已可用，记忆被导向"摘要留下的剩余预测缺口"。

**部署形态**：压缩边界处拼接 [摘要; 软记忆]，之后接新交互；精确记录仍通过普通归档/文件检索工具获取——检查点可读、残差可学、归档可检索，三者互补。

**三篇方法全景对比**：

| 组件 | MemTrial | What to Admit | REMORY |
|---|---|---|---|
| 决策点 | 决策前（信任与否）+ 决策中（选草稿） | 生成前（准入+呈现） | 压缩边界（构造残差） |
| 核心机制 | 因子设计差分 + 贝叶斯收缩 + t 检验 | 属性-策略分离裁决 + 物理删除 | 冻结 actor 分布匹配 + 两阶段课程 |
| 是否改 LLM 权重 | 否 | 否 | 否（只训记忆网络） |
| 额外推理成本 | 8 倍草稿调用 | 每查询 1 次裁决调用 | 记忆网络前向 + ≤4096 输入位 |

## 五、评估指标与实验证据

### 5.1 MemTrial：四基准 + 15 方法对比

**指标体系**：主指标为投资者效用（确定性等价收益，%/月或 bp/天，三种风险偏好投资者平均）；辅助指标为累计净回报 CR、年化夏普比率 SR、最大回撤 MDD，以及财富相对 1/N 的落后幅度；消融指标为信任率（多大比例决策真正按学习价值行动）。

**数据集**：(1) PortBench-Full/Raw：99 资产 6 类，月度决策 20 个测试月（2023-24），338 条经验；(2) InvestorBench：4 股+现金，每日决策 149 天，63 条经验；(3) ClassAlloc：5 资产类月度 71 月，58 条经验（截至 LLM 知识截止后）；(4) PlantedMem：半合成，真实价格+真实 LLM 草稿，植入 12 条已知质量经验（3 有用/6 中性/3 误导），7 种机制设定 × 100 世界种子——专门检验"经验确有信号时能否学到"。

**主表（Table 3）关键数字**：五设置平均效用比最佳经验学习 Agent 高 **21.2%**；PlantedMem 上 15 法第一（0.87%/月，显著）；真实市场上距 1/N 最多低 2.2%（对比经验学习 Agent 落后 15-38%）；162 次运行财富从未落后 1/N 超 5%（基线在 22-44% 运行中如此）。

**RobustTo-LLM（Table D.17-19）**：8 个 LLM（gpt-4.1-mini/nano、gpt-5-mini、Gemini2.5Flash、ClaudeHaiku4.5、Llama-3.3-70B、Qwen3-235B、DeepSeek-V3.1）× InvestorBench 全部 11 个配置中，MemTrial 全胜（超最佳经验学习 Agent 4-33%）。

**信任检验的机制验证（Figure 6 + Table D.13）**：PlantedMem 无信号机制下信任率仅 2-3%；β=0.25 时从首年 12% 升至第十年 91%；真实市场 PortBench/InvestorBench 信任率 0-0.6%——检验响应的是"价值是否泛化"而非"经验是否有影响"（InvestorBench 上经验改变 85% 天的决策，但信任率仅 0.3%）。

**学习质量（Figure 5）**：PlantedMem β=0.25 时，学得价值与真实质量排序相关性 0.81（MemTrial）vs 0.08（outcome credit/MemRL）。

**为什么这套实验设计能证明论点**：PlantedMem 提供"已知真值"的受控检验（证明方法在信号存在时确实能学到），真实基准提供"诚实的负结果"（证明现有方法在无信号时确实受损、MemTrial 的锚定确实兜底）。两半缺一不可——只有前者会怀疑合成设定过强，只有后者会怀疑方法没用。

### 5.2 What to Admit：双评测面 + 三重对照

**指标体系**：外部基准 MemSyco-Bench 四任务 × 300 样本——ofj（客观事实判断失败率：存储偏好是否扭曲客观答案）、csc（情境范围控制：偏好是否泄漏出适用范围）、mec（记忆-证据冲突：存储声明是否压过提供的证据）、pm（个性化使用失败率：适当偏好未被应用，越低越好但收紧准入会推高）。合并失败率池化四个任务。判定：单一外部 judge GLM-5.2，与人机一致 κ=0.70。

**核心数字（Table 2）**：合并失败率 Bare 46.2% → FC 39.5%（−6.7pp，p=2.7×10⁻⁷）→ PS 37.4%（−8.8pp，p=4.1×10⁻¹²）；ofj 45.2%→20.4%（−24.7pp，p=7.6×10⁻¹⁹），答案准确率 56.2%→75.9%；csc 33.3→25.3；mec 91.7→84.0；pm 14.7→20.0（+5.3pp 恶化，FC 更差 +7.6pp）。

**三重对照设计**：
1. **Gate 基线**（复现 MemGate 查询条件门控）：ofj 45.2→45.5（p=1.0，零改善）、pm +8.0pp 恶化——证明相似度门控结构上无法分离主题相关的有害记忆；
2. **预算匹配对照**（各臂同 PS 单元数）：PS ofj 23.3% vs 随机选择 31.7%（Holm p=.001）vs 相关性排序 44.3%——证明外部收益部分来自选择质量本身；
3. **verdict-shared 呈现对照**（同裁决、同内容、只变渲染）：PN vs CH 九个任务-指标对中唯一显著单元（ofj 准确率 73.7→77.7，p=.043）过不了 BH 校正（q=.39）；1200 对池化差异 0.8pp（p=.43）——呈现层无稳健差异。

**单变量隔离（Section 5.4）**：开发面 DeepSeek-V4-Pro 跨域维度，只收紧注入集（影响分 <0.5 的记忆从提示剔除），其余全固定：失败率 42.5%→25.0%（p=1.6×10⁻⁴）——准入这一杠杆单独有效。

**边界发现（Section 5.5）**：GPT-OSS-120B 在测试配置下泄漏无改善（64.0%→70.0%，p=.12）；mec 任务所有保留冲突前提的臂误导率 82.3-85.7%，只有 NoMem 臂为 0%——措辞修复不了在场的前提；预注册效应量门槛未达（8.8pp < 10pp 阈值，pm 准确率 −6.0pp 超出 −3pp 界）。

**为什么这套实验设计能证明论点**：三重对照把"裁决管线整体有效"（pipeline 对比）、"选择本身有效"（预算匹配）、"呈现不重要"（verdict-shared）三个主张分别隔离——每个效应都有专属的受控比较，而非依赖同一张主表讲故事。预注册+审计脚本则压制了"挑好看的结果"的空间。

### 5.3 REMORY：同 Actor 严格对照

**指标体系**：SummHay（92 查询）三指标——Coverage（找回的洞见）、Citation F1（引用归因）、Joint（联合分，621 条参考洞见平均）；Agent 基准分数与成本；重复工具输出/工具错误计数（行为质量代理）；压缩后首动作盲评胜率。

**SummHay 主表（Table 1，Qwen3.8-27B）**：

| 表示 | Coverage | Citation F1 | Joint |
|---|---|---|---|
| Raw context | 72.46 | 56.60 | 43.41 |
| Summary | 67.55 | 56.98 | 39.84 |
| Summary++（等预算文本补充） | 67.52 | 56.94 | 39.78 |
| **Summary+REMORY** | **67.95** | **61.03** | **43.39** |

关键读法：REMORY 用 5.2% 的输入位置（5,024 vs 96,872）追平全上下文的 Joint 分（43.39 vs 43.41）；Citation F1 +4.04；等预算的文本补充（Summary++）完全无效（39.78≈39.84）——**同样的位置预算，学习的连续 token 有效，生成的文本无效**。553 条两条件共同覆盖的洞见上 Citation F1 仍从 57.31 升至 61.41，配对 bootstrap 95% 区间 [+0.74,+6.21]。

**Agent 基准（Table 2-3）**：同 actor 内双臂对照（权重/harness/提示/工具/解码/预算/压缩策略全固定，双臂均可检索精确历史）。Qwen3.8-27B：AutomationBench 35.5→45.3（+9.8）、JobBench 33.4→41.0（+7.6）、Terminal-Bench 2.1 71.9→76.4（+4.5）、BrowseComp 74.0→77.0（+3.0）；GLM-5.3-Flash：TB 84.3→87.6（+3.3）、BrowseComp 84.9→89.0（+4.1）。重复工具输出降 17.9-29.8%、工具错误降 25.3-49.7%；成本除 JobBench（$3.09→$3.21）外全部下降。

**首动作盲评（Section 3.3）**：488 个配对下一动作，GPT-5.6-Sol 匿名评审：残差动作 345 胜（70.7%）/21 平/122 负。

**案例**：LiveTrading 双账户案例（2026-09-23 截止）：结算 ROI −11.86%（无残差）vs +5.11%（有残差），生成成本 $303.81→$170.30（论文注明两轨迹的市场选择与时机不同，回报对比受限）。

**为什么这套实验设计能证明论点**：SummHay 把"覆盖"与"归因"分开度量，残差的增益集中在归因（+4.04）而覆盖几乎不变（+0.40）——这正对应"连接找回的声明与支持证据"的联想式解释，排除了"残差只是记住更多"的替代解释。Summary++ 对照排除了"位置预算"混淆，同 actor 双臂排除了模型能力混淆。

## 六、效果优势的根源解释

### 6.1 MemTrial：差分消除混淆项的因果链

**对比对象**：outcome credit（FinMem/MemRL/ExpeL 等的经验学习机制）——它曾经有效，因为游戏/编码环境中结果确实反映 Agent 自身选择。

**baseline 的根本局限**：市场结果 = 共享行情 + 经验效应，而 outcome credit = 当日均值 + 一半贡献，第一项主导（ρ=0.91-0.97）。这不是"没做归因"的工程缺陷，而是**结构性的不可分离**：单臂观测数据中处理（用某经验）与混杂（市场）完全纠缠，任何事后回归只能关闭三分之一的差距（Uplift credit 实验）。

**因果链**：同日同市场因子设计草稿差分（方法差异）→ 共享行情项在对比中精确相消、贡献估计偏差只剩三阶交互混叠（机制变化）→ 学得价值与真值排序相关 0.81 vs outcome credit 的 0.08（指标提升，PlantedMem β=0.25）→ 单日贡献噪声大（56 月仅 2-4 月有效应）→ 分层贝叶斯跨日期跨内容收缩进一步降噪 → 即便如此真实市场值不外推（信任检验通过率 0-0.6%）→ 锚定 1/N 保证下行有限（≤2.2%）。

**反事实推理**：去掉信任检验直接按贡献行动（Counterfactual selection），真实市场上同样落后 1/N；去掉锚定换成草稿平均（Draft averaging），损失 16-41%。两个组件的必要性都被消融证明（Figure 4）。

**边界与诚实的负结果**：论文 Limitations 明确承认：真实市场增益来自锚定的"不做"，而非记忆的"用好"；ClassAlloc 上信任检验通过的 93 个决策中，被信任草稿反而比锚定混合少赚 0.05pp；LLM 存在前瞻偏差（知识截止前能背出市场回报，绝对回忆相关 0.10-0.63）。MemTrial 证明的核心主张因此收窄为："现有经验学习在真实市场受损，MemTrial 通过可信的'不信任'止损"——这正是实验设计支撑的范围。

### 6.2 What to Admit：认识论切分优于相似度切分

**对比对象**：查询条件门控（MemGate 类）——曾经有效，因为多数噪声记忆确实主题无关。

**baseline 的根本局限**：谄媚/泄漏记忆**在构造上就是主题相关的**（"用户买了比特币"与比特币问题高度相关）。相似度空间的门控面临两难：要么把有害与有益一起放行（ofj 零改善），要么一起拒绝（pm 恶化 +8.0pp）。这是表征层面的几何限制，不是阈值调优问题。

**因果链**：情境裁决按认识论状态（验证过的事实？用户信念？）与范围相对查询（答案关于用户还是世界？）切分（方法差异）→ 有害偏好单元被物理排除出上下文，无法再影响生成（机制变化：不在场 vs 标注不在场）→ ofj −24.7pp、准确率 56.2%→75.9%（指标提升）；预算匹配下 PS 仍胜随机/相关性选择，证明收益部分来自选择本身而非注入格式。

**mec 的顽固性解释**：记忆-证据冲突下（误导率 82.3-85.0%），只要冲突前提还在上下文里，生成器就压倒性地跟随它——**任何措辞（PN/CH/注释）都无法修复在场的前提**，只有物理删除（NoMem 臂 0%）有效。这反向强化了"准入是正确杠杆"的论点：能被措辞解决的事情呈现层早就解决了。

**pm 恶化的根源**：准入收紧必然误伤——结构不同的 FC（+7.6pp）与 PS（+5.3pp）在同一任务过冲，说明代价在准入这一杠杆本身而非某个实现。裁决日志显示 56% 应受限单元被判为 CONTEXT、仅 8% 被 deny——裁决器在细粒度情境权限上欠触发（180 对探针实验中 PS 对等预算相关性臂无显著优势）。

**适用边界**：非对称失效策略（fail-open/fail-closed）意味着收益与代价绑定在同一开关上；GPT-OSS-120B 的零改善说明配置特异性（另一生成时配置能把它从 84.0% 降到 45.5%，但机制未明）。预注册门槛未达（8.8pp<10pp）——论文选择如实报告而非降低标准。

### 6.3 REMORY：可微表示填补文本不可表达的缺口

**对比对象**：纯文本摘要 + 等预算文本补充（Summary++）——曾经有效，因为多数任务主线足够。

**baseline 的根本局限**：摘要丢弃的信息是**分布层面**的（下一个 token 的预测概率），不是"哪些事实被省略"能枚举的。Summary++ 实验给出关键证据：给摘要加同样多的生成文本位置，Joint 分纹丝不动（39.78 vs 39.84）——**被丢弃的归因线索无法靠"更多文本"重新表达**。这是模态限制：文本重述只能传递可命题化的内容，而连续向量可以承载对冻结 actor 预测分布的微调。

**因果链**：软 token 在冻结 actor 输入空间中直接构造可微分表示（方法差异）→ 经"穿过冻结 actor 的反向 KL 分布匹配"训练，残差被导向摘要后的剩余预测缺口（机制变化：不是重构全部信息，而是对齐续写分布）→ 归因线索恢复（Citation F1 +4.04、553 共同洞见上 57.31→61.41）而覆盖不变（+0.40）→ Agent 侧更好的先前反馈获取 → 重复输出降 17.9-29.8%、错误降 25.3-49.7% → 四基准一致增益且多数更便宜。

**两阶段必要性**：图 3(d) 显示残差目标下重构初始化显著优于随机初始化（训练诊断曲线）——阶段 I 不是可有可无的预热，而是阶段 II 收敛的前提。

**通用性证据**：增益跨两个 actor（Qwen 1.94B / GLM 1.502B 记忆网络）、跨四类基准（浏览/终端/工作流/专业任务）一致成立；GLM-5.3-Flash+残差 89.0 接近发表的前沿参考（Gemini 3.1 Pro 88.0 / GPT-5.6 Sol 90.4，注意前沿数字用原始 harness，非受控对比）。

**未决问题**：案例研究（细胞分割修复）只演示互补性，未定位具体哪些省略细节来自记忆；LiveTrading 是单轨迹对比，市场差异限制回报结论；软记忆不可人读，出错时调试成本高于文本摘要（论文未讨论，属推测）。

### 6.4 三篇合观的共同根源

三个优势根源指向同一结构性原理：**在信息的原始证据尚完整的时刻做决策，并让决策的作用机制与信息的载体匹配**——MemTrial 在市场结果揭晓前做同日对照（证据=完整市场路径）；What to Admit 在生成前物理排除（作用机制=上下文在场性）；REMORY 在压缩边界学习连续残差（载体=可微输入空间而非命题化文本）。三者的 baseline 失效都源于"决策点后移/载体错配"：事后归因遇到不可分离的混淆、措辞引导遇到无法撤销的在场、文本补充遇到无法命题化的分布信息。

## 七、必要知识反推

假设让一个完全没有背景的人重做这三项工作，最少需要掌握什么？

### 7.1 领域知识层

- **LLM Agent 与记忆系统的运作机制**（三篇共用）：理解检索-生成循环、经验如何写入与取出、上下文窗口的锯齿模式——不知道这些就无法定位"决策点"该放在哪。REMORY 还需要长程 Agent 的实际形态（Codex CLI 的 /compact、工具调用轨迹）。
- **金融学与投资组合基础**（MemTrial）：确定性等价效用、投资者约束（风险资产上限/防御资产下限）、1/N 组合为何难以战胜（DeMiguel 2009 的经典结论）、交易成本对频繁调仓的侵蚀——不理解"为什么 1/N 是强基线"就会误判改进空间。
- **记忆风险分类学**（What to Admit）：谄媚、跨域泄漏、记忆-证据冲突、有益个性化的四象限——不掌握 PersistBench/MemSyco-Bench 的问题分类就无法设计正交的评测面。
- **人类记忆的双重系统**（REMORY）：工作记忆容量限制与长时记忆的海马索引机制——这是"检查点+残差"构型的直觉来源。

### 7.2 方法论知识层

- **实验设计与因果推断**（MemTrial 最重）：因子设计/半分数/resolution IV、Banzhaf 值与主效应的等价性、混淆与对照的思想——论文的核心创造力正在于把 A/B 测试的方法论搬进 Agent 的日常决策。
- **贝叶斯分层模型**（MemTrial）：Fay-Herriot 小区域估计、收缩估计的直觉（测量少向先验收缩）、边际似然优化超参。
- **prequential 分析与安全部署**（MemTrial）：用前向样本外预测考核模型；安全策略改进（只有高置信胜过基线才部署）。
- **预注册与多重比较校正**（What to Admit）：McNemar 配对检验、Holm/BH 校正、效应量门槛——现代实证方法论的完整工具箱。
- **分布匹配与提示压缩**（REMORY）：Wingate 2022 的行为准则（匹配续写分布而非重构输入）、反向 KL 的性质、Gist/ICAE 的前序探索。

### 7.3 工程知识层

- **评测基础设施**：三篇都依赖重资产——MemTrial 跑 15 方法 × 4 基准 × 多 LLM 的受控日志；What to Admit 冻结 9,600 个外部判定并配审计脚本；REMORY 固定 harness 双臂对照。不会构造"只变一个变量"的部署，结论就无从谈起。
- **成本核算**（MemTrial/REMORY）：每决策 $0.05 的预算意识、token 计价的成本模型——LLM 实验的可行性约束。
- **记忆网络工程**（REMORY）：门控交叉注意力、分层压缩保序、DFlash 类架构、梯度穿过冻结模型的训练技巧。

### 7.4 知识融合的关键节点

- **节点一（MemTrial）**：把"数据估值"（ML 视角）与"临床试验对照"（统计视角）在"LLM 决策草稿"这个新载体上融合——因子设计作用于 LLM 采样而非固定数据集，这是没有任何单一领域预设过的组合。
- **节点二（What to Admit）**：把"访问控制"（安全视角：权限类别、fail-open/fail-closed）与"类型化语义单元"（NLP 视角）融合成权限语义准入——安全工程的经典二分法被移植到记忆治理。
- **节点三（REMORY）**：把"残差连接"（深度学习架构直觉）沿序列维度延伸到"摘要+软记忆"的互补构造，再用分布匹配准则（提示压缩文献）限定训练目标——两个独立传统的交汇产生了"只补缺口、不重构全文"的简洁目标。

## 八、论文中可以提取的通用性灵感

**灵感一：没有对照就没有信用——把 A/B 测试搬进一切评分系统**
- 核心思想：任何"用结果给输入记功"的机制，在存在共享混杂因素时都会系统性失真；同场对照差分是唯一可靠的清洗手段。
- 论文证据：outcome credit 与市场相关 0.91-0.97、与真贡献相关 −0.02-0.07；同日草稿差分把排序相关性提到 0.81（PlantedMem）。
- 推广场景：(1) 推荐系统的物品价值评估（曝光位混杂）；(2) 广告归因（渠道间共线）；(3) 多 Agent 系统中协作贡献分摊；(4) 自动化运维中规则库的效果归因；(5) 教育 AI 中学习资源与成绩的因果剥离。

**灵感二：先预测住未来，再部署——prequential 信任门槛**
- 核心思想：学到的东西在样本外预测成功之前一律视为未验证；部署时保留保守回退（锚定），随证据累积逐步放权。
- 论文证据：真实市场信任率 0-0.6% 时锚定把落后限制在 2.2% 内（基线落后 15-38%）；PlantedMem 有信号时信任率升至 91% 并兑现 +11% 于最佳锚定基线。
- 推广场景：(1) 自动交易策略的上线门槛；(2) AutoML 中自动搜索组件的灰度发布；(3) 机器人新技能的安全验证；(4) 企业知识库条目的置信分级；(5) 任何"学习到的策略 vs 保守默认"的在线切换。

**灵感三：不可分离的混杂用设计消除，而非用回归修补**
- 核心思想：观测数据的事后调整（回归控制）只能关闭部分差距；把整个对照实验内嵌到每次决策，混杂在估计中精确相消。
- 论文证据：Uplift credit（回归调整）仅关闭三分之一的 outcome credit 与反事实选择差距；因子设计差分直接消除市场项。
- 推广场景：(1) 在线服务的实时实验分层；(2) 临床试验的自适应设计；(3) 定价实验的地理位置对照。

**灵感四：主题相关性 ≠ 无害性——按认识论状态与范围切分信息**
- 核心思想：有害信息往往与任务高度相关（否则不构成威胁），相似度/相关性过滤在结构上无法分离它；需要正交维度（来源可靠性、时效、适用范围、验证状态）。
- 论文证据：Gate 门控 ofj 失败率 45.2→45.5（p=1.0）零改善；情境裁决按认识论切分后 ofj −24.7pp。
- 推广场景：(1) RAG 系统的检索后过滤（区分权威来源与用户臆测）；(2) 内容审核中的"相关但违规"识别；(3) 企业知识库的权限分级（不只按主题，还按可信度）；(4) 多轮对话中用户自我报告与外部事实的分离。

**灵感五：物理删除优于标注警告——在场性决定影响力**
- 核心思想：只要信息还在上下文里，任何"请忽略它"的指令都不可靠；改变行为最可靠的方式是改变什么进入上下文。
- 论文证据：mec 任务所有保留冲突前提的措辞变体误导率 82.3-85.7%，NoMem 臂 0%；呈现层（PN vs CH）无稳健差异。
- 推广场景：(1) 提示注入防御（物理剥离可疑段而非警告模型）；(2) 隐私合规（脱敏不如排除）；(3) 人类决策的注意力管理（移除干扰物优于自我告诫）。

**灵感六：决策杠杆解耦后分别度量——混合效应是归因失败的温床**
- 核心思想：把复合机制拆成正交杠杆，为每个杠杆设计专属受控对照；一个杠杆有效不能外推到整个系统，一个杠杆无效也不能否定系统。
- 论文证据：准入/呈现解耦后发现准入 −6.7~−8.8pp 而呈现无稳健差异；verdict-shared+预算匹配+单变量收紧三重对照各自隔离一类效应。
- 推广场景：(1) RAG 系统拆分检索/重排/生成归因；(2) 推荐系统分层评估召回与排序；(3) 任何 pipeline 系统的组件级消融设计。

**灵感七：可读检查点 + 可学习残差的互补构造**
- 核心思想：显式可读的摘要（人类可审计的主干）与学习的连续表示（模型可利用的残差）互补，二者条件化绑定；不需要残差重构全部信息，只补主干留下的缺口。
- 论文证据：Summary++ 等预算文本补充无效（39.78≈39.84）而软残差 Joint 追平全上下文（43.39 vs 43.41，5.2% 位置）；归因增益集中（Citation F1 +4.04）覆盖不变（+0.40）。
- 推广场景：(1) 数据库的可读快照+学习索引；(2) 编译器的 IR 摘要+神经辅助优化；(3) 语音合成的文本前端+神经韵律残差；(4) 任何"人要读、机要用"的双消费者表示场景。

**灵感八：把目标限定在"剩余缺口"上训练**
- 核心思想：当系统中已有一个可用的粗糙解（摘要、规则、启发式），不要从头学习完整任务，让学习组件专门对齐粗糙解未覆盖的残差——目标更小、样本效率更高、与既有组件不冲突。
- 论文证据：阶段 II 的记忆只对"摘要之后的预测缺口"做分布匹配，明确允许与摘要重叠、不重构每个事实；两阶段训练（先重构后残差）显著优于随机初始化。
- 推广场景：(1) 混合推荐（规则引擎打底、模型学残差）；(2) 量化交易中经典因子+神经残差；(3) 机器人控制的名义控制器+学习残差修正；(4) 机器翻译的记忆库+神经覆盖。

**灵感九：诚实的负结果是方法可信度的组成部分**
- 核心思想：报告"方法在哪失效"（MemTrial 真实市场信任率 0-0.6%；What to Admit 的 pm 恶化与门槛未达；REMORY 的案例不可归因）不仅不削弱论文，反而界定了效应的适用范围，是实证质量的信号。
- 论文证据：三篇都设有效应量门槛/限制章节并如实报告未达标；MemTrial 甚至证明"记忆在真实市场的增益尚待证明"这一自我否定式结论。
- 推广场景：(1) 科研写作与评审文化；(2) 企业 A/B 实验的失败归档制度；(3) 基准评测的"已知失效面"披露规范。
