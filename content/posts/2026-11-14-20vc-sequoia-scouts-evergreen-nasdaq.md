## 先说结论

本期 20VC 周评三人场（推断：Harry Stebbings 主持，Jason Lemkin、Rory O'Driscoll 联谈）拆四件大事。红杉宣布撤出伦敦办公室、终止 Scout 计划（外部「侦察兵」代投机制）、早期与成长团队合一，嘉宾认为真正有分量的是常青（Evergreen，长持型）基金的清盘——「智力上正确、结构上失败」。黄仁勋部分是辞任公告前两天录下的快照：一方认为「他需要一张通行证」，另一方反驳「可以希望、不能假设」，共同的增量判断是「钓鱼执法一无所获」与「中国才是最大输家」。纳指 100 单日蒸发 2.5 万亿美元被归因为杠杆化 pod（多经理基金内独立交易组）连环爆仓而非 AI 交易破裂——判据只看 OpenAI 与 Anthropic 的 ARR（年化经常性收入）。下半场回老本行：Anthropic 的 70–78 美元低开定价术与「市场疲劳」之争、OpenAI 增速回到 70%、agent（AI 智能体）「太贵太耗算力」的成本账、投委会三选一，以及 agent 时代 SaaS 席位模式被市场判「终局」。

## 红杉的一周：常青基金「智力上正确、结构上失败」

嘉宾开场就纠偏：伦敦撤办、合伙人之争都是「人间常态」，值得拆的是常青基金关停。复盘这套 2022–23 年落地的结构：原始判断没错——「无论我们风投做得多好，真正的钱是在 IPO 之后赚的」，红杉背景公司一度占纳斯达克约四分之一市值（节目口径），长期持有一篮子优质科技股理应跑赢标普。但三个问题致命：择时糟糕，刚让所有人锁仓就撞上下跌，「一年后跌 30%，很疼」；LP（有限合伙人）各有流动性需求，想自己做选择；最「有意思」的是激励错位——合伙人个体在清算 carry（超额收益分成）后想拿多久拿多久，若重演红杉投思科的故事，完全可以自己长持、把股票分给 LP 各自决定，而现在等于「强制 LP 吃下你以为的维生素」。另一嘉宾补充：Altos Ventures 的 Ho Nam（人名经转写校正）用一组续存基金（continuation fund，允许老 LP 退出、新 LP 接盘）实现了同样目标——对照之下常青结构「复杂、用力过猛，关掉是对的：把事情搞简单，钱照样赚」。这里还埋着通向英伟达话题的暗线：英伟达董事会上那位 1993 年进入的红杉背景合伙人，「我打赌他一股没卖、身家几十亿」——个体可以长持，机构不能替 LP 锁仓。

Scout 计划曾让红杉「领先所有人好几年」，但「秘密运转时效果最好」，被全行业克隆后优势摊平（按转写推断为 Jason 与 Rory 互补观点）；Jason 更直接：「不想用小合伙制去运营 Scout、去运营 Arc 这种连速成班都不算的平庸加速器」——他当年想过做 SaaS 加速器，一算要招 15 个人再管起来「就想跳楼」。他引 Founders Fund 对照：成长基金 11 个月投完、真正的投资专业人士只有三五个，押中 Stripe、SpaceX（转写另有一家疑为 Anduril，未确认）——「早期适度分散、后期极度集中」（约 20 笔收缩到七八笔）才是正事。伦敦一役，嘉宾承认欧洲确有好资产（点名 ElevenLabs、Bolt），但红杉的表态是「从美国足以覆盖」。Jason 给创始人的提醒是本场金句：「机构可以是持久的，任何具体的合伙人都不会持久」——红杉的 CFO、CEO、伦敦全体合伙人与一批美国合伙人已相继离开，「别把你的 VC 想得比他实际更永久」。

## 黄仁勋：辞任前两天的 VC 快照——通行证、调查选人与「中国是输家」

时点：节目自述录制于周二（按发布日倒推为 11-10），即黄仁勋辞任、CFO 临时接棒的公告（[Hard Fork 一手拆解](https://inkeast.github.io/MessageDaily/posts/2026-11-14-hard-fork-jensen-huang-downfall/)口径为 11-12 盘前）前两天——本场是「事中」的 VC 视角存档，部分判断两天后即被事态超越。被节目认定的事实层：黄仁勋承认与一名「据称为中国间谍」的女子有婚外情，董事会就此启动调查；节目强调查的是合规与安全——是否存在安全违规、政府如何处理、英伟达是否曾游说司法部在对 MegaSpeed 的行动上放软。针对该女子及 MegaSpeed「转送芯片入中国」的指控均未经核实，第二段婚外情时间线、董事会动机、白宫内斗与接班分析站内已展开，[中文侧「明面交出 CEO」推演见《圈里圈外》195 期](https://inkeast.github.io/MessageDaily/posts/2026-11-13-quanliwai-195-nv-ceo-change/)，不重复。

本场独有增量有三层。其一「通行证」之争：Jason 认为黄仁勋需要一张通行证——从 1993 年干到今天、任期最长的科技 CEO，把公司带到五万亿美元市值（本场口径；Hard Fork 录制时点称约四万亿，两说并列），此前节目也讨论过乔布斯期权倒签案先例；Rory 反驳：这是涉国家安全的调查，政府早知情、鲁比奥的报告、信息未上达的疑问一大堆——「可以希望他过关，不能假设能过关」。节目还引一篇帖子（作者转写作 Sean McGuire，未核实）劝「别因情报机构的把柄材料（compromat）把最重要的事搞砸」。其二，Jason 的调查选人机制论，来自他亲历的两起董事会调查（一男一女 CEO）：「当输入开始时，输出可能已经被决定了」——调查方是被调查方雇佣的律所、范围自己定；Rory 反方是程序制衡：调查几乎必然被国会和司法部二次复核，「作业会被不那么友好的人检查」，而英伟达董事会九席中四席是三十年级老臣（1993 年进入的原始投资人 Mark Stevens 与 Tench Coxe、93 年起的审计委员会主席、Synopsys 的 CEO；节目另称 Cooley 律所负责人在董事会并主导调查），专业声誉约束下难以闭眼走过场。其三最反直觉：Jason 听遍黄仁勋访谈后判断，「钓鱼执法」一无所获——无需中国特工游说，黄仁勋出于本职与真心（防止中国出现替代供应商侵蚀份额）本来就在推对华卖卡，「特朗普的职责是治国、他的职责是把英伟达经营好，你设局也套不出他本来就要说的话」。推论即开场预告：中国才是最大输家——不仅卖卡更难，把 GPU 放在边境几英里外的新加坡、泰国数据中心为中国模型跑推理的「绕道」也会被全面关停；相关法案已过众院、卡在参院（节目口径），本案大概率把它推过去。节目另称英伟达内部已决定不再向 MegaSpeed 出售任何产品。Rory 的玩笑作注脚：「就不能换个对象吗，比如 SAP 的？」

## 从纳指 2.5 万亿到 Anthropic 定价术：AI 交易只看需求侧

Harry 转述对冲基金朋友「用多年未见的低沉语气」来问：纳指 100 单日蒸发 2.5 万亿美元，怎么了。一位常驻嘉宾（转写未标名）给时间线（节目口径）：周二晚中期选举明朗、民主党大胜，周三股市先涨，周四才因「数据中心审批受阻、芯片可能卖不动」的焦虑跳水——「第一反应其实是涨」，结论是「没人真知道什么」：那不是 AI 交易破裂的第一声，而是激进的 pod 超仓后被连环爆掉——这类机构风控是回撤 5% 收走支票簿、7.5% 直接开除（对 Citadel 类多经理基金的描述）。他每周重复的纲领是：「AI 交易不会从供给侧裂开」——不因数据中心建不建得成、不因英伟达份额被 AMD 抢，只要需求还在、而需求会体现在 OpenAI 与 Anthropic 的 ARR 上，「其他一切都会大致没事」。供给约束的更多背景见[11-13 供给链分析](https://inkeast.github.io/MessageDaily/posts/2026-11-13-101-ai-us-newworld-datacenter/)。

话锋随即转到眼前的 Anthropic IPO。Jason（推断）的转述自认「含混」：本轮原定千亿美元，似乎未足额认购、缺口约两百亿由私募配售补足，其中一部分是谷歌既有承诺的「重新包装」；Rory 纠正口径——「还没到谈超额认购的阶段，是流程时点问题，尚未定价」。Jason 认为管理层「打得漂亮」：建议发行价 70–78 美元/股，较上一轮私募的 54 美元上调两三成、显得克制；坊间「1 万亿还是 1.4 万亿」只是口径差——私募估值把所有已授予期权算进去，公开市场只算已归属（vested）部分。他的 IPO 哲学值得整句记录：「宁可低开高走，不要高开回落——一旦开始回落，所有人就都失去了信心。」Harry 是空方：OpenAI 已把市场「募疲劳」（1.25 万亿美元估值下原定融资只落到百亿出头，节目两处口径 100 亿/110 亿并存），Robinhood 认购邮件刚进他邮箱，「我判断上市后横盘」；他引一位万亿级配置机构：「不担心这 800 亿 run rate（年化收入），担心的是下一笔 1000 亿——那层资金很薄。」Rory 是多方（自称「今天我成多头了」）：第一个可买的纯生成式 AI 标的，上市后账上将有 2000 亿美元现金、「超过美国任何一家公司」，他打赌 CFO 六到九个月内备好可转债文件再融 500 亿（Harry 补充 400–600 亿都有可能），「你会宁愿自己是 Anthropic——一个月内拿到钱和流通股本，跟私募时代讨饭碗（begging bowl）那套彻底了断」。Jason 收尾：这是给所有人的礼物——此前只能从 CoreWeave、英伟达、Nebius 的报表缝里拼数据，以后每季度都有 Anthropic 真数字。招股书深度拆解见站内 [latedtalk 两篇](https://inkeast.github.io/MessageDaily/posts/2026-11-12-latedtalk-anthropic-s2-lizhaoyu-pricing-risk/)，不重复。

## OpenAI 回到 70%：代币弹性实验与 agent 的算力账单

Harry 引述 OpenAI 的 Greg Brockman（如今出面表态的越来越多是 Greg）：Q3 年化收入增速 70%、企业级收入翻倍并首次成为收入大头、Codex「在不少方面压制 Claude」。嘉宾共识很克制：能预测的只有「两家十二个月后的收入都会比今天多得多」；产品层面是乒乓——在 Astra 与 Fable/Opus（转写口径模型名）之间跑个简单 eval（评测）轻而易举，MongoDB 的 Dev 上节目说过「开发者没有忠诚度」，没人敢预测一百天后的份额比。真正看点是代币价格弹性：两家必然竞相降价，10%–20% 的降价带来 15% 的用量增长（净收入下降）还是 21%（净上升）——「我们即将发现答案」，竞争三基础已明：算力、资本、代币定价。

Jason 再算 agent 成本账：OpenAI 自曝其 agent 产品（转写作 DOL/Dots，拼写未核实）「非常贵、非常耗算力」；Rory 说「伟大创业公司总会解决」，Jason 部分反对：他原以为跑一个 agent 每月四五美元——那是 Lovable、Replit 这类非持久虚拟机的生意，收 25–30 美元已算好生意（Wix 两亿美元收 Base44 同一逻辑）——实际 20–30 美元起步，而且「我们从 agent 身上学到的是：还想让它们干更多」；他的 Muse 每月 20 美元全天候在跑，「Rory 觉得 Meta 扛得起，也许——但其他所有人都受算力约束，GPU 没有通缩」。Rory 以周期论回应：短期算力价因供需涨、长期因摩尔定律跌，「你离那天还有两年还是五年？我的直觉是五年」。Jason 收束：「如果 agent 不能 24/7 想跑就跑地替你干活，它就只是一个自动化工作流。很好，但没那么有趣。」

## 投委会时间：fal、Revolut、Zipline 三选一

固定桥段「投资委员会」：三人自组的「O'Driscoll Lemkin Ventures」（名称经转写校正）本周三单——Zipline 以 215 亿美元估值融 15 亿（较 1 月三倍）、fal 以 160 亿美元估值翻倍（ARR 超 8 亿美元）、Revolut 二级市场按 1150 亿美元定价（较上轮 +53%）。Jason（被点名作答）选 fal：「趋势是你的朋友」，推理需求每年翻几番时没人关心长期格局，「最坏情况 400 亿估值也能转手」，尽管约 6% 毛利率与同行 Fireworks 一个月被黑两次是真实暗面。Harry 反选 Revolut：「给我 1150 亿的 Revolut 复利十年，收工」——唯一核心风险是创始人 Nick（公开身份 Nikolay Storonsky）的关键人风险，「别让他靠近马路、汽车和任何移动物体」。Rory 各拆一层机制：Zipline 是「独一份」（N of 1），但真正生意已从非洲送药变成美国本土配送（沃尔玛合约、达拉斯、全美 300 万单、每单可能只挣 5–10 美元），「215 亿估值等于把宝押在沃尔玛合约上，惊人但吓人」；fal 所在第三方推理市场（不含基础模型厂）约 50 亿美元且疯长，「但 160 亿估值上你可能离终点比离起点近」；Revolut 的钱主要是转账非放贷，客群今天 19–25 岁，「未来二十年他们会要房贷——有望成为欧洲最大银行，还有四倍空间」。三人还玩回环：若按上半场常青长持逻辑，fal 这种不可预测的进不了组合——结构退潮，口味还在。

## Agent 重排 SaaS：API key 黑产、席位折价与加州财富税折戟

## 机制 → 影响 → 启发

- **常青结构退潮链**：GP 想替 LP 捕获 IPO 后复利（红杉背景公司曾占纳斯达克约四分之一，节目口径）→ 锁仓撞上 22/23 入场、LP 流动性需求与「GP 拿满 carry」的激励错位 → 谁得：拿回退出自由的 LP、用续存基金实现同目标的基金；谁失：想分享后 IPO 时代的 GP 品牌 → 二阶影响：长持叙事退潮、结构创新回归简单 → 观察指标：其他常青/续存基金公告、LP 份额转让折价 → 启发：资管结构第一约束是激励相容（谁被锁、谁已变现），「智力正确」不是充分条件。
- **专注收缩链**：品牌强到可远程覆盖（「从美国足以覆盖」）→ 红杉关伦敦、停 Scout、团队合一 → 谁得：旗舰品牌火力集中；谁失：欧洲本地早期覆盖与 scout 网络外部性 → 二阶影响：被克隆的套利型机制优势归零、平庸加速器被判不经济 → 观察指标：其他平台基金是否跟进收缩、红杉在欧洲种子轮出现率 → 启发：信息/渠道型护城河公开即被套平；「机构持久、合伙人不持久」，融资时按此校准预期。
- **需求侧判据链**：供给端噪音（数据中心焦虑、纳指单日蒸发 2.5 万亿）→ 实为杠杆 pod 连环强平 → 判据回到 OpenAI/Anthropic 的 ARR → 谁得：有 ARR 的实验室与「低开高走」的 Anthropic；谁失：高杠杆持仓者 → 二阶影响：代币降价弹性实验定收入曲线；上市后 2000 亿现金+可转债工具箱改变对 OpenAI 的相对位置 → 观察指标：两家季度 ARR、代币价格、Anthropic 上市表现与增发 → 启发：判断「AI 交易」看需求侧收入与定价行为，不看供给端新闻流；「低开高走」是可复用的 IPO 置信纪律。
- **调查与地缘收紧链**：涉国家安全丑闻（据称间谍与 MegaSpeed 转送指控，未经核实）→ 调查选人与程序决定走向（「输出在输入时可能已定」 vs 国会/司法部二次审查）→ 谁得：管制强硬派；谁失：中国算力获取（卖卡+跨境托管双收紧）、英伟达治理确定性 → 二阶影响：新加坡/泰国托管模式承压、参院法案或被推动 → 观察指标：参院立法、MegaSpeed 刑事调查、英伟达披露口径 → 启发：危机治理第一决策点是「谁来尽调」；涉国家安全的个人丑闻没有乔布斯式通行证（本场观点两天后被辞任公告印证，见互链）。
- **席位重估链**：agent 成为买家与流量（人类用户占比下降）→ agent 受益者拿溢价（Cloudflare 39%）、席位股折价（Figma 跌破百亿、席位模式判「终局」）→ 谁得：agent 化基础设施与 AI 原生新贵（Lovable/Replit 各 10 亿美元）；谁失：未自我改造的 pre-AI 应用公司（「12/31 大限」）→ 二阶影响：并购回流但多为无流动性「软着陆」；造富（人均 4100 万）与税基竞争（加州否财富税）绑定人才黏性 → 观察指标：席位股倍数、agent 流量占比、加州后续税案 → 启发：SaaS 估值锚从人头转向 agent 调用量；自我改造有截止日——「明年再说」就是 2025 年说过的那句话。
