## 一、论文背景

### 1.1 长程任务与上下文边界：agent 的"遗忘"问题

语言模型 agent 越来越多地处理**长程任务**（long-horizon tasks）——通过反复调用工具与环境交互来完成任务，比如修一个仓库级的 bug、做六轮有依赖关系的购物决策、迭代式地开发一个机器学习模型。这类任务的交互历史（几十轮工具调用、观测、推理）很快就会超出模型的**活跃上下文**（active context）。

于是出现了一个关键场景：**上下文边界**（context boundary）。当上下文接近预算时，环境会清空当前消息历史。一个建网站的 agent 可能需要回忆"为什么之前那次视觉修正被否掉了"——但那段对话早已离开 prompt。信息没有消失，它只是不在模型"眼前"了。

这把 agent 记忆问题变成了三个决策：**该记什么（write）、该读什么（read）、什么时候做**。

### 1.2 现有路线：推理时记忆系统 vs 记忆后训练

业界解决 agent 记忆有两大路线：

- **推理时记忆系统**：给 agent 外挂一个记忆库，任务策略本身不变。代表工作包括 Mem0（提取-整合-检索管线）、MemGPT/Letta（操作系统隐喻的分页记忆）、A-Mem（笔记间自动链接的 Zettelkasten 式记忆）、Zep（时序知识图谱）。这些是"外围设施"，策略权重从没学过记忆行为。
- **记忆后训练**：用 RL 或蒸馏把记忆控制**训进策略本身**。近一年的工作包括：训练专用记忆操作（Agentic Memory）、从下游结果学习上下文压缩（CompactionRL）、训练 agent 主动折叠自己的上下文（Agent-Fold）、用任务奖励训练 agent 用文件系统维护状态（CAMP-I）。

### 1.3 核心痛点：OPD 教记忆，双边都被接口卡住

最新一波工作用 **on-policy distillation（OPD，在线策略蒸馏）** 训练记忆控制：学生自己采样轨迹，冻结的教师对学生实际生成的每个 token 给概率监督。OPD 兼具 RL 的状态对齐和 SFT 的稠密 token 级信号，2025 年以来被 Qwen3、GLM-5 等广泛采用。

但把 OPD 用到记忆上时，现有工作几乎都通过**专用记忆工具**（六个 store/retrieve 之类的工具调用）或 **compaction 协议**（触发摘要响应）来承载记忆。CAMP-II 指出这**双边削弱**了蒸馏：

1. **教师侧**：冻结教师从没见过这些自定义接口——它对一个从没用过的工具协议给不出可靠判断（" Privileged, but Biased" 等工作证实 PI 条件教师会在陌生接口上误导自蒸馏）；
2. **学生侧**：学生对陌生工具采样不出有意义的记忆动作——而 OPD 只能监督学生采出来的行为，采不出来就学不到（MemOPD 不带 SFT 冷启动时五域全零分就是明证）；
3. **负优势问题**：教师给陌生接口上的记忆动作打低分，把学生从要教的行为上推开，却不指明替代行为，训练不稳定。

于是论文提出核心问题：**教师能否通过师生都已有先验的操作，教小模型控制记忆？**

## 二、论文定位和关联工作

### 2.1 研究谱系一：Agentic RL for Memory（把记忆训进策略）

| 工作 | 核心思想 | 记忆接口 | 与 CAMP-II 的关键区别 |
|---|---|---|---|
| MemPO (2026) | 状态整合与摘要保留的策略优化 | 内部摘要 | CAMP-II 记忆在外部文件，教师也能读 |
| Agentic Memory (ACL 2026) | RL 训练统一长短期记忆管理 | 专用记忆操作 | CAMP-II 用预训练内的 Bash 而非新工具 |
| CompactionRL (2026) | 从下游结果学习上下文压缩 | compaction 协议 | CAMP-II 消融显示该接口掉 16+ 点 |
| Agent-Fold (ICLR 2026) | 主动上下文折叠 | 折叠协议 | 同上，协议在预训练外 |
| CAMP-I (arXiv:2609.34422) | 任务奖励 + 异步 PPO 训练文件记忆 | **Bash/文件** | **CAMP-II 的直接前作**：信号从任务奖励换成教师 token 级监督 |

CAMP-I 是本论文的基石：它首次提出给 agent 可执行 shell 与回合持久工作区，让"建文件、改文件、搜文件"成为记忆，用任务奖励训练。CAMP-II 继承其文件记忆接口，但把训练信号从稀疏的任务奖励换成稠密的教师蒸馏——论文的关键论证是：**任务奖励训练只问一个问题（学生的先验能否通过探索触达该行为），蒸馏要问两个（学生还得采得出来 + 教师还得评得准），而共享接口先验一次回答两个问题。**

### 2.2 研究谱系二：推理时记忆系统（对照组）

Mem0、MemGPT、A-Mem、Zep 四个系统全部是推理时外挂层：agent 查询一个位于权重之外的存储，任务策略本身从未被训练。CAMP-II 训练任务策略本身，且记忆保存在教师也能读的普通文件里——这使蒸馏监督可以直达记忆内容。

### 2.3 研究谱系三：OPD for Agent Memory（直接竞品）

| 工作 | 做法 | 遗留问题 |
|---|---|---|
| MemOPD (2026) | 重建紧凑记忆调用状态再蒸馏 | 记忆接口是紧凑调用协议，两模型都没练过 |
| ACM (2026) | 标注轨迹后蒸馏上下文编辑与检索 | 接口为给定 |
| Hy-Memory (2026) | 单独的记忆写入器，先 OPD 后 RL | 写入器是学出来的陌生模块 |
| HELM (2026) | 学习式层级记忆控制器 + 独立推理器 | 双模型分离损失 13.2 点 |

这些工作在**状态轴**上对齐了师生（教师必须评学生实际所处的状态），但**接口轴**仍是给定的、陌生的。CAMP-II 的定位：**把接口本身当作设计变量，从师生共享的先验中选取**——这是对 OPD 设计空间中尚未被触碰的一根旋钮。

### 2.4 定位总结

| 维度 | 之前的路线 | 本论文的突破 |
|---|---|---|
| 记忆接口 | 专用工具 / compaction 协议（预训练外） | 普通 Bash/文件操作（预训练内） |
| 训练信号 | 任务奖励（稀疏）或 OPD（但接口陌生） | 冻结教师的 token 级 OPD（接口熟悉） |
| 教师适配 | 需 SFT 冷启动 / 状态重建 / 轨迹标注 | **零适配**，通用教师直接评 |
| 环境覆盖 | 单域或短程 | 五域长程统一联合训练（CAMG-II） |

## 三、问题定义

### 3.1 从具体场景到抽象结构

具体问题：如何训练一个小模型 agent，在上下文被反复清空的长程任务中学会用文件做记忆？

论文的抽象洞察是：**记忆蒸馏的可行性由接口决定，且是一个双边约束**。把它形式化为一个"交集"条件——监督只能落在交集里：

| | 教师偏好该动作 | 教师不偏好 |
|---|---|---|
| **学生自然发出该动作** | 交集：直接监督动作及其内容 | 过量：负优势，随差距增大而破坏性增强 |
| **学生不发出该动作** | 缺失：动作本身无直接监督 | 空集：从不进入损失 |

形式化设定：有限视野部分可观测任务，学生策略 π_θ 在可见上下文 h_t 采样动作 a_t（属于环境原生动作集 ∪ 共享文件动作集）。OPD 目标是在学生自己到达的每个 token 前缀 s 上，最小化与冻结教师 π_T 的反向 KL，逐 token 优势为教师-学生对数概率比 A = sg[log q(x|s) − log p_θ(x|s)]。

**求**：选择记忆接口 m（文件 / 专用工具 / compaction），使（i）学生初始策略在该接口上的记忆动作概率 Q₀ 足够大（覆盖），（ii）教师在该接口上对学生所写内容的判别足够可靠（监督质量），从而最小化教会记忆行为所需的监督次数 N ∝ 1/(Q₀·u₀)（u₀ 为初始对数几距）。

### 3.2 这个抽象的精妙之处

论文没有把"接口"当作中立的通道，而是证明它是**决定监督能否落地的第一因**：附录 B 的成本定律给出 N ∝ u₀/Q₀——覆盖每差一个数量级，教学成本就涨一个数量级。专用工具在两处落在交集之外（学生不采、教师不懂），compaction 同理；而文件操作天然落在交集内。这把"选哪个记忆接口"从工程品味问题变成了可推导的设计问题。

## 四、问题解法

CAMP-II 的解法 = **CAMG-II 环境（五域统一文件记忆接口）+ 完全异步 OPD（token 级教师监督直达文件写入）**。

### 4.1 CAMG-II：五域长程环境套件

CAMG-II 扩展前作 CAMG 的环境，砍掉难以用 RL 优化的 DeepResearch，新增企业知识工作（General）与视觉落地网页开发（Visual）：

| 环境 | 任务来源 | 考验的记忆能力 | 规模 |
|---|---|---|---|
| Shop | WebShop 720 验证商品，六会话依赖购买 | 跨会话保留客户偏好与购买决策（8 种依赖族：属性链、潜在偏好、新近覆盖、干扰鲁棒等） | 六轮购买唯一有效序列 |
| Coding | SWE-smith，93 仓库 | 诊断、仓库编辑、测试证据跨多个上下文 | 11,218 任务 |
| AutoResearch | OpenMLE 公开任务包 | 假设与验证证据跨迭代保留 | 931 任务 / 804 族 |
| General | MiMo 企业任务（表格/文档/业务系统） | 跨文档与系统交互的证据调和（含工具签名修正） | 评分员裁决 |
| Visual | MiMo 网站简报 + 视觉评分 | 设计要求与视觉检查发现（多模态预览图像） | 绝对 rubric 分 |

**统一的共享文件记忆接口**（类比：给每个考场发同一本可自由书写的草稿本）：

- 仿 mini-swe-agent 的极简 shell 接口：单一 `bash` 动作可创建、检查、搜索、修改、执行文件；多行内容用一个引号 heredoc 写入；
- 每回合一个**回合私有、跨上下文替换持久**的工作区；只有 `.agent_memory/` 下的常规文件算策略记忆；
- **上下文替换协议**：上下文接近预算时，策略必须通过普通文件响应写/更新有界的 `CONTINUATION.md`（8,192 字节上限）；写有效后环境清空消息历史，新上下文只含任务/工具说明 + 续接文件**路径**（不注入内容），策略需自己发起读取恢复状态；
- 记忆文件与任务产物共处一个工作区，一次响应可同时改任务文件和记忆文件（各算一个 RL step）。

### 4.2 CAMP-II：完全异步的文件记忆 OPD

训练循环（类比：学生自己开车，教练坐在副驾对每一步打分）：

1. **Rollout**：学生用已发布权重 θ⁻ 在五域等比混合的环境中滚动生成回合，逐 token 记录 (x_i, s_i, log μ_i)（μ_i 为采样时概率）；
2. **教师打分**：冻结 Qwen3.8-27B 教师读取与学生相同的可见文本与图像观测，对学生实际采样的每个 token 给出 q_i = π_T(x_i|s_i)——**包括文件写入的每个 token**；
3. **学习者更新**：minibatch 上做 clip 版反向 KL 策略梯度（Eq. 4：min(ρA, ρ̄A)，ρ = p_θ/μ importance ratio，PPO 式裁剪 1±ε），排除指令/观测/padding；
4. **完全异步**：完成回合进持久队列，学习者不等最慢回合，回合可能晚数个权重版本才进 batch，靠 importance ratio 校正；每轮后发布权重。

关键细节：

- **前缀保真**：教师评分所用前缀 s_i 就是学生实际产生的调用（可见上下文、token 位置、因果 mask，含上下文替换后的调用与学生记录的读观测）——私有标签与未读文件内容从不进入；
- **纯 OPD**：主方案关闭任务奖励损失与 critic，6,400 回合 / 100 学习轮 / 每域 1,280 回合；4B 训练约 250 GPU 时（8 GPU：4 训练 + 2 rollout + 2 教师服务）；
- **两文件角色**：CONTINUATION.md 有界（8KB），普通笔记文件自由组织，互不挤压。

### 4.3 方法全景

| 组件 | 输入 | 输出 | 作用 |
|---|---|---|---|
| CAMG-II 五域环境 | 任务包 + bash + 持久工作区 | 带奖励/终止状态的回合 | 提供需要跨边界记忆的可验证任务 |
| 共享文件接口 | bash 命令字符串 | 文件系统变更 + 观测 | 记忆载体，落在师生共享先验内 |
| 异步 OPD 学习器 | (x_i, s_i, μ_i, q_i) 队列 | 学生权重更新 | token 级教师监督直达每次文件写入 |
| 冻结教师 π_T | 与学生相同的可见上下文 | 每 token 概率 | 零适配的内容评判者 |

## 五、评估指标与实验证据

### 5.1 指标体系

- **主指标**：CAMG-II 测试集五域成功率均值（每域 128 任务，共 640；Shop/Coding/AutoResearch/General 为成功率，Visual 为 rubric 分×100、未交付记零）；
- **外部迁移**：Terminal-Bench 2.1 与 SWE-Bench Pro V2 的免网络子集成功率；
- **机制指标**：接口 surprisal（教师/初始学生在各接口上生成 token 的平均负对数似然，nats）、记忆动作占比、负优势均值、教师内容偏好判对率；
- **因果指标**：三向记忆干预（保留/换成他回合记忆/清空）后的完成分；
- **消融**：接口替换（memory tools / compaction）、记忆 token 梯度屏蔽、等量随机屏蔽。

| 冻结学生 Qwen3.5-9B | 90.6 | 26.6 | 56.2 | 60.9 | 36.5 | 54.2 |
| 冻结教师 Qwen3.8-27B | 100.0 | 63.3 | 83.6 | 93.0 | 40.3 | 76.0 |
| MemOPD | 0 | 0 | 0 | 0 | 0 | 0.0 |
| MemOPD (w/ SFT) | 93.0 | 27.3 | 39.1 | 62.5 | 37.3 | 51.8 |
| CompactOPD | 93.8 | 24.2 | 37.5 | 61.7 | 23.6 | 48.2 |
| ACM | 94.5 | 21.9 | 11.7 | 59.4 | 8.5 | 39.2 |
| HELM（原架构） | 87.5 | 0.0 | 9.4 | 53.1 | 33.1 | 36.6 |

| 策略 | TB 2.1 | SWE-Bench Pro V2 | 均值 |
|---|---|---|---|
| Qwen3.5-4B | 23.1 | 11.2 | 17.1 |
| Qwen3.5-9B | 23.1 | 23.1 | 23.1 |
| Qwen3.5-35B-A3B | 33.8 | 27.4 | 30.6 |
| CAMP-II-4B | 30.0 | 18.1 | 24.1 |
| CAMP-II-9B | **38.0** | **30.1** | **34.1** |

学到的记忆行为泛化到训练外基准：4B/9B 各超初始模型 6.9 点；CAMP-II-4B 均值超 9B 初始模型、CAMP-II-9B 均值超 35B 大模型且两榜均最高。行为层面佐证：训练后策略每回合写 CONTINUATION 5.2 次/读回 5.0 次（初始 1.7/2.1），329/337 条笔记在替换后被读回，13.2% 的写入提前于替换至少一步（主动记账）。

### 5.4 机制证据：接口为什么决定成败

- **Surprisal（图 3a）**：文件接口教师 0.42 / 学生 0.19 nats；专用工具 0.70/0.98；compaction 0.91/1.40。文件接口对教师的花费约为 compaction 的 1/3，学生 1/5——且教师处处更贵，换更强模型不解决接口陌生问题；
- **动作覆盖（图 3b）**：学生记忆动作占比：文件 21.6% vs 专用工具 7.8% vs compaction 5.9%——文件接口下教师目标最便宜且学生本来就常做该动作；
- **负优势（图 5）**：接口决策与内容 token 的平均负优势从文件到 compaction 约翻倍（0.109→0.219；0.475→0.909）——越陌生推力越强且无替代目标；
- **教师内容偏好（附录 D.3）**：教师把"携带本任务信息的笔记"排在陌生笔记之上的判对率：文件 76.5% / compaction 70.0% / 工具 63.8%；关键信息替换实验中文件接口 60/60 全对（margin +0.577 nats，Fisher 检验对工具 p=0.0007）。

### 5.5 消融与因果干预

| 变体 | 均值 | 相对 CAMP-II |
|---|---|---|
| CAMP-II | 64.6 | — |
| 换 compaction | 48.2 | −16.4 |
| 换专用记忆工具 | 48.2 | −16.4 |
| 记忆 token 梯度屏蔽 | 47.3 | −17.3 |
| 等量随机屏蔽 | 63.3 | −1.3 |

- **接口消融**：换掉文件接口掉 16-17 点——接口选择决定大部分增益；
- **监督内容消融**：屏蔽记忆 token 损失几乎抹平增益，而等量随机屏蔽只掉 1.3——增益确来自"学该写什么"的监督，不是 token 预算；
- **三向干预（图 6）**：同一回合在首个边界后分三路续跑，购买分 1.00（保留自己记忆）/ 0.67（换别回合记忆）/ 0.45（清空）——后续成功由所写记忆**因果**决定，排除了"只是练了任务能力"的解释；
- **去掉强制写**：移除"边界必须写 CONTINUATION"的要求，训练后策略仍得 62.6、同环境重训 64.0——记忆行为不是对规则的形式合规，而是学到的内在策略。

## 六、效果优势的根源解释

### 6.1 根源机制与证据链

**因果链**：共享文件操作先验 →（a）学生侧动作覆盖 21.6%（7.8%/5.9%）+（b）教师侧 surprisal 0.42 nats（0.70/0.91）且内容判别 76.5% 判对率 → 蒸馏监督落在"交集"内且负优势最弱 → token 级监督直达每次文件写入的内容 → 学会"记什么/何时读回" → 五域 +12.8 点对最强基线、外部基准 +6.9 点迁移。

逐环节验证状态：

1. "文件接口 surprisal 最低"——论文实验直接测量（图 3a），已支持；
2. "覆盖充足 + 负优势最弱使 OPD 可收敛"——论文消融（MemOPD 无 SFT 全零、负优势翻倍）与附录 B 成本定律 N ∝ u₀/Q₀ 共同支持；RSA 分析（附录 D.1：师生表征 rank 相关文件接口 0.927 vs 0.868/0.864）补充了表征层证据；
3. "增益来自记忆内容监督"——梯度屏蔽消融 + 三向干预双重支持（论文实验）；
4. "该机制可推广到更大规模"——**阅读者推测**：论文自陈局限为学生 ≤9B、单一冻结教师，多教师 OPD 未测试。

**为什么基线曾经有效又必然受限**：MemOPD/ACM/HELM 们的状态对齐技术确实解决了 OPD 的状态轴问题（教师必须评学生实际所处的状态），但接口轴仍把监督推出交集——协议调用是"错一个 token 全动作作废"的短序列，教师错误既贵又频繁（约定不在可见上下文中），reverse KL 又把早期信号花在最不可靠的尾部 token 上。这不是实现瑕疵，而是接口选择带来的结构性障碍。

### 6.2 相关工作检索与对照

| 研究 | 相似尝试 | 相关结论 | 与本文的差异 | 对根源解释的影响 |
|---|---|---|---|---|
| [CAMP-I (arXiv:2609.34422)](https://arxiv.org/abs/2609.34422) | 同一文件接口，任务奖励 PPO 训练 | 文件记忆可从任务奖励习得；4B/9B 曾追平 35B/122B 级模型 | 无教师，信用分配跨长程 | **支持**：接口先验单边（探索）也有效；CAMP-II 证明加双边监督再 +10.4 点 |
| [MemOPD (arXiv:2608.07068)](https://arxiv.org/abs/2608.07068) | 重建紧凑记忆状态后 OPD | 状态对齐有效 | 接口仍陌生 | **限定**：只修状态轴，接口轴损失照在（本文全零分复现） |
| [Hy-Memory (arXiv:2610.22196)](https://arxiv.org/abs/2610.22196) | RL 训练独立记忆写入器 | 专用写入器可学 | 写入器是额外陌生模块 | **限定**：接口仍非共享先验 |
| [GKD (Agarwal et al., ICLR 2024)](https://arxiv.org/abs/2306.13649) | OPD 基础框架 | 学生自生成数据 + reverse KL 稠密监督 | 未涉记忆/接口 | **支持**：OPD 只能监督学生采出的行为——覆盖论据的源头 |
| [Privileged but Biased (arXiv:2608.04794)](https://arxiv.org/abs/2608.04794) | PI 条件教师如何破坏自蒸馏 | 教师在陌生条件下误导学生 | 非记忆场景 | **支持**：教师侧不可靠的机制证据 |
| [Mismatch matters (arXiv:2608.09836)](https://arxiv.org/abs/2608.09836) | token 不匹配下的 OPD | 负优势随师生差距增大而破坏稳定 | 理论向 | **支持**：负优势问题的一般化佐证 |
| [AutoCompact / CompactionRL (arXiv:2607.05378)](https://arxiv.org/abs/2607.05378) | 学习 compaction 时机与内容 | compaction 可学且有效（SWE-bench +9.2） | 判据是任务奖励/裁判修正，非冻结教师 | **挑战（弱）**：compaction 路线在带 SFT/RL 兜底时也有效——但恰因绕开了"冻结教师评陌生协议"，与本文"冻结教师"设定不冲突 |
| Mem0 / MemGPT / A-Mem（推理时记忆系统，2023-2025） | 外挂记忆管线 | 推理时记忆可降 token 成本并提准 | 策略权重不训练 | **补充**：说明记忆价值本身成立；CAMP-II 回答的是"训进策略"这另一半 |

交叉验证要点：检索范围内未发现与"共享接口先验"直接对立的结论——compaction/专用工具路线的正面结果均出现在"教师可适配或有 SFT/RL 兜底"的设定下，与本文"冻结教师 + 纯 OPD"设定不构成反例；但"更强模型不能自动修复接口陌生"（教师 surprisal 处处更高）这一断言的外部独立复现尚未见，属于本文自证。

### 6.3 综合判断与未决问题

- **多研究共同支持**：(i) OPD 只能教学生采得出的行为（GKD→CAMP-II 全链条）；(ii) 教师在陌生接口上判别不可靠（Privileged-but-Biased 等 + 本文 surprisal/偏好实验）；(iii) 记忆内容因果影响长程成功（本文三向干预 + CAMP-I 行为证据）。
- **仍属推测**：成本定律的精确比例 N ∝ u₀/Q₀（两 token 约简的常数因子仅有 ±30% 数值验证）；"接口先验"效应在 >9B 学生、多教师、非 Qwen 家族上的保持。
- **适用条件**：需要冻结教师 + 纯 OPD 设定下才严格成立；若允许教师适配或任务奖励兜底，接口劣势可被部分买回（MemOPD w/SFT 回到 51.8 即为例证）。
- **可能失效条件**：任务原生接口本身在预训练内（如纯代码编辑任务）时，文件接口的相对优势可能收窄；Visual 域教师仅 40.3 分，说明教师弱处蒸馏天花板也低。

## 七、必要知识反推

假设一个零知识的人要复现这项工作，最少需要掌握：

### 7.1 领域知识层

- **Agent-环境交互循环**：多轮部分可观测任务、动作/观测/回合/视野的形式化（不理解则连训练循环都写不出）；
- **上下文边界与记忆的三决策**：write/read/when（问题来源）；WebShop/SWE/OpenMLE/MiMo 各域的任务语义与成功判据（环境构建的前提）；
- **LLM 预训练分布中哪些操作是"已知的"**：bash/文件读写是代码语料的主体，专用工具协议不是——这是"接口先验"假设的经验基础。

### 7.2 方法论知识层

- **OPD/GKD 脉络**：学生自采样 + 教师逐 token 反向 KL、其 policy-gradient 等价形式、importance ratio 裁剪（算法直接建立其上）；
- **负优势问题与 reverse KL 的尾部加权性质**（训练稳定性分析的理论工具）；
- **RL 基础设施**：异步 rollout-learner 架构、行为概率记录、权重发布（完全异步 OPD 的工程前提）；
- **两 token 约简与漂移分析**：sigmoid 恒等式、连续化积分（成本定律推导的数学）。

### 7.3 工程知识层

- 上下文预算管理：65,536 prompt / 32,768 response 上限、观测信封、续接预留与提前触发点的计算；
- 沙箱隔离：网络隔离、可写根、进程/时间/文件数限制（五域统一环境的安全实现）；
- 评估设计：为什么 Visual 用绝对 rubric 分而其余用成功率、未交付记零的公平性考量。

### 7.4 知识融合的关键节点

1. **"蒸馏问两个问题，RL 只问一个"**——把任务奖励训练与蒸馏的可行性条件差异映射到接口的双边约束上（领域知识 × 方法论知识的化学反应）；
2. **交集表的工程化**：把"学生会不会采/教师会不会评"的四象限落到"选 bash 而不是造工具"的设计决策上；
3. **用 surprisal 当接口度量**：把"熟悉度"这一模糊概念操作化为可测量的 nats 数，使接口选择可被实验裁决而非品味之争。

## 八、论文中可以提取的通用性灵感

### 灵感 1：接口先验——监督要走双方都已会的路

**核心思想**：任何"教师教学生"的系统，监督通道本身必须落在两者的既有能力交集内；通道再精巧，只要双方陌生，监督就落空。
**论文证据**：文件接口教师 surprisal 0.42 vs compaction 0.91 nats；换接口掉 16-17 点；MemOPD 无冷启动全零。
**推广场景**：(1) 人机协作培训——用新人已熟悉的工具教新流程而非专用系统；(2) 多智能体通信协议设计——共享词汇表的协议优于表达力更强的新协议；(3) 模型间蒸馏的任何场景——先审计两模型对任务格式的先验再选监督载体；(4) API 设计——面向 LLM 的接口应复用语料中高频模式。

### 灵感 2：双边可行性分析——教一个行为要同时检查"能采到"与"能评准"

**核心思想**：设计教学/优化目标前，先画那张 2×2 交集表：学习者自然产生该行为吗？教导者能可靠评价吗？只有交集里的东西能被直接监督。
**论文证据**：21.6% vs 7.8% 的覆盖差与 76.5% vs 63.8% 的判对率差共同决定三个接口的命运；附录 B 把它形式化为 N ∝ u₀/Q₀。
**推广场景**：(1) 课程设计——练习必须落在学生"够得着且教师判得动"的范围；(2) RL 奖励设计——探索可达性与奖励可辨别性缺一不可；(3) 自动化评估系统的可行性论证；(4) 主动学习中的采样-标注联合约束。

### 灵感 3：稠密 token 级监督直达"内容"，而非只训"行为外壳"

**核心思想**：教会"做什么"之后，真正的增益藏在"做得怎么样"的细节内容里；监督必须细到内容 token 才能兑现。
**论文证据**：屏蔽记忆 token 的损失（保留任务 token）增益从 64.6 掉到 47.3，等量随机屏蔽只掉到 63.3。
**推广场景**：(1) 代码评审教学——评逻辑而非只评有没有提交；(2) 写作训练——逐句反馈优于只给总分；(3) skill 学习系统——反馈要进入操作步骤内部；(4) 过程奖励模型（PRM）vs 结果奖励的取舍。

### 灵感 4：最朴素的载体常常最优——预训练分布就是免费的脚手架

**核心思想**：与其发明专用机制，不如审计已有能力里什么最接近目标行为，把它当训练靶点；普通 bash 之于记忆，正如通用底座之于专用工具。
**论文证据**：一个 `bash` 入口 + 一个 CONTINUATION.md 文件，胜过六个专用记忆工具与整套 compaction 协议；CAMP-I 已证同接口可追平大模型。
**推广场景**：(1) agent 工具设计——先问"提示词 + 文件系统能不能做"再考虑新工具；(2) 长上下文替代方案——文件系统作为跨会话状态底座；(3) 教育——先利用日常经验当类比再引入形式符号。

### 灵感 5：三向干预是建立行为因果的金标准

**核心思想**：要证明"某内部行为带来收益"，在行为发生的分叉点保留/置换/删除该行为做对照，比相关性或消融更有说服力。
**论文证据**：1.00/0.67/0.45 的完成分梯度直接把任务成功归因于所写记忆的内容。
**推广场景**:(1) agent 行为分析——审计任何"中间产物"的因果作用；(2) 数据增广实验——置换/删除中间特征；(3) 可解释性研究——激活修补（activation patching）的同构思想。

### 灵感 6：环境即方法论——用"统一接口 + 域多样性"隔离要研究的变量

**核心思想**：把五个异构域装进同一记忆接口，任何性能差都能归到域、任何接口差都能跨域平均——环境套件本身成了控制变量的仪器。
**论文证据**：CAMG-II 让"接口消融"可在同任务集上干净执行（48.2 vs 64.6），五种子方差 0.5。
**推广场景**：(1) 基准设计——控制接口、变化任务；(2) 多任务学习的消融设计；(3) 任何"能力归因"实验的平台搭建。

## 附录：一页速查

- **一句话**：让师生共享最熟悉的 bash/文件操作做记忆接口，冻结教师逐 token 蒸馏学生（含文件写入内容），单策略跨五域学会跨上下文记忆。
- **关键数字**：CAMG-II 五域均值 4B 64.6 / 9B 66.5（教师 76.0）；对最强 OPD 基线增益 ×2.97；TB2.1 38.0% 超 35B 模型；干预分 1.00/0.67/0.45；接口替换 −16~−17 点。
- **训练配置**：Qwen3.5-4B/9B 学生 + 冻结 Qwen3.8-27B 教师；100 轮 × 64 回合 = 6,400 回合纯 OPD；约 250 GPU 时（4B）。
- **与前作关系**：CAMP-I 证明"文件记忆 + 任务奖励"可行；CAMP-II 证明"文件记忆 + 共享先验 + 教师蒸馏"更强，并补齐接口为何重要的机制因果链与成本理论。
