## 先说结论

这一周的 AI 新闻有两条真正的主线，其余都是长尾。第一条是**安全**：一个在 PHP 里躺了 20 年、复杂到「人类研究员实际无法利用」的老漏洞，被 OpenAI 的模型先于攻击者找到并披露，随后在两小时内引来数十万次利用尝试；几乎同时，部署平台 Railway 的环境变量泄露让大批开发者连夜轮换 API 密钥。Matt 的判断是行业正处在一个临界点：AI 一面点燃漏洞、一面又被用来抢先排雷。第二条主线是**网站对 Agent 的站队**：继亚马逊封禁代购 Agent 之后，Yelp、达美航空、摩根大通、嘉信理财等更多公司跟进封禁，而 Shopify 反向宣布全面 Agent 友好——「人类优先还是 Agent 优先」正在成为每个消费网站必须做出的商业选择。Claude Duet 的发布则是 Agent 个人助理军备赛（Dots、Muse、Grokbot）的又一发。

## 安全主线：20 岁的 PHP 漏洞，与一场 API 密钥大挪移

PHP 这件事的戏剧性在于「先后手易位」。主持人介绍，PHP 驱动着维基百科、WordPress、Drupal 等站点，按一些口径多达 70% 的网站在不同程度上使用 PHP；漏洞本身已存在 20 年，利用它需要一条「复杂到处于人类研究员实际能力边缘」的攻击链——而强大的 AI 模型把这种冷僻 bug 变成了真正可利用的武器。这次是 OpenAI 用 GPT-5.6 Sol 先找到了它，抢在攻击者之前公开，并放出了供开发者自查版本的检测工具。Cloudflare CEO Matthew Prince 给出的时间线被节目引用：漏洞公布前 10 小时内观测到数千次利用尝试，公布后 45 分钟内跳到数万次，两小时内数十万次，「现在已是百万级」；安全公司 Wiz 称这是「软件史上最严重的漏洞之一」（主持人补充：实际伤害有限，一批网站短暂下线打补丁）。

第二起没有这么幸运：应用部署平台 Railway（托管大量 Web 应用的后端与数据库）遭入侵，未授权第三方可能接触到加密的环境变量、且部分拿到了解密内容。主持人科普了这意味着什么——环境变量里往往存着 OpenAI/Anthropic 的 API 密钥，拿到密钥的人可以盗用你的额度消费。结果是大量基于 Railway 的公司本周紧急轮换密钥。他把两件事放在一起下判语：「AI 编码与网络安全能力越来越好，我们正处在 AI 好到开始弄坏互联网的临界点」——PHP 那次是 AI 公司抢在爆炸前排雷，Railway 这次是伤害已经发生；而「如果 Railway 会出事，凭什么 Vercel 或其他托管平台不会」。

## Claude Duet：主动式个人助理的又一局

Anthropic 的 Claude Duet 被主持人称作本周最大发布（带引号——因为他自己也还没拿到资格）。定位是对标 ChatGPT 的 Dots、Meta 的 Muse、xAI 的 Grokbot 的个人助理：不等你提问就主动打招呼（演示里是一句「早上好 Nicole，今天有：健康许可、招聘决定、Northfield 续约」），随后补充细节、主动建议「现在就可以替你办」的事项；可连接的销售点系统、在线商店、CRM、客服、薪酬、银行数据直接汇成内嵌仪表盘——主持人认为这个「仪表盘与对话内联」的形态比 Dots、Muse 都清爽。隐私侧 Anthropic 配了专用分类器与安全系统提示词，逐条检查消息、拦截信用卡号或证件号等敏感信息外泄；集成面覆盖 Gmail、Slack、QuickBooks、Stripe、Gusto、LinkedIn、DocuSign、HubSpot、Canva、Shopify 等「常规阵容」。目前仅 Pro/Max 用户可进候补名单、逐步放量；主持人已与 Anthropic 沟通争取测评资格，到手后会做深度演示。

## 「人类优先」还是「Agent 优先」：网站开始站队

主持人花最长篇幅讲的其实是这条结构性线索。继亚马逊停止让 Agent 代客购物之后，本周 Yelp、达美航空、摩根大通、嘉信理财、Cars.com、美铁（Amtrak）等更多站点加入封禁行列。他拆解的机制值得完整转述：一旦购物由 Agent 完成，用户的第一入口从「打开亚马逊」变成「吩咐我的 Agent」，亚马逊就从「目的地」降为「供应链里可替换的一环」——Agent 会按最便宜或最快送达替你挑商家。Shopify 选择了另一边：宣布旗下商家站点全面 Agent 友好，等于赌「放 Agent 进来」赢得的订单会大于被管道化的损失。主持人的预测是中长期多数网站不得不放行——如果越来越多用户让 Agent 代购，持续封禁就是持续丢单。同一逻辑的另一个切面是 Yelp：一边封禁外来 Agent，一边自己上线「替你打电话问餐厅等位、问菜单」的功能——封 Agent 但想当你的餐厅 Agent。

## OpenAI 28 天连发，第三周

延续前两周的盘点（见本站 2026-10-21 文章）：第 12 天靠跨子代理复用上下文、延长上下文缓存与改进请求路由提升了有效用量；第 13、15、17 天无发布、按约「重置」；第 14 天上线桌面端「编辑历史消息」——OpenAI 员工解释为「编辑点之后的所有模型输出与工具调用全部作废、从该点重来」，主持人坦承没分清这和直接改道（steer）的区别；第 16 天被主持人认为最有分量：API 缓存延长到 12 小时，登录用户在 Codex 与 Work 中「缓存永久保留、回头继续旧会话不挨罚、保证命中」。另有：聊天记录 PIN 锁（滚动放量中）；Decisions API 第三次官宣、正式 GA，基于 GPT-6 Luna，专注「有界答案」类问题——输出概率估计、选项判定或打分。呼应这条线，Perplexity 开源了自己的两个决策模型（40 亿与 270 亿参数，主持人按榜单图称 4B 版位居图表最左/最优）。

## 工具、模型与机器人：速览

- **Ideogram 矢量模型**：ideogram.ai/models/vector 可生成可编辑 SVG；主持人早期试用，狼嚎月与「轮滑猴子」案例中 4 张有 2 张可用（多腿翻车仍在），胜点是矢量元素可单独选中改色改形。
- **ElevenLabs Chimera**：图像+音频生成口型同步视频，底层组合了字节的 Seedance 2.5（转写识别为 Seed Dance）与 ElevenLabs V4。主持人实测吐槽有信息量：上传的是他站姿照片，成片却把他放上凳子、加了特写和照镜子镜头——「一次都没用我的原图」；UI 一堆小 bug（提交按钮跑出屏幕、30 秒上限在生成完才报错），但口型同步「确实越来越近了」。
- **Mistral Voxtral 3**（转写识别为 Misstraw/Voxstraw，按产品线疑为 Mistral 的 Voxtral）：语音 Agent 演示可观——双人同时对话可实时分辨说话人（节目引用其演示词「我在实时做 diarization」）、可被打断、可调用工具。
- **Perplexity Computer 本地化**：其 Agent 软件可完整跑在 Mac 上（云端计算机不再必需），运行 Qwen 3.6（转写识别为 Quin 3.6），建议 36GB 以上统一内存。
- **Canva Craft**：Canva 首个自研图像模型，出自收购来的 Leonardo AI 团队，入口在 Dream Lab 标签页并开放 API（主持人披露自己持有少量 Canva 投资）。
- **GPT Image 3 传闻**：Testing Catalog 称 OpenAI API 内出现 Aurora Red/Green/Blue Alpha 等代号，主持人按惯例判断「离发布不远」。
- **Zoom 深伪检测**：面向企业的 AI 活动可视性工具，判断通话对端是真人还是深伪——呼应前几年 CEO 深伪视频指挥转账的骗案。
- **微软 MAI-DXO**（转写识别为 MAIDXO）：文章《Building Medical Superintelligence》称其诊断准确率为医生的 1.7 倍、为「医生+教科书+联网」的 2 倍多、为「无资源医生」的近 4 倍（均为节目转述的研究口径）。
- **宇树机器人视频**：一段病毒视频展示其人形机器人（型号转写识别为 H2/X2H 不一）翻越汽车、踢凹陷引擎盖、4 米跳下、脚下绑烟花空翻、「保护」路人、抬车「救人」、推开险被撞的孩子——主持人逐帧质疑：抬车抬的是塑料保险杠、车身大部分重量可能不在机器人手里；推小孩的力道比那辆慢速车大得多；他判断全程为遥控演示机械能力、并非自主行为。
- **赞助段落**（已按节目披露识别）：Hyper Agent 平台支持直接用现有 ChatGPT 订阅登录驱动「像员工一样分工」的多 Agent 团队，付费档赠 100 美元额度。

## 观察指标

两条主线各给一个可跟踪的信号：安全侧，看「AI 抢先找洞—平台分钟级披露—攻击面瞬时放大」这个循环会不会成为常态（PHP 案的「公布后 45 分钟尝试翻十倍」就是模板），以及 API 密钥类泄露后各托管平台的轮换与赔偿方案；站队侧，盯 Shopify 的 Agent 友好政策能否转化出可感知的订单增量——那是其余观望网站决定开放与否的定价锚。
