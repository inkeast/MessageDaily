先说结论：Matthew Berman 请来 Anthropic 研究员 Jeremy Berman（两人同姓但并无亲属关系；嘉宾自述自学出身、循直觉入行），用约 56 分钟把大语言模型的训练讲成一节公开课：神经网络就是一堆可自动调节的「旋钮」，PyTorch 按导数方向替你拧；语言模型把同一份数据变成「预测下一个词」；预训练得到一台无保证的互联网自动补全机，后训练用预填与指令数据「骗」出助手人格；强化学习（DeepSeek 的 GRPO）让模型在可验证环境里从试错中自己学会思考。最后回答「模型能否逃出训练分布、做出真正的新发现」时，嘉宾押注肯定，理由是「推理本质上就是把那些不太可能、但真实且有趣的东西变得更可能」。全程演示基于免费工具（Google Colab 免费 T4 + 开放权重的 Qwen 小模型），主持人结语称以此为业「不需要博士学位」。

## 一、神经网络：从一张纽约房价表开始的「旋钮」心智模型

Jeremy 的讲法从具体例子切入：预测纽约公寓价格，输入是位置（SoHo）、面积、卫生间数，输出是成交价。传统做法是把「面积在一千到两千之间、卫生间一到两个，价格就在这一带」之类的判断手写成代码——七条数据可以硬编码，百万条数据、上千个输入就写不动了；节目类比房产经纪人「脑子里装着几百个输入」（装修、建造年代……）做的其实是模式匹配。神经网络的路子是让计算机自己把这个函数「长」出来：每个输入乘上一个参数再求和（参数初始随机，如 0.25、0.05、0.15），这些参数就是旋钮。主持人复述确认——旋钮相当于给每个输入分配「重要度」——嘉宾认可这是好的表述。三个旋钮不够就加旋钮、加层，函数套函数，这就是神经网络；训练目标是把 loss（预测与真实值的平均偏差；例子：两百万美元的公寓预测成一百万）压到最小。嘉宾还给了一个去魅视角：语言模型「其实就是从 Hugging Face 下载的一份文件——数字就是大脑，即参数；所谓两万亿参数的模型就是两万亿个数字，外加一个描述这些数字如何接线的 Python 函数」。

## 二、训练：让计算机替你拧旋钮

手动逐个调旋钮不可行，嘉宾称让计算机自动完成这件事是「神经网络真正伟大的发明」：PyTorch、JAX、TensorFlow 这类 autograd 引擎记录全部参数与计算，算出 loss 后对每个参数求导（链式法则，他建议初学者直接把「PyTorch 会告诉你每个旋钮的影响」当作黑盒接受），再按学习率朝降低 loss 的方向微调每个参数——这就是反向传播（backpropagation）。主持人总结：「你刚才描述的就是今天所有 AI 的基本单元。」两个补充要点：其一是万能函数逼近器性质——层与旋钮够多即可表示任意函数，玩具示例里 loss 理论上可压到零（现场 1000 步从 8 降到约 0.07 百万美元偏差，受限于示例只是个简单线性函数）；其二是训练原料只有两样——输入与真实世界答案（标签）。他顺带给出门门捷径：让 Claude 或 ChatGPT 写并逐行讲解这段 PyTorch 代码，「这些系统极其擅长此事」。

## 三、语言模型：同一份数据换个玩法

同一张房价表可以原样变成文本：输入是词（实际是 token，为直观先当词理解）的序列，任务从「输出一个数」变成「预测下一个词」——看到 SoHo 预测逗号，看到「SoHo,」预测 1200。模型学习数据中的模式并「成为你的数据」：只喂这类文档一百万行，它就只擅长这类文档的语言，但仍能学到足够模式把正确价格「续写」出来。主持人与嘉宾确认专用网络与语言模型的关系：数据与算力足够时两者理论上收敛到同一个正确函数；有限资源下若只求输出价格，普通神经网络性价比更高；语言空间自由度大得多，需要多得多的参数、数据与算力才能收敛到同等精度。

## 四、预训练的真相：一台互联网自动补全机

把任意文本——整个互联网——倒进去训练，得到 base model：它会「浸泡」进互联网的模式，做无保证的自动补全——不保证正确、连贯或有帮助，只保证更像训练数据。嘉宾用 Qwen 2.5 0.5B（5 亿参数、开放权重）现场演示：空输入让它随机续写一百词，先吐代码、再吐中文，据此可推断训练数据里这两类文本占比很高；输入「Matthew Berman said」它编造出一段「访谈名言」（「一本好书应该是有主角的好故事」），主持人指出原因——训练数据里没有他的信息，若把他的 YouTube 转写喂进去，不保证真实但「会更像你」。节目点出：ChatGPT 走红之前公众接触的多是这类 base model。后训练第一步是「预填骗术」：既然模型只会补全，就把文本预先写成「user: 1+1 等于几？assistant:」——模型顺着它见过的所有助手语料，把自己补全成一个助手；Qwen 2 用 im_start/im_end 标记规范了这种格式（转写「M start, M end」已校正）。但 base model 不知道何时停，会一直续写到 token 上限。于是造数据：人工撰写或生成约十万条「好助手回答」样本，带上格式与 stop token 再训练——用嘉宾的话说模型「开始有了自我（ego）」，学会扮演助手并适时停止，这就是 instruct 模型（「天为什么是蓝的」演示回答基本合格；嘉宾一句带过这大致就是 GPT-3 时代的水平）。平时 API 里的 role/content 消息结构本质就是同一套预填，聊天界面与模型看到的补全文本「完全等价」——用 tokenizer 就能看到模型实际收到的 token 序列。主持人特意说明：这一切都可以免费用 Google Colab（嘉宾用的就是免费 T4）加开放权重复现，链接在简介里。

## 五、让它思考：从一句提示词到 GRPO

助手模型仍会不假思索地抢答：演示问 398×923+2901，模型自信地答 37,000，节目称正确答案约 370,000。研究者发现只要预填「let's think step by step」再让它续写，答案就明显变好——主持人回忆这是 ChatGPT 公开走红之后公众才普遍掌握的技巧（他早期做模型评测视频时还在手动敲这句话），嘉宾补充「实验室内部当时是否已掌握不好说，公开渠道确实是新东西」。第一个公开的思考模型是 OpenAI 的 o1，而公众真正理解其机制是在 DeepSeek R1 论文发布之后。Jeremy 解释非思考范式为何持续很久：互联网缺少「思考过程数据」——博客与代码都是思考的成品而非思考本身；即便喂思考数据，模型也只是模仿思考的样子（他补充：数据与模型足够大时原则上也能真正掌握思考模式）。突破口是强化学习：让模型自己试错。朴素做法是「答一百次只把对的收进训练集」——拒绝采样（rejection sampling），确实有效，但学不到负样本，且每次回答中大量无关 token（他举例「of、does 之类的随机词」）也被一并强化。DeepSeek 所用 GRPO（组相对策略优化）把一组回答按格式遵循与正确性打分、减去组均值得到 advantage：高于平均的回答中每个 token 变得更可能，低于平均的更不可能——既学了负样本，又在规模上抵消噪声。更关键的是 on-policy 性质：模型用自己生成的数据训练，只需轻轻拧旋钮就强化了「它本来就能给出的好答案」；模仿别人的思考时，你在放大那个人全部思维路径的同时「并不知道压低了哪些词」，更容易连带损伤既有能力。这也回答了主持人「为什么预训练与后训练要分开」：预训练吃世界的离线数据（off-policy）；模型一旦有了助手人格，再拿代码语料回去训，它会「入戏」开始用代码腔说话、丢掉助手行为。已有论文尝试把 RL 融入训练全栈，两阶段未来可能合并。当下可复制的配方是：凡能构造「模型多次作答 + 对错可验证」的环境，模型就会在该任务上爬山式自我提升，对既有能力的破坏有限——「当然仍有一些退化」。

## 六、能逃出训练分布吗：推理=把不太可能但正确的东西变可能

最后一个问题是个老批评：模型只是训练分布上的下一词预测器，分布里没有的东西它怎么「新发现」？嘉宾立场：据他所知，语言模型迄今尚未做出改变世界的全新发现，但已开始攻克未解决的人类数学难题；他押注它们终将做到，因为「推理就是把那些不太可能、但真实且有趣的东西变得更可能的过程」——爱因斯坦提出广义相对论之前，这个想法对他自己也远非高概率选项，是长期推理逐步搭出新抽象才推导出来；模型同理，只要持续训练它们做长程推理，没有理由不能发展出新知识、逃出训练分布。这一判断与本站此前整理的 Anthropic 自主改进（RSI）相关讨论可互为参照（站内成文：[METR 与 Anthropic 的 RSI 十二个月时间线](https://inkeast.github.io/MessageDaily/posts/2026-11-08-matt-berman-metr-anthropic-rsi-12-months/)）。

## 机制链与读者启发

- 心智模型链：把「参数」译成「旋钮」、「训练」译成「按导数方向微调所有旋钮」之后，房价预测器与 GPT 级模型的差别只剩规模与数据形态——嘉宾整期都在示范这种去魅式科普（两万亿参数=两万亿个数字+一张 Python 接线图）。启发：遇到 AI 玄学表述，先问它在拧什么旋钮、loss 是什么。
- 数据形态链：互联网只有思考的成品没有思考过程 → 模仿式训练只能学到思考的样子 → 可验证环境+自生成数据（RL/on-policy）让模型从试错中长出自己的推理。启发：评估一个训练故事，先看奖励信号是否可验证、数据是否模型自己生成的。
- 人格链：base model 无人格只是补全 → 预填+指令数据骗出助手自我（ego） → 有了 ego 之后离线数据回流会破坏人格（代码腔、遗忘）。启发：对已微调模型做继续预训练要警惕灾难性遗忘；对话界面的 role 结构本质是格式化预填。
- 学习路径链：免费算力（Colab T4）+开放权重（Qwen 0.5B）+让 Claude/ChatGPT 写讲解代码 → 自学复现全部核心实验成为可能 → 嘉宾本人就是这条路径的样本，他的建议是「找到让你着迷的部分，钻进兔子洞」。主持人结语：以此为业不需要博士学位，需要的是大量努力。

这期节目不是新闻，而是一份可反复使用的概念地图：往后任何训练相关的新闻（新 RL 算法、新 scaling 争论、新开放权重发布）都可以放回「旋钮—loss—数据—ego—试错」五个格子里检验自己是否真的理解了它。
