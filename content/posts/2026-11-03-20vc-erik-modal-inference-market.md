## 先说结论

这是 Modal 刚宣布 D 轮之后的一场信息密度很高的对谈：**ARR 破 10 亿美元、年增 15 倍、Accel 领投 7.5 亿美元、投后估值 157.5 亿美元**（经 Axios/Accel 官网/Modal 官方博客核实；Harry 在节目中称 D 轮「昨天」宣布，与公开报道的 2026 年 10 月 14 日相符）。嘉宾 Erik Bernhardsson 的核心判断有三层：其一，**推理就是「新云」，但单卖 token 没有生意**——零切换成本必然导向逐底竞争，赚钱靠沙箱、post-training、agentic 等平台产品集；其二，**90% 软件毛利的时代已经结束**——客户付的每一美元要穿过应用、模型、基础设施、云、英伟达多层栈，每层抽走 20–30%，Modal 的长期目标是 40–60% 而不是传统软件的 90%+；其三，**比所有人预期大 10–100 倍的推理市场会碎裂成大量专门化子市场，其中有机会长出千亿美元公司**——他用非文本模型 Jev（TypeSafe AI）做例证，并当场回答 Harry「85 亿美元估值你会不会投」：会。对更广泛的读者，这场对话还给出了一组可直接对照自身的基准：GPU 交期 3–4 个月的采购外推法、每月 30–40% 的需求增速、新毕业生被实验室以 2000 万美元以上的薪酬包挖走，以及「每一轮融资都当作最后一轮来融」的纪律。

## 一、卖 token 为什么没生意：推理是「新云」，赚钱靠平台和毛利栈

先把 Modal 的位置说清楚：它不做模型，做的是跑模型的地方——嘉宾称为「为 AI 时代解构并重构云」（960–1080s）。这套叙事的起点是一个朴素的商业判断：**推理市场会变成「 enormously large」的「新云」，但推理本身不够**（720–840s）。如果只是把 token 按美元卖出去，切换成本为零，客户随时换供应商，那就是「逐底竞争」（a race to the bottom）。所以 Modal 把推理与 post-training 沙箱、agentic 工作流、低延迟/批量推理等一整套产品捆在一起——用嘉宾的话说，「没人想买单轮把戏，人们要买一整套工具」——而支撑这整套产品的自研基础设施「非常难复制」。

毛利部分是全场最有结构感的一段（840–960s）。Harry 引入背景：当前推理服务商的毛利普遍在 25–40% 区间，能不能随着吃下更多技术栈走向 70%？嘉宾认为**几乎没有任何公司今天还有「软件毛利」**——十年前硅谷常见的 90%+ 毛利已经死了，而且原因「几乎是拓扑学的」：今天的技术栈是应用→模型→基础设施→云→英伟达，客户在栈顶付的一美元要流过很多层，每一层都要留 20–30% 的毛利。所以他给 Modal 的长期画像是 40–50–60%——「空间很大、钱很多，但你在把它分给栈里的很多层」。这个判断对投资者和创业者都是直接的估值锚：**用传统 SaaS 的毛利结构去套 AI 基础设施公司，会系统性看错**。（本站此前分析 Cerebras 上市后毛利率指引时也遇到过同一问题：推理硬件的毛利同样被供应链与租回设备挤压，见[上文互链](https://inkeast.github.io/MessageDaily/posts/2026-06-22-cerebras-ipo-ai-compute-inference-era/)的分析框架。）

这条链完整地展开是：**信号**（纯 token 转售毛利 25–40%、零切换成本）→**直接原因**（商品化供给 + 无锁定 → 价格战）→**谁得谁失**（平台型厂商得溢价与 staying power，纯 API 转售商失利润率）→**二阶影响**（推理层并购与产品套件化加速，「压缩层」论失效）→**观察指标**（推理厂商的收入构成中沙箱/训练/workflow 等非 token 收入占比、客户续约形态）→**读者启发**（在 AI 栈的任何一层做生意，先问自己:客户离开你的摩擦力是什么）。

## 二、比预期大十倍到百倍的市场，正在碎裂成专门化机会

嘉宾承认，推理市场的规模超出了包括他在内所有人的预期——「比我想的大 10 倍或 100 倍」（840–960s）。而大市场会分裂：低延迟/高延迟、各类微调与 post-training、新硬件、「让你用少得多的资源做推理的古怪新技术」。他由此推出本期最出圈的判断：**「专门化模型 + 推理市场，有机会造出千亿美元公司」**（开场即抛出，1800–1920s 再次展开）。Harry 当场做投委会游戏：Jev（TypeSafe AI 的非文本「校准决策」模型——经 TechCrunch/Bloomberg 核实，2026 年 10 月 9 日 a16z 领投 8.7 亿美元、估值 75 亿美元）凭什么值千亿美元？嘉宾的答案不是基准分数，而是**品牌、社区与「运动感」是新时代的巨大资产**。Harry 追问「85 亿美元时你会投吗」，他答「会，可能退出、可能上市」。注意一个数字出入：节目说 85 亿，公开报道是 75 亿——本文按转写保留节目数字并标注差异，不替任何一方背书。

支撑「专门化」叙事的是 Modal 自己的供给端打法，这段几乎是一份 GPU 采购方法论（960–1200s）。三月份的英伟达 GTC 被 8 岁写代码、36 岁创业的这位瑞典人形容为「露天毒品市场，只不过货是 GPU」——500 家云厂商在场内狂奔询价。Modal 与 **25 家 neo-cloud** 合作、自称控制全球约 0.1% 的算力（自称约数），长期目标是把供给侧的碎片产能与需求侧的波动聚合起来高效调度。工程底座是彻底自研：不用 Kubernetes 和 Docker，自研容器文件、文件系统、容器运行时、调度器——**数千付费客户的负载各自波动剧烈，聚合之后却是平滑曲线**，这让 Modal 敢让客户「按 GPU 秒计费、不签三年锁定量」；Jev 上线当晚在 Modal 上一夜扩容，Modal 事先毫不知情。采购侧的方法是：GPU 交期 3–4 个月，按全体客户的聚合需求做直线/指数外推——过去 12 个月月环比增长约 30–40%，外推三到四个月就是 2–3 倍需求，照此买产能。他也纠正了一个流行误解：**并不是全球缺货**——英伟达每月出货量「疯狂」（节目称数十万块 Blackwell 级别），价格确实涨了，但「只要你愿意比别人付更多，就能买到很多 GPU」；Modal 结构上反而是 GPU 的多头（长协锁量、短租放出，价格上行可传导）。

硬件价格的时间轴上，嘉宾与被引用的黄仁勋观点一致：Harry 转述黄仁勋在伦敦的回答——供给终将赶上需求，「可能一年，可能五年」；嘉宾的口径是「硬件价格像重力，长期必然下降」，当前短缺造成的涨价可能再持续一两年甚至五年，但终会回落（1200–1320s）。芯片竞争格局他拒绝二选一：**英伟达会继续增长，Cerebras、Etched（转写另有两家疑作专名保留原文）等专用芯片也会增长**——市场大到来得及容纳所有人。Harry 问 Cerebras 股价跌三成怎么看，他说不炒股、只被动买指数。对 CUDA 护城河，他认为「有点被高估」：CUDA 本身是个挺难用的低层编程模型，真正的锁定是生态——每家开源推理引擎（vLLM、SGLang）与 PyTorch 都是英伟达优先；他自嘲「过去十五年我每年都说明年是非英伟达加速器之年，年年错」，Trainium、TPU、AMD 在追但仍落后（1440–1560s）。对 neo-cloud 向上进攻推理层（Nebius 创始人曾在本节目宣称要拿下推理市场），他礼貌地怀疑：很难同时做好核心生意和别人的市场——最难复刻的是每分钟放置百万级沙箱、秒级伸缩数千 GPU、数十万并发任务的整栈工程；而他对 CoreWeave/Nebius 最尊敬的其实是**财务工程**：锁长期客户合同→据此融资→买芯片→交付→数年还债，「这是一场资本游戏」（1560–1680s）。

## 三、开源推理见顶了吗：与 Jason Lemkin 的分歧，和「拥有智能」的边界

开源是本场火药味最浓的交锋点。Harry 转述 Jason Lemkin 的「见顶论」：前沿闭源厂商正在 bluntly 提供极便宜的产品，美国企业又不愿用中国模型，两股风叠加，开源 LLM 推理的使用量将平台期甚至下滑（2280–2400s）。嘉宾的回应干脆利落：「这是一种固定饼大小的思维」——**未来十二个月及以上，开源与闭源都会增长 5 倍、10 倍、20 倍**，争论谁更大没有意义。这场分歧背后是 Modal 自己的学费：他坦承曾以为开源推理「会是逐底竞争的商品化空间」而按兵不动，**DeepSeek 发布后才连夜组队，相关团队从一两个人扩张到十二个月后的三十人，如今是开源推理的前三名提供商**——「承认误判、快速补课」本身就是组织能力。他还点出一个结构性变化：开源模型正在集体转向 licensing 收费，能捕获价值就有钱训更好的模型，形成正循环；他并希望出现更多欧洲与美国模型——尊重中国实验室的能力，但「权力更分散对世界更好」（1560–1680s）。对欧洲的判断有两层：先说欧洲难积累巨额资本，随即自我纠正——**欧洲的人才资本其实极多，真正缺的是把顶尖人才聚合进同一家公司的能力**，而这恰是美国的强项（1680–1800s）。

「每家公司都该拥有自己的智能吗」这个应用层问题，嘉宾给的是两面答案（2880–3000s）：节目引用的两侧案例是 Harvey（称专门化模型很棒）与一家转写疑作「Lagora」的公司（称底层模型变得太快、该策略荒谬）。他的立场：开源微调的真实价值在于**底座不会变、不会被拿走、可以持续调参**——这解释了为什么总有人要自有模型；但拥有智能只是延迟、成本、性能、可 hack 性、相邻服务等诸多因素之一，不是普适答案。有趣的是 Harry 指出这个诚实对他生意不利（「每家公司都需要，而我们是帮你做的伙伴」才是利益一致的说法），嘉宾笑着举出反例：TypeSafe 的 Jev 是高度专有模型，照样跑在 Modal 上——Suno、Runway、TypeSafe 这类专有模型客户与开源微调客户**两头都是 Modal 的生意**，通用平台的中立性本身是护城河。模型路由（routing）同理：可以是好生意（他个人投了 OpenRouter 且「结局很好」），但长期更可能被吸收进综合平台（3120–3240s）。

后训练一段值得所有押注 Agent 的人细读（2520–2760s）。他认为 pre-training 向 post-training 的资源迁移「是新常态」，但**post-training 有效的边界是反馈机制有限的任务**：写代码（可以在沙箱里跑强化学习——很多实验室正在 Modal 沙箱上做这件事）、网络安全、数学（Lean 与 OpenAI 的形式化证明）、法律（evals）。对反馈回路更长的工作，RL 是否够得着，他明确存疑——工程师的工作时间尺度是周和月，「我猜我们终将撞到 RL 的某些限制，但我错了太多次，也许还会错」。顺着工程师话题，他给出本场最「反焦虑」的判断：**极度看多软件工程**。三十年编程史里，语言、云、框架每次提效都扩大了软件需求；外行最大的误解是把工程师当成「英语翻译成代码」的角色，实际工作是理解需求、在人之间做接口；抽象层一路从汇编→COBOL→C++→Python→如今的 agents 上移，工程师「未来十到二十年没问题」。作为佐证他报了 Modal 自己的账：**150 名工程师、每月约 50 万美元花在编码 agent 上**——Harry 直呼「低得让人担心，应该十倍、应该 token maxing」，并引用一家公司（转写疑作）「推理花费是人力薪资三倍」的说法；嘉宾笑答团队已经全员 agent-pilled（2760–2880s 处 Harry 亦引用 Claude Code「600 亿美元收入、主导 2 万亿估值」与 Benioff「3 亿美元、工程师薪资 5% 花在 Claude Code」的说法——均为节目引用，未独立核实）。他的结论沿同一机制：效率提升只会让 agent 吃掉更多工作流——「这是计算机与软件五十年的规律」。

## 四、品牌、人才与钱：新基础设施公司的第二战场

技术栈之外，这场对话有一整条关于组织与资本的暗线。护城河话题上，嘉宾先立规矩：护城河有严格定义（《Seven Powers》），早期公司根本没有护城河——他常回看 Ben Thompson 写 Snap 的「姜饼人策略」：**Snap 没有护城河，只是跑得比别人快**；今天几乎所有创业公司的真实防御力就是速度（480–600s）。Harry 顺势给出自己的投资三要素：顶级团队、产品决策速度（他举的例子是 Instinct 的功能交付速度——该产品经核实为 2026 年 8 月上线的邀请制个人 AI agent，WhatsApp/iMessage 即可唤起，Harry 自称在上面跑着一百多个自动化，从买演唱会门票到母亲的用药提醒）、以及品牌。品牌怎么造？嘉宾用 Jev 创始人的对照讲得极其生动：「人人都想克隆 Jev，但没人愿意穿上粉色皮草大衣上台、用 unhinged 的方式讲 Jevolution」——**品牌=真实+不同=给公司造一个人格，再把它变成一场运动**。他自省 Modal 缺一点「人格崇拜 cult」，可以更 loud；而早期 Modal 的获客飞轮是他本人：粉丝数到五万之前，他每天凌晨一点到两点半给每个新关注者手写感谢私信，一晚 50–100 条，其中一半后来成了 Modal 的天使投资人（1920–2040s）。

产品节奏的故事可能是对创业者最有用的一段（2040–2280s）：Modal 的第二产品**沙箱 2023 年就上线了，前两年不温不火，直到 2025 年夏天模型（转写校正为 Sonnet 4.5）的代码生成能力突然成熟才爆炸，如今是 3 亿美元 run rate、约占公司收入三分之一**——「第二产品用了四年才见成功」，而公司「五年到十亿收入」。更早的 serverless 函数产品 2021 年就发布，真正的杀手应用 Stable Diffusion 是他们没预料到的。他的方法论：基础设施公司要造「积木」，工程师会提各种随机需求，你要蒸馏出基本原语、相信自己的直觉，然后**「在游戏里待得够久，让时机来找你」**。未来的产品地图上，刚上线的训练产品他希望六到十二个月做到 1 亿美元 run rate，后面还有批量、强化学习、数据仓库、向量库、CI、agent harness——他自嘲这是「ADD 大脑」，所以必须无情排优先级、一次只做一两件。

## 机制与启发

把全场内容压缩成四条可迁移的链条：

1. **毛利栈链条**：AI 技术栈分层（应用→模型→基础设施→云→英伟达）→ 每层 20–30% 抽成 → 90% 软件毛利结构性消失 → 平台化（多产品集）成为推理层唯一逃离逐底竞争的路径 → 二阶影响：估值模型从 SaaS 倍数转向「层内份额×毛利带宽」→ 观察指标：非 token 收入占比、客户切换摩擦 → 启发：在栈上任一层创业，先回答「客户离开我的摩擦力是什么」。
2. **专门化链条**：市场规模超预期 10–100 倍 → 子市场（低延迟、批量、微调、非文本模型如 Jev）足以各自撑起大公司 → 通用实验室与专门化玩家分层共存（非零和，英伟达与专用芯片同理）→ 二阶影响：应用层按功能「非捆绑」选模型成为默认架构 → 观察指标：专门化模型的定价与采用（Jev 类「校准决策」模型的收入曲线）→ 启发：别用「通用模型会碾压」一票否决专门化创业——历史（他十五年看错非英伟达加速器）同样警告反方向的过度自信。
3. **供需聚合链条**：GPU 交期 3–4 个月 + 单客户需求波动大 → 聚合数千客户得到平滑需求曲线 → 聚合者可以「按 GPU 秒」零售弹性、吃效率价差 → neo-cloud 上攻推理层受制于整栈工程复杂度，胜负手在调度器/文件系统这类「无聊」资产 → 观察指标：GPU 交期、月度需求增速（Modal 为 30–40%）、硬件价格「重力」何时压过短缺溢价 → 启发：任何紧缺商品的聚合层都有同一门生意，前提是你自控调度与计费的底层。
4. **人才—资本链条**：实验室以 2000 万美元级薪酬包虹吸应届生 → 现金竞赛创业公司必输 → 用 95 分位现金 + 股权上行 + 员工二级出售先例把股权做成「硬通货」→ 二阶影响：薪酬结构设计成为早期公司核心能力；同时「每轮当最后一轮融」的公司在回调中活下来 → 观察指标：应届生薪酬包、员工二级出售的普遍化、依赖输血公司的融资死亡率 → 启发：融资纪律与人才货币化是同一枚硬币——都关于让你的「纸面资产」变成真钱。
