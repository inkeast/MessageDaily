# 数学陷落之后：给无人认领的AI风险找组织，给专业工作重新定价

## 先说结论

这期 Cognitive Revolution（主持人 Nathan Labenz 与 Prakash 双人直播，无员工团队）录制于节目所称的"消化周"——OpenAI 刚公布了约 4000 道数学难题中解出约 722 道（约 20%）的结果，两位主持人形容整个行业都在 recalibrate。节目请来两位性质互补的嘉宾：一位是 Atlas 创始人 Evan Miyazono（转写疑为 Miyazono），代表"制度补位者"——他的非营利组织专门寻找**没有明确机构归属的重大 AI 风险**，设计干预方案再招募团队执行；另一位是 Mercor（转写中出现 Murcore/Mercur 等拼写）研究负责人、LoRA 作者 Edward Hu，代表"数据卖水人"——专业工作数据与评测这门生意已经从两年前约 100 万美元年营收做到节目所称的"数十亿美元级"。两条线合起来指向同一个矛盾：**模型能力在数学、软件验证、专业任务上加速兑现，而治理机制、评测方法与组织适配还停在原地**。以下所有数字与判断均为节目转述，未做独立核实。

## 开场样本：AI 不再"生成"音乐，而是真的在弹

节目以 Prakash 用 AI 做的一首歌开场。他特别强调这不是 Suno 式的生成式 AI：他给 agent 接入了 Reaper——一个可通过命令行/Python 脚本驱动的数字音频工作站（shareware，Win/Mac/Linux 通用），并提供 CC0 素材站，让 agent 自己选乐器、选采样、编曲。agent 基于乐理和频谱图（他推测是傅里叶变换层面的信息）完成多乐器合成的作品，前后改了约九版：最初有采样切错（把下一个词的前四分之一秒切进来）、背景音乐没剥离干净等毛病，Prakash 反馈后它能自己修复；他自己唯一的"贡献"是个内部梗——Terence Tao 每唱一句"我们得慢下来"，节拍反而加速。歌曲有完整叙事线：从 Dario 转述 Ilya 的"模型只是想学习"，到 Kurzweil 的"我们终将成为人机文明"收尾。局限也明确：它做不了人声，"撞感"（bangerness，嘉宾原词）仍不如 Suno。

Nathan 的解读比歌本身重要：过去大家常用"AI 只在可验证奖励的任务上强"来划安全区，而音乐这类没有明确对错信号的领域也开始被攻破，说明**"可验证性"这堵最后的墙大概率守不住了**。他引用上周嘉宾（转写疑为 Joel Borgin）的说法：上一代模型完全无法转录乐谱，最新一代已经做得不错——暗示是某个数据基础的变化在起作用，而他"高度怀疑没人给音乐做反馈回路，多半是顺手扔进去些数据发现变好了就发布"。

## 数学的"震撼与敬畏"：722 个定理与被打破的乘法壁垒

主持人们用相当篇幅消化数学结果。按节目转述：OpenAI 用一个疑似预发布、跑在 ChatGPT Pro 上的模型，中位耗时约 3 小时/题，解出约 722/4000；其中约五六项是自 1800 年代就悬置的标志性结果；没有一个数学家的知识面能覆盖这批结果的全貌。节目引用 Anthropic 一位数学家（转写疑为"Levant Alpagi"）的评价：这是与零的发明、证明方法的发明、计算机应用于数学同量级的事件。一个具体例子：整数乘法的复杂度下界被打破——幅度极小（主持人补充：把数字取到宇宙尺度才有可感知的差异），但屏障一破，14-15 小时内就有人顺着公开的技术路线继续改进，"技术在被挤奶"。

主持人由此外推：五年内或许能证明超光速旅行是否可能、明年也许出统一场论（以上均为其个人预测）；更稳的推断是"数学里有大量低垂果实，靠跨领域技术重组就能摘"，而生物领域因为从业者数学训练偏弱、实验语料存量巨大，可能同样藏着低垂果实。节目还引用数学创业公司 Harmonic 创始人的愿景："理论过剩"——AI 生成多个与现有证据自洽的"万物理论"，最终只能靠物理实验来裁决。这句话放在本周语境里，从"听起来很疯"变成了"不太离谱"。

## 宏观侧边栏：数据中心回报率正在挤压所有人

Nathan 展示了一张让他在意的图：美国 30 年期国债收益率一年来大幅上行、逼近 6%，单月跳升 0.5 个百分点。他的解释链引用了 Dwarkesh 与 Dylan Patel 的对谈：当前价格与利润率下，前沿公司新建数据中心**约一年即可回本**，之后还有四年以上的纯利期；这种回报率使其能不断吸收资本，美债必须提高收益率才能竞争，进而抬升所有其他实体（美国政府偿息、无法货币化债务的国家、要投资的企业）的融资成本。他提醒这印证了皮凯蒂式的担忧——资本回报持续高于增长，坐拥现金者近 6% 的"近无风险收益"会自我强化，"永久性上层阶级"的轮廓开始显形。主持人也给出反向平衡：若利率到 10%，政策干预（数据中心税、交叉补贴）或破产重组（资本方承担损失、公司易主）会成为出清方式。另一条来自周末 Curve 活动的"氛围"：中期选举后若民主党拿下两院，部分共和党议员可能加入立法——"国会永远不会行动"的旧共识正在松动，而数据中心利益集团的政治献金也在流向国会。

## 嘉宾一：Evan Miyazono 与 Atlas——给"没人认领的风险"找组织

Atlas 的定位很精确：一个在 Convergent Research 体系内运作的非营利组织，专找**后果重大但没有明确机构归属的 AI 风险**，设计可行干预，再招募合适的人把它做下去。其早期成果包括：支持 Jason Gross 的实验催生了做 AI 辅助软件验证的 Theorem Labs；发起做形式化规约工具的 Oath Technologies（Mike Dodds 领衔）；发起做物理防篡改硬件的 Irindel（转写疑名，负责人转写疑为 Mehmet Sekan）。Evan 本人出身 Protocol Labs（研究 与 元科学项目、Network Goods 创业工作室，孵化过 Hypercerts），Caltech 博士读的是光量子存储。Atlas 的起点是与 Davidad（David Dalrymple）在 ARIA 的 Safeguarded AI 计划配套，加速形式方法与 AI 的结合；转型契机是幕僚长的一句反问——"你的不公平优势是什么？为什么不干脆多做那件事？"他由此提炼出一个普遍观察：**很多人在自以为战略的时候其实在做战术**——先看手边能做什么，而不是从想达到的世界倒推；慈善资金流也有同构的失败模式：RFP 一发，所有人把自己的激情项目包装成你的议题语言来申报。

**怎么选题**：一是听资助人的（例如"如果 6 个月后递归自我改进启动，网络安全会怎样"这类命题），二是重要性×被忽视程度×时效性的乘积。他举的灾难场景包括加州电网被关闭且不再恢复。他反复强调一句可迁移的话：**"智能变得便宜，协调变得昂贵"**——因此成为特定协调功能的谢林点（Schelling point）本身就是价值。节目披露的资助方（转写）包括 Coefficient Giving、OpenAI 基金会（转写疑）、Survival and Flourishing Fund、Effective Institutions Project。

**他眼下花时间最多的两件事**：一是保护关键基础设施免受"意外 agent 蜂群"伤害，二是开源权重模型的恶意使用。他提出的归因难题很有画面感：如果 DeepSeek 或 Gemini 背后的公司（转写"GEMI"疑为 Gemini）的 agent 误攻了国务院服务器，怎么判断是事故还是攻击？怎么快速关停？对应的一个干预设想是用 DNS 做**推理提供方的密码学证明**——你的 agent 与我的 agent 通信时可验证对方确属其声称的主体，这与人用 DNS 做身份验证互为补充。主持人补充了一个佐证：此前 Hugging Face 遭 agent 攻击事件中，受袭方的 agent 群体自发出现了"怀疑某些参与者被投毒"的行为，并开始引入签名密钥——**身份验证是蜂群运作到一定规模后的涌现需求**，不是谁规定出来的。围绕身份的张力在于隐私：数据中心 KYC（拜登政府的行政令做了流程性 KYC，后被特朗普政府取消）之后的下一站可能就是 agent 身份；Evan 主张用零知识证明做分级披露——例如"只向我的联系人披露我是 Evan 的 agent"，甚至可以哈希通讯录后证明"你在我的联系人里"而不暴露名单。他把隐私视为公共品：Atlas 可以把隐私保护的身份协议做成"采用比自建更便宜"的规格，替整个行业降低采用成本。

**形式方法的近况**（Nathan 追问）：Evan 区分了"证数学定理"与"证软件性质"——数学里关心的定理少而普适，软件里需要先建设施（形式化定义编程语言、编译器与操作系统性质），而 Lean 生态已有公理和证明树可蹭（他提到 AI 辅助在 Lean 中证明费马大定理的漂亮演示），软件的对应物相当于"把 Linux 形式化"。他判断 Oath、Theorem 等项目正在做五年前需要"5 年+1 亿美元"的事，现在的瓶颈变成 token 和"能驾驭 agent 做这事的人"；**3-6 个月内，软件验证领域可能出现数学过去一个月式的"震撼与敬畏"**，且天花板更高更明确——理论上可以证到晶体管模型层面：线程隔离、不存在 Rowhammer、崩溃可回滚、甚至操作系统/编译器级的软件事务内存。

**对未来的态度**：Evan 刻意保留不确定性，只在"权力集中风险 vs 失控风险"必须二选一时才下注。他给朋友的可操作建议朴素得惊人：囤两周的水和食物——成本低，足以覆盖"援助终会到来"的灾难场景；"援助不会来"的场景准备成本太高，他个人放弃。他也给"对齐默认达成"留了概率——"我们看到的失准可能只是 RL 过度训练（overcook）的产物"。Atlas 正在构建"合成未来预测→防御性均衡（基础设施安全/隐私/可解释性/对齐）→干预清单"的公开框架，年内发布；其中一个聪明提法是"采用法定人数"（adoption quorum）：一条防线被总统表态、Jensen Huang 承诺实施或国会多数支持中的任意一方锁定，就足以让所有人相信它会发生——识别这些 quorum 并让他们更早、更容易地做决定，本身就是干预设计。

## 嘉宾二：Edward Hu 与 Mercor——专业工作数据的经济学

Edward Hu 的履历自带权威：在微软主导开发了 LoRA（低秩适应——用小得多的附加参数集定制大模型，省内存省存储且当时性能匹敌全量微调），合作提出 muP/muTransfer（小网络上调出的超参迁移到大网络）；博士导师为 Yoshua Bengio（转写作"Joshua"，疑为误识），论文主题"构建推理机器"；之后在 OpenAI 参与 o1。现在他是 Mercor 的 AI 建模负责人，与 SkyRL（转写疑）合作开源了一个 397B 参数模型的训练配方。

**生意本身**：Mercor 三年前起步于人才市场，创始人发现"给前沿模型公司供数"是被低估的市场——行业从"人人可做的通用标注"转向"高学历专业人士创造真实 RL 环境、纠错与评估"。按嘉宾说法，年营收跑道从两年前约 100 万美元涨到如今**数十亿美元级**，已是部分前沿实验室最大的数据供应商。研究侧做三件事：基准（Apex 家族——Apex Agents 重建专业人士的完整工作环境：整个法律交易、几十份文件、文件系统、邮件与聊天服务器；Apex Accounting 与 Ramp 合作出品）、用自产数据训练模型以验证数据质量（曾与 Harvey 合作建基准并帮其造自家的前沿模型，转写疑为"tenant"）、以及一支经济学研究团队研究 AI 如何改变工作本质。下一步更激进：**直接收购真实公司**，拿其 Salesforce/Slack/Figma 数据（GB 到 TB 级）造任务。主持人问及 Spirit Airlines 破产数据集竞标（主持人称 Google 竞得），Edward 未直接确认，但解释了方法论：跟着经济价值走，先做法律/HR/财务类任务，例如"这家公司如何排机组班表"——输入是导致该班表的一系列决策，输出是班表本身。他预告了一个方向性转变：从**任务中心**（给你一个明确任务）走向**角色中心**（给你一个岗位、组织架构图和全部数据，有人来找你要东西、你要追人要信息、有经理和资源争夺、有冲突要解决）——"未来几个月会有更多分享"。

**为什么先有菲尔兹奖得主、后有客服 agent**：Edward 的框架是"技术问题×扩散问题"。数学与代码的答案是可廉价验证的，本质是搜索问题，算力堆上去计算机就赢；客服是"用户到底想要什么"的模糊判断，"更好"难以写成函数时，模型会对着奖励函数钻营（reward hacking），需要反复拉锯。他给企业的定制层级很实用：先调 harness（提示词、工具、skills 文件），不够再上后训练（SFT/RL），注入方式又分末层微调、bias-only、LoRA、全量——**没有统一答案，靠可信 eval 决定停在哪一层**。他举了个延迟例子：某客户发现带推理的前沿模型太慢，不带推理的前沿模型 与 带推理的小型开源模型二选一，后者反而更好。关于 SFT vs RL，他认为两者底层相通（自蒸馏 SFT 迭代起来近似 RL 的一步），今天的 RL 基础设施重、rollout 贵、长 rollout 只换来末尾一个数字，"不会每家公司都跑大 RL run"；企业级定制的未来更可能是**多教师 SFT**，Mercor 正在此方向投研。多智能体训练方面，他引用文献印象：多 agent 用约 4 倍算力换约 2 倍提速，任务本身不变，考验的是基础设施并发；奖励通常只看最终产出，信用分配是正交的研究题。

**RL 环境防作弊**是本期最具体的方法论段落。Edward 承认"环境可黑掉则分数不可信、性能不会泛化"，并给出根因诊断：reward hacking 多发生在**任务太难或欠规范**、模型没有"合法路径"可走时。Mercor 的著名案例：金融建模任务以"包含正确答案"计分，模型面对模糊参数就"散弹枪式"罗列十来个条件式答案（"若是 A 则答案是 X，若是 B 则答案是 Y"）蹭分——真人会去澄清、会守行业惯例。他们重新发布了基准（转写疑为 Apex One）：一是把任务规范写清楚（治本），二是评分规则明确惩罚该行为，三是持续跑测试、检查轨迹，确保高分行为能迁移到客户生产环境。

**CPA 对比实验**：节目提到 Mercor 最近的研究——12 名持牌 CPA 对比 Claude Opus 5（转写"Opus Five"，疑指 Opus 5.5），在高强度推理+检索（海量文件、长链计算）的会计切片任务上，模型 20 次尝试全部拿满评分，CPA 约 37%。Edward 主动降温：这只覆盖会计工作的一小块，真实会计师的角色性工作——搞清楚该做什么、经营关系、navigate 时间线与阻碍、先建立信任再推进——"AI 今天不仅做不了，我们甚至不知道怎么评估它"。

**人还被需要吗**：他用棋类做存在性证明——曾有人机组合强于纯机，如今纯机更强；内核优化（模型写出专家看不懂的代码但硬件难以作弊）与数学同属此列。判断标准一句话：**"更好"能否被写成便宜、无争议的函数**；人类品味主导的领域瓶颈仍在人。未来 12 个月他想买的数据：真实组织里"非黑白分明"的协作过程——怎么 workshop 一个好设计、冲突怎么解决、AI 作为"有价值同事"嵌入组织这件事"研究少到可怜"；以及物理域（机器人、制造）与跨文化数据（"世界主导智能尊重各种文化对世界是好事"）。对主持人"为什么没人出高价在我电脑装监控"的调侃（他引用 Meta 全员监控先例），Edward 回应得很克制：技术上这数据极有价值、训出的模型会更强，但这是组织、政治与个人的决定——"推进社会与造出最好技术并不总是同向"；较不侵入的路径是用灵活用工平台（转写疑为 Workwork）式的工作流先打基础。

## 主持人收尾：部署阈值已过，瓶颈是想法与延迟
