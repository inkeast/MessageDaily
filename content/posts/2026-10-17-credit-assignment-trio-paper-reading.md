## 一、论文背景：RLVR 的奖励到底稀在哪里

要用强化学习训练大模型智能体（业内称 RLVR，Reinforcement Learning with Verifiable Rewards），第一步是给模型的输出打分。最流行的打分方式是**结果奖励**（outcome reward）：只看最终答案对不对，对给 1、错给 0。数学题可以对答案，代码题可以跑测试，这就是『可验证奖励』的由来。

但结果奖励有一个结构性缺陷：**稀疏**。一条推理轨迹动辄几百上千个 token、几十步工具调用，而奖励信号只在最后一刻出现。这带来两个后果：

1. **信用分配失败**。轨迹答对了，是哪些 token、哪一步操作的功劳？答错了，又该罚哪一步？结果奖励无法区分——它把同一个分数广播给轨迹上的每个动作。ProAS 的测量显示，Qwen2.5-1.5B 在 ALFWorld 的**成功**轨迹中竟有 41.6% 的动作属于结构无效的『不合理动作』，它们跟着正优势一起被强化了。
2. **训练信号饥饿**。GRPO 这类组相对算法要求同一任务的一组 rollout 里有 reward 方差才能产生优势。Tev 算了一笔账：若策略解出任务的概率 p=0.05、组大小 G=8，则全组皆败、优势全为零的『废组』比例是 (1-p)^G ≈ 66%；p=0.01 时高达 92%。长程任务上未训练模型的 p 恰恰只有百分之几——Tev 实测未训练 Qwen3.8-27B 在其语料上仅解出 3.2% 的环境，52% 的 rollout 还没提交就耗尽了 65k token 上下文。

过程奖励模型（PRM）试图缓解第一个问题：对推理的每一步打分。但 PRM 的步级分数仍然覆盖几十上百个 token，P2T 称之为『步内的模糊性』；而且训练 PRM 本身昂贵、标注噪声大。于是问题变成：**能不能在不付出巨大代价的前提下，把粗粒度奖励拆解成真正细粒度、且可靠的学习信号？**

本组合读的三篇论文，恰好代表了回答这一问题的三条互补路径：

- **Tev**：从**环境侧**入手——反向合成带有已知正确中间状态的训练环境，从源头制造出密集、可验证、防 gaming 的进度势奖励；
- **P2T**：从**奖励侧**入手——不训练任何新模型，用梯度归因把现成 PRM 的步级奖励重分配到 token 级；
- **ProAS**：从**优势侧**入手——不动奖励函数，而是用参考图标注动作结构性质，对轨迹级优势做非对称塑形。

## 二、论文定位和关联工作

### 2.1 环境合成谱系（Tev 所处脉络）

开源社区的智能体训练语料（SWE-Smith 50.1k、Terminal-Universe 32k、TMAX-15K 14.6k、SETA 4.5k、Endless Terminals 3.3k、CLI-Gym 1.7k）规模大但都是 PR 尺寸的短程任务，评估只有终态 pass/fail；真正的长程任务只存在于人写的小规模评测集（几十到几百题，每题数周专家工时）。Tev 的差异化在于**反向构造**：先有已知正确的潜世界，再渲染、再损坏成任务——这与让 LLM 正向生成『任务+输入+检查器』的 self-instruct 路线（Prompt-first 类）相反，也不同于从单个人工制品出发的 BART 去噪、代码变异等传统反向构造：Tev 损坏的是**整个世界的一次渲染**，任务、验证器、进度信号全部锚定在同一个 W 上，从结构上杜绝了『环境、任务、验证器各自看起来都对、合起来描述三个问题』的 artifact drift。奖励塑形方面，Tev 的 PPRS 直接继承 Ng et al. 1999 的势函数塑形（PBRS）框架，但刻意保留终局势 λΦ(sT)、改变了优化目标（经典 PBRS 会归零终局势以保持最优策略不变）。

### 2.2 Token 奖利谱系（P2T 所处脉络）

Token 级监督现有两条路：其一，训练专门的 token 级奖励模型——PRIME（arXiv:2502.01456）在线隐式训练、OREAL 复用策略网络骨干、TVM 加标量头训练，代价高且伪标签噪声大；其二，启发式代理——token 熵（arXiv:2505.15134）、SPRO 用策略与参考模型的 log 概率差，便宜但与『token 是否真有贡献』缺乏语义对齐。P2T 站在第三条路上：**归因而非训练**——把现成 PRM 的输出当作被解释对象，用可微系统的梯度做归因。这与可解释性领域『积分梯度 / Taylor 归因』的思想同源，但目标是训练信号而非解释报告。同期工作 CAPO 用 LLM 找错步再罚步内 token，T-SPMO 用前缀期望差分估计 token 贡献（纯 outcome、无 PRM），P2T 与它们的区别是单次前向+反向的 O(1) 效率与 PRM 的判据来源。

### 2.3 优势塑形谱系（ProAS 所处脉络）

critic-free 算法里，DAPO 靠动态采样缓解优势消失但信用仍在轨迹级；GiGPO（arXiv:2505.10978）与 MiGPO 通过跨 rollout 匹配锚点状态/里程碑计算步级相对优势，本质是**组间对齐**。ProAS 的定位是**组内塑形**：不跨轨迹比较，而是在单条轨迹内部用结构标注（合理/推进）重分配优势，因此与 GRPO/DAPO/GiGPO 正交、可叠加——实验里 GiGPO+ProAS 正是成绩最好的组合。ProAS 的干预分析（噪声注入、强制抑制后采样续跑）方法学上也呼应了 LLMs Get Lost in Multi-Turn Conversation（ICLR 2026）对上下文污染的研究。

### 2.4 三篇对照定位表

| 维度 | Tev | P2T | ProAS |
|---|---|---|---|
| 切入点 | 环境+奖励 | 奖励重分配 | 优势塑形 |
| 细粒度单位 | 每回合工作区状态 | 每 token | 每步动作 |
| 额外模型开销 | 无（确定性程序打分） | 一次 PRM 前向+反向 | ARG 图匹配（免模型） |
| 是否需要标注 | 需先写环境生成器 | 需现成 PRM | 需子目标标注（可蒸馏/在线演化） |
| 改 RL 目标吗 | 改（加 λΦ(sT)） | 改（优势加 αR） | 改（优势重分配） |
| 适用场景 | 长程、p 极低的任务 | 数学/多模态推理 | 多轮具身/网页智能体 |

### 2.5 GRPO 家族的公共地基

三篇论文的实验底座高度重叠，理解这些公共设施有助于看懂对比数字：

- **GRPO**（DeepSeekMath 提出）：对同一任务采样 G 条 rollout，用组内归一化差分 (R_i−μ)/(σ+ε) 作为每条轨迹的优势，免去 value 网络。它是三篇论文共同的默认宿主——Tev 用其变体 DPPO 训练、P2T 直接在 GRPO 上加 token 项、ProAS 把 GRPO 作为最弱底座演示抬升幅度。
- **DAPO**：在 GRPO 上加非对称裁剪与动态采样，缓解优势消失，但信用仍停留在轨迹级。
- **GiGPO / MiGPO**：把组内归一化下沉到步级——GiGPO 匹配跨轨迹的锚点状态，MiGPO 匹配里程碑。两者是 ProAS 最直接的对照对象，也是『步级信用』路线上与 ProAS 最接近的前序工作。

一条便于记忆的谱系：**GRPO（轨迹级）→ DAPO（轨迹级+动态采样）→ GiGPO/MiGPO（跨轨迹步级）→ ProAS（组内步级塑形）**；而在奖励信号侧：**outcome → PRM（步级）→ PRIME/SPRO（token 级、需训练或自引导）→ P2T（token 级、免训练归因）**；在环境侧：**人工长程评测集 → LLM 正向合成短程语料 → Tev 潜世界反向合成长程语料**。三条谱系各自独立演化，又在 2026 年 10 月同一周交汇于『细粒度信用分配』这个主题。

### 2.6 三个谱系各自的『前一格』与『下一格』

沿时间轴看，三篇论文分别站在三个谱系的最新一格上，而它们此前一格的工作恰好构成了各自的直接对照物：

- Tev 的前一格是 **TMAX / SETA / Endless Terminals** 一类『LLM 正向合成 + 单元测试验证』语料工厂——Tev 保留了它们『规模化生成可验证环境』的目标，但把生成锚点从『任务描述文本』换成了『潜世界程序』，把验证时机从『事后跑测试』提前到『生成时八门禁』。
- P2T 的前一格是 **PRIME 与 SPRO**——两者要么在线训练奖励模型（PRIME）、要么借用策略自身统计量做代理（SPRO），P2T 把这两个成本项都清零，代价仅是一次反向传播。
- ProAS 的前一格是 **GiGPO/MiGPO**——它们靠跨轨迹匹配锚点拿到步级优势，ProAS 反其道在单轨迹内做结构标注塑形，因此能以即插即用方式叠加在 GiGPO 之上（GiGPO+ProAS 是全部配置中的最优点）。

这种『站在前一格肩膀上、只改一个支点』的模式本身就是三篇论文能干净归因自身贡献的原因——每篇的消融设计都恰好能隔离出自己改的那个支点。

## 三、问题定义：三篇论文的共同抽象

三篇论文表面各异，抽象出来是同一个问题：

**给定**：(1) 一条由 N 个决策单元（token / 动作 / 回合）组成的轨迹 τ；(2) 一个只在粗粒度上可靠的评价信号 R（终局 pass/fail、PRM 步级分、或组内归一化的轨迹优势 A）；(3) 一个策略优化器（GRPO/DPPO 等），它需要每个单元的信用值才能计算梯度。

**求**：一套映射 g: 粗粒度信号 → 单元级信用 {r_i} 或 {A_i,t}，满足三个约束——

1. **保真**：信用分配要反映该单元对结果的边际贡献（P2T 直接用『换成 null token 后奖励变化多少』定义之）；
2. **高效**：计算代价可扩展到大规模 RL（P2T 要求从 O(N) 次前向降到 O(1)；Tev 要求打分器是确定性程序而非 LLM 裁判）；
3. **抗 gaming**：分配器本身不能成为被攻击面（Tev 用 14 个 gaming 探针全零 + 角色Independence 三重门强制之；ProAS 用严格图纯洁性剪枝防伪标注）。

这个抽象的精妙之处在于：三篇论文把『信用从哪来』的假设分别押在**世界结构**（Tev：正确中间状态可构造、可验证）、**评价函数的局部可微性**（P2T：PRM 对 token embedding 的梯度含贡献信息）、**任务的结构先验**（ProAS：子目标 DAG 可标注动作性质）三个不同的支点上——而它们殊途同归地都选择了『以进度/过程为锚』的分配原则。

## 四、问题解法

### 4.1 Tev：潜世界反向合成 + 进度势奖励塑形（PPRS）

**类比**：传统出题是先出考卷再写标准答案；Tev 是先写好『平行世界的完整真相』，再把真相渲染成文件、故意弄脏，让考生（agent）修复——因为出题人手里始终握着未被弄脏的世界，任何中间状态的对错都可以当场判定。

六阶段流水线（每步都是确定性种子程序，无 LLM 参与生成）：

1. **世界构造**：按种子和规模层级程序化生成潜世界 W（如零售仓库的 502 名客户、52 种商品、6,210 笔交易），并生成缺陷计划（声明哪些记录将被哪种算子损坏）；
2. **工作流 DAG**：把环境工作流编译为阶段 DAG（如 profile-sources → reconcile-facts / normalize-dimensions → load-facts → aggregate-validate → package-sidecars），关键路径长度即任务视界；
3. **渲染**：把 W 投影为 CSV/JSON/SQLite/safetensors 等多种格式的干净输入，并断言渲染可逆（从文件能精确恢复 W）；
4. **受控损坏**：按缺陷计划注入 schema 漂移、重复缺失记录、乱序分片等可逆损坏——损坏后的输入树 s0 完全决定 W，正确答案可从 agent 所见精确计算；
5. **公开规范**：只给 agent 任务提示词与输入树；
6. **隐藏测试套件**：密封变质换不改分的等价变换、以及必须挂掉的陈旧输出反事实。

奖励侧，每个环境提供**进度契约**：DAG 导出的节点集 V、权重 w_v、先验集 pre(v)。部分打分器 c_v(s) 直接对照潜世界打分，信用按先验门控（节点得分取其与全部先验的最低分），势函数 Φ(s)=Σw_v·c̃_v(s)∈[0,1]。塑形奖励取回合势变化之和（伸缩求和后即终局势）：**R(τ) = 1[pass] + λΦ(sT)**，λ=0.25。由于 Φ≤1，任何通过的 rollout 得 1+λ，严格高于任何未通过的，不会出现『用部分进度换完成』的投机；全灭组的组内 reward 变为 λΦ(sT)，只要各 rollout 走到不同深度就有方差——这就是修复 GRPO 饥饿的机制。资格门方面，全部 14 个 gaming 探针（空输出、最小 schema 合法输出、硬编码、路径穿越等）必须同时被严格验证器和进度打分器判零，参考 solver、替代 solver、验证器、进度打分器四者代码闭包互不相交。

### 4.2 P2T：一阶 Taylor 归因的免训练 token 奖励

**类比**：想知道公司哪个员工对业绩贡献大，不必逐个开除再看业绩（leave-one-out 的 O(N) 次实验），只要看业绩函数对每个岗位的『敏感度梯度』，乘上把该岗位换成空岗的变动量——一次审计得到所有人的边际贡献。

三步机制：

1. **定义**：token y_i 的归因分 I_i = R(E) − R(E_{i←∅})，即把第 i 个 token 的 embedding 换成 null token（选 PRM 词表中的 padding token `<|endoftext|>`）后过程奖励的变化。I_i>0 说明它抬高了奖励；
2. **高效近似**：对 R(E_{i←∅}) 在 e_i 处做一阶 Taylor 展开，得 **I_i ≈ ∇_{e_i}R(E)ᵀ(e_i − e∅)**——所有 token 的梯度一次反向传播同时获得，N 个归因分只需一次前向+一次反向，O(N) 次 PRM 调用降为 O(1)；
3. **重分配**：步内归一化 w_i=|I_i|/Σ_{j∈T_s}|I_j|，token 奖励 **R_i^P2T = R_s + η·w_i·R_s**（η=0.5）。正确步里高影响 token 拿最多奖励，错误步里『罪魁』token 挨最重罚。保留 R_s 作基线是关键设计：归因分有梯度近似噪声，基线限制了噪声扰动。

接入 GRPO 时：Ã_{n,i} = Â_n + α·R^P2T_{n,i}（α=1.0）。两个值得注意的负结果实验：带符号的重分配（正贡献奖、负贡献罚）反而比纯幅值版低 1.2 分（步内正负项不平衡所致）；null token 用 EOS（`<|im_end|>`）最差——它携带『回答结束了』的评判语义，替换等于注入评测信号而非抹除信息。

### 4.3 ProAS：ARG 驱动的非对称优势塑形

**类比**：Uniform 信用像给全队发同样的奖金/罚款——赢了连捣乱的也领奖，输了连背锅的也挨罚。ProAS 先请一位懂流程的裁判（ARG）标记每个人的动作是否合法、是否推进，再分别改工资条。

四步机制：

1. **ARG 构造**：把任务进度抽象为 M 个有序子目标的 DAG——顶点是**置换不变的状态等价类**（WebShop 里先选颜色还是先选尺码都算完成同一子目标），边是合法状态转移。用预收集的成功轨迹初始化，训练中每验证出一条新成功轨迹就严格并入（在线演化）；
2. **两级标注**：合理性 Re = 转移是否是 ARG 中的边；推进性 PA = 是否到达 ARG 中未曾到访的状态（PA=1 ⇒ Re=1，非推进动作包含显式错误与合法但原地打转）；
3. **干预分析定位病灶**（方法学亮点）：噪声注入实验——在相同环境状态的可视历史前插入四步不合理动作，期望成功率 ESR 从 82% 跌到 58%，证明不合理动作污染上下文而非仅仅『无害冗余』；抑制实验——在失败轨迹上强制禁止不同 Future-Drift（FD=该步及下游非推进动作计数）的动作再采样 50 条续跑，FD 为 47/23/11/4 的动作被抑制后恢复 ESR 为 24%/16%/10%/0%，FD 越高越是『祸根』；
4. **塑形公式**：

```
Ã_{i,t} = Re · A_i              若 A_i > 0   （MUI：正轨迹中不合理动作优势归零）
        = D_{i,t}/D̄_i · A_i     若 A_i < 0   （APR：负轨迹中按归一化 FD 分摊惩罚）
        = A_i                    其他
```

MUI 防止污染源搭正优势的便车；APR 把惩罚按 FD 比例向早期关键偏离集中，纠正『后期摆烂动作其实只是早期错误的下游连锁』的误罚。整个框架不含任何可训练参数，即插即用于 GRPO/DAPO/GiGPO。

## 五、评估指标与实验证据

### 5.1 Tev：长程基准上的跨视界泛化

**指标**：S@k（平均评分）/ P@k（全解率），k=1/5，每任务 5 次 rollout。**数据集**：ALE-CM（Agents' Last Exam 的计算与数学域）、TB 3.0/4.0 CM 子集（22/18 题）、TB 2.1（89 题，中程）。

| 对比 | 关键数字 | 含义 |
|---|---|---|
| TEV-27B vs Qwen3.8-27B | ALE-CM P@5 0.17→0.28（+65%）；全解 P@1 0.12→0.16（+33%） | **追平 GPT-6 Astra 与 Claude Opus 5（均 0.28）**，达前沿分 85% |
| TEV-9B vs Qwen3.5-9B | ALE-CM P@5 +83%（0.06→0.11）；TB 2.1 P@1 +28% | 小模型也吃配方 |
| TEV-27B 零样本泛化 | TB 3.0 P@1 0.09→0.14（+56%）；TB 4.0 0.04→0.10（**2.5×**） | 只训 ALE 相关数据，泛化到更长视界，**超 GLM 5.2 与 Gemini 3.7 Flash** |
| TEV-27B 中程 | TB 2.1 P@1 0.794，追平 Claude Opus 4.8（0.789） | 长程训练不伤中程 |
| TEV-320B（GLM-5.3-Flash） | TB 4.0 P@1 0.29→0.37，TB 3.0 security 0.22→0.45 | 开源最强，TB 4.0 仅落后 Opus 5 / Fable 5 / GPT-5.6(sol) |

**实验设计为何有证明力**：(1) 消融表把『数据侧』与『奖励侧』贡献分开——terminal-only 奖励在 27B 上几乎全是零优势组，**训练连一个完整优化器步都完不成**，而 PPRS 能训完，这是密集奖励必要性的最硬证据；(2) 数据消融中，仅把验证器换成 agent 视角的 LLM 写法（Public-view），88% 的组被丢弃、S@1 掉回 0.24（低于基线 0.25），证明『隐藏真值锚定』而非『数据量』是关键；(3) 13-gram/8-gram 零重叠的去污染协议 + CM 子集与全榜 Pearson r=0.96/0.97 的代表性校准，排除了 leakage 与子集偏选的解释；(4) 14 个 gaming 探针全零是『指标好看但没学到真本事』的反作弊保险。另有一处容易被忽略的细节值得单列：Table 1 的难度对比中，TEV-GYM 的 P@1 仅 29%（最难的语料）而 median agent time 12.4 分钟（最长，约为最耗时前序语料的 6 倍）——**它证明了密集奖励的价值恰恰在 p 极低的困难区**：此前语料的 P@1 在 47%~83% 之间，组饥饿问题本不严重，TEV-GYM 把训练语料推到了此前『不可训练』的难度带。

### 5.2 P2T：40 对全胜与训练效率

**指标**：Pass@1（每题采样 8 次、温度 0.6 取平均）。**数据集**：文本侧 AIME24/25、AMC23、MATH-500、MinervaMath、OlympiadBench、GaoKao2023en 七基准；多模态侧 MathVista/MathVerse/MathVision/MMMU/MMStar。

| 对比 | 关键数字 | 含义 |
|---|---|---|
| 40 个模型-基准对 | **无一例外全胜 outcome reward**，平均 +2.5%~+9.4% | 跨家族（Qwen/LLaMA）、跨范式（base/CoT/LongCoT/混合）、跨模态 |
| Qwen2.5-Math-7B | AIME24 28.8→40.3（**+11.5**），七基准均值 48.0→53.8 | 最大单点增益 |
| DeepSeek-R1-Distill-1.5B | GRPO 只 +1.6，P2T 再 +8.4；MinervaMath +14.2 | **outcome RL 停滞处 P2T 增益最大** |

**消融的证据链**：48.0（outcome）→ 50.6（+步级 process）→ 53.8（+步内 token 再分配）——**+3.2 来自步内再分配本身**，排除了『只是多加了个奖励模型』的解释；PRM 质量差（ReasonFlux 53.8 vs Skywork 50.0，差距 3.8 与 P2T 增益同量级）则划定了方法边界：上限受 PRM 判据质量约束。

### 5.3 ProAS：即插即用的普适抬升

**指标**：128 题静态验证集成功率 SR / 任务分 TS，三种子均值±标准差；加速比 Spd@K=基线与 ProAS 达到目标 SR 所需环境步数之比。

| 对比 | 关键数字 | 含义 |
|---|---|---|
| GiGPO+ProAS 7B ALFWorld | **94.3%**，超 MiGPO（91.9%）与 GPT-5.6-Sol（78.9%）达 **15.4 分** | 新 SOTA，小开源模型超专有模型 |
| GRPO+ProAS 1.5B ALFWorld | 70.3→87.0（**+16.7**，三篇中最大单项抬升） | 最弱底座受益最大 |
| WebShop 1.5B | DAPO/GiGPO+ProAS 并列 66.7%，超 MiGPO **13.1 分**；7B GRPO+ProAS 70.8% | 两个环境一致 |
| 收敛加速 | 1.12×~2.44×；7B 平均 ALFWorld 2.2×、WebShop 1.7× | 不只终值高，还更快 |
| PPO 对照 | 1.5B ALFWorld 36.5%±28.7%（巨大方差） | critic 路线在长程上不稳定，反衬 critic-free+塑形路线的合理性 |
| vs SFT | GiGPO+ProAS 超 SFT 12.2 分 | 主动探索优于被动克隆同样标注 |

**消融的证据链**：去掉 MUI 掉 15.4（正轨迹里的搭便车是主要病灶）、去掉 APR 掉 3.7、用朴素掩码替代 APR 的 FD 加权掉 14.1（证明『按责任大小分摊』而非『一刀切屏蔽』才是对的）；ARG 换随机标注灾难性崩溃（-39.3）说明标注质量是生命线，但剪掉 40% 仍超 GRPO 7.0 分、7B 蒸馏 ARG 也能到 83.6%——鲁棒性来自**在线演化**把新成功路径不断并入补洞（Static 消融直接掉 4.2 分佐证）。

### 5.4 跨论文证据互证

三篇论文的实验虽然互不重叠，但有三个论点获得了彼此独立的交叉支持，可信度高于任何单篇自证：

1. **『outcome 奖励在困难区停滞』**：P2T 用 DeepSeek-R1-Distill 上 GRPO 仅 +1.6 证明之；ProAS 用 PPO 的巨大方差（±28.7）与 uniform 信用测量证明之；Tev 用 (1-p)^G 废组率计算与 27B terminal-only 训练失败证明之。三种完全不同的实验范式指向同一诊断。
2. **『细粒度化的增益随任务难度上升』**：P2T 显示竞赛级基准增益是 MATH-500 的 2~7 倍；Tev 显示越难的子集（TB 4.0 P@1 2.5×）相对增益越大；ProAS 显示底座越弱（1.5B vs 7B 的 GRPO）绝对抬升越大。三者共同暗示细粒度信用是『解锁低 p 区域』的钥匙而非锦上添花。
3. **『信号可靠性先于信号密度』**：Tev 的 Public-view 消融（验证器失真则 88% 组废弃）、P2T 的 PRM 消融（差 PRM 吃掉 3.8 分）、ProAS 的 Random 消融（随机标注崩 39.3 分）从三个方向证明：密集但错误的信号比稀疏但正确的信号更有害——这为后来者划出了清晰的工程优先级。

## 六、效果优势的根源解释

### 6.1 因果链分析

**Tev 优于稀疏奖励/LLM 合成语料的根源**：GRPO 的优势 = 组内 reward 的归一化差分。terminal-only 下长程任务的组内 reward 几乎恒为全零向量 → 差分恒零 → 梯度恒零（27B 训练实验直接证实）。PPRS 把 reward 变为 λΦ(sT) 后，**信息流的关键变化**是：即使全组皆败，不同深度的终局势仍产生组内方差，差分恢复非零，且其排序恰是进度排序——把『废组 92%』的批次重新变成有效梯度信号。这一步是『机制上必然』而非『调参调得好』：Figure 4 的实测组中，8 条 rollout 在 terminal-only 下全 0，密集势下变成 0~1 的有序分布。而潜世界锚定解决的是另一个根：正向 LLM 合成中任务/验证器/输入三者独立采样导致互不一致（artifact drift），验证失真 → reward 虚假 → RL 学到错误目标；Tev 让三者都是同一个 W 的函数，验证正确性 by construction。以上各环节均有论文消融支持（Sparse 行、Public-view 行、Prompt-first 行）。

**P2T 优于 outcome/代理 token 奖励的根源**：outcome 奖励对同轨迹所有 token 施加同号梯度，正确步与错误步被同步强化/抑制——DeepSeek-R1-Distill 上 GRPO 仅 +1.6 的停滞正是该机制的外显（论文实验支持）。P2T 的机制变化在**信噪比**：PRM 梯度 ∇_{e_i}R 提供了与最终判据语义对齐的局部敏感度（区别于熵代理的语义无关性），幅值归一化把步级判据 R_s 的『预算』重新分配给边际贡献大的 token。分层消融（50.6→53.8 的步内再分配增量）证明收益确实来自再分配而非 PRM 本身。**标注为推测的部分**：梯度近似对深层的累积误差、以及 PRM 在非训练域的外推失真，论文未做定量刻画，只是用 R_s 基线做了工程兜底。

**ProAS 优于均匀信用的根源**：两条已被干预实验直接验证的机制——(1) 不合理动作会污染自回归上下文、显著降低后续成功率（ESR 82%→58%，同状态对照），因此正轨迹里强化它们是净伤害，MUI 归零消除之；(2) LLM 的自回归性使早期偏离级联放大（FD 越高的动作被抑制后恢复越多），均匀惩罚把连锁后果错算成每个动作的独立过错，APR 按 FD 分摊纠正之。16.7 分的最大抬升出现在底座最弱的 GRPO+1.5B——底座越弱、轨迹里的结构噪声越多，塑形的可修复空间越大（此推断与数据一致，但作者未明说，标注为阅读者推测）。

### 6.3 综合判断与未决问题

**多研究共同支持的机制**：(1) 组相对 RL 在稀疏终局奖励下存在饥饿/均匀信用双病灶（GRPO 原文、DAPO、Tev 的 (1-p)^G 定量、ProAS 的梯度展开皆独立指向）；(2) 以『进度/过程』为锚的信用细化在数学推理、具身、网页、长程终端四类场景一致有效（三篇 + PRIME/GiGPO/MiGPO/SPA-RL 交叉）。**仍属推测的机制**：P2T 梯度近似的误差量化、ProAS 的 FD-责任映射是否在超长视界仍近似线性、Tev 的配方对非终端形态任务（对话、开放创作）的迁移。**适用条件与失效边界**：Tev 依赖可构造潜世界的域（论文自承新工作流需重写生成器）；P2T 上限受 PRM 域内判据质量约束（最差 PRM 掉 3.8 分）；ProAS 依赖子目标可枚举（随机标注即崩溃，Distill 是兜底而非免票）；密集奖励若锚错目标会反噬（Dark Room 反例）。

## 七、必要知识反推

假设让一个零背景的人复现这三条路径，最少需要哪些知识？

**领域知识层**：(1) LLM 智能体的决策过程形式化（状态-动作-历史、多轮 rollout），不理解就无法定义『单元级信用』；(2) GRPO 的组归一化优势与其梯度展开（ProAS 附录 A 逐项求导证明 on-policy 时每步梯度恰为 A_i——这是『均匀困境』的数学定义处）；(3) PBRS 势函数塑形理论（Tev 的 R=1[pass]+λΦ 直接脱胎于此，且要知道它为何刻意偏离）。

**方法论知识层**：(4) 反向任务构造谱系——去噪、受控错误注入、指令回译，Tev 的潜世界优先是它们在『世界级』对象上的推广；(5) 归因分析工具箱——leave-one-out 定义、Taylor 一阶展开、梯度 × 输入差的内积形式（P2T 的全部数学）；(6) 因果干预设计——ProAS 的同状态噪声注入与强制抑制采样是标准的反事实实验，须懂 Wilson 区间与控制变量；(7) PRM 训练与数据构造脉络（Math-Shepherd 的 MC 标注、VisualPRM、ReasonFlux），否则选不对 P2T 的宿主奖励模型。

**工程知识层**：(8) 种子化程序生成与可逆性断言（Tev 的渲染 round-trip 检查、30 秒 CPU 生成一环境的成本工程）；(9) 防 gaming 验证工程（14 探针设计、角色闭包隔离、变质测试）；(10) 大规模 RL 基础设施（DPPO、verl/Verl-Agent 训练框架、B200 集群的四天训练预算）；(11) 去污染协议（n-gram 滑窗、NN Jaccard 校准）与子集代表性校准（Pearson r）。

**知识融合的关键节点**：三篇论文各自都有一个『化学反应』时刻——Tev 把『程序化世界生成』（图形学/数据工程技能）与『RL 塑形理论』（经典 RL 技能）在『每个正确中间状态可渲染』这一点上焊接，才同时得到可验证性与密集奖励；P2T 把可解释性领域的梯度归因（视觉/可解释技能）从『事后解释工具』翻转成『训练信号生成器』；ProAS 把认知任务分析里的子目标分解与 RL 的优势估计在『状态等价类』上对接——三个融合节点共同指向同一洞察：**信用分配器不必是学出来的，可以是构造出来的**。

## 八、论文中可以提取的通用性灵感

**灵感一：反向构造优于正向生成（锚定单一真相源）**。凡『题目+答案+检查器』三元组都要生成的场景，先构造唯一真相再派生三者，一致性 by construction。论文证据：Tev 数据消融中正向合成的两个变体（0.24/0.23）都不及反向构造（0.29）且 88% 组被丢弃。推广：考题/考纲自动生成、测试用例合成、仿真数据工厂、合规规则引擎——任何『生成物之间必须互洽』的场景。

**灵感二：O(N)→O(1) 的归因换轴——用梯度近似反事实**。『逐个替换看变化』的 leave-one-out 直觉人人有，把它 Taylor 展开成『梯度·扰动内积』就变成一次反向传播。论文证据：P2T 全部 40 对实验建立在单次前向+反向之上。推广：特征重要度计算、A/B 测试的预筛、供应链『哪个环节断供影响最大』、代码库 blame 分析。

**灵感三：先做干预实验，再设计机制**。在改算法前，用噪声注入/强制抑制两组反事实实验把『病灶是什么』钉死（上下文污染 -24% ESR；FD-恢复 ESR 单调），机制设计只是干预结论的直译。论文证据：ProAS 的 MUI/APR 与 Insight 1/2 一一对应。推广：组织流程改造前的试点对照、医疗诊断的激发试验、UI 改版的可用性探针。

**灵感四：奖励基线 + 增量修正，防止单点噪声劫持**。P2T 保留 R_s 基线只加 η 加权项、Tev 保留终局 1[pass] 且保证 1+λ 严格占优、ProAS 只塑形不换目标——三者都避免用新信号整体替换旧信号。推广：定价系统的规则基线+模型残差修正、推荐系统的兜底策略+精排增益、任何『新方法未经验证就全量接管』的工程风险场景。

**灵感五：防御性资格门让自动化产物可被信任**。Tev 的 8 道生成时门禁（含 14 探针 gaming 全零、四角色代码闭包互斥）证明：合成数据的可信不是靠事后抽检，而是把验收内建到生成时刻。推广：LLM 辅助代码的 CI 门禁、合成训练数据的自动质检、AI 生成内容的发布前校验。

**灵感六：结构先验可以免训练地放大弱信号**。ARG（人工子目标图）+ 在线演化让 1.5B 模型借结构知识打出 16.7 分抬升，而同等标注直接 SFT 反而更差（79.7 vs 87.0+）。结构先验的最佳用法是当『裁判』而非『教材』。推广：流程知识在 RPA 中的用法、医学指南之于 RL 治疗策略、法律条文之于合同审查 agent。

**灵感七：把『谁该受罚』变成可测量的量，而不是拍脑袋分摊**。ProAS 的 Future-Drift 是一个极简的量——某步之后非推进动作的计数——却比『一刀切屏蔽非推进动作』（消融掉 14.1 分）和均匀惩罚（基线）都好。这说明责任分摊的关键不在『找不找得到责任人』，而在责任大小的度量是否与真实因果负担单调相关（抑制实验直接验证了这种单调性）。推广：事故复盘中的根因权重分配、多人协作项目的绩效归因、故障树分析里节点重要度排序。

**灵感八：在线演化是对先验知识退化的结构免疫**。ProAS 的 ARG 不是一次性资产：每验证一条新成功轨迹就并入图（公式 5），使剪掉 40% 的残缺 ARG 仍能靠演化回血（Incomplete 仍超 GRPO 7 分，关掉演化再掉 5.2 分）。静态知识库会过时，但『验证通过即并入』的机制让参考结构随策略能力共同生长。推广：规则引擎的案例回填、知识图谱的增量校准、任何依赖人工先验且部署后持续运行的系统。

## 加评：三条路径的合流点

把三篇放在一起看，最有意思的不是各自的成绩，而是它们对『信用从哪来』给出了三种**免费午餐之外**的回答：Tev 说信用来自**世界的可构造性**（代价：写生成器的前期工程）；P2T 说信用来自**现成判别器的局部几何**（代价：受制于 PRM 质量）；ProAS 说信用来自**任务的结构先验**（代价：需要子目标标注）。三者都没有引入新的可学习组件——这与『再训一个奖励模型』的老路形成鲜明对照，暗示 2026 年的共识正在转向：**RLVR 的下一个瓶颈不在优化器，而在信用信号的生产工艺**。

组合的想象空间也肉眼可见：Tev 的潜世界天然可以导出 ProAS 式的子目标 DAG（Tev 的 workflow DAG 与 ARG 几乎同构），P2T 的梯度归因理论上可以下钻到 Tev 的部分打分器 c_v。谁先把『环境侧构造 + 奖励侧归因 + 优势侧塑形』叠成一条流水线，谁就可能拿到下一个 Pass@k 的台阶——三篇论文的实验互不重叠（终端长程 / 数学推理 / 具身网页），恰好为这种组合留足了验证空间。

对从业者的务实提示：三篇论文的落地门槛各不相同。ProAS 门槛最低（免训练、即插即用，有开源代码与 verl-agent 集成），适合先在现有 GRPO 管线上验证收益；P2T 需要一个域内可靠的 PRM，数学/多模态推理团队大多已有现成资产，加一次反向传播即可；Tev 是重工程路线（每个域要写生成器并通过八道门禁），但它是三者中唯一能把『训练数据生产』本身变成可扩展资产的——如果团队的瓶颈在『没有可训练的难任务』而非『奖励太粗』，Tev 是唯一解。

最后值得留意一个三篇论文都没写、但数据里已经冒头的信号：三者的增益都来自把同一批 rollout 里的『既有信息』榨得更干（Tev 复用未提交 rollout 的进度、P2T 复用 PRM 梯度、ProAS 复用结构标注），而不是靠更多采样或更大模型。当信用分配的工艺红利吃完之后，下一个问题大概率会回到『优质难任务从哪来』——这恰是 Tev 这类环境合成路线提前押注的方向。
