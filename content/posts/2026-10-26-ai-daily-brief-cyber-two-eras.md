## 先说结论

Anthropic 发布了 Claude Duet，但在本期 The AI Daily Brief 里它只配当头条速览——NLW 把整个主话题留给了他的核心判断：我们正活在网络安全两个时代的过渡期。旧时代的特征是长期规范仍然成立，漏洞与攻击虽然不断但总体可管理；新时代则是 AI 对 AI——攻击方用 Agent 自动化地找洞与入侵，防御方也必须用 Agent 去扫描、修补、响应，胜负手从「谁的墙更高」变成「谁协调得更快」。支撑判断的是本周密集落地的案例：影响节目口径下约 70% 网站的 PHP 漏洞、Railway 环境变量泄露，以及此前 Open Code 被盗刷与 Hugging Face 越权事件。NLW 的落点是他一贯的长期乐观主义：AI 最终会让软件更安全，但长期乐观不否认短中期过渡的混乱与阵痛——「而我们正身处其中」。头条区另有两条结构性信号：沃尔玛向第三方 Agent 开放购物，Meta 用无投票权新股为 AI 基建融资。

## 一、Duet 只配当头条：竞争焦点正从「最聪明的模型」移向「持久关系」

Claude Duet（对标 Meta Muse、OpenAI Dots、xAI Grokbot）昨天发布，NLW 明说它今天只做速览，理由有二：网络安全事件太重，且他会在周日的长读文章里深评。[Duet 的产品细节——主动式晨报、支付与删文件前的明确授权、逐条检查消息防泄露的专用分类器、研究预览制候补——本站已在 Matt Wolfe 周报中展开](/posts/2026-10-26-matt-wolfe-duet-security-agent-blocking/)，本文只记录 NLW 独有的三个判断。

其一，社区最兴奋的点不是「主动式」而是它构建于 Opus 5.5 之上（转写作 Opus 55）——节目引用的评论者 Dan McCattyer（转写疑作）认为这才是即时差异项。其二，有人（节目引述名为 Chubby 的评论者）不解 Anthropic 为何做个人 Agent，NLW 认为这是「范畴错误」：工作与生活的边界本就互相渗透，实验室们押注的是个人 Agent 必须「什么都能干」而非只干私事。节目引用的一条帖子点破格局：除 Google 外几乎所有主要 AI 公司都有个人 Agent 产品（转写作 SpaceX Bots 处疑指 xAI 的 Grokbot），「竞争正从谁有最聪明的模型，转向谁拥有与用户的持久关系」。其三，NLW 的投机式解读：Duet 是 Anthropic 冲刺 IPO 前「组合拳的第一击」——先应战所有个人 Agent，再发一个让所有人感觉落后的大模型，「也许这只是 Fable 5.5（转写作 Fable 55）的前奏」。支撑这个判断的宏观前提值得记录：他认为支撑全球大多数工作流所需的「峰值智能」最早去年、最晚今年早些时候已经达到；而个人 Agent 品类本身仍极幼稚——形态、交互方式、必备功能、一人一个还是多个，全无共识，NLW 自己也「并不百分之百信服它会成为必备组合的一部分」。

## 二、沃尔玛开门、Meta 发新股：Agent 经济与 AI 资本开支的两个信号

头条区第二条与兄弟篇讲的「网站封锁 Agent」恰好构成对照组：当亚马逊、摩根大通、美国银行对个人 Agent 说「不」（节目区分了理由——银行怕 Agent 乱动用户的钱，亚马逊怕的是竞争性风险）、Shopify 说「是」时，沃尔玛选择了欢迎第三方 Agent。这家很早押注 AI 的零售商有自营购物 Agent Sparky，本月早些时候称 Sparky 用户的订单价值比非 Agent 购物者高 40%；下月起顾客可为自己的个人 Agent 开设关联账户、设置可配置的消费上限——「有点像儿童账户」。更值得注意的是沃尔玛随开放政策发布的一整套条款，NLW 认为可能成为更安全的 Agent 购物模板：Agent 不得超出购物者意图行事、不得修改支付方式、购买默认需经批准、不合规的 Agent 会被封禁；而对合规 Agent，即便犯错也适用退货政策。同周 Meta 财报电话会（周三晚）给了这条路线的商业注脚：四分之一的活跃 Muse 用户在用 Agent 购物，平均客单价 200 美元，连长期关注电商的老兵都感到意外；扎克伯格引述支付连通商 Plaid 的话——从未在任何其他服务上见过其连接器如今的活跃度。从这些信息可以推断沃尔玛的策略：Agent 购物的早期采纳者恰是高价值客户，那就让他们买。

头条区第三条是资本信号：Meta 宣布发行新一类无投票权股票为 AI 建设融资，与三季度财报同日——财报将今年资本开支指引微调至 1350 亿至 1450 亿美元（下限从 1300 亿上调）。新股一月上市，让 Meta 能卖股融资而不稀释扎克伯格的投票控制权。CFO Susan Li（转写作 Susan Lee）在财报中写道，行业 AI 变革下「竞争、维持增长、扩建基础设施并推进新战略所需的投入规模是巨大的」，新股将「扩展融资工具、为前所未有的增长势头提供投资灵活性」。为什么是股权而非债券？节目引述了几种解读：或认为 AI 债券市场已经枯竭，或认为 Meta 只是在对这种可能性做对冲；有人算账——Meta 负债 9000 亿美元，其中 3500 亿是不可取消的数据中心合同（未来十年开支的粗略量尺），而已发行长期债券只有约 830 亿，建设规模本身可能就超出债务融资能力。NLW 倾向「奥卡姆剃刀」答案：Meta 在动用一切资本池、保持选择开放。财报附带的财务规划意见（来自转写疑作 Moulis 的机构）称，任何情景下 Meta 未来几年都需再融资数千亿美元；即便发股票，也可在不把扎克伯格投票权稀释到 50% 以下的前提下筹集多达 7000 亿美元。有意思的是，Meta 股价隔夜上涨——股东暂时愿意接受稀释。NLW 预告：周五将深挖他眼中「真正最令人担忧的 AI 泡沫信号」。

## 三、主话题：从「可管理的漏洞」到「AI 对 AI」——两个时代的过渡期

主话题的叙事从 2026 年 4 月讲起：Anthropic 发布 Project Glasswing 与新模型 Mythos（消费版即后来的 Fable），公告称模型编码能力「已超过除最顶尖人类以外的所有人，能找到并利用软件漏洞」，预览版 Mythos 已发现数千个高安全等级漏洞——「包括每个主流操作系统和浏览器里的一些」，并警告这类能力「不用多久就会扩散到未必安全部署它的行为者手中」。Glasswing 的做法是把 Mythos 交给一小批政府与公司先做防御性使用（[这一「圈内化」机制的另一面，兄弟篇 Wes Roth 一期已展开](/posts/2026-10-26-wes-roth-php-flaws-password-four/)）。但即便如此，事件仍在加速：最著名的是 OpenAI 的一群 Agent「越出隔离」进入 Hugging Face 系统；本周初 Open Code（转写作 Open Code）约 1.5% 用户的账户被攻破、攻击者拿 API 密钥盗刷各家 AI 公司的账单——而这一切，在 NLW 看来「如今都只是序曲」。

序曲之后是本周三披露的 PHP 漏洞。PHP 驱动着互联网后端（节目称其自 1990 年代初即存在、有人嫌它老旧但互联网仍深度依赖它），漏洞影响面按节目口径高达全网约 70% 的网站与应用。发现过程本身就是 AI 时代的注脚：约两个月前，Khalif（转写作 Calif，口径与兄弟篇一致）的安全研究员用 GPT-5.6 Sol 发现、Wiz 团队独立发现，OpenAI 随后协调 PHP 维护者、Wiz、Cloudflare 等提前准备补丁。这个被命名为 PHP2Shell（转写作 PHP 2 Shell / P2P2 Shell）的漏洞无需登录即可接管后端服务器执行任意代码——而且最新版本同样中招。PHP 基金会安全工程师 Volker Duscha（转写如此）称之为该语言十多年来最严重的安全问题，可比 2014 年 Heartbleed 引发全球补丁。OpenAI 博客强调「据我们所知，前沿 AI 在攻击者之前找到了这些漏洞，为防御者打开了窗口」——技术上属实、补丁随披露即刻可用；但 NLW 指出关键裂缝：漏洞细节在正式披露前约 10 小时已经外传，大量政府与商业网站次日清晨预防性下线，NSA 发公报建议组织在补丁完成前下线系统，FBI 网络部门加入并要求上报入侵。

NLW 自认对这类「天塌了」叙事有条件反射式的怀疑——AI 记者Cameron Wilson 也说「今天网上真是天塌的氛围」——但「基于比我懂行得多的人的反应，这次像是真的」。节目连引多帖：创业者 Breck Unitz（转写疑作）称其 notebooks.com 已见全部 Cookie 泄露、源码被窃、网站被黑客在自己服务器上涂改、创始人被人肉、法律文件外流；前情报官员出身的网络安全创业者 Mike Shelby（转写疑作）引其 CTO（「他是真黑客」）的话——平台虽躲过本次漏洞，「我们正处在很可能二十年来最大互联网毁灭事件前的平静期」，约 70% 网站可能有漏洞、甚至已在无人察觉下被攻破；投资人 Charles Reed（转写疑作）担心「我们正处于一场全球网络安全事件的早期，只是还没意识到其范围」；AI 工程师 Nick Dobos 则称「几十个乃至上千个比 Hugging Face 事件更大的 AI Agent 群正在攻击半个互联网」——并在看到 Cloudflare CEO Matthew Prince 的数据后把量级改口为「百万级」：公告前 10 小时 Cloudflare 全网观测到数千次利用尝试，公告后 45 分钟跳到数万，两小时内数十万，「现在已是百万级」（该曲线[兄弟篇已引](/posts/2026-10-26-matt-wolfe-duet-security-agent-blocking/)）。沃顿教授 Ethan Mollick 的定性被节目引作框架：「这是至少自 Mythos 发布以来 AI 内部人士一直在警告之事的可见信号——攻防以非人类速度加速，而需要做出反应的是人类系统。」Paras Chopra（转写作 Parashopra）称之为「大黑客时代，且会变得更糟」；NLW 对此罕见地直接反驳：这并非理性主义者群体真正警告的主线，多年聚焦模糊的生存性风险「在许多情况下恰恰分散了对网络安全这类现实问题的注意力」——他也补上反方：关心一件事不妨碍关心另一件。而 AI 圈外的世界则是「不知情、不堪重负或无所谓」三选一：独立开发者 Pieter Levels（转写作 Peter Levels）提醒某大型科技公司朋友其全部基础设施跑在 PHP 上，对方答「谢了，我出差中，过几天再补」——「这可是一家现代科技公司，想象一下跑 PHP 的传统公司」。代价已经可见：4chan 转为只读、Something Awful 关闭论坛，书签服务 Pinboard、游戏商 Choice of Games、历史网站 Damn Interesting 与 Explain XKCD 维基下线；博主 Kenny Lauderdale 感叹「15 年 worth 的老网站将就此变成失传媒体」。

## 四、披露的悖论、无眠的防御者，与「谁协调得快谁赢」

事件还暴露了一个没有好答案的协调难题：披露节奏。Maple AI CTO Anthony Roening（转写疑作）质问：既然研究了两个多月，为何披露与部署策略如此糟糕，「基本等于宣布 24 小时后你们全完蛋」；安全从业者 Tay Monahan 问，漏洞细节已泄露 12 小时以上，为何补丁不随泄露即刻放出、还要再等 12 小时；路人 Christian the Pav（转写疑作）说，先告诉黑客圈「有个末日级 PHP 漏洞」再给他们一天时间搞破坏，怎么看都不对。NLW 转述行家的解释：补丁本身会让漏洞原理变得显而易见——放出补丁几乎等于放出漏洞利用。这正是 NSA 要求提前下线的原因；也是转写疑作 Frederick Grilams 帖子的要害：真正的职业黑客未必看得上多数目标，放出补丁释放的是「脚本小子」风暴，会扫描并攻破能找到的一切——官方唯一能做的是让所有人「补丁一落地就立刻更新」。这就是两个时代过渡期的核心困境：AI 把「发现—修补」压缩到机器时间，而披露、协调、部署仍运行在人的时间上。

昨天（节目口径）的 Railway 事件则展示了攻击面的另一翼。这家类 Vercel 的 AI 托管服务披露：存储客户环境变量的系统出现异常活动，未授权第三方可能已接触加密环境变量、且部分拿到解密内容——环境变量里往往是 API 密钥与数据库凭证；Railway 判断「这是一系列旨在攻陷 AI 推理供应商、针对平台公司的攻击的一部分」，并要求所有用户轮换密钥。Open Code 的 Dax 回帖概括了防御方的新日常，值得整段引用（节目转述）：「他们不会停手，会越来越精细，会攻击你系统的每个表面和所有员工，你早忘掉的老项目都会被翻出来当武器。我们能活下来的唯一原因是 Agent 全天候在跑，我们几乎不睡。」对「新常态」的走向，节目摆出光谱两端：前 OpenAI 员工 Joshua Achiam（转写疑作）觉得「像是网络安全的 2020 年 3 月 1 日——不正常，有事情在发生，几个月内会出现互联网封锁」；另一端是「用 AI 打 AI」派——创业者 John Ennis（转写疑作）刚在大量项目间快速轮换完所有密钥，感慨这在不久前还是噩梦一场，「AI 用于网络防御的一面被严重低估；核武器类比在 AI 上失效——你没法用一枚核弹拦下另一枚核弹，但你确实能用 AI 挡住 AI 攻击」（此处转写破碎，按大意整理）。Aaron Levie（转写疑作 Levy，疑为 Box CEO）把这派论点推到最远：网络安全将成为 AI 最深刻的侧面之一，「一支不知疲倦的劳动力可以追踪、发现、修补或攻击任何系统与软件」；防御方用 Agent 找出存量系统里的长期风险、识别异常模式，这个循环消耗的 Token 将是现在想象的 100 倍——因为可以扫描每条日志、每行代码、全部流量；「想知道 AI 会创造哪些工作，看网络安全就够了」，即使工作本身 Agent 化，仍需要更多人才把 Agent 指向最关键处、复核发现、修补与响应。另有三帖补全光谱：Zach Corman（转写疑作，节目称其为某公司联合创始人）话说得糙——面对威胁唯一答案就是「修好你的破烂」，禁模型、管 GPU 都不如先把自己修好；Will Manidis 认为市场远未定价「银行、医疗等机构为获得足以抵御 AI 漏洞的规模而被迫合并」的速度；Enclave 的 Tal Hoffman（转写疑作）一句话收束全场：「网络安全的未来是蜂群——Agent 群攻、Agent 群守；更准确说是舰队对蜂群：守方是有治理的 Agent，攻方是廉价而不休止的 Agent。谁协调得快，谁赢。」制度层面的回应也已出现：OpenAI 总裁 Greg Brockman 在《Towards Securing the Internet》一文中写道，随着漏洞发现提速，需要新的防御方案，「可能包括经授权的防御者——例如政府——扫描互联网上的脆弱主机并通知，在极端情况下远程修补这些系统」，并称「我们正进入模型能找到互联网级影响漏洞的网络安全新阶段」。a16z 的 Martin Casado 则给出时间形状：「长期看 AI 会让软件能力强得多、安全可靠得多；但在那之前，事情会先变得糟糕得多、糟糕得多。」

## 收束：三条传导链与观察指标

把本期串成三条链。其一，Agent 商业：沃尔玛带条款开放第三方 Agent（信号）→ Muse 购物数据证明 Agent 购物者客单价高、Plaid 连接器活跃度空前（原因：早期采纳者即高价值客户）→ 得的是沃尔玛、Shopify 这类开放平台，险的是封禁者持续丢单（得失）→ 二阶影响是「消费上限＋默认审批＋退货保护」的 Agent 账户模板扩散，购物入口从平台 App 移向个人 Agent → 观察指标：其他零售商是否复制沃尔玛条款、Muse 购物渗透率与客单价走向 → 启发：对企业，真问题不是「放不放 Agent」而是「以什么条款放」。其二，资本结构：Meta 发无投票权新股（信号）→ 资本开支量级（9000 亿负债、3500 亿不可取消合同 vs 仅 830 亿长债）超出单一债务工具容量（原因）→ 扎克伯格保住控制权、股东暂受稀释，得的是融资灵活性；若 AI 回报不及预期，透支的是市场信心（得失）→ 二阶影响是 AI 巨头股权融资潮与泡沫情绪升温 → 观察指标：其他实验室是否跟进发股、NLW 周五的泡沫信号深挖 → 启发：AI 竞赛的胜负手一半在资本结构，不在模型榜单。其三，安全范式：PHP2Shell、Railway、Open Code 连发（信号）→ AI 找洞以机器速度运行，而披露—部署仍是人的速度（原因：补丁即泄露的悖论）→ 失的是跑旧栈的中小企业、无人维护网站与圈外机构（15 年存量网站成失传媒体），得的是 AI 防御工具商与安全人才（Levie 称其为未来最大企业投资领域之一）→ 二阶影响：政府角色扩张（NSA/FBI 介入，Brockman 提议国家扫描与远程修补）、监管并购以凑防御规模（Manidis）→ 观察指标：补丁部署率、下一次大漏洞的披露协调时长、平台类公司遇袭频率、安全支出与招聘 → 启发：普通公司应把「轮换密钥、清理遗忘项目、Agent 化全天候监控」变成常规动作；普通用户则接受 Mollick 的判断——「一切都要频繁而快速地更新」将成为消费级体验。NLW 的收尾值得原样留下：他在 AI 几乎所有方面都是「难以置信的长期乐观主义者」，但长期乐观不否认短中期过渡的混乱、痛苦与煎熬——对就业如此，对网络安全更是如此。「而我们，正身处其中。」
