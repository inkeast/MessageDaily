### 一、 今日核心洞察与重点摘要

- **LLM 安全进入"自主武器化"实证阶段**：清华团队证明一个商用廉价 LLM（DeepSeek API，单次成本 $1.74）能全自主完成"定位 + 设计 + 植入"的选择性权重后门闭环（ASR 99.21%、未见域迁移 97.55%），单神经元手术仅改动 6,144 个参数（0.0005%），常规榜单与困惑度筛查全部失效——模型供应链安全从此需要假设"攻击者只拥有一张 API key"。
- **评测基础设施进入权限分离时代**：SplitBench 首次把"跑测试"与"判结果"分离，与原生 grader 判决一致率 98.7%，360 次完全知识对抗尝试 0 次绕过（原生 grader 中招 230/429）；同日 Benchmarks' Last Exam 审计 8 大基准发现 71.7% 的缺陷在惩罚合规解而非放水——"基准分数"正在从被动数字变成需要安全工程守护的资产。
- **推理加速的信息论新矿脉**：投机解码中"验证用随机数可在起草前采样并与验证方同步"这一被忽视的信息源被首次利用（DICE，免训练、无损，吞吐 +4.3%-24.6%）；MemOnce 用"只缓存一次 + 只检索一次 + 按需解码"让原生记忆模型首次超越全上下文基线（+5.77%，缓存降 1313 倍）。
- **具身与多模态两条线并进**：Duopra 把全双工语音从"会对话"推向"会干活"（Pass@1 4.7%→44.7%）；NoPeWorld 读 DiT 冻结隐状态做碰撞预测，世界模型违反率 74%→16%；StereoVLM 证明视差监督比深度监督 OOD 泛化 +29 个百分点。

**今日企业+高校研究合作趋势**：24 篇深读论文中 11 篇为企业+高校合作（46%）。模式上延续"企业出生产场景与算力、高校出方法学"的主流范式，并出现三个值得注意的深化：其一，**安全与评测类合作占比显著上升**——博世北美研究院与 CMU/UIUC 共同完成机器人动作级评测（AgentRoboCritic），Caliptra/Google 与威廉玛丽共建根信任固件漏洞管线（Mjolnir），产业界开始为"评测与安全基础设施"投入一线研究力量；其二，**国产算力栈进入学术主战场**——中国电信 Xingchen AGI Lab 联合华为把 cmHC 架构改进验证到 300B-MoE 并在昇腾 910C 上做融合算子（时延 -44.8%），产学研闭环覆盖"算法-模型-芯片"全栈；其三，**语音与空间智能的企业数据壁垒显性化**——腾讯为上交 Duopra 提供全双工模型与真实评测场景，字节 PICO 为清华 ReSpaceBench 提供头显记录的真实住宅数据，这类"只有企业拿得到的数据"正成为合作的核心筹码。

##### 论文 1：**[Non-penetrating World Models / 非穿透世界模型]**

- **核心亮点**：
  - **任务定义**：防止交互式视频世界模型"穿墙"（物体穿透）——首个系统研究该问题的工作，属于视频世界模型的物理合理性领域。
  - **方法核心**：NoPeWorld——冻结视频 DiT 的中间层隐状态已编码即将发生的接触信息，在其上训练 <2M 参数的轻量交叉注意力预测头，对 34 个离散候选动作逐一预测安全性/扫掠间隙/意图分数，不安全动作被替换为最保意图的安全动作（collide-and-slide 投影）。
  - **评估指标**：自建 NoPeBench。Task 2 六模型平均违反率 74%→16%；LingBot-World 2.0 违反率 89%→4%（SIS 从 5 升至 56）；Task 3 零样本迁移静态违反 67%→19%；推断开销 Pred 模式每决策仅 0.09s（+1% 路线时延）。
  - **为何优于 baseline**：方法差异（读 DiT 内部状态而非解码像素+外部深度估计）→ 机制变化（探针实验证明 DiT 中间层 regret 0.055 显著优于 VAE latent 0.110/像素层 0.126，接触信息只存在于去噪中间块；且在 chunk 生成前即可替换动作，保留 wall-slide 意图）→ 指标提升（违反率降 58 个百分点并零样本迁移至开放域/第三人称/动态障碍）。
- **团队背景**：香港理工大学 B Learning & Generation Lab，纯高校。

##### 论文 2：**[Learning Video Foresight Reasoning from Unlabeled Videos via On-Policy Self-Distillation / 基于在线策略自蒸馏的无标注视频前瞻推理学习]**

- **核心亮点**：
  - **任务定义**：让 VLM 从当前视频预测未来事件/下一步动作（视频前瞻推理），无需人工标注或外部大模型监督，属于 VLM 后训练领域。
  - **方法核心**：Future-OPSD——首个视频前瞻在线策略自蒸馏框架：学生只见过去片段生成推理-回答，冻结教师（同模型初始副本）配对真实未来片段为学生响应逐 token 打分；定义 foresight score（InfoNCE 极限形式）并推导 KL 正则下界，token 优势 = λ×真/假未来对比项 + (1-λ)×蒸馏项。
  - **评估指标**：TwiFF-Bench（Qwen3.6-27B 评分）：Qwen3-VL-8B +14.2（53.6→67.8）；SEED-Bench-R1 封闭规划 Qwen3.5-9B +15.9（L3 级）；通用视频理解（TempCompass 等 4 项）保持 +0.2~+1.5。
  - **为何优于 baseline**：方法差异（未来片段作为特权证据打分 + 无关视频未来做对比参照）→ 机制变化（token 级案例显示上下文 token 优势被降权、决策相关内容 token 被放大，监督聚焦最有价值的未来信息而非表面续写）→ 指标提升（双任务两位数增益且不损害通用理解，50K 数据时超越 SFT 与 GRPO）。
- **团队背景**：布法罗大学、石溪大学、约翰霍普金斯、杜克、马里兰大学，美国五校纯学术合作。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2611.26954)；[💻 项目页](https://jingchensun.github.io/future-opsd/)

##### 论文 3：**[MemOnce: A Scalable Memory Architecture for Large Language Models / MemOnce：可扩展的 LLM 记忆架构]**

- **核心亮点**：
  - **任务定义**：为持续交互/长程任务的 LLM 构建可复用、有界的记忆状态，实现准确召回 × 线性时间 × 有界 GPU 缓存三者兼得，属于 LLM 基础架构领域。
  - **方法核心**：MemOnce——只缓存每段最后 1/8 的最终层隐状态作为持久记忆库（深度×时间双压缩）；每查询仅检索一次（终 token 描述子余弦 Top-K=64），稀疏索引跨所有注意力层与解码步复用；检索到的记忆经轻量层专属 MLP 按需解码回各层 KV cache。
  - **评估指标**：5 项记忆基准（4K-1M）：Qwen3.5-4B 后训练 MemOnce 平均 60.07%（超全上下文基线 +5.77%，**首个超越全上下文的原生记忆模型**）；1M 上下文状态缓存降 1313×、预填充延迟降 6.9×、吞吐 3.5×；对比 M+ +18.68%、Metis +32.27%；通用能力 MMLU/GSM8K/GPQA 平均 65.98 vs 基线 65.88（无灾难遗忘）。
  - **为何优于 baseline**：方法差异（最终层状态 + 单次索引 + 按需 KV 解码，而非固定状态压缩或逐层检索）→ 机制变化（可扩展记忆库突破固定状态容量瓶颈；解码回 KV 保留注意力全部表达力；查询条件稀疏检索过滤无关历史，缓解超长序列注意力稀释）→ 指标提升（记忆分首次超越全上下文基线，检索时延比 M+ 快 12 倍）。
- **团队背景**：南京大学、中国科学技术大学，国内纯高校合作。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2611.27973)；[💻 项目页](https://clare-nie.github.io/MemOnce)

##### 论文 4：**[Duopra: From Full-Duplex Conversation to Full-Duplex Agency / Duopra：从全双工会话到全双工智能体]**

- **核心亮点**：
  - **任务定义**：让全双工语音交互模型在掌握对话能力（接管/停顿/打断）之外获得任务能力（及时工具调用 + 随用户纠正修订参数），即"全双工 agency"，属于全双工语音智能体领域。
  - **方法核心**：Duopra（基于 RV-Audio 9B）——把后端代理表示为一个自包含的工具 query(task)，直呼工具与委派共享同一动作接口；三阶段训练：协议 SFT → 全双工 RL（Dr.GRPO，奖励及时完整执行）→ 仅投影器修复（thinker 更新后只训 3.7M 参数投影器对齐 talker 条件方向）。
  - **评估指标**：FDB v3（100 条真实含糊语音）：同一 Qwen3-8B 后端下 Pass@1 从 RV-Audio+Harness 的 4.7% 升至 44.7%（+40.0）；DeepSeek 后端 49.3%；多调用任务从 RL1 的 0% 提升到 24.1-31.3%；FDB v1.0 三项接管率全部超过基础模型（Turn 59.1→75.6、Intr. 79.5→91.3）。
  - **为何优于 baseline**：方法差异（统一动作接口 + 执行结果驱动的全双工 RL）→ 机制变化（RL 先把发起率从 no-call 89.7% 压到 18.7%——基线失败主因是发起不足构成 Pass@1 上限；再把发起转化为完整执行；投影器修复把中文 CER 减半）→ 指标提升（Pass@1 十倍级提升且对话接管率不降反升，与 Gemini Live 2.5 相当）。
- **团队背景**：上海交通大学、腾讯、上海大学、布里斯托大学——企业+高校合作（第一作者在腾讯实习完成，腾讯提供全双工基座模型与真实场景）。

- **核心亮点**：
  - **任务定义**：评测具身模型跨重访的持久空间记忆（识别重访房间、区分同类房间、跟踪状态变化），属于空间记忆 benchmark 领域。

##### 论文 6：**[StereoVLM: Binocular Vision-Language Models for Metric 3D Spatial Reasoning / 双目视觉语言模型与度量 3D 空间推理]**

- **核心亮点**：
  - **任务定义**：让 VLM 从标定双目观测中学习可迁移的度量 3D 空间推理（首个几何感知双目 VLM），属于具身空间智能领域。
  - **方法核心**：StereoVLM（基于 Qwen3-VL 2B/8B）——层级几何监督链：像素级跨视对应→视差→标定条件度量深度（Z=f_x·B/d）→语言指称物体的对应/视差/深度→带朝向 3D 框 grounding；训练混合 15% 点级 + 10% 物体级立体指令 + 75% 通用指令。
  - **评估指标**：自建 Stereo3D-Bench（2,017 几何对 + 1,556 语义对 + 94,546 QA）。StereoVLM-8B 深度 δ1 95.17%、点级对应 MAE 3.80px、物体级 66.98%；关键发现：视差监督 OOD δ1 74.92% vs 双目深度监督 45.89%（+29.03）；GPT-6 Astra 同输入下对应 MAE 9.27→3.80px、物体级 +19.37。
  - **为何优于 baseline**：方法差异（层级监督显式连接对应-视差-深度-语义 vs 通用多图 VLM 把双目当两张普通图）→ 机制变化（视差作为图像空间量与场景尺度解耦故泛化更好；干预实验证明真正依赖跨视几何——复制右图时物体级从 64.43% 崩至 8.18%，排除"多 token/语义先验"解释）→ 指标提升（全部指标 SOTA 且 2B 版即全面超 GPT-6 Astra）。

##### 论文 7：**[AgentRoboCritic: Understanding the Capability of Frontier Agents on Direct Robot Control / 前沿智能体直接机器人控制的能力画像]**

- **核心亮点**：
  - **任务定义**：对前沿多模态语言智能体直接输出低层数值动作控制机器人的能力做动作级（而非 episode 级）分析与失败归因，属于机器人学习评测领域。
  - **方法核心**：意图锚定动作评价框架——策略智能体在每个动作的同一 tool call 中必须陈述局部意图 g_t（缺失即被 harness 拒绝重发），评论模型依据全局目标+局部意图+多视角观察输出结果 + 七类失败模式 + 证据注释；用 GPT-6 Astra 标注 12 个操作基准共 12,844 动作，并微调开源 Muse-Glimmer-30B 评论器。
  - **评估指标**：400 动作人工标注集：GPT-6 Astra 评论器 Outcome 79.25%/失败模式 80.68% 均第一；微调 Muse-Glimmer-30B 失败模式准确率 32.58%→74.24%（+41.66），成本仅 $0.79（比 GPT-6 Astra 低 30 倍以上）；去掉局部意图后 GPT-6 Astra 崩至 25.25%；零样本策略 RoboTwin 2.0 成功率 91% vs π0.5 的 0%。

- **团队背景**：卡内基梅隆大学、UIUC、博世北美研究院——企业+高校合作（CMU 主导，博世提供工业场景）。

##### 论文 8：**[AeroRSI: Recursive Self-Improvement for Aerial Vision-Language Navigation / 无人机视觉语言导航的递归自我改进]**

- **核心亮点**：
  - **任务定义**：无人机视觉-语言导航（aerial VLN）中让策略从自身失败中递归自我改进（无需人工标注），属于具身导航后训练领域。
  - **方法核心**：AERORSI 三模块循环——自适应失败锚定（失败前多尺度探针）→ 续飞验证修复（候选动作从恢复态执行后由**当前策略**继续飞行打分，即用策略自身行为估计 Q^π）→ 保持式修复学习（只模仿验证过的修复 + 保留无需修复状态的当前输出 + 跨轮 replay）。

- **核心亮点**：跨 8 个前沿基准 749 个任务的统一审计——闭式问答任务 Accepted 率 92.5% vs 文档 rubric 30.0% vs 智能体执行 28.9%（P=1.3e-58）；**71.7% 的缺陷在惩罚合规解而非放行捷径**，纠正"缺陷=放水"的默认假设；共享容器 C4 泄漏率 14.7% vs fresh git-diff 2.7%（5.5 倍降）。**优势根源**：评分架构决定失败通道——rubric 失败于僵化清单 vs 未声明期望，执行式 harness 因程序化断言难以验证可变状态且易泄漏特权上下文；多数缺陷压低分数意味着未验证多步套件的原始天花板低估了前沿真实能力。
- **团队背景**：Benchmarks' Last Exam Lab（独立实验室）。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2611.27622)；[💻 代码仓库](https://github.com/ZekkiCat/Benchmarks-Last-Exam)

##### 论文 21：**[Git History Is a Pangenome / Git 历史是一个泛基因组]**

- **核心亮点**：代码训练数据测量——首个对"仓库全历史作为语料"的系统量化：典型仓库历史 = 当前代码的 19 倍（成熟仓库 89 倍），精确去重零削减、MinHash 后仍 2 倍；commit 仅 8.7% 字节为新增（十分之九 token 早已存在）。**评估指标**：去重脚本默认只对 40-52% 文件保留当前版本（keep-newest 升至 94% 代价仅 +0.1-0.2 倍）；SWE-bench 修复中位数存在于 18 个后续版本，逐字节数去重只能删 1 个。**优势根源**：多数 commit 只改几行、文件以近同质变体集合存在——哈希级去重看不见任何重复；keep 规则与时间无关导致一半文件留旧版；含修复的组留下的幸存者携带基准答案，基准过滤必须对每个版本单独做子串过滤。
- **团队背景**：GitLab Inc.（工业界单作者，预注册研究）。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2611.27154)；[💻 复制包](https://osf.io/5nwgv/)

##### 论文 22：**[Cannot Wait to Verify / 验证器等不及了：并行起草消除验证器闲置]**

- **核心亮点**：投机解码加速——ALD 自适应层并行起草：用当前已提交隐状态作共享代理输入并行求值未来层，首个余弦相似度低于 0.95 的层前接受并刷新。**评估指标**：起草阶段最高 1.65 倍加速；Math 端到端 2.19×→3.75×；GPU 利用率 batch1 43.5%→57.4%；额外峰值显存仅 2.7MB（0.03%）。**优势根源**：draft 模型相邻层隐状态余弦相似度普遍很高（层间冗余），在线相似度检查替代固定近似使接受率接近标准 SD；定理 1 给出偏差 ≤ 局部近似误差的 Lipschitz 加权和。
- **团队背景**：IIT Bombay + Singapore-MIT Alliance。
- **相关链接**：[📄 点击阅读论文原文](https://arxiv.org/abs/2611.27477)
