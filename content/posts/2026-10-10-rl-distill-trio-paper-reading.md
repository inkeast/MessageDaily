这三篇论文放在一起读有一种奇妙的互补感：MiMo-V2.6 是工业界的全栈答卷，LoopOPD 是架构学派的巧思，STI-OPD 是训练动力学的精修。它们共同指向 2026 年后训练领域的核心焦虑——**当奖励信号和教师信号成为瓶颈时，如何系统地生产出更细、更可信、更便宜的监督信号**。

## 一、论文背景

要理解这三篇论文，需要先建立几个基础概念。

**强化学习（RL）与可验证奖励（RLVR）是什么。** 大模型的后训练（post-training，即预训练之后的进一步训练）中，强化学习是让模型在环境中试错、依据奖励信号改进策略的方法。当任务答案可以被程序自动判定对错（如数学题答案、代码测试通过与否）时，奖励就是"可验证"的，这条路线称为 RLVR。类比：学生做题，机器自动判卷，判卷结果是唯一的学习信号。

**on-policy 蒸馏（OPD）是什么。** 蒸馏指用一个更强的教师模型指导学生模型。传统蒸馏在固定数据集上做，但学生将来遇到的上下文与固定数据分布不一致（train-infer 不匹配）。OPD 的做法是：让学生自己生成轨迹（rollout），教师在学生生成的每个 token 上给出概率分布，学生用反向 KL 散度向教师的分布靠拢。类比：不再是抄老师的旧笔记，而是学生自己做题、老师在旁边每一步都给意见——意见是"逐 token 的密集指导"，比 RL 的"整题判分"信号密得多。OPD 的名字里 "on-policy" 就是指训练数据来自学生自己的当前策略。

**三篇论文各自面对的瓶颈：**

1. **MiMo-V2.6 面对的是规模化瓶颈。** RL 的效果一度被认为" scaling 不动"——简单堆 GPU 收益递减。Xiaomi 团队的判断是：瓶颈不在算力本身，而在三个被忽视的维度：环境多样性不够（模型学会的是刷特定 harness 而非真本事）、奖励信号分辨率不够（二元测试奖励让所有通过解等价，模型学会走捷径如输出超长、防御性补丁）、以及 MoE 大模型训练稳定性（router 漂移导致专家负载崩塌）。

2. **LoopOPD 面对的是循环模型的监督真空。** 循环语言模型（LoopLM，如 Ouro 系列）让同一组 Transformer 参数在生成每个 token 前反复计算多次（循环 d=1..L），用"计算深度"替代"参数量"换取推理能力。问题是后训练时：GRPO 只把奖励记在最后一个循环（terminal loop）上，中间循环的潜在计算没有直接监督；RLTT 把奖励摊到所有循环但需要逐循环存 log-prob，显存随循环数线性膨胀，长轨迹训练做不了；标准 OPD 需要更强的同族教师——Ouro-2.6B 已经是自家最强，没有教师可用。

3. **STI-OPD 面对的是轨迹漂移。** 把 OPD 搬到多轮智能体任务（如操作虚拟家居环境 ALFWorld）上，学生第 1 轮走错一步，后续所有观测都变了——因为动作塑造后续观察。于是轨迹漂出教师的"可靠区"，教师的 token 级指导在错误上下文上可能变成错误指导。类比：学徒第一个零件装错了位置，师傅后续的指导都是针对"正确的半成品"说的，对当前的歪架子反而有害。

## 二、论文定位和关联工作

### 谱系一：agentic RL 的规模化（MiMo-V2.6 的位置）

- **前序工作**：Kimi k1.5 / DAPO 等确立了大规模 RLVR 的工程范式（partial rollout、动态采样）；DeepSeek 系列确立了 GRPO 类算法；MiMo-V2-Flash 是本团队的直接前作，贡献了 MOPD（多教师蒸馏）与数据调度器。GRS/GAR 的 GAR 部分有独立论文（Dong et al., 2026）。
- **同期对标**：Claude Opus 5、GPT-5.6 Sol 等前沿闭源模型是其评测对象。
- **本论文突破**：第一个把"评分器算力"（grader compute）当作与训练算力、环境多样性并列的第三扩展轴的公开全栈报告；开源了从 9B 蒸馏模型到环境、RL 框架、mini-harness 的完整复现套件。

### 谱系二：循环模型的中间层监督（LoopOPD 的位置）

- **Universal Transformer（2019）** 首创参数共享的循环深度；**Geiping et al.（2025）** 与 **Saunshi et al.（2025）** 证明循环深度是测试时算力的新扩展轴；**Ouro（Zhu et al., 2025）** 把它做成预训练模型家族——LoopOPD 的实验基座。
- **RLTT（Williams et al., 2026）**：把奖励信用扩展到所有循环——LoopOPD 指出其显存线性膨胀缺陷。
- **OPSD（Zhao et al., 2026）**：用特权信息构造同模型教师，但引入师生上下文失配（Kaur et al., 2026 指出）。
- **本论文突破**：教师优势来自"更多循环计算"而非参数或特权信息，师生同参数同上下文，天然规避失配；D-LoopOPD 让教师随学生更新而"水涨船高"，形成闭环递归自改进，并给出双深度同时局部下降的理论充分条件。

### 谱系三：多轮蒸馏的漂移控制（STI-OPD 的位置）

- **损失过滤派**：SCOPE、SAGE-OPD 用 KL 或置信度给损失加权/遮蔽——不纠正错误动作本身。
- **轨迹构造派**：TCOD 渐进放开轨迹深度；Guided-OPD 用课程混合师生回合；TurnOPD 分配回合深度与权重；ReOPD 用教师轨迹做前缀回放。
- **教师干预派（最近邻）**：Relay-OPD 检测失败前缀后交给教师接力；FutureBridge-OPD 用未来轨迹验证教师"桥段"是否有效；DASH-OPD 用滞后阈值切换执行者；MOTAB、SMRC-SD 沿交互式模仿学习（DAgger、scheduled sampling）思路做回溯。
- **本论文突破**：识别出所有干预式方法的共同理论缺口——干预 token 采自教师分布，却用假设学生采样的 reverse-KL 积分去监督，期望值对不上。STI-OPD 用重要性加权恢复正确目标，同时用随机概率干预替代手调阈值。

| 维度 | 之前的路线 | 本三篇的突破 |
|---|---|---|
| RL 奖励信号 | 二元测试奖励，所有通过解等权 | GRS/GAR 组内质量排序 → 细粒度优势（MiMo） |
| 循环模型教师 | 依赖外部更强教师或特权信息 | 深层循环=算力特权教师（LoopOPD） |
| 干预式蒸馏 | 阈值/课表控制 + 目标失配 | 概率干预 + 重要性加权保目标（STI-OPD） |
| 共同点 | — | 都在回答「监督信号的生产与保真」 |

## 三、问题定义

三篇论文的具体场景不同，但抽象出的是同一个本质问题的三个侧面：**如何在不引入外部不可得资源的前提下，制造分辨率更高、覆盖更广、且始终保持正确目标的监督信号？**

| | MiMo-V2.6 | LoopOPD | STI-OPD |
|---|---|---|---|
| 具体问题 | 大规模 RL 中二元奖励无法区分通过解的质量 | LoopLM 中间循环无监督、无同族教师 | 多轮 OPD 中轨迹漂移使教师指导失效 |
| 抽象问题 | 给定通过/失败信号，如何把组内质量差异转化为可用的学习信号 | 给定同一模型的不同算力档位，能否用高档位监督低档位 | 给定会失真的教师信号，何时干预、如何不失真地学习 |
| 形式化 | 组内通过解集合 P，求质量因子 f_i 使正优势从低质流向高质：λ=ΣA_j，A'_i=λf_iA_i | 学生 π(ℓ)、教师 π(L) 共享参数 θ；最小化 D_KL(P(ℓ)‖P(L))，求同时下降 R_ℓ、R_L 的条件 | 干预概率 α_t=s_t/(1+s_t)；求 E_{x~π_T}[w log(π_θ/π_T)] = D_KL(π_θ‖π_T) 的修正权重 |
| 约束 | 奖励必须仍锚定测试结果；hacking 率可控 | 不用外部教师、不用特权信息、显存不随循环数膨胀 | 保持 reverse-KL 目标形式；推理时无教师 |

这三个形式化的精妙之处在于**它们都没有改变学习的最终目标**（MiMo 仍以测试通过为锚、LoopOPD 仍是 reverse-KL、STI-OPD 显式恢复 OPD 期望），改变的只是信号的**生产与再分配方式**。这使得效果提升可以归因于信号质量而非目标偏移。

## 四、问题解法

### 4.1 MiMo-V2.6：三轴扩展 + 质量再分配

**先看基座。** MiMo-V2.6-Pro 是 1.02T 参数/42B 激活的 MoE 模型，Flash 是 310B/15B；骨干是滑动窗口注意力（SWA，窗口 128）与全局注意力（GA）交替的混合结构，配 MiMo-ViT 视觉编码器和音频编码器。预训练后有一个"以智能体为中心"的中期训练（mid-training），把上下文扩到 1M，并把优化器从 AdamW 换成 Muown（Muon 变体，矩阵级正交化更新 + 行范数控制），为大 batch RL 做准备。

**轴一：训练算力。** 全异步训练，每步 1,568 prompt × 16 rollout = 25K 条轨迹、2.7–3.7B token，上下文最长 1M。RL 花费：Pro 260 万美元、Flash 90 万美元。成本构成：rollout 43.8%、训练 43.5%、评分 12.7%（Pro）。论文标题戏称 "You Only RL Once"——一次大跑完成，不靠多轮重训。

**轴二：环境与 harness 多样性。** 任务横跨代码（占 RL 任务 68%）、通用（12%）、视觉（13%）、上下文跟随（3%）、网络安全（4%）。代码任务有五条合成管线（GitHub PR、员工真实需求、规格驱动、CodeMidas 从源码反推、长时程工程），每条都过"规格-测试对齐审计 + 8 次重跑稳定性检查 + rollout 审计"三道关。网络安全任务用 sanitizer 报告的漏洞类型+崩溃位置做确定性验证，描述与验证同源。**多 harness 训练**是重要设计：不用生产级 harness（工程护栏使信用分配失真），而是用可自由重组的最小 mini-harness 池，迫使能力落在模型而非 harness 惯性上。

**轴三：评分器算力——本文方法核心。** 类比：二元测试奖励像"只看分数的判卷"，GRS/GAR 像"组内互评比稿"。

- **GRS（离线合成 rubric）**：对高通过率任务，离线收集多条 rollout 让 agent 研究归纳出方案 rubric 与行为 rubric，训练时 grader 进入执行环境逐条打分，最终奖励 R_i = R_test · S_sol · S_beh——乘法形式保证失败解仍为零分、通过解按质量分层。
- **GAR（在线优势再分配）**：对其余代码任务，SFT 训练的 agentic grader 在共享工作区对比组内全部轨迹，按方案合适性、实现精度、最小性、无副作用、工艺五维排序通过解；确认 hack 的轨迹奖励清零；然后按公式把正优势质量从低质通过解转移给高质通过解（保持组内总优势守恒，失败轨迹不动）。评分异步进行，异常输出回退原始优势。

**行为正则化两件套。** 组相对长度惩罚：对通过率超过阈值的组，取通过解生成 token 数的 B 分位为参考长度 ℓ*，超过 ℓ* 的成功解按超出幅度扣减奖励（封顶、带容忍带 δ）——惩罚只作用于成功解，困难 prompt 组不罚以保留探索空间。分段级行为惩罚：对格式违规与工具调用错误的 token 打标记，正优势轨迹中被标记 token 的优势置零并把扣除的质量回补给未标记 token，负优势轨迹中被标记 token 的惩罚加倍——"没有错误的行为得到更多强化或更少惩罚"，且每个符号方向的总优势质量守恒，防止过度负优化压力导致熵失控。

**稳定性配套。** MoE router 冻结（消融显示可训练 router 20 步内负载崩塌：CV 0.78→2.0、冷专家 0.5%→22%，且仅回滚 router 即恢复）；多层反 reward-hacking（环境清理、hack agent 主动找漏洞迭代清理、训练中离线审计 + GAR 清零），确认 hacking 率全程 <2%；训练-推理一致性靠 R3 路由回放与 top-p 候选集回放；Sample Mixer 保证混合任务批次分布稳定。

训练日志中的失败复盘同样有参考价值（§5.5）：Flash 与 Pro 的 30 步训练分别中断多次，原因包括 GPU 显存双比特错误、Kubernetes pod 崩溃、grader 网络不可达、partial rollout 下短轨迹先完成导致长度估计偏差耗尽 KV 池、MoE 微批内单专家 30 倍过载引发的 OOM——大规模异步 RL 的工程可靠性与算法本身同等重要。

**MOPD2 收尾。** RL 之后用多前缀多教师 on-policy 蒸馏扩展到难验证领域（游戏开发、科研、具身智能）：把教师轨迹切成 k 个历史前缀，学生从每个前缀续写一轮，对应领域教师给 token 级监督——用前缀限制学生早期偏航。具体分两种：Teacher-Prefix OPD 用 mixRL 教师 rollout 的轨迹做前缀，SFT-Prefix OPD 用高质量合成演示做前缀——后者解决"开放域 SFT 教师覆盖不了学生反复偏航后的历史"问题：固定演示前缀让每次采样只偏航一轮。这个设计呼应了 STI-OPD 对同一问题的不同解法（前缀约束 vs 随机干预），两者可以对照阅读。

### 4.2 LoopOPD / D-LoopOPD：深层循环当教师

**核心机制类比**：同一个学生，做一遍题（浅循环 ℓ=2）和做四遍题（终循环 L=4），四遍的质量自然更高。让"做四遍的自己"教"做两遍的自己"——教师优势来自算力（多两遍循环），不来自任何外部资源。因为共享参数，这个教师是免费获得的。

**LoopOPD（静态版）**：初始化学生 θ←θ_0、冻结教师 θ̄_0←θ_0；学生用浅循环策略 π(ℓ) 采样 rollout；在同一前缀上计算深循环分布 P(L)（教师）与浅循环分布 P(ℓ)（学生），最小化逐 token 反向 KL（式 9）。梯度只流过学生分布。

**D-LoopOPD（动态版）**：关键洞察是共享参数意味着更新学生的同时终端循环策略也在变。于是每步用**当前**的深循环当教师（stop-gradient），学生更新 → 参数共享 → 新的深循环 → 下一步的教师。交互链：π(L)_{θt} →OPD→ π(ℓ)_{θt+1} →参数共享→ π(L)_{θt+1}。这形成闭环递归自改进。

**理论保证（Theorem 1）**：单次蒸馏更新要同时降低两个深度的任务代理 R_ℓ、R_L，充分条件是两处的梯度对齐 γ_ℓ, γ_L > 0 且步长 η < min(2γ_{d,t}/(β_d‖g_t‖²))。论文还构造了反例说明"教师更强"不自动保证 γ_L>0——参数共享是双刃剑。

**实现细节**：学生深度消融选 ℓ=2（loop1 学生自身太弱，AIME24 Avg@16 仅 0.63；loop3 离教师太近，61.46 vs 62.08 没有蒸馏空间；loop2 平衡最佳）。训练用 4 张 H200，DAPO-Math-17k 数据集，31,744 token 最大生成长度。

### 4.3 STI-OPD：分歧驱动的随机干预 + 重要性加权

**第一问：何时干预？** 学生每轮先提出完整响应 â_t，用 k3 估计器（g = r−1−log r，r 为教师/学生似然比）逐 token 估计反向 KL——k3 非负、无偏、且在近策略区方差低于 k1（消融验证：换 k1 各项全面下降）。长度归一化得分 s_t = (1/L)Σg_{t,k}。干预概率 α_t = s_t/(1+s_t)——平滑单调映射，无手调阈值、无固定课表。Bernoulli 采样决定保留学生响应（z_t=0）或整轮替换为教师重生成（z_t=1）。替换是整轮的，保证推理与动作一致；被丢弃的学生提案不进历史也不进训练缓冲。

**第二问：教师 token 怎么学？** 标准 OPD 的采样 reverse-KL 损失假设 token 来自学生分布，但干预轮的 token 来自教师分布，直接套用期望值不对。STI-OPD 对教师 token 加重要性权重 w_θ(x,c) = π_θ(x|c)/π_T(x|c)，由恒等式 E_{x~π_T}[w·log(π_θ/π_T)] = D_KL(π_θ‖π_T)（固定上下文时）恢复学生在条件 reverse-KL 下的期望。合并目标（式 11）：学生轮直接用标准采样损失，教师轮用加权损失，两支估计同一目标。工程上把 −ℓ 当 reward 走 PPO 式损失，ω 做裁剪稳定优化。

**类比**：k3 分数像"师生意见分歧度测量仪"；α=s/(1+s) 像"分歧越大、师傅越可能接管"的渐进规则；重要性加权像"把师傅的示范换算回学徒视角"的汇率。

## 六、效果优势的根源解释

### 6.1 根源机制与证据链

**MiMo-V2.6：奖励分辨率 → 信用分配 → 行为质量。**

因果链：二元测试奖励使组内所有通过解获得相同优势（机制瓶颈：信号分辨率 1 bit）→ GRPO 类更新只能提高"通过解对失败解"的概率比，无法区分好通过与差通过 → 在通过率上升后，模型在"通过"等价类内随机漂移，实际漂向样本量占优的捷径（长输出、防御性宽泛补丁——这些行为更容易碰瓷通过测试）→ turns/长度暴涨、pass@k 停滞（无 GAR 消融实证）→ GRS/GAR 把组内质量排序转成连续优势信号（分辨率从 1 bit 提升到排序粒度）→ 正优势从低质通过解转移到高质解 → 同样是"通过"，好解被强化得更多 → 行为收敛到小而精的补丁。[论文实验已支持：GAR 消融的 turns/长度/pass 曲线 + 行为审计]

多 harness 泛化的根源：单 harness 训练使策略与 harness 特定实现耦合（能力存在于"模型×harness"联合体中），mini-harness 池的多变性切断了这层耦合，迫使能力内化于模型参数。[论文实验已支持：held-out harness 50%→66%]

Router 冻结的根源：RL 梯度对 router 的扰动引发专家负载正反馈崩塌（冷专家得不到梯度→更冷），冻结切断反馈环。[论文实验已支持：回滚对照]

**LoopOPD：监督直达中间计算 + 教师同上下文。**

因果链：GRPO 的信用只记在终循环（中间循环无直接监督，梯度经参数共享间接传播，信号弱）→ RLTT 补监督但显存随循环线性膨胀（只能短 rollout，2,048 token 截断率高）→ LoopOPD 教师与学生条件在**完全相同的上下文与前缀**（同 token、同参数族），逐 token reverse-KL 是密集分布监督且直达 ℓ 层 → 中间循环表征被显式塑形，参数共享把改善传导到所有深度（跨循环各深度提升实证）→ D-LoopOPD 教师随学生更新：教师不会过时、且保持更高熵（论文实验：D 版教师/学生熵全程更高）→ 学生 rollout 更多样、探索更广 → 递归增益（D 版优于冻结版 6.46/1.46/1.05 pp on AIME24/25/26）。[论文实验已支持：熵曲线 + 跨循环表]

[阅读者推测] LoopOPD 在 AIME 上的增益部分可能来自长 CoT 数学任务与 31,744 解码预算的匹配——其训练 rollout 即长轨迹，蒸馏信号覆盖长推理分布；RLTT 因显存放弃长 rollout 导致该分布缺失。

**STI-OPD：干预修复状态分布 + 加权保目标。**

因果链：多轮中动作塑造后续观测 → 单轮偏差经环境转移函数复合 → 学生访问的历史脱离教师 rollout 支持区 → 教师 token 指导在这些历史上的可信度下降（甚至有害）→ 阈值式干预把 k 估计噪声放大为控制的突变（小阈值过度干预、大阈值漏干预，论文非单调消融实证）→ 随机概率干预使控制强度随分歧平滑变化：分歧大→教师接管、修正下一环境转移（干预影响的是状态分布本身，而非仅损失项）；分歧小→学生保留探索 → k3 的低方差保证近策略区不误判 → 干预 token 经重要性加权仍服务条件 reverse-KL 目标（恒等式 10）→ 漂移受控且探索保留 → 误差复合最重的最长时程任务增益最大。[论文实验已支持：长时程增益分布 + 阈值对照 + 预算匹配对照 + 消融]

注意一条诚实的边界（论文自己指出）：重要性校正只修 token 采样分布，不修正干预决策本身引入的上下文分布偏移——上下文分布是设计者主动选择的（这正是干预的目的），不属于"需要修正的偏差"。

### 6.3 综合判断与未决问题

**多项研究共同支持的机制**：(1) 密集 token 级监督优于稀疏结果奖励的样本效率（OPD 系论文 + RLTT + Thinking Machines 实践）；(2) 训练分布与推理分布对齐（on-policy 性质）是蒸馏有效的前提（DAgger 传统 + Kaur 分析 + STI 消融）。**仍属推测的机制**：D-LoopOPD 熵优势→探索→增益的完整链条（论文只展示熵曲线与最终性能的相关性，未做熵干预对照）；MiMo 多域混合（68% 代码）中非代码任务的增益归因。**适用条件**：LoopOPD 需要 LoopLM 架构且存在能力足够的中继循环（loop1 太弱即失效，学生深度消融证明）；STI-OPD 需要教师可输出逐 token 概率（黑盒 API 教师不可用，论文 limitation 明示），且干预是整轮替换、无法部分修正；MiMo 的 GAR 依赖可对比的组内通过解混合存在（全通过/全失败组被动态采样过滤）。**可能的失效条件**：任务不可验证且无 rubric 可循时 GRS/GAR 均无抓手；教师与学生能力差过大时 STI 的 k3 分数长期高企、干预率居高不下（论文未报告该极端）。

## 七、必要知识反推

假设一个零背景的人要做出这三篇论文，最少需要掌握什么？

**领域知识层**：
- Transformer 与 MoE 架构细节（SWA/GA 混合、专家并行、router 机制）——不理解专家负载就不可能诊断出 router 漂移崩塌并想到冻结（MiMo §5.4 的对照实验设计完全依赖对 MoE 负载动力学的理解）。
- 循环模型机制（共享参数多次前向、每个循环产生一个 next-token 分布）——这是 LoopOPD 全部设计的本体；必须知道 Ouro 的跨循环精度差异（loop2 39.16 vs loop4 62.08）才能想到"档位即教师"。
- 多轮智能体的环境动力学（动作→观测→历史的闭环）——不理解"动作塑造后续观测"就看不到轨迹漂移问题（STI 的问题定义第一步）。
- RLVR/GRPO 的奖励信用分配机制、蒸馏的正/反向 KL 差异（reverse KL 是 mode-seeking，保学生已有能力）。

**方法论知识层**：
- 重要性采样与 KL 估计器族（k1/k3 的偏差-方差权衡）——STI 的两个核心组件直接建立在这两个经典工具上；k3 的非负性与低方差性是 Schulman 2020 博客的已知结论。
- 神经正切核（NTK）与一阶优化分析——LoopOPD Theorem 1 的证明工具（Jacobian 块 K_{dℓ} 描述跨深度更新传导）。
- 消融实验设计意识：三篇都靠"去掉唯一组件看退化"来归因（GAR 消融、学生深度消融、去加权消融）。
- 奖励 hacking 的攻防思维（MiMo 的 hack agent 是红队方法论的迁移）。

**工程知识层**：
- 大规模异步 RL 基础设施（partial rollout、控制面/数据面解耦、KV cache 分层、投机解码）——MiMo 的三轴扩展每一轴都有工程支柱；DFlash 草稿模型在 RL rollout 日志上微调后接受长度提升 31.3% 这类细节决定了成本可行性。
- 评测协议控制（Avg@k 的多采样方差、同一教师/数据/预算下的 baseline 公平性）——STI 的同预算对照与 LoopOPD 的统一评测长度（31,744）是结论可信的前提。
- 分布式训练一致性（MXFP4 QDQ、R3 路由回放、top-p 候选集回放）——训练与推理引擎数值不一致会污染重要性比率。

**知识融合的关键节点**：
1. MiMo：把"评测科学中的组内比较"（rubric、比稿）移植到"RL 优势再分配"——交叉点在"组"这个共同结构（GRPO 的 rollout 组 vs 评审的对照组）。
2. LoopOPD：把"测试时算力扩展"（更深循环=更强）与"蒸馏教师选择"两个不相关领域焊接——洞察是"算力特权可以替代参数特权"，且共享参数让这个教师零成本。
3. STI：把"随机化平滑决策"（对抗阈值噪声的通用技巧）与"重要性采样修正期望"（离策略评估的标准工具）组合到干预式蒸馏上——两个组件各自平凡，组合恰好补上理论缺口。

## 八、论文中可以提取的通用性灵感

**灵感一：算力档位即教师（计算特权的自监督化）。**
核心思想：同一系统的"更多计算"版本可以作为"更少计算"版本的教师，无需外部资源。论文证据：LoopOPD 用深循环教浅循环，AIME24 62.08→71.67；D 版动态刷新教师再涨 6.46pp。推广场景：(1) 推理系统——长思维链模型蒸馏给短思维链的自己；(2) 搜索系统——带检索增强的回答教无检索的回答；(3) 代码——带完整测试反馈运行的版本教静态版本；(4) 科学计算——细网格模拟教粗网格模拟；(5) 机器人——慢速规划控制器教快速反应控制器。

**灵感二：把噪声决策换成概率化平滑映射。**
核心思想：当决策依据是含噪声的估计值时，阈值化会把估计误差放大为行为的突变；把估计值单调映射为动作概率可以平滑这层噪声。论文证据：STI 的 α=s/(1+s) 全面优于最优确定性阈值（τ=1.0），且免调参。推广场景：(1) 系统运维——熔断器按异常分数概率性降级而非硬阈值；(2) 推荐系统——探索率随不确定性平滑缩放；(3) 医疗决策——按风险评分概率性安排复查而非一刀切；(4) 网络拥塞控制——按丢包率概率调整窗口；(5) 教育——按错题率概率性插入复习而非固定课表。

**灵感三：组内相对质量优于绝对二元判定。**
核心思想：当绝对评分难以定义时，同批候选的相对排序仍可提取，且排序信息足以重塑激励。论文证据：MiMo GAR 把通过解排序后重分配优势，turns 稳定、补丁更小；hacking 率 <2%。推广场景：(1) 众包质检——同批工单互评定位低质通过项；(2) 编译器优化——同程序多变体并行编译按资源占用排序择优；(3) 内容审核——批量候选拼稿而非逐条绝对打分；(4) A/B 实验——同期多候选的组内比较消除时间趋势干扰；(5) 招聘/评审——结构化组内比较降低绝对分校准成本。

**灵感四：修正采样失配以保住学习目标（重要性加权的普适性）。**
核心思想：任何"从分布 A 采样、却在为分布 B 的目标做估计"的训练流程都存在系统偏差，可用重加权恢复无偏。论文证据：STI 去加权消融降幅最大（Look 73.7→61.9）。推广场景：(1) 因果推断——倾向得分加权修正处理组选择偏差；(2) 推荐系统——曝光日志的逆倾向加权去偏；(3) 主动学习——按采样概率重加权标注样本；(4) 机器人遥操作数据——按操作者策略概率加权修正演示分布；(5) 模拟到现实迁移——对 sim/real 概率比加权。

**灵感五：让控制器随误差收敛自动退场。**
核心思想：外部辅助（教师、监控、护栏）的强度应设计成随系统自身能力提升而自然衰减，避免永久依赖。论文证据：STI 干预频率随师生分歧趋零而下降（图 4），推理时零教师依赖；LoopOPD D 版教师"水涨船高"同属此型。推广场景：(1) 自适应UI——新手引导随操作熟练度淡出；(2) 数据库——一致性检查随系统稳定降频；(3) 教练系统——辅助提示随学员正确率递减；(4) 自动驾驶——人机共驾的接管概率随置信度调整；(5) 微服务——熔断恢复后的渐进流量放量。

**灵感六：监督信号要锚定在可验证的底座上再做分层。**
核心思想：软性质量信号（rubric、排序）容易漂移或被博弈，应与硬验证信号乘法耦合，让"过硬的底线"约束"分层的增量"。论文证据：MiMo 的 R=R_test·S_sol·S_beh 乘法形式——失败解无论 rubric 多好看都是零分；确认 hacking 直接清零。推广场景：(1) 安全合规——合规检查通过是 1、体验优化只做乘法加成；(2) 编译优化——正确性门控之上再优化速度；(3) 交易系统——风控通过前提下再谈收益率分层；(4) 药物筛选——活性阈值之上按选择性排序。

三篇论文读罢，最深的印象是：2026 年的后训练竞争已经从"谁的模型大"转向"谁的监督信号分辨率高、覆盖广、还保真"。MiMo 证明这件事值得花千万美元级算力做工业级整合，LoopOPD 和 STI-OPD 证明在架构层和目标函数层还留着大量精巧的免费午餐。而三者共同的方法论气质——不发明新目标，只让信号更诚实——或许是比任何单项技术都更值得带走的启发。
