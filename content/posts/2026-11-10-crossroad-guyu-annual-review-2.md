## 先说结论

本期是《十字路口》年终复盘系列的第二期。嘉宾谷雨的身份恰好卡在几个正在松动的位置之间：南京大学本科、俄亥俄州立博士、Yu Su 门下做过 Mind2Web 这类奠基性 agent 基准的研究者，如今是 NeoCognition（做 continual learning 与 computer use agent，口述种子轮四千万美元、17 个全职）的联创，创业快满一年。主持人 Koji 请他把 2026 年 AI 带给自己的十个 aha moments 讲完，结果十个里有四个的开场白是同一句：我被打脸了——去年他断言创业公司做 RSI 没戏、上半年还在到处讲 memory notes 做 continual learning 不靠谱、两年前认为数学离不开形式化验证、而论文体系这一年的崩塌速度也超出了他的预期。

被打脸的方向是同一个：还是得信 scaling，而且模型的迭代快到「以周为单位」。从他自己的总结里，有三个判断值得没听节目的读者带走：其一，AI 研发能力增强之后，大厂积累的 infra 和训练配方反而可能成为累赘，RSI 的机会属于没有历史包袱的新实验室；其二，coding 训练规模的上升把 computer use 的「手」（操作层）基本解决了，剩下的战场在「脑子」（认知层）——那正好是他的公司押注的生意；其三，「明年，起码明年下半年之前」的关键词是 continual learning，就像 2025 年底到 2026 年是 coding、再往前是视觉语言一样。围绕这三条，还有学术评价体系的崩塌、创业一年「别急着造灭火器」的学费、AI 视频忽然能拍出两小时一致的长片、Personal Agent 靠产品形态而非技术临界点起量——一份诚实到自嘲的一线年终盘点。

十个 aha moments 速览（正文章节与编号对应）：①创业公司做 RSI 成立了；②computer use 真的泛化了；③数学被 informal 地解决；④memory notes 的上限被低估；⑤论文与评审体系崩塌；⑥创业本身（动机与一年体感）；⑦学术团队变成了 SISP；⑧创业环境热到诡异；⑨AI 视频能拍两小时一致的电影；⑩Personal Agent 突然起来了。

## 旧 infra 会从资产变累赘：RSI 为什么反而属于新实验室

第一个 aha moment 是谷雨自己贴出来的「打脸实录」。他原来的判断有两层：RSI（递归自我改进）本质是模型赛道，得追着 OpenAI 和 Anthropic（口述「O 跟 A」）这种最前沿模型厂跑，新创业公司没有资格上牌桌；而且做 recursive 得有起点——你得先有自己的模型。转折点是「前阵子 Recursive 跟 Miranda 的发布」（口述口径）：他转述说，Miranda 有一个人花了三个多月，训出的 pretraining model 比 Kimi K3 还要强。这直接推翻了「小团队做不出像样的起点模型」的假设。

谷雨给出的机制解释值得完整展开，因为它是全文最重要的一条链条：**AI 的研发能力越来越强，总有一天它写 training infra、写 training recipe 的能力会超过人——到那一天，大模型公司过去积累下来的 infra 和 recipe 反而会变成累赘。**他举了一个具体例子（朋友口述，转写将该技术记作「Score Center」，未能核实）：国内某模型厂明知某项技术有用、用上可能提一两个点，但为了用它需要适配自家 infra，代价太大，最终选择不做。而对一个从零开始的创业公司来说，反正 infra 是 AI 帮着搜出来的一套新配方，「我随时可以迭代它，随时可以丢掉它」。Koji 把这个机制翻译成了组织问题：正因为技术还在快速变化，infra、SOP、组织架构一旦成型就难以调整，新实验室反而有灵活性、可能有更大的加速度。前提条件也直白：走模型赛道做 full stack 训练需要钱、卡和数据，所以「Recursive、Miranda 他们确实拿很多钱」（经核实，Recursive 即 Richard Socher 创办的 Recursive Superintelligence，2026 年 5 月出 stealth 时融资 6.5 亿美元、投后估值 46.5 亿美元；Miranda 未能核实到对应公开实体）。Koji 追问除了这两家还看好谁，谷雨点名了转写作「JFT」的公司（未能核实）和 Jeff Dean 的 Discovery Loop（经核实，2026 年 8 月成立，9 月已被曝寻求约 500 亿美元估值），并表示国内也有一些、可以再观察。

把这条链条写全：AI 自动化研发能力上升 → 大厂既有基础设施从资产变为适配负担（改造成本超过收益，宁可放弃已知增量）→ 无历史包袱的新实验室可以用 AI 原生的方式快速迭代技术栈 → RSI 的可行路径向 startup 开放 → 观察指标是 Recursive、Miranda 这类公司的下一个交付物能不能持续支撑其估值。对非创业的读者，这里的可迁移原则是：判断一类组织或个人的既有优势时，要问它在范式快速切换期是需要持续付维护费的负债，还是还在生息的资产。

## 「手」解决了，「脑子」没有：Computer Use 的残余问题与 ApprenticeBench

第二个 aha moment 来自谷雨自己的主业。他说 computer use agent「这个事情快解决了、真的泛化了」：去年大家还在讨论泛化性和可靠性，去年底到今年初，操作层面的问题基本解决完。归因很明确——coding 的训练规模上去了，能力泛化到了软件操作和网页操作。代价与收益的边界也挪了：现在的状态是「手已经基本解决，但 cognitive level、认知层面或脑子层面还有一些需要解决的问题」，也就是知道一件事该怎么处理（每家公司内部的业务流程、处理事情的惯例、特定的审批流），一旦知道，对应的操作就不会错。他强调认知层严格说已经不属于 computer use 的范畴、是 orthogonal 的，但它必须体现在与软件网页的交互上——这正是 NeoCognition 在做的事。

这一段最有信息量的不是判断而是自我否定：公司刚成立时花了几个月专门解决操作层的可靠性问题，做法是让 agent 多跑几次、把做对的那次挑出来封装成可复用的 skill，为此搭了一整套 pipeline；现在发现「完全不需要」——让 Opus 5.5 自己实现一遍流程，很快也对，而且过程中会自己纠错。一年前值得一个团队数月投入的工程补丁，被模型的原生能力直接吸收了。

顺着 continual learning 的定位，他介绍了公司刚发布的 ApprenticeBench（转写误作 Martin's bench）：建筑行业的会计报账场景，100 道题，全都围绕同一件事——报账，但每道题背后藏着不同的公司惯例、工作流和审批规则。关键设计是这 100 个任务不独立，必须一个接一个 in a stream 连着做：做后面的题要用到前面题目里学到的规则，评的是「边干边学」的持续学习过程。谷雨借此批评了当下 long-horizon 基准的普遍偏差——找一堆特别难、一个人要做半天的任务：这种任务既难找、又难 scale up。他给出的比喻是全期最好的一句：**真正的长程，不是一个会计一笔账报一个星期，而是一个菜鸟员工变成公司老员工的那几个月到一两年。**长程 scale up 的终局是量变引起质变，得到 lifelong intelligence。顺带盘点：谷雨所在的 OSU NLP 组此前做过 MMMU（多模态）、Mind2Web（2023 年 5 月，他称之为 LLM 时代最早的 computer use／web agent 基准，变体 Online-Mind2Web 据其口述被 Anthropic、OpenAI、Gemini 发模型时采用），以及与清华合作的 AgentBench。

分数现状与提分路径也交代得很实：ApprenticeBench 第一版，最强模型（Claude 系）大约 80 分；continual learning 的能力是当前前沿与非前沿模型的分水岭；最能带来提升的数据是「教模型更好写 memory notes」的数据。他听说 OpenAI 和 Anthropic 各有自己的 recipe，并猜想 Claude Code、Codex 这类 long session 天然会伴随这种性质的数据——但 recipe 并不成熟，NeoCognition 自己也在探索，其他模型实验室没有特别好的解，那两家在这个基准上也还有很大提升空间；新版本很快发布，「目前的最强模型分数也会低很多」。至于刷分：一是基准没有公开，「厂商没有办法追着我们杀」；二是它测的是 meta level 的持续学习能力，只把题目本身做对没有意义——「你要真把这（元能力）刷上去，那我也服了，确实也算积德了」。

这一节的两条链条：其一，coding 训练规模上升 → 操作能力外溢到 GUI → 可靠性从工程封装问题变成模型原生能力（旧 pipeline 贬值）→ 应用公司的机会窗口从操作层上移到认知层与业务知识层。其二，基准怎么定义能力，优化就往哪里去：连续任务流＋不公开＋只测元能力 → 针对题面的优化无意义 → 刷分与真实进步方向罕见地一致 → 观察 ApprenticeBench 新版发布后前沿模型的分数变化，就能看到 continual learning 这项能力的斜率。

## 当智力突然不值钱：数学、memory notes 与崩塌的论文系统

第三、四、五个 aha moment 可以放在一起读，因为它们是同一个故事在三个领域的重演。数学上，2024 年的共识（包括谷雨自己）是需要 formal verification、需要 Lean 这种形式化系统来提供训练信号，否则「train 一个 LLM 来嫁接自己，有点左脚踩右脚」，上限不会高；结果去年靠 informal 的方式（数据量上去、质量上去）已经拿到 IMO 金牌，今年「放大了五十倍、一百倍」，前几年的 open problem 基本都能被 informal 地解决。谷雨的检讨只有一句：「还是某种 bitter lesson，我们还是应该相信 scaling 可以解决更多的问题。」第四个 aha 是更私人版本：他今年上半年还在到处讲 memory notes 这种 continual learning 路线「不是一个可靠的优化算法、肯定不行」，下半年承认两个临界点同时到了——computer use 到了临界点，memory notes 的上限也被低估了。他保留了限定条件：瓶颈从来是模型自身的能力，模型越强，这条路线的上限越可观；而且「so far 真正这方面比较强的，也就是 Anthropic 跟 OpenAI，其他大家做的都不行」。Koji 在此做了全场唯一的归纳：前几个 aha moment 都和模型的快速进化有关，颠覆的是「用工程手段或其他 learning paradigm 去补模型短板」的思路——今年的答案还是更加相信 scaling。

第五个 aha 是学术体系的崩塌，也是与[李磊篇](/posts/2026-10-29-crossroad-lilei-phd-10-questions/)「论文从硬通货贬值成 nice to have」互为印证的一手体感。谷雨说这个趋势 2023 年就有，但「到二六年真的发现临界点到了：评价体系、投稿系统、会议系统彻底崩塌」。他自己的状态：一年半没投过一篇论文（不是没得投，是「不想投、不是一个很高的优先级」）；半年多没审过稿、没当过 AC，理由是「感觉这对我的时间并不是很尊重」；当 AC 一个 batch 十六篇文章，真正质量过得去的也许一两篇——背景是大量的 AI slop 和灌水（转写误作 ASLAP），论文数量与能力「已经完全没有任何的相关性了」。招聘端的变化更直接：NeoCognition 招人主要看聊——问做过的事、看对方对你们正在做的事的理解，流程里让候选人做 research presentation，因为 presentation 最能体现逻辑表达、QA 反应和对问题的理解。他设想的重建是高 taste 的同行评议，像美国院校招聘里的 job talk——senior 教授们凭判断评价一个人，而不是「现在本科生也可以当审稿人」的无门槛评审。但体系重建有滞后性，学术圈还在按惯性走，结果就是中美两边的教职优先级都在后移：AI PhD 去 frontier lab 或新实验室「确实可以赚很多钱」，学校待遇差、资源少，还叠加评价体系的问题。

这段的结尾是全期情绪最重的地方。Koji 引用朋友的玩笑：十年之后，教授的社会地位不如夜店的男模。谷雨的回答是「我真的这么觉得」，并给出了自己的历史坐标：进入现代文明之前以及之后很长一段时间，体力都比脑力值钱；机械时代让强壮贬值；数字时代让脑力升值；而 AI 是数字世界的机械，它来了，脑力就开始贬值——短期内机器难以取代的，他认为是情绪价值。他还引述一条新闻（节目口径，未核实）：全世界卖得最好的两种减肥药的收入，大于这些模型公司的收入。面对「现在还值不值得读 PhD」的提问，他的回答是全场最简的决策原则：「我不给建议，自己开心就好」「想做一件事去做就是一种理性」。他还分享了一个近期着迷的对照样本——「拼豆自习室」：按小时付费，每人一格小隔间，几百种颜色的拼豆和工具全部备好，大家像工厂流水线一样安静劳作，而且是付费的；Koji 顺势接了句玩笑：「我们公司可以退钱，让大家付费来上班。」两人都承认这段聊得搞笑，「但想起来挺五味杂陈」。

链条：模型产出论文与代码的边际成本暴跌 → 论文供给失控（AI slop）→ 审稿与计数式评价失效（16 篇里 1–2 篇可用）→ 筛选信号迁移到难以伪造的环节（research presentation、当面深聊）→ 人才与优先级流出学术界 → 观察：顶级会议投稿与审稿参与率的走势、前沿实验室的招聘标准。启发与李磊篇一致但更尖锐：任何可被批量伪造的信号都会贬值，个人要积累的是难以伪造的部分——品味、判断力、把事情做成的记录。

## 造灭火器还是卖砖头：学术团队的市场学费

第六到第八个 aha moment 都是关于创业的。先说动机，因为后面的学费都从这里长出来：谷雨说自己这辈子没有一秒钟想过去大厂——不喜欢固定的上班与作息，需要「在状态的时候做事、不在状态的时候可以不做事」；需要 ownership，想自己决定方向而不是完成别人的使命；以及对风险「没有任何的概念，想做就做，不会计较代价」。他承认这可能和家庭给的松弛感有关：父母对世俗节点没有要求。创业快一年，被 Koji 问到「想要的自由自主都拿到了吗」，他把它记作又一个 moment。

第七个 aha 是全期对创业公司最有迁移价值的一条：**我们成了「拿锤子找钉子」的人（solutions in search of problems，SISP）。**铺垫是他的骄傲：团队在导师 Yu Su 带领下，学术界口碑一直很好，很大程度是因为 vision 和 taste——从不先发明一个算法再找应用场景，而是从问题的 fundamental issues 出发去解决，这也是「我们在 LLM Agent 时代做了一些开创性工作」的原因。但放到创业上，这个模式反了过来。他拆解的机制是：做学术研究，只要在一套技术体系内闭环、自洽就行；做 startup，光自洽是自娱自乐，**你需要和市场一起完成闭环**——fundamental problem 还要能回答「解决别人的什么问题、带来什么商业价值」。continual learning 确实是当下 AI 的 fundamental problem，但把它放进产品和市场里应该是什么形式、解决谁的问题，正是过去几个月到一年交的学费。「这个道理都懂，纸上得来终觉浅。」

紧接着是灭火器与砖头的比喻（谷雨引述的 VC 理论）：一个人头上着火了，他不会等你造好灭火器——手边有砖头，他先拿砖头把火拍灭。学术团队做事 solid，总想造一个特别满意的灭火器；但灭火器造出来之前，卖砖头的已经卖出去一百个。投射到业务上：他们对发布标准定得太高，总想 release 特别 solid 的东西；而公司有时候应该先发布不那么成熟的东西、先把闭环跑起来，「甚至有时候你就先把牛吹出去都行，但我们确实这方面太本分了」。他补充了节奏的另一面：说得早、成为第一个 moment 的创造者，后面会有红利，但前提是不断 deliver——做得好的典型，他的答案是马斯克，「硅谷 fake it till make it 的极致」（口述口径）。顺带回应了「高中生毕业直接工作」的趋势：合理，因为对个体而言，前十几年的教育更多是在完成筛选而非磨炼能力，教育资源足够的地方确实可以早做真正有价值的事；但它不会大众化，对环境的要求太高。

第八个 aha 是创业环境的骤热。最直接的体感错位：创业过去是非主流路径，过去一年他频繁听到「大家都在创业，我周围人都在创业，我也想去创业」——「什么时候创业成了一个随大流的事情？」归因是趋利，以及钱真的多：他到今年六月才知道国内投了这么多钱，此前大家的印象还是硅谷的钱更多。他给的量级对比：NeoCognition 作为 AGI 创业公司拿 4000 万美元种子轮在硅谷已经算大（最常见的种子轮是 500 万、1000 万美元），国内 2023、2024 年创业的很厉害的老师也就拿五百万、一千万美元；而今年上半年，国内一些所谓 new lab 直接给出 10 亿到 20 亿美元级的估值（转写记作「T Billion 到二十亿」，量级未核实）——「对我来说确实非常非常震惊」。他的解释带着不确定：可能是房地产的钱找不到去处，「我确实不太懂，这个可能 Koji 老师看得更清楚一点」。评价上他偏正面：鼓励创新对社会是好事，让掌握前沿技术、最有想法的年轻人没有压力地拿到资本去尝试也是好事——而且多数不签回购、不对赌，压力不是个人财务上的，是「会不会浪费几年时间」。

## 两小时的 AI 僵尸片、两个 Personal Agent 与明年的关键词

最后两个 aha moment 分别关于创作与个人生产力。第九个是 AI 视频的质变：最近几个月，它真的能做一段两个小时左右、前后非常一致的电影。谷雨的样本很具体：B 站 UP 主「龙小胖」（名字照转写，未能核实）用 AI 让他童年喜欢的香港僵尸片演员林正英（1997 年去世，经核实）「回归」拍了一部新僵尸片——两个多小时，人脸、情节、衣着从头到尾一致，七八个角色完全保持一致；而大半年前，几分钟的 AI 视频里人脸还在不断变。他强调观看体验的性质变了：不是「来了解一下 AI 能做到什么程度」，而是真的把它当一个故事、一部电影看。弹幕都在讨论剧情而不是 AI；B 站声明了 AI 创作，观众知道、但不在乎——「最终大家对于一个事情怎么产生的可能不是很有所谓，关键还是最后的 deliverable 长什么样」。他的结论是这个时代利好创作者，「像 Alex Wong 说的，大家都可以去 dream」（人名照转写）。附带两个注脚：他的朋友用 AI 辅助写了部科幻小说，设定是算力越来越贵的未来，人已永生，想获得更多算力享受生活就要用记忆去换——因为记忆是数据，模型的进化仍需要吃掉更多人的记忆，「一个很悲伤的故事」；以及价格信号——去年一部 60 集×1 分钟的 AI 短剧剧本报价约 7 万元人民币，现在「AI 一天能给你写一百个出来」（均为口述）。被人类智力贬值触发的总结，是他对未来最粗暴的一条判断：**未来人只需要两件事，一个是审美（决定正确的方向、前进的路线），还有一个是美（情绪价值）。**

第十个 aha 呼应节目标题里的另一个关键词：Personal Agent 突然起来了。谷雨的判断与本站[AI会客厅篇](/posts/2026-11-04-ai-lounge-vc-personal-agent/)的「模型能力＋分发」解释不同侧重点：他认为起量的主因不是技术到了什么临界点——coding 更强、computer use 后台操作网页能力更强当然有关——而是两个产品层面的关键设计。第一，真要做 personal assistant，ChatGPT 或 Claude 那种 session-based 的会话管理肯定不合适：不能说一件事开一个窗口，而要有一个 persistent 的单独会话从头到尾，「像你在微信上跟人聊天一样，每个对象一个窗口」；第二，要有人的感觉，这就是为什么大家都要做卡通形象——比如 Muse 的毛绒形象做各种 PR，一定程度的拟人化。至于被热炒的 proactiveness，他觉得根本不是新技术：连 OpenClaw 就有这个 feature，ChatGPT 的 schedule task 一样能固定时间看邮件给推送，「本质上就是产品跟交互体验」。他自己的用法是一个现成的对照样本：同时用 Muse 和 Instinct（见[AI助理争夺战](/posts/2026-10-25-guigu101-ai-assistant-wars/)的格局梳理），两个都在帮他看邮件看消息——因为国内的服务平台（外卖、订酒店、订机票）用不了；真正有用的是挑出需要 prioritize 的邮件推送给自己。会不会收敛到只用一个？「当我生活中形成依赖之后，一个就够」——眼下试不同的产品只是尝鲜。这条链条与本站[GPT-6 Astra 篇](/posts/2026-10-20-guigu101-gpt6-astra-who-first/)「个人 Agent 的瓶颈不在智能而在身份与成本」互为印证：技术之外，形态与关系设计正在成为起量的第一变量。

收尾的预测环节,谷雨给的是可检验的路线图：模型发展每一年都有一个关键词，对职业规划有参考意义——2024 到 2025 年是视觉语言／多模态，2025 年底到 2026 年是 coding，接下来是 continual learning，「起码明年下半年之前」。更进一步的瞎预测（他强调不一定发生）：明年真的会有一个来自 RSI 创业公司的最强模型，或者至少是 SOTA 级别的前沿模型。对行业，这期节目把 2026 年的主线说得很清楚：模型的原生能力正在逐个吃掉上一年的工程补丁——操作可靠性、记忆系统、甚至「写论文」本身；组织与个人的策略因此从「补模型短板」转向「判断哪个短板马上会被模型自己解决」。对读者，可操作的观察清单只有四条：Recursive、Miranda 这类 RSI 公司的下一个交付物；ApprenticeBench 新版发布后前沿模型的分数；OpenAI 与 Anthropic 的 memory notes recipe 是否产品化；以及 RSI 公司是否真的交付那个「最强模型」。四条里任何一条兑现或证伪，都值得重新校准自己明年的重心。
