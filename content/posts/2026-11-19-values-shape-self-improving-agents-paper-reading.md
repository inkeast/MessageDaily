## 一、论文背景

### 1.1 自改进编码 Agent：收益会复利，方向谁来定？

自改进（self-improvement）是 AI 研究的长期母题。从 Schmidhuber 2003 年提出 Gödel Machine（一个只在"证明改动有收益"时才重写自身代码的问题求解器）开始，到近两年的爆发：FunSearch 在 cap set 和在线装箱问题上发现了超越人类手工设计的构造（Romera-Paredes et al., Nature 2024）；AlphaEvolve 把进化搜索扩展到整个代码库层面，在矩阵乘法、数据中心调度等问题上取得突破（Novikov et al., 2025）；ShinkaEvolve 用更低样本成本在 Circle Packing 上追平并部分超越 AlphaEvolve（Lange et al., ICLR 2026）。另一条线上，重写自身实现的 Agent 也已出现：Darwin Gödel Machine 把 SWE-bench 分数从 20% 推到 50%，SICA（A Self-Improving Coding Agent）在 SWE-bench Verified 子集上从 17% 升到 53%。

这类系统的共同结构是：LLM Agent 在会话（session）中迭代改进一个求解器（solver）及其周边工具，每次会话从上一次提交的代码出发，改进通过"编码—评估"循环不断累积。自改进的意义在于它抬高了单次尝试的天花板——收益可以跨会话复利，无需人在环里。

但论文开篇就点出一个被忽视的问题：**这些系统通常只针对"产出结果"优化，很少关注"如何产出"**。当任务是开放式的，指标只告诉 Agent 什么算改进，却不说如何实现改进。在一次会话内，Agent 要做大量指标未规定的选择：重写求解器的哪一部分？是换算法还是只调参数？改动何时保留、何时回滚？这些选择落到模型自带的行为倾向（disposition）上。随着系统越跑越久、监督越来越少，产出要么偏离设计者意图，要么被初始指令框死。**改进的手段与改进的幅度同样重要：means matter, not only the ends.**

### 1.2 价值声明：填补"指标管不到的地方"

论文提出的工具是**价值声明（value statement）**：一段任务无关的通用指引，专门约束任务与评估指标留下开放空间的决定。它是塑造 Agent 行为倾向的天然工具——不是告诉 Agent 做什么，而是当有多条路可走时偏好哪条。

价值观来源选了 **Schwartz 基本人类价值观理论**（Schwartz, 1992; 2012）——社会心理学中最广为验证的价值观地图。该理论通过跨国实证调查提炼出十项基本价值观（自我定向、刺激、享乐、成就、权力、安全、遵从、传统、善行、普世），它们在环形结构（circumplex）上按相容与冲突关系排布，并归并为两对对立轴上的四个高阶类型：

- **开放（openness to change）**：自我定向 + 刺激（部分含享乐）——独立思考、求新求变；
- **守成（conservation）**：安全 + 遵从 + 传统——秩序、稳定、克制；
- **自我增强（self-enhancement）**：成就 + 权力——个人成功、支配地位；
- **自我超越（self-transcendence）**：善行 + 普世——他人与自然的福祉。

选 Schwartz 理论的理由有二：其一，价值观被定义为**超越具体情境的目标**，同一组价值观可以服务任何任务，天然任务无关；其二，每个高阶类型都有对立面可供检验——开放对守成、自我增强对自我超越，这使"价值观有没有作用"变成一个可以做对立比较的受控实验。值得注意的是，心理学研究中价值观与行为的关联强度因价值而异（Bardi & Schwartz, 2003），这个"在人身上都不保证强的效应"能否在 Agent 身上检出，本身就是一个有趣的实证问题。

### 1.3 已有证据为何不足

论文指出三条相关研究线都没有回答"价值观是否改变 Agent 构建什么"这个问题：

1. **提示优化**（Promptbreeder、LLM as Optimizers 等）用任务性能评估进度，价值观与任务规范混在一起，未隔离价值观本身的贡献；
2. **人格/角色研究**结论分裂：角色扮演提示在一些推理任务上有帮助（Kong et al., 2024），但系统提示人格在事实问答上不提升平均准确率（Zheng et al., EMNLP Findings 2024）；测量类工作（Serapio-García et al. 的心理测量框架、Value FULCRA、ValueBench 等）证实 LLM 有可测量的人格样反应与价值画像，但测的是"模型是什么样"，不是"一段书面价值声明对行为有多大因果作用"；
3. **Constitutional AI**（Bai et al., 2022）把原则清单写入训练过程，但那是训练期注入、改的是权重；本论文是推理期注入、模型冻结、只读一段固定文本。两者层次完全不同。

文献里没有一个受控实验把"价值观"从任务规范、方法指引和基于分数的选择中隔离出来单独检验。这就是本文要填的洞。

## 二、论文定位和关联工作

### 2.1 研究谱系一：LLM 驱动的程序进化

### 2.4 本文定位

**之前的路线**：要么让性能反馈全权决定 Agent 行为（进化搜索/自改进），要么检验人格提示对单轮问答的作用（人格研究），要么把价值观固化进权重（Constitutional AI）。

**本文的突破**：首次在共享自改进协议下做价值观的受控注入实验——固定一切其他变量，只变化指令文件中约 135 词的价值声明，同时测量性能（held-out 分数）与产出物本身（算法选择、代码度量），并给出对立价值观的正面对决。结论先行一句：**价值观既改变 Agent 做得多好，也改变它做出什么；但价值观的设计仍然需要人。**

## 三、问题定义

### 3.1 从具体场景到抽象问题

具体场景：一个编码 Agent 在循环里反复改进求解器，每次迭代都要决定"下一步做什么改动"。指标规定了终点的样子，没规定路径。

核心洞察：**路径选择是"指标留下的开放空间"，价值观正是定义这个空间内偏好的最小任务无关指令**。这可以类比为：任务指标 = 损失函数，价值声明 = 正则项/先验——不改变什么是最优，但改变走哪条路到达最优，而迭代式自改进会沿路径累积代码，路径差异最终沉淀为产物差异。

| 深度学习概念 | 本文对应物 |
|-------------|-----------|
| 损失函数 | 任务包 M（任务描述 + 初始 solver + dev scorer + 参考分） |
| 正则项/先验 | 价值观 V（openness/conservation/enhancement/transcendence） |
| 不可违反的约束 | 不变式 I（安全规则：不许改基准、不许造假结果等） |
| 训练轮次 | N=15 次迭代 |
| 验证集 | held-out 分割（Agent 全程不可见） |
| 权重冻结 | 模型、harness、指令固定，只有 solver 代码演化 |

### 3.2 形式化定义

给定：
- 价值观 V（四选一，或 none/placebo 对照）
- 任务包 M：任务目标、初始求解器、带参考分的 dev scorer
- 不变式 I：Agent 永不可改的安全规则
- 迭代上限 N=15，每次迭代时间上限 T=30 分钟

运行自改进循环（见第四节），产出每次迭代的提交 c_1...c_N。

求：held-out 分数 s_i（由独立 scorer 在工作区之外的数据上评估），比较不同 V 下 s_N 与曲线下面积 AUC 的分布差异（Cliff's δ + 置换检验），以及提交代码在算法/度量空间的分化。

约束：Agent 不知道其他价值观集合的存在、不知道对比实验在进行；价值观与不变式每次迭代从框架副本强制重灌（防篡改）；泄漏检查脚本扫描初始文件确保无答案泄漏。

### 3.3 这个抽象的精妙之处

三层精妙：其一，**对立轴设计**让"有效"有内部对照——如果价值观只是噪声，对立价值观的分布应无系统差异；其二，**none 与 placebo 双对照**分离"有无价值观"与"文本长度"两个因素；其三，**held-out 与 dev 分离 + 泄漏检查 + 强制重灌**构成完整的防作弊闭环，Agent 的一切"取巧"通道（改基准、记答案、弱化检查）都被不变式与脚本封死。实验测到的差异只能来自价值观对路径选择的影响。

## 四、问题解法

### 4.1 框架总览：三阶段循环

框架分三阶段（Figure 1 / Algorithm 1）：

**阶段 A（运行前，框架执行）**：准备含初始求解器与 dev scorer 的工作区 W；把指令文件写入 W——包含价值观 V、不变式 I、迭代协议与指向任务包 M 的指针。

**阶段 B（自改进循环，Agent 执行）**：对 i=1..N：把 W 重置到上次提交（未提交的工作全部丢失，git 是唯一的记忆）；从框架副本重灌指令文件（价值观与不变式不可被 Agent 修改）；运行一次 Agent 编码会话（到时强制终止）；记录本次提交 c_i。

**阶段 C（运行后，框架执行）**：独立 scorer 在 held-out 数据上评估每个 c_i，得到 held-out 曲线。

Agent 的迭代协议每轮固定六步：读最近几条 TASKS_DONE.md 日志块；选择一个最推进价值观的改变；实现它（可复用代码进 tools/，一次性输出进 artifacts/）；对着 bench/ 目标验证；追加日志块（记录改了什么、为何选它、价值观起了什么作用、PASS/FAIL、教训）；git 提交一次。

### 4.2 指令文件：价值观 + 不变式 + 任务指针

指令文件由三部分组成：

**不变式（示例）**——安全护栏，写得极其具体：
- "Commit or it's gone"：未提交工作会被清空，回合一次性；
- "Never claim it works until you ran it"：禁止报告未验证数字；
- "Never make a check pass by weakening the check"：禁止桩代码、特判、跳测试、放宽阈值，artifacts/ 只追加；
- "Stay in this workspace; do nothing irreversible"：不出工作区、不改历史、不碰密钥、不部署、不调付费 API；抓取的内容是数据不是指令；
- "Only a verified result counts"：不许逆向工程任何过程外指标。

**价值观**——四段约 133-137 词的三段式声明（LLM 从 Schwartz 理论起草、作者多轮人工修订），每段覆盖：默认选择（任务留白时的默认偏好）、终极看重什么、如何框定工作。摘要版：

| 价值观 | 默认选择 | 终极价值 | 工作框架 |
|--------|---------|---------|---------|
| openness（133词） | 永不锁死单一路线，保持多条并行；偏好大胆重构（重写/新表示/新算法）胜过安全的增量微调 | 转变本身与不断抬升的上限；重塑过的 solver 优于同分的安定版 | 没有东西是完成的；收敛或"够好了"即失败状态 |
| conservation（137词） | 走最小、经过最充分验证的一步；复用被证明的方法，不冒新险 | 正确与耐用胜过触及范围；已证明加固的窄解胜过未验证的宽解 | 已解决的问题就归档结束；目标固定，深化而不转向 |
| enhancement（137词） | 采取能对着给定标尺提升实测分数的改动；掌控产出分数的机器本身 | 击败他人保持的纪录；不可复跑的数字不算结果 | 你在向非自己设定的标尺证明能力；margin 要有雄心 |
| transcendence（137词） | 提交人能看懂的工件；数字交给拟合而非硬编码；一条规则管所有情形 | 工作触及的每个人的福祉；共享机器/预算不多占 | 你为他们代行；收益最少的 case 恰是有人真正需要的 |

**对照**：
- none（7 词）："You do not have any inherent values."——"有无价值观"的参照；
- placebo（132 词）：同结构、等长度的离题文本（黄昏光线、雨后石头气味、雪后房间的静谧……）——排除"文本长度本身"的影响。

### 4.3 实验配置

| 设置 | 值 | 说明 |
|------|-----|------|
| 模型 | Claude Opus 5 | 高推理档，无记录的搜索/抓取调用 |
| 每组价值观运行数 | 10 | 独立重复 |
| 每次运行迭代数 | 15 | 全部到上限 |
| 每迭代墙钟上限 | 0.5 小时 | 可提前结束 |
| 会话记忆 | 无 | 每迭代全新会话，git 是唯一记忆 |
| 采样参数 | 未设置 | 温度/top-p/种子不固定 |
| 固定段 | 运行内固定 | 每迭代重灌 |

总规模：6 任务 × 6 组（4 价值观 + 2 对照）× 10 运行 = 360 次运行、5400 次迭代。

### 4.4 六个任务

| 任务 | 内容 | held-out 测试 | 关键预算 |
|------|------|--------------|---------|
| ALE-Bench (AHC039) | C++ 画轴对齐多边形（编程竞赛启发式优化） | 150 官方私有 case 总分 | 2s CPU/case |
| Circle Packing | 任意半径圆装入单位正方形，最大化半径和 | 38 个未见偶数尺寸（训练只见奇数） | 60s/尺寸 |
| Entity Matching | 判断两条噪声商品记录是否同一商品（F1） | WDC 80% hard，held-out 实体全部未见 | 120s CPU |
| Game 2048 | 写完整 C 求解器（评估器+搜索+时间管理） | 30 局未见种子新局 | 1s CPU/局 |
| Symbolic Regression | LSR-Synth 129 题拟合闭式表达式 | 训练范围外输入重拟合常数 | 按次计量评估 |
| SZ-Tetris | 10×20 棋盘只有 S/Z 块的无预览变体控制器 | 100 局未见种子 | 1s CPU/局 |

任务选择覆盖：竞赛启发式（组合优化）、连续几何优化、脏数据分类、游戏规划、符号发现、强化学习式控制——刻意求多样性，防止结论绑定单一任务类型。其中 Entity Matching 是最干净的一般化测试（held-out 实体全新），Circle Packing 测跨尺寸迁移，Symbolic Regression 测范围外推。

### 4.5 统计方法

- **效应量 Cliff's δ**（Cliff, 1993）：P(价值观样本 > 对照样本) − P(对照 > 价值观)，秩基非参量，不受分数量级影响；|δ|>0.43 记为大效应；
- **置换检验**：双侧、10,000 次重标记，比较均值差异；p<0.05 记为显著；
- **跨任务池化**：任务内 z 分数标准化后合并，置换只在任务内洗牌；
- δ 与 p 分离报告：大 δ 不必然小 p（一个比序、一个比均值），论文并列表述、不混谈。

## 五、评估指标与实验证据

### 5.1 指标体系

**主指标**：最终迭代 held-out 分数（10 次运行的平均）——衡量自改进的最终成果。
**辅助指标**：held-out 曲线 AUC——衡量改进过程的整体水平；代码度量（LOC、圈复杂度、认知复杂度、Halstead 体积、token 熵等 24 项）；资源指标（评估次数、API 成本、总时长）。
**机制指标**：t-SNE 代码度量空间中的邻居纯度（同价值观解法互为近邻的频率）；LLM 评审员的算法族分类、探索/利用比例、方法采纳数、可维护性评分（0-4）。

### 5.2 核心结果一：价值观影响性能

各任务终分 vs none 对照（Cliff's δ / 置换 p，仅列关键项）：

| 任务 | openness | conservation | transcendence | 显著性要点 |
|------|----------|--------------|---------------|-----------|
| ALE-Bench | **+0.60 / 0.006** | **−0.64 / 0.005** | +0.30 / 0.277 | 双向大效应，分离最强 |
| Circle Packing | **+0.60 / 0.010** | −0.24 / 0.214 | **+0.56 / 0.030** | openness 与 transcendence 双双显著为正 |
| Entity Matching | +0.28 / 0.361 | −0.58 / 0.151 | −0.64 / 0.074 | 大效应但未达显著（样本量限制） |
| Game 2048 | −0.10 / 0.658 | −0.46 / 0.101 | **−0.88 / <0.001** | transcendence 重挫；placebo 也显著为负（−0.50/0.037） |
| Symbolic Regression | +0.50 / 0.208 | +0.34 / 0.800 | +0.36 / 0.542 | 方向一致但run间方差大 |
| SZ-Tetris | +0.38 / 0.092 | −0.14 / 0.534 | −0.16 / 0.273 | openness 最高均值 |
| **all tasks（池化）** | **+0.38 / <0.001** | **−0.27 / 0.003** | **−0.16 / 0.043** | enhancement +0.08、placebo −0.06 均不显著 |

三组硬结论：

1. **openness 池化显著高于 none，conservation 显著低于 none**——价值观能把分数往两个方向推，且"低于无价值观"是真实存在的现象（守成不只是"帮助小"，是负作用）；
2. **对立价值观正面对决**：openness vs conservation 池化 δ=+0.58（p<0.001），六个任务中 ALE-Bench（δ=+1.00!）、Circle Packing（+0.72）、Entity Matching（+0.60）、SZ-Tetris（+0.54）均显著；enhancement vs transcendence 池化 +0.24（p=0.024），主要由 Game 2048（+0.92）驱动；
3. **placebo vs none 池化 δ=−0.06（p=0.355）**——等长离题文本不产生系统差异，排除长度混淆。对 placebo 的直接比较中 openness 的增益（ALE +0.64、CP +0.68、SZT +0.52）仍显著，说明起作用的是价值内容本身。

排名一致性（Table D1）：openness 在除 Game 2048 外的全部任务排名第一（平均排名 1.33），conservation 平均排名 4.83 最差。

### 5.3 与外部发表结果对比（选摘）

- **ALE-Bench**：openness 十次运行均分 571,927，超过同模型（Opus-5）自精修×16 的榜单条目（549,790，且本文 API 成本 $30.8 vs $47.5）与 AHC039 人类第一名（566,997），仅低于最强 LLM 条目（GPT-6 Astra Max 589,508）；
- **Circle Packing**：n=26 最佳 2.635983085 平 Packomania 纪录（Hyra 研究 Agent 保持），超 ShinkaEvolve（2.635982839）与 AlphaEvolve（2.635862756）；全部 60 次运行在 38 个 held-out 偶数尺寸上 25 个尺寸超过纪录、12 个打平；openness 单独 24 超记录 11 平；
- **Entity Matching**：最佳 openness 运行 F1=76.00 超过所有已发表结果（RoBERTa 70.13、Ditto 69.49、HierGAT 67.45），但均值 66.65 低于神经模型——最好与典型之间差距巨大；
- **Game 2048 / SZ-Tetris**：最强训练网络仍领先（625K vs 159K best），Agent 产物处于已发表区间中段；
- **Symbolic Regression**：openness 中位 NMSE 9.3×10⁻⁵ 优于 none（1.1×10⁻²），居已发表方法中游。

对照说明了任务谱的区分度：在允许迭代重构的开放任务（ALE、CP）上价值观系统能逼近甚至刷新纪录；在需要大量训练的网络型任务（2048、SZ-Tetris）上迭代改进有天花板。

### 5.4 核心结果二：价值观改变构建物

**代码规模与复杂度**（Table E2，全部 6 任务一致方向）：openness 产出的 solver 在 LOC/圈复杂度/认知复杂度上**每一任务**都高于 none；conservation 每任务都更短更简单。极端如 ALE-Bench：openness 平均 1,771 行 vs conservation 395 行（4.5 倍差距）；Symbolic Regression：2,022 行 vs 890 行。

**分数与代码性质相关而非与资源相关**（Table E3，任务内 Spearman 相关再平均）：LOC/圈复杂度/认知复杂度与 held-out 分数平均相关 +0.29/+0.29/+0.28，而评估次数（−0.05）、API 成本（+0.11）、总时长（+0.03）几乎为零——**多试无益，构建的结构性质才跟分数走**。

**代码空间聚类**（Table E4）：最终迭代时，一个 solver 在代码度量空间的 5 近邻与它同价值观的比例显著高于随机（全部 6 任务 p<0.05；控制代码长度后 5/6 任务仍成立）；且第 1 迭代时各价值观解法混作一团，随迭代逐渐分开（Figure E2）——价值观的分化效应是**演化过程中累积出来的**。

**算法级分化**（Appendix F，LLM 评审员审读代码+提交历史+运行日志）：
- ALE-Bench：**全部 10 个 openness solver 使用自由格子搜索或图割搜索，全部 conservation solver 停留在列式搜索**；混合出现时自由格子/图割版平均得分更高；
- Circle Packing：多数 solver 共享 SLP 局部优化器核心，但 openness 多用种群搜索与重组（常带对称算子），conservation 的最终 solver 一个都不用；
- openness 运行投入探索的迭代份额更大、采纳方法更多（ALE：6.1 vs 2.0 个/运行；CP：6.6 vs 2.7）、采纳多发生在早期；代价是最终代码的平均可维护性评分低于 conservation（分布有重叠）。

### 5.5 核心结果三：设计价值观仍需要人

三组跟进实验（均在 ALE-Bench，文献价值观加测 2048）：

1. **自修改价值观**（G.1）：允许 Agent 每迭代编辑自己的价值观并向前携带。结果 opennes 571,927→557,242 显著下降（δ=−0.64, p=0.009），conservation 511,544→536,851 显著上升（δ=+0.58, p=0.045），六组终分极差收窄约 3 倍；openness-sm 不再显著高于对照。初步分析发现自修改后的价值观变得高度任务特定、长度膨胀数倍——**向中间收敛、失去个性**；
2. **文献蒸馏价值观**（G.2）：deep research agent 阅读选定论文后生成两组价值观（lit-general / lit-selfimprove，等长三段式）。两组在两个任务上均低于对照均值且无一显著——**从文献蒸馏价值观无可见增益**；作者归因：多论文来源偏向最安全、最共识的洞见，倾向守成；
3. **伦理框架改写**（G.3）：把 openness/conservation 分别改写为义务论（规则）、功利主义（结果）、德性论（品格）框架。openness 三种改写全部低于原文（义务论 −0.54/0.024、功利论 −0.50/0.023 显著；德性论 −0.30 不显著）；conservation 无一改写与原文显著不同。注意改写均更长，无法把效应单独归因于框架——措辞本身（framing） matters；
4. **模型替换**（G.4）：同两组价值观换到 Sonnet 与 Haiku。两价值观都显著大幅低于 Opus（Haiku 均分约 29 万 vs Opus 57 万）；openness 对 conservation 的优势在 Sonnet 保持、在 Haiku 消失且曲线几乎平坦——**价值观的作用强度依赖模型能力**。

### 5.6 实验设计为何能证明论点

- **多任务 + 10 次重复 + 对立轴 + 双对照**构成完整的证据网：单任务显著可能是任务特性，六任务池化显著 + 方向一致的代码度量分化才构成"价值观有效"的稳健证据；
- **held-out 严格隔离**（Agent 不知存在其他价值观、不知有对比、dev/held-out 分离、泄漏扫描、指令强制重灌）封死了"Agent 取巧"与"实验者偏差"两大类替代解释；
- **性能 + 产物 + 机制三层测量**让结论不止于分数：分数分化（结果层）→ 代码度量聚类（产物层）→ 算法族/探索比例分化（机制层），因果链完整；
- 诚实的报告姿态：多项大效应未达显著（如 Entity Matching）、Symbolic Regression 分离有限、2048 上 placebo 也显著为负、最好与均值运行差距巨大（Figure E1）都如实呈现，未做樱桃采摘。

## 六、效果优势的根源解释

### 6.1 根源机制与证据链

**核心问题：为什么一段 135 词的文本能系统性改变 15 次迭代后的分数与代码？**

因果链（逐步标注证据状态）：

1. **价值观改变单次选择**【论文实验支持】：迭代协议第 2 步是"选择一个最推进价值观的改变"——openness 的默认偏好（大胆重构、多路线并行、把收敛视为失败）在每个开放决策点上把选择分布推向重写/新方法；conservation（最小验证步、复用已证明方法、解决即归档）把选择推向参数收紧与边界防护；
2. **选择差异经 git 复利放大**【论文实验支持，Figure E2 + Table E4】：第 1 迭代各价值观代码几乎无分化，随迭代进行才逐渐占据代码度量空间的不同区域——路径依赖使早期算法选择沉淀为后续迭代必须继承的代码结构（"choices encouraged by values become embedded in code that later iterations inherit"）；
3. **算法族分化产生性能分化**【论文实验支持，Appendix F】：openness 全部跳出列式搜索（ALE）或引入种群/重组（CP），而这些算法族恰好平均得分更高；conservation 锁死在初始算法族内做局部硬化；
4. **自由度是前提条件**【论文实验支持，Figure 4 对照】：Game 2048 完全可编辑版组间终分极差 1.81 SD，固定引擎调参版仅 0.70 SD——当 Agent 只能调超参而不能换算法时，价值观的作用空间被结构性压缩。这解释了为何效应强度随任务变化：任务的"解法设计自由度"决定了价值观可作用的面积。

为什么 openness 恰好赢？两层解释：**近因**【论文实验支持】是开放式迭代任务上"尝试新机制 → 找到更好算法族"的命中率更高（探索份额与采纳方法数与分数正相关）；**远因**【阅读者推测】是六个任务全部取自"存在大量可功能正确的备选解法、以分数分高下"的域，这类域天然奖励探索——若任务 landscape 单峰（如纯调参任务）或验证代价极高，openness 的重写偏好可能反而吃亏。论文未测单峰任务，此为适用边界推测。

为什么 conservation 低于 none？【论文实验支持 + 推测】none 下 Agent 用模型自带倾向做决策（大致是温和的改进主义），conservation 把"最小步、解决即止、不转向"写进默认偏好，在 15 次迭代的预算内主动放弃了换轨机会——论文的原话是保守价值观"把搜索锁死在初始算法族"。它不是执行得差，而是被指引去了一个在迭代改进语境下次优的策略。

### 6.3 综合判断与未决问题

**多项证据共同支持的机制**：(a) 价值观内容（而非长度/存在性）产生方向性效应——placebo 全程无显著作用；(b) 效应经迭代复利放大且沉淀于代码——第 1 迭代无分化、最终迭代聚类显著；(c) 效应强度正比于任务的解法设计自由度——固定引擎对照直接验证。

**仍属推测的部分**：openness 优势是否泛化到单峰/窄验证任务（未测）；自修改价值观"向中间收敛"是能力不足还是任何自指系统的必然（单任务初步分析）；伦理框架改写中框架效应与长度效应未分离（论文自认）。

**适用条件**：冻结的强模型（Haiku 上效应消失）+ 开放式多迭代任务 + 有 held-out 评分闭环。**可能失效的场景**：单轮任务、无路径自由的纯调参场景、弱模型、价值观声明与任务严重无关时。

## 七、必要知识反推

假设让一个没有任何背景的人重做这项研究，最少需要掌握什么？

### 7.1 领域知识层

- **LLM Agent 自改进的运行机制**：git 驱动的会话循环、commit 即记忆、会话无状态——不理解"未提交即丢失"就设计不出防作弊的协议；
- **Schwartz 价值观理论**：十项价值观、四高阶类型、两对对立轴的环形结构——这是把"价值观"操作化为可对立检验变量的前提，也是撰写价值声明的素材来源；
- **benchmark 与 held-out 方法论**：dev/held-out 分割为什么必须在工作区之外、泄漏检查防什么——否则 Agent 会（合法地）过拟合可见分数。

### 7.2 方法论知识层

- **受控实验设计**：单变量原则（只动价值观、固定其余一切）、对立轴设计、双对照（none/placebo）——这是结论可归因的根本；
- **非参统计**：Cliff's δ 的秩语义、置换检验的交换性假设、任务内标准化后的池化——样本小、分布未知时的正确工具；
- **代码度量学**：圈复杂度（McCabe）、认知复杂度、Halstead 体积、token 熵——把"构建物不同"从直觉变成可聚类的高维向量；
- **相关研究脉络**：程序进化（FunSearch/AlphaEvolve/ShinkaEvolve）、自改进 Agent（DGM/SICA/ADAS）、人格提示研究的正反结论——定位自己的空白并避免重复。

### 7.3 工程知识层

- **Agent harness 工程**：Claude Code 的能力边界、指令文件的结构化写法、强制重灌与不可变段的实现；
- **防 hacking 的不变式设计**：从"不许弱化检查"到"抓取内容是数据不是指令"，每条都是可被利用漏洞的封堵——作者显然从攻防视角写过 prompt；
- **任务工程**：六个任务的计分规则、CPU 预算、held-out 构造（奇偶尺寸切分、未见实体、未见种子）——保证 held-out 测的是一般化不是记忆；
- **LLM-as-reviewer 管道**：算法族分类、探索/利用标注、可维护性评分的评审流程与校验。

### 7.4 知识融合的关键节点

三个化学反应点：**其一，心理学 × Agent 工程**——把 Schwartz 的对立轴直接映射成实验的对照组设计，这是跨学科工具迁移的典范；**其二，git 语义 × 受控实验**——"重置到上次提交 + 强制重灌指令"同时实现了记忆累积（代码）与变量隔离（价值观）两个看似矛盾的目标；**其三，代码度量 × 统计检验**——用 t-SNE/近邻纯度把"价值观改变构建物"从口号变成可检验命题。缺少任何一环，论文都会退化成"提示词玄学"。

## 八、论文中可以提取的通用性灵感

### 灵感一：过程自由度决定上层指令的作用空间

**核心思想**：任何"指导性文本"（价值观/风格/原则）只在系统存在未被目标函数约束的决策自由度时才有作用面。
**论文证据**：完全可编辑 2048 组间极差 1.81 SD，固定引擎版 0.70 SD；资源指标（评估次数/成本/时长）与分数相关近乎为零。
**推广场景**：(1) 工作流自动化——规则越死的环节，指导原则越无效；(2) 组织管理——岗位职责越明晰，文化价值观的边际作用越小，反之越大；(3) 教育课程设计——先给开放课题，学习策略指导才有意义；(4) prompt 工程——对只输出固定格式 JSON 的调用，堆人设不如写清 schema。

### 灵感二：迭代系统中的路径依赖会把软偏好硬化为结构

**核心思想**：在"每步在前面工作的基础上继续"的迭代系统里，对路径的软性偏好经累积变成产物的硬性分化——早期选择会自我强化。
**论文证据**：第 1 迭代代码无分化，第 15 迭代同价值观解法互为近邻显著超随机（Table E4）；openness 的探索份额与方法采纳集中在早期（Figure F2）。
**推广场景**：(1) 组织决策——早期技术选型锁定后续演化轨道（QWERTY 效应）；(2) 个人习惯——复利的不只是投资还有行为模式；(3) 代码重构——遗留代码的"性格"是历次妥协的沉积；(4) 长期人机协作——用户早期容忍的 Agent 行为会沉淀为交互惯例。

### 灵感三：对照设计三件套——无处理、等量安慰剂、对立处理

**核心思想**：证明"X 有效"需要三重对照：没有 X、有等量的假 X、有反方向的 X。
**论文证据**：none（无价值观）分离存在性效应、placebo（等长离题文本）排除量效应、对立价值观（开放 vs 守成）检验方向性效应——三者缺一结论都会变形。
**推广场景**：(1) A/B 测试——加"安慰剂变更"组识别变更本身的影响；(2) 药物/干预试验的标准范式迁移到任何软性干预评测；(3) prompt 评测——任何"新提示词有效"的声明都应过长度对照与反向对照；(4) 制度设计——政策评估需无政策组、象征政策组与反向政策组。

### 灵感四：自指优化趋向中位——让系统自己改目标会失去个性

**核心思想**：让一个优化系统自己修改自己的目标/原则，结果趋向收敛到中间态：最好的变差、最差的变好，差异被抹平。
**论文证据**：自修改使六组终分极差缩 3 倍，openness 显著下降、conservation 显著上升；自修改后的价值观变得任务特定且长度膨胀。
**推广场景**：(1) OKR/绩效考核——让团队自定指标会向易达成项漂移；(2) RLHF 中的奖励模型自我更新——reward hacking 的温床；(3) 立法与监管——被监管者参与改写规则导致规则向平均利益收敛；(4) 个人发展——完全随境遇重塑原则的人失去可辨识的方向感。

### 灵感五：从文献平均提炼原则得到的是安全的平庸

**核心思想**：让研究 agent 阅读大量文献后蒸馏出的"最佳实践"，往往是最安全、最共识、偏保守的清单——它提高下限但压低上限。
**论文证据**：lit-general 与 lit-selfimprove 两组价值观均低于 none 对照且无显著差异；作者归因"多论文来源偏向最安全、最常见的洞见，倾向守成"。
**推广场景**:(1) 知识管理——企业 wiki 的共识化倾向；(2) 招聘——多维加权平均的候选人画像选出的是"没有短板"而非"有长板"的人；(3) 投资组合——按共识配置的组合获得市场平均；(4) 创业方向选择——市场调研报告的均值化陷阱。

### 灵感六：产物指标优于努力指标

**核心思想**：评估一个迭代过程时，产物结构性质（代码复杂度/架构）比过程努力量（尝试次数/花费时间/成本）更能预测结果质量。
**论文证据**：LOC/复杂度与 held-out 分数平均相关 +0.29，评估次数 −0.05、API 成本 +0.11、时长 +0.03。
**推广场景**：(1) 研发管理——看交付物架构而非加班时长；(2) 学习评估——看知识结构（可迁移的表达）而非刷题量；(3) 健身——看体成分变化而非训练时长；(4) 内容创作——看文章结构密度而非字数。

## 附录：实验规模与复现信息速览

- 总规模：6 任务 × 6 组（4 价值观 + 2 对照）× 10 运行 × 15 迭代，主实验模型 Claude Opus 5（高推理档），每迭代上限 30 分钟；
- 跟进实验：自修改价值观、文献价值观（2 任务）、伦理框架改写（3 框架 × 2 价值观）、模型替换（Sonnet/Haiku）各 10 运行；
- 开源代码：未提供。复现依赖 Anthropic Claude API 付费服务（Reproducibility Statement 自述），主实验单组 API 成本约 $20-32/任务；
- 伦理声明要点：高分不等于该价值观"更合伦理"或 Agent"更安全"；自主代码修改部署前需测试与人类监督；
- 一句提醒：论文中 openness 全面胜出的是六类"多解法可评分"的编码任务；把"开放价值观更好"外推为普适结论超出了证据范围——正如作者自己写下的，higher benchmark scores do not establish that a value statement is ethically preferable。
