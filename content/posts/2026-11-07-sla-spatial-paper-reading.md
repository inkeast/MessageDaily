## 一、论文背景

机器人操作要同时做好两件事：**理解语义**（"把蓝色瓶子递给我"）与**在三维空间里精确控制**（抓取位姿、避障轨迹、双手协调）。视觉-语言-动作（VLA）模型把预训练 VLM 与动作专家结合，被视为通才操作策略的基础路径——但论文开篇即指出一个结构性缺陷：

### 1.1 主流 VLA 的"空间短板"从何而来

典型 2D VLA 基座的视觉表征继承自 2D 图文对预训练，**3D 物理知识通常只在任务适配（后训练）阶段才被引入**。作者做了一个非常轻量但有力的验证实验（depth probing）：冻结一个 VLA 的全部参数，只训一个 DPT 头把 VLA 的视觉嵌入解码成深度图——结果显示**仅从 2D 图像学出的嵌入根本解码不出有意义的空间结构**。也就是说，视觉 token 里没有足够的 3D 信息，动作 token 自然难以从中获取精确的三维线索。

### 1.2 给 VLA 补 3D 的三条既有路线与各自的坑

1. **显式 3D 输入**（PointVLA、GeoVLA 等接点云；BridgeVLA 投影多视图）：改变模型架构与输入管线，部署时还需要额外的几何提取。
2. **后训练表征监督**（ROCKET 多层空间对齐、VEGA 监督视觉编码器、Mind-VLA 指令感知对齐；以及本文团队自己的 Spatial Forcing）：空间能力只是"任务级外挂"，没有沉淀为可迁移的基座能力。
3. **3D 感知预训练**（自我中心空间嵌入、3D 标注、物体位姿）：规模远小于 2D VLA 预训练。

另一条现实约束是**数据异构性**：可靠的深度/点云数据噪声大、不完整；机器人传感器类型/位置/标定各异；不少大规模机器人数据集根本没有深度——这使"人人都要 3D 输入"的路线难以规模化。

### 1.3 持续预训练范式的启发

在 NLP 领域，持续预训练（Llemma 数学、AgentFounder 智能体）已被证明能在保留基座知识的同时规模化注入领域能力；机器人领域 ET-VLA、AXIS 也开始用持续预训练换本体/扩数据，但都聚焦**数据来源**。本文的问题因此是：**能不能不改架构、不要求 3D 输入，把空间理解通过持续预训练变成 VLA 基座的迁移性能力，并在下游后训练中继续维持？**

## 二、论文定位和关联工作

### 2.1 谱系一：VLA 基础模型

OpenVLA、π0、RDT-1B、GR00T N1 从跨本体数据学语言条件动作预测；π0.5、RT-H 用语言任务层级增强理解；GR-2 融合视频预训练；RDT2/Xiaomi-Robotics-1 借 UMI 手持采集扩数据。这条线回答"数据从哪来、规模怎么扩"，但**没有规定预训练期间几何表征应当如何被监督**——SLA 恰好补位：在既有基座（π0.5）上做空间监督的持续预训练。

### 2.2 谱系二：3D VLA

- 显式输入派（PointVLA/GeoVLA/BridgeVLA/FALCON）：部署需额外几何提取；
- 训练期监督派（ROCKET/VEGA/Mind-VLA/Spatial Forcing）：只在后训练加 3D，空间理解是"附属能力"；
- 3D 预训练派（SpatialVLA 等）：规模有限。

SLA 的差异化：**站在预训练好的 2D VLA（π0.5）上，用隐式表征对齐做大规模持续预训练**，兼得"基座级泛化"与"零推理开销"。

### 2.3 谱系三：持续预训练

领域适配（BioBERT/FinBERT/Don't Stop Pretraining）→ 能力注入（Llemma/AgentFounder）→ 机器人（ET-VLA 换本体、AXIS 数据扩展）。SLA 是"能力注入"路线在空间智能上的实例，且证明与 Spatial Forcing（同一团队的纯后训练版本）相比有系统性增益。

### 2.4 定位总结

| 维度 | 显式 3D 输入 | 后训练对齐（Spatial Forcing 等） | **SLA** |
|---|---|---|---|
| 空间能力定位 | 部署期输入 | 任务级附加 | **基座级能力（持续预训练）+ 后训练维持** |
| 架构改动 | 需改输入/特征融合 | 训练分支 | **训练分支，推理零改动** |
| 对 3D 传感器依赖 | 部署必须有 | 无 | **无（教师可选利用部分标定/深度）** |
| 数据可扩展性 | 差（深度缺失多） | 中 | **好（RGB 即可，几何标注可选）** |

## 三、问题定义

### 3.1 核心洞察

VLA 生成动作的方式是 x^A_t ~ p_θ(x^A_t | {x^V}, {x^L}, x^A_<t)：**动作以视觉 token 为条件**。因此视觉 token 的空间质量直接决定动作的几何精度——与其改动作头或加 3D 输入，不如**直接监督中间视觉嵌入，让 3D 信息"住进"表征里**。

### 3.2 形式化

- 给定：预训练 VLA 策略（π0.5，PaliGemma 骨干 18 层 + 流匹配动作专家）、多视角 RGB（可选部分相机标定/深度）、冻结外部 3D 感知教师 f_3D（OmniVGGT）、异构机器人语料；
- 优化目标：L = L_action + α·L_align，其中 L_action 为常规动作损失（流匹配），L_align 为视觉 token 聚合特征 z_i 与教师空间目标 y_i 的余弦对齐损失（y = R[f_3D(I)+E]，R 为双线性重采样到 VLA token 分辨率，E 为位置嵌入）；
- 约束：**推理时架构与原 VLA 完全一致**——教师、投影 MLP、层选择门全部只在训练期存在，部署不需要深度图与相机标定。

类比：这像给学徒（VLA）配一位几何师傅（冻结 3D 教师）在旁边"影子教学"——师傅不动手改学徒的动作输出（L_action 照旧），只在表征层面不断纠正学徒"看图的方式"（L_align）；出师后师傅离开，学徒已经学会用几何眼光看场景。

### 3.3 抽象的精妙之处

它把"给 VLA 加 3D"这个模糊需求，收敛为一个**纯训练期的表征正则**问题：不改变输入模态、不改变推理架构、不要求每条数据都有几何标注——三个工程约束全部满足的同时，把空间信息注入到动作生成真正依赖的中间变量（视觉 token）上。

## 四、问题解法

SLA 的完整配方 = π0.5 初始化 + 空间对齐持续预训练 + 异构数据统一 + 自适应层选择 + 状态 dropout + 后训练延续对齐。

### 4.1 组件一：空间对齐目标（训练主损失）

1. 多视角图像 I 输入冻结 OmniVGGT，取最终层表征，加位置嵌入后双线性重采样到 VLA 视觉 token 分辨率，得到逐 token 空间目标 y_i；
2. VLA 第 ℓ 层的视觉 token (ℓ)x_V 经 LayerNorm + 两层 MLP 投影（参数跨层共享）；
3. 聚合后 z_i 与 y_i 做余弦相似度最大化（Eq. 5）；
4. 梯度更新 VLA、MLP 投影器与聚合门；教师冻结。
5. 总损失 L = L_action + α·L_align，α 控制对齐强度。

OmniVGGT 的选择理由（关键工程洞察）：它基于 VGGT，交替帧内/跨视角注意力，其 **GeoAdapter 可以用占位 token 处理缺失标注**——相机内外参、深度都"有什么用什么"，随机多模融合让教师同时暴露在 RGB-only 与几何增强输入下。这正好匹配异构语料"标注不齐"的现实。

### 4.2 组件二：自适应层选择（特征依赖门）

固定选某一层做对齐有两个问题：需要逐层试验；不同数据域的最优层不同（浅层偏视觉细节、深层偏任务语义）。SLA 为每个视觉 token 在每一层学一个 token 级、通道级的 sigmoid 门 (ℓ)g = σ(W_g (ℓ)x_V + b_g)（门参数跨层共享），聚合特征 z = Σ_ℓ (ℓ)g ⊙ MLP(LN((ℓ)x_V))。多层同时被监督，不同深度的线索（深度、通道信息）被自适应地融合进统一空间表征。

### 4.3 组件三：概率状态 dropout

机器人本体状态（关节角/末端位姿）可能变成**捷径**：策略学会"这个状态对应演示里的那条轨迹"，而不是响应场景的视觉变化。SLA 在两个训练阶段都对每个样本独立地以概率 p 丢弃整个状态 token 段（指令与图像保留），推理时恢复正常状态输入。这与空间对齐形成互补：对齐让模型"能看懂几何"，dropout 逼它"必须用几何"。

### 4.4 组件四：异构数据统一（持续预训练语料）

六个公开数据集共约 **171 万 episodes / 14,330 小时**：InternData-A1（630K，合成脚本策略）、AgiBot World Beta（168K，真机双臂）、RoboCasa365-Pretrain（630K，仿真厨房）、RoboCOIN（183K，真机双臂异构平台）、DROID（95K，Franka 真机）、MolmoAct（7.9K，Franka 真机）。统一化处理包括：

- **动作表示**：以末端执行器（EEF）绝对位姿为观测、chunk 级 delta EEF 为目标——绕开关节空间不兼容；坐标系统一（单臂取臂基座为原点，双臂取两臂基座中点；+x 前 +y 左 +z 上）。
- **旋转表示**：delta 旋转用 SO(3) 矩阵复合 ∆R = R_t R_0^⊤ 再取旋转向量 Log(∆R)∨，避免欧拉角直接相减在 ±2π 边界产生的离群值（论文 Figure 3 展示了这些离群点如何压扁归一化后的有效动作范围）；旋转向量三通道**按通道独立归一化**优于共享尺度归一化。
- **降采样与过滤**：脚本化仿真数据按任务保留 0.5%–15% 不等的 episodes（如 InternData-A1 重复度高的任务留 3%、其余 10%；RoboCasa365 的 MimicGen 留 0.5%、复合任务留 15%）；排除灵巧手与底盘运动数据；用动作统计剔除异常速度；去静止 idle 帧；并排除会造成评测泄漏的下游基准数据。

### 4.5 组件五：两阶段一致的训练流程

- **持续预训练**：36k 步、全局 batch 4,608，学习率 1k 步预热到 5×10⁻⁵、30k 步余弦衰减到 1×10⁻⁵后恒定；48 张 H100 约 110 小时。
- **后训练**：按基准分别配置（LIBERO-Plus 512×30k、RoboTwin 256×30k、RoboCasa-Panda 64×60k、RoboDojo-Real 512×40k、真机 64×20k），**空间对齐在后训练中保留**（消融证明两阶段都用最优）。
- **记忆机制**（仅 RoboDojo-Real 长程任务）：把主相机历史帧（初始帧 + 前 8 秒每秒 1 帧，共 9 帧）作为额外图像输入，同一 SigLIP 编码器编为 token；记忆帧不参与空间对齐分支。

### 4.6 推理形态

与 π0.5 完全相同：无教师、无投影器、无门、无深度/标定输入、无额外计算。这是方法可工程落地的前提——持续预训练的收益"免费"叠加到任何已有 π0.5 部署管线上。

## 五、评估指标与实验证据

### 5.1 指标体系

- 主指标：各基准成功率（SR，%）/ RoboDojo 的 Score（0–100 部分进度分）+ SR；
- 稳健性指标：LIBERO-Plus 七个扰动维度（相机/机器人/语言/光照/背景/噪声/布局）、RoboTwin Clean2Random 域随机化；
- 数据效率指标：RoboCasa-Panda 的 50 demos/task 对比他人 300–3,000 demos；
- 消融指标：数据比例（5/25/50/100%）× 两阶段对齐开关的 4 配置、固定层 vs 自适应层、状态 dropout 概率（0–100%）、四种旋转表示、相机标定有无。

### 5.2 基准一：LIBERO-Plus（10,030 rollouts，七维扰动）

SLA 总分 **87.4%**：超 π0.5（84.4%）3.0pp、超自家纯后训练版 Spatial Forcing（85.1%）2.3pp、超 robot-only Qwen-RobotManip（87.1%）0.3pp。**相对 π0.5 在全部七个维度上均提升**：噪声 89.0→95.4、背景 94.1→98.0、光照 96.2→98.8（全场最高）、布局 84.5→86.2 等——空间知情表征在观测受扰时保住了任务相关的场景结构。

### 5.3 基准二：RoboTwin 2.0（50 个双臂任务，每任务 100 trials）

Clean2Clean 86.0%、**Clean2Random 72.3%**、平均 79.2%。Clean2Random 超 π0.5（46.0%）**26.3pp**、平均超 20.9pp；相对表中最强对手 ME-Dex-1.0（平均 78.9%），Clean2Random 高 4.2pp（其 Clean2Clean 89.6% 略高）；相对 Spatial Forcing 平均高 10.5pp——持续预训练阶段贡献显著。附录逐任务表显示强弱差距：Grab Roller/Shake Bottle 双双 100%，而 Place Cans Plasticbox 从 96% 掉到 40%（域随机敏感任务）。

### 5.4 基准三：RoboCasa-Panda（24 个厨房任务，3 种子共 3,600 trials）

**50 demos/task 达 68.4%**，为表中最优：超同样 50 demos 的 Cosmos Policy（67.1%）1.3pp、Spatial Forcing 0.8pp；超过用 300 demos 的 GR00T-N1.5（64.1%）、HAMLET（66.4%）乃至 3,000 demos 的 DP-VLA（57.3%）。10/24 任务 >80%，TurnOffMicrowave 100%。

### 5.5 基准四：RoboDojo-Real（三本体联合后训练单一策略）

总体 **Score 42.3 / SR 33.9%**：超 π0.5（22.9/12.8）**19.4 分 / 21.1pp**，超最强对手 InternW0-∆（38.9/31.7）3.4 分 / 2.2pp。Piper 本体上双指标第一（60.3/55.0）；ARX X5 上居第二。附录 RoboDojo-Sim 上平均 16.4/12.0% 亦为最高（超 π0.5 5.0/5.1pp），其中 Memory 维度 26.2/25.8% 仅次于 SimpleMemVLA。

### 5.6 真机八条件（A–H，双臂 Piper + 单臂 Franka，每条件 50 个物体实例）

| 条件 | 能力 | π0.5 | Spatial Forcing | SLA |
|---|---|---|---|---|
| A 双手递蔬菜 | 双臂协调 | 74 | 84 | **94** |
| B 捡起被人扔出的水果 | 位置泛化+恢复 | 52 | 66 | **82** |
| C 抓取被人移动的水果 | 动态响应 | 42 | 58 | **76** |
| D 另一机器人抓蔬菜（100+10 demos） | 少样本跨本体 | 48 | 62 | **78** |
| E 抓水瓶（训练场景） | 基线 | 90 | 94 | **98** |
| F 静态变高度桌面上抓手表 | 空间泛化 | 68 | 64 | **84** |
| G 升降桌上抓手表 | 动态几何 | 44 | 60 | **78** |
| H 按指令抓未见过的黑胶带 | 指令跟随 | 60 | 56 | **80** |

**八个条件全部第一，平均 83.8%，超 π0.5（59.8%）24.0pp、超 Spatial Forcing（68.0%）15.8pp。** 值得注意的细节：A→B 的性能衰减 SLA 只有 12 分（π0.5 衰减 22 分）；F 上 Spatial Forcing（64）反而低于 π0.5（68）而 SLA 达 84——说明纯后训练对齐的收益并不均匀，完整配方才稳。

### 5.7 消融实验（RoboTwin Clean2Random）

**数据规模 × 两阶段对齐（Table 6）**：

| 持续预训练对齐 | 后训练对齐 | 5% 数据 | 25% | 50% | 100% |
|---|---|---|---|---|---|
| ✗ | ✗ | 43.8 | 46.5 | 46.1 | 48.2 |
| ✗ | ✓ | 45.6 | 53.4 | 55.3 | 57.1 |
| ✓ | ✗ | 46.6 | 52.0 | 58.4 | 63.2 |
| ✓ | ✓ | **49.2** | **60.5** | **67.4** | **72.3** |

三个关键读数：①只堆数据不对齐，100% 数据也只从 43.8 到 48.2（中间还非单调）；②两阶段全开在**每一个**数据比例上都最优，且从 5% 的 49.2 涨到 100% 的 72.3（+23.1pp）——数据与空间监督是**乘性**而非加性关系；③满数据下单阶段对齐（63.2/57.1）都比双阶段（72.3）低 9.1/15.2pp。

**自适应层选择（Table 7）**：固定层 1/6/12/18 的平均 SR 分别为 51.7/54.0/75.7/71.3（最优固定层是 12，且 18 层反而下降——"越深越好"不成立）；自适应融合 79.2，超最优固定层 3.5pp、Clean2Random 超 5.0pp。

**状态 dropout（Table 8）**：0%→38.1、25%→**79.2**、50%→53.9、75%→61.9、100%→56.7。非单调且 25% 显著最优——完全不给状态（100%）同样次优，说明要在"逼模型看图"与"保留本体感知信息"之间取平衡。

**旋转表示（Table 9）**：旋转向量 79.2 > 四元数 74.3 > 欧拉角 65.5 > Rot6D 62.9（四种均在 SO(3) 复合框架下比较，隔离了"表示"这一个变量）。

**相机标定（Table 10）**：无对齐 31.8 → RGB-only OmniVGGT 教师 42.8 → 带标定教师 46.0（+3.2pp）；且标定只喂给训练期教师、部署不需要。

### 5.8 实验设计如何支撑主张

- 每个基准都同时给 π0.5（同底座不对齐）与 Spatial Forcing（同方法只缺持续预训练）两条对照线，把"持续预训练阶段"的边际贡献干净分离；
- 数据 scaling 的 4×4 全因子矩阵证明了"空间监督×数据规模"的交互，而非单一配置的侥幸；
- 真机八条件覆盖双臂协调/静态空间/动态/跨本体/指令跟随五个正交能力轴，且用 50 个独立计分物体实例控制评测方差。

## 六、效果优势的根源解释

### 6.1 根源机制与证据链

**根源一：动作精度受限于条件表征的空间质量，监督"条件"比改造"生成器"更根本。**

因果链：动作 token 以视觉 token 为条件（Eq. 1）→ depth probing 证明 2D 预训练的视觉嵌入几乎不含空间结构 → 空间对齐把 3D 教师的信息注入视觉嵌入 → 动作头从表征中取到几何线索 → 空间敏感指标提升。**论文实验已支持**：depth probing 的负结果 + 各空间敏感条件（F 变桌高 84 vs 68、G 动态桌 78 vs 44、B 位置恢复 82 vs 52）的大幅提升。

**根源二：空间能力必须沉淀在基座（持续预训练），后训练修补为时已晚。**

因果链：后训练数据量小且分布窄 → 只在后训练加对齐时，表征的空间重塑受限于小数据与任务特定分布 → 持续预训练在 171 万 episodes 上重塑表征后再由后训练"维持" → 泛化面（Clean2Random、扰动、跨本体）显著更强。**论文实验已支持**：Table 6 中满数据下"仅后训练对齐 57.1 vs 双阶段 72.3"；真机上 Spatial Forcing 在 F 条件甚至低于 π0.5，而 SLA 稳定最优。

**根源三：状态捷径会绕过视觉证据，必须显式阻断。**

因果链：本体状态与演示轨迹强相关 → 策略可记忆"状态→轨迹"映射而无视场景变化 → 遇到扰动/动态场景（物体被移动、桌面升降）时失效 → 状态 dropout 随机切断该捷径，迫使模型消费视觉 token（其中已含对齐注入的几何信息）→ 动态/扰动条件增益最大。**论文实验已支持**：dropout 0%→25% 平均 SR 从 38.1 到 79.2；C/G 两个动态条件相对 π0.5 提升 +34pp（C、G 均为最大增幅类条件之一）。**阅读者推测（标注）**：25% 最优的非单调性可能反映状态信息本身在精细控制（如夹爪开合时刻）中不可完全替代，论文未进一步拆解各控制子技能对状态的依赖差异。

**根源四：异构数据的价值取决于"统一表示"，而统一表示的关键坑在旋转。**

因果链：跨本体联合训练必须统一动作空间 → EEF 位姿+统一坐标系解决平移部分 → 欧拉角直接相减在 ±2π 产生离群值、污染归一化 → SO(3) 复合 + 旋转向量消除离群 → 四种表示的受控对比（79.2 vs 62.9–74.3）确认旋转向量最优。**论文实验已支持**（Figure 3 的分布离群可视化 + Table 9）。

### 6.3 综合判断与未决问题

- **多证据共同支持**：①表征级监督优于输入级改造（与 ROCKET/VEGA/Mind-VLA 一致，SLA 是其基座化）；②两阶段 > 单阶段 > 无对齐的排序在所有数据比例稳定成立；③状态捷径的存在有独立文献支撑，25% dropout 的干预有效。
- **仍属推测**：25% 这一最优点是否随任务/本体变化；门控学到的层贡献分布与"浅层几何/深层语义"直觉的具体对应（论文未可视化门值）。
- **适用边界**：长程任务上 SLA 的 RoboDojo-Sim Long-Horizon 维度（22.3/11.9%）低于多数基线——空间对齐不解决长程规划，需要记忆机制补位；Piper X 本体成功率仍低（10.0% SR），跨本体迁移并非全解。
- **可能失效条件**：当任务主要依赖力控/触觉而非视觉几何时，视觉空间对齐的收益可能收窄；当深度/标定完全缺失且场景纹理贫乏时，教师自身的空间表征质量会制约对齐上限。

## 七、必要知识反推

### 7.1 领域知识层

- **VLA 模型的信息流**：视觉/语言 token 如何条件化动作 token、动作专家（流匹配）的输出形态——不知道"动作吃视觉 token"这一结构，就找不到监督视觉嵌入这个杠杆。
- **机器人数据异构性的具体形态**：关节空间不兼容、坐标系约定差异、深度/标定覆盖率不齐——不理解这些就无法设计 EEF 统一与"部分几何标注可用"的教师选型。
- **表征探测方法**：linear/depth probing 范式——这是验证"表征里有没有 3D"的最低成本手段。

### 7.2 方法论知识层

- **持续预训练范式**：学习率预热-余弦衰减、大 batch 累积、如何在注入能力的同时保住基座知识。
- **知识蒸馏/表征对齐**：余弦对齐损失、教师冻结、投影头设计；VGGT/OmniVGGT 类几何基础模型的能力边界与 GeoAdapter 的占位 token 机制。
- **SO(3) 旋转与表示学习**：欧拉角卷绕、旋转向量（log 映射）、四元数、Rot6D 的数值性质——旋转表示消融的全部背景。
- **门控融合**：Gated Attention 式 token/channel 级门——自适应层选择的直接原型。

### 7.3 工程知识层

- **大规模分布式训练**：48×H100、全局 batch 4,608、梯度累积、110 小时的预算规划。
- **数据工程**：按任务分级的降采样率（0.5%–15%）、异常速度过滤、idle 帧剔除、评测泄漏防控——这些"脏活"决定持续预训练的成败。
- **评测协议设计**：多 seed、逐物体计分、按评测集数加权平均——控制真机评测方差。

### 7.4 知识融合的关键节点

1. **问题转译节点**：把"机器人不会 3D"转译为"视觉 token 缺空间信息"（depth probing 验证），再转译为"训练期表征对齐"——三次转译链条是全文灵魂。
2. **范式嫁接节点**：把 NLP 的持续预训练范式（能力注入）嫁接到 VLA 的空间能力上，并意识到对齐损失与 π0.5 架构的兼容性使这一嫁接"零推理成本"。
3. **反直觉细节节点**：状态 dropout 的引入——大多数人给 VLA 加信息（3D 输入、状态增强），这里反而"藏信息"逼出视觉依赖；25% 的最优值只有实验能告诉你。

## 八、论文中可以提取的通用性灵感

### 灵感一：能力的正确注入时机在预训练，不在后训练

- **核心思想**：一种能力若要可迁移，应当在基座表征形成期注入（大而杂的数据），后训练只做维持与适配；任务级注入只能得到任务级能力。
- **论文证据**：满数据下双阶段 72.3 vs 仅后训练 57.1；Spatial Forcing 在真机 F 条件（64）低于 π0.5（68）而 SLA（84）稳定。
- **推广场景**：代码模型的测试意识注入（预训练对齐测试信号 vs 微调时才学）；多语言模型的推理能力预训练；推荐系统的因果去偏作为预训练目标；Agent 的工具使用先验。

### 灵感二：监督"条件表征"而非改造"生成器"

- **核心思想**：当输出以中间表征为条件时，用辅助对齐损失提升该表征的质量，比为输出端加装模块更根本、且推理零开销。
- **论文证据**：对齐分支训练期即弃，推理架构与 π0.5 相同，却拿到 +24.0pp 真机增益；depth probing 证明被监督的表征确实获得了结构。
- **推广场景**：检索增强 LLM 对检索嵌入做事实一致性对齐；语音合成的声学表征对齐说话人向量；自动驾驶对 BEV 特征对齐高精地图；医学影像报告生成对齐解剖结构嵌入。

### 灵感三：教师应当容忍"标注不齐"

- **核心思想**：规模化监督的最大敌人是标注覆盖率；选教师（或设计教师）时"有什么用什么、缺了用占位符"的柔性输入，比强求完整标注更能吃到长尾数据。
- **论文证据**：OmniVGGT 的 GeoAdapter 用占位 token 吸收缺失标定/深度，随机多模融合让 RGB-only 也可用；标定可用时再 +3.2pp。
- **推广场景**：多模态医疗模型的"部分检查可用"训练；半结构化日志的知识蒸馏；传感器降级工况下的工业质检；众包标注质量不齐的指令微调。

### 灵感四：主动切断捷径，逼模型使用你要它学的信号

- **核心思想**：若存在更易拟合的捷径（状态→轨迹记忆），新注入的能力（视觉几何）不会被真正使用；以概率丢弃捷径输入是零成本的"强制消费"手段。
- **论文证据**：状态 dropout 0%→25% 使平均 SR 从 38.1 升至 79.2；动态条件（C/G）增益最大。
- **推广场景**：图像分类中丢颜色通道逼模型学形状（防背景捷径）；LLM 训练中屏蔽表面统计防止长度偏置；推荐系统丢弃流行度特征逼出兴趣建模；学生模型训练丢先验答案防记忆。

### 灵感五：旋转（周期量）的差分必须走流形复合

- **核心思想**：对周期性/流形上的量求 delta 时，先在原始群上复合再映射到表示（SO(3) 复合→log 映射），而不是在表示空间直接相减——否则边界处产生虚假离群值毒化归一化。
- **论文证据**：欧拉角直接相减在 ±2π 产生离群点压缩有效值域（Figure 3）；SO(3) 复合下旋转向量 79.2 显著优于其他表示。
- **推广场景**：角度预测任务（风向、时钟）；周期时间特征；经纬度差分走大圆距离；相位类信号（通信、声学）的 delta 编码。

### 灵感六：数据混合要按"行为多样性"而非"体量"配比

- **核心思想**：高度重复的合成/脚本数据体量大而信息量低，按任务分级降采样让各源处于可比量级，防止少数场景主导训练。
- **论文证据**：InternData-A1 重复任务留 3%、RoboCasa365 MimicGen 留 0.5% 等分级保留率；配合 Table 6 显示配比后的数据扩展与空间监督形成乘性收益。
- **推广场景**：爬虫语料的去重配比；自动驾驶仿真场景的多样性采样；不平衡数据的课程设计；Agent 轨迹数据的行为聚类下采样。
