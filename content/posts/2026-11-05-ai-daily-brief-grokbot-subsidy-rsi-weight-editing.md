## 先说结论

主持人把本期三组新闻串在一条暗线上：**AI 的持续加速（他反复用的词是 RSI，递归自改进）正在撞上「谁为智能付钱」的商业模式拷问**。起点是马斯克一条看似随口的帖子——Grokbot 的服务成本相对收入「高得不可持续」，配合悄然上线的用量限额，被市场空方当成补贴时代终结的实锤，也点燃了「个人代理这个品类本身是否成立」的旧争论；中段是仍在下注的另一方（Meta 把 Muse 押在中小企业上）和两个首次给个人代理「性价比」标价的新基准（SemiAnalysis 的 GDPX、OpenAI 的 LifeVal）；终点是当天社群最大新闻——MIT 团队证明 GPT-6 Astra 能直接读改小模型权重，把「AI 建 AI」从口号变成有机制、有复现的学术结果，而 Anthropic 同一时期在 S-1/A 修订里写下「可能即将触及 RSI 危险阈值」。NLW 自己的收束判断带怀疑色彩：模型变强与收入增长之间并没有人们直觉里的那条直线，瓶颈在采用而非能力；而对 RSI，市场还在纠缠「来没来」，只有安全主义者认真描述过「来了之后世界长什么样」。

## Grokbot 限流：一条帖子如何引爆「补贴终结」叙事

事件本身很小：周末有 Grokbot 用户抱怨开始撞上从未有过的用量限制，有人请求重置，马斯克回应称「Grokbot 的服务成本相对收入高得不可持续」。主持人强调，马斯克没给任何细节，用户走哪个套餐触限也不清楚——但对盯盘的人，尤其是空方，这条帖子「像炸弹一样」落下，因为马斯克过去两周的话构成了一组矛盾：几天前他刚说「随着超级智能富足的到来，为遥远的未来省钱毫无意义」（Bruno Lemos 等人立刻翻出对比）；几周前他还夸过「从没见过增长像 Grokbot 这么快的东西，而且没有免费档，说明用户得到的价值超过他们付的钱」——Benjamin DeCraker 把两条拼在一起：两周前 Grokbot 还是 xAI 收入增长的明星故事，现在变成亏损且不可持续。

比「话术矛盾」更伤的是套餐信任。用户 Shrek 的披萨比喻被主持人整段引用：我一直买你的 12 寸披萨，某天打开盒子变成 6 寸，你告诉我成本太高、12 寸从此就是 6 寸，没吃饱怪我选错了尺寸——「要降成本可以，提前说；披萨好吃我可以买两三个，不吃我也可以走，但选择权在我，你不能一边照卖 12 寸一边悄悄缩成 6 寸还不通知，然后回头说我选错了订阅。」也有人立刻看到竞争含义：Alex Michael 称这对 Dots 和 Duet 是「大胜、很可能把大量用户赶回它们那里」；Hermes 的开发方（转写作 News Research，疑为 Nous Research，见校正表）随即贴出 Grokbot 用户迁移到 Hermes 的具体指引。更结构性的质疑来自 Open Code 的 Dax：这正是我们当初不看好这种产品形态的原因——人们不愿为它付费，所以它只能是漏斗顶部的引流品，可「引流到什么，目前还看不出来」。

主持人提醒这不是新话题：2025 年秋天的泡沫大辩论就围绕 OpenAI 免费用户的承载成本展开；本节目 4 月底还做过「补贴时代终结」专题。这次空方反应迅疾——Eric Sky 说「马斯克要弃赛了」；以看空科技闻名的 Nick Huber 断言「音乐要停了，找好椅子：VC 钱烧完→价格大涨→用户流失→估值崩塌」；Hedgey Markets 称这是补贴终结的又一标志，并引用夏季一项测算（主持人注：疑指 SemiAnalysis）：200 美元的 ChatGPT Pro 套餐按标准 API 价格跑满一个月，成本约 1.4 万美元。主持人还补了一个背景：马斯克有煽动市场恐慌的前科——上月 CoreWeave 债券大跌后他只回了一个「Yikes」被财经媒体广为传播，10 月又说「债市对任何没有独立于 AI 数据中心的实质收入的公司几乎完全关闸」——所以「四维象棋」（故意砸盘以便低价收购或打击对手）的猜测也不乏人，但主持人明说：现在无法知道。

## 主持人的账本：谁在为智能付钱

NLW 的立场自陈「远非 AI 空方」，但他认为空方的存在本身是健康信号——人人都迷 Anthropic 和 OpenAI 才危险，泡沫概率某种程度上与空方声音的大小成反比；当然也要分辨质量，常年看错还不断移动门柱的 perma-bear 未必值得跟。他自己对「大家按 API 自然价格付费」的判断是：变化没那么大，订阅用户会分成两类——一类是带效率折衷的模型对其用途足够好、留在 20–30 美元档；另一类从套餐里获得足够价值、愿意把智能开销当作生意成本照付。他拿自己举例：到处跑的 API 加高级套餐，「值不值毫无悬念」——溢价成本仍远低于等价的人力（而那些人你原本既请不起也管不过来），所以这是以前不会发生的净新增支出。他观察到 2026 年进入 agent 时代后，相当比例的收入实际来自已经在用 API 付费的重度用户。由此他指出两个空方论点其实互相打架：一边说转 API 计价后人们会因不值而弃用，一边说市场过度集中于少数重度用户——真正值得追问的是 Chema Palajapatia（转写名）那条更细的中间路线：**这些重度用户本身有几成还在被 VC 补贴**。答案目前无人知晓。

## 还在下注的人与两个新基准

即便 Grokbot 收缩，重注个人代理的仍大有人在。a16z 的 Olivia Moore 认为 Meta Muse 真正的故事甚至不在消费者端，而在中小企业：「Muse for SMB 可能是当前消费 agent 里最被低估的故事」——Meta 系应用 36.4 亿日活带来的近乎无限、极低成本的分发，加上超过 5 亿中小企业在用 Meta 做营销；如果 Meta 给这批商家开放 agent 的可发现性（Q3 财报电话会与此前博客都已预告：为 SMB 建 connectors 生态、Muse 分析打通 Meta 账户加 QuickBooks、Canva、Stripe），对能超定向触达「急迫购买需求」用户的本地商家可能是巨大利好。她的收束比喻：Muse 可能成为中小企业的「神经系统」，让 Meta 逐步捕获它们越来越多的经营活动。（主持人此前多次报道过 Meta 靠 Muse 在 AI 竞赛里重获立足点，此为节目引用口径。）

同一周出现的两个基准第一次给这个品类标了价。SemiAnalysis 的 GDPX 面向「有经济价值的任务」（芯片设计、金融、生物）：Opus 5.5 以 12% 的得分成为「驱动 agent 价值最高」的模型，但单任务 51 美元；Gemini 4 Carbon 以 10.9% 居次、单任务仅 16 美元——Chubbyonx（转写名）直接算账：差 1.1 个百分点、便宜约 4 倍，性价比 Gemini 4 大胜；主持人补充，这正呼应各家实验室今年的共同课题——用更高效的模型把个人代理的成本打下来，以及新训练技术可能带来的「更强更小」模型。OpenAI 的 LifeVal 则测日常生活中的个人代理价值（找托育、办政务、做预算、备考、改食谱、订菜、设计训练计划等），面向「每周超 10 亿 ChatGPT 用户」：官方评分显示能力从 GPT-5.2 的 49.3% 稳步升至 GPT-6 Astra 的 80.6%。主持人强调 OpenAI 的表述——他们在以免费用户为对象测量并「爬山」（hill-climbing）优化这些日常任务，并援引编码 agent 的先例：「一项能力一旦被测量并成为强化学习目标，就会大幅进步且变得更便宜」。社群反应两极：Fraser X 称「忘掉那些花哨基准，LifeVal 对 99% 的用户可能是最重要的基准」；Simon Smith 则嗅到发布节奏——「这像是向公众发布个人代理前夕才会发的帖子」，并留下一个对赌问题：ChatGPT 先变成更好的个人代理，还是 Muse 先铺开语音模式——「ChatGPT 的语音模式很棒，但 Muse 是更好的个人代理」。

## MIT 权重编辑论文：社群当天最大新闻与它的分裂反应

第三条故事被主持人称为「一眼扫过 AI 社群就能确定是当天最大的新闻」：MIT 研究者（节目称由博士生 Rukiya Takahi 主导，名字依转写存疑）发表论文，证明 GPT-6 Astra 能读取并直接调整小模型的权重来改进其表现。实验对象是 Qwen3.5 0.8B，目标推理能力：Astra 只改了 0.016% 的权重，就把其数学基准成绩提升 6 倍、指令遵循提升 3 倍。论文摘要的原话：「前沿 LLM 出人意料地擅长原生读写神经网络权重，远超我们对人类或常规算法的预期」「仅凭权重，GPT-6 Astra 就能说出一个网络被训练来做什么；不需要任何环境反馈，它就能从零写出胜过 PPO 训练一亿步的小型游戏网络」。作者描述的修复过程极其直白：「我们就是让 Astra 把 Qwen3.5 0.8B 的数学变好。Astra 看到 Qwen 卡在推理循环里——这是 Qwen 自己的模型卡都警告过的已知问题。给它 50 次练习题上的前向传播预算，它定位了成因并把病因编辑掉了。全程没有梯度、没有训练。」该论文的八个实验细节与边界，本站已在 Matthew Berman 同期视频的成文里逐条拆解（见文首互链），此处不重复。

社群反应瞬间分裂。兴奋侧：Yu Chenjin（转写名）称之为「神经网络的基因编辑，比蒸馏还酷」；开发者 Nick Dobos 认为论文「把真正的头条埋了」——修 bug 式改权重固然酷，但「从零手写全新权重」才是大事，「如果这成立，训练大模型还需要吗？这是不是真正的 RSI？」谨慎侧：Ethan Mollick 教授说「看起来很酷，但等复现」——而复现很快就来了：Google 高级研究员 Alex Krenzel（转写名）复现结果并称「这是只出现在最新一代模型上的阶跃式涌现能力」，同时给出主持人全文引用的限定：被编辑的模型非常小（其实验中的 Breakout 网络仅 20,486 个参数，前沿模型超过一万亿），性质上更像 2010 年代「这个神经元看到狗就亮」的可解释性研究被推到超出人类能力的规模——人手做过小模型、工具辅助做过稍大模型，现在是推理能力让模型「亲手」做更大（但仍小）的模型；下一步显然是测试运行时自我改进，他认为当前模型还做不到、但几代之内可能可行。唱反调的还有微软研究的 Wei Zhu：结果有趣，但「标题有点过热」——6 倍数学提升来自修掉循环 bug，不是提升一般数学能力。Voyage AI 的 Chandan Singh 则反向开炮：质疑过热的其实是在「低卖」——「我们做过类似实验，Claude 模型能从零写出完整可用的神经网络权重」。Tenbris（转写名）的判断被主持人放在结尾前：「强烈预期这类事情一年内发生，并成为 RSI（可能是相当陡峭的 RSI）的驱动因素之一。可解释性是极度双刃的：擅长优化（广义）的模型，也会擅长优化自己。」

## RSI 从口号变成监管语言

论文之外，RSI 同一周以另一种身份出现：合规与招股文件里的风险语言。AI 新闻聚合者 Andrew Curran 注意到 Anthropic 周一上午在 S-1/A 修订中新增的表述：内部估计显示公司「可能即将触及 RSI 危险阈值——可归因于 AI 的急剧加速的进展，一年取得的进展相当于 2018–2024 基线的两年」，并称正考虑更新负责任扩展政策（RSP），因为他们「不预期能够在没有实质人类监督或理解的情况下，安全地让 Claude 完全自主地设计并构建下一代又一代前沿模型」——新政策的目标是把前沿模型研发的控制权留在人类手里，而不是把研究整个交给模型。主持人点出语境：Anthropic 临近 IPO，金融圈正在把 RSI 当作 IPO 定价的关键变量之一。《华尔街日报》刊出 Anthropic 的图表——AI 现已引领 26% 的研究——标题写「AI 领域最聪明的人相信这是世界上最重要的图表：AI 开始构建更好的 AI，自我改进正在加速研发，并吓坏所有人」；图表由 Anthropic 联合创始人 Jack Clark（他称 RSI「可能是世界上最重要的技术趋势」）九月基于八月数据首发，周末被前白宫 AI 负责人 David Sacks 转推放大——Sacks 还补了一句「那是八月的数据，现在十月了，谁知道到了哪一步」。另一侧，Alphabet 财报电话会上 Pichai 的表述被引为注脚：「我们已经到了 AI 帮我们提高训练与发布速度的阶段，我预计未来 12 个月将因 RSI 而继续加速。」

## 收束：模型更强 ≠ 收入直线

NLW 对整场讨论的元批评是：所有人都默认「更强的模型＝更多采用＝更多收入」，却没人觉得需要论证。历史证据只有一条——真正的能力阶跃确实解锁过大规模采用（Opus 4.5 那一跳开启了我们至今身处的 agent 编码时代）；但在没有新阶跃出现时，他认为证据并不支持采用瓶颈在模型能力：企业消耗掉的智能只占它们可能消耗的极小一部分，原因不是模型不够强，而是「惯性是真实的、企业系统是笨重的、采用就是很难」。同一事实可以写成空头版（这么强的力量都没人用）或多头版（只是还没用起来）。所以无论投资者愿意怎么给自己讲 RSI 与收入的故事，模型进步到收入之间未必有直觉里那条直线；值得肯定的进展是，至少有些投资人开始问「有了 RSI 之后会怎样」，而不再只是「RSI 来了没有」。他最后一句刺得漂亮：眼下唯一对「RSI 之后的世界」给出完整想象的，是那些被它吓到、认为它应该被定为非法的安全主义者——你可以不同意他们，但至少他们在描述那个世界。而整个场域可能正在重演 AGI 这个词的老路：花在定义它、争论它来了没有的注意力，已经超过花在理解它到来意味着什么上的注意力。

## 机制 → 影响 → 启发

1. **补贴信号 → 信任与迁移链**：厂商为抢用户把套餐定价在成本之下（补贴时代）→ 用量增长触发限额/缩水 → 感知背叛（12 寸披萨变 6 寸）驱动用户流向 Dots、Duet、Hermes 等对手 → 二阶影响：全行业被迫回答「自然价格下谁还在用」。观察指标：各家是否跟进限额、API 收入占比、重度用户被 VC 补贴的比例（Chema 之问）。证据：Hedgey 引用的 Pro 档 1.4 万美元/月成本测算、2025 秋泡沫辩论。
2. **基准 → 强化学习目标 → 成本曲线**：能力一旦被测量（LifeVal、GDPX）→ 成为 RL 爬山目标 → 「大幅进步且更便宜」（编码 agent 先例）→ 个人代理的单位经济性改善反过来缓解补贴压力。启发性在于基准不只是记分牌，而是优化方向的指挥棒——品类价格战会沿着基准指标打。
3. **权重编辑 → 小模型即改即用 → RSI 机制化**：大模型读改小模型权重（0.016% 权重、数学 6 倍，且已复现、限定在 ≤0.8B 小模型）→ 端侧模型按任务即时强化、无需重训 → 「训练还需要吗」成为开放问题；同时能力边界同样清晰（修 bug≠更强，微软研究者的批评）。观察指标：能否从 2 万级参数扩展到前沿规模、运行时自我改进何时可行（Krenzel：几代之内）。
