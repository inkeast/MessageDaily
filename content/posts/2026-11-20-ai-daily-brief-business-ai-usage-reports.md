# 用量涨36%、花销只涨2%：三份报告里的企业AI真实账本

## 先说结论

The AI Daily Brief 这期正片，把几天内接连撞见的几份企业 AI 研究——Ramp AI Index（10 月与 11 月两期）、Databricks 周一刚发布的 AI Index、Arcana Research 第一份企业 AI 年度研究——放在一张桌上读。主持人 NLW 的核心判断是：它们讲着同一个故事——用量的增长正在跑赢支出的增长，企业正学着在价格战里当买家。节目引用的 Ramp 数据称，过去一个月企业 token 用量增 36%，支出只增 2%；同口径下 OpenAI 与 Anthropic 的每百万 token 均价 10 月约降 21%。驱动力不是企业集体投奔更便宜的中国模型，而是这些模型的存在本身逼着大厂降价（主持人推断，兼有厂商自身的效率动机）；换供应商日益常态化——节目引用 Databricks 数据称，其 Unity Gateway 客户中只用单一供应商的占比从 7 月的 64%，到 11 月初翻转为 72% 用两家以上。结果是买方市场：Anthropic 拿走企业端势头，支出向前 1% 高度集中（Ramp 口径约为中位数的 625 倍、Databricks 口径约 281 倍）。报告间也有分歧——token 支出增速年化约 22% 的显著放缓、agent「热度第四、落地垫底」——但主持人认为趋同远比分歧有力；留给企业的最大启示是：你手里的谈判筹码，多半比你实际用出来的多。

## 四个来源、同一个故事：这期节目在讲什么

正片的选题过程本身就是个信号：主持人说，几天之内接连撞见四份讲着「相当相似故事」的材料——Databricks 周一刚发布的新 AI Index、Arcana Research 的第一份企业 AI 年度研究、以及约一周前发布的 Ramp AI Index 11 月期连同其 10 月期（三份报告、四份材料，故称「四个来源」）。叠在一起，它们描绘的是一个「企业手里的选项多得多、而且越来越习惯四处流动去拿最好交易」的商业 AI 环境。

与本篇最相关的前情，是本站当天发布的同频道旧文《[公司变成一台系统：AI 原生公司的七个做法](https://inkeast.github.io/MessageDaily/posts/2026-11-20-ai-daily-brief-ai-native-7-practices/)》：那一期谈最成熟的公司在组织内部怎么用 AI（上下文、触发器、验证、问责），这一期谈钱和用量的数字形态。两篇合看，恰好是 2026 年 11 月企业 AI 的「做法」与「账本」两个切面——而账本上最扎眼的，恰恰是那些把做法跑通了的少数公司（详见下文「支出两极」）。

本集前半段的新闻线，本文按一事一句带过、不展开（原文与译文见文末附录）：① Jensen Huang 回归案——董事会聚焦 Wachtell Lipton 律所主持的独立调查，回归谈判并不存在，评论员 Scott Galloway 在 CNN 称复职「几率几乎为零」；Sam Altman 表示「营收和需求增长如此强劲，行业会没事」，并援引自己 2023 年被逐的经历表达共情；《华尔街日报》称临时 CEO Colette Kress 将收紧数据中心兜底与投资，且 Jensen 辞职前数月本就在收缩——柏林会议上他要求 neocloud 预付芯片货款：「我甚至不需要你们，我可以把这些产能全给 Elon。」② 商务部出口管制新规——新加坡、马来西亚、泰国、印尼、巴西五国数据中心购买先进 AI 芯片须申请许可，存量 90 天内补办；规则自述「由财政部和国家安全委员会撰写并按其指示行事」，把政府内部两派的分歧摆上台面。③ 「国家冠军」计划——据报道名单包括英伟达、亚马逊、微软、OpenAI、Anthropic，配套许可快速通道、国际拓展支持与联邦融资。④ OpenAI 与 Apollo Research、METR、Transluce、Goodfire 签约嵌入独立安全评估员，但访问限制（不开放 Slack、可保留信息、可删改报告）引来 Neel Nanda 等人批评；主持人罕见加重语气：评估标准不应由被评估的公司自行划定。⑤ 摩根大通牵头的银行大故障——官方归因于本地部署硬件上的软件 bug、与网络安全无关；学者 Vivek Wadhwa 公开表示「有些事说不通」。

## 用量跑赢支出：价格战如何改写企业 AI 的账本

第一个大主题，是整期节目的题眼：用量的增长跑赢支出的增长。节目引用的 Ramp 数据称，过去一个月，Ramp 体系内企业消耗的 token 总量上升 36%，而为这些增量 token 支付的费用只多了 2%。原因并不神秘——token 总体在变便宜：节目转述称，OpenAI 与 Anthropic 两家合计，10 月每百万 token 的平均价格下降了约 21%。

这里有一个容易被读浅的机制点，主持人特意拆开讲：这不一定意味着企业在集体转向更便宜的中国模型；更关键的因果是，这些更便宜模型的存在本身，就在迫使大供应商降价。他也补了一句平衡：把模型做得更高效、把价格打下来，本来就是 OpenAI 与 Anthropic 的既定动机之一——两种解释「不管具体是哪种组合」，都开始体现在数字上了（主持人推断，未做裁断）。

价格战能转化为节省的前提，是企业敢于换模型。节目引用的 Databricks 数据给出了最直观的切换证据：其 Unity Gateway（一个模型路由器式的效率产品）上的公司，7 月时有 64% 只用单一模型供应商；到 11 月初完全翻转，72% 使用两家或更多。Databricks 由此提出一个主持人反复认同的论点：裸 token 单价是个错误的观测指标，企业会越来越关注「每个成功任务的成本」（cost per successful task）。

需求侧的乐观由 Arcana 的调研补齐（节目转述）：在 Global 2000 公司的领导者中，AI 如今已是一条八位数的预算线，91% 预计 2026 年增加投入，多数预期增幅在 20%–40%。但同一份调研也量出了先锋与中段的落差：足足三分之二的领导者说，自己对模型与 API 支出「没有可见性」。主持人的推断只有一句：这个状态会很快改变。

> **传导链一（价格战→账本重写）**：变化＝token 月用量 +36%、支出仅 +2%（节目引用 Ramp 数据）。原因＝每百万 token 均价 10 月约 -21%（节目转述 OpenAI+Anthropic 合计口径），更便宜模型的存在施压降价＋厂商自身效率动机。谁得谁失＝企业买家得议价权，模型厂商失定价权、直面商品化风险。二阶影响＝换供应商常态化（单一供应商 64% → 多供应商 72%，节目引用 Databricks 数据），采购指标从裸 token 价转向每成功任务成本。观察指标＝每百万 token 均价、多供应商企业占比、cost per successful task。启发＝没有可切换的基础设施，价格战的收益就与你无关。

## 买方市场、两极分化与 Anthropic 的企业势头

第二个共同主题，主持人定义为「买方市场」：买家握有筹码，因为换供应商正在变成常规动作。节目转述的 Arcana 调研称，整整三分之一的 OpenAI 客户表示愿意换掉它（最常考虑的去处是 Anthropic），43% 的 GitHub Copilot 客户对换掉持开放态度、普遍指名 Claude Code。

竞争格局的受益方相当清楚：Anthropic 拿走了企业端势头。三个口径互相印证（均为节目转述）：Ramp 上略低于 45% 的美国企业向 Anthropic 付费（OpenAI 为 40.6%）；Unity Gateway 上 68.8% 的专有模型 token 流向 Anthropic 的模型；被要求说出一个令人兴奋的 AI 供应商时，Arcana 受访者中 81% 点名 Anthropic。

第三个主题是支出集中，也是本期数据里最陡峭的部分。节目引用的 Ramp 数据称，截至 11 月，支出前 1% 的公司人均月支出约是中位数公司的 625 倍——中位数公司每人每月 16.32 美元，头部公司超过每人每月 1 万美元。主持人照例给出 Ramp 样本告诫：Ramp 覆盖的是一组特定的、偏科技与前沿的公司，其前 1% 是高度分化的群体。但 Databricks 也测到巨大落差：中位用户每周花 2.49 美元，第 99 百分位用户每周约 700 美元——约 281 倍。而在所有研究里，编码依然为王：Ramp 上 72% 的支出来自工程团队；Arcana 的 Global 2000 受访者中整整三分之一在试点 AI 编码工具，是所有类别中最大的试点群体。正在破圈的场景是客服：Ramp 上客服团队的支出占比从 6 月的 0.8% 升至 11 月的 13.3%；Arcana 受访者中 38% 已在用 AI 客服。

> **传导链二（厂商竞争→企业端易主）**：变化＝Anthropic 在三个企业口径上领先。原因＝切换常态化＋Claude Code 在编码场景的拉动（43% 的 Copilot 用户愿换、普遍指名 Claude Code，节目转述）。谁得谁失＝Anthropic 得收入与心智，OpenAI 失锁定。二阶影响＝厂商从「卖能力」转向「卖效率＋可迁移性」，锁定策略贬值。观察指标＝各厂商付费企业渗透率、token 份额、愿换供应商比例。启发＝采购应把「可迁移」当默认条款来谈。
>
> **传导链三（客服破圈→预算泛化）**：变化＝客服支出份额 0.8%→13.3%（节目引用 Ramp 数据）、38% 的 Global 2000 已用 AI 客服（节目转述 Arcana）。原因＝客服是编码之外第一个 ROI 可验证的 agentic 场景。谁得谁失＝模型厂商得增量预算，传统客服 SaaS 与外包承压。二阶影响＝AI 预算从工程专项变成全公司科目。观察指标＝非工程职能的支出占比。启发＝中位数公司向头部靠拢，会先发生在「完成可验证」的职能上。
>
> **传导链四（先锋复利→市场悬念）**：变化＝前 1% 支出约为中位的 625 倍（Ramp）／281 倍（Databricks）。原因＝先锋企业把 AI 嵌进生产流程——具体做法正是同频道前文《七个做法》梳理的上下文、触发器、验证与问责。谁得谁失＝AI 原生公司得复利，中段 Global 2000 失效率（三分之二连支出都看不清）。二阶影响＝全行业 capex 能否转化为 ROI，取决于中位数是否向前 1% 靠拢。观察指标＝中位企业人均月支出的斜率、支出可见性比例。启发＝先把「看得见花在哪」解决掉，是中段公司最大的一颗低垂果实。

## 报告打架的地方：增速、前沿模型与「垫底的 agent」

主持人用几处「分歧信号」给趋同叙事做压力测试。其一，Arcana 说 91% 的领导者预期 2026 年花得更多（多数 +20%–40%），而 Ramp 上的 token 支出增速已在放缓：8 月增长 1.05%，9 月降到 0.22%，10 月回升到 1.65%。主持人自己算了账：若 1.65% 的月增速维持，年化复利约 22%——相比过去是显著放缓，但仍落在 Arcana 预期区间之内（节目口径，写作者未复算背书）。

其二，前沿模型的去向。10 月，Ramp 上前沿模型的支出占比从 67.7% 微升至 69.5%；而 Databricks 一侧，Fable 的 token 份额从 5.5% 跌到 0.6%。主持人的解读（推断）：这可能不是前沿模型整体失宠，而是 Fable 一家的问题——同期 Databricks 上 Opus-55 的 token 占比六周内从 7.2% 涨到 37.9%，「可能只是 Opus 55 强到 Fable 52 还没找到位置」。（写作者注：Opus-55、Fable 52 为转写原词，版本号拼写存疑，见文末 ASR 校正表。）

第三处反差关于 agent。主持人预告，年终盘点时「几乎所有人都会宣布 2026 年是 agents 落地成真之年」；但节目转述的 Arcana 数据称，自主 agent 在「试点与计划」的热度指数上排第 4，在实际部署的采用指数上垫底——热度与落地之间，隔着一整个中段企业世界。这恰好与同频道前文互为注脚：让 agent 从愿景变成部署的，正是那套编排、验证与问责的组织功课。

最后是主持人主动交代的边界：三份调查各有先天局限——Databricks 只统计走其网关的客户，Ramp 是一小撮特定类型的买家，Arcana 的 Global 2000 样本量总体偏低。他的结论是「趋同的故事远比分歧的有力」，而他真正留给行业的大问题是：那前 1%——Ramp 口径 625 倍、Databricks 口径 281 倍——究竟是彻底的离群值，还是其他所有人中位数的未来？他自己的回答：答案必然在两者之间，但「行业能多接近那 1% 反映中位」，将决定整个市场的规模，以及这轮 capex 能否兑现成 ROI。

## 留给读者的杠杆：观察指标与启发

主持人给企业听众的收束建议直白：在谈判桌上，「你手里的筹码多半比你实际用出来的多」。竞争极其凶狠，模型供应商正拼命避免自己的产品沦为通用商品；在这场竞争里有便宜可捡——前提是你已经建好了能真正切换的基础设施，才接得住这些变化（主持人观点）。

综合全期（含写作者归纳），一份观察仪表盘：① 每百万 token 均价与 cost per successful task 的剪刀差；② 多供应商企业占比（64%→72% 的曲线是否延续）；③ 非工程职能（首看客服）支出份额；④ 中位企业人均月支出的斜率（16.32 美元／2.49 美元这两个中位数就是基准线）；⑤ agent 采用指数与热度指数是否收敛；⑥ 支出可见性比例（三分之二看不见自己账单的现状何时逆转）。写作者推断：这六项里任何一项的拐点，都会先出现在这三份报告的下一次更新里——它们已经证明彼此可以互为交叉验证。

一句提醒收尾：本文所有数字均为主播转述三家商业研究的口径，样本各有偏向（Ramp 偏科技型公司、Databricks 偏自家网关客户、Arcana 样本量偏低），引用时请连样本一起引用。
