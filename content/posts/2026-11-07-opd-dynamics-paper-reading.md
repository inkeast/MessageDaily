# 一、论文背景

## 1.1 OPD 是一个自我反馈的学习循环

在线策略蒸馏（On-Policy Distillation, OPD）是语言模型后训练的新兴范式：学生在自己生成的轨迹上训练，每个 token 位置都被冻结教师的下一 token 分布密集监督（通常用 reverse KL）。它同时结合了两个传统方向的优点——密集监督（对比 RL 的稀疏结果奖励）和训练在学生真实访问的状态上（对比离线蒸馏的分布偏移）。

但 OPD 有一个独特的结构性特征：**每次参数更新都会改变学生本身，进而改变生成后续训练数据的分布**。这是一个反馈循环：今天学什么决定了明天在哪里学。这个循环如何塑造学习与泛化，此前几乎无人理解。

## 1.2 两个悬而未决的失败模式

论文瞄准 OPD 社区已观察到但缺乏解释的两个失败模式：

**失败模式一：停滞（stagnation）**。Li et al. 2026b 发现一个反直觉现象：一个更大、benchmark 分数更高的同家族教师，向学生转移的能力反而不如一个 RL 训练的同级"兄弟"教师——尽管两者基准性能几乎匹配。学生的 loss 在降，但精度停滞。为什么密集的监督信号换不来学习？

**失败模式二：退化（degeneration）**。弱学生在 OPD 下不仅不进步，反而在 100 步内在 MATH 上大幅退步，生成质量崩塌（Li et al. 2026b、Fu et al. 2026、Wang et al. 2026 均有记录）。为什么降低教师-学生分歧的更新会让生成变差？

## 1.3 需要什么样的理论

要解释这两个现象，需要追踪三样东西的耦合演化：(1) 教师给什么信号（请求场）；(2) 学生的几何结构如何把这些信号转化为参数运动（响应能力）；(3) 参数运动如何改变学生未来访问的 prefix 分布、从而改变未来的监督信号。现有的微调动力学分析（如 Ren & Sutherland 2025 对 SFT/DPO 的核分解）只覆盖固定数据分布的离线算法——OPD 的分析必须额外追踪**训练分布本身的运动**，这是本文理论工具箱的新颖之处。

# 三、问题定义

## 3.1 从具体困惑到抽象结构

**具体困惑**：同样的学生、同样的 loss 配方，为什么换一个教师就停滞？为什么弱学生 loss 在降、精度在崩？

**核心洞察**：OPD 不是在固定数据集上优化，而是一个**闭环系统**——监督信号 → 参数更新 → 预测变化 + 访问分布变化 → 新的监督信号。失败必须在这个环的结构中定位，而不是在单点上。

**形式化**（OPD 循环）：

```
Πt (rollout 分布) →M→ μt (训练 source 分布)
→q→ Γt = μt·Bt (请求群体：visitation × 教师请求场)
→Φ→ Δθt (参数步：切映射拉回)
→response→ Δlog pt (策略变化，经切核 K 广播到所有 prefix)
→Πt+1 (下一轮 rollouts)
```

其中每个 OPD 更新在任意"接收者" prefix x 上的响应（响应定律，式 2）：

```
Δpt(a|x) = η · Σs μt(s) · [Apt(x) · Kt(x,s) · Bt(s)]a + O(η²)
```

- **Bt(s)**：请求场——教师-学生在 prefix s 上的分歧（reverse KL 的负 logit 梯度），Bt(s,a) = pt(a|s)·(ℓ̄t(s) − ℓt(s,a))；
- **Kt(x,s) = Φt(x)Φt(s)ᵀ**：切核——学生共享参数使源 prefix s 与接收者 x 的 logit 联动；
- **Φt(s) = ∇θ zθt(s)**：切映射——把 logit 空间的请求拉回参数空间。

**求什么**：给定教师 q 与学生初值，刻画沿该闭环积分后学生能达到什么；具体回答三个子问题——转化（§3.2）：请求何时能变成有效的参数运动？广播（§3.3）：参数运动走向何方、如何影响未来训练源与终局精度？预备（§3.4）：能否用离线蒸馏改变循环的起点使之进入良性轨道？

## 3.2 抽象的精妙之处

- 请求场 B 捕捉"教师想要什么"，切映射 Φ 捕捉"学生给得起什么"，二者乘积的群体平均决定实际更新——**分歧大（B 大）不等于学得动（ΦᵀB 有效）**，这直接拆解了"强教师信号强却转移失败"的悖论。
- 广播分解把"预测变化"（drift）与"访问分布变化"（routing）分离——**loss 下降可以完全由 drift 在低质量 prefix 上的拟合贡献，与终局精度无关**，这拆解了第二个悖论。
- 所有量（overlap、Ξ、routing/drift）都是可从训练日志直接估计的诊断量——理论不是事后解释，而是可在训练早期读出的健康检查。

# 四、问题解法

论文的解法是**恒等式驱动的机制分析**：先推导精确分解（附录 C 全部带证明），再在真实 OPD 运行上逐项测量。

## 4.1 转化：Ξ = P·A·C 分解（§3.2）

**类比**：把教师请求想象成"作用力"（压力 P），学生切空间想象成"传导介质"。转化增益 Ξ 分解为：

| 因子 | 定义 | 物理意义 |
|------|------|---------|
| 压力 P | Eν‖Bt(s)‖² | 教师请求的总能量（分歧多大） |
| 可及性 A | Eν‖Φ(s)ᵀB(s)‖² / P | 单位请求能量能激起多大的参数梯度（切映射对请求多敏感） |
| 连贯性 C | ‖Eν g(s)‖² / Eν‖g(s)‖² | 各 prefix 梯度是否同向叠加（0=完全抵灭，1=完全对齐） |
| 总增益 Ξ | ‖u‖²/P = A·C | 请求转化为参数运动的整体效率 |

**诊断方法**：冻结初始请求场 B₀、prefix 银行与 token 坐标，在每个 checkpoint 重新施加同一请求——只有核在变，从而单独测出核适应（特征值放大 vs 特征子空间旋转）。

## 4.2 广播：routing/drift 分解 + 延续值分析（§3.3）

对任意 per-prefix 读数 Y（loss、熵），其总量 JY 的变化率分解（式 5）：

- **Routing（路由）**：RY = Cov(Y, λ)——学生访问了哪些 prefix（祖先 token 的对数概率速度 λ 之和改变 prefix 的到达概率）；
- **Drift（漂移）**：DY = E[Ẏ]——固定 prefix 上预测本身的变化。

对**终局读数**（正确性，非局部量），式 9 给出速度×延续优势的加权分解：JY(T) − JY(t⋆) = ∫ Σx dt(x)·Ea[ζt(x,a)·(Q−V)优势] dt——**更新对终局分数的作用取决于被偏爱分支的延续值**。当被推高的分支延续同样失败时，逐 token 拟合教师换不来精度。

**估计方法**：交叉打分——冻结第 i 时刻的 rollout 银行、换第 j 时刻的学习器（Mij 矩阵），对称平均分离出 routing 与 drift 的精确端点账目（式 8，两者之和精确等于总变化）。

## 4.3 预备：离线蒸馏作为循环起点的手术（§3.4）

由失败机制直接导出干预：退化源于"早期 routing 把未预备学生推入它执行不了的推理状态"。离线蒸馏（在教师生成的轨迹上做 token 级 forward KL）**不要求学生自己先到达这些状态**，可以先建立"延续准备度"。剂量实验：预备 1/2/4 遍后跑 OPD，对比继续离线蒸馏的对照（匹配优化器步数与序列呈现）。

## 4.4 方法全景表

| 组件 | 输入 | 输出 | 作用 |
|------|------|------|------|
| 请求场语义分析 | 最强 1% 请求位置的 LLM 标注（Opus 5，13 类语义标签） | 富集度 Eq(c) | 区分兄弟/大教师请求的语义功能 |

# 五、评估指标与实验证据

## 5.1 指标体系

- **主指标**：AIME 2024+2025 汇总 pass@k（k≤32，60 题、每题 32 样本的无偏估计）与 per-problem 解出率分布（可靠性曲线）；MATH-500 严格 pass@1（剂量实验）。
- **转化诊断指标**：P/A/C/Ξ（按 CONTROL/TECHNICAL 语义 strata 分别报告）；请求能量保留率（终点 Pₜ/P₀）；对初始请求的可及性变化 At[B₀]/A₀[B₀]。
- **广播诊断指标**：累积 routing/drift 贡献（nats）；答案分支概率与分支延续正确率；prefix 难度变化（初始延续者成功率差，百分点）。
- **语义分析指标**：最强 1% 请求中的类别富集度（相对全语料频率的倍数）。

## 5.2 核心实验数据

**强教师转移少（§3.2 起点）**：1.5B 与 7B 各固定一个起始学生（DeepSeek-R1-Distill-Qwen），兄弟教师（JustRL-1.5B / AceReason-Nemotron-7B）带来大幅提升；更大的蒸馏教师（DeepSeek-7B / DeepSeek-14B）尽管 benchmark 更高却全程转移甚微——1.5B 终点 0.62 vs 0.49，7B 0.45 vs 0.31（图 2）。

**请求场语义分化**：兄弟教师的最强请求集中在句首与控制类动作（1.5B 规划开句富集 3.59× vs 大教师 0.30×；7B wait 族 token 4.50× vs 1.23×）；大教师集中在句内技术性位置（数字 token、数学事实回忆）。最强 1% 请求中，兄弟教师的句首份额在 1.5B/7B 分别超出大教师 19.2 与 27.6 个百分点。

**7B：连贯性差异主导**：健康请求可及性与停滞运行几乎相等，但连贯性高 **2.75–3.24×**，总增益 Ξ 高 2.27–2.62×；停滞运行靠更高压力（分歧更大）维持了相当的梯度范数——梯度范数掩盖了转化质量。这证实了 Li et al. 的梯度不连贯猜想（7B 案例）。

**1.5B：核旋转差异主导**：初始 A、C 差异都不大；健康运行在 50 步内主子空间重叠降到 0.77（几乎无特征值放大），固定请求的 top-3 投影增益中位数 **+5.5 个百分点**，成对优势 +1.79pp（95% 置信 [0.94, 3.13]）——切空间主动转向训练教师的请求（偏好性适应，非共享移动）；200 步时主特征值强度 2.31×、请求方向敏感度 2.08×。停滞运行反而收缩（0.67×、**0.83×**）。

**弱 Qwen 退化解剖（§3.3）**：
- 前 20 步 loss 从 0.58 升至 0.85，routing 贡献 +0.455、drift −0.187——学生被推入深长高熵的推理状态（1536-2047 深度窗口 surprisal 从 3.24 升到 6.47 nats，教师 top-1 概率从 0.51 跌到 0.29），教师在这些状态上的监督也变得低置信；
- 后续 drift 主导地在这些低质量 prefix 上拟合：固定 batch-41 prefix 上 loss 从 0.79 降到 0.06、熵 4.99→3.99——**loss 下降是真的，但学的是"不确定教师的不确定预测"**；
- 答案分支概率 0.74→0.19→0.07（步 0/20/100，教师自身 0.30）；步 100 时 continue 分支仅 8% 能产出答案、正确率 0.03，而教师同 prefix 续写正确率 0.60——**问题在学生执行分支的能力退化，不在分支选择**；
- prefix 难度：初始延续者在步 50 的 1024-token 深度 prefix 上成功率已低 8.1pp，退化随训练向浅层蔓延（256/512/1024 三深度在步 200 为 −5.9/−6.1/−8.5pp）。

**DeepSeek 健康对照**：loss 0.263→0.015 主要由 drift（−0.214）贡献、routing 微小（−0.033）；wait 族检查行为双向校准（过度使用 −1.82 nats、不足使用 +1.92 nats），教师相对差距在自有与 held-out prefix 上都下降。

**离线预备（§3.4，三对配对/两规模复现）**：
- AIME 汇总：Qwen-7B +OPD pass@1 = 0.2693 vs +离线对照 0.1906（Δpass@1 = +0.086/+0.071，2024/2025）；Qwen-1.5B 0.0281 vs 0.0078；Llama-8B 0.0693 vs 0.0349——**三个家族全部显著为正**；
- 可靠性：Qwen-7B OPD 在 60 题中 36 题至少解出一次（对照 26 题）、15 题解出率 ≥1/2（对照 10 题）；
- 剂量（Qwen-1.5B，MATH-500 严格 pass@1）：预备 1/2/4 遍后起点几乎不变（45.9/45.7/47.1%），100 步 OPD 终点 45.9%→**56.2%**（1 遍 vs 4 遍）；7B 同趋势（0.823→0.853）。

## 5.3 实验设计如何证明论点

- **"是不是请求本身的问题？"**——固定初始学生、只换教师，对比请求场语义与转化分解：证明大教师请求在语义位置与转化几何上都系统性不同（富集度表 + P/A/C 表的双重证据）。
- **"是不是梯度范数不够？"**——停滞运行梯度范数与健康运行相当甚至更大（压力大补偿了连贯性低）：直接否定"信号不够强"解释。
- **"loss 在降怎么会退化？"**——routing/drift 分离 + 固定 prefix 复测 + 答案分支干预三重证据锁定机制：先 routing 进坏状态、再 drift 拟合坏监督、且被推高的分支学生执行不了（延续优势为负）。交叉打分的对称估计保证了分解的精确可加性。
- **"预备是不是就是更强的起点？"**——剂量实验的关键设计：1-4 遍预备起点几乎不动（45.7-47.1%），但 OPD 终点单调上升——收益不在起点精度而在"延续准备度"，且只有跑后续 OPD 才兑现（继续离线蒸馏无此收益）。

# 六、效果优势的根源解释

## 6.1 根源机制与证据链

**为什么强教师转移失败？**

因果链：大蒸馏教师的最强请求集中在句内技术位置（数字/推导/事实）→ 学生在这些位置上各 prefix 的梯度相互抵灭（连贯性 C 低 2.75-3.24×，7B【论文实验已支持】）→ 即便压力 P 更大、梯度范数相当，有效参数运动 ‖u‖²=PAC 仍低 → loss 停在高处、精度停滞。而兄弟 RL 教师请求集中于句首控制类动作（规划开句、wait 回溯、质疑标记），恰好是 RL 训练所强化的"何时调用推理机制"（与 Venhoff et al. 2025a 的可解释性发现一致【论文引用支持】），这类请求在学生参数空间中方向一致、可叠加。更深一层（1.5B）：健康运行中切核的主子空间主动向训练教师的请求方向旋转（+5.5pp 投影，偏好性 +1.79pp），停滞运行核收缩——**学习本身重塑了对未来监督的响应能力**，形成健康/停滞的自我强化【论文实验已支持；"RL 强化的控制类请求为何天然更连贯"是阅读者依据引用文献的合理推测】。

**为什么弱学生退化？**

因果链：教师负请求压制早期答案承诺 → routing 把从未练过长推理的弱学生推入高熵深状态（surprisal 6.47 nats、教师 top-1 仅 0.29）→ 后续 drift 在这些状态上拟合低置信教师 → 被 favor 的 continue 分支学生执行不了（0.03 vs 教师 0.60）→ 终局精度下降（延续优势为负）→ 退化的 prefix 又成为下一轮监督源（Γ 重生成），恶性循环【论文实验已支持，式 7 给出 μ 重加权的精确形式】。

**为什么离线预备有效？**

因果链：离线蒸馏在教师轨迹上建立延续技能（不需要学生自己到达）→ OPD 阶段 routing 仍会大幅移动 μ（预备运行同样非单调：熵 2.17→4.33 的 routing 冲击），但学生现在能执行被推入的状态 → 教师在这些状态上的监督相对可靠 → 在线纠错得以运转 → 精度大幅提升【论文实验已支持：预备运行轨迹分析 §E.5；"延续准备度"这个抽象概念由式 9 的延续优势项背书】。

## 6.3 综合判断与未决问题

**多项证据共同支持的机制**：(1) 教师请求的语义-几何性质（而非 benchmark 强度）决定转化——本文的富集度/PAC/核探测三线证据 + Li et al. 现象 + Venhoff et al. 可解释性背景；(2) routing-then-fitting 的退化时序——交叉打分、固定 prefix 复测、分支干预三线证据闭环；(3) 预备的延后收益——三家族复现 + 剂量单调性。

**仍属推测的部分**：控制类请求"天然更连贯"的原因（是 RL 训练使然还是任务结构使然，论文未分离）；7B 与 1.5B 两种适应模式（放大 vs 旋转）的规模依赖成因；单种子运行（论文 Q&A 承认约 4000 GPU 小时限制，机制量是 run 内精确恒等式、结果量有三配对复现，但轨迹级 run 间方差未量化）。

**适用边界**：结论限于数学推理与所选模型族（论文自述）；理论采用梯度流近似（动量/预条件/裁剪的实际优化器路径会偏离 raw flow，论文在 C.2 明确该近似并留作未来工作）；分析假设固定 prompt 分布与正则参数路径。

# 七、必要知识反推

## 7.1 领域知识层

- **OPD 的循环结构**：学生生成 → 教师打分 → 更新 → 改变生成——不理解这个闭环就无法提出"转化/广播"的分解点。
- **reverse KL 的请求场形式**：B(s,a) = p(a|s)(ℓ̄ − ℓ(s,a))，softmax 耦合下的精确负 logit 梯度——所有转化度量的出发点。
- **推理模型的行为学**：wait 族回溯、答案承诺标记、认识控制——不知道这些行为的语义就无法设计 13 类标注体系或 wait 读数实验。

## 7.2 方法论知识层

- **切核/NTK 工具**：K(x,s)=Φ(x)Φ(s)ᵀ、Rayleigh 商、特征分解——可及性与核适应分析的数学底座（直接继承 Ren & Sutherland 2025 与 Malladi et al. 2023）。
- **恒等式驱动的实验设计**：先证精确分解（式 4/5/8/9 全部带证明），再设计能分别测量各项的干预（冻结银行、冻结请求、强制分支）——保证"测到的就是理论里的那一项"。
- **因果分解的控制变量惯例**：冻结 B₀ 测核变化；同一 checkpoint 核中比较两个教师的场（分离偏好性 vs 共享移动）；对称交叉打分消除端点约定歧义。
- **统计工具**：有限样本修正的无偏 ‖u‖² 估计（Prop C.9）、成对 problem-bootstrap、精确条件 bootstrap（卷积法）。

## 7.3 工程知识层

- **OPD 训练基础设施**：GH200 节点、~4000 GPU 小时的预算约束下如何设计"主对比不依赖种子方差"的实验（配对 + 复现 + 恒等式）。
- **rollout 银行与交叉打分的工程实现**：按批次（1/21/41/.../196）冻结 32 条 rollout，checkpoint 网格上批量打分。
- **LLM 语义标注流水线**：用 Opus 5 按固定 13 类标签标注 36,416/38,168 个位置，迭代打磨标注法。

## 7.4 知识融合的关键节点

1. ** imitation learning 传统 × 核方法**：DAgger 的"在访问状态上学习"思想 + NTK 的响应定律 = 能处理"分布自己会动"的在线分析框架——这是本文理论的核心创造。
2. **可解释性发现 × 蒸馏诊断**：把"RL 学会的是何时触发机制"（Venhoff et al.）转化为对教师请求场的语义分类，从而把"好教师"从抽象概念变成可测量的请求画像。
3. **失败解剖 × 干预设计**：routing 进入坏状态 → 不可执行分支 → 负延续优势这条链，直接倒推出"离线预备 = 在教师轨迹上预装延续技能"，剂量实验再反向验证机制——诊断与干预闭环。
4. **RL 价值函数思想 × 蒸馏分析**：式 9 的 Q−V 延续优势权重把 RL 的 cost-to-go 视角（Ross & Bagnell 2014）移植到蒸馏的 dense 监督分析中，使"教师偏好 ≠ 学生可执行"这一直觉有了精确形式。

# 八、论文中可以提取的通用性灵感

## 灵感 1：反馈系统失败要定位在"环"上，而不是"点"上——两阶段分解诊断法

**核心思想**：自生成训练数据的学习系统（以及更广的自指涉系统）的失败，应拆解为"信号转化为更新的效率"（转化）与"更新反作用于数据分布的后果"（广播）两个可独立测量的环节；单看 loss 或梯度范数会同时漏判两者。

**论文证据**：停滞运行梯度范数相当但连贯性低 2.75-3.24×；退化运行 loss 从 0.79 降到 0.06 的同时终局精度崩塌（拟合的是坏分布上的坏监督）。

**推广场景**：(1) RLHF 的奖励模型 + 策略共演化循环：分离"奖励信号可转化性"与"策略漂移反馈"；(2) 推荐系统反馈回路（用户行为训练模型、模型塑造用户行为）；(3) 自举式数据引擎（模型合成数据训练自身）：转化=数据利用率、广播=数据分布漂移；(4) 组织学习：培训内容可吸收性 vs 培训改变工作流后产生的新学习需求。

## 灵感 2：监督者的"可学习性画像"比"强度画像"重要——请求的语义位置决定可转移性

**核心思想**：一个指导者的价值取决于其"纠错请求"落在学习者的哪个能力维度上：落在"何时行动"类元控制位置（可叠加、方向一致）比落在"如何执行"类细节位置（易相互抵灭）更可转移——即使后者的指导者绝对能力更强。

**论文证据**：RL 兄弟教师最强请求富集于句首控制位（规划开句 3.59×/4.13×、wait 4.50×），大蒸馏教师富集于数字/推导细节位；前者的请求连贯性高 2.75-3.24×，学生实得收益大得多。

**推广场景**：(1) 导师制：教"什么时候回头检查"的导师比逐步替学生做推导的更强导师更能提升学生；(2) 代码审查：审查意见应聚焦流程/时机层面（何时重构、何时补测试）而非逐行风格细节；(3) agent 设计：orchestrator 对 sub-agent 的指令应作用于任务调度层而非微操作层；(4) 医学带教：上级医师的查房提问（激发诊断路径反思）优于直接给出鉴别诊断细节。

## 灵感 3："能到达"与"能执行"是两种能力——干预的价值在于预装后者

**核心思想**：任何自生成系统都存在"被推向自己执行不了的状态"的风险；离线强制遍历目标状态（无需自己到达）可以预装执行能力，其收益不在当下指标而在后续在线学习中的稳定性——"延后收益"必须通过后续学习来评估。

**论文证据**：预备 1-4 遍起点不动（45.7-47.1%）但 OPD 终点 45.9%→56.2%；弱学生被推入的 continue 分支正确率 0.03（教师同位置 0.60）——到达与执行完全脱钩。

**推广场景**：(1) 教育：先修课的价值不在转学分的成绩而在后续课程中的"跟得上"；(2) 机器人：离线演示数据预装运动基元，再上线做在线适应；(3) 职业训练：模拟舱强制经历罕见工况，防止实战首次遇到时崩溃；(4) immune 系统类比：疫苗 = 离线暴露于抗原，为真实感染预装应答。

## 灵感 4：干预率应该由分歧本身决定——无调度表的自动消退机制

**核心思想**：好的辅助机制其干预频率应等于当前不一致程度（可测量、自动随学习消退），而不是外部设定的日程表——这消除了调参负担并保证机制在收敛时自动退出。

**论文证据**：（本文与 CoRD 论文形成对照）本文的弱学生在高分歧区被过量干预而崩溃；核适应分析显示健康运行对剩余请求的能量保留只有 0.5-1.5%（停滞运行 60.2-79.0%）——分歧消褪与学习健康度直接挂钩。

**推广场景**：(1) 辅助驾驶：介入力度应随驾驶员状态偏差成比例、随技能提升自动减弱；(2) 渐进式 API 迁移：兼容层按实际调用差逐步收缩；(3) 教学脚手架：提示量随学生错误率自适应；(4) 微服务降级：兜底逻辑按真实错误率启停。

## 灵感 5：把"学习如何学习"量化为响应几何的演化——响应能力是训练的产物而非固定禀赋

**核心思想**：学习者对监督的敏感度不是固定属性，而是被训练历史重塑的（特征子空间旋转/放大）；早期训练可以"为学习而学习"（先改变响应几何，再收获损失下降），诊断应监测响应几何的走向。

**论文证据**：1.5B 健康运行 50 步内子空间重叠降至 0.77、固定请求投影 +5.5pp（先旋转、后放大 2.31×）；停滞运行核收缩（0.83×）——与"lottery winning"早期对齐现象（Baratin et al. 2021）跨领域呼应。

**推广场景**：(1) 课程设计：先安排"学会如何听讲"的元学习期再上强度；(2) 主动学习：采样应考虑模型对候选样本的 Jacobian 增益而非仅不确定性；(3) fine-tuning 实践：warmup 阶段的作用可能主要是重塑核几何（提示 lr schedule 研究新方向）；(4) 员工 onboarding：首月的项目安排塑造的是"对反馈的响应带宽"。
