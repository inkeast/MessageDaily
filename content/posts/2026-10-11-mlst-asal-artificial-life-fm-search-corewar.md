# 用基础模型当"生命裁判"：ASAL 自动搜索人工生命，与 LLM 进化出的 Core War 军团

> 信源说明：本文基于 Machine Learning Street Talk（MLST）2026 年 10 月发布的专访（视频 ID 615B5nyMFPk，全长约 48 分钟），嘉宾为 ASAL 论文（Automating the Search for Artificial Life with Foundation Models）第一作者 Akarsh Kumar（MIT 硕士论文工作、与 Sakana AI 等机构合作；转写将其名写作 Akash Kumar，经查论文作者列表更正为 Akarsh）。文中"pick breeder skulls""Linear by Bert Chan""Thomas Moore""UFR""Maplete"等为转写疑似讹误，已按上下文推定并标注。所有实验数字均为嘉宾或论文自述，本文未做独立核实。

## 先说结论

这期节目回答了一个看似冷门、实则指向 AI 底层范式的问题：如果当前大模型是一种"统计智能"，那是否存在另一种基于"规律性"的智能范式，以及我们能否用工具自动找到它。嘉宾 Akarsh Kumar 的答案分两步：第一步是用视觉语言模型当"裁判"，把人工生命研究从手工调一个模拟器变成自动搜索整个模拟空间（ASAL），他们把 26 万条规则全部跑完，发现最有趣的开放式模拟只占其中一个小岛；第二步是让 LLM 充当进化算法的变异算子，去进化会互相攻击的汇编程序（Core War），首轮进化就能击败 96% 的人类程序，多轮军备竞赛后程序行为方差持续收敛——趋向"单一通才战士"。对读者的可迁移结论是：进化被 AI 圈严重低估了，它不是梯度下降的备胎，而是"部分解即收益"的离散组合搜索算法，配上 LLM 这种比随机变异好得多的变异算子后威力倍增。

## 为什么此刻人工生命值得重做一遍

Akarsh 开场先纠正一个流行误解：进化绝不是随机。这是整期节目的题眼，也是后面 Core War 结果的理论铺垫。

他借 Jeff Clune 的话解释人工生命的立场：要声称理解智能或生命，就不能只研究"生命是什么"（那是生物学），而要研究"生命可能是什么"——理解所有可能的智能构成的空间，才能谈支配智能的一般原则。"你不能只看一辆车就说所有车都这样，同样不能只看 GPT-5 或人脑就说所有智能都这样。"主持人补充：这也是我们不只靠神经科学理解智能、而要造 AI 的原因——要更机制性的理解。

节目穿插介绍了模拟器谱系（这段是理解 ASAL 的背景板）：

- **康威生命游戏**：2D 网格细胞开/关、两三条极简规则，跑起来却涌现惊人复杂性。嘉宾提到社区 Discord 里有人发现每 64 步重复一次的飞船图案；社区还给系统定义了"因果速度上限"——信息每步最多传播一格，称之为光速 c，滑翔机速度记作 c/16，"像真物理一样"。他说很多人当它是玩具，"但它玩具到恰好可以研究"。
- **Lenia**（嘉宾口述"Linear"，转写疑似讹误；Bert Chan 之作）：把生命游戏连续化到三通道（可映射 RGB）、用连续微分方程更新。节目插播了 Bert Chan 本人的原声："我把这个系统在我电脑里煮了一下，某种毛骨悚然的东西发生了——一个图案爬过了我的屏幕。"
- **神经细胞自动机**（Mordvinov 的 Growing Neural Cellular Automata，2020）：把 3×3 邻域→单细胞的更新规则换成一个小神经网络，可学出"壁虎图案被删掉一部分后能自我重建"的系统。主持人借此点题：我们不想学"壁虎长什么样"（骗子解），而想学"从构件重建壁虎的能力"——路径依赖又出现了。
- **Boids 与 Particle Life**：前者是鸟群/鱼群模拟（决策规则换成小神经网络去搜索），后者在欧氏空间扔裸粒子、用 6×6 类型相互作用矩阵当"物理"，调矩阵就能看到从噪声到"类细胞"结构的谱系。

真正的研究问题在 Akarsh 口中是一句话："**在什么样的世界里我们得到复杂性与涌现的开放式创造，在什么样的世界得不到？为什么这套物理跑出来是奇观、那套物理只有随机噪声？**"这正是他做 ASAL 的直接动机。

## 方法：不硬编码一个宇宙，而是参数化一整族宇宙，让基础模型当裁判

ASAL 的核心思路是把"coding up 元素周期表"换成"说定有一百种元素、让算法自动找出它们怎么相互作用"。具体做法是参数化一个模拟空间，然后让视觉语言模型以三种方式介入：给定监督目标（如"多细胞生物""神经网络""病毒""菌落"）找产生该现象的模拟；找时间上开放式产生新奇的模拟；以及照亮整个空间的多样性搜索。

为什么用基础模型而不是手写指标？Akarsh 给了两个理由。第一是表述容易："我想要一只猫"比逐像素监督容易得多，而且"要任意一只猫"远比"要这只特定的猫"好搜——把约束放松后满足条件的解空间大得多，优化难度骤降。第二是对 Goodhart 定律的防御：复杂度、涌现、"有意思"都难以数学化，硬要写成一个指标再去优化，"你会得到你要求的，但不是你想要的"。既然真正想要的是人类主观模糊的判断，而人类在环太贵，就用统计上贴近人类表征的基础模型当近似裁判。

他特别强调这利用了**计算不可约性**（借 Wolfram 的概念）：不去预测哪条规则更好，直接把模拟跑开、看发生什么、丢给基础模型评判、再回来迭代。

结果层面（均为论文/嘉宾自述）：ASAL 找到了比康威生命游戏更开放式的细胞自动机；把 26 万条规则全部运行、用 CLIP 嵌入投到 2D 并按开放式程度着色后，空间呈现"一大岛不开放式解 + 一小岛酷解 + 一个孤点"的结构——**开放式是个稀疏区域，不是均匀分布**。在 Particle Life 里，有的物理矩阵涌现出带红色外壳、内部紫黄三角的"类细胞"自持结构，嘉宾把它解读为"物体在利用这套物理把自己持续保持在世界里"——并接上他与 Blaise（前次节目嘉宾）讨论的"生命即坚持"：即使系统不接地（纯计算模拟），坚持现象依然会涌现，虽然并非所有模拟都会出现。

主持人还追问空间结构：初始状态层面生命游戏极混沌——改一格细胞，原本能跑上万步的模拟百步内就坍缩成振荡态；但**物理规则层面更鲁棒**，18 条可开关规则里改一条影响通常不大。不同世界里滑翔机形态各异（有的像火车沿轨走），但主持人提出"汇聚模式"若跨世界普遍存在，可能是"底层基底的影子"——嘉宾注明这只是一个假说，怀疑者也可以说这只是网格/解释器带来的设计偏置。

## "统计智能"之外的另一条路：课程、路径依赖与自动学对称性

访谈后半段转向更具观点性的部分：当前大模型是"统计智能"，而 Akarsh 认为还存在"基于规律性的智能"范式，后者的证据散布在多个线索里。

第一是训练顺序的反差。人类与动物按自然课程学习；而"我们的模型给什么学什么——训微积分就学微积分，不必先学算术"。主持人举重若轻地点出这有多怪。Akarsh 承认有观点认为这种无序也许更好，但他判断"宇宙不是这样运作的"：顺序学习与路径依赖的进化之所以造出规律、鲁棒、可泛化的表征，正是因为复杂表征要在已有规律之上一层层构造。他坦承"为什么必须这样"没有短答案，但自然进化、assembly theory（生化领域的进化理论）、人类学习都如此，"要么证明它必要、要么证明它不必要，都会是重大发现"。

第二是 Wolfram 的**计算不可约性**：没有捷径，想获得复杂表征就得合成构件、走完路径。Ken Stanley 的 novel search（ novelty search）也常被误当随机——恰恰相反，随机是乱做动作，新颖性搜索明确记得做过什么并避开它。

第三，Akarsh 把一切统一进正则化视角：数据是正则化（捏泥塑形）、权重衰减是正则化（偏好低范数解），而课程学习/尊重对称性是"**极强极强极强的正则化**"——也许正是我们真正需要的那种。节目插播 MLST 旧纪录片片段（Kenneth Stanley）：阶梯结构表明发现的意义不只在于找到积木，还在于让未来发现更多——"重要的不只是你到达哪里，还有你是怎么到的"。主持人对比当前行业只看 benchmark 分数、"刚通过数学奥赛"的取向，指出"怎么到的"被系统性忽略。

第四是"自动对称性学习"。CNN 平移不变、Transformer 置换不变，都是人为写进的对称性；但"光照不变性"——让图像模型对白天黑夜不变——世界上没有哪个方程能给你保证。Akarsh 认为 FER 式进化学到的解（转写作"pick breeder skulls"，疑为 Picbreeder 系工作之讹误）里，归纳偏置不在假设空间里，而是**烤进找到的神经回路本身**——这是统计训练给不了的。

至于如何从人工生命走向 AGI：Akarsh 定性它为"对智能的极长期下注"，但有两个保留——即使造不出智能，这些研究本身仍产出关于宇宙与涌现的科学洞见；而且按 Ken Stanley 的思路，不需要逐粒子模拟整个自然演化，要找的是"超高效、且能给出你想要的智能"的**抽象**，这是开放问题。

## Core War：LLM 当变异算子，进化出击败 96% 人类战士的军团

最后一个板块是最"工程可落地"的。Core War 是 1980 年代发明的编程游戏：各写一个 Red Code 汇编程序（图灵完备）放进虚拟机随机地址，程序可任意行事，目标是成为最后一个还活着的——手段是在对方执行流前注入非法操作把它弄崩溃。主持人称之"图灵版的权力的游戏"。

Akarsh 团队的问题：让 LLM 进化这些程序互相对抗，能否造出开放式军备竞赛？做法是"一个程序起步（人类的或 LLM 生成的均可），LLM 作为变异算子，在进化循环里优化出一个能击败它的战士；再优化第三个打败前两个；再第四个打败前三个……"他指出空间极具欺骗性、非局部，贪心遗传算法不行，他们用了 MAP-Elites（转写作 Maplete）这类 quality-diversity 算法。

两个主要结果（嘉宾自述）：

1. **首轮进化即击败约 96% 的人类战士数据集**（约 300 个人类作品）。关键反差：LLM 直接零样本写 Red Code 很烂，best-of-n 采样也烂；但放进带验证器的进化循环就非常强——"这与 Alpha Evolve 的教训相同"。
2. 越往后轮次的战士越**泛化**——更可能击败没见过的人类战士；且行为特征向量的方差随轮次下降，趋向"单一通才战士"的行为收敛。

Akarsh 用此回应"进化=随机搜索"的轻视：进化是已知解离散组合问题的最强算法，其被低估的核心是**选择机制**——只要解出拼图的一角并留住它，就能把指数搜索变成线性搜索；它只要求变异"百分之一的时间是有用的"。LLM 前时代的程序空间随机变异（如 AutoML-Zero 类工作）几乎零概率撞出有用代码，而 LLM 的"有用变异率"远超 1%，于是"每次成功都留存叠加"——进化+LLM 的组合"比单用 LLM 强得多，根本不是一个量级"。

## 三条机制链与读者启发

**链条一：人工生命 → 搜索范式迁移。** 变化：手工调模拟器→参数化空间+FM 裁判（ASAL）。原因：模拟器家族可参数化，而人类判断可用 FM 近似且免于 Goodhart。受益：ALife 研究者获得可扩展的发现管道；风险：FM 裁判本身的偏差会定义"什么算有趣"。观察指标：更多领域用"生成模拟空间+模型评分"替代手工设计（材料、化学、物理环境）。启发：任何"好结果难以形式化但一眼可辨"的领域，都适合把评价器换成 FM、把设计空间参数化。

**链条二：统计智能 vs 规律性智能 → 训练范式的路线分岔。** 变化：单轨统计训练→有人认真押注路径依赖的构造式表征（课程、novelty search、计算不可约性）。原因：无序学习在鲁棒与泛化上留下疑点，而进化/人类学习的共同结构是顺序构造。二阶影响：若成立，纯规模路线的表征质量有天花板，课程与环境设计重新值钱。观察指标：是否有工作实证"预训练顺序影响同 benchmark 分数模型的下游鲁棒性"。启发：判断一个学习系统别只看分数，要看它是"怎么到的"——同一分数下路径依赖的表征可预期更可干预。

**链条三：LLM 变异算子 → 组合搜索成本结构改变。** 变化：随机变异近乎零命中→LLM 变异显著超阈值。原因：选择机制留住部分解+变异质量提升，指数问题降为线性。受益：一切有廉价验证器的离散搜索（代码、证明、芯片布局、对抗样本）；风险：同样的机制也放大自动化红队与攻击代码搜索。观察指标：Alpha Evolve 式系统的生产化落地数量。启发：**有验证器的领域，进化循环是对零样本能力最直接的放大器**——评估你的领域里"验证成本"与"变异空间"，两者都友好就值得把 LLM 塞进进化循环。

值得保留的不确定性：26 万规则的"小岛"结论基于特定着色与嵌入方式，鲁棒性未讨论；FM 裁判与人类判断的偏差如何量化，论文与节目都未给出方案；Core War 的行为收敛是趋势陈述（"至少趋势如此"），未给出统计检验细节；"统计智能 vs 规律性智能"是嘉宾的研究纲领而非已证结论。
