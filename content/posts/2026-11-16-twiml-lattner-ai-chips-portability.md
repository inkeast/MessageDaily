## 先说结论

这是 TWIML AI Podcast 在毛伊岛骁龙峰会（Snapdragon Summit）现场录制的一期 16 分钟短访谈：主持人 Sam Charrington 对话 Chris Lattner——LLVM、Clang、Swift、MLIR、Mojo 的缔造者、2022 年联合创立 Modular，如今的高通「先进 AI 软件与平台」执行副总裁（转写自述；据高通官方新闻稿核实，2026 年 6 月 24 日宣布收购 Modular、7 月 29 日完成，全股票交易约 39 亿美元）。两人的缘分始于 2020 年 TWIML 办的「Great ML 语言大辩论」，当时 Lattner 代表 Swift 出席——Sam 自述这个日期是「问了一个 agent」才查回来的。访谈信息密度很高，三条主线：其一，AI 推理负载正被拆成 prefill、decode、投机解码等阶段，不同芯片各擅一段，「异构」是数据中心的常态而非过渡，软件栈的使命是让开发者写一次代码就吃满不同芯片；其二，Modular 的方法论不是在几十年遗留系统上再糊一层抽象，而是从硅片自底向上重建整个栈——「默认兼容、按芯片特化」，Mojo 已按 Apache 许可证开源，年内还将围绕 Max 推出开放联盟；其三，对 Agent 写代码，Lattner 重度使用但边界清晰：架构性代码必须有人在环，只有行为规格的代码（比如「跑得快就行」的 AI kernel）可以放手让 agent 去磨。

## 一、异构是常态：换芯片为什么等于重写代码

Lattner 从历史讲起（转写 120s–240s 段）：AI 起步时 CPU 是唯一要紧的芯片，但 AI 太重要、计算太密集，很快催生了专用芯片——NVIDIA 的 GPU 是大量数据中心计算的领导者，Google 在造 TPU 及其他专用加速器。真正的变化发生在最近：AI 计算强度再上一个量级后，人们意识到「工作负载的不同部分可以由不同芯片来跑」——有的芯片擅长 prefill（预填充）阶段，有的擅长 decode（解码）阶段，有的擅长投机解码（speculative decoding）。这些阶段的资源画像截然不同：有的高度并行、吃算力，有的很串行、吃内存，还有的只要求低延迟。Lattner 的结论是：芯片侧既然没有「一刀切」，软件就必须横跨并统一这一切——「你就不用为三块芯片把同一段代码翻来覆去写三遍」。

这段判断不是抽象预言，而是对 CUDA 生态现状的回应：访谈开头（0s–120s 段）Lattner 就把「数据中心里的 CUDA 和 NVIDIA 芯片」点为「硬件很多、没人会编程」的代表场景。这也是算力故事的另一面——当先进制程产能与光刻工具成为供给侧硬约束（见此前[Dwarkesh 走访 Intel 晶圆厂的报道](https://inkeast.github.io/MessageDaily/posts/2026-10-25-dwarkesh-intel-chips-2045/)），剩下能挖的效率空间大量藏在软件层。Sam 随即追问了一个关键工程问题：统一不能走「最小公分母」路线——只取各硬件能力的交集、放弃每块芯片的独门性能。这其实是所有跨硬件抽象层都挨过的经典批评。

## 二、Modular 的答案：从硅片往上重建，默认兼容、按芯片特化

Lattner 的解法（240s–360s 段）是一个分层判断。先把 AI 拆成模块化部件（Modular 名字的由来），会发现大量逻辑其实与架构无关：数据中心里对进来的查询做批处理（batching）的逻辑、围绕投机解码和 KV cache 的调度逻辑，全都不关心底下是什么芯片；而矩阵乘法最内层那一小段则高度硬件相关，因为每块芯片访问数据、加载权重的方式都不同。所以策略是「统一公共部分、特化硬件部分」，而且不建在遗留系统之上——他从硅片开始自底向上造整个栈：编程语言（Mojo）、编程模型、AI kernel、serving 架构。他的论证是组合式的：当最底层的 sin/cos/arctan 原语是同一套，ReLU、softmax、transformer 块、attention、KV cache 就能逐层组合复用——「与其一切默认互不兼容，不如默认兼容，只在能从芯片特性里赚到 alpha（超额收益）的地方做特化」。

这套方法论的说服力来自履历：LLVM、Clang、Swift、MLIR 都是他主导构建的编译器与语言基础设施（Qualcomm 官网高管页核实），其中 MLIR 当年就是为「异构硬件编译」而生。换句话说，「在统一与特化之间怎么划界」这件事，他已经做了二十多年。

## 三、并入高通：开放是被买出来的，竞争要回到硅片本身

访谈中段（360s–480s 段）Lattner 讲了收购的来龙去脉。Modular 做了约四年半，在 2026 年夏天冲向自家活动 ModCon 之前，为六家硬件厂商的六种架构发布支持，其中一家就是高通——合作顺利，于是高通找上门来，核心说辞只有一句：「你们在建一个不可思议的技术平台，你们应该让它真正开放。」Lattner 坦承创业公司做不到这一点：必须保护 IP、必须想清楚变现。而高通愿意付这个钱（据公开报道约 39 亿美元全股票），因为它想撬开数据中心：高通在造数据中心芯片、也在往价值链多层布局，它要的是「很多不同芯片、很多公司都在创新、也互相竞争」的生态，让竞争回到硅片本身的优劣上，「不希望软件挡住任何人竞争的路」。

落地动作有两个（节目称）：Mojo 已按 Apache 许可证开源；年内将围绕 Max——Mojo 之上、把芯片变成可部署模型的那一层——推出开放联盟。社区反应被 Lattner 描述得很直白：创业阶段「我们会开源 Mojo」喊了太久，「互联网上很多聪明人听过太多宣言」，Apache 开源真正落地反而是最好的定心丸——「这帮人是认真的，宣言会变成现实」。

收购的另一半逻辑在设备端（480s–600s 段）。创业公司只有云上能赚钱，所以 Modular 从来没理由投入边缘——尽管已经有人在 Arduino 上跑这套栈。高通从吊坠、耳机、手表、手机到笔记本和 IoT 的完整设备谱系，第一次给了「统一的 AI 软件平台」向下扎根的商业理由。Lattner 的路线说法是「先高通设备、再全世界」：每个功耗性能档位都有对应芯片，开发者终于能「为自己的工作负载选对芯片」。

## 四、Mojo 的定位：从写算子的小众语言，长成 Python 家族的通用语言

对 Mojo 的现状，Lattner 出言谨慎（600s–720s 段）：Mojo 和 Max 是「根本性技术」，仍在成形。今天 Mojo 适合写 GPU 上的矩阵乘法、神经网络内部实现；Max 适合把数据中心 GPU 上模型 serving 的性能榨满——支持列表包括 NVIDIA、AMD、Google TPU、AWS Trainium、高通和 Apple GPU。但「想亲手写算子的人受众很小」，所以 Mojo 会继续长成完全通用的语言——已经有人用它写网络协议栈、高层应用和游戏；「作为一个完美主义者，我不想把还没就绪的东西吹过头」，「给它六个月到一年」。

更长线的叙事是 Python。Lattner 强调 Mojo 是「Python 家族的成员」，正面解决 Python 最大的痛点——性能、分发、包管理：「很多人离开 Python 非常不情愿，是为性能不得不走，不是不喜欢这门语言。」他还顺带对照了 Swift：好东西、学到了很多，如今十五岁（嘉宾口述口径，该语言 2014 年公开发布），且只能在 CPU 上跑——Mojo 是「再造下一个东西」的机会，一头接住 CPU 之外的现代算力，一头引入编程语言的新技术与易用性。

## 五、Agent 写代码：两级纪律，与「三个月解决难题」的怀疑

访谈最后三分之一最值得反复看（720s–960s 段）。Lattner 先给了整体观感：AI 十年，节奏快到人人自危，「每隔一个周二就有人说新品类让人类完蛋」，但他在行业里待了十年，知道「这种事每个周二都发生一次」；解法是接受模糊性、认清「人们每天都在过度宣称」、专注把东西做好交付客户——「你就能得到这一切的好处，不必为失业夜不能寐」。接着是他自评「最辣」的观点：他最不同意「我们花三个月做出了 agents，于是把一个长期存在的问题一笔勾销」——芯片设计、AI 软件、编程、数学，「这些事我们做了很久」；这让他想起「六个月内不再需要放射科医生」的旧论——Geoff Hinton 是聪明人，但做产品、做体验远不止写代码。软件工程的常识是读代码的时间多于写代码，AI 加速了写，替代不了产品设计、演化、营销、品牌和判断。但反面同样成立：「风险不是你会被淘汰，风险是你会落后」——AI 不是可选项，必须拿工具做实验。

他自己的工作流（840s–960s 段）是「重度使用者+明确纪律」：仍在 GitHub 上大量写码；AI 是「思考伙伴」，适合机械活和非架构性任务；「万物皆混搭」，AI 对既有系统的了解可能比我们深，拿它做方案对比极有价值。但「完全自动驾驶」式的「帮我解决」会给你能通过测试、却未必正确的代码，「你还是得看」。这套纪律在他团队里被制度化为两级策略：**架构性的东西（系统、编译器）必须有人在环；只有行为规格的东西——比如一个只需要跑得快的 AI kernel——放手让 agents 去磨，而且「我不用维护那段代码」**（音频在 960 秒处戛然而止，这句正好话音未完）。

## 机制链条与读者启发

**链条一：可移植软件栈 → CUDA 式锁定价值贬值。** 变化：Modular 栈开源并并入高通（Mojo 已按 Apache 开源、Max 年内开放联盟）→ 原因：创业公司无法兼顾保护 IP 与开放，高通愿意以「软件不挡竞争路」换取数据中心入场券 → 谁得：非 NVIDIA 芯片（AMD/TPU/Trainium/高通/Apple GPU）的开发者生态、需要换芯片的模型服务商；短期谁失：靠软件锁定收租的在位者 → 二阶影响：竞争轴回到硅片性能与功耗本身，硬件议价权向买方移动 → 观察指标：Max 开放联盟的实际条款与成员名单、六大架构之外新增芯片支持的增速、数据中心推理市场份额变化 → 启发：评估任何 AI 芯片新闻时先问「软件栈跟不跟得上」——可移植栈每成熟一分，靠生态锁定维持的溢价就贬值一分。

**链条二：推理负载分段 → 异构组合成为默认架构。** 变化：prefill/decode/投机解码被识别为资源画像迥异的阶段 → 原因：AI 计算强度上升，单芯片无法在并行算力、串行内存、低延迟三项上同时最优 → 谁得：能做阶段专用芯片的厂商；谁失：只提供通用 GPU 的玩家 → 二阶影响：数据中心从「一堆同构 GPU」走向按阶段组合的异构集群，调度与可移植软件成为关键资产 → 观察指标：厂商是否推出 prefill/decode 分离的产品形态、开源栈对各阶段 kernel 的覆盖度 → 启发：性能优化的最大收益在系统层组合，不在单芯片峰值参数。

**链条三：边缘的商业空白被收购填补。** 变化：一套为规模化设计却只投云端的栈，突然获得全设备谱系的落地理由 → 原因：创业公司只有云上能变现；高通有从吊坠到数据中心、覆盖 IoT 的完整谱系和出货量 → 谁得：高通设备上的 AI 应用开发者（一套工具横跨功耗谱系）；谁失：各设备私有 SDK 的锁定价值 → 二阶影响：「一次编写、多端部署」的门槛下降，可能催生新的端侧 AI 应用类别 → 观察指标：Mojo/Max 进入高通手机/手表/耳机官方工具链的时间表、端侧模型 serving 工具的统一化程度 → 启发：平台技术的采用节奏由商业激励决定，不只由技术优劣决定——判断一项技术会不会普及，先看谁有动力付钱。

**链条四：AI 编码的两级纪律。** 变化：资深系统工程师（编译器背景）重度使用 AI 编码但拒绝全自动 → 原因：自动驾驶模式会产出「通过测试却不对」的代码，而软件工程的真实成本在读与维护 → 谁得：按「架构性 vs 行为规格」分级使用 AI 的团队；谁失：跳过审查、把输出直接合入的团队（隐性技术债）→ 二阶影响：把行为规格写清楚成为新的工程能力，代码审查的价值进一步上升 → 观察指标：纯 spec 类任务（kernel、胶水代码）全自动化的真实案例数、架构层 AI 参与度的行业调查 → 启发：把任务先按「错了多贵」分级——贵的留人在环，便宜的放手让 agent 磨——这是当下最可操作的 AI 编码策略。
