## 一、论文背景：AI 玩游戏，输在"想得太慢"

### 1.1 一个反直觉的事实：会思考反而是劣势

想象让一个博学的推理大模型去玩《黑神话：悟空》。它看得懂画面——敌人是谁、血条多长、Boss 正在抬刀蓄力；它也知道该怎么办——"敌人抬刀后约 0.3 秒是闪避窗口"。但问题出在时间上：推理模型每生成一个 token 都是一次串行解码步骤，想得越深、中间 token 越多、耗时越长。论文引用 Realtime-Bench 等工作的判断：在持续变化的环境里，等推理完成，**观察已经过期、动作机会已经溜走**。人类玩家不需要在每次闪避前写一段分析——这就是认知科学里卡尼曼《思考，快与慢》中 System 1（快速直觉）与 System 2（慢速深思）的区别。论文标题里的 System-One，指的正是把决策交给"快系统"。

### 1.2 决策模型：快，但"没见过世面"

2026 年 9 月以来，一类叫**决策模型（decision model）**的新物种快速崛起（本系列此前精读的 Jeva 四部曲、AnyS1、Piccolo、Jeveration 都属这波浪潮）。以 TypeSafe AI 的 JEV 为代表，它们保留类似大语言模型的骨干，却换掉了输出接口：不逐字生成文本，而是通过决策头直接给候选答案打分，**单次前向传播**就返回结构化判断，延迟约 50-200 毫秒——够快了。但论文点出两个软肋：其一，没有多步推理，复杂判断做不了；其二，**提示词传不了细粒度的多模态经验**。论文 Figure 1 给了个杀手级例子：《黑神话》里 (a)(b)(c) 三帧都是"敌人高举武器"，(a)(b) 处于攻击前摇的不同阶段，只有 (c) 才是真正的闪避窗口——区分它们靠的是武器角度和姿势的细微近期变化。这种区分写成长提示要么描述不全、要么描述太长导致延迟翻倍，而 few-shot 示例图片更会让处理时间暴涨回大模型水平。**结论：可靠的细粒度视觉判断，必须写进模型参数，不能停在提示里。**

### 1.3 强化学习：会练，但练不起

经典强化学习（RL）的执行端本来就快——浅层网络一次前向出动作，天生适合高频控制。问题在**获取策略的成本**：在线 RL 需要成千上万次试错，而真实游戏客户端有账号认证、持久化服务状态，既不能沙箱化、不能可靠重置、也不能并行开副本；离线 RL 免交互但要先采集大量轨迹，且受数据覆盖限制。在"几个真实 episode"的适应预算下，两条路都拿不出足够证据——一条没机会探索，一条没见过替代动作的后果。

### 1.4 核心类比：教练、运动员与肌肉记忆

论文最动人的洞察来自运动学习：**懂自行车原理不等于会骑自行车**。维持平衡的姿势修正太快，来不及 deliberation，必须通过数小时渐进练习变成"肌肉记忆"——不经有意识重构就能做出的反应。人类学一个动作比 RL 快几个数量级，差别在哪？**教练**。教练既不替运动员做动作、也不完整描述动作，而是看录像、定位错误、设计一个隔离该错误的训练动作，让练习时间花在缺失的区分上。本论文把推理模型放进教练角色：它命名哪些观察重要、规定该练什么、定义如何解读训练记录，然后由监督训练（LoRA 微调）把判断固化进决策模型参数——作者称之为**外部肌肉记忆（external muscle memory）**。

## 二、论文定位和关联工作

### 2.1 谱系一：递归自改进（RSI）

RSI 指系统把自身输出用于构建更好的自己。2026 年它已从科幻概念变成工程实践：Anthropic 披露 Claude 写了自家代码库 80% 以上的合并代码；Weco 的 AIDE² 让外层 agent 在八天内百步无人值守地重写内层 agent。论文明确站在两类前序工作上：**代码修订型自改进**（Voyager 技能库、Reflexion 语言反思、Self-Refine、SICA、Darwin Gödel Machine 改的是可执行程序）与**参数更新型**（自指权重矩阵学的是更新机制本身）。System-One RSI 的独特之处：**推理模型指导的是"任务判断 + 控制规则"两条腿，而训练流程本身固定不动**——既改参数（LoRA），也改代码（行为树/决策树），由同一份经验池驱动。

### 2.2 谱系二：决策模型与双系统分工

本系列已持续追踪这条线：Jeva 奠定决策原生架构的结构保证；AnyS1 把 agent 工作流中可枚举决策点交给专用 System-1；Piccolo（同为阿里体系）用 RSI 协同演化决策模型与数据；Jeveration 让 System One 单次前向生成图像；System 1 agents（昨日精读）把整个工具调用环节交给决策模型。本文与它们的关键区别：**前述工作要么训练专用模型、要么零微调用现成模型，本文研究的是"适应"本身**——如何用极少的真实交互把一个通用决策模型练成特定任务的实时控制器。论文还引用 System Switch（何时该停下来思考）作为互补：本文相当于把"思考"整体移出在线时间路径。

### 2.3 谱系三：实时游戏 Agent

- **VARP**（阿里，2025）：用 GPT-4o 等 VLM 玩《黑神话》，中等战斗 90% 成功率——但必须在推理时用照片模式**暂停游戏**，正是本文要消灭的妥协；
- **腾讯 Cerebellum 双系统**（2026）：Brain（System 2）规划 + Cerebellum（System 1）紧凑 VLM 帧级执行，约 9 小时通关第一章——但每款游戏需要专门的预训练 + SFT + RL 三阶段训练；
- **OpenAI Dota 2 / 经典 RL**：依赖大规模并行模拟，与本文"不可沙箱"设定正交。

本文位置：**不暂停、不并行、不预采集专家数据，用 5-20 局真实对局完成适应**——填补了所有前序工作留下的空档。

### 2.4 谱系四：知识蒸馏

Distilling System 2 into System 1、Distilling Step-by-Step、Policy Distillation 都证明"把慢思考蒸进快直觉"可行。本文可视为该范式在**视觉实时控制 + 无专家演示**条件下的实例化：教师不是另一个模型，而是一个由推理模型组成的**教练团队**；蒸馏目标不是答案文本，而是**结构化任务判断**。

### 2.5 定位对比表

| 路线（论文 Table 1） | 优势 | 活环境中的结构性限制 |
|---|---|---|
| 在线 RL（Dota 2 等） | 从交互反馈学策略 | 环境复制、重置、并行 rollout 被外部依赖阻塞 |
| 离线 RL | 从既有轨迹学习 | 数据采集昂贵；覆盖不足限制分布偏移下学习 |
| 推理型 computer use | 用深思运用任务知识 | 反复推理加延迟；视觉接地仍不可靠 |
| 推理生成 CV/控制程序（Code as Policies、Voyager） | 把任务知识变成可执行规则 | 感知条件需逐一边缘案例规格化与测试 |
| 未适应的 JEV 类决策模型 | 无推理痕迹返回结构化判断 | 预训练能力未必覆盖新任务所需区分 |
| JEV 提示优化 | 不动参数修订指令 | 细粒度区分难以表达；输入变长推高成本 |

**本文突破**：推理模型供任务知识与监督 + 决策模型供毫秒级执行 + 少量真实交互经验池——三要素首次同时满足。

## 三、问题定义

### 3.1 从具体场景到抽象问题

具体场景：让 AI 在《绝区零》《黑神话：悟空》这类商业游戏客户端里实时对战。抽象后，问题是一个三元组约束下的能力形成问题：

- **给定**：一个环境 E（连续演化、不可暂停、不可并行、约 200ms+ 的响应窗口）；一个通用决策模型 f_θ（27B，JEV 类）；一个可自由使用的推理模型 T（时间上无限慢但可以场外用）；
- **求**：系统 S = (f_θ, C_φ)——决策模型 + 控制器 C_φ（决策树/行为树），使在线控制表现最大化；
- **约束**：①零专家操作演示；②不包模拟器、不改环境动力学、不开并行实例；③交互预算仅为少量真实 episode。

形式化非常干净（论文式 1）：z_t = f_θ(o_t, q)，a_t = C_φ(z_t)。观察 o_t 和任务问题 q 进，**结构化判断** z_t 出（单次前向），控制器把判断映射为动作。注意输出的是"判断"而非"动作"——这个接口选择是全文的枢纽（见第六部分分析）。

### 3.2 教练-学生类比的结构对应

| 人类运动学习 | System-One RSI |
|---|---|
| 深度思考（教练的物理知识） | 推理模型 + 松散描述的先验知识 |
| 教练看录像、指出错误 | 推理模型离线分析图像 + 动作日志 |
| 隔离训练动作（针对缺失区分） | 定向经验采集 + 视觉标注协议 |
| 非精确语言指导 | 推理模型用自然语言写控制规则与标注规范 |
| 肌肉记忆 | LoRA 固化进决策模型参数的判断 |
| 高频实时任务（骑车/游泳） | OODA 循环 ~230ms 闭环 |

这个抽象的精妙之处：它把"知识"与"能力"分离——推理模型有知识没速度，决策模型有速度没经验，**练习（practice）是把前者转化为后者的唯一通道**，而教练让练习的每一分钟都花在刀刃上。递归性体现在（论文式 2-5）：第 r 轮的部署系统产生第 r 轮的经验，经验决定第 r+1 轮的监督与模型——每一轮都建立在前一轮系统自己产生的证据上。

## 四、问题解法

### 4.1 全景：内外双循环

**内层 OODA 循环（在线，~230ms）**：Observe（截帧）→ Orient（决策模型单次前向，对每个任务相关问题返回一个结构化判断；可选 CV 前处理）→ Decide（模型撰写的决策规则把多个判断联合映射为动作）→ Act（执行接口按键，含按键时长毫秒级指定）。**推理模型完全不参与内层**——这是延迟的保证。

**外层 RSI 循环（离线）**：由四个推理模型 agent 组成的团队驱动：
1. **Planning & Coordination Agent**：维护任务规范，编排两条更新路径（改控制器 vs 改模型）的分工与反馈；
2. **Rollout / Capture Agents**：执行 OODA 并录制"图像 + 动作"同步日志，从简单策略甚至随机策略起步，保证首批记录反映环境而非预设策略；
3. **Visual Labeling Agent**：给录制观察分配监督标签——或直接标注，或定义一套从记录事件推导标签的协议（如从受击事件反推闪避窗口标签）；
4. **Training / Deploying Agent**：训练（LoRA SFT）、验证（NLL 选 checkpoint）并部署新权重回 OODA runner。

### 4.2 训练细节：把区分写进参数

- **监督来源**：无需奖励函数、无需专家演示。标签 = 推理模型直接标注 ∪ 事件驱动协议（如"该帧之后 N tick 内是否受击"）。论文坦承其认识论边界：轨迹标签只描述已执行动作下发生的事件，**不能告诉你换一个动作会发生什么**（无反事实）。
- **经验池**：跨轮保留观察、动作、结果；采样可偏向错误、稀有状态、任务相关事件；相邻相关帧在数据预算核算时须与独立经验区分。这与模仿学习里 DAgger 的数据聚合动机同源（在当前策略访问的状态上收集标签）。
- **参数更新**：LoRA 只作用于攻击预警类问题（ZZZ），视觉骨干冻结、决策头与校准不动；标签频率失衡时用类别加权 focal loss。ZZZ v1 用 922 训练帧 / 164 验证帧，v2 累积到 1,462 / 260。
- **每轮成本**：ZZZ 每轮 5 局、迭代 ×2；Wukong 每轮 20 局、迭代 ×4。

### 4.3 三种改进模式与迁移

系统 S = (f_θ, C_φ) 的两个组件是**独立的改进对象**：
- **Model-only**：固定控制器，微调判断（感知不足时）；
- **OODA-only**：固定模型，推理模型修订决策规则/动作时序/配置（判断对但映射错时）；
- **Joint**：两者同改（任务问题或输出 schema 变了，接口两侧必须同步）。

迁移同理：换环境时可固定 adapter 只改控制器（判断是否仍适用）、全固定（直接迁移）、或联合适应。**判断接口与动作映射的分离**让"学到了什么"与"怎么用"可以分别审计和复用。

### 4.4 延迟控制：交错推理与独立执行

即便单次前向够快，控制器还要让观察、决策、执行持续流动。论文 Figure 11 给出调度模式：三个推理 worker 错峰启动（间隔约 L/3），每个启动时读**最新**帧而非排队等旧帧；新调度可覆盖未执行的旧调度，动作队列满时丢弃最旧动作——以此限制过期工作量。作者诚实地标注：结果间隔 L/3 是理想调度性质，**不是**单次推理时间被缩短；且并发仅在服务容量充足时有效，延迟预算必须按完整"观察→执行"路径核算。

## 五、评估指标与实验证据

### 5.1 三个环境与指标体系

| 环境 | 任务 | 主指标 | 辅助指标 |
|---|---|---|---|
| Snake（贪吃蛇） | 纯图像、多障碍、真实观测延迟 | 平均分 1.30→7.35 | — |
| Zenless Zone Zero（绝区零） | 攻击预警判断 + 在线对战 | balanced 准确率；胜场 | 完成时间、t50、决策延迟 |
| Black Myth: Wukong（黑神话） | 闪避生存 / 进攻取胜 | 平均生存时长；胜率 | 获胜局时长 |

**为什么 balanced accuracy 是主指标**：260 帧验证集里 224 帧 none、11 帧 yellow、25 帧 red——极度失衡。always-none（永远答"无预警"）基线 top-1 高达 86.15%，但三类召回平均只有 33.33%，实战中等于永远不闪避。balanced accuracy 对三类召回等权，衡量的正是"该闪避时看得出要闪避"的能力——**指标设计直接对应任务本质**。

### 5.2 ZZZ 攻击预警验证（260 帧，224/11/25 类分布）

| 模型 | Top-1 (%) | Balanced (%) | NLL |
|---|---|---|---|
| Always none | 86.15 | 33.33 | N/A |
| zzz-rsi-base | 63.85 | 44.52 | 0.6799 |
| zzz-rsi-v1（922 帧） | 79.23 | 74.87 | 0.4565 |
| zzz-rsi-v2（1,462 帧） | 81.15 | 77.98 | 0.4966 |

LoRA 微调一轮把 balanced 从 44.52% 拉到 74.87%，二轮到 77.98%。注意 v2 的 NLL（0.4966）反而比 v1（0.4565）差但 balanced 更好——checkpoint 按 NLL 选，选出的却是在关键少数类上更强的模型，恰说明单一指标与任务目标可能脱节。

### 5.3 ZZZ 在线对战（每配置 5 局、300s 上限）

| 模型 | 胜场 | 中位完成 (s) | 中位 t50 (s) | p50/p95 延迟 (ms) |
|---|---|---|---|---|
| zzz-rsi-base | 2/5 | 261.2 | 167.0 | 231.4/244.2 |
| zzz-rsi-v1 | 5/5 | 236.2 | 26.0 | 229.1/249.4 |
| zzz-rsi-v2 | 5/5 | 239.3 | 29.7 | 230.2/255.0 |

t50 = 对手失衡槽首次过半的时刻，衡量"打出压制力"的速度：从 167 秒压缩到约 26-30 秒，**快了一个数量级**。决策延迟稳定在 ~230ms——适应没有以牺牲速度为代价（判断还在单次前向里）。论文如实标注：5 局不配对样本无法建立 v1 与 v2 的排序。

### 5.4 ZZZ 控制器修订（9 对手、39 尝试、26 完成）

| 对手 | v2 平均 (s) | v3 平均 (s) |
|---|---|---|
| YeShiyuan | 242.7 | 159.3 |
| Amalgam | 207.2 | 190.8 |
| Butcher | 214.0 | 163.0 |
| Pompey | 245.0 | 194.0 |

| Sweeper | 278.0 | 242.0 |
| Girtab | 无完成 | 243.0 |

Girtab 从零完成到两次完成（257s/229s）是质变；YeShiyuan 缩短 83 秒。论文强调：各对手样本数与完成子集不同，这些均值描述的是"观察到的 runs"，不是均匀改进率；且该研究**没有隔离固定权重的控制器干预**。

### 5.5 Wukong 闪避生存（纯闪避策略，不攻击不治疗）

| 模型 | 局数 | 平均 (s) | 中位 (s) |
|---|---|---|---|
| 静止参考 | 6 | 23.6 | N/A |
| wk-rsi-v1 | 10 | 108.1 | 114.9 |
| wk-rsi-v2 | 10 | 160.0 | 170.1 |
| wk-rsi-v3 | 5 | 160.9 | 166.7 |
| wk-rsi-v4 | 5 | 260.5 | 212.2 |

从站着挨打 23.6 秒到 v4 平均 260.5 秒（**11 倍**），v3→v4 提升约 62%。必须注意批次断裂：v1/v2 批次动作冷却 350ms，v3/v4 批次 500ms，两段不可直接比较。

### 5.6 Wukong 进攻取胜（闪避 + 攻击 + 治疗协同）

| 模型 | 局数 | 胜率 (%) | 全局平均 (s) | 获胜局平均 (s) |
|---|---|---|---|---|
| wk-rsi-base | 10 | 0.0 | 21.9 | N/A |
| wk-rsi-v1 | 10 | 20.0 | 74.1 | 139.7 |
| wk-rsi-v2 | 10 | 30.0 | 89.5 | 122.4 |
| wk-rsi-v3 | 15 | 60.0 | 139.7 | 154 |
| wk-rsi-v4 | 15 | 66.7 | 125.3 | 131 |

基线 10 局全败，v4 十五局赢十（66.7%），获胜局平均 131 秒——递归迭代呈单调爬升。同样诚实标注：两批次控制器设置不同、获胜子集不同，数值未隔离模型适应本身的效应。

### 5.7 实验设计的证明力评估

这套实验能证明的：细粒度视觉判断可通过极少真实交互固化进参数（验证集 +33 个百分点 balanced），且判断精度提升**传导**为在线胜率与压制速度（离线/在线两端闭环）。不能证明的：v1 与 v2 的优劣排序、控制器修订的净效应、批次间可比性——论文逐条自我声明，这在同类工作中相当罕见。

## 六、效果优势的根源解释

### 6.1 根源机制与因果链

**因果链主干**（每步标注证据等级）：

1. **推理模型在时间关键路径外供给任务知识与监督**【论文设计已支持】：教练团队离线写控制规则、定义问题 schema（如攻击预警三分类）、制定标注协议——推理的分钟级延迟被完全隔离在 200ms 窗口之外。对比：推理型 computer use 每步都付推理税，VARP 干脆暂停游戏。反事实：若推理模型参与在线循环，延迟立即超出窗口——这是结构约束而非工程调优问题。
2. **LoRA 把提示传不了的细粒度视觉区分固化进参数**【论文实验支持】：预攻击 (a)(b) 与闪避窗口 (c) 的差异（武器角度、姿势近期变化）——论文 Table 1 明示提示优化的结构性限制：细区分难以表达、长输入推高成本；MedJev 等工作证实多图长提示使延迟增长数倍。balanced 44.52%→77.98% 正是"参数承载了提示承载不了的区分"的直接证据。
3. **单次前向取代逐步推理 → ~230ms 稳定闭环**【论文实验支持】：p50 延迟在 base→v2 间几乎不动（231→230ms），而判断质量剧变——速度与精度解耦，因为两者由不同机制承担（架构供速度，参数供精度）。
4. **判断精度转化为在线表现**【论文实验支持，但样本小】：预警 balanced 提升 → 胜场 2/5→5/5、t50 167→~28s（压制速度 ×6）、Wukong 胜率 0%→66.7%。转化路径清晰：更早更准识别 red 预警 → 决策树在正确时刻触发闪避/格挡 → 受击减少、输出窗口增加。【每配置仅 5 局，效应方向明确、幅度置信区间宽——阅读者标注】
5. **经验池跨轮复用放大稀缺交互的价值**【论文设计 + DAgger 文献支持】：v1→v2 训练帧 922→1,462（累积而非替换），下一轮建立在上一轮系统自己访问的状态分布上——这正是 DAgger（Ross et al. 2011）刻画的 policy-dependent state distribution 问题的对偶利用。
6. **模型/控制器分离使改进可定向**【论文设计支持】：感知不足改 θ、映射不足改 φ——9 对手实验走的是 OODA-only 路线（模型不动、行为树修订），Girtab 从零完成到两次完成证明"判断已够好、用法不对"这一诊断的真实存在。

**结构上必然更好的理由**：六条路线各自缺一角（Table 1），本文不是在某条路上做得更努力，而是**把三要素分配给各自唯一胜任的载体**——知识给推理模型（场外、无限慢）、速度给架构（单次前向）、经验给参数（LoRA）。任何单一载体承担两个要素都会撞上结构墙：提示装不下经验（路线 6 的墙），推理挤不进窗口（路线 3 的墙），RL 拿不到交互量（路线 1/2 的墙）。

### 6.3 综合判断与未决问题

**多来源共同支持的机制**：①"慢思考蒸馏进快直觉"有效（AlphaGo Zero 谱系 + 文本蒸馏谱系 + 本文，三域独立重现）；②推理延迟是结构性约束（Realtime-Bench + VARP 的暂停妥协 + 本文）；③判断/动作接口分离的可组合性（Jeva 生态 + 腾讯双系统 + 本文的 OODA-only 实验）。

**仍属合理推测的部分**：④"教练监督比无指导试错更数据高效"——本文有人类玩家常识作侧证（人类学 dodge 远快于数千次试错的 RL），但论文未做无教练消融；⑤判断精度到胜率的转化幅度——方向有证据，量级受 5 局样本限制。

**优势成立的前提**：任务判断可被有限 schema 枚举（预警三分类、受击倒计时）、视觉区分可从少量帧学会、有可用先验知识供教练起步。**可能失效的条件**：先验缺失或错误会同时误导探索与监督（论文自陈）；环境剧变时经验池分布失效；监督标签来自轨迹、天然缺乏反事实信息——如果错误恰好出在"没试过的动作"上，教练也看不出来。此外论文自陈的方法学限制必须如实记录：训练/验证集同源 episode、验证集同时用于 checkpoint 选择与成绩报告（选择偏倚，引 Cawley & Talbot 2010）、批次间 cooldown 不同（350ms vs 500ms）导致 Wukong 四代不可全段比较、每配置 5 局的样本量。**这些限制不影响"结构性路线成立"的定性结论，但任何具体数字的精确比较都应谨慎。**

## 七、必要知识反推

假设把一个空白的团队放进这个课题，最少必须知道什么？

### 7.1 领域知识层

- **实时控制与响应窗口**：必须理解 ~200ms 窗口意味着什么（视觉停留时长量级），否则不会把"推理移出在线路径"当作第一原则；
- **动作游戏的视觉语法**：前摇/后摇/闪避窗口/失衡槽——不知道"预警帧"这个概念，连该问决策模型什么问题都定义不出来；
- **运动学习与刻意练习**：Ericsson 的刻意练习理论（教练、隔离训练、针对薄弱环节）——整篇论文的组织隐喻与流程蓝本；卡尼曼双系统——System 1/2 分工的认知科学根据。

### 7.2 方法论知识层

- **决策模型/JEV 架构**：单次前向返回结构化判断的接口、决策头与校准——这是"肌肉"的载体；不知道它就不会想到判断可以参数化；
- **蒸馏谱系**：System 2→System 1、Policy Distillation、Distilling Step-by-Step——知道"教师信号可以不是答案而是判断"；
- **模仿学习的数据聚合**：DAgger 揭示的 policy-dependent state distribution——经验池跨轮累积的理论依据；
- **RSI 谱系**：Voyager/Reflexion/Self-Refine/DGM 各自改什么（代码/记忆/权重）——本文"改判断 + 改规则、训练流程固定"的定位需要这张地图才能想清楚；
- **类别不平衡学习**：focal loss、balanced accuracy——没有这一条，会被 86% 的 always-none 基线骗过。

### 7.3 工程知识层

- **推理服务与延迟预算**：交错 worker、覆盖式调度、队列丢弃策略、完整观察→执行路径的核算——延迟是设计出来的不是测出来的；
- **屏幕捕获与输入注入**：帧同步、动作日志毫秒级对齐——经验池的原始材料；
- **LoRA 实操**：冻结骨干、只调 adapter、NLL 选 checkpoint——把训练成本压进"几局游戏 + 几分钟微调"的预算。

### 7.4 知识融合的关键节点

三个化学反应点：**① 教练隐喻 × LoRA**——"教练的非精确语言指导"与"低秩参数更新"在结构上同构（都只动一小块、都依赖学生已有基础），融合出"外部肌肉记忆"概念；**② DAgger × RSI**——数据聚合的迭代依赖被重写为"系统自己产生下一轮的证据"，把模仿学习的旧工具变成自改进的新引擎；**③ 双系统 × OODA**——OODA 循环本是军事决策框架，与决策模型的结构化判断接口对接后，Orient 环节首次可以被一次前向填满。

## 八、论文中可以提取的通用性灵感

### 灵感 1：知识载体与执行载体的彻底分离

**核心思想**：有知识的不必执行，执行的不必有知识——用"练习"做传送带。
**论文证据**：推理模型零参与在线循环，决策延迟 ~230ms 不随判断质量提升而变化；六路线对照表证明任何"一载体双职能"方案都撞结构墙。
**推广场景**：机器人（大模型场外规划课程、小模型在线控制）；金融交易（研究模型离线生成信号定义、低延迟模型盘中执行）；客服系统（推理模型设计话术判断标准、决策模型毫秒级路由）；自动驾驶（车队教练分析事故录像、车端模型固化反应）。

### 灵感 2：专家演示不是经验学习的必要条件

**核心思想**：教师 + 环境 + 协议 = 监督信号，可以完全不请专家"做一遍给你看"。
**论文证据**：全程零专家操作演示，标签来自推理模型标注与事件驱动协议（受击事件反推闪避窗口标签）；ZZZ 每轮仅 5 局即完成一轮适应。
**推广场景**：稀缺专家领域（外科手术、高危工业操作）的自动化训练数据生产；无法重放的线上事故复盘；古董/濒危技能的数字化保存——录像 + 教练推理 ≈ 演示的替代品。

### 灵感 3：把"改提示"升级为"改参数"，当且仅当知识无法被语言完整传达

**核心思想**：提示是知识的外挂、参数是知识的内化；细粒度感知经验属于后者。
**论文证据**：预攻击 vs 闪避窗口的姿势/武器角度差异——提示写不清、few-shot 传不动，LoRA 后 balanced +33 个百分点；论文 Table 1 明确列出提示优化路线的表达力天花板。
**推广场景**：医学影像（病灶边界感知微妙差异难言传）；工业质检（缺陷形态谱系难以穷举）；鉴伪（笔迹/纹理直觉）；任何"老师傅看得出来但说不出来"的领域。

### 灵感 4：不平衡场景的指标必须对齐任务本质

**核心思想**：在 86% 与 33% 之间选 44→78 的那条线——top-1 会骗人，类别等权的指标才对应"关键时刻不缺席"。
**论文证据**：always-none 基线 top-1 86.15% 但实战等于躺平；balanced accuracy 揭示真实能力差距；NLL 最优 checkpoint 与任务最优 checkpoint 不一致。
**推广场景**：欺诈检测（正例稀少）、罕见病筛查、故障预警、内容审核——一切"漏报代价远大于误报"的场景。

### 灵感 5：经验池是稀缺交互的复利账户

**核心思想**：在不可重放的环境里，每一次真实交互都应被永久保留、跨轮复用、定向重采样。
**论文证据**：v1→v2 训练帧 922→1,462 累积；采样可聚焦错误与稀有状态；DAgger 理论背书。
**推广场景**：生产事故数据、临床稀有病例、军工试验、航天遥测——凡"样本昂贵且不可再生"的领域都需要经验池思维而非"用完即弃"的数据集思维。

### 灵感 6：诚实的方法学自检本身就是贡献

**核心思想**：小样本 + 选择偏倚 + 批次断裂，与其藏，不如逐条声明并指出正确做法。
**论文证据**：论文主动引用 Cawley & Talbot 说明验证集复用的选择偏倚；逐条标注 5 局不建序、cooldown 不同不可比、无固定权重对照——并给出"未来评估应分离 checkpoint 选择与测试、保留旧模型对照"的改进方向。
**推广场景**：所有小样本实证研究（初创产品评估、临床试验早期阶段、线下实验科学）的报告规范。

## 结语

对本系列持续追踪的决策模型浪潮而言，这篇论文补上的是"最后一公里"的问题：此前我们看到的决策模型——Jeva 的架构、AnyS1 的训练、Piccolo 的数据工程、System 1 agents 的编译——都在解决"如何让模型做好判断"，而 System-One RSI 回答的是"一个现成的决策模型如何在几个真实 episode 内学会新任务"。答案优雅得像它引用的运动科学：**别让聪明人上场踢球，让聪明人当教练**。推理模型的全部知识通过控制规则、问题 schema 和标注协议在场外注入，LoRA 把它们压进参数成为肌肉记忆，运动员在 230 毫秒内凭条件反射行动。它的证据还带着小样本研究应有的谦逊——5 局、同源验证集、断裂的批次——但方向的合理性由六条路线的结构性对照、三个环境的同向结果和跨域蒸馏文献共同托底。当实时交互成为 AI 下一个主战场（从游戏 QA 到机器人到自动驾驶），这套"教练-学生-肌肉记忆"的范式值得放进每个 agent 工程师的工具箱。
