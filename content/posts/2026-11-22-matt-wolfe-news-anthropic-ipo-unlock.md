## 先说结论

这一期的头条是 Anthropic 上市：节目称其以每股 83 美元发行 9.8 亿股、募资 813 亿美元，超过今年 6 月的 SpaceX 成为史上最大 IPO，周四在纳斯达克（代码 ANT）开盘 111.50 美元、收于 97.17 美元（首日约 +17%），公司估值约 1.27 万亿美元、位列全球第 12。但 Wolfe 认为首日股价不是重点——重点是这家公司把内部人股份做成了分阶段解锁：12 月中旬到 2 月初，最多 16 亿股内部人股票获准流通，超过 IPO 本身的发行量。这张有日期的解锁日历，把「AI 是不是泡沫」从一个争论变成了一场可以旁观的实测。模型侧，OpenAI、Google、微软同周各发一个（组）新模型，共同主题被他一句话点破：「花更少的钱买到更多聪明」；而他用自己的「惊艳我」测试发现，两个 OpenAI 模型在无人引导时交出了几乎雷同的深海网站答卷——收敛与品味问题浮出水面。文章按 IPO 机制→三模型横评→品味测试→工具与快新闻展开，最后给出可操作的观察清单。

## 一、史上最大 IPO 的正确读法：解锁日历才是试纸

先对齐事件本身（节目称）：周三夜间定价每股 83 美元、发行 9.8 亿股、募资 813 亿美元；周四开盘 111.50 美元、收盘 97.17 美元、首日上涨约 17%；截至录制时估值约 1.27 万亿美元、全球第 12 大公司。上市日的媒体叙事本站已有两篇展开——[Hard Fork 的上市日连线](https://inkeast.github.io/MessageDaily/posts/2026-11-22-hardfork-gta6-anthropic-ipo/)（节目称完全稀释估值超两万亿、募资超 2000 亿）与 [Latent Space 的 S-1 拆解](https://inkeast.github.io/MessageDaily/posts/2026-11-21-latent-space-anthropic-ipo-tanay-jaipuria/)；本站不调和两组口径，仅照录 Wolfe 本期自述数字。

Wolfe 的独有贡献是把注意力从价格挪到了解锁结构上（节目称）：常规 IPO 的内部人锁定约六个月，而 Anthropic 分阶段解锁——上市首日员工即可卖出各自持股的 10%（合计上限 3.15 亿股）；下一批在 12 月中旬；1 月 5 日至 2 月 2 日之间还有三批；到那时累计最多 16 亿股内部人股份可卖，已超过 IPO 本身；其余大部分在六个月内解锁，只有联合创始人与最大股东最多要等一年。他的推理链很干净：握股的人是最了解公司的人——亲手建造它的员工、看过多年每一份报表的投资者；接下来几个月，这些人逐批面对「落袋还是持有」的选择。他特意说明：卖一部分完全正常（员工要买房、风投要回钱），不值得恐慌；要看的不是「卖没卖」，而是「卖多猛」。如果离公司最近的人在第一个窗口就大举出货，这种怀疑会很快传导到整个 AI 市场；反之，在能带着几十亿美元离场时选择持有，就是信息最多的人在表态「我们还在早期」。他给出的第一个观察日期是 12 月中旬。

上市还改变了两件事（节目称）。其一，账本每季度公开：招股文件已显示上半年营收 163 亿美元（上年同期约 12 亿美元）、算力支出 89 亿美元——此后不必再依赖泄露消息。其二，多了一个盯着股价的股东群体，而把这一切看得最紧的是 OpenAI：节目引用其 CFO 对员工的说法，OpenAI 计划 2027 年或更早上市。Wolfe 的收尾希望（标注为主播愿望）：解锁到来时人们大多持有——那说明对 AI 大盘有信心；如果风投们一获准就尽快倾倒，那说明它们是来赚快钱的，「泡沫破裂式局面」可能就此开场。

## 二、三份新答卷：前沿战争打到「每任务成本」

本周三个新模型，Wolfe 全部实测。第一个是 OpenAI 的 GPT-6.2 Astra 与 GPT-6.2 Soul（节目称）：Astra 是顶级难题模型、Soul 是便宜日常款，均已进入 ChatGPT 与 Codex 付费档；卖点是「用更少的 token 干完同样的活」——API 实际便宜 20%，Astra 每百万输入/输出 token 为 8/40 美元，Soul 为 2/10 美元（价格与上代持平、更省 token）。在 Artificial Analysis（下称 AA）上 6.2 Astra 是第二聪明的模型、仅次于 Claude Fable 5.2，但每任务成本 4 美元对 Fable 5.2 的 26.54 美元——基准分只差三分（节目引用 AA）。这个模型的差评海啸与系统卡争议，站内已有两篇深挖（[差评三层拆解](https://inkeast.github.io/MessageDaily/posts/2026-11-21-ai-daily-brief-astra-62-backlash/)、[系统卡深读](https://inkeast.github.io/MessageDaily/posts/2026-11-22-ai-explained-astra-system-card-race-to-top/)），此处不重复；本期增量是他的自有基准：视觉基准 Bussy Bench 上 Astra 7.4 分/第 6 名（1.42 美元、约 5 分半），Soul 6.9 分/第 18 名（68 秒、14 美分）——而被替代的旧款 6.1 Soul 仍以 8 分排在榜首，新 Soul 在该视觉测试上实际退步；Pro 版（Astra Pro 7.6 分/4.24 美元/近 17 分钟，Soul Pro 6.8 分/约 1.04 美元）反而不敌普通版，画 SVG 不值得上 Pro（Matt 实测）。Megabonk 游戏测试里 Astra 做出他见过最好的开场画面（他猜测因为调用了 GPT 图像模型，主播猜测），玩法正确、优于 Fable 5.2、接近 Opus 5.5；早测者「过早停手、大项目难跟随」的批评与 OpenAI 自家报告「更易略过途中问题」他也照录（节目引用）。结论：Claude 用户不必换，ChatGPT 用户直接拿它试视觉活。

第二个是 Google 的 Gemini 4 Neon（节目称）。家族座次：Carbon 是对标 Fable/Astra 的大杯，Neon 坐中间主力档（对标 Opus/Soul），定价每百万输入/输出 3/15 美元、100 万 token 上下文，无免费档（AI Pro/Ultra 可用）。数字面（节目引用 AA 与 Google）：智能指数 61，只比 OpenAI 当前最强的 6.2 Astra 低 1 分、价格不到其一半；比自家 Carbon 每任务便宜 32% 还高 1 分；AA 编码代理指数以 59 分排第一——在 Claude Code 里的 Fable 5.2 与 Codex 里的 6.2 Astra 之前，且登顶组合是「Neon + Google 的 Antigravity」。Wolfe 的实测：Bussy Bench 7.1 分/第 12 名、70 美分、约 5 分钟（约 Astra 半价、低 0.3 分，Carbon 仍以 7.9 居第二）；Antigravity 本身大幅进步、「接近 Codex 还差一点」，而且已可在里面选用部分 Claude 模型；Megabonk 克隆机制全对、画面不如 Astra。Neon 的发布与 Pareto 前沿视角，[Wes Roth 一期](https://inkeast.github.io/MessageDaily/posts/2026-11-21-wes-roth-gemini-neon-victus-arena/)已展开，此处不赘述；Wolfe 的增量判断是：这是「眼下最佳性价比、尤其走 API」，而且「永远别把 Google 排除出局——他们手里的训练数据比谁都多」（主播判断）。

第三个几乎全是价格故事：微软 Ignite 大会发布的 MAI Code 2（节目称，数字全部为微软口径）——号称以 40% 的成本实现 GPT-6.1 Soul 98% 的性能、以 5% 的成本实现 Claude Opus 5.5 的 96%；盲测前端应用评估中 64% 的开发者更prefer它而非 GPT 6 Soul（Wolfe 猜这偏设计维度）；不针对复杂长项目，已进 GitHub Copilot、将上 OpenRouter 与 Vercel。顺带一句他的私货吐槽：MAI Code 2 发布日恰好撞上 OpenAI 的 6.2 发布，「OpenAI 就爱挑别家 keynote 同一天发东西抢风头——他们自己不承认，但绝对干」（主播观点）。Ignite 其余两件同话术：「以零头价接近最好」——图像模型 MAI Image 2.7 在 AA 图像编辑榜第一（文生图第四、落后 ChatGPT 图像系）、实时语音模型 MAI Realtime One 起步每音频分钟 1 美分。

## 三、「只要惊艳我」：一次测出模型的默认品味

这是本期最有意思的原创测试。动机来自他周二那期视频的观察：vibe-coded 网站开始长得都一样。于是他把同一条提示词原样丢给本周三个模型：「给我建一个真正让我惊艳的网站……主题由你定，只要惊艳我。」——看模型在没人指挥、没人引导设计时拿什么出来（Matt 实测，首次公开结果）。

结果颇有戏剧性。Astra 交出「Pelagic Ocean Atlas（远洋图集）」：动画水母、海藻床、鱿鱼，可下潜、可记录深度、带音效——漂亮但交互有限。Soul 交出的竟是同一个创意的微调版：同样的深海、同样的「下潜」叙事，连「below the light / begin descent」这样的措辞都部分相同。两个不同模型、同一条自由提示词，做出几乎同一个网站。他随即引用 Theo Brown 的长文佐证（节目引用）：Theo 与播客搭档让 6.2 Astra 在两个完全不同的游戏里各做一个独特关卡，两人拿到的是同名同主题的「水＋音乐＋铃铛」关卡 Bellweather——原文的判词是「它太频繁地向均值回归」。Wolfe 感叹自己刚刚亲历了同一现象。而 Neon 完全换了方向：一个机械腕表主题站——模拟指针、齿轮组装与镂空分解视图、悬停点亮背景、制表师放大镜检查细节。他的裁定：在「自由发挥」这件事上 Neon 明显优于两个 OpenAI 模型，且综合编码能力、价格与设计感，是当前最佳性价比、可当日常主力。这个测试的迁移价值在于：评估模型别只看「照着做」的基准分，要看「没人给方向时」的默认输出——那是训练分布趋同与否、品味差异最诚实的暴露口。

## 四、一句话建站与快速连发：agent 从「说」走到「做」和「买」

工具侧的主角是 Gemini Notebook（原 NotebookLM，节目称）：新功能让你输入「Make me a site」并描述需求，它基于你装载的资料源生成交互式网站——销售仪表盘、任务追踪器、备考学习站。Wolfe 现场实测：把本周新闻笔记本喂给它，约两分钟生成一个报纸样式的新闻站，含图表、表格、可筛选的来源列表。一个值得留意的细节：生成站的大标题写「Anthropic 1.8 万亿美元的登场」，与他自述的 1.27 万亿估值并不一致——他把两者都展示了出来，这恰好是 AI 生成内容需要核数的现场教材（两说均照录）。

快速连发部分按主线归组。支付与接管电脑：ChatGPT Wallet 与 American Express、Chase、Mastercard、Visa 合作（节目称）——信用卡只存一次、每笔购买需 Face ID 或指纹确认，agent 拿到的是替身卡号、永远看不到真卡号；目前仅美国、仅信用卡、仅限每月 100 美元起的 Pro 套餐；Wolfe 坦言自己还没设置、「还是不太舒服把信用卡交给 agent」（主播态度）。Gemini 的 Mac 应用新增「替你用电脑」：后台窗口里跨应用点击、打字、填表，你指定可触碰的应用、大动作前先询问，官方示例是从一张蝴蝶画在 Blender 里重建并做成动画；仅美国、需 Apple Silicon、付费档。Claude 的常驻助手 Duet 向美国全部 Pro Max/Ultra 候补用户开放，但后台运行计入正常限额——重度用户额度消耗会加快。声音与影像：HeyGen Avatar 6 号称单张照片生成无时长上限的说话视频、示例 25 分钟以上单镜头 2K，并宣称「图灵测试 84%」——其口径是在 42% 的场合人们把 AI 片段当成了真的（50% 即无法分辨；厂商宣称，Wolfe 未实测）；Suno 上线 visuals，为歌曲生成歌词视频/专辑封面/片段（单段上限 15 秒、积分另算）；ChatGPT 加了实时听写（边说边出字）。开发者侧：Google Labs 的 Stitch Loop 接入代码与应用数据、持续检查安全/性能/无障碍并构建修复待审批（候补中、价格未知）；桌面版 Claude Code 可口述主题自定义界面（「不增产但好玩」）；ChatGPT for sales 打包销售工作流、接入 HubSpot/Salesforce/Gong/Granola/DocuSign 等 30 余工具（仅商业版/企业版）。世界模型：DeepMind 的 Genie 4 仅向 Ultra 订阅者开放——输入提示生成可实时走动的世界、且可在世界中改提示（换天气、加角色）、边走边生成含人声的音效；老款 Genie 3 的单世界时长从 1 分钟提到 3 分钟。

## 观察与启发（机制 → 影响 → 启发）

1. **解锁日历=信念的可观测事件。** 变化：分阶段解锁让信息最多的人（员工/VC）逐批获得卖出权 → 12 月中、1 月 5 日、2 月 2 日是天然实验窗口 → 谁得谁失：持有=内部人对 AI 大盘背书，倾销=「赚快钱」叙事坐实 → 二阶影响：结果直接为 OpenAI（CFO 称 2027 年或更早上市，节目引用）的定价与条款搭台 → 观察指标：各解锁日的抛压与内部人交易披露 → 读者启发：与其争论泡沫，不如把内部人行为当最高质量的信念信号排进日历。
2. **竞争轴心从「最聪明」移到「每任务成本」。** 变化：三巨头同周发布「几乎一样聪明、便宜得多」的模型（Astra $4/任务对 Fable $26.54；Neon 半价追平 Astra、登顶编码代理指数；MAI Code 2 以 4 成成本卖 98% 性能） → 原因：API 用量增长放缓后，单价成为存量竞争的主变量（推断） → 谁得：应用开发者与企业买家；谁失：坚持质量溢价的 Anthropic 与 Pro 档订阅价值 → 二阶影响：应用层毛利改善、聚合器议价力上升 → 观察指标：AA 每任务成本、编码代理指数 → 启发：选型按价位段与任务类型，别按聚合榜总分。
3. **「自由发挥」暴露分布趋同。** 变化：同一自由提示词下 Astra 与 Soul 交出雷同深海站（Theo Brown 的 Bellweather 关卡互证） → 机制：训练数据与对齐目标趋同→默认审美向均值回归 → 谁得：输出差异化的模型（Neon 的机械表站）与会引导品味的用户；谁失：「AI 出品」的模板化价值 → 二阶影响：品味从模型属性变成提示工程责任 → 观察指标：新模型在零引导任务上的输出多样性 → 启发：评测一个模型，先看它没人指挥时拿出什么。
4. **支付隔离层让 agent 商务成为可能。** 变化：ChatGPT Wallet 用「替身卡号＋生物识别逐笔批准」把卡号与 agent 隔离 → 机制：授权粒度从「给卡」细化到「给单笔」 → 谁得：高频小额自动化；谁失：完全托付的便利性（每笔都要确认） → 二阶影响：agent 可完成的商业闭环边界由风控设计决定 → 观察指标：交易限额、拒付与订阅类扣款的处理 → 启发：给 agent 授权时先读隔离层设计，摩擦即安全边界（Wolfe 本人暂不启用，同样是一个数据点）。
