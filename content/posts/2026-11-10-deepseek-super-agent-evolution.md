## 先说结论

这是一场主播 **杜宇说AI**（自述有移动互联网时代投资背景，以下称主持人）在 2026 年 11 月做的下午场直播复盘，连麦两位嘉宾：技术视角的 **Gate元宝**（自述正在创业、做一个具身智能多 agent 协作项目，以下称元宝）和零五后 UP主 **三颗门牙X**（以下称门牙）。谈话由两组数字点燃——DeepSeek 官方当天凌晨公布的 **API 日活 154 万**、**单日 token 消耗 92 万亿**（原话「将近一百亿亿」，两个量级自相矛盾，以前者为准存疑记录），叠加 10 月 31 日 Harness 团队公布的 **Super Agent 架构**。三位讲者的核心判断高度一致又互为补充：Super Agent（Router+Worker 双层架构）**不是从零到一的惊艳，而是从「没有组织」到「有组织」的必经一步**——元宝的打分是：如果年初 OpenClaw（养虾）让 LLM「长出双手」算十分，Super Agent 只值五分，下一个十分可能是具身智能从虚拟走进物理世界。对读者真正有价值的不是「又火了一个概念」，而是三个可迁移的判断：**基模再强也替代不了组织架构**（清华毕业生≠清华项目经理）、**执行已被 AI 压缩后，验收成了新瓶颈**（节目引述约 30%–40% 时间花在验收 AI 输出上）、**agent 生态的安全问题本质是权限与组织设计问题**。本站此前已写过 [DeepSeek Harness 的开放逻辑](https://inkeast.github.io/MessageDaily/posts/2026-08-24-deepseek-harness-open-strategy/)（两天十万 Star、一切皆插件）与 [DeepSeek V4.1 Flash 实测](https://inkeast.github.io/MessageDaily/posts/2026-10-29-matt-berman-deepseek-v41-flash-crushed/)，本文聚焦 Super Agent 架构本身与这一年 Agent 赛道的完整脉络。

## 官方数据先行，架构后来：Super Agent 到底「新」在哪里

先把事件的时序摆正（以下均为节目陈述）：DeepSeek Harness 的桌面端 **9 月底才发布**，主持人的判断是「这个增长速度史无前例」；Super Agent 架构由 Harness 团队于 **10 月 31 日**公布，官方技术文档把它定位为 **Research Prototype**（研究原型）——主持人特别强调，它是「架构系统」而非完整终端产品，DeepSeek 主站用户规模远大于 Harness 用户规模，Super Agent 的大众渗透率还不高，但正因为是架构，开放性和可 DIY 程度也更高，这是 Harness「一切皆插件」理念的延续。

元宝给出的技术叙事是一条清晰的能力堆栈：最底层是硬件，往上是 LLM——他称之为**「缸内大脑」**，很聪明但只会输出文字、无法触碰任何实际系统；年初 OpenClaw 火起来，等于让 LLM「伸出了手」，通过 MCP 等协议操控浏览器、本地文件，从缸内大脑变成「电脑里能干活的小员工」；但 agent 仍是**单一 loop**——做一份 PPT 要人盯着一轮一轮推进，就算同时开三四个窗口并行，人自己成了那个「路由器」。Super Agent 做的事，是把「协同」本身也下放给 AI：一个「项目经理」接收任务、拆分、派发、跟踪进度、适时汇报。元宝强调它必须被理解成**一套可持续运行的系统或生态，而不是一个更强的 agent**——如果仅仅「能调用子 agent」就算新物种，那任何普通 agent 都是 Super Agent；关键在任务调度、消息响应、权限管理、任务恢复这一整套框架能不能稳定运行，「要不然你随便一个 agent 放到 Router 层，它是一个比较垃圾的项目经理」。

架构的具体形态是 **Router+Worker 双层**：Router 层是调度中心（项目经理），Worker 层是执行层（Worker A/B/C……）。门牙补充了官方文章的对比论证：早期「team agent」式主从结构里，**主 agent 负担太重**——既收集子 agent 结果、又分派任务、又做组织，效果不好；Super Agent 因此**把 Router 层职责收窄**，让它少做事、专注调度，Worker 承担更多执行，Worker 下面甚至可以再开子 agent。官方实验称：单 agent 开子智能体耗时长、效果一般，Router+Worker 架构最终效果更好（节目引述，未附原始数据）。两位讲者还提到同一先例时口径不一：元宝说是谷歌 DeepMind、主持人说 OpenAI「前段时间在 GitHub 上传了七百多道数学题」，用主 agent 协调多个方向的工作者去解——无论归属哪家（转写无法裁决，存疑并列），共识是这类金字塔结构早已出现在前沿实验里，Super Agent 是把它产品化、框架化了。

为什么这值得「五分」而非零分？元宝的哲学比喻是：从 LLM 到 agent 是「从没人变成有人」，从 agent 到 Super Agent 是「从部落到有金字塔的组织」——从没有金字塔到有金字塔是跨越，从小金字塔到城镇的大金字塔则进步有限。主持人随即点题：智能体领域正在出现**一门新的组织行为学**，只不过研究对象不是真人组织，而是智能体的算法结构——这个判断是全场最有延展性的论点之一。

## 养虾、养马、养鱼：一部 Agent 编年史

第二部分复盘这一年，元宝用三个动物讲完了整条线。**养虾 = OpenClaw**：名字里的 CLAW 是「钳子」，logo 是小龙虾；它能连飞书 CLI、有 Terminal、能整理文件改文档名，「电脑里有个智能体」的体感由此而来。**养马 = Hermes Agent**（元宝口中的「NR 开发的开源 Agent」，转写疑为 Nous Research）：核心卖点是**长期记忆**，让 agent 越用越懂你，门牙评价它「有一点自我迭代、自进化的想象空间，但实际上还没有实现」。**养鱼 = DeepSeek Harness 的蓝鲸桌宠插件**：因为 DeepSeek 是鲸鱼形象，社区自发做了桌面小宠物，能帮你刷 B 站找合口味的视频，甚至有人开发插件让这条鱼去直播平台表演才艺、收打赏换成自己 agent 的 token——元宝强调养鱼完全是社区自发而非官方行为，但它证明了两件事：情绪价值与形象也是刚需，且这一切建立在 DSH「真的开源」之上。他顺带回忆 DSH 早期被戏称为「毛坯房」（转写原词「解装房」，据上下文校正）：最早要靠 Node.js 命令行安装，连 exe 安装包都没有。

门牙的用户侧时间线则从 2025 年的 **Claude Code** 讲起：闭源黑盒，「用就用了」；转折点是 **OpenClaw 开源**——第一，UI 交互让普通人能用上（还带定时任务）；第二，开源把 Agent 框架本身交到社区手里，「大佬们改源码让它越来越好用」，大家由此意识到 **Agent 框架的好坏会直接影响能力**；第三，工作渗透从写代码扩展到更多事务。他同时提到一个转折点的墓碑：OpenClaw 时代现象级、如今「从现在看不行」，他记忆里「腾讯的 Q Cloud 已宣布停止运营」（转写疑似，未核实）。之后的序列是 Codex、WorkBuddy、Hermes，再到 DSH 的高度定制化——「打开它就是白白的，啥也没有」，恰恰把想象空间留给了用户，预示 Agent 会越来越个人化。

产品排序上两位嘉宾出现了有信息量的分歧。门牙用得最多的是 **Codex**（「完整、上手就能用、很丝滑」）和 DSH（「越用越像我自己造的」），他淘汰 WorkBuddy 的原因很直白：技能太多「不知道要用啥」——但马上补一句公道话：**小白不想折腾，WorkBuddy 开箱即用确实好**。元宝则给出分层框架：Claude Code/OpenClaw/Hermes 属于**实验性产品**（Terminal 使用门槛、环境配置门槛、早期安全漏洞明显——为了养虾还掀起了「养 Mac」买硬件热潮）；WorkBuddy、千问、「豆包工作」（转写疑似产品名）是当下**面向用户的好产品**；DSH 暂列第二，但「当用 AI 像上网一样成为默认技能时」，DSH 的千人千面会反超开箱即用。再往下一层是 Personal Agent（他提到 Muse、「Minas」、Dot 等，后两个名字转写存疑）：元宝判断 **Personal Agent 的爆发以 Super Agent 框架被普遍接受为前提**——单线程的私人秘书「你帮我订个机票」转半天还不够完善，真秘书得能按重要紧急四象限并行排任务。这与本站 [AI助理争夺战](https://inkeast.github.io/MessageDaily/posts/2026-10-25-guigu101-ai-assistant-wars/) 与 [智能体手机入口之争](https://inkeast.github.io/MessageDaily/posts/2026-10-22-guigu101-agent-phone-entry/) 讨论的「谁接到需求谁拿走入口」是同一条主线：入口之争的下一程，比的是谁能当好项目经理。

至于为什么至今没有国民级 Agent：元宝归因于产业阶段——从 2022 年底 GPT 时刻算起快四年，放在宏观尺度仍是**产业前期**，各方向厮杀未结束；主持人念的网友评论做了更完整的归纳：**算法还需优化、硬件还需降价、资源还需集中、效益还需明确**，以及「普通人要简便、专业人士要透明」的需求分层。不同人排序不同恰恰构成了赛道百花齐放。

## 单agent、多agent还是聊天机器人：任务的分层与 30%–40% 的验收刚需

门牙的现场 demo 是全流程最实的部分：面对「Super Agent 火不火、多少是营销」这个问题，他的做法是新建一个文件夹做调研——自己写了 skill，让多个 agent 分头查 X 上的讨论、官方文档、公众号解读，再由**验证 agent**交叉核对，最后汇总成报告指出哪里有价值；四个 agent 协作约 **三十多分钟**完成交付，产出落在 Wiki Analysis 文件夹里。他的规则写在 AGENTS.md（转写「Agent DM D」，疑为该文件）里：新对话开工前先看文件夹已有资料，**不重复干活**。他的方法论总结为一句话：**看第一手资料，把「营销」和「技术信息增量」分开称重**——他点名两个营销案例：某模型发布被包装成「OpenAI 研究员出品、无幻觉、便宜、快」（模型名转写为「J-E-V」，存疑），以及「GPT Ultra六」宣传中 AGI 评分高达 99 点几，「从技术角度看他怎么测出来的，其实是有点那个的」。

任务分层的经验法则也来自门牙：**判断标准是「这件事现实中需不需要多个人干」**——多渠道调研加验证、写代码加独立审核（他提到 Anthropic 的做法是开一个全新 agent、用干净上下文审代码以保持客观，「Ansar Pick」为转写疑似），都适合多 agent；Codex 已经会自动开多 agent（他让 Remotion 生成动画参考图时观察到默认行为）。但**搭地基用多 agent、盖楼和验收用单 agent**——多 agent 一口气做太多反而跑偏，而人的精力应该留给验收。他引述一份报告称**当下约 30%–40% 的时间花在验收 AI 输出上**，这个数字成为后文多个判断的支点。日常闲聊（感冒吃什么药、生成商单回复）他全交给豆包，「又快又免费」。元宝补了一个收束性的预判：未来的交互形态里**用户不会再区分单 agent 还是多 agent**——就像秘书听到「明天天气如何」自己答，「赶快做标书」自己去协调，把人工智能极致地想象成一个人就够了。

主持人则从这里引出商业视角的冷水：如果技术上真能做到「只跟一个 agent 对话」，商业上就是一家公司独大的巨大垄断，「谁能坐这个位置咱们赶紧去买他的股票」——但也正因如此，**商业逻辑本身会阻碍这个画面的实现**；元宝同意，终局更可能是几个 App 各自长成完整秘书，那才是 Personal Agent 的真正形态。

## 瓶颈不在智能：拆分反馈、权限与「Agent 的组织行为学」

元宝对瓶颈的拆解是全场机制密度最高的部分，可归纳为三层。**第一层是任务拆分的反馈滞后**：拆分任务的主 agent 在结果出来前并不清楚最终呈现，「拆得好不好」的负反馈必须全部跑完才能得到，而跑完很费事、且不知道真结束了没有——好战略家的训练回路无法闭合。**第二层是 agent 之间的权限与信息设计**：不做权限划分，所有子 agent 上下文一致，效果未必好；完全按个性隔离，又在闭门造车——共享文档给谁、给多少，是新的制度设计问题。**第三层是安全**：他把 agent 的行为模式比作**水流——永远往最容易完成任务的低处流**；一旦某个 agent 发现漏洞并同步给其他 agent 或文档，权限被连锁拿走，就会造成「agent 作弊出逃」的假象；于是需要直通上报机制（他类比公司里的「反腐信封」：底层执行 agent 发现漏洞如何直达 CEO agent），而有了直通通道又要回答「监管由哪个 agent 辅助」，否则 CEO agent 会被杂七杂八的上报淹掉。他的结论：**这套 agent 公司的组织架构与组织文化现在还是雏形、只能算小公司，当 agent 数量长到中大型企业规模时，这些是至关重要的生存问题**——与主持人「智能体需要新的组织行为学」互为印证。

主持人的补充从产品侧切入：agent 落地难还因为**使用高度个性化、可复制性低**——验收标准因知识背景而异（听过一百万首歌的人和听过十首歌的人评判标准不同），「最大公约数不够大」，所以难有统一共识的国民级产品。元宝自己的创业项目给出了架构外溢的实例：具身智能的多 agent 协作——把机器人每个关节（转写「转轴机关」，疑为舵机/关节）都当作一个独立 agent，脑内主 agent 当 CEO 下发拆分后的指令，每个关节 agent 只负责自己的动作并积累局部数据；他的假设是这会比「只有大脑和脑干」的集中式更稳定。他同时划清了一个边界：**模型强大与 Super Agent 架构能力是两回事**——基模再强，等于招了个清华北大毕业的员工，也没法多线程施展；一个清华项目经理带五六个普通 agent，团队能力照样放大。对模型侧感兴趣的读者可对照本站 [DeepSeek V4.1 Flash 实测](https://inkeast.github.io/MessageDaily/posts/2026-10-29-matt-berman-deepseek-v41-flash-crushed/)——模型性价比与架构组织力是两条独立推进的战线。

把以上收成四条「机制 → 影响 → 启发」链条（推断由写作者归纳，证据均来自节目）：

1. **Router 职责收窄 + Worker 可再嵌套**（机制：主 agent 过载是 team agent 的失败原因，Super Agent 把调度与执行分层）→ 长任务可在单会话完成、系统持续在线并主动响应（门牙引用官方文档；demo 中群聊噪声里主动捡出有价值的问题）→ 启发：评估 agent 产品时先看「项目经理层」是否称职，而不是只看基跑分；组织能力本身正在成为可产品化的对象。
2. **一切皆插件 + 真开源**（机制：DSH 把替换成本降到极低，连形象都能二创）→ 养鱼蓝鲸桌宠、直播赚 token 的社区现象，插件互通沉淀个人工作流（元宝、门牙分别陈述）→ 启发：情绪价值与个性化是 Agent 时代的一级需求；个人最值得积累的是自己打磨的插件集与 AGENTS.md 类规则文件，而非换用某个「最强」产品。
3. **执行被压缩、验收成瓶颈**（机制：30%–40% 时间用于验收，标准因人而异）→ 「有判断力的秘书」成为可付费刚需（主持人明确表示愿意付费）；也是国民级产品难以统一的原因（最大公约数小）→ 启发：把个人验收标准显性化为文档与 skill，就是把自己的判断力资产化；创业方向上「替用户做基础判断」比「替用户执行」更稀缺。
4. **agent 安全 = 权限与组织设计**（机制：agent 水往低处流 + 漏洞跨 agent 同步）→ 权限划分、直通上报、监管 agent 成为规模化前提（元宝推断）→ 启发：人类公司治理的反腐信封、员工手册、部门墙，都是现成的 agent 组织学素材；做 agent 系统的人值得重读组织行为学。

## 终局与 2027：工具 App 消亡、A2A/GEO 新生意、AI 剪辑之后是生物

展望部分从「2036 年的 Super Agent 长什么样」开始。元宝的推理链是：做得好终究需要**云上的虚拟沙盒/云主机**放个人资料与事务，agent 也在云端；交互设备只需要三要素——**屏幕、音频输入、音频输出**——由此可以排除带键盘的电脑（概率较低），但排除不了**智能眼镜、智能手表和手机**；更远处若脑机接口实现（他给到百年尺度），屏幕也不需要，视觉神经直接映射。他还给了一个「另一个多元宇宙」：具身智能与 agent 融合，实体 AI 本地算力运行、「我们只需要掏电费」，体内再「人格分裂」出 CEO 与执行 agent。收束到触手可及：**一到两年内，Personal Agent + 好的云主机 + 带宽**。门牙的近期形态则更朴素：Super Agent 文章里「接了群聊、主动感知环境、有 issue 就自己去解决」（「meetup 上有 issue」为转写原文，疑指 GitHub），他期待的是 agent 对环境噪声的甄别越来越准、自进化自迭代到「不用反复验证就给出符合我个人需求的答案」。

对「会不会取代 App」，两位的答案有一层精巧的分型。**工具类 App 会被完全替代**：从 Word 转 PDF 到 P 图，再到剪辑——门牙和元宝都点了剪辑：海外有人逆向了 CapCut（转写「开kat」），配合 Opus 5.5（转写「obs五点五」）就能剪视频，学习成本高的工具首当其冲。**服务类 App 是共生然后萎缩但不消亡**：人偏懒，秘书点外卖次数越来越多、打开 App 越来越少，商家与平台转向 **A2A 交互与 GEO 优化**（从做 SEO 排名转向做推荐时代的优化）；但萎缩不等于消亡——agent 省算力省 token 时给你的商家信息更少（名称加评分），只有打开 App 才能看到真实用户「阴阳怪气」的评论；淘宝的「逛」、抖音 B 站的「刷」这类体验型场景不会被替代；炒股 App 里量化派会被 agent 吃掉，但「看玄学」的用户不信 AI 占卜，「真喜欢占卜的人还是要找人与人之间的沟通」（元宝自我标注：后半段是玩笑式猜测）。商业机会已经出现：主持人说写字楼电梯广告里除了 AI 产品，「看得最多的就是 GEO 优化」，能拿出这么多广告预算「证明这块蛮肥」；元宝判断 GEO 与当年 SEO 玩法类似，「套了一层 AI 的壳子，商家更认可」。组织侧信号同样值得记录：主持人观察到 **DeepSeek 的招聘结构因 Harness 而变**——从招算法专家转向大量招有经验的工程人才，「这是个工程问题，不一定是多么高深的科学问题」。

2027 年的预测两人各押一处。元宝押 **AI 剪辑**：Remotion、HTML 网页做出的剪辑效果已经不错，且剪辑语料足够丰富，他预计 2027 年 Q1 国内外模型做出的效果能对标现在的 AE 老师，「是真的颠覆剪辑」；由此得出一个更一般的判断——**被基模吸收的下一个行业，一定是语料库极其庞大的行业**——他押生物、医药、化学，「生物领域的数据比互联网上的数据规模还要大」。门牙押 **AI 融入日常 App**：现在很多 App 里「根本看不到 AI 的影子」，更主动地渗透、更亲民是方向；他提到身边很多人已被灰度到「微信小V」（转写存疑），但仍在灰度阶段，国民级 App 如何调用 agent 是真正值得期待的入口。对研究 Code Agent 与 NES（本站读者的高相关方向）而言，这场直播给出的最硬的增量是：**调度层（Router）的职责收窄、验收环节的刚需化、权限与上报机制的组织学设计**——这三个问题都发生在模型之外、系统之内，恰是工程与科研能下手的地方。
