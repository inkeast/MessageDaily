## 先说结论

Thore Graepel 是 2015 年入职 DeepMind、参与 AlphaGo 与 AlphaGo Zero 的研究者，也是自认「第一个正式输给 Baby AlphaGo 的人」。他在 TWIML 这期访谈里的核心主张是：**大语言模型本质上是 AlphaGo 里的「策略网络」——一个在人类数据上学会的、极强但只会预测下一个 token 的模式匹配器；只靠生成更多 token，得不到能在不确定性下推理、能做出发现的 AI。** 他的证据是围棋史上最著名的那一手：对李世石第二局的第 37 手，策略网络给它的概率只有万分之一，真正选中它的是另一部件——向前推演变化并评估结果的博弈树搜索。由此他把今天的 LLM 推理问题重新定义为一个架构问题：把「知识」从「推理过程」里拆出来，让语言模型只做它擅长的小事（提出候选假设、把外部证据翻译成对假设的概率判断），而由一个显式的、可审计的推理过程去更新信念。他所在团队已做出第一代系统，能回答博士级科学问题并留下完整推理轨迹；他同时认为，现有以答案对错打分的基准（如 GPQA Diamond）测不出这种能力。这些是他与一个小型创始团队的做法与判断，没有给出独立评测数据。

## 一、第 37 手教了什么：模式匹配器不会给自己惊喜

Graepel 的叙述从他的入职第一天开始：2015 年第一天上班，David Silver 就让他和 Baby AlphaGo 下一盘测试棋——那是 Chris Maddison 在 Ilya Sutskever 指导下做的实习项目，对面执子的是后来在纪录片里被称为「AlphaGo 之手」的 Aja Huang。他是业余一段棋手，自认是「第一个正式输给 Baby AlphaGo 的人」，之后与 Silver 等人一起做出 AlphaGo、那场对局以及 AlphaGo Zero，朝着「能在这些环境里推理的、更通用的自主系统」走去。

主持人问他第 37 手说明了什么。他复述了现场：九段解说 Michael Redmond 把这手棋摆上讲解盘，又收回去，说「不，这一定是失误」，因为它太反常。更有意思的是 Silver 事后钻进系统查到的数字：策略网络——那个接收局面、给出落子概率分布、用来预筛候选手的神经网络——给这一手的概率只有万分之一。所以选中它的只能是系统的另一部分，即博弈树搜索：它向前看各种变化，再由价值网络判断结果。Graepel 说，这才是「我认为 AI 应该使用的那种推理」。

他把这一手推广成一条通用教训：**完全基于模仿的系统——在 AlphaGo 里是在人类棋谱上训练的策略网络，在今天是训练来预测下一个 token 的大语言模型——极不可能带来惊喜或真正新的知识**；只有一个「专门的推理过程」，去看一个动作或一项发现的后果，才能冲出「人类知识的凸包」。他补充了边界：这不意味着不能在其他领域学会推理，但你需要先弄清楚推理要达成什么。

## 二、把科学方法写成「推理走子」：信念、假设、证据、概率

Graepel 对「推理」的描述 本质上就是把科学方法形式化。他说人类能对未知的新事物推理，靠的是科学方法：先有一个「关于某个问题你当前相信什么」的表示，再在其上推理、把这个表示向前推进，以减少对该问题的不确定性；而这些动作，就是你我在推演问题时所做的「推理走子」。具体到一个问题，过程是：先审视问题本身的假设，再提出可能成为答案的假设（哪怕是坏选项），然后引入外部证据去确认或否证它们；证据会提高或降低你对某个假设的信念，而这种增减可以用概率论——他称之为「不确定性的微积分」——来量化。他引用 E. T. Jaynes 的《Probability: The Logic of Science》，并说自己会选择概率论作为这个问题的答案。

他强调这不只是打个比方：他们「基本上制定了一门推理语言，列出可以做的各种推理动作，然后系统可以学习最优策略，去减少对任何问题的不确定性」。其中一致性是难点：一个假设可能蕴含另一个假设，概率分配要让它们联合一致；新证据到来时按连贯的方式更新，使信念状态始终自洽。而「信念状态在推理过程中不断生长」，在他看来正是推理的核心。一旦有了它，就可以超出非黑即白的陈述，给出带概率的答案——他用医生诊断举例：认为是一种病还是另一种病的概率，直接决定治疗决策。接下来的每一步推理，都选「最能减少不确定性」的那个动作，或者「在给定时间、算力或金钱成本下最能减少不确定性」的动作。

主持人的追问是：这些不确定度是要针对每个场景手工设定，还是有一个通用机制？Graepel 答，他们并不是在教某个 LLM 去推理医学或修车；模型做的是基于语言与训练数据的通用 token 预测。比如查维基百科得到一条陈述，是否就该给它 100% 的概率？他说「我是贝叶斯派，总会给自己留一点余地」，这样新证据来了才能改变看法；实操上先按来源可靠性给启发式的高低，再看能否通过大量案例把概率校准到频率意义上的正确。他承认「很难把这些数字弄准」，但至少「在尝试量化不确定性，并用概率规则去组合它们」。

## 三、「法国的首都是哪里」：知识从哪里来，推理轨迹去哪里留

访谈中段用一个最小的例子把整套流程走了一遍。主持人问「法国的首都是哪里」，系统先像人一样审视问题的假设；然后提出假设——伦敦、马德里、巴黎，甚至「米老鼠」这样的坏选项；接着引入外部证据，比如一个维基百科页面；再判断这条证据让各假设的概率升还是降。答案大概率还是巴黎，但系统不会说 100%，而是说「这个概率最高，我有来自外部来源的证据」。关键在下一步：这个带置信度、带证据、带推理轨迹来历的「小事实」不会丢掉，而是存进一个显式知识表示里；下次有人问，系统给出的是一个「已经由推理系统认证过的答案」。主持人问这是否只限于被问到的问题，Graepel 说两者都有——查法国的时候也会顺带把「马德里是西班牙首都」以某个概率存下来。

证据也不限于维基百科：他把证据定义为「把系统内部信念结构与外部世界连接起来」的通用概念，可以是关于蛋白质问题时调用 AlphaFold。你还可以喂它一篇医学论文，让它拿第一条陈述去推理、必要时拆成子问题、从不同来源取证、得出结论并入库。

这一节里他给出了对 LLM 最尖锐的判断：模型的知识来自「你通常拿不到的、极其庞大的训练数据集，你不知道里面有什么」，所以「我们从根本上不信任大语言模型里的知识」，而「让 AI 推理系统可靠、可信的关键一步，是把知识从推理过程中分离出来」。产出也应当不同：你得到的是一条「系统实际据以得出结论的推理轨迹」，而不是「某种晦涩的思维链，它只是模型给出的答案的前兆」。

## 四、小而清的调用：为什么这能避开幻觉，也更便宜

主持人问了一个工程问题：把正确的信息取进上下文，会不会遇到检索增强（RAG）同样的困难？Graepel 的回答把话题转向「很多人在给 LLM 的同一个根本弱点打补丁」。他的做法是把推理过程拆成对语言模型——或其他「神经算子」，在机器人场景里是小型视觉语言模型——的非常小的调用：模型只负责与外部世界接口、解释证据、也许提议假设，不负责推理本身。以法国首都为例，你不再问系统「法国的首都是哪里」，而是问「维基百科的这段文本是否支持『巴黎是法国首都』这个陈述」。调用小而边界清楚，「几乎没有办法产生幻觉」。

这样做有两个附带收益。一是算力：复杂推理不再需要一个万亿参数模型从头做到尾，可以用一个你信任的较小基座模型，把推理过程搭在上面，「甚至更省算力」；他还提到主权层面的含义——拿不到前沿模型的人也能做前沿水平的推理。二是与「决策模型」的契合：主持人提到近期 TypeSafe 的 Jev 这类「决策模型」是否会帮到这条路，Graepel 称那是「一场精彩的攻势」，并只向 TypeSafe 的同事道贺，然后给出一个简化定义——大语言模型是「字符串进、字符串出」的函数，决策模型是「字符串进、数字或向量出」，换来的可能是更少算力、更低延迟，以及（取决于训练方式）校准过的概率，「这些恰恰是推理过程需要的要素」。

## 五、成熟度、审计与基准：第一代系统能做什么，现有基准测不出什么

Graepel 说这些想法目前在「创始团队加几位开发者」的规模上推进，已有「第一代」实现了这种推理系统的系统：可以问它博士级的科学问题，看着它如何拆解问题、回答子问题、提出假设、取证或调用工具。他举的例子是物理或化学问题——某种原子在一个复杂分子里有几个——系统需要用化学工具查明成分再推理。主持人问这是否需要针对题型调参，他说他们发现这些推理模式「相当通用」：问题拆解、提出假设、取证、质疑假设、调用工具并想清楚该向工具问什么——「推理操作其实是一个有限的字母表，我们已经刻画了它们是什么」；而如何把它们串成复杂的推理结构，是可以学习变好的。知识与策略两面由此分开：知识随推理积累，推理策略则能从已完成的推理轨迹里学会「更便宜、更快地得出更好的结论」。

主持人的最后一个技术质疑是「认识论的完整性」：整套机制最后仍要靠一个 LLM 来裁决证据的相关性，就像用 LLM 当裁判——怎么保证这一端不把系统带偏？Graepel 回答「仲裁者（arbiter）是个好词」，并说这正是要小心的地方：高估一条证据的相关性会让系统对某个假设过度自信，而这会顺着信念网络传导下去；这比假设生成更须谨慎——漏掉一个假设只是让你晚一点到达。他们的办法是给系统植入一种「认识论上的谦逊偏置」：不确定就充分地表示不确定，不要过度自信；LLM 只充当「解释者」，把证据语义翻译到假设的世界里，而所有真正的知识都必须来自扎实的证据。主持人问这是否意味着数据源必须「纯净、权威、规范」，不像 LLM 那样在整个互联网上推理；Graepel 说可靠来源确实重要，「对人类推理者同样重要」，但系统还能对来源的可靠性本身做推理——他用警报举例：如果允许「警报本身可能是坏的」，你会得到对警报为何响起的更完整的解释图景；医学论文也可以按机构、作者等线索评估可靠性。

谈到基准，他认为基准「在某种意义上给了我们研究方向」，而现有推理基准（如 GPQA Diamond）只看答案对不对，而答案可能本来就在前沿模型的训练集里，也可能在没有任何完整推理的情况下蒙对选择题；更好的基准应当给「中间步骤、推理策略是否一致、是否真的导向结果、有没有跳步和未证成的假设」客观打分。他特别指出前沿厂商正在隐藏或编码思维链以防止蒸馏——在他看来这恰恰说明那不是真正的推理：「你无法依赖那条轨迹……推理不只是推理的结果，推理也是通向结果的论证。」回到思想源流，他说这一切某种意义上是「回到 AlphaGo 架构」，因为它早已包含 Kahneman 所说的系统一（神经的、快速模式补全与识别）与系统二（审慎规划）的二重性；再往前，是七十年前的达特茅斯会议以来那条「没有大模型也必须想清楚什么是知识、如何表示、如何可靠地得出结论」的研究传统。主持人与嘉宾都以他与合作者（转写作 Mattis）近期发表的一份白皮书作为这组想法的入口。

## 机制链与启发

1. **模式匹配器的上限由训练数据的「凸包」决定，突破要靠独立的搜索部件。** 证据：[480s–720s] 策略网络给第 37 手万分之一概率、由博弈树搜索与价值网络选中；嘉宾由此推断纯模仿系统「极不可能产生惊喜」→ 原因是模仿目标把输出分布锚定在人类既有行为上 → 二阶影响：以「更大规模下一个 token 预测」为唯一路线的 AI，在发现类任务上的边际收益会递减，而「学习型直觉 + 推演评估」的组合架构重新有了价值（嘉宾称 AlphaGo 已示范了系统一与系统二的二重性）→ 观察指标：各大实验室是否把搜索/验证部件重新接回生成模型，以及「推理基准」是否开始给过程而非只给答案打分 → 启发：评估任何「AI 做研究」的产品时，先问它的结论是从模式里读出来的，还是被一个独立过程检验出来的。
2. **把知识从推理里拆出来，换来的是可审计性，代价是对外部证据源的依赖。** 证据：[1440s–1800s] 嘉宾称「从根本上不信任 LLM 里的知识」，主张知识来自带出处、带置信度的「认证事实」；[2760s–3000s] 主持人追问数据源是否必须「纯净、权威」，嘉宾答可靠来源「对人类推理者同样重要」，且系统可对来源可靠性再推理 → 直接原因是模型权重里的知识不可追溯、不可校验 → 高风险场景（医疗诊断、法律、金融）得到一条可回放的推理轨迹，但系统质量的上限转移到证据源与「证据相关性判断」这一环 → 启发：做可靠 AI 应用时，把预算从「更大的模型」挪到「更干净的证据管道与可审计的中间表示」上，可能是更划算的一笔。
3. **把大模型切成小调用，同时改变了成本结构与信任结构。** 证据：[1920s–2280s] 把推理拆成「小而边界清楚」的模型调用以避免幻觉；不需要万亿参数模型，可用较小的可信基座模型，还有主权层面的意义；与「决策模型」（字符串进、数字出）在算力、延迟、校准概率上互补 → 原因是模型只承担「语义翻译」这一局部功能，推理逻辑外置到可检验的过程里 → 二阶影响：模型厂商的规模竞赛与「推理过程」的价值被解耦，小模型 + 好过程可能成为一条独立的产品路线（写作者推断）→ 启发：看一类 Agent 产品时，区分它的智能到底在模型里还是在过程里；后者往往更便宜、也更容易审计。
4. **「谦逊偏置」是用效率换稳健的显式设计。** 证据：[2640s–2760s] 嘉宾称高估证据相关性的错误会沿信念网络传导，因此在这一步比假设生成更保守——漏掉假设只是慢一点，并给系统植入「不确定就充分地表示不确定」的偏置 → 这是一种用「更慢达到答案」换「更少不可逆错误」的权衡 → 启发：构建任何会累积状态的系统（记忆、知识库、多步 Agent）时，把「过度自信的更新」当作首要失败模式来防，而不是把「漏掉答案」当作首要失败模式。
