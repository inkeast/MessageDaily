## 一、论文背景

这篇论文回答的问题一句话就能说清：**给通用编程 agent 一份"模型发现配方"（recipe），它能不能真的发现或改进科学模型？** 要理解这个问题为什么此刻值得问，需要先理清四层概念。

### 1.1 什么是"模型发现"

从数据中找出描述现象的数学模型——可能是一个解析表达式（如开普勒行星轨道公式），也可能是模拟器里的一组方程（如心脏血液循环模型）。历史上靠人类专家"肉眼看数据 + 猜函数形式"，20 世纪后逐步自动化：

- **符号回归（Symbolic Regression, SR）**：让算法在"算符+变量+常数"组合成的表达式空间里搜索，找出既拟合数据又不过于复杂的公式。2009 年 Schmidt 和 Lipson 的经典工作用遗传编程 SR 从观测数据中自动恢复哈密顿量等已知物理定律，是自动定律发现领域的标志性事件。
- **穷举符号回归（ESR）**：Bartlett 等人 2024 年提出，把某复杂度以下的所有函数全部生成打分，保证找到该复杂度内的最优解和完整排名——代价是复杂度上限很低（实际约 10 个算子），而文献中的经典公式动辄 20+ 个算子，穷举够不着。
- **神经架构搜索（NAS）与 AutoML**：模型不必是公式，也可以是神经网络结构或整条机器学习流水线，同样可以自动搜索。

这些方法共享一个根本约束：**结构性选择（搜索空间）必须预先人工设定**——用哪些算符、允许哪些层、什么组合合法。建模者要花大量精力把算法适配到具体问题上。

### 1.2 LLM 如何改变搜索

大语言模型带来了新的可能：**让 LLM 直接生成或修改可执行程序**，程序本身就是模型。DeepMind 的 FunSearch（2023，Nature）和 AlphaEvolve（2025）用"LLM 提议代码变更 + 自动评估器打分 + 进化保留"的循环，做出了 4×4 复矩阵乘法 48 次乘法（56 年来首次改进 Strassen 算法）、Google 数据中心 0.7% 算力回收等成果。LLM 提议比随机变异贵，但能吸收领域知识和历史尝试的证据，在评估昂贵的场景下反而更划算。

### 1.3 Coding Agent 与 Agent Skill：本文的载体

- **通用 coding agent**：Claude Code、OpenAI Codex、OpenCode 这类终端型编程代理，能读代码、改实现、跑实验、根据结果决定下一步——不再需要为每个任务写专用 harness。
- **Agent Skill（技能）**：一个文件夹加一份 SKILL.md——顶部 YAML 元数据（name、description）+ 正文 Markdown 分步指令，可附带脚本和参考文档。类比来说，**提示词像口头教新同事干活，说一遍忘一遍；Skill 像把 SOP 写成活页夹放进工位**，可安装、可版本管理、可分发，且"渐进式披露"——平时只占两行元数据，任务匹配才展开全文。该格式 2025 年 10 月随 Claude 推出，12 月成为开放标准，2026 年 10 月 Anthropic 将其捐赠给 Linux 基金会，已有 70+ 平台接入、累计安装近 2.8 亿次。
- **Karpathy 的 autoresearch**（2026 年 3 月）：最接近的软件先例。把一个 program.md 指令文件交给通用 agent，让它反复"改 train.py → 跑 5 分钟实验 → 看 val_bpb → 保留或回滚"，一夜跑数百实验。Karpathy 自己称 program.md 是"超轻量技能"。

### 1.4 现状的核心缺陷

已有 LLM 模型发现工作（LLM-SR、AlphaEvolve、SR-Scientist 等）都依赖**专用 harness**——自己造一套编排软件来协调 LLM 调用、候选生成和评估。这带来两个问题：一是每换一个领域就要重造流水线；二是研究者最在意的科学约束（物理可容许性、共享机制、验证协议）很难灵活地塞进固定管道。automodel 的赌注是：**方法论本身写成一份可移植技能，通用 agent 的现成能力（读代码、spawn 子代理、跑实验）就是执行引擎**——不必造任何专用软件。

## 二、论文定位和关联工作

### 2.1 LLM 作为优化器与程序生成器

| 工作 | 核心思想 | 与 automodel 的关键区别 |
|---|---|---|
| OPRO（Yang et al., ICLR 2024） | LLM 迭代"提议-评估-反馈"做优化 | 未应用于模型发现，无代码执行 |
| FunSearch（Romera-Paredes et al., Nature 2024） | LLM 生成候选程序+自动评估+种群搜索，发现数学构造 | 进化单函数（10-20 行），需专用 harness、百万级采样 |
| AlphaEvolve（Novikov et al., 2025） | Gemini 驱动进化整个代码文件，多指标、数千采样 | 仍是专用流水线；未开源完整系统；需自动评估器 |
| ShinkaEvolve / OpenEvolve / SkyDiscover（2025-2026） | 开源/自适应进化代码搜索 | 同上，专用 harness 家族 |

| 工作 | 核心思想 | 与 automodel 的关键区别 |
|---|---|---|
| LLM-SR（Shojaee et al., ICLR 2025） | LLM 写方程骨架程序+数值拟合常数+进化选择 | 专做方程发现，固定循环结构 |
| LLM4ED / LEMMA / LaSR | LLM 进化算子发现微分方程 / 生态机理模型 / 概念库引导符号搜索 | 各自绑定领域与搜索算法 |

### 2.3 可复用实验循环与技能化研究工作流（automodel 的直接谱系）

| 工作 | 核心思想 | 与 automodel 的关键区别 |
|---|---|---|
| **autoresearch（Karpathy, 2026.3）** | 通用 agent + Markdown 指令 + 少量脚本 = 持续优化循环 | 面向 LM 训练代码改进；automodel 将其泛化为科学模型发现方法论，增加评估器校准、并行子代理、外部终检等科学规范 |
| autoresearch 社区版（Goenka） | 用户定义目标、可编辑范围、验证程序、基线测量、持久日志 | 同上 |
| ARIS（2026） | Markdown 技能协调研究执行与跨模型评审 | 研究方法学通用，非模型发现专用 |
| DisCo / Repo-to-Skill（2026） | 从 ML 仓库蒸馏操作知识为技能 | 蒸馏已有知识；automodel 编码发现方法论 |
| SRHarness（清华，2026.10） | agentic SR 的可复用运行时（统一动作/持久状态/轨迹管理），符号恢复率 93.69% | 显式软件框架路线 vs automodel 的纯指令路线 |

### 2.4 定位结论

| 维度 | 之前的路线 | automodel 的突破 |
|---|---|---|
| 执行引擎 | 专用 harness（自建编排软件） | 通用 coding agent 现成能力 |
| 方法论载体 | 硬编码在管道里 | 一份可移植 SKILL.md（零专用引擎） |
| 交互性 | 跑完才有结果 | Setup/搜索循环中人可介入修订目标与权衡 |
| 模型形态 | 通常限方程或限代码 | 解析式、模拟器内方程修改均可 |
| 验证规范 | 各自为政 | 强制评估器校准+统一重评+外部终检 |

automodel 处在 autoresearch（通用 agent + 指令文件）与 LLM-SR/AlphaEvolve（LLM 模型发现）两条线的交点上：**前者提供了"技能化"的执行范式，后者提供了"模型发现"的问题域**，它是第一个把两者合起来的工作，并诚实地声明：本文贡献是方法论的，不与专用方法比性能。

## 三、问题定义

### 3.1 从具体场景到抽象问题

具体场景五花八门：天体物理学家想找比文献公式更优的星系质量函数；心脏科医生想修正循环模拟器的某个方程；农学家想为每块管理区找氮响应曲线的函数骨架。表面上毫无共性，论文的洞察是它们共享同一个深层结构：

> **给定**：数据 D、一个可打分的评估函数（拟合目标+选择分数）、一个参数拟合例程（可能没有）、资源预算、以及"什么算最终证据"的判定标准；
> **求**：模型的结构修改序列，使选择分数最优；
> **约束**：模型表示与改动方式必须适配现有代码库与科学约束（物理性、跨对象共享机制等）；最终须通过未参与搜索的外部检验。

### 3.2 关键抽象：结构搜索与参数拟合的分离

所有案例都拆成两层：**结构**（公式形态/方程形式，由 agent 提议）和**参数**（常数/系数，由数值优化器拟合）。这与深度学习"架构搜索 vs 梯度训练"的分层完全同构：

| 模型发现 | 深度学习 |
|---|---|
| agent 修改表达式结构 | 架构搜索修改网络结构 |
| Nelder-Mead/最小二乘拟合常数 | 梯度下降训练权重 |
| MDL/BIC 惩罚复杂度 | 正则化/参数量约束 |
| 保留测试集外部终检 | 独立测试集评估 |

### 3.3 这个抽象的精妙之处

把"发现模型"形式化为"受约束的结构假设搜索+可信评估"，让**同一个工作流**可以覆盖从一行函数字符串到 C++ 模拟器内方程修改的任意形态——变的只是评估器和"模型"的定义，不变的是四阶段流程。这正是"技能"能够可移植的前提：技能编码的是流程而非领域。

## 四、问题解法

automodel 是一套纯自然语言指令+模板，无专用编排引擎、无数值优化器——执行完全依赖 coding agent 及其环境。工作流分四个阶段，每阶段有独立配方并产出上下文记录（CONTEXT.md 记决策与进展，CHECKLIST.md 记进度），使后续会话可脱离对话历史恢复工作。

### 4.1 Phase 1：Setup——把科学问题工程化

类比"实验设计前的 pre-registration"。研究者与 agent 共同确定：模型输入输出与可容许性质、拟合目标与选择分数、参数拟合例程、资源预算、外部终检的判据。两条硬性科学规范写进技能：

- 用**未惩罚误差**（如 RMSE）做选择分数时必须配验证集或交叉验证；
- 用**复杂度惩罚准则**（AIC/MDL）时可在拟合数据上选择，但仍需外部终检——因为惩罚复杂度不能补偿"从众多候选结构中挑最好"带来的选择效应。

同时评估候选评估的运行时/内存成本，并检查环境能否 spawn 子代理、执行实验。

### 4.2 Phase 2：Baseline——先校准评估器再谈搜索

类比"测量仪器先校准再用"。agent 拟合既有模型（或实现一个简单参数化基线），由子代理跑完整评估管线，检查输出合理性并记录时间/内存开销。这一步同时验证了文件委派访问与代码执行可用——评估器不可信，后面一切分数都是空中楼阁。

### 4.3 Phase 3：Iterate——嵌套并行搜索循环

核心搜索是一个嵌套循环，好比"实验室主任（编排 agent）带领 S 个独立方向的研究生（并行子代理）"：

- 编排者 spawn **S 个子代理**，分配**互不重叠**的搜索方向；
- 每个子代理迭代 **I 次**：(i) 按方向修改模型结构 → (ii) 拟合自由参数 → (iii) 记录结果；
- 完成 I 次后编排者收束一次 **meta-iteration**：复核各子代理结果、丢弃未完成运行、用统一协议**独立重评**短名单候选，然后下发更新的搜索方向；
- 共 **M 个 meta-iteration**，参数 (M, S, I) 由用户在阶段开始时按 Phase 2 的开销估计商定；
- 结束后与用户协商：继续搜索还是进入终检。

### 4.4 Phase 4：Finalize——冻结与外部检验

类比"论文投稿前的独立验证"。用 Phase 1 定义的外部终检评估候选：保留测试集、独立数据集、和/或拟合范围之外的物理性质检查。技能明确禁止把同一检验重复用作独立证据。冻结策略因科学问题而异：有的应用结构与系数全冻结；有的冻结共享结构机制、允许案例特异参数重拟合。终局模型、性能、接受标准与局限全部写入 CONTEXT.md。

### 4.5 各阶段全景对照

| 阶段 | 输入 | 输出 | 防的什么坑 |
|---|---|---|---|
| Setup | 数据、目标、约束 | 评估协议、CONTEXT.md | 选择效应过拟合、目标含糊 |
| Baseline | 基线模型 | 校准的评估器、开销档案 | 评估器有 bug、委派不可用 |
| Iterate | 搜索方向、预算 | 短名单+完整记录 | 方向重复、子代理自评偏差 |
| Finalize | 短名单 | 终局模型+外部检验结论 | 循环内信息泄漏到检验 |

## 五、评估指标与实验证据

论文用五个学科案例检验同一技能，每个案例自带领域指标——这本身就是主张的一部分：**技能的普适性就是评估对象**。

### 5.1 案例一：天体物理——星系恒星级质量函数（Claude Code Opus 4.8）

- **任务**：为 SDSS 巡天测量的 SMF 找比文献标准（Schechter/Saunders/Bernardi 函数）更优的解析形式。ESR 穷举到复杂度 ~10 就到顶，而 Saunders/Bernardi 含 ≳20 个算子，存在"穷举够不着、人工靠经验"的空档。
- **指标**：描述长度 DL（nats，越低越好）= 负对数似然 NLL + 参数复杂度 + 函数复杂度，近似负对数贝叶斯证据，单一指标同时奖励拟合优度、惩罚参数与算子。要求候选在 Sérsic/cmodel 两个独立版本数据集上**同时获胜**，并过物理性三检查（函数恒正、随质量单调下降、积分收敛且低于宇宙重子预算）。
- **结果**：搜出 A1-A7 七个超越 ESR 最优的函数；**A5**（x^θ4·(θ0+θ1x^θ2+θ5x^θ6)^θ3）以 19 算子（Bernardi 23 个）在两数据集 DL 分别优 **36.5 和 15.7 nats** 且似然更高，13 算子的 A2 在单数据集也胜 Bernardi 23.5 nats；A5 积分约为宇宙重子预算 5%，可安全外推——作者称之为"迄今经验最优的 SMF"。

| 函数 | 算子数 | ΔDL(Sérsic) | ΔDL(cmodel) |
|---|---|---|---|
| 最优 ESR | 10/9 | +196.8 | +189.7 |
| Saunders | 21 | +169.4 | +144.6 |
| Bernardi | 23 | 0（基准） | 0 |
| A2（automodel） | 13 | **−23.5** | +76.3 |
| A5（automodel） | 19 | **−36.5** | **−15.7** |

### 5.2 案例二：心血管建模——CircAdapt 方程修正（Codex GPT-5.6）

- **任务**：闭环心循环模拟器 CircAdapt（C++）对患者的剩余误差是否源于方程本身？3 名开发患者 + 1 名留出患者，指标为六个腔室体积测量的 MAPE；14 个既有生理参数逐患者独立校准，新引入的结构系数须**跨患者共享**——保证发现的是机制不是记忆。
- **结果**：心肌激活因子方程从 Cs=tanh(6.84L²) 扩展为 Cs*=tanh(6.84L²·exp(gL·Ef))（纳入瞬时组织形变 Ef，gL=3）：三名开发患者 MAPE 4.15→3.77、6.82→4.47、**2.27→1.02**，留出患者 5.21→4.84（作者诚实标注为"适度留出优势，非群体级泛化证据"）。第二轮更广搜索（16 个新结构修改，含 Kelvin-Voigt 心包、双群 ECM 等）无一超过该激活修正（最佳新候选 4.03% vs 3.09%）。
- **防伪机制现身说法**：每个结构修改内置"恒等值"还原原始方程做一致性检查；早期一个通过恒等检查的"右心室参考面积修改"被人工艺审计发现新系数代数等价于重标定既有参数——遂把五个心脏参考面积并入校准参数表。**agent 的伪创新被人机协作逮住**，这成为论文强调研究者监督价值的例证。

### 5.3 案例三：精准农业——氮响应曲线骨架（Claude Code Opus 5）

- **任务**：蒙大拿两块冬麦田（Field A 四个管理区、Field B 三个），为每区找共享符号骨架（常数占位），再逐站点拟合参数。描述性任务，无数据切分。
- **指标**：站点级平均误差 r̄（曲线 z-score 标准化后）。
- **结果**：对经典农学模型是碾压级——比二次-平台模型准 57.4×/248.9×，比指数模型准 16.2×/63.1×；对神经符号回归 SeTGAP 平均准 4.2×/9.7×。**结构性诊断**是亮点：agent 发现 38%-81.2% 的位点在高氮率下产量下降，而经典模型单调饱和、结构上无法表达内部极大值——失败是结构性的而非数值的。代价是表达式更复杂（最多 8 系数 vs SeTGAP 最多 5），且系数可辨识性审计显示站点级参数弱可辨识、不应独立解读。人机三次介入：定 (M,S,I)、复核跨 agent 排名、仲裁 7→8 参数的复杂度权衡（17-41% 误差降幅超过预注册的">5% 每参数"阈值，用户选 8 参数）。

### 5.4 案例四：汽车轮胎动力学（Codex GPT-5）

- **任务**：为归一化侧向轮胎力找非 Pacejka 替代结构。五个垂直载荷 bin：1-3 训练、4 验证、5 终测；约束显式解析、有界、载荷连续、禁多项式基、须真非 Pacejka。
- **结果**：非对称双曲正切模型（双 tanh 组合，含光滑符号依赖调制）训练 RMSE 0.0592→0.0521（−12.0%），验证 0.0467→0.0384（−17.8%），**冻结结构与系数后**留出载荷 bin 测试 0.0583→0.0546（−6.3%），R² 0.983→0.986。部分系数逼近优化边界，作者如实标注宏观参数应视为预测律组分而非独立可辨识物理量。

### 5.5 案例五：交通流建模（Codex GPT-5.6 Sol）

- **任务**：LWR 守恒律中五个经典基本图（Greenshields/IDM/Weidmann/Triangular/Del Castillo）各配一个正指数乘性修正 g(ρ)，NGSIM I80 数据按时序三分。评分 E = Edata + 0.01×表达式节点数——新增机制必须抵过自身复杂度成本。
- **结果**：5×3×3 搜索共 225 次"基线×候选"拟合，AM-Del Castillo 拿到全场最低留出误差 Edata=6.780（十模型第一），AM-Greenshields 对自身基线改进最大（**−23.17%**），4/5 基线族获改进（IDM 例外 +2.30%）。发现的修正结构可物理解读：密度对比度特征只在空间不均匀处激活，相当于对发展中的交通波前做非平衡修正——作者强调这是结构假设而非已识别的驾驶行为机制。

### 5.6 对照实验：技能本身的消融

天体物理案例补了一个直接对照：**同一 agent 同一模型、去掉技能只给"改进模型"的泛化指令**，3 个独立会话 wall time 与算力封顶在 automodel 运行水平。结果：三个会话都在 40-65 分钟、token 预算用不到一半时自认任务完成；虽有两个在单数据集上找到胜 A5 的函数，但只有一个在双数据集上胜 Bernardi 且幅度远小于 A5。**automodel 找到的最优函数仍是全场最佳**——作者归因于技能强制的 meta-iteration 让搜索在单一函数双数据集获胜前不停止，即提升了 agent 的持久性。

## 六、效果优势的根源解释

### 6.1 根源机制与证据链

**对比对象**：专用发现管道（AlphaEvolve/LLM-SR 家族）曾经有效，因为自动评估+进化搜索确实能走出人类盲区；泛化指令 agent（对照会话）也有效，因为 agent 本身具备读码改码跑实验的能力。

**baseline 的根本局限**：专用管道把方法论硬编码在软件里——换领域重造轮子，科学约束（物理性、共享机制、外部终检）塞不进固定流程；无技能 agent 则缺流程纪律，40-65 分钟即自认完成（对照实验，论文支持），搜索持久性与方向多样性全凭模型自由发挥。

**因果链（方法差异 → 机制变化 → 指标提升）**：

1. **强制 meta-iteration → 持久性 → 跨数据集一致性获胜**：技能规定 M 轮"子代理跑完→元代理复核→再定向"，agent 无法提前"自认完成"。对照实验中无技能会话 40-65 分钟止步、仅 1/3 双数据集胜 Bernardi；automodel 持续搜索直到出现双数据集均胜的 A5（−36.5/−15.7 nats）。【论文实验已支持】外部佐证：Épi 持久研究 agent 的核心结论同样是"persistence beats raw scale"——允许跨会话延续的研究战役比单次推理链解决更难问题（120 个数学纪录）；Karpathy autoresearch 的固定 5 分钟循环同理，700 次实验沉淀 20 项有效改进。
2. **方向不重叠的并行子代理 → 搜索多样性 → 结构创新**：S 个子代理各持独立假设空间（如农业案例"显式非单调峰值表达式 / 高阶 Padé 有理核 / 复合扭曲辐角"），避免全都挤在同一函数族。【论文实验已支持（农业各 agent 探索不相交函数空间的记录）】机制佐证：AlphaEvolve 消融显示去掉进化循环（即只有单线搜索）性能显著退化。
3. **元代理统一协议重评短名单 → 防子代理自评偏差 → 排名可信**：短名单候选由根进程用同一评估器重评后才接受（交通案例明文）。类比 Kaggle 竞赛组织者统一复测各队提交。【论文设计层面支持，案例级直接证据未单独消融——阅读者推测：其必要性部分由心血管"恒等检查+人工审计逮住伪修改"间接体现，但那是人与技能协作而非元代理重评本身的消融】
4. **结构与参数分离 + 复杂度惩罚 → 证据式模型选择 → 可外推的简洁公式**：MDL/AIC 型准则近似贝叶斯证据，A5 用 19 算子胜 23 算子的 Bernardi 同时提升似然，是"更准且更简"而非"堆复杂度换拟合"。【论文实验已支持】外部一致：Ford et al. 2026 用 ESR+MDL 在同一数据上得到同性质结论（简单函数可在 DL 上胜文献式，但复杂度上限挡住更大胜幅）；Bilevel Autoresearch 等循环工程综述亦把 verifier/状态/停止条件列为可靠循环三要素——automodel 的评估器校准、CONTEXT.md、终检一一对应。
5. **身份值一致性检查 + 人机协作 → 防伪结构创新 → 机制级修改可信**：心血管案例中恒等值检查保证"结构修改"不退化为参数重标定，人工审计识破代数等价的伪修改。【论文实验已支持】这一条外部少见直接对照——清华 MechBench 发现 agent 恢复现象规律（35%）远易于恢复底层机制（13.75%），说明"找机理"比"找公式"难一个量级，automodel 靠人来把关机制解读是当前合理分工。

**反事实推理**：去掉 meta-iteration（对照实验已做）→ 持久性崩塌、最优函数找不全；去掉统一重评 → 各子代理分数不可比（论文以协议设计规避，无独立消融）；去掉外部终检 → 复杂度惩罚无法补偿多重选择效应（Phase 1 规范明文，农业案例若做留出评估可预期误差反弹——推测）。

### 6.3 综合判断与未决问题

**多项证据共同支持的机制**：结构化循环提升 agent 持久性（对照实验 + autoresearch + Épi）；结构与参数分工 + 复杂度惩罚产出可外推简洁模型（五案例 + ESR/MDL 文献独立脉络）；并行多样假设空间优于单线搜索（案例记录 + AlphaEvolve 消融）。

**仍属推测的机制**：元代理统一重评的独立贡献（无单独消融）；人机协作审计的不可替代性（仅一个案例的轶事证据）。

**优势成立条件**：存在可校准的自动评估器；领域有可借鉴的文献函数/结构先验；研究者有能力定义外部终检。**可能失效条件**：评估昂贵或需人工实验的任务（AlphaEvolve 同款限制）；结构上与已知先验迥异的 target（LLM-PySR 的警示）；机制层发现需求（MechBench 鸿沟）；以及论文自认的缺口——更系统的对照测试与与传统搜索算法的计算成本对比仍待做（对比应计入数值校准、agent 推理与研究者投入三重成本）。

## 七、必要知识反推

假设找一个完全没有背景的人重做这项工作，他最少必须掌握什么？

### 7.1 领域知识层

- **符号回归与信息论准则**：不懂 MDL"用最少 nats 通信数据"的含义，就无法设计天体物理案例的双数据集 DL 评分，也不会明白为何 A5"更少算子更高似然"是硬胜利；不懂 AIC/BIC 的选择效应，就无法理解 Phase 1 为何强制验证集或外部终检。
- **各案例的领域常识**：SMF 的物理性三检查（正值/单调/可积）来自宇宙学常识；心肌激活因子的生理学含义决定"组织形变调制收缩"是不是合理机制假设；氮响应曲线的单调饱和假设来自农学传统——agent 的结构失败诊断（38%-81.2% 位点高氮减产）需要知道"管理区共享函数骨架"这一领域设定才有意义。
- **Pacejka Magic Formula 与 LWR 守恒律**：轮胎与交通案例的基线各自是两本教科书的第一章，不知道基线为何长这样，就无法设计"必须真非 Pacejka""乘性修正保持零流态"这类结构约束。

### 7.2 方法论知识层

- **LLM 引导搜索谱系**：OPRO 的提议-评估-反馈范式、FunSearch/AlphaEvolve 的进化循环、LLM-SR 的骨架+拟合分工——automodel 的设计是对这条线取舍后的产物（吸收分工、抛弃专用引擎）。
- **实验设计规范**：训练/验证/测试切分、预注册阈值（农业">5% 每参数"）、冻结协议（结构与系数何时一起冻、何时只冻结构）、多重比较的选择效应——这些是把"agent 搜索"提升为"科学发现"的门槛知识。
- **数值优化**：多起点 Nelder-Mead+basin-hopping、差分进化、双退火、TRF 有界最小二乘、Powell 搜索——知道非线性拟合的非凸性才知道为什么必须多起点、为什么拟合不充分会伪造"结构差异"（天体物理案例用多方法全局搜索复核 margin 真实性正是为此）。
- **可辨识性概念**：参数逼近优化边界意味着什么、站点级常数弱可辨识时如何限定结论强度——两个案例的局限性声明都依赖这个概念。

### 7.3 工程知识层

- **Agent Skill 规范**：SKILL.md 的渐进式披露、目录结构、跨平台兼容——技能写得太长不加载、描述写错不触发。
- **Coding agent 能力边界**：子代理 spawn、委派文件访问、上下文窗口管理——Phase 2 专门验证这些，说明作者深知"执行引擎"的可靠性不能假设。
- **持久化上下文设计**：CONTEXT.md/CHECKLIST.md 让跨会话恢复不依赖聊天历史，这是把 agent 工程从"对话"升级为"战役"的关键。

### 7.4 知识融合的关键节点

- **节点一：科学方法论 × agent 工程**。把 pre-registration、验证协议、冻结规则翻译成 agent 可执行的阶段指令——不懂实验设计的人写出的技能只会让 agent 更勤奋地过拟合。
- **节点二：信息论 × 搜索算法**。MDL 既当评分又当正则，使"超出 ESR 复杂度上限"的搜索有了与穷举结果直接可比的标尺（评估器复现文献 DL 到 <0.01 nat）——没有这把统一的尺子，agent 找到的函数无法和百年文献对话。
- **节点三：分布式搜索 × LLM 上下文**。方向不重叠的子代理设计同时借用了进化算法的种群多样性思想和 LLM 的上下文吸收能力——纯进化不会定向，纯 LLM 会扎堆，元代理的"复核+再定向"把两者焊接起来。

## 八、论文中可以提取的通用性灵感

**灵感一：把方法论做成可移植资产，而不是造专用系统。**
核心思想：当通用执行引擎（coding agent）足够强时，竞争优势从"谁造了更好的管道"转移到"谁写出了更好的配方可移植技能"。
论文证据：automodel 零专用编排代码，同一份 SKILL.md 驱动 Claude Code 与 Codex 在五个学科复用；对照实验显示配方本身（而非更多算力）带来持久性与最终质量差距。
推广场景：①代码评审/安全审计方法论技能化给不同团队的 agent；②临床试验方案设计流程封装为技能供研究护士 agent 使用；③财务尽调 checklist 变成投研 agent 技能；④DevOps 事故响应 runbook 技能化；⑤教学设计 (ADDIE 等) 模型封装给教育内容 agent。

**灵感二：结构化循环是对抗 agent"提前自满"的第一杠杆。**
核心思想：无强制流程的 agent 倾向于在"看起来够了"时停机；把"继续搜索直到满足客观退出条件"写进流程，能系统性地提升产出上限。
论文证据：无技能对照会话 40-65 分钟、不足半预算即自认完成；automodel 的 M 轮 meta-iteration 强制搜索直到单一候选双数据集获胜。
推广场景：①销售 agent 在"客户似乎满意"时停 vs 达成 NPS 阈值才停；②论文写作 agent 迭代至盲审模拟通过；③产品经理 agent 迭代 PRD 至验收标准全覆盖；④谈判 agent 至帕累托改进穷尽才收口；⑤自动化测试生成 agent 至覆盖率达标的循环。

**灵感三：评估器先于搜索——先校准尺子再开始赛跑。**
核心思想：任何自动优化循环的产出上限由评估器质量决定；把"评估器复现已知基准到指定精度"作为独立阶段，是所有可信发现的入场券。
论文证据：Phase 2 专门拟合基线并验证评估管线；天体物理评估器复现文献 DL 至 <0.01 nat，使 agent 产出直接可与发表数字同台。
推广场景：①LLM 评测前先用 benchmark 复现校准 judge；②推荐系统 A/B 基础设施先验证分流无偏；③自动驾驶仿真器先复现监管场景库；④数据标注质检流程先校准抽样器；⑤竞赛平台统一复测各队提交。

**灵感四：恒等值检查——用"可还原原状"防伪创新。**
核心思想：要求每个"修改"内置一个能精确还原原始行为的参数值，任何新组件都先证明自己不是既有机制的重新参数化。
论文证据：心血管案例的恒等检查配合人工审计识破一个代数等价的"伪结构修改"。
推广场景：①代码重构要求行为等价测试通过；②组织流程改革设"回滚对照"验证增益非冗余；③模型微调保留零训练等价检查；④法律合同修改条款逐条可追溯原文；⑤财务衍生品定价新增因子须证明增量信息。

**灵感五：复杂度惩罚 + 外部终检的双闸门。**
核心思想：内部选择用带复杂度惩罚的准则（MDL/AIC）允许在拟合数据上比较，但"从多候选中选最好"这一行为本身引入选择效应，必须有未参与搜索的外部检验兜底——两个闸门缺一不可。
论文证据：Phase 1 规范明文；交通案例 E=Edata+0.01n 强制新机制抵过复杂度成本；轮胎案例 bin5 冻结后单次评估。
推广场景：①特征工程自动化后的留出集闸门；②提示词优化中的 held-out 任务集；③量化策略筛选的样本外复核；④架构搜索的独立搜索-评估 split；⑤药物筛选的双盲二期验证。

**灵感六：多样假设并行 + 统一复核的"研究生-导师"架构。**
核心思想：探索阶段让多个独立方向互不重叠地跑，收敛阶段由单一权威用统一协议重评——兼顾发散与可比。
论文证据：S 个子代理各持不相交函数空间；元代理丢未完成运行、统一重评短名单再定向；五案例均采用 (M,S,I) 参数化。
推广场景：①投资组合多策略并行+风控统一压力测试；②产品 A/B 多创意并行+统一北极星指标；③科研基金多方向资助+统一结题评估；④多 agent 辩论系统设独立裁判；⑤众包设计的并行投稿+统一盲评。

**灵感七：诚实标注证据强度是科学 agent 系统的必要设计。**
核心思想：系统应把"适度的留出优势""弱可辨识参数""结构假设而非机制结论"写进产出记录，而不是让所有结果听起来同样确凿。
论文证据：心血管留出改进被明确标注"非群体级泛化证据"；农业参数弱可辨识性列为 stated limitation；交通结构解读声明"是结构假设，需其他道路验证"。
推广场景：①医疗诊断 agent 输出附置信分级；②新闻聚合 agent 区分证实/传闻；③法务检索 agent 标注判例约束力层级；④代码 agent 区分测试覆盖的与推测的行为；⑤市场预测 agent 附情景条件而非单点结论。
