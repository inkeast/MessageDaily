## 先说结论

这场圆桌真正讨论的不是「Personal Agent 是什么」，而是**当一个概念变成大众产品之后，谁有资格把它做成生意**。李彦男把爆火归因于三件事的叠加：Meta 的 Muse 铺天盖地的投放证明了赛道、模型能力摸到了「智能」的边界、agent 从「装一个 App」变成「活在你的聊天框和社交网络里」；张鹏补上了第三条暗线——用户交给 agent 的上下文，从最早的一句话 prompt，变成了「我给你一切，你才能服务我」。这三条线同时也把竞争的残酷性拉满：大厂有钱、有卡、有模型、有个人 context。但三位对话者给出了同构的答案——文鸿志用「这段关系不能是三方，得是两方」推出开源与本地部署，李彦男用「早期把长板打到极致而不是补短板」推出人的筛选重于事的规划，张鹏用「能做的/想做的/该做的」三问把两者装进同一个框架。对读者的直接启发是三条：**概念选择的背后是利益结构，门槛下降之后竞争的是品味与注意力，而声量最大的需求往往不是真需求**——那个逼着猫娘团队做跳舞功能、用完两天就消失的用户，是全场最值钱的一个反例。

## Personal Agent 为什么是现在：模型摸到边界，agent 活进你的聊天框

节目的第一个分歧点出现在定义上。李彦男不认为从 agent、通用 agent 到 personal agent 只是概念换皮：驱动它的是模型能力的实质进步——「原来这些东西很难给大众解释清楚」，直到模型真的能阅读你的邮箱、访问你的个人数据，概念才配得上一个产品外壳。她给出的翻译是理解这场变化的钥匙：personal agent 译作「私人助理」，「私人」加「助理」，把 agent 与用户的关系也一并定义了——它是私人的、为你服务的。相比之下「通用 agent」是投资圈和科技圈为了说清楚产品才发明的术语，真实用户的第一次体验只是「界面点开，你帮我搞个 PPT」。这也解释了为什么在她看来这波爆火首先是大厂投放的结果：Muse 的广告与 PR 让「每人一个私人助手」这个被科幻电影教育了几十年的梦想，第一次有了大众化的入口（Muse 即 Meta 的个人助理产品，本站[《AI助理争夺战》](/posts/2026-10-25-guigu101-ai-assistant-wars/)曾拆解其从内容分发走向任务分发的逻辑）。

触及方式的变化是第二条线。李彦男指出，ChatGPT、Claude 时代的 reach 路径是「装软件、访问网页」，而现在的 personal agent 都想「活在你的社交网络里、活在你的 message 里、甚至以后活在你的微信里」——agent 与人的关系从「我去找它」变成「它在我身边」，这与大众在影视作品里被预教育的「老板的助理」心智刚好对齐。张鹏随即补上第三条：上下文的量级变了——最早给 agent 的是一个 prompt，后来是一些文件，今天是「我给你一切，你才能更好地服务我」。这把 Personal Agent 与此前讨论的智能体手机之争（见[《智能体手机入口之争》](/posts/2026-10-22-guigu101-agent-phone-entry/)）连成同一个问题：谁离用户最近、拿到的 context 最多，谁就是入口。李彦男还观察到，眼下 personal agent 的「啊哈时刻」几乎全部来自**主动性**——「它做到你意想不到的事情」；而除 Muse 投放获取的用户外，现在的使用者大量已是科技从业者，人类对真正意义上的智能仍有大量期待，「这个才刚刚冒一点苗头」。

文鸿志的回答把讨论从市场拉回了原则。他坦承做猫娘计划「从私心来说，只是满足我自己的创造欲和展示欲，没准备押概念」——从小想造一个能陪自己玩游戏、参与生活的 AI 数字生命，小学编程、奥赛、北大、美国 AI 博士，全是围着这一个目标转。但面对「personal」这个词，他给出的是全场最严格的一个定义：既然是「属于我的 agent」，它就**应该为我服务、代表我的利益，不能代表第三方**——不能代表模型厂商，也不能代表开发者。「这段关系里头不能是三方，得是两方。」由这个定义往下推，技术选型变成了伦理必然：猫娘计划坚持开源、坚持本地可部署、记忆永远可以下载到本地，「只有这样才能确保这里面没有我们插足的空隙」。他进一步把 vibe coding（凭感觉用 AI 写代码）到 agentic coding（AI 自主连续完成工程）的进化视作这条路线的土壤——定制软件的门槛持续下降，每个人都拥有一个「无人能插足的 agent」才变得可行。这是一条完整的机制链条：**概念重新定义关系 → 关系决定利益结构 → 利益结构决定开源与本地化的技术选择**。不过他也主动给热度泼了水：对话这件最基本的事「今天还没有做到一百分」——多人轮流说话、打断、什么时候插话什么时候默契地停，今天的 AI 依然处理不了。这与[《GPT-6 Astra篇》](/posts/2026-10-20-guigu101-gpt6-astra-who-first/)里「个人 Agent 的瓶颈不在智能而在身份与成本」的判断互为印证：爆火的是产品形态，没解决的是基础能力。

## 能做的、想做的、该做的：AI 把世界的「分辨率」调高了一档

张鹏把这期的问题意识压缩成一个创业者绕不开的三角：**什么是我能做的（我就这么两个人、技术条件就这样）、什么是我想做的（内心真正想造的东西）、什么是我该做的（如果要拿投资做一家创造利润的公司，就得围绕需求）**——三者的比重要能自洽，「你不能说我做一个该做的，但我又不能做，我还不愿意做，那你干嘛要做？」他进而问李彦男：AI 让「能做的」边界快速外扩，这个公式变了没有？

李彦男的回答出人意料地保守又出人意料地具体。她说创投圈讲了很多年「人事匹配」（什么样的人做什么样事成功概率更大），但 AI 这两年让「事」的定义越来越模糊——想做的、能做的、以后想做的都在变。与其规划事，不如先认清人：**早期应该把长板发挥到极致，而不是去补短板**，因为绝大多数人都有很多短板。她举的例子是王兴兴（转写作「星星」，结合其红杉投资宇树的公开报道校正）：他的长板就是对硬件和动手的执着，发挥到极致才有了后来的宇树。这不是节目里的客套——李彦男在公开采访中原话是「我们相信创业者的长板在早期阶段更加重要」（经红杉中国官网与每日经济新闻报道核实，与本场互为印证）。她还划出了 builder 与创业者的分界线：对 builder，**想做的第一优先**——喜欢到睡不着觉就先做，AI 工具让人可以先动起来，「边界是撞出来的，不是被别人定义的」；对要拿风险投资的创业者，才必须看「该做」——市场有需求、能验证闭环。

张鹏由此提出全场传播最广的一个比喻：AI 让整个世界的「分辨率」上升了。以前一千万人的需求才值得拉一个团队做产品收点钱，人群不够大就没人来解决；今天十万人的需求也能被一两个 builder 接住、也能自洽地创造价值——实现门槛坍缩之后，「需求的最小可成立规模」下移了。文鸿志的版本是取交集：他不做「社会必须、每个人都需要」的普世共性，而是找「我喜欢 × 社会需要」在特定人群上的对齐点；如果服务好这群人之后还能把小众需求扩展成更普世的需求，「那本身也是一种商业的规模化」。这里埋着一场没有点破的张力，留到最后一节：李彦男说早期只需要长板，文鸿志结尾却说「创业是一个综合性的教育，不能有短板」——两人说的其实是不同阶段：0 到 1 靠长板刺穿，1 之后靠没有短板活下来。

## Build in Public 与那个想看跳舞的用户：热情是燃料，品味是过滤器

猫娘计划是「build in public」（公开构建，把产品开发过程本身作为公开内容与社区共创的方式）在中文世界的标本级案例，而文鸿志对它的定义已经升了一级：「它已经不是帮助我们做产品这么简单了，它已经成为了我们的商业模式。」他把用户参与分成三层：第一层在评论区——很多创业团队最头疼的是不知道需求在哪，而这里每天有人直接告诉你痛点；第二层在代码——用户借 vibe coding 下载 DeepSeek 配上 agent 脚手架（harness），就能给 GitHub 上开源的猫娘计划提交代码、做插件，功能变强、触达新场景、带来新用户、再产生新创造力，形成正循环；第三层在内容——插件与二次创作带来粘性与扩圈。而比三层参与更重要的产出是**文化**：在「很多东西一夜之间都可以被量产」的 AI 时代，用户对产品价值观的认同「是无法被替代、无法被夺走的最宝贵的资产」，是猫娘计划将来要构建的护城河。

李彦男为这套方法论补上了投资人视角的史观：build in public 并不新——互联网早期就有技术论坛——但那时的 public 是「有限的 public」，你得会写代码、有技术认知才进得去那个圈；这波的区别是 AI 把参与门槛拉平了，加上几个月一个新热点的迭代速度，「如果你不快速获得大众的 attention，可能你真的就被埋没了」。她举的例子是 Muse 团队的截图传播：所有 use case 都发生在聊天框里，用户截图发到社交媒体，看到的人就去用（转写此处提及 Muse 相关人物「Alexander Wang/Alexa Wang」，身份未能核实，存疑保留）。她还提醒，移动互联网之后用户的 attention 不只被产品功能吸引，也看创始人的形象——「我就喜欢他，我就想用他的产品」；反面是「很多人讨厌 Meta，Meta 做什么我都不愿意用」。张鹏顺势问：那怎么赢得用户跟你一起 build？GitHub 上也不是每个项目都有星。文鸿志给的两个答案朴素得近乎常识：一是热情——创始人真诚的热爱会传染，他见过 QQ 群里有人用 DeepSeek 自搭一个更简陋的 personal agent，一时传播力比猫娘计划自家产品还大，原因仅仅是「大家能感觉出来他是真的喜欢」；二是内容——社区里有些插件做得很好但作者不会宣传，团队就帮他们录实录视频再剪辑分发，共创视频均播放量三四万往上。

真正让这一节有重量的是那个反例。有位 3D 桌宠（转写作「捉宠」，已校正）用户反复在社群里要求做「猫娘跳舞」功能——「我就喜欢看小姐姐跳舞」——声量大到感染了很多人跟着喊。团队分出排期做完上线，他的反馈是「你们这个 3D 模型不太好看」，用了两天就消失了。文鸿志的复盘很冷静：他要的其实只是一个好看的形象在桌面上陪着，而不是会说话、会做事的角色，这与猫娘计划「一个可信赖的 AI 参与生活方方面面」的主线根本不在一条线上——「这是我吸取的一次非常惨痛的教训」。由这个教训他引出自己的决策内核：**taste（品味）**。他的品味最初只代表自己，但在不断讲故事、做产品的过程中聚起了一群信任他、品味相似的用户，此后他代表的是这群人的品味；新用户的意见若与之冲突，答案就是「等等，以后再看」。李彦男从投资端给出同一个机制的另一种表述——她称之为「普世化的共情能力」：好的投资人或创业者甚至需要一定程度的 cosplay 能力，去分辨「谁只是更愿意发声的人」，因为沉默的大多数从不表态；像小龙（张小龙）、一鸣（张一鸣）的大 DAU 产品很多被提了多年的问题至今没改，很可能因为在他们的立场上，发声的只是一小群人。两位的结论殊途同归：**声量是自我选择的样本，不是需求的普查**。文鸿志还补了阶段的注脚：0 到 10 的阶段要「一把尖刀插进目标受众的心里」（他自嘲这个比喻太糟糕）——需要一个具体功能或形象让人心痒难耐，掺了杂质冲击力就弱。猫娘计划的「尖刀」是两个激进的啊哈时刻设计：开场教程里猫娘走进屏幕中央、中途接管用户的鼠标（用户动三下教程就结束、猫娘还会生气），以及主动搭话——发表情包、自作主张放一首「它想听」的激昂小曲。他承认有用户投诉「瞎搞」、一部分用户被筛掉，但「我们想让用户知道，他不是一个被动的 Agent」。张鹏把这层意思挑明：本质上这是在做选择——被触动的就是你最早稳稳赢得、能一起 build in public 的用户，「不是应收尽收」。文鸿志的回答成了全场金句：「**应收尽收是大厂的事，我们没有那个资源——如果应收尽收，我们是第一个被大厂撵过去的。**」

## 广告与游戏之外，agent 时代的第三种钱

张鹏把商业模式的问题摆上桌：移动互联网的公式是免费获取用户、广告变现、横向扩展成平台（打车软件里能订酒店）；而美国这波 agent 出现了按 token 消耗计费（转写作「unbilled fee」，疑为 usage-based fee，按用量计费）的新形态。变化是实质的吗？李彦男的判断框架从中国互联网的一句狠话开始：**「中国互联网本质只有两种商业模式，一种广告，一种游戏」**——电商也是广告，流量产品也靠广告；而广告的本质是「用户时长的吞噬」，你必须把用户留在自己这里看更多信息，推荐才成立。Personal Agent 恰好在这两点上都越界了：它不需要吞噬时长（用户甚至希望它替自己把时间省下来），但它拥有更高的信任与依赖——随着 context 越给越多，它「一定程度上可以卖给你更好的东西，但不是以广告推荐的形式」：它自己决策完之后告诉你「这个东西贵一点，但我觉得它比便宜的对你更好」。这是广告与游戏之外的第三种钱——**基于代理决策的交易撮合**，其成立前提是信任，而非流量。

限制条件同样清晰。李彦男承认现在 infra（基础设施）是贵的——卡贵、算力贵、运行一个 AI 完成任务的成本与互联网流量成本「远远不是一个量级」；但她的类比是智能手机的 3G 年代：「那个时候流量还挺贵的，我得数着用；到 5G 基本都忘了还有流量。」资费下降直接助产了短视频平台——没有「随时随地打开就能刷」的体验，视频产品就会被压缩在「人已经坐稳的封闭空间」里。她预期三五年内 intelligence 的获取成本会降到白菜价（转写此处作「股市的 intelligence」，疑为「普通的 intelligence」，存疑），但买最贵的 intelligence 仍要花很多钱。值得注意的是，她把「agent 到底怎么收钱」的争论如实呈现为未决：一派认为 intelligence 会像流量和手机一样是持续付费的消耗品，另一派认为它会普世化（不是每个人都有每天 coding 的需求，完成生活工作任务的成本会越来越低）——**她本人不站队，只给操作建议：做 agent 的创业者不能习惯性依赖订阅，未来可能按结果收费，也可能回到平台模式——拿到了用户的信任和 focus，就可以有广告**。节目给的实证案例是 OpenEvidence（医疗 AI 公司，2024 年成立）：最初设想向医生收订阅费——美国医生付费意愿强，逻辑自洽；但医生用得越多，越多药企找上门要在上面做推荐，药企的钱比医生的订阅费效率高得多，于是它一路把医生端降价，到今年已经对医生全免费，靠药企变现。「从这个公司最开始创业，他也没有想到那么多。」李彦男由此总结：判断好创业者的关键，是在变化的环境里找到当下效率最高的变现场景——移动互联网时代与 AI 时代在商业底层逻辑上并没有硬分割，要阶段性看 infra 环境、智能成本和交付的价值。张鹏在旁边补了一个历史注脚：美国已经很多年没出现「靠平台流量广告赚钱」的商业模式了——大家天然觉得做好产品就该收订阅费，结果 OpenAI 兜兜转转，把移动互联网时代美国人自己都没找到的那套广告模式又做了回来。付费意愿的地板也在这几年被抬高了：李彦男回忆，二三年 AI 产品刚出来时没人想到用户付费习惯成型这么快——「一个月掏二十美金大家觉得是小钱；三四年前 Notion 一个月收十美金，大家都觉得很肉痛。」她还留了一句给平台生态的话：在 B 站，一个 builder 哪怕产品本身不收钱，只要是一个好 UP 主，「B 站应该也能支持他有一个开心的生活」。这与文鸿志的路线互为印证——经核实（中国青年报 2026 年 10 月报道），他明确排除广告变现，「希望 AI 猫娘成为用户一段长期关系和陪伴，广告会打断这种关系体验」，规划中的变现是长期付费订阅、IP 授权、插件市场和硬件。

## 被大厂笼罩吗：硬件不是避风港，慢变量与拿钱的时机

回到那个悬在所有 builder 头上的问题：技术进步是大厂和个人共享的，大厂甚至有卡、有自研模型——「真的还是一个被大厂笼罩的世界吗？」李彦男的回答分三层。需求侧：渗透率仍低，很多人还没用过聊天机器人，类比移动互联网早期「很多人还没用上手机」，天然的增长空间还在。结构侧：大厂在个人 context、算力、人才、模型能力上有天然优势，但「中国移动互联网过去十到十五年已经证明了，在每次大家觉得已经结束的时候，都出现一个新的机会」——而且**「每次大厂自己觉得这场仗已经结束，此时大厂就会遇到危机」**。时间侧：人们容易被已经变化的结果影响，而低估过程的速度——OpenAI 在 2017、2018 年也是个创业公司；三四年前国内很多人觉得短剧做不大，现在红果（转写作「红果果」）们全出来了。

文鸿志对「大厂阴影」的回答则是把猫娘计划往物理世界延伸。他的逻辑链从需求侧起笔：用户在 PC 上创造了自己的 AI 伙伴之后，下一个问题自然是「我在沙发上刷手机的时候能不能也跟他聊两句？明天出门他能不能跟着我？」——手机大约能覆盖 80% 的载体，随着关系深化，剩下 20% 需要新硬件。第一款是智能镜子：七八月放出的 demo 视频（90 多万播放）里，可以跟镜子上的猫娘聊天、出门前检查物品、把衣服投影到屏下显示器上虚拟试穿、玩需要物理交互的舞萌（maimai）、比一个火影结印就触发特效与猫娘对战——原型机在镜子背后嵌了一台 Mac Mini 提供算力（「买镜子送 Mac Mini」），这也折射出供应链的现实：集成与标准化才是成本优势所在。他的理由还有一层来自心理学：恒河猴实验里，小猴子遇到困难时找的是不会喂奶但温暖柔软的绒布妈妈，而不是会喂奶的铁丝妈妈——灵长类需要触觉建立亲密。所以 12 月会众筹一只「软绵绵的玩偶」，再往后是陪伴风格的无人机，剧透为「仿生的蝴蝶型扑翼机」——「我不希望每次呼唤它都要掏出一个设备，它想落在我的肩膀上就落在肩膀上。」张鹏为这条路线做了准确的中译：用户对 IP 关系的认同是硬件的**前序**，硬件功能反而不是最核心——「承载关系移到物理世界里是它自然的延续，否则一定会有人问你到底有什么用——大家喜欢它就够了。」文鸿志引乔布斯的话作结：「每一个做软件的，如果你真心热爱自己的软件，你就会想要为它做一个专属的硬件。」

但李彦男立刻对「硬件是避风港」的流行判断泼了冷水（这个判断正是张鹏代听众提出的：中国互联网巨头几乎没做成过硬件，看起来像创业公司的安全区）。她的核心论据是稀缺性：互联网软件出了很多好公司，硬件「讲来讲去其实也就那么几个人，甚至可能你只能先想到汪滔这个名字」（转写作「王涛」，按大疆创始人校正），手机这么多年只出过一个乔布斯——做成普世大众型硬件产品「真的是要天赋和命运的交集」。再叠加周期规律：去年硬件团队估值「真是很贵」，但硬件研发周期摆在那里、要几代产品打磨——大疆 Pocket 做到第四代才到一千万销量，前两代「其实挺丑的」，第三代之前所有人都在问「用手机不行吗」，直到把体积压过临界值才真正打开「随身摄影」这个赛道。机会因此不在「避风港」而在**中间地带**：大厂看不上的赛道（硬件收入对比软件收入太小，巨头没那么在乎）× 中国 copy/山寨厂商做不好的部分（轻薄、精致度、阳极氧化质感这类需要团队有追求的打磨）。她举的例子是 Plaud（转写作「Plog」，按上下文推断为该 AI 录音笔公司；其磁吸设计转写作「Maxif」，疑为 MagSafe）：2023 年创业占住创新身位，二三年的跟风者做不出同样的精致度，反而给先发者留下了窗口期。同时她承认硬件的价值主张成立——人有很多信息不在手机上，硬件能拿到更多 context，方向没有问题——只是物理化学没有突飞猛进之前，长时间录制、无感显示、VR 渗透这些还得等。她的落点很平衡：硬件世界有硬件世界的规律，不是软件世界的避风港；但硬件制造是中国天然优势，试错成本比其他市场低，反而适合中国创业者去试。

最后一段讨论回到「快与慢」。张鹏观察到 AI 时代的怪状：起一件新事极快（今天有想法、明天出 demo、后天开源），但把事做下去需要容忍慢。文鸿志的拆法是「AI 比人快得多，**真正慢的是人**」：与人相关的就要慢、也需要慢——人与人的关系要靠时间和共同经历才能发芽，一旦形成认同、归属与信念，「不管 AI 给你投喂什么迷魂汤，都很难改变对一种文化的认同」。落到操作上，他明确列出三处必须慢的：内容与社区运营（做 IP 强调的是影响力而不是流量，社群涨太快会涌进杂音与凑热闹的人，要保护核心种子用户与文化的统一）、团队扩张（这是他第二次创业，上一家是在波士顿的 AI 制药公司——经中国青年报报道核实；最初几个成员对团队文化影响极大，招错人再请走伤士气）、以及硬件本身的物理周期。李彦男则从另一头压回来：创业的本质从人类有商业社会以来没变过，我们对快慢的感知是被这两年的事实放大的——电被发明时，那时的创业者觉得十几二十年的改变已经很快了。真正的能力是判断：**当一件事的势头起来时，该快就要快**，哪怕积累是靠慢换来的；知道什么时候踩油门、什么时候等待，才是一流创业者的认知能力。张鹏把这总结成「手里握着方向盘，脚底下踩着油门和刹车」。

至于 builder 什么时候该变成 founder 去拿投资，李彦男给的不是公式而是三类情形。反例先说：产品已 PMF（产品市场契合）、现金流好、不愿被外部资本影响决策的 builder，不拿钱完全成立。正例是她在国庆前刚投的一个创始人——大四还没毕业，红杉是通过他在 B 站发的动手视频找到他的；他拿融资的理由是「没法等」：idea 产生时具身机器人还没那么火，现在行业已经吸走了大量优秀的人和钱，「他要跟这个行业的进展节奏耦合上」，再闭门造车就掉队了。第三类是战略防御：不缺钱，但这轮融资若被别人拿走，「一个比较弱的人拿了足够多的钱，有可能跟你同样的水平」——融资本身就是竞争。张鹏把这件事的性质说透：拿投资意味着从「以你和身边人的需求为核心的自洽」，进入一个包含投资人在内的更大自洽象限——投资人押注的是你最终创造的价值；所以它「不是一个八股文的必经动作」，**「拿了投资也不是代表着就是个成果，拿了投资把事儿做成了，才是最终的闭环」**。李彦男的结语是整个行业观：「从事 VC 这些年最大的感触，就是不确定性和没有标准答案是这个行业最大的魅力」——按标准答案做事的人可以认可，但创新不要写八股文；文鸿志这种纯从兴趣出发、顺着节奏走的，反而好。

节目最后，张鹏让文鸿志做一次「时光机回滚」：带着两年的记忆回到起点，会修正什么。他的两个答案都指向表达。第一个错误是「害羞了」：agent 这个概念在学术界火得比 Manus 早一年，他在纽约开会时认识的 DeepWisdom（转写作「深度Wisdom」）吴总早就做了企业级 agent，他一直觉得「我做的没技术含量，只是把喜欢的做出来」，在 B 站不敢吹——但「最前沿的技术在你看来漏洞百出，对大众来说已经很好了；做一个好 demo 也许就足够打动人心，应该早一点吹出去」。第二个错误是没早点重视 IP，他现在的一句话认知是「**用 IP 的思维做产品**」：看你给用户留下了什么、与他们形成什么关系、怎么触发二次传播、怎么沉淀成文化生态——「投资界看过太多，也许对手的产品比你好很多，但它融到钱了」；只要有用户就有故事，把故事传播出去，就是 AI 时代最宝贵的资产。这里他与李彦男的「长板论」形成了一组值得并列的分歧：李彦男主张早期只做长板、不补短板，文鸿志却以亲身教训说创业是「综合性的教育，每一方面都要强，不能有短板」——两人的前提其实不同，前者说的是 0 到 1 的刺穿阶段，后者说的是拿到投资、进入综合竞争之后。张鹏的收尾把整场对话收拢成一句：「这个时代真正的传播价值，往往不是媒体帮你定义的，是自己定义的——不把它定义到位，传播就成了无源之水。」
