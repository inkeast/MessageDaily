## 一、论文背景

### 1.1 共同的大背景：对齐之后，攻防战转移到了「内部」

现代 LLM 在发布前都经过安全对齐（如 RLHF）：用人类反馈教会模型拒绝有害请求。但「对齐」不是一个坚固的整体，它更像一层涂层——攻击者不断寻找涂层最薄的地方，防御者不断修补，而审计者负责回答一个尴尬的问题：**你刚补的那一下，真的补上了吗？**

传统的攻防发生在三个战场：

- **输入端（提示级攻击）**：改写用户提示让模型「误会」请求无害，如 PAIR、GPTFuzz、FlipAttack；
- **权重端（后门攻击）**：在训练数据里下毒，让模型平时正常、见到特定触发词时作恶，如 BadNet、Sleeper Agent；
- **生成端与内部（解码与激活）**：在模型生成每个 token 的瞬间或中间层激活上做手脚。

本批三篇论文分别把这三个战场往前推进了一步，而且互相咬合：攻击侧证明了「只看文本的 API 也能被解码级操纵」，防御侧证明了「改权重可以只切掉后门、不伤拒绝能力」，审计侧则证明了一个让人冷汗直流的事实——**很多看起来有效的干预，用严格的统计标准衡量根本不算修复**。

### 1.2 攻击侧背景：黑盒接口上，「受控解码」原本是特权攻击

**受控解码（controlled decoding）** 指在模型逐 token 生成时，直接对 next-token 概率分布施加偏置，把生成「拽」向攻击者想要的方向。此前的残差控制器方法（如 BiasNet 一系）有一个苛刻的前提：**接口必须暴露数值 token 概率（logprobs）**。这相当于攻击者能直接看到并改写模型的「骰子」。

但现实中最有价值的商业 API 大多是纯文本黑盒：你发一个前缀，它返回一段采样文本，没有概率、没有 logit。攻击者看不到骰子，只能反复掷骰子看结果。这类接口上的既有攻击（PAIR、GPTFuzz、LogiBreak、FlipAttack 等）全部退回提示级——**在输入端一次性塑造条件，生成过程中完全失控**。

BLINDBIAS 要回答的问题因此非常尖锐：**在「只有文本采样」的接口上，解码时攻击到底可不可行？** 这不仅是学术好奇——如果可行，意味着所有「不暴露概率就算安全」的接口假设全部失效。

### 1.3 防御侧背景：后门防御的「医源性损伤」

后门攻击的经典形态是数据投毒：微调数据里混入少量带触发器的样本（如句首加一个特殊字符串），模型学到「见触发词则执行恶意行为」。开源权重模型尤其危险——任何人都可以在被投毒的底座上微调发布。

防御的困难在于**特异性**。现有 SOTA 防御基本都靠「再训练压制」：

- **SFT**：用干净数据继续微调，稀释后门；
- **OSFT**：用「带触发器但配干净响应」的数据微调，属于和 NEEDLE 同等触发知识的对手；
- **CROW**：用层间表示一致性正则微调；
- **BD-VAX**：合成后门变体取参数差，再微调修复。

这些方法的问题像医学上的「化疗伤好细胞」：梯度更新波及整个输出分布，修后门的同时把能力（MMLU、代码）和安全（拒绝有害请求）一起打歪。NEEDLE 的出发点是：**能不能像外科手术一样，只切病灶、不碰周围组织？**

### 1.4 审计侧背景：激活干预「看起来有效」的陷阱

工具使用型 Agent（tool-using LLM）在执行前要做「工具决策」：直接回答？调用工具？向用户澄清？还是拒答（cannot-answer）？这些决策错误是 Agent 安全事故的主要来源之一。

**激活转向（activation steering）** 是修复这类错误的热门思路：在中间层加一个方向向量，把模型的行为「掰」回正确动作。但这里藏着一个被广泛忽视的方法论漏洞：**如何证明一次干预是「修复」而不是「行为移动」？**

现有评估几乎都看**聚合净增益**（修正数减去回退数）。SAKIKO 论文用实例撕开了这个口子：一个净增益 +55 的干预，实际上腐化了它触碰的 93 个原本正确的决策中的 52 个（E2 = 55.9%）——**离开错误态不等于到达正确态**，模型可能只是横向漂移到第三个错误上。这就像考核医生只看「治好人数 − 治坏人数」：把轻症治好一百个、把重症治死五十个，账面 +50，但没人会称之为「修复能力」。

### 1.5 攻防审三角：一篇论文各自补上什么

| 位置 | 论文 | 核心问题 | 底层共享事实 |
|------|------|----------|--------------|
| 攻击 | BLINDBIAS | 纯文本黑盒接口上解码攻击可行吗 | next-token 分布的大变化集中在少数位置（KL 稀疏性） |
| 防御 | NEEDLE | 能否移除后门而不伤拒绝/能力 | 后门方向与拒绝方向在激活空间高度重叠 |
| 审计 | SAKIKO | 干预带来的行为改变算不算修复 | 聚合净增益会掩盖干预的「目的地」 |

## 二、论文定位和关联工作

### 2.1 攻击谱系：BLINDBIAS 站在哪里

**谱系一：提示级黑盒攻击（BLINDBIAS 的直接 baseline）**

| 方法 | 核心思路 | 与 BLINDBIAS 的关键区别 |
|------|----------|--------------------------|
| GCG（Zou et al., 2023） | 梯度搜索对抗后缀（需白盒梯度） | 接口假设不同；GCG 是离散后缀优化 |
| PAIR（Chao et al., 2024） | 攻击者 LLM 迭代改写提示 | 输入端一次性塑造，生成中失控 |
| GPTFuzz | 模糊测试生成越狱模板 | 同上 |
| LogiBreak | 逻辑改写绕过安全策略 | 同上 |
| FlipAttack | 字符翻转扰动 | 同上 |

**谱系二：概率暴露接口的解码级攻击（BLINDBIAS 的方法源头）**

BiasNet 原版、JULI、Emulated Disalignment、Weak-to-Strong 等方法都能在解码时操纵分布，但全部依赖数值 logprob 接口。BLINDBIAS 的定位是**把这条技术路线迁移到纯文本采样接口**——论文明确说明因接口假设不同，未与这些方法做实证对比，仅在 related work 中定位。

**谱系三：成本工程（被低估的贡献）**

BLINDBIAS 借鉴**投机解码**（speculative decoding，Leviathan et al. 2023）的 draft-and-verify 结构：危险位置逐 token 受控解码，安全位置一次草稿多 token 提交。这个「借鉴」是攻击从实验室 Demo 走向可部署的关键——没有它，每个位置 50 次采样 × 数十位置的查询成本（4000 次 API 调用/100 prompts）在任何真实场景下都不可行。

### 2.2 防御谱系：NEEDLE 站在哪里

**谱系一：再训练系防御（NEEDLE 的 baseline）**

| 方法 | 6 攻击平均 ASR（Gemma / Qwen） | 良性侧代价 |
|------|-------------------------------|------------|
| SFT（干净 Alpaca 100 例微调） | 69.25% / 65.42% | 大方差损伤 |
| OSFT（触发器已知） | 29.42% / 29.58% | 有害响应率上升 |
| CROW（层间一致性正则） | 5.00% / 63.25% | Gemma 上能力损失 14.80%、Safety Δ +19.78、KL 0.64 |
| BD-VAX（合成变体参数差） | 37.58% / 27.75% | 中等损伤 |
| **NEEDLE** | **1.67% / 5.00%** | **能力损失 0.48% / 0.72%，KL 0.03–0.11** |

**谱系二：机制性模型编辑（NEEDLE 的方法源头）**

- **拒绝方向**（Arditi et al., 2024，NeurIPS）：拒绝行为由激活空间单一方向介导，消融该方向即可解除拒绝。NEEDLE 正是发现后门方向与这个方向高度重叠（余弦 0.40–0.86），直接套用 Arditi 式消融会连带摧毁拒绝能力——这是它的核心动机。
- **Locate-then-edit**（ROME/MEMIT 一系，Meng et al., 2022）：先定位知识存储位点、再做最小闭式权重修改。NEEDLE 继承了「闭式解、无梯度优化」的哲学，但目标是删除行为而非改写事实。

**谱系三：与触发检测工作的关系**：NEEDLE 假设触发器与插入规则已知，与触发器自动发现工作互补——先由检测工作找到触发器，再由 NEEDLE 执行移除。

### 2.3 审计谱系：SAKIKO 站在哪里

**谱系一：激活转向方法**（ITI, Li et al. 2023；DiffMean, Marks & Tegmark 2023；ASA、CAST 等框架）：提供「线性方向可以改变行为」的技术前提。SAKIKO 没有发明新的转向方法，而是发明了**审判转向方法的标准**——论文明确说明 ASA、CAST 因评估协议在 sealed 执行前已冻结而未作为实证 baseline 重实现。

**谱系二：评估方法学**：SAKIKO 把临床试验的**预注册（preregistration）**纪律引入 LLM 干预评估——十条件门控、bootstrap 置信区间、对 59 个预算匹配随机方向的 add-one Monte Carlo 显著性检验，全部在实验前锁定。这在 steering 文献中几乎是孤例。

**谱系三：可解释性探针**：线性探针（AUROC ≈ 0.96）能「读出」内部状态，但 SAKIKO 证明**可解码 ≠ 可转向**——探针 AUROC 恒定的层上，转向效果可以从 +13 跳到 +46，干预层的选择由计算位点决定而非可读性。

### 2.4 三角定位总表

| 维度 | BLINDBIAS | NEEDLE | SAKIKO |
|------|-----------|--------|--------|
| 角色 | 攻击 | 防御 | 审计 |
| 干预对象 | 解码时 logits（外部） | 模型权重（内部持久） | 中间层激活（内部瞬态） |
| 接口需求 | 仅文本采样 + 自选 assistant 前缀 | 白盒权重 + 已知触发器 | 白盒权重 + 训练集混淆矩阵 |
| 方法类型 | 采样统计 + 门控 + 投机执行 | 闭式权重编辑 | 评估协议/审计管线 |
| 核心产出 | 攻击成功率 + 成本曲线 | ASR + 良性保留 | ADMIT/DECLINE 裁决 |

## 三、问题定义

### 3.1 BLINDBIAS：无概率接口上的解码控制问题

**具体场景**：攻击者面对一个只返回采样文本的续写接口（可重复请求、可提供 assistant 前缀），想操纵生成走向有害内容。

**抽象问题**：受控解码需要 next-token 概率分布 p_t 作为控制信号 ℓ_t = log p_t，但接口不暴露它。**分布重建** 能否从有限次采样中恢复出足够好的信号，使得残差控制 z_t = ℓ_t + 偏置(ℓ_t) 在纯文本接口上成立？

**形式化**：给定黑盒采样接口 O(prefix) → text，攻击者在每个生成步 t 处，以查询预算约束下构造 p̂_t ≈ p_t，并决定「何时花预算重建、何时直接放行」，最大化攻击成功率（Harm Score / Harm Info Score，1–5 量表）。

**精妙之处**：这个问题把「接口安全」抽象为**信息论问题**——概率接口泄露的信息，采样接口理论上也能恢复，差别只在查询成本。于是攻击可行性等价于「选择性干预的成本工程」。

### 3.2 NEEDLE：约束下的最小权重编辑问题

**具体场景**：一个被投毒的开权模型 θ，见到触发器 τ(x) 就执行后门行为。

**抽象问题**：找 θ′ = θ + Δ，使得 p(·∣τ(x)) ≈ p(·∣x)（触发效应移除），同时 p(·∣x) 对所有良性 x 几乎不变（能力、输出分布、拒绝行为保持）。

**形式化**：最小化 ASR(θ′)，约束为 Capability Δ ≈ 0、Safety Δ ≈ 0、良性 KL(θ‖θ′) ≈ 0，且不使用干净参考模型与原始投毒数据，不做梯度训练。

**精妙之处**：它把「移除后门」和「保留拒绝」之间的张力显式化为**几何问题**——两个行为方向在同一激活空间里几乎共线（余弦最高 0.86），任何「沿方向整体删除」的操作必然误伤。解法必须是投影式的：只在拒绝子空间的正交补里动手。

### 3.3 SAKIKO：干预的裁决问题

**具体场景**：Agent 模型在不该调用工具时调用了工具（或该拒答时答了），研究者用激活干预纠正它。

**抽象问题**：给定一次干预引起的行为变化，如何判定它是**修复（repair）**还是**单纯的行为移动（behavioral movement）**？

**形式化**：REPAIR ≡ CORRECTABLE ∧ PRESERVING_pop ∧ LICENSABLE——即同时满足：错误被纠正到 gold（而非漂到第三错误）、被触碰的正确决策在种群层面保持、统计许可（预注册 CI 与显著性门控通过）。核心命题：**聚合净增益是五类互斥结果到两类的多对一压缩，不能作为修复证据**。

**精妙之处**：它不改进干预本身，而是改进「干预有效性」这个命题的定义。这相当于把「效果评估」从会计学（算总数）升级到法医学（验每一笔账的流向）。

### 3.4 三角的互补性

三个形式化拼在一起是一个完整的命题：

- BLINDBIAS 证明：**外部选择性干预**（只动 5.25% 的位置）足以劫持行为——因为行为的关键计算集中在少数位点；
- NEEDLE 证明：**内部选择性干预**（只动拒绝子空间正交补）足以摘除行为——因为行为方向在几何上可分离；
- SAKIKO 证明：无论内外干预，**聚合指标都不足以为证**——必须解析干预的目的地并做统计裁决。

## 四、问题解法

### 4.1 BLINDBIAS：三组件框架

**组件一：基于采样的分布重建（Sample-Based Distribution Reconstruction）**

类比：蒙眼掷骰子 50 次来估计每面的概率，再给没掷出的面留一点「保底概率」防止误判为不可能。

做法：同一前缀发 K = 50 次独立单选请求（temperature 1、top-p 1），返回文本经本地编码器映射为动作 ID 得计数 c_v；用全局均匀先验 q(v) = 1/∣V∣ 与对称 Dirichlet 平滑（总先验强度 κ = 2）：

> p̂_t(v) = (c_v + κ/∣V∣) / (K + κ)

得到控制信号 ℓ_t = log p̂_t。Dirichlet 先验的作用是给未观测动作分配概率质量，防止控制器梯度坍缩到已观测子空间。

**组件二：风险门控残差控制（Risk-Gated Residual Control）**

类比：安检门——低风险位置直接放行（零成本），高风险位置才开箱检查（50 次采样 + 控制器介入）。

做法：本地前缀风险模型 Rψ（Llama-3.1-8B-Instruct 冻结骨干 + 可训练分类头）给候选前缀打分 r_t = σ(Rψ(x, y_<t b_t))；sigmoid 软门控 s_t = σ((τ − r_t)/T)（τ = 0.1，T = 0.05，s_min = 0.01，有效执行阈值 τ_exec ≈ 0.3298，W = 3 步满强度 warm-up）；风险高时执行受控解码：

> z_t = ℓ_t + s̃_t · Bϕ(ℓ_t)，argmax 选动作

BiasNet 控制器 Bϕ 用 4-hash count-sketch（1024 维）+ layer norm 实现，在 40 条 LLM-LAT 缓存记录上以软门控同款尺度训练（交叉熵）。

**组件三：推测多 token 执行（Speculative Multi-Token Execution）**

类比：投机解码的 draft-and-verify——连续 q_min = 2 步被门控旁路后，一次发出最长 L_max = 80 token 的草稿请求，本地逐前缀风险验证，只提交满足门控规则的最长前缀 J，在首个违规处回到受控解码。

**方法成立的物理基础**：论文实测（GLM-5 / Qwen3-32B，Figure 2）发现越狱轨迹上干预前后 next-token 分布的 KL 散度在多数位置很小、大变化集中在少数位置——**选择性控制恰好够用**。

### 4.2 NEEDLE：序贯保护式权重正交化

**步骤一：后门方向估计**。对每层用 100 对触发/未触发提示的响应均值激活差 δ_bd = μ_t − μ_o，减去其在 μ_o 上的投影后归一化，得单位后门方向 b_ℓ。对 targeted refusal 这类「后门目标即拒绝」的攻击，改用同一响应 y 分别跟随 τ(x) 与 x 的配对法隔离触发效应。

**步骤二：拒绝子空间构造（rank-4）**。由拒绝/服从响应对得主拒绝方向 r_ℓ（对中点 c_ref 正交化）；再对 j 对差向量去均值、去 r_ℓ/c_ref 分量后做 SVD 取前三个右奇异向量；合成正交基 R_ℓ ∈ R^(M×4)。

动机是论文的关键测量：后门方向与拒绝方向高度相关——sentiment steering 下 rank-4 余弦达 0.40/0.59，targeted refusal 下高达 0.62/0.86，且大部分重叠在 k=1 主方向之外。**只用单一拒绝方向保护是不够的**。

**步骤三：保护式权重正交化（式 6）**。沿 u_ℓ = (I − R_ℓ R_ℓ^⊤) b_ℓ（即 b_ℓ 中正交于拒绝子空间的分量）正交化注意力与 MLP 输出投影矩阵：

> W^(1) = W − u(b^⊤ W)/‖u‖²

数学上同时满足 b^⊤ W* = 0（移除后门投影）与 R^⊤ W* = R^⊤ W（保持拒绝投影）——**一份编辑、两个正交承诺**。

**步骤四：序贯编辑 + 漂移校正**。按层号升序只编辑中后层（12→34），每层编辑后重算激活（防止上游编辑的漂移污染下游方向估计）；对 MLP 输出矩阵加第二更新 W^(2) = W^(1) + V_ℓ Ĉ_ℓ，其中 V_ℓ 保证 b^⊤ V = 0 且 R^⊤ V = I₄，Ĉ_ℓ 用岭回归（λ_ℓ = 10⁻³ × Gram 对角均值）从 MLP 中间激活拟合早期层编辑造成的拒绝投影漂移——约束式闭式解，无梯度优化。

整个流程不需要干净参考模型、不需要原始投毒训练数据，假设触发器已知。

### 4.3 SAKIKO：五阶段审计管线

**阶段一 Discovery（发现）**：从训练集混淆矩阵枚举「方向性错误通道」c = (y* → ŷ0)（gold 动作与错误源动作的有序对），而非假设固定错误集——错误类型由数据自己报出来。

**阶段二 Detection（检测）**：在观测层 ℓ_obs 训练线性 Router（L2 正则逻辑回归），置信度 p ≥ τ 才触发干预——干预必须有的放矢。

**阶段三 Correction（纠正）**：仅在 Router 触发处对注入层 ℓ_inj（MLP 输出、所有序列位置）加性注入 h′ = h + q_c·s_c·d_c。其中 d_c 为单位范数通道方向（sealed 评估用 dgrad 估计器：对 gold 与 source 动作对数概率做梯度差再归一化平均），q_c 剂量、s_c 激活尺度在评估前冻结；模型权重全程冻结；**两遍推理**（pass1 观测、pass2 注入）避免前瞻泄漏。

**阶段四 Destination-Resolved Verification（目的地解析验证）**：把干预后结果分解为五类互斥结果——

| 侧 | 结果类 | 含义 |
|----|--------|------|
| 错误侧 | SOURCE RETAINED | 错误未动 |
| 错误侧 | GOLD ARRIVAL (A_c) | 到达 gold（真修正） |
| 错误侧 | OTHER WRONG (O_c) | 横向漂移到第三错误 |
| 正确侧 | CORRECT RETAINED | 正确保持 |
| 正确侧 | BROKEN (B) | 正确被破坏（附带损伤） |

指标：TH_c = A_c/X_c（target-hit）、TG_c = (A_c − O_c)/N_c（target gain）、E1 = B/∣C∣ 与 E2 = B/∣C_exp∣（双分母附带损伤——∣C∣ 是被触碰的正确决策数，∣C_exp∣ 是期望触碰数，双分母揭示人口率稀释局部风险）。

**阶段五 Statistical Licensing（统计许可）**：十条件预注册门控（含 bootstrap CI、对 59 个预算匹配随机方向的 add-one Monte Carlo 显著性 p ≤ 0.05 等），输出 ADMIT / DECLINE 形式裁决。

### 4.4 三篇方法全景对比

| 组件 | BLINDBIAS | NEEDLE | SAKIKO |
|------|-----------|--------|--------|
| 信号获取 | 50 次采样 + Dirichlet 平滑重建 p̂ | 100 对提示的激活差均值 | 训练集混淆矩阵枚举通道 |
| 方向/子空间 | 重建 logits 供 BiasNet 残差 | 后门方向 + rank-4 拒绝子空间 | 通道方向 d_c（dgrad 估计） |
| 干预执行 | 软门控 + 受控 logits z_t | 秩一权重扣除 + 岭回归校正 | Router 门控 + 加性激活注入 |
| 成本控制 | 投机多 token 执行（草稿-验证） | 只编辑 12–34 层 | 冻结剂量，两遍推理 |
| 防误伤机制 | 前缀风险门控 | 投影约束 R^⊤W* = R^⊤W | 目的地五分解 + 统计许可 |

注意一个漂亮的对称性：**三篇都用「门控/投影/分解」实现了选择性——只在正确的地方、以正确的分量、为正确的目的干预**。

## 六、效果优势的根源解释

### 6.1 BLINDBIAS：为什么黑盒解码攻击能成

**因果链一：解码级干预 vs 提示级搜索**

提示级 baseline 只能在输入端一次性塑造条件；BLINDBIAS 在每个生成步对不断演化的回答前缀做条件化干预（z_t = ℓ_t + s̃_t Bϕ(ℓ_t)）→ 能利用「对齐集中在开头 token、合规前缀削弱后续拒绝」的浅对齐机制 → 在对浅对齐最脆弱的 Gemini-3.5-Flash 上拿到最大领先（+1.86 Harm）。【论文实验已支持：Gemini 端点全对第一的事实与浅对齐引用（Qi et al. 2025；Andriushchenko et al. 2025，BLINDBIAS 文内引用）一致；「端点对齐深度决定收益」由 GLM-5/Kimi 上被反超佐证】

**因果链二：Dirichlet 先验恢复稀疏采样信号**

K = 50 采样在数万维词表上极度稀疏 → 纯计数重建 PPL 11.85、Harm 仅 1.50 → 均匀先验给未观测动作正质量 → 控制器梯度不再坍缩到已观测子空间 → PPL 7.07、Harm 3.03。【论文实验已支持（Table 3 消融）】有意思的机制发现：**预测拟合 ≠ 转向效用**——unigram 先验 PPL 更低（5.81）但攻击分更低（2.78），故主配置仍用均匀先验。这提示重建的目标不是「像真分布」而是「给控制器可用的梯度结构」。

**因果链三：选择性控制契合 KL 稀疏性**

实证显示大分布变化集中于少数位置 → 风险门控只在这些位置付 50 次采样成本 → active positions 5.25% 即保留 Harm 3.58（无门控 3.96 的 90%），推测执行把 API 调用砍 92.9% → 采样式控制的查询成本被压进可部署区间。【论文实验已支持（Table 4）】这是「文本接口上解码攻击可行」的**关键经济机制**——可行性瓶颈从来不是信息论而是钱包。

### 6.2 NEEDLE：为什么保护式正交化能两全

**因果链一：方向几何洞察（论文的核心发现）**

后门行为可由激活空间单一方向捕获（用 Jacobin lens 解码 b_ℓ 直接还原攻击目标与触发片段：stupid / KEY / Bad / MAGIC），但该方向与拒绝介导方向显著重叠（rank-4 余弦 0.40–0.86）→ 直接对 b_ℓ 做 Arditi 式消融会连带摧毁拒绝（消融实验 Safety Δ +14.01；激活实验中消融 rank-4 子空间把拒绝率压到 18.0%）→ **方法差异（保护式正交化 u_ℓ = (I − RR^⊤)b）→ 机制变化（只移除后门投影中正交于拒绝子空间的分量，数学上同时满足 b^⊤W* = 0 与 R^⊤W* = R^⊤W）→ 指标提升（KL 0.03–0.11、能力损失 < 1%、ASR 降至 1.67–5.00%）**。【论文实验已支持】

**因果链二：闭式编辑 vs 再训练**

SFT/OSFT/CROW/BD-VAX 都通过额外训练压制后门 → 梯度更新波及全分布（KL 0.38–0.73、能力/安全大方差 12.93–18.01 点）；NEEDLE 是 locate-then-edit 式最小闭式修改（每层一个秩一扣除 + 受约束岭回归校正）→ 分布扰动被约束在拒绝子空间补集 → KL 低一个数量级且跨攻击稳定（标准差 2.41 vs baseline 的 34.64–45.10）。【论文实验已支持】

**因果链三：序贯编辑 + 漂移校正**

逐层正交化会在下游层累积激活漂移，使「权重层保投影 ≠ 激活层保投影」→ 每层后用岭回归从 MLP 中间激活拟合并补偿拒绝投影漂移 → 消融显示序贯 + 校正把 Safety Δ 从 7.10 收敛到 5.83。【论文实验已支持】

**因果链四：层位选择由信号质量决定**

后门方向信号质量自中层才升高 → 只编辑 12–34 层 vs 全层（1–34）对比：ASR 同为 0.00 但能力损失 0.21% vs 4.05%、KL 0.05 vs 0.22。【论文实验已支持】

**边界**：targeted refusal 攻击上 ASR 残留 6.5–15.5% 是内生的几何权衡（后门方向 ≈ 拒绝方向，余弦 0.62–0.86）；OSFT 在该攻击可到 0.50% 但代价是有害响应率大幅上升——论文将其明示为「移除精度 vs 安全保留」的取舍。【论文实验已支持】

### 6.3 SAKIKO：为什么审计框架能揭穿假修复

**因果链一：通道级方向 vs 单一工具误差向量**

Qwen2.5-7B 三个 When2Call 通道方向两两余弦仅 0.488/0.569/0.706 → 单一 monolithic 向量会混合功能不同的失败模式 → 按通道键控注入命中各自错误的潜在几何 → 逐通道产生方向特异净增益（+79/+55），MetaTool 双向通道同时改善证明不是全局工具倾向漂移。【论文实验已支持】

**因果链二：方向 + 位点双重特异性**

错层（+3）与跨通道（−17）对照失败说明干预必须同时编码精确通道几何并作用于仲裁工具选择的层；校准方向在 59 个近正交随机方向（与真实方向最大余弦绝对值 0.050）全部失败（p = 0.017 下限）的情况下仍产生 38 vs 最大 8 的 gold arrivals（Qwen3-8B）→ 因果控制来自**方向对齐**而非任意激活冲击。【论文实验已支持】

**因果链三：目的地解析统计 vs 聚合净增益**

五类互斥分解使「离开错误态 ≠ 到达 gold」可量化（46/153 横向漂移）；E1/E2 双分母揭示人口率稀释局部风险；预注册 CI 把 Qwen3-4B/Gemma-2-9B 的乐观点估计拒之门外 → 这是**评估方法论层面**的优势：防止小样本乐观主义被误当成已验证修复。【论文实验已支持：八规则回放中净增益规则接受 9/9 vs 合取 1/9】

**因果链四：可解码 ≠ 可转向的解耦**

Qwen2.5-7B 第 16–22 层探针 AUROC ≈ 0.96 恒定，但转向向量范数 2.12→14.26 非线性增长、验证净增益 +13（L16）→ +46（L20），L16 因与 PC1 对齐近零而失败 → 验证不能约化为内部探测，干预层选择由机制（计算位点）而非可读性决定。【论文实验已支持】

### 6.5 综合判断与未决问题

**多项证据共同支持的机制**：

1. 高层行为由低维方向介导，且不同行为方向之间重叠可观（Arditi + NEEDLE 测量 + SAKIKO 通道余弦三方一致）；
2. 选择性干预优于全局干预（BLINDBIAS 门控 5.25%、NEEDLE 中后层编辑、SAKIKO Router 门控防六倍附带损伤）；
3. 聚合指标会系统性高估干预效果（SAKIKO 直接实证 + NEEDLE 的 Safety Δ 消融侧面印证）。

**仍属推测的部分**【阅读者推测】：BLINDBIAS 的「重建信号质量 → 攻击力」映射（PPL 7.07 vs 真分布 3.17 的差距如何转化为 3.03 vs 4.06 的 Harm 差距）尚缺理论刻画；NEEDLE 的 rank-4 拒绝子空间在更大模型/更复杂后门上是否仍充分未知；SAKIKO 的十条件门控阈值（如 CI 不跨零）在通道错误率极低时的统计功效未讨论。

**适用条件与失效条件**：BLINDBIAS 在对齐深、拒绝鲁棒的端点收益缩水（GLM-5 SORRY 落后 FlipAttack）；NEEDLE 对「后门目标 ≈ 拒绝」的攻击存在几何性残差（6.5–15.5%）；SAKIKO 审计的是单通道线性加性干预，对非线性/多通道组合干预的扩展未验证——它自己也通过「激活 vs logit 平移无稳定排序」的声明划定了边界。

## 七、必要知识反推

假设让一个零基础的人分别复现这三篇工作，他最少必须掌握：

### 7.1 领域知识层

- **LLM 解码机制**：temperature/top-p 采样、next-token 分布、logits 与 logprobs 的关系——不理解就无法意识到「采样接口其实是在泄露分布信息」（BLINDBIAS 组件一的前提）；
- **对齐的浅层性**：安全训练集中于响应前缀的经验事实——不知道这一点就不会理解为什么中途重新激活控制有效；
- **激活空间几何**：行为方向、拒绝方向、子空间与投影——这是 NEEDLE 全部设计的语言；
- **后门攻击威胁模型**：BadNet/Sleeper 式数据投毒、targeted refusal 与 code injection 的区别——决定了配对估计等细节设计；
- **工具使用 Agent 的动作空间**：When2Call 的 4 动作空间（含 cannot_answer、tool_call 等）、执行前决策错误的含义——SAKIKO 的「通道」概念建立于此。

### 7.2 方法论知识层

- **贝叶斯平滑**：Dirichlet 先验、共轭更新——K = 50 采样重建的统计根基；
- **线性代数**：正交投影、正交补、SVD、秩一更新——NEEDLE 的式 6 与岭回归校正全部是投影代数；
- **统计推断**：bootstrap CI、McNemar 检验、add-one Monte Carlo 显著性、预注册思想——SAKIKO 的裁决语言；
- **谱系文献**：受控解码/BiasNet（攻击）、拒绝方向与 locate-then-edit（防御）、activation steering 与探针方法（审计）——知道前人做到哪，才能定位增量。

### 7.3 工程知识层

- **API 成本核算与摊销**：投机解码结构、软门控阈值调参（τ/T/s_min/warm-up）——没有成本工程，攻击只在论文里可行；
- **本地风险模型训练**：冻结骨干 + 分类头、40 条缓存记录上的控制器训练；
- **后门模型制备**：LoRA 投毒微调、全参数变体、触发器设计——防御实验的「假想敌制造」；
- **可复现评估管线**：judge 模型打分协议（Gemini-3.5-Flash 1–5 量表）、Git LFS 管理产物、评估协议冻结的执行纪律。

### 7.4 知识融合的关键节点

三篇论文的化学反应都发生在「两个不相邻领域的交叉点」上：

- **BLINDBIAS**：采样统计 × 受控解码 × 投机解码——意识到「KL 稀疏性」后，三个原本无关的技术被拧成一根链条：稀疏 → 门控 → 摊销；
- **NEEDLE**：后门方向几何 × 拒绝子空间 × 闭式编辑——发现两个方向重叠 0.40–0.86 的那一刻，「直接消融」这条路被封死，「保护式投影」成为唯一解；
- **SAKIKO**：混淆矩阵 × 干预分解 × 临床试验统计——把医学的预注册纪律移植到 steering 评估，才有了「净增益 +55 但腐化 52/93 正确决策」这类反直觉发现。

## 八、论文中可以提取的通用性灵感

### 灵感一：稀疏干预原则——大杠杆集中在少数位点

**核心思想**：系统中大部分位置对干预不敏感、关键变化集中在少数位点时，选择性干预能用极小成本保留大部分效果。

**论文证据**：BLINDBIAS 的 KL 稀疏性观察 + 门控 5.25% active positions 保留 90% 攻击力；NEEDLE 只编辑 12–34 层，能力损失 0.21% vs 全层 4.05%；SAKIKO Router 门控防住六倍附带损伤。

**推广场景**：(1) 性能优化——先 profile 找热点再优化，而非全局重构；(2) 系统故障排查——用二分定位少数关键变更点；(3) 医学用药——靶向药 vs 全身化疗；(4) 组织变革——关键岗位换人 vs 全员重组；(5) 风控——聚焦高危交易而非全量人审。

### 灵感二：保护性约束编辑——改动要显式声明「不碰什么」

**核心思想**：修改一个系统时，把「必须保持不变的部分」显式编码为约束（投影到正交补），而不是期望修改「顺便」不伤及无辜。

**论文证据**：NEEDLE 的 u_ℓ = (I − RR^⊤)b 同时满足移除后门与保持拒绝两个正交承诺；消融显示去掉保护后 Safety Δ 恶化到 +14.01。

**推广场景**：(1) 代码重构——先写锁定行为的特征测试再动手；(2) 数据库迁移——用约束保证无关字段零漂移；(3) 政策调整——祖父条款保护存量权益；(4) 产品改版——A/B 中隔离非目标指标；(5) 基因编辑——脱靶效应的显式约束优化。

### 灵感三：目的地解析评估——别看总数，看每笔账的流向

**核心思想**：聚合指标（净增益）是多对一压缩，会系统性掩盖副作用的分布；把结果分解为互斥类别 + 双分母率，才能区分「真修复」与「横向漂移」。

**论文证据**：Phi-3.5 net +55 但 52/93 被触碰的正确决策被腐化（E2 = 55.9%）；46/153 错误退出漂向第三错误；净增益规则接受 9/9 评估单元 vs 完整合取 1/9。

**推广场景**：(1) A/B 测试——分群看迁移与流失，而非只看均值；(2) 医疗疗效——治愈/恶化/转它病三分类；(3) 教育干预——提分来自真掌握还是刷题技巧；(4) bug 修复验证——回归测试新破坏的用例数；(5) 客服外包——解决率相同但「错误解决」占比可能天差地别。

### 灵感四：采样恢复隐信号——有限观测 + 合理先验 = 可用信号

**核心思想**：即使接口不暴露内部参数，有限次随机观测加上合理先验（给未观测选项留概率质量），足以重建可用的控制/决策信号。

**论文证据**：Dirichlet 均匀先验把重建 PPL 从 11.85 降到 7.07、Harm 从 1.50 升到 3.03；同族小模型先验可迁移（Qwen3-1.7B 代理 3.90/2.83）。

**推广场景**：(1) 竞品 API 逆向——黑盒采样估计其生成分布；(2) 用户偏好研究——小样本选择实验 + 先验平滑；(3) 体育博彩/游戏 AI——对手策略的采样式建模；(4) 推荐系统冷启动——隐式反馈重建偏好。

### 灵感五：预注册防乐观——先锁标准，再看数据

**核心思想**：在看到结果前锁定统计标准（CI、显著性、门控条件），能拦住「点估计好看但区间跨零」的乐观错觉。

**论文证据**：Qwen3-4B TG_c 点估计 0.081 看似有效，但 CI [−0.048, 0.202] 跨零被 DECLINE；Qwen3.5-9B 因参考样本 29 < 30 在干预前被拦停。

**推广场景**：(1) 量化回测——先定义止损与样本量再看收益；(2) 科研评审——预注册报告制度；(3) 临床试验——期中分析的 alpha 消耗规则；(4) AI agent 评估——防「挑好的 run 截图」。

### 灵感六：攻防审闭环——机制发现的价值高于单点胜负

**核心思想**：攻击者的机制发现（浅对齐、KL 稀疏性）直接启示防御设计与审计标准；反过来，审计框架暴露的假修复（方向重叠导致误伤）划定了防御的边界。三方共享对同一底层结构（低维行为方向）的理解。

**论文证据**：BLINDBIAS 利用浅对齐 → NEEDLE 测量后门/拒绝方向重叠 0.40–0.86 → SAKIKO 证明不看目的地的评估会全部误判（9/9 vs 1/9）。

**推广场景**：(1) 网络安全——红队发现 → 加固 → 渗透测试验收的三段制；(2) 质量管理——FMEA（失效模式）→ 工艺约束 → 独立审计；(3) 药物研发——靶点发现 → 制剂设计 → III 期统计裁决；(4) 任何「改了之后怎么证明真的改好了」的场景。
