## 先说结论

2026 年 11 月，Canva 把自己的 AI 研究团队推向了台前。TWIML AI Podcast 第 784 期中，Canva AI 研究负责人 Stefano Corazza（音频开场自述身份，经 TWIML 节目页与 Canva 新闻室核实）描述了团队「大概是我人生中最忙的一个月」：图像基础模型 Craft、视觉语言模型 Brush 相继官宣，背后还有已投产的约一百个 AI 模型——Canva 在走一条「自己训模型、自己压推理成本、直接嵌入设计工作流」的路。这期对话真正值得记住的不是又一家公司做了文生图——Craft 首次提交就在 DesignArena 榜单排到第四（主持人陈述，嘉宾确认）——而是嘉宾给出的自研条件清单：独占数据加全栈自持，可以让参数少两个数量级的模型打平乃至超过大模型，同时再快一个数量级、便宜一个数量级（节目称约比最贵的前沿模型便宜 40 倍）。Corazza 另一个判断对行业更锋利：对创意任务，约一千亿参数已经够用，前沿参数竞赛在这个场景进入边际递减；接下来的杠杆，是把生成拆成「可编辑的结构」，并把迭代循环压到足够快。这套逻辑不只在 Canva 成立——按他的说法，数千员工规模甚至更小的公司都可以照此自查。

## 一个月四连发：设计工具公司为什么要自己训模型

节目的开场白把行业痛点钉得很准：图像生成模型已经足够好，但「用它做设计」仍像玩老虎机——咒语念对了可能中奖，想改结果就变成打地鼠。做梗图无所谓，当设计是职业时，这种游戏很快令人厌倦。Corazza 还坦承自己身上有过「硅谷偏见」：以为新技术只要单发足够完美就会被自然采纳，现实从不是这样，尤其当任务含创意成分。这也是开场引语的落点：「AI 会做到七成、八成，永远不会到十成」，所以必须围绕迭代来构建——最后一公里需要人留在环里，而且迭代要快、也要「好玩」。

时间线本身就是信号。Corazza 说，Canva Research（研究部门）上周正式亮相，官宣前十二小时图像基础模型 Craft 先行发布；接受采访当天「四十分钟前」，团队刚官宣视觉语言模型 Brush，这个月几乎每周都在发新模型。据 Canva 新闻室（本站查证），该部门现有 160 多名 AI 研究科学家与工程师，隶属约 400 人的 AI 团队；Corazza 于 2025 年 6 月加入，此前任 Roblox Studio 负责人、Adobe Fellow 与副总裁（增强现实方向），更早创办过被 Adobe 收购的动作捕捉公司 Mixamo。

主持人 Sam Charrington 把最锋利的问题摆上桌面：前沿实验室的 API 就在那里，开放权重模型也任取，Canva 自研到底是「有趣」还是「显然」？Corazza 的回答是两个条件：其一，拥有别人没有的独占数据——Canva 十几年的设计资产；其二，把模型深度垂直整合进自家技术栈，会带来性能与成本的巨大红利，他明确说这适用于其他「数千员工甚至更小」的公司。核心账目是：有数据时，参数少两个数量级的模型经微调与强化学习可以打平甚至超过大模型，而更小的模型天然更快更便宜——目前大约比最贵的前沿模型便宜 40 倍（节目称约）。选型也不教条：Craft 从零训练，因为要解锁的突破不在既有模型里；Brush 则在开放权重模型之上搭建——按任务选底座。他还补了一个生态观察：图像生成的头部模型如今多为开放权重，而视频生态约四个月前因几家公司开放权重引发多米诺效应、逼同行跟进，AI 视频每秒成本随之暴跌——两个生态几乎「上下颠倒」，他说这值得单独做一期节目。

## 场景图先行：把设计从「抽卡」改成「改结构」

Craft 的核心技术不是更大的扩散模型，而是拆解生成流程。嘉宾描述了三步：先把输入与提示词「放大」到最强；再转成完全结构化的场景图（scene graph）——仍是文本形式，但包含包围盒、相对位置等全部细节；最后一步才由从零训练的扩散模型渲染像素。这样编辑就发生在像素生成之前：LLM 可以在版式阶段介入，修改是非破坏性的，不再像「烘焙—展示—推倒重来」那样每轮都丢信息。主持人补充说，他在此前与高通（Qualcomm）研究者的对话中讨论过这种「两阶段生成」，但据他所知目前还没有流行的开放权重版本。

结构化中间层还催生新工作流：让 AI「先出十个版式方案」，此时不必生成任何像素，人确认后再统一渲染。同一条路线上，Canva 年初发布了 Magic Layers，把平面图拆解成图层与元素供精细控制——嘉宾透露，Magic Layers 处理的大多数图片其实来自 Canva 之外：用户在别处生成，回 Canva 编辑。他的总结是：过去两年创意人向 AI 要的就是两样东西——一致性与控制；「我们不想提供老虎机：生成二十次也许碰上好的。我们要让投入的时间可控、结果可预期。」

一个出乎团队意料的发现是扩散模型的「胃口」：参数超过一定规模后，它能吃下极详细的场景描述。过去六个月 Craft 的场景描述显著变长，长到没有人愿意逐行阅读（除非可视化编辑）；而且场景生成与扩散模型两端要互相校准——既不过度生成描述，也不欠训练渲染端，让二者互为理想的输入与输出。

## 第四名的意外、卡通翻车与千亿参数够用论

质量证据方面，主持人称 Craft 当时在 DesignArena 排名第四（转写原话「one of the number four」疑为 at number four），Corazza 确认这是首次提交，「连我们自己都有点意外」，并把成绩归因于十年设计数据的收割（含用户授权与外购授权数据）、数百次实验与多项突破的叠加。训练数据刻意求多样：图库、合成数据、用户生成内容，加上 Canva 自创或授权的数百万份设计——因为「AI 味」（AI slop）式的同质化正是要对抗的东西，这也呼应 Canva 服务每个市场、每种语言的定位。

边界案例更值得细看。模型在人像与自然风光上表现很好，卡通类却进不了前三——主持人指出这很反直觉：人像似乎用不上规划层，卡通才更依赖场景生成。Corazza 的归因是：人像最忌「AI 皮肤感」，团队为写实下了大功夫，这份努力「渗漏」到了卡通侧，产出偏写实、偏 3D。好消息是这属于模型「口味」问题：微调加强化学习即可纠正，不必重训——而且这个问题是在 Arena 上遇到不同的设计师人群才暴露的，内部评测没能提前发现。

规模判断则直接挑战 Scaling 叙事。他说 LLM 军备竞赛已到数十万亿甚至更高的参数量，但创意任务「约一千亿参数已经算大」，只要数据与后训练得当就能成事；视频理解或许需要略多，其余任务千亿以下「已经能创造奇迹」。反过来，用最贵的前沿模型做场景描述，经济学不成立——「一张图大约一美元」（节目称）。他还提到 MiniMax H3（此处转写含糊，节目页资源列表可佐证）等视频模型同样在用 LLM 生成结构化输入。基准与评测是另一块空白：现有基准大多只测「单次生成」，而设计编辑不等于图像编辑——行业至今没有公认的「编辑一份设计」基准，公开的 PresentBench（约 200 个幻灯片任务示例，节目引用）测的也还是生成。Canva 内部用精细 rubric（可读性、构图等评分项）配合视觉语言模型做裁判，嘉宾称「已经相当可靠」，但前提是人类先说清什么是好设计——人讲不明白，VLM 就评不了；人评与竞技场仍是终极测试。

## 速度就是质量：推理成本的雪崩与全栈自持的门槛

Brush 被嘉宾定义为「视觉语言模型，但本质是设计 agent」：它理解多图层、异构元素（矢量、位图、字体文本）的 composition，能接受「让它更 Gen Z」这类连设计师都难接住的高层指令，能产出三十页幻灯片并保持品牌一致。造这个 agent 最难的不是模型而是 harness（模型与工具之间的执行框架）——已经是第三代，经验是把它做薄、做简，让 LLM 自己写代码调用设计工具、「自由奔跑」，某种程度上是在「删掉人类预设」。它写的就是常规代码与 API 调用；关键经验是让操作方式贴合 LLM 训练语料中最多见的形态，顺着既有数据的「沟槽」走，而不是教模型一套分布外的私有语言。

这里出现了全期最重要的机制判断：一年前 LLM 还是「盲发单发」——生成一次、对结果无知；现在模型能看见自己的产出并迭代。「循环越快，一切越有效」：LLM 可以在人看到之前先自己迭代十次——过去每次迭代要一分钟，根本不可行。所以速度不是锦上添花，而是质量杠杆。嘉宾引用游戏开发的一条行规——超过十秒的等待完全不可接受：先锋用户愿意为「魔法时刻」等一分钟，日常生产不行。

成本侧的证据同样具体。Canva 多数用户是免费用户（学生、非营利组织），推理成本直接决定 AI 可及性；「一个月能挤出十倍性能，说明行业还在极早期」，团队两周优化出五倍是日常；720p AI 视频每秒生成成本在一年多里下降了两个数量级（从约半美元到低于一美分，节目称），他预计还会再降一个数量级，到每张图或每秒视频 0.1 美分时将触发又一次普惠式突破。他拿存储作类比：不会便宜到像 Dropbox 那样让人失去计价感知，但方向类似。前提是全栈自持：自托管、拿到权重，从 GPU 层、内核、推理步数、蒸馏到批处理与缓存逐层挤压收益。他也观察到旧金山冒出「一打」推理优化创业公司，因为「帮你省十倍」的价值主张最好卖；为显卡优化了几十年的图形工程师，与云弹性、AI 模型知识跨学科组合，正在交付奇迹。蒸馏则是常规操作：Craft Fast 与 Craft Ultra Fast 将在几周内推出（嘉宾称），把速度与质量的档位交给开发者与设计师自选。

## 当 agent 成为新用户：API、MCP 与为机器而设计

Craft 已通过 Canva Connect API 与 Canva MCP 开放——「MCP 昨天刚上线」（相对录制日），而 Canva 的 MCP 用量在「暴涨」。此前 Magic Layers 与 Lucid Origin（图像生成公司 Leonardo.AI 的模型，Canva 于 2024 年收购该公司）已有 API，但嘉宾称这次的关注度高得多。需求来自两端：企业客户——Canva 增长最快的业务，同比三位数增长（节目称）——想用 API 自建工作流，「现在人人都能 vibe code」放大了这类需求；另一端是从 Claude 或 ChatGPT 里通过 MCP 调用 Canva 能力的 agent：「你要生成图片？我可以用 Canva」，再回到 Canva 精修。

嘉宾判断这是行业性的：公司们突然发现自己在「既为人、也为 agent 构建」，agent 用量增长「不可避免」。而 agent 需要的东西与人不同：更结构化的文档、免订阅即可预览、低摩擦的自助试用——因为「很多时候是 agent 而不是人来选方案」。他描绘的闭环是：agent 以极低门槛启动，自建原型、自测可用，再回去请人拍板，批准后才进入规模化。

研究组织自身也在被这套速度重塑。Corazza 说规划周期从一年缩到「一个月都很模糊」；具体模型组合每几个月换一轮，他给团队的要求是「别对抗不断变化的生态，拥抱它」——使命与愿景不变，项目全换；「一年前，我们今天上线的这些模型一个都还没立项」，按此逻辑，一年后上线的模型今天大概率也没开始做。他甚至从带两个小孩的经验里得出类比：预训练像让孩子尽可能多地积累词汇，但词汇量与「成为脱口秀演员的表达风格」无关——早期的广度暴露决定后期的风格空间，训练模型与养育孩子互为镜像。

对行业而言，这场对话把图像生成的竞争焦点从「谁的单次生成更惊艳」挪到了「谁的迭代循环更快、结构更可编辑、单位成本更低」。老虎机式的赌运气正在被工程化流水线替代，而赌注押在独占数据与全栈自持上。对读者，可以盯三个指标：设计编辑类基准是否出现（今天的基准仍以单发生成为主）、开放权重的两阶段生成模型是否出现（主持人称目前没有流行的版本）、以及「为 agent 设计」的功能——免登录预览、自助试用——是否会成为 SaaS 标配。三者任一落地，都意味着这场从 Canva 出发的实验已经变成行业的方向。
