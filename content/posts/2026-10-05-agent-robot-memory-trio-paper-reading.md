## 一、论文背景：决策信息为什么要「跨执行体」流动

把三篇论文放在一起读，需要先建立一个共同视角：**一个复杂系统里往往有很多个相互独立的执行体，而正确的决策所需要的信息，恰恰不都在单个执行体手里**。

**DMM 面对的多智能体路径规划（MAPF）**。MAPF 的任务是在共享环境中为大量智能体（仓库机器人、游戏单位、自动驾驶车队）找一组互不碰撞的路径——即使在对环境做了大幅简化的图表示下，求最优解也是 NP 难的。经典解法是一条中央控制器收集全部信息统一规划（如 LaCAM），但仓库断网、灾区通信中断、矿井覆盖巡查等场景根本没有可靠的中央设施，于是研究重心转向**去中心化 MAPF**：每个智能体只看得到局部观测，自己决定下一步动作。学习派方法（从早期的 GNN 通信策略到 MAPF-GPT 这样的模仿学习基础模型）已经能在大量实例上接近专家水平，但它们共享一个未被正视的结构性缺陷——**每个智能体独立采样自己的随机动作**。走廊里两个对穿的机器人，各自的局部策略都学得没错（「前进」和「让行」都合理），但独立掷骰子会把「局部有效」的选择重组成「联合不可行」的动作：四种组合里两种是碰撞或死锁。

**APPL 面对的少示范机器人模仿学习**。机器人要从少量人类示范学会操作技能，主流载体是 Diffusion Policy——把动作生成建模成去噪扩散过程，天然适合示范数据里的多模态动作分布。但它要同时跨越两道泛化鸿沟：**组合泛化**（把已学技能重新组合解新任务）与**技能泛化**（单个技能在没见过的物体位移、新初始状态下仍然可用）。已有的分层方案是：上层用 LLM 读技能的名称/指令/符号描述来选技能，下层是各技能的策略网络。问题出在两层之间的信息丢失——组合层看到的只是技能的「名字和说明书」，完全看不到策略训练时的结构信息（这个策略到底在什么坐标系下学、依赖哪些变量、泛化到什么范围），于是经常选错版本、在超范围状态下强行调用。

**HIDE/SEEK 面对的部分可观测机器人操作**。机械臂连续操作时，很多决定成败的变量在当前帧里根本看不见：已经按了几次按钮、被遮挡的物体是什么、多步任务执行到了第几步。这类**隐藏任务状态**必须从交互历史中恢复，可当前机器人学习的评测体系（RLBench 等）主要按任务种类与长度组织，大量「决策点上视觉等价、隐状态不同」的情形从未被系统考察；同时 VLA 大模型（π0.5、GR00T 等）虽然在标准任务上得分可观，却普遍缺乏维护这类状态的能力。

三篇论文的共同底色由此浮现：**决策所需的信息必须跨越执行体的边界——从邻居智能体传到我（DMM）、从策略训练结构传给运行时选择器（APPL）、从交互历史传到当前决策（HIDE/SEEK）**。而三条主流路线分别卡在「传的是已定动作而非形成中的意图」「传的是技能名字而非适用范围」「干脆没机制保存历史状态」。

## 二、论文定位和关联工作

| 谱系 | 代表工作 | 核心思想 | 与 DMM 的关系 |
|---|---|---|---|
| 学习型 MAPF 基础模型 | [MAPF-GPT](https://arxiv.org/abs/2409.00134)（2024，Skrynnik 等，同团队前作） | 纯模仿学习 + Transformer，无通信无启发式 | DMM 直接继承其 encoder-decoder 骨架；LC-MAPF-3M 基线与其共享同构网络、同数据、同参数量，构成精炼机制的受控对照 |

| 经典求解器 | [LaCAM](https://arxiv.org/abs/2211.13432)（Okumura，AAAI 2023）、MAPF-LNS2 | 惰性约束加入搜索 / 大邻域搜索 | MovingAI 上的对比对象；提供专家轨迹与 SoC 参照（LaCAM*） |

### APPL：结构先验注入策略的谱系

| 谱系 | 代表工作 | 核心思想 | 与 APPL 的关系 |
|---|---|---|---|
| 扩散策略基座 | [Diffusion Policy](https://arxiv.org/abs/2303.04137)（Columbia + TRI，RSS 2023） | 动作生成 = 条件去噪扩散 | APPL 每个技能的训练载体；vanilla 版即基线 B0 |
| 对称性/等变先验 | [Equivariant Diffusion Policy](https://arxiv.org/abs/2407.01812)（CoRL 2024）及 [A Practical Guide for Incorporating Symmetry in DP](https://arxiv.org/abs/2505.08730)（NeurIPS 2025） | 用 SO(2)/SE(3) 等变网络或相对轨迹表示注入几何对称性 | 「先验塑造训练」路线的代表作；APPL 的差异：先验不由人手定为单一对称群，而是由 LLM 按技能提出多个互补候选，且同一先验要兼任运行时接口 |
| LLM 组合技能 | SayCan、Skillformer 等分层框架 | LLM 读技能描述选技能 | APPL 的 runtime agent 同属此类；差异：接口四元组（先验描述/交接条件/训练支撑/验证证据）让「说明书」与「能力范围」同源 |
| VLA 大模型 | [π0.5](https://arxiv.org/abs/2504.16054)（Physical Intelligence，2025） | 异构数据协同训练的通用操作策略 | Exp.2 中被微调后作为 Agent+VLA 基线（32.5%/70.0%/6/16），全面落后于 APPL |

定位结论：APPL 不发明新先验，而是发明**先验的「双角色」制度**——此前的等变线只做 coverage（训练时注入）、LLM 组合线只做 selection（运行时描述），两条线各自为政且信息不通；APPL 用「同一先验、两种实现」把两个阶段焊在同一条信息链上。

### HIDE/SEEK：机器人记忆评测与架构的谱系

| 谱系 | 代表工作 | 核心思想 | 与 HIDE/SEEK 的关系 |
|---|---|---|---|
| 多视角操作策略 | [RVT-2](https://arxiv.org/abs/2406.08545)（NVIDIA，2024） | 虚拟视角 + coarse-to-fine 两阶段 | SEEK 的策略骨架沿用该范式（coarse-to-fine 多视角）；RVT/RVT-2 为基线（35.7%/42.9%） |

## 三、问题定义：三个本质问题的抽象

### DMM：独立采样的联合分布不可表达问题

**具体场景**：走廊对穿。两个智能体、各两个合理动作（go/wait），联合层面只有 2 种有效组合（一进一让），独立采样却给 (g,g)/(w,w) 各 1/4 概率。

**抽象与形式化**：给定联合策略以乘积执行器 Π_u π_u(a_u|·) 近似，定义**去中心化分解 gap**：当条件总相关 TC(A|X) > 0 时，最优乘积执行器相对真实联合分布的 KL 误差存在下界 = TC(A|X) + Σ_u I(A_u; X_{−u}|X_u) > 0。这是一个信息论式的「不可消除误差」声明：**无论各智能体的边际策略学得多好、无论通信内容多丰富，只要最终动作是独立采样的，误差就有非零下界**。

**精妙之处**：它把「多智能体不协调」从工程问题（网络延迟、算法不好）提升为表征问题（乘积分布无法表达残余相关性），于是解法必然是改变采样结构本身，而不是继续加宽通信带宽——通信只丰富条件信息，固定通信记录后残余的相关性仍无法由乘积形式表达。类比：两个人隔墙各掷骰子，哪怕事先通读了对方的全部资料，掷出来的点数仍然独立；要相关，必须**看得见对方正在掷的结果**。

### APPL：能力范围与适用假设的同源问题

**具体场景**：LLM 要在多个功能相近的策略（同一技能的四种不同先验实现）里选一个，但接口上只有技能名与指令，没有任何「这个版本在什么状态下可用」的信息。

**抽象**：每个策略 π 有真实泛化范围 W(π)（训练时被先验塑造），组合层推断适用区域 A（运行时从描述读出）。组合泛化要求 A ≈ W。定义运行时接口 I = (d, h, s, v)：先验描述 d、交接条件 h、训练支撑 s、验证证据 v。**问题变成：如何保证描述 d 与塑造 W(π) 的训练结构同源，使 A 忠实（faithful）且信息充分（informative）**。

**精妙之处**：此前没有人把「训练时的归纳偏置」与「运行时的说明书」当作同一信息的两种编码。APPL 的等式是：**先验 →（训练实现）→ W(π)；先验 →（语言实现）→ A；同源 ⇒ A ≈ W**。类比：药品的说明书应当由做临床试验的同一个团队来写——疗效边界（W）与适应症描述（A）出自同一份证据，才不会误导处方。

### HIDE/SEEK：按隐藏变量类型组织记忆的问题

**具体场景**：机械臂重复按同一按钮 N 次，中途每一帧的画面几乎一样——第 3 次与第 7 次的观测视觉等价，但正确的下一个动作不同。

**抽象**：部分可观测操作中存在**隐藏任务状态** z_t（已按次数 / 被遮挡物体身份 / 执行到第几步），当前观测 o_t 不可推断，须从交互历史恢复：z_t = g(o_{1:t}, a_{1:t-1})。现有基准按任务长度与种类组织，无法区分「长但马尔可夫」与「短但需记忆」；HIDE 按决策所需隐藏变量的**类型**（RC/HSR/EPT）组织 15 任务 / 375 变体。**问题变成：给定类型化的隐藏状态，设计记忆机制使策略在每类上同时领先，且不牺牲标准任务性能**。

**精妙之处**：观测混叠（observational aliasing）在 RL 里是老概念，但把「哪类混叠决定哪类记忆」做成类型学，相当于给记忆系统开了成分化验单：滑窗治「刚发生了什么」、检索治「离开视野的证据」、计数器治「重复中的进度」——对症下药而非一股脑堆注意力。

## 四、问题解法：三套机制拆解

### DMM：意图迭代去噪 + 两阶段训练

**核心类比**：扩散模型把「从噪声逐步精炼到干净样本」的过程搬进离散动作空间——但精炼的对象不是最终动作，而是「意图」。

机制分步：

1. **意图向量**：每个智能体 u 维护均值中心化 log 空间的意图向量 z_u，初始独立 ~Dirichlet(1)（各智能体初始意图统计独立，这正是「噪声起点」）。
2. **跨 K 轮精炼**：每轮 r，智能体广播「消息特征 + 当前意图」，从邻域解码出动作 logits、采样离散投票 y_r，以阻尼更新 z_r = (1−δ)·z_{r−1} + δ·e(y_r) 累积进意图；最终 a_u = argmax z_K。
3. **关键设计**：**被精炼的意图本身就是通信信号**——邻居能在彼此提交前条件化于对方的「正在形成的随机选择」，意图轨迹经通信耦合后收敛到协调的联合结果（对应专家分布的有效模态之一），联合分布从乘积形式中解放出来，直接消解 gap 的第一项。
4. **训练两阶段**：先专家轨迹模仿预训练（逐轮监督投票 + 双重 teacher forcing，退火但保留地板 β₀ = β_r = 0.8——这是学到「相关精炼」的必要条件，β = 0 时退化回 50.1%）；再上 **MICPO**，一个免 critic 的组相对 RL：每步共享相同初始意图的 G = 24 条匹配轨迹组成轨迹组，组内归一化优势、按 agent×轮次计算重要性比率、KL 锚定模仿参考策略。
5. **规模工程**：观测相关计算移出精炼环、GPU 常驻执行、目标跳过推理、并行 CS-PIBT 分组，使每步成本近恒定。

输入：各智能体局部观测 + 邻域消息；输出：提交前的协调动作。整个精炼环内没有中央节点——去中心化执行的前提保住了。

### APPL：先验双角色 + 冻结库 + LLM 运行时

**核心类比**：先验像「同一个人既当教练又当解说员」——训练时它塑造打法（coverage），比赛时它向场外指导解释这套打法怕什么（selection）。

机制分步：

1. **离线 construction agent**（Exp.1 为 GPT-6 Astra，Exp.2 全角色为 GPT-5.6 Sol）把完整示范切成带重叠交接段的技能。
2. **每技能提出多个互补结构先验**：如物体坐标系（「抓取只依赖夹爪相对物体位姿」）、目标系、TCP 局部修正；每个先验训练一条独立 Diffusion Policy——先验经表示/动作坐标系/辅助损失落地为训练目标（式 2），塑造 W(π)。
3. **同一先验写成语言**，进入运行时接口 I = (d, h, s, v)；从示范入口态验证每条策略（跑 1.5× 段长查退出条件），据反馈增补第 4 条策略并写使用注记——验证报告成为 v 的证据。
4. **在线 runtime agent（LLM）读接口**选策略、实例化类型化参数/时长/停止条件并组合（式 7）；**库与 agent 均冻结**，全部智能发生在离线构建期。

两个训练修订案例直接展示先验如何改变外推结构：drawer/N=2，A4 在柜体系坐标中减去 4·(p_handle − p_hand) 项，让网络只预测可外推残差，OOD 从 75.00% 提到 100.00%；assembly/N=5，A4 在环提起前衰减与目标相关的特征以消除「螺母-目标位置相关」捷径，41.25% → 93.75%。

### HIDE/SEEK：三路互补记忆 + 类型化基准

**HIDE 基准**：基于 RLBench 构造 15 任务 / 375 变体，三类各 5 任务（RC/HSR/EPT），每任务 100 训练演示 / 25 测试回合，自动关键帧分段标注。

**SEEK 框架**：三路记忆经 memory attention 融入 coarse-to-fine 多视角策略：

| 记忆 | 内容 | 机制 | 对应隐藏状态 |
|---|---|---|---|
| WCM 滑窗上下文记忆 | 最近 K = 6 条交互记忆 | 直接保留 | 「刚发生了什么」（近期 RC/HSR） |
| PAM 持久锚点记忆 | 已离开滑窗的历史 | 对历史按 cos 相似度检索最相似参考 a_t = argmax cos(k_t, k_i) | 被遮挡前的物体位置等 HSR 证据 |
| SCM 阶段计数记忆 | 离散计数器 + 可学习 stage embedding | 在预测的阶段边界推进 | 重复动作中的执行进度（EPT） |

训练用 L = L_act + λ·L_stage（动作损失 + 阶段预测损失），两阶段进行：先 LoRA 适配视觉骨干、再冻结骨干训记忆。关键约束：**读预算有界**（每视角 ≤ K + 1 anchor + 1 stage），且视觉历史保留空间特征图使检索提供局部化而非全局信息。

## 六、效果优势的根源解释

### 6.1 根源机制与证据链

**DMM 的因果链**：

1. baseline 为何曾经有效：MAPF-GPT/LC-MAPF 等模仿策略把「给定观测该做什么」的边际分布学得足够好，在低冲突密度场景成功率很高——这掩盖了采样结构问题。
2. 根本局限（结构性，非学习性）：即使各智能体边际分布完全正确，独立采样的乘积分布也给 (g,g)/(w,w) 各 1/4 概率（gap 下界 log 2 > 0）；通信只丰富条件信息，固定通信记录后残余相关性仍无法由乘积分布表达。【论文实验已支持：走廊 ~50% ≈ 均匀分布】
3. 根本性改变：DMM 把「正在形成的随机选择」（意图 + 离散投票）放进通信内容 → 邻居能在彼此提交前条件化于对方的样本 → 意图轨迹经通信耦合收敛到协调联合结果 → 联合分布从乘积形式中解放，直接消解 gap 第一项。【论文实验已支持：50%→94.8%；反事实：β = 0 时退化回 50.1%，说明须保留 teacher-forcing 地板才能学到相关精炼】
4. 指标提升是冲突率下降的直接后果：POGEMA/MovingAI 更高成功率、更低 SoC、更高覆盖。【论文实验已支持】
5. 规模机制：意图精炼将观测相关计算移出精炼环 + GPU 常驻 + 目标跳过 + 并行 CS-PIBT 分组 → 每步成本近恒定（8× 智能体仅 1.73× 步时长）。【论文实验已支持；阅读者推测：该常数步成本是「精炼环内只有轻量意图更新、重计算已在环外完成」的架构必然，而非调参巧合】

**APPL 的因果链**：

1. 根本局限：组合层只见符号描述 → 推断的适用区域 A 与真实 W(π) 脱节 → 选错版本、超范围调用。VLA 基线走另一极端——端到端把选择与执行压进一个网络，组合信息（32.5% vs 50.0%）与技能泛化两头落空。【论文实验已支持】
2. 根本性改变：同一先验两种实现 → A 与 W(π) 同源（faithful & informative）→ runtime agent 据先验/交接/支撑选对策略版本。两个修订案例展示机制：drawer 减去 4·(p_handle−p_hand) 项 → 网络只预测可外推残差（OOD 75.00%→100.00%）；assembly 衰减目标相关特征 → 消除「螺母-目标位置相关」捷径（41.25%→93.75%）。【论文实验已支持】
3. 决定性反事实：**同一冻结策略库**仅隐藏接口信息，成功率 50.0%→20.0%、组合 8/16→2/16——性能差完全由选择信息造成，非策略容量。这是全篇最硬的证据。【论文实验已支持】
4. 多先验并行 + 验证：每技能保留多实现使不同归纳偏置覆盖不同情形；验证报告为选择提供证据——但作者诚实指出示范态验证在位移下会误导排序（covered peg 8/8→1/8 案例），是机制的已知边界。【论文实验已支持；标注为论文自述局限】

**HIDE/SEEK 的因果链**：

1. 根本局限：HIDE 的决策点上观测视觉等价但隐状态不同（观测混叠）→ 无记忆/短记忆策略原理上无法区分；SAM2Act+ 类记忆偏重场景空间信息，不维护计数（MME 在 RC 仅 2.4%）。【论文实验已支持】
2. 根本性改变：按三类隐状态分别供给信息——WCM 给近期事件、PAM 检索已离开窗口的历史证据（被遮挡前的物体位置）、SCM 用显式计数器解决「重复动作后场景回到相似外观」的进度判断（纯视觉相似度无法区分中间重复与最后一次）→ 三者读预算有界且互补 → 三类任务同时领先。【论文实验已支持：分类差距 +15.2/+9.6/+7.2；消融中视觉特征记忆对 RC +30.4pp】
3. 不掉点的机制：视觉历史保留空间特征图使检索提供局部化而非全局信息 + coarse-to-fine 骨架本身强 → RLBench 84.7% 与复现 SAM2Act 84.1% 持平。【论文实验已支持】

### 6.3 综合判断与未决问题

**多研究共同支持的机制**：(1) 结构先验注入训练能提升少示范泛化——APPL 与等变扩散策略两条独立路线同结论；(2) 显式记忆机制对部分可观测任务必要——SEEK 与 SAM2Act+ 在各自基准上互相印证；(3) 通信丰富条件信息不等于消除协调缺口——MAGAT 的通信路线与 DMM 的 gap 定理互为正反面。

**仍属推测的机制**：DMM 百万智能体的常数步成本是否在任意拓扑（非迷宫）下保持，论文只测了迷宫域（阅读者推测为架构性质但证据单一）；APPL 的先验由 LLM 提出，提出质量对先验「忠实性」的影响未系统消融——示范态验证会误导排序（covered peg 8/8→1/8）提示该环节有真实风险；SEEK 的三路记忆在三类任务外的普适性（如需语义记忆的任务）未验证。

**优势成立条件与可能失效条件**：DMM 需要 K 轮通信带宽与邻域连通性，通信受限或时延高的场景须重新验证；APPL 依赖技能库与任务族的结构同质性，全新动力学技能无先验可提时退化；SEEK 的 SCM 假设阶段边界可预测，连续无明确阶段的任务（如力度控制）中计数器机制失效。

## 七、必要知识反推

假设让一个完全没有背景的人重做这三项工作，最少必须掌握：

**领域知识层**：

- MAPF 的问题形式（图、碰撞约束、SoC 指标）与去中心化设定下「策略而非规划」的目标差——不懂这个就无法理解为什么 gap 定理针对的是执行器结构而非算法精度。
- 扩散去噪的迭代精炼直觉（从噪声到样本的逐步收敛）——DMM 把它迁移到离散意图空间，需要理解「每轮采样 + 阻尼累积」如何对应「去噪步」。
- 机器人操作中的坐标系变换（世界系/物体系/TCP）与常见结构不变量（抓取只依赖相对位姿）——不懂就无法理解 APPL 先验为什么能消除「绝对位置记忆」捷径。
- 部分可观测性与观测混叠——HIDE 的全部任务设计建立在这个概念上。

**方法论知识层**：

- 信息论基础：KL 散度、总相关（TC）、条件互信息——DMM 定理的表述语言。
- 模仿学习与组相对 RL（GRPO 式组内优势）——MICPO 的直接前置；teacher forcing 与调度退火的训练技巧。
- Diffusion Policy 的训练目标与表示选择如何影响外推——APPL 式 2 的落点。
- LLM 作为 runtime agent 的接口设计与 prompt 工程；基准构造方法论（变体设计、自动标注、隐藏测试划分）。

**工程知识层**：

- GPU 常驻执行、批并行、通信拓扑管理——百万智能体实验的使能技术（峰值 49.07 GiB/GPU、0.745 µs/agent/step 是工程产物）。
- RLBench/ManiSkill/MetaWorld 仿真栈、关键帧分段、LoRA 微调、真机部署（Franka + D455）。

**知识融合的关键节点**：

1. **DMM 的创造性节点**是「扩散去噪 × 多智能体通信」的嫁接——发现「迭代精炼的中间状态天然是可通信信号」，这一步既需要去噪的形式知识，又需要对「独立采样 vs 协调采样」的信息论敏锐。
2. **APPL 的创造性节点**是「先验 = 训练目标 = 接口文档」的三位一体——把 ML 里久已存在的归纳偏置知识，翻译成 LLM 可消费的运行时信息；两个修订案例（残差化、特征衰减）是把抽象先验落成具体训练代码的工程直觉。
3. **HIDE/SEEK 的创造性节点**是「隐藏状态类型学 × 记忆架构对应表」——先做分类学再做系统设计，每类记忆的机制与一类混叠严格对齐；这种「先化验、后处方」的方法论本身是可迁移的。

## 八、论文中可以提取的通用性灵感

**灵感一：正在形成的决策本身就是最有价值的协调信号。**
核心思想：协调多个独立决策者的关键是交换「未定型的意图」而非「已提交的动作」——前者允许相互条件化，后者只能事后补救。
论文证据：DMM 走廊实验 50%→94.8%；反事实 β=0 退化回 50.1%（须学到「相关精炼」而非机械多轮）。
推广场景：多车路口协商（交换「我倾向先走」的软意图而非确定轨迹）；多 agent 工作流编排中各子 agent 先广播草稿计划再定稿；分布式数据库的乐观并发控制（提交前暴露写意图）；乐团/团队即兴协作中的「示意-响应」节拍。

**灵感二：能力的塑造与能力的陈述应当同源。**
核心思想：任何「库 + 选择器」架构（技能库/工具库/模型库）里，条目的说明书必须由塑造其能力的同一结构生成，否则选择器必然误判适用范围。
论文证据：同一冻结策略库仅隐藏接口 → 50.0%→20.0%、组合 8/16→2/16；恢复部分接口信息逐级回升（20.0%→45.0%→50.0%）。
推广场景：API 文档由实现代码的约束自动生成（含前置/后置条件）；MCP 工具描述携带真实失败模式与适用域；微服务注册中心的健康度/能力自描述；招聘 JD 由岗位真实业务约束而非模板生成。

**灵感三：按「决策需要什么」而非「表面难度」来组织评测与记忆。**
核心思想：长不等于难——评测与系统设计都应按决策点上的信息缺口类型（本例：计数/证据/进度）分类，机制与缺口一一对应。
论文证据：HIDE 三类任务对应三路记忆，分类差距 +15.2/+9.6/+7.2；MME 偏重场景记忆在 RC 仅 2.4%；记忆长度消融 0/2/4/6 → 46.7%/53.7%/57.2%/62.9%。
推广场景：对话系统按「需记住的事实/需追踪的意图演变/需计数的重复行为」分类设计状态；工业质检按缺陷类型而非产线长度配置检测记忆；教育诊断按错误成因分类而非按分数；缓存系统按访问模式类型（时间/空间/计数局部性）分层。

**灵感四：结构性下界是方法迭代的指南针。**
核心思想：当能证明某误差存在信息论/复杂度下界时，正确的反应是改变结构（如采样方式）而非继续在原结构上加数据/参数。
论文证据：gap 下界 = TC(A|X) + Σ I(A_u; X_{−u}|X_u) > 0 直接指明「独立采样」是硬伤，DMM 的机制精确对准第一项。
推广场景：模型集成与蒸馏中的容量下界论证；联邦学习的通信轮数下界；分布式系统一致性协议的复杂度下界（FLP 式不可能性指导工程折衷）。

**灵感五：读预算有界的模块化记忆优于单一无限上下文。**
核心思想：给决策体配置多条廉价、专用、容量受控的记忆通道，比堆一个巨大统一上下文更稳（且不伤已有能力）。
论文证据：SEEK 每视角读预算 ≤ K+1 anchor + 1 stage，三路互补在 RLBench 上不掉点（84.7% vs 84.1%）；VLA 端到端大上下文路线在 HIDE 上 13%–26.4%。
推广场景：LLM agent 的分层记忆（工作记忆/情景检索/任务状态计数器）；数据库的冷热分层与物化视图；操作系统页面置换的多队列设计；个人知识管理中「日记 + 索引 + 里程碑」三分离。
