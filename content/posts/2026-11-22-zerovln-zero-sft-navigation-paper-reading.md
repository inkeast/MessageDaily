**一分钟版本**：ZeroVLN 让 VLM 大脑完全不经导航 SFT、只用自然语言工具调用指挥一个 34.8M 的流匹配动作专家，先靠特权规划器把大脑真实请求接地成轨迹来训练专家，再用轨迹级 RLOO 闭环联合优化双策略——同骨干同数据下全面碾压 SFT 基线，且大脑通用能力几乎无损（59.16% 对 59.47%）、权重位移仅 0.01497%。它把 R1-Zero 的"零 SFT 纯 RL"路线第一次完整带进了连续控制世界。

## 一、论文背景

视觉语言导航（VLN）要求智能体把语言指令、视觉观测与自身运动连接起来：听懂"出了房门上楼梯，在第二个平台停下"，然后把它变成一连串连续控制。VLN-CE（Continuous Environments）是其中最难的设定——智能体不在导航图（nav-graph）的预设节点间跳转，而是在连续空间里输出平面位移与航向增量，撞墙、卡死、绕路都是常态，任何一次决策失误都需要后续轮次来弥补。

VLN-CE 之难，难在三层叠加：其一，连续动作空间里没有"可走的边"这种归纳偏置，每一步位移都要自己负责避障；其二，长视野——一条 R2R 指令平均要走 10 米以上、跨多个房间，任何一轮的决策误差都会向后传播；其三，RxR 这类密集描述指令还要求精确的地标顺序跟随。这让"语义上大概正确"与"物理上可行"之间的鸿沟成为任务的中心矛盾，也解释了为什么分层架构（大脑管语义、专家管物理）成为共识。

当前主流做法是"慢-快"（slow-fast）分层：一个通用 VLM 当大脑负责语义决策，一个可学习的动作头（action expert）负责连续执行，两边各自在自己的时间尺度上运转——大脑每轮一次决策，动作专家在每轮内做多次快速循环。问题出在训练方式上——代表方法无一例外对 VLM 大脑做导航域 SFT：NaVILA 微调 VLM 直接输出数值运动命令；DualVLN 微调 VLM 预测像素目标交给连续动作专家；StreamVLN、NavFoM、Uni-NaVid、JanusVLN 等也都要把导航域监督灌进大脑。

论文开篇就给了这记重锤（图 1）：在 Qwen2.5-VL-7B 上跑 DualVLN 的官方适配流程，十二项通用视觉/空间基准里 CV-Bench-3D 掉 83.33 分、CV-Bench-2D 掉 75.97 分、EmbSpatialBench 掉 70.52 分、DA-2K 掉 34.86 分——导航技能学到了，通用大脑废了。这就是具身场景下的灾难性遗忘：导航域的窄分布监督把基座权重大幅拉偏，而具身产品的实际部署恰恰要求同一个大脑既能导航又能问答、描述场景、执行新任务。语言模型社区早已熟知这个现象（对齐税、能力挤占），但在具身场景里它被放大了：导航示范的格式（坐标、命令码）离通用预训练分布比聊天格式远得多，所需的分布重塑也就猛烈得多。

作者受 DeepSeek-R1-Zero 启发——推理能力可以不经 SFT、直接从基座模型通过 RL 涌现——提出一个对称的问题：**导航能力是否也能完全不碰大脑、通过交互学出来？** 这个问题在导航域比在推理域更难：推理任务（数学、代码）有天然的答案正确性判据，RL 的回报信号现成；导航的成功信号虽然也有（到没到目标），但要经过几十轮交互、几百个动作才揭晓，且连续控制的探索空间远比离散 token 采样复杂。此外 R1-Zero 只训一个策略，慢快框架还要回答"两个策略怎么联合更新"——单侧更新的失配问题（消融里 brain-only 跌破初始化）是这个领域的新坑。ZeroVLN 给出完整答案，并且是第一个同时做到这两点的慢-快 VLN 框架：

1. VLM 大脑零导航域 SFT——大脑从不在导航示范数据上做监督拟合，适配只发生在动作专家与 16 个可学习 query 上，大脑参数仅被 RL 的回报加权信号轻轻推动；
2. 慢快双策略闭环 agentic RL 联合优化——大脑的语义决策与动作专家的连续执行共享同一条轨迹级优势信号，在同一个优化步内共同进化。

这件事的工程含义很直接：具身智能体的经济学。一个 35B 大脑被导航 SFT 毁掉通用能力后，你无法在同一台机器人上复用它做问询、描述场景、执行其他任务；而 ZeroVLN 训完后大脑几乎是原装的——通用能力保留率 59.16% 对基座 59.47%，可以继续承接任何新任务的学习而不必从基座重新出发。换大脑（升级到下一代 VLM）时也只需重训 34.8M 的动作专家与轻量 RL，无需重跑大脑 SFT 的全量数据管线。再往深处看，这触及了具身智能的一个根本张力：**专业化（适配特定任务）与通用性（保留基础能力）在同一组权重上此消彼长**。此前社区用 LoRA、正则化、数据配比等手段缓和这个张力，ZeroVLN 提供的是第三条路——从训练范式的层面绕开它：不让任务适配发生在"拟合外部目标"的意义上，只让它发生在"强化已有行为"的意义上。

值得注意的时间点：这项工作出现在 agentic RL 基础设施成熟（GiGPO/PGPO/Flow-GRPO 等在 2025-2026 年密集落地）与 VLM 工具调用能力标准化（Qwen 系预训练即含 function calling）的交汇处。没有前者，闭环联合优化两个策略在工程上不可行；没有后者，语义接口无法复用大脑的原生能力。论文的 GitHub 仓库与 HuggingFace 权重同步放出，可复现性在同类工作中属于第一梯队。

再往前看一层研究脉络：VLN 社区 2024 年起就有两条暗线在靠近这条工作——一条是"减少对大脑的侵入"（LoRA 化、冻结大脑只训外挂），另一条是"RL 进 VLN"（VLN-R1、ETP-R1 等对规划层做 RL 微调）。前者保住了通用性但导航上限受限（外挂容量小），后者提升了性能但仍是 SFT 初始化之上的修补。ZeroVLN 把两条线拧在一起并推向极致：彻底零 SFT + 完整闭环 RL，用 41 页的篇幅、两个理论命题与十组实验证明这个极致位置是可达的。

## 二、定位与关联工作

把 ZeroVLN 放进 slow-fast 导航谱系，关键是看两个坐标：大脑与执行器之间的**接口形态**，以及**谁被训练、用什么信号训练**。

| 方法 | 接口 | 大脑是否 SFT | 动作执行器 | 数据量（R2R-CE SR） |
|---|---|---|---|---|
| NaVILA | 数值命令（turn left 45°） | 是 | 模拟器直接执行 | 34.4K 受控（46.5） |
| DualVLN | 像素目标（坐标） | 是 | flow-matching 专家 | 34.4K 受控（15.4） |
| StreamVLN | 慢快上下文建模 | 是（分段流式） | 内置 | ≥150K（56.4） |
| NavFoM | 具身导航基座 | 是 | 扩散/流专家 | ≥182K（56.2） |
| JanusVLN | 双隐式记忆 | 是 | 内置 | ≥169K（60.5） |
| Uni-NaVid | 视频动作序列 | 是 | 内置 | ≈80K（47.0） |
| AgenticNav / NavGPT | 文本工具调用 | 否（免训练） | 固定工具链 | 0（零样本） |
| **ZeroVLN** | **语义工具调用** | **否（RL 更新）** | **可训练流专家** | **34.4K（52.7）** |

表中一个耐人寻味的对照：Uni-NaVid（≈80K，SR 47.0）与 NaVILA 受控版（34.4K，46.5）分数几乎相同——数据翻倍在这条线上没有带来翻倍收益；而 ZeroVLN 用同样的 34.4K 拿到 52.7。数据量与范式改进在当前 VLN-CE 上的边际回报，由此可见一斑。

三条对照线值得展开：

- **几何接口 SFT 派**（NaVILA/DualVLN/StreamVLN/NavFoM/JanusVLN）：把导航能力"写进"大脑参数，代价是权重位移与遗忘。论文受控实验里 NaVILA 权重位移 7.67%、DualVLN 3.21%，通用基准双双归零。这一派内部也分档：NaVILA 的数值命令由模拟器直接执行，训练管线简单，受控对比里反而比 DualVLN（要学几何目标预测 + 动作执行两件事）全面更强；StreamVLN 用流式上下文管理解决长视频推理、NavFoM 做成导航基座模型、JanusVLN 用双重记忆解耦语义与空间——它们用更多数据换更高分数，但没有一个质疑"大脑必须 SFT"这个前提。
- **免训练工具调用派**（NavGPT、MapGPT、SayNav、AgenticNav）：大脑冻结、暴露文本工具，证明 VLM 原生就有一定导航决策力，但执行器是固定原语（前进固定距离/原地转向），连续环境的精细运动跟不上，也没有任何组件在学习。ZeroVLN 的 Direct Tool Use 基线复现了这一点——零训练在 SAGE-3D 拿到 39.5% SR，出乎意料地高，但 R2R/RxR 只有 19.0/21.8，长指令多段任务的原语式执行撑不住。这一派的真正价值是为 ZeroVLN 提供了两个关键论据：大脑原生决策力存在（零 SFT 路线的地基），以及原语执行的天花板（可学习执行器的必要性）。
- **特权监督派**（Loquercio 高速飞行、iPlanner、ViPlanner、NavDP、CAST）：用仿真里的特权信息（mesh 几何、全局占据图）给策略造监督标签。ZeroVLN 的请求接地规划器正属于此脉，但用途反转为"给大脑的自然语言请求配轨迹"，而非给固定指令模板配轨迹——这个反转是它能保住大脑的关键。传统特权蒸馏里特权信息直接教策略（观测→动作的端到端映射），ZeroVLN 里特权信息只出现在数据构造阶段、且从属于策略自己提出的请求——特权者的角色从"教师"降为"翻译"。

三条对照线各自暴露了 ZeroVLN 所在空位的边界条件：SFT 派证明可学习执行器有效但大脑必须付出遗忘代价；免训练派证明大脑原生决策力但执行上限锁死；特权派证明特权信息有用但通常以固定指令为中心。ZeroVLN 的设计可以看作对三个边界的同时回应——语义接口回应遗忘、可训练专家回应执行上限、请求接地回应特权信息的正确用法。

方法学近亲还有 agentic RL 一支：GiGPO 的组内-组间双层优势、PGPO 的势函数引导、Agent Lightning 的轨迹分解成训练转移、Agent-R1 的输出/反馈分离、VAGEN 的世界模型推理与双层信用分配；连续策略侧有 DPPO（扩散策略梯度）与 Flow-GRPO（流采样的随机化改造）提供了对生成式动作模型做 RL 的机制。ZeroVLN 的贡献点在于把这些零件组合成"VLM 大脑 + 连续动作专家"的联合闭环优化，并给出轨迹级信用分配在导航上的适配与对照实验。与 SFT 灾难性遗忘分析相关的理论参照是 RL's Razor（Shenfeld et al., 2025，在线 RL 比离线拟合遗忘更少的分布视角解释），本文则从参数范数视角补了另一半论证。

一句话定位：**ZeroVLN = 免训练派的语义接口 + SFT 派的可学习连续执行器 + R1-Zero 式纯 RL 更新**，三个组件此前从未被同时实现。与最接近的几个邻居划界：AgenticNav 同样用文本工具但执行器固定且零训练（没有可学习的执行组件）；DualVLN 同样有可学习流专家但接口是像素目标且大脑 SFT（执行器学的是几何条件而非语义条件）；ETP-R1 对拓扑规划做闭环 GRPO 但底层控制器不变（只训决策层）。ZeroVLN 独占地落在"语义接口 × 双侧可训 × 零大脑 SFT"的交集里。

## 三、问题定义：SFT 重塑分布 vs RL 选择性强化

抽掉所有工程细节，这篇论文真正处理的是一对抽象矛盾的两种更新语义。

**SFT 的语义是"重塑输出分布"。** 对大脑在上下文 x 下的响应分布 p 与示范分布 q，交叉熵损失 L_SFT = -Σ q_y log p_y 的梯度把每个响应的 logit 拉向 q_y - p_y 的方向（命题 1 左半：-∂L_SFT/∂z_y = q_y - p_y）。这个式子值得逐项品味：q_y 是示范要求的目标概率，p_y 是大脑当前概率，梯度之差就是"搬家指令"——与响应 y 本身的质量毫无关系。哪怕大脑已经能以 90% 概率给出正确导航响应，只要示范分布要求另一种表达方式（比如规定必须输出像素坐标而非自然语言描述），SFT 就会持续把概率质量从前者搬向后者。导航示范要求大脑输出"234 447"这样的像素坐标或"turn left 45°"这样的命令模板——这些 token 序列在通用 VLM 的自然分布里概率极低，SFT 必须施加大幅参数位移才能把分布搬过去。搬过去的代价是原有分布（问答、描述、空间推理）被挤掉，这就是遗忘的微观机制。

**RL 的语义是"按回报选择性强化"。** REINFORCE/RLOO 梯度是 p_y(R_y - J)——只对回报高于均值的响应加权、低于均值的抑制，与任何外部规定的分布无关（命题 1 右半：期望 RLOO 梯度恰为回报目标 J = Σ p_y R_y 的梯度，leave-one-out 基线的贡献在期望下因 Σ∇p = 0 而相消）。注意这个梯度的两个因子：p_y 意味着只有大脑本来就会（以非零概率）生成的响应才可能被强化——RL 无法创造新行为，只能筛选已有行为；(R_y - J) 意味着筛选标准是回报差异而非与某个范本的相似度。若所有响应回报相等，梯度为零，大脑纹丝不动；若大脑已有的语言表达里有些说法导向成功，RL 就放大这些**本来就存在**的 token 路径。图 6 的机制示意是这两个公式的可视化：SFT 把"pass the bench / stop here"的分布硬拗成几何/命令格式；RL 只是给大脑自己采样的请求按轨迹回报加正负号——A > 0 的请求路径被强化，A < 0 的被抑制。

由此得出问题的本质表述：**导航学习对大脑的最小要求是"提高好决策的概率、降低坏决策的概率"，而 SFT 额外要求"把输出分布整体搬到示范的形状上"。** 命题 2 把这个直觉钉死为参数几何：在局部线性近似 p_{θ0+Δ} = p_0 + BΔ（B = ∇_θ p_{θ0}）下，达到同一回报增益 δ > 0 的最小范数更新是唯一的 Δ_return = δg/‖g‖²（g = B⊤R 为回报梯度）；任何拟合示范分布的更新 Δ_SFT 都可分解为 Δ_return 加一个与回报梯度正交的分量 w（g⊤w = 0），且 ‖Δ_SFT‖² = δ²/‖g‖² + ‖w‖² ≥ ‖Δ_return‖²。正交分量 w 就是"为了像示范而多付的参数位移"——不提升回报，只负责把分布形状改写成示范的样子，且只要 q - p_0 ≠ BΔ_return 就必然非零。

附录 C.3 进一步用信息论不等式链起因果：定义通用提示分布上的 KL 散度 K(θ) 与期望得分 V(θ)，在 Hessian 范数有界 M 的假设下，K(θ1) ≤ M/2·‖Δ‖²，|V(θ1) - V(θ0)| ≤ √(K/2) ≤ √(M/2)·‖Δ‖（Pinsker 不等式 + Jensen；a ∈ [0,1] 的得分差被总变差距离控制，总变差又被每提示 KL 的 Pinsker 界控制，再对提示分布 Jensen）。参数位移小则通用响应稳定。相对位移 ε = ‖Δ‖/‖θ0‖ 通过 ‖Δ‖ = ε‖θ0‖ 进入界——0.01497% 对 7.67% 的五百多倍差距，就是这条不等式链的实证。注意这个界的两个低调但关键的限定：它约束的是"采样解码下的期望得分"（不是贪婪解码），且曲率 M 在初始化处是 Fisher 信息——即界在"大脑还接近基座"的区间最紧，这正是 ZeroVLN 的运行区间。

要让 RL-only 路线成立，前置条件是大脑的"原生请求空间"已经可执行——否则好决策没有好回报，RL 无从选择；其次 RL 的探索要能采到成功轨迹，否则组内优势全为零、更新停滞。这两条把问题定义直接翻译成了解法约束：让自然语言请求变成可训练的执行接口（否则前置条件不成立）；让监督信号来自大脑自己的语言而非人造模板（否则专家学的是别人的分布）；让初始化足够强以支撑稀疏奖励下的 RL（否则探索采不到成功）。第四部分的三个组件恰好一一对应。

## 四、问题解法：语义接口 + 请求接地 + 联合 RL

### 4.1 语义工具接口：大脑说人话，专家干活

大脑（Qwen3.6-35B-A3B，MoE 架构，激活 3B）不预测任何几何量，只发三个工具调用：

- `run_action_head(target, where, plan)`：把移动决策表达为自然语言三元组——目标（"the doorway leading to the hallway"）、相对方位（"on the left side of the current view"）、局部计划（最多三条自然语言短句）；
- `turn(direction, degrees)`：原地旋转换视角（连续两次为上限，成功的移动调用重置计数）；
- `stop(reason)`：给出可见证据并结束任务。

接口设计的约束都写在工具描述里：run_action_head 明确禁止提供原始动作、坐标、未来轨迹、目标距离或安全预算——大脑只能"点名"不能"开车"；系统提示要求目标必须锚定在当前或保留的观测里、局部目标须服务于最终指令、受阻时换可通行路径或转身侦察、不许机械倒车或重复受阻请求。语义条件通过 16 个可学习 query（维度 2048）拼接进 VLM 输入、取末层隐状态 Q_t 交给动作专家（式 1）——大脑"看图说话"的隐层表示就是专家的语义条件信号，无需任何导航格式的输出头。这个设计的深意在于：工具调用本来就是现代 VLM 的原生能力（预训练里见过海量 function calling 数据），大脑在导航里做的事与它在通用任务里做的事同构，分布不用搬家。

一个值得对比的细节：Direct Tool Use 基线的工具是 move_forward(distance)/turn/stop——参数是数值，语义含量为零；ZeroVLN 的工具是 run_action_head——参数是自然语言，语义含量饱和。这组对照隔离出一个变量：**接口的语义化程度**。零训练时前者 SAGE-3D 39.5%，说明数值接口也够大脑凑合用；但学习潜力完全不同——数值接口没有给"学习"留出接口侧的可改进空间，语义接口让动作专家可以把"听懂人话"这门手艺练到 95% 以上的配对精度，而大脑的表达方式保持不变。

系统提示的设计也值得注意（附录 G.1 完整公开）：轨迹图例的解读说明（绿色 S 起点、蓝色 C 当前位、橙色方块受阻、红叉碰撞）、"运动坐标相对每次调用起点"的坐标系约定、"turn 上限两次、成功移动重置"的节奏约束、"从门口看到目标够不够、要不要走近"的停止语义辨析——这些细节把导航的隐性经验编码进了提示工程，是零 SFT 路线里"把领域知识放进上下文而非权重"的具体实践。

动作专家是个 34.8M 可训练参数的流匹配网络（12 层 Transformer 解码器，hidden 384，6 头，前馈 1536），复用 Qwen3.5-4B 冻结视觉塔（333.5M，只取 vision tower）提取参考图与当前图特征。条件融合走双流：语义适配器 P1 把 Q_t 投到条件空间加语义通道嵌入，视觉适配器 P2 给视觉 token 加视觉通道嵌入，拼接成 49 token 的交叉注意力记忆（16 语义 + 32 视觉 + 1 流时间）。执行采用"预测 16 步、只执行前 4 步前缀"的 chunk 模式：每次预测 H=16 步动作序列（每步 3 维：平面位移 x/y + 航向增量），执行前 h=4 步后刷新观测重新预测，一个移动调用最多 4 个执行周期（Nf=3 步流积分）。语义条件与参考图在整个调用内固定、当前图逐周期刷新——慢通道的意图保持、快通道的视觉闭环。每次调用返回执行反馈（是否受阻、碰撞、实际位移 path_m/net_m、方向对齐度），大脑据此继续、转向查看、修改请求或停止。总参数 368.3M，其中可训练的只有动作专家 34.8M + 上下文 query 0.033M。

### 4.2 阶段一：请求接地监督（大脑冻结）

动作专家要听懂人话，需要"请求-轨迹"配对数据。这里有个鸡生蛋问题：配对数据的请求从哪来？直接造模板会偏离大脑的真实请求分布（附录 D.2 用实验证明此路不通，见第五部分）；沿固定专家轨迹在线生成请求，动作标签又与请求内容无关（同一状态的不同请求共享同一段轨迹标签，GT-Route 对照证明同样不行）。ZeroVLN 的解法是第三条路——**让冻结的大脑先说话，特权规划器再为它的话找轨迹**，请求与标签同时来自这个闭环：

1. **大脑在线 rollout**：大脑以温度 1.0 在每个决策点发出真实移动请求（每决策点最多尝试 4 个候选调用，直到有一个通过验证）；
2. **特权语义规划器接地**（训练专用，推理时不存在）：用 mesh 派生语义图解析请求的名词短语、自我中心方位、空间关系，通过词汇匹配与冻结文本编码器检索物体实例，按深度可见性、方向一致性、空间关系支持、语义匹配、表面距离五准则字典序排序候选；对每个实例在包围盒边界采样接近点（首选驻足距离 0.3m，向外递增采样，剔除占据与不可达点），用 A* 在八连通占据栅格上规划路径（含间隙惩罚 λ_c=0.8、首选间隙 0.6m、样条平滑、25% 绕路上限），按"行程 + 可见性惩罚（λ_v=1）+ 距离惩罚（λ_d=2）"选出最优接近点（式 13/14）；门口/房间请求用映射的开口与相邻房间身份构造"开口前-中-后"有序路点，拒绝穿越无关房间；楼梯请求用原生三维导航网格，限制在匹配的楼梯段与请求的上下行方向内；无可达物体但有方向性请求时，沿该方向逐步缩短位移直到找到无碰撞端点；三类目标全无则拒绝该请求；
3. **执行验证**：在仿真器里实际执行规划轨迹，位置误差达 0.035m 或航向误差达 2° 即拒绝，碰撞、受阻、路点缺失一律拒绝；
4. **配对成监督**：通过验证的轨迹（65 个路点，取每 4 个一点得 16 个动作增量，切成 4 个执行周期）与 originating request 配对。

34,445 个 episode（SAGE-3D 14,628 / R2R 10,069 / RxR 9,748）共产出 384,836 个锚点（SAGE-3D 108,860 / R2R 140,610 / RxR 135,366），执行验证保留率 65.6%（三数据集 61.1%/67.3%/67.9%）。参考轨迹长度跨越 0.1-0.3m 到 ≥8m 的多个尺度（图 5，短轨迹集中部分反映了 0.1m 的采集阈值）。这份数据有几个值得注意的性质：它不需要数据集提供的人类专家轨迹（R2R/RxR 的原始示踪路径完全没用上，只有指令和场景），也不需要任何人工标注——唯一的外部依赖是仿真环境的 mesh 几何，而这是环境自带的。换句话说，**同一个数据管线可以不加修改地用在任何有 mesh 的仿真环境里**，这是它区别于"数据集驱动"路线的根本。

监督本身还有一个关键设计——**执行前缀监督**。动作分块方法（Diffusion Policy、π0、DualVLN）通常对全部 16 步预测算损失，但实际只执行前 4 步就重规划，其余 12 步是"永远被丢弃的预测"，训练与执行错位。ZeroVLN 保留 16 步全序列预测（网络输入不变），但流匹配损失只对前 4 步计算（式 3：对前 h·da 个动作分量平均，所有 H 个动作 token 仍在网络输入里）——模型只对自己真正执行的动作负责，后续动作交给刷新观测后的下一个周期监督。这个设计的精妙之处在于"训练目标与执行协议对齐"而不牺牲预测视野：16 步的完整预测给流匹配提供了足够的上下文结构，4 步的损失边界则把监督质量集中在真正兑现的部分。此阶段只训可学习 query 与动作专家（AdamW，lr 5e-5，batch 64，SAGE:R2R:RxR=1:1:2 采样，约 1.8 epoch / 10,826 步，四节点各 16 卡），大脑与视觉塔完全冻结——**这一阶段的零大脑更新，正是通用能力保留的第一重保险**。

### 4.3 阶段二：轨迹级 RLOO 联合 agentic RL

监督适配后，动作专家会执行单条请求了，但导航成功还取决于大脑跨轮次的连续决策——单条请求执行得再好，请求本身选错了目标、或停止时机不对，任务照样失败。第二阶段对大脑 π_θ 与动作专家 π_ϕ 做闭环联合 RL，核心设计决策有三个：信用分配的粒度、奖励的密化分层、梯度路径的分离。逐一拆解：

**信用分配：轨迹级 RLOO。** 每个 episode 采样 G=8 条独立完整 rollout（每条最多 50 轮），第 i 条的累计回报 R_i = Σ r_{i,t}，优势 A_i = R_i - 其余 7 条的平均回报（式 4，无标准差归一化、无折扣）。整条轨迹的所有工具调用 token 与所有流生成路径共享同一 A_i。这个看似"粗糙"的设计（不区分哪一轮贡献大）实则是深思熟虑的选择：导航成功取决于跨轮次的决策与执行的组合，逐轮估计优势需要知道"哪一轮贡献了成功"——这在部分可观测的长视野交互里近乎不可能。轨迹级把整条轨迹当作一个联合策略的单一动作来评估，避开归因难题。

为什么不用轮级优势（逐轮比较剩余回报，附录 B.7 的变体）？对照实验（图 11）给出答案：轮级会强化"到达过目标但随后失败"的决策——OSR 高而 SR 随训练反降、NE 上升；轨迹级把"到访"与"完成"绑在一起评估，SR/SPL 更高、NE 更低、OSR-SR 差距收窄。轮级优势的问题在于它按轮对齐基线，一次到达目标的高回报轮会被正强化，哪怕后续轮次把任务搞砸；轨迹级让每一轮都为最终结果负责。两条曲线在训练中后期的分岔（轮级 SR 从峰值回落、轨迹级持续上升）是这组对照最有信息量的画面。

**四项互补奖励**对付长视野稀疏信号（式 5）。设计哲学是从"最容易得到的信号"到"最难得到的信号"分层密化，保证 rollout 组内无论整体多差都能排出优劣：

- r_succ：终端成功（环境原生判据确认的那一轮给 1）——最稀、最强；
- r_arr：首次到达（第一次进入目标区给 1，之后离开再进不给，原地转向不能触发）——比成功易得的 outcome 信号，哪怕最终没停对也奖励"到过"；
- r_prog：距离进展（有界邻近势函数 D/(D+d) 的增量，d 按可通行距离度量而非直线距离——绕墙走的真实成本被如实计算、D 按初始距离定标、下界 d_min=1m 防止尺度消失）——所有 rollout 全失败时仍能区分谁离目标更近，缓解梯度退化；
- r_info：信息发现（新发现的深度验证任务相关实体，上限 N_info=5 个、权重 0.01、每 episode 奖励封顶 0.05）——奖励"主动看"而非只奖励"走"，掩护原地转向侦察这类无位移但有信息增益的行为；封顶设计防止智能体刷"看新物体"而不前进。

权重 wsucc=warr=wprog=1、winfo=0.01，折扣 γ=1（无折扣——轨迹级信用分配下每轮都为最终结果全额负责）。

**双梯度路径**是联合更新的结构要点（式 12）：

- 大脑走文本 REINFORCE 梯度 g_θ = ∇_θ L_text：每轮响应 token 的平均对数概率被 sg(A_i)（停梯度）加权，再对轮、对 rollout 平均，λ_text=0.1，on-policy 无 PPO ratio、无 KL 锚定——轻得不能再轻的更新；
- 动作专家走 Flow-SDE 路径策略梯度 g_{Q,φ}：按 Flow-GRPO/DPPO 方式把确定性流采样随机化为 SDE 路径（三段均匀流时间网格 u=1→2/3→1/3→0，噪声尺度 0.08，Euler-Maruyama 积分），对采样生成路径的对数似然 ℓ_exec（对去噪步与全部 H×da 个动作分量求和）加权裁剪优势 A^exec = clip(A_i, -1, 1)，梯度穿过 VLM 到达可学习 query 但不触碰 θ。裁剪的作用是防止单条极端 rollout 的巨大负优势把流策略一把推垮。

两条路径通过共享的轨迹级优势耦合（都朝导航成功优化）、通过分离的参数路径解耦——动作策略的梯度不会直接改写大脑的工具调用分布，大脑只被自己的文本回报信号更新。这个不对称有一个精妙的分工含义：**query 是两侧的"接触面"**，它既接收大脑的语义上下文（前向），又被动作侧的梯度塑造（反向），等于大脑不需要改自己就能"学会更好地表达"——全部适应压力被 0.033M 个 query 参数吸收了大半。Algorithm 1 给出完整流程。

训练仅 200 步（lr 1e-6，每步 64 episode × 8 rollout = 512 条长视野轨迹，SAGE:R2R:RxR = 2:1:1 采样，八节点各 16 卡），R2R SR 就从 17.0 冲到 52.7。对比两个阶段的算力画像颇有意味：适配阶段 10,826 步 × 64 锚点是"便宜的大批量监督学习"，RL 阶段 200 步 × 512 rollout 是"昂贵的在线交互"——前者铺地基、后者起高楼，两阶段预算相差近两个数量级（按样本计），恰好对应"多数能力来自专家适配、决策质量来自 RL"的贡献分工。

一个容易忽略的实现细节是上下文管理：大脑 131K token 上下文，thinking 全程关闭；每轮 512 token 补全预算；长 episode 触发历史压缩——保留初始任务与最近 8 轮、每 4 个旧轮采 1 个完整轮、移除旧轨迹快照但保留最新累计轨迹。执行反馈的结构化设计同样精心：每次移动调用返回 option_id/chunk_id、逐 chunk 的相对位姿与受阻/碰撞/无进展标志、path_m（轨迹长）与 net_m（净位移）的区分、direction_alignment（计划方向 vs 实际方向）——大脑拿到的不是裸观测，而是便于归因的执行审计报告。这类反馈设计是"反馈驱动恢复"能力（案例里受阻后改请求）的接口基础。

理论侧的收尾在附录 C.2：动作专家适配先抬高了初始回报 J_0（图 9 的 27.0→37.5 就是 J_0 的提升），剩余回报缺口 δ = J* - J_0 变小，由式 ‖Δ_d‖ = (J*-J_0)/(‖g‖κ) 可知所需的大脑更新量随之缩小——"先把执行器练好，再让大脑少改"，这就是零 SFT 还能保住通用能力的第三块拼图。注意这条推理链的完整性：语义接口（减少要学的东西）→ 请求接地适配（提高 J_0）→ 回报加权 RL（避免拟合示范分布）→ 小参数位移 → Pinsker 界下的通用响应稳定。四个环节缺一不可，单独拿掉任何一环（比如接口保留但用 SFT 更新大脑、或 RL 但无适配初始化）都会破坏结论——消融实验恰好逐一验证了这一点。

## 五、评估指标与实验证据

### 5.1 受控对比的设计逻辑

论文最硬核的部分是对比设计的纪律性。VLN 文献里"跨论文比数字"是重灾区——骨干不同、数据不同、增强不同，谁也说不清差距来自方法还是工程。本文用三组设计堵住这些漏洞：

- **基准与指标**：SAGE-Bench-3D（基于 3D Gaussian 场景，到达目标区即成功）、R2R-CE 与 RxR-CE（还须停在目标区；RxR 指令更长更密）；指标 SR/SPL/NE/OSR 全套，官方评测集 + 每 episode 200 轮上限；RL 训练中每 4 步在每基准 100 个固定 episode（100 轮上限）上做中间评估。
- **受控组**：NaVILA 与 DualVLN 用官方开源实现，**只替换骨干为同一个 Qwen3.6-35B-A3B、只替换训练数据为同一份 34,445 episode**，各自保留原生数据增强与训练管线（NaVILA 扩成 1,305,082 个监督样本、全参数微调 1 epoch，是 ZeroVLN 语义锚点数的 3.39 倍；DualVLN 两阶段用 1,539,344 / 1,126,788 个样本，为 4.00×/2.93×）——不限制对手的样本扩张，只锁死源头，确保比较的是范式而非数据工程。这一点尤其大方：对手用 3-4 倍的监督样本仍然输了 30 个点，范式差异的说服力反而更强。
- **零训练参照**：Direct Tool Use 基线（原始 Qwen3.6-35B-A3B + move_forward/move_backward/turn/stop 数值工具，无任何训练）丈量大脑的原生导航力。发表结果组（NaVid-SAGE/NaVILA-SAGE 500K、Uni-NaVid ≈80K、StreamVLN ≥150K、NavFoM ≥182K、JanusVLN ≥169K）单列，避免数据量混淆。

这组设计合起来实现了一个三变量解耦：骨干固定 → 性能差异不来自底座；源数据固定 → 不来自数据量；原生管线保留 → 不来自"对手被削弱"。剩下的差异只能归于训练范式本身。读者在做任何"方法 A 比方法 B 好"的对比实验时，可以直接抄这套解耦清单。

三个读数：

1. 同骨干同数据，ZeroVLN 对 DualVLN 三基准 SR 全面超出 30 个百分点以上（51.3/21.2、52.7/15.4、51.4/17.7），对 NaVILA 在 SAGE-3D 拉开 27.8 点、R2R 6.2 点、RxR 2.7 点。值得注意的是 ZeroVLN (w/o RL) 与 DualVLN 的对比——两者都是"冻结大脑 + 训动作专家"，差距（36.9 对 21.2 等）全部来自监督构造方式（请求接地 + 前缀监督 vs 像素目标），单这一项设计差异就值 15+ 点，是全部环节里杠杆最大的一环；
2. 用 NaVILA-SAGE 约 1/14 的数据（34.4K 对 500K）在 SAGE-3D 反超 5.3 点，对 Uni-NaVid 的 OSR 优势达 13.4/9.1 点（SR +5.7/+2.7）——注意 NaVid-SAGE 500K 在 SAGE-3D 只有 36.0，连受控组的 ZeroVLN w/o RL 都比它高，说明 SAGE-3D 上大数据 SFT 不是万能药；
3. 相比发表的大数据 SFT 方法（StreamVLN 56.4 / NavFoM 56.2 / JanusVLN 60.5 档）在 R2R 上仍有 4-8 点差距，但那些是 4-5 倍以上数据浇出来的——数据效率与能力保留是 ZeroVLN 换取的筹码。而且趋势值得注意：RxR 上 ZeroVLN 51.4 对 StreamVLN 54.4 的差距（3 点）比 R2R 上的（3.7 点）更小、对 NavFoM（49.4）实现反超——密集长指令场景下语义接口的优势相对更大，因为大脑的语言理解力被直接兑现而无需经过几何格式转换的窄门。

### 5.3 通用能力：参数与功能双重验证

这是本文最独特的实验板块——绝大多数 VLN 论文只测导航，本文把"大脑还剩多少通用能力"放到了同等地位，且从参数与功能两个层面独立测。

**参数层：权重位移。** 按任务向量范式（Ilharco et al.，d_rel = 100·‖θ_ft - θ_pre‖₂/‖θ_pre‖₂，双精度累加，含冻结权重、新增组件因无基座对应物而排除）：ZeroVLN **0.01497%**、DualVLN 3.21%、NaVILA 7.67%——ZeroVLN 比两个 SFT 基线小两个数量级以上（约为 NaVILA 的 1/512、DualVLN 的 1/214）。这个数字的含义：RL 200 步、lr 1e-6 的更新在大脑参数空间里只留下了极轻的痕迹，却完成了 SR 17→52.7 的跃升。

**功能层：十二项基准全景。** 基准覆盖通用视觉（CV-Bench-2D/3D）、深度定位（DA-2K）、教育推理（ERQA）、具身空间（EmbSpatialBench、RoboSpatialHome）、多选手空间（MMSI-Bench）、指代空间（RefSpatial 三子集）、3D 空间关系（3DSRBench、ViewSpatialBench），VLMEvalKit 统一协议（温度 0.7/top-p 0.8/top-k 20、规则匹配评分非 LLM 裁判）。平均分：基座 59.47%、ZeroVLN 59.16%（十项持平或超过，CV-Bench-3D 93.58 对 93.17 甚至略升），两个 SFT 基线十二项全部归零。逐项看 ZeroVLN 的两处下降在 RefSpatial Placement（43.0→38.0）与 Unseen（42.86→38.96）——轻量损失但远非崩塌。

**零分质疑：格式还是能力？** 两个 SFT 基线全零会不会只是"不会按格式答题"？作者补了一个杀手级实验（图 8）：固定 Answer: 前缀后直接读选项 token 的下一 token 概率、选概率最高的有效选项，绕开格式生成——ZeroVLN 62.00% 对基座 62.86%，NaVILA/DualVLN 仍贴近 32.48% 的随机线（七基准 700 题分别答对 280/255，ZeroVLN 434，基座 440）。这个实验把"能力"与"答题格式"解耦测量，结论无法辩驳：SFT 基线损坏的不是答题格式，是参数里编码的视觉能力本身——它们看到空间问题会下意识输出"turn left 45°"，因为整个输出分布已经被搬到了导航格式上。

### 5.4 为什么有效：三段证据链

论文的"why it works"分析分三段展开，每段回答一个问题：

**大脑原生会导航吗？——会。** Direct Tool Use 零训练拿 39.5% SAGE-3D SR——通用 VLM 本来就能做有用的移动决策，这是请求接地监督可行的地基，也是整个零 SFT 路线的合法性来源。但 R2R/RxR 只有 19.0/21.8 说明原生决策力有上限：长指令、多段路径的连续跟踪超出免训练能力范围，这正是需要学习组件的地方。

**适配阶段给了 RL 什么？——强初始化与可采样的成功轨迹。** 语义对齐适配把 SAGE SR 从 27.0 提到 37.5（R2R+RxR 均值 11.6→17.4），且前缀监督在同轨迹下一致优于全序列监督（图 9）；适配后策略 Pass@4 达 43.5%，让 RLOO 的分组里更容易采到成功轨迹，缓解稀疏终奖下的优势退化——这是初始化质量与 RL 采样效率的连接点：RLOO 的组内基线只有当组内既有成功又有失败时才有区分力，Pass@4 43.5% 意味着 8 条 rollout 的组几乎必然包含成功样本。

**联合 RL 补上了什么？——跨轮决策质量。** 17.0→52.7（R2R）、18.7→51.4（RxR）、36.9→51.3（SAGE）。轨迹一致性检验（图 14，1000 个请求、同观测同噪声种子）确认 RL 后动作专家的目标跟随行为基本保留（预测轨迹与规划目标的端点距离和角度偏差在两阶段都维持低位）——RL 改进的是决策质量，没有破坏执行保真度。这个对照很关键：它排除了"RL 提升来自动作专家继续变好"的替代解释，把增量归因到大脑的语义决策上。

案例研究（附录 F，七个成功 rollout 全景）展示了机制：

- **受阻恢复**（R2R 楼梯案例）：第 15 轮请求爬下一段楼梯被退回受阻，第 16 轮左转、第 17 轮重试再受阻，再换视角后第 19 轮的移动请求完成全部动作步，第 25 轮正确停止——SPL 72.8%、NE 0.36m、路径 11.97m、25 次工具调用。受阻信息以自然语言+轨迹图回流的接口在这里兑现为"换路"决策。对比 SFT 方法的典型失败模式（重复输出同类命令直到超时），这种行为差异直接来自训练信号的差异——RL 见过"受阻后修改请求获得回报"的轨迹，SFT 的示范里没有失败恢复这个章节；

- **地标确认**（RxR 台灯案例）：指令描述"右边有三幅画像、左边有床的台灯"，第 20 轮接近台灯受阻后左转移位重发请求，第 24 轮 stop 的 reason 里同时引用台灯、画像、床三个地标——SPL 81.3%、NE 0.18m。停止理由的可解释性是语义接口的独特副产品：每个 stop 调用都自带"为什么停"的证据陈述，审计与调试成本大幅降低；
- **干净执行**：R2R"上楼梯在顶上等"案例 11.21m 路径 SPL 100%、17 轮调用；RxR 地标链（走廊→楼梯→餐桌→玻璃门→挂钟墙）17.87m 路径 SPL 0.951、22 轮——密集指令的节奏跟随；
- **门后侦察**（R2R 露台案例）：大脑先请求经电视走向滑门，右转侦察出口后再请求走向露台，第 26 轮在室外停止——SPL 64.3%、NE 1.04m。"先看再走"的信息发现奖励（r_info）在这里体现为行为偏好；
- **厕所定位**（R2R 卫生间案例）：先请求最近的门廊、转身侦察房间、第 8 轮请求接近马桶、第 10 轮细化方向、第 12 轮在视野中出现马桶时停止——SPL 76.8%。"目标粗定位→细化→确认停止"的三段式是 ZeroVLN 最常见的收尾节奏。
- **效率下限**：也有 SPL 40.5%、20m 路径、39 轮调用的低效案例（找白色架子房间）——探索代价的具象化，与第六部分的 SPL 权衡互为注脚。

这些案例合起来给出一个行为学画像：ZeroVLN 的导航是"请求-观察-修正"的对话式循环，而不是"感知-预测"的单向流水线——这是 RL 从交互中学习（而非从示范中模仿）的行为学签名。七个案例的量化指标（SPL 从 40.5 到 100、工具调用从 12 到 39）也勾勒出行为质量的方差范围：上限能到满分路径，下限仍在"能到但绕路"——方差本身是探索式学习的特征，稳定地压窄方差而不过度牺牲 OSR，是后续工作的明显抓手。
### 5.5 消融与"模板增强不迁移"的关键发现

- **联合性消融**（图 12/13）：只训动作专家提升有限（执行再好也补不上决策上限）；只训大脑先升后跌破初始化——大脑请求分布漂移而动作专家固定，两者失配，SR/OSR 双双恶化到初始化以下。联合更新是唯一持续上升的配置，轮级信用下结论一致。这条消融是"联合优化"主张的最直接证据：慢快策略必须在同一个回报信号下共同进化——它揭示了分层系统的一个内在规律：**层间接口（这里是语言）是软的，两侧分布各自演化时会渐行渐远，只有共享目标能把它们锁在一起**。
- **前缀 vs 全序列监督**（图 9）：同冻结大脑、同参考轨迹，只改监督位置——前缀监督的 SR 曲线一致高于全序列，且为 RL 提供了更强的初始化。训练目标对齐执行协议的意义被干净地隔离验证（数据、初始化、训练设置、评测全部固定，唯一变量是损失覆盖的动作位置）。

**奖励消融**（固定轨迹级信用，图 12 下排）：去掉首次到达奖励 OSR 严重退化（终奖太稀，学不会到达）；去掉终端成功奖励则 OSR 高而其余指标恶化（学会了到访、学不会停止——两个 outcome 奖励必须配合使用才能平衡到达与完成）；去掉距离进展或信息发现任一，训练变弱或不稳（过程奖励在 outcome 稀缺时支撑学习信号）。这组消融与奖励设计形成完整闭环：每一项奖励的存在理由都被"去掉它会怎样"的实验反向确认。

**模板增强实验**（附录 D.2）值得单独讲，因为它反直觉地证伪了一条看似合理的路线。设想很自然：动作专家分不清"向左绕"和"向右绕"怎么办？造配对数据——受 CAST 启发，在同一导航状态下构造左/右对角轨迹，配上对应语言模板（"向左前方斜向移动…"）注入 plan 字段，共 49,647 个方向对 + 19,114 个物体/关系对。结果分三层：

- **模板内学到完美**：动作专家在训练模板上的配对方向准确率从 0% 拉到 95.90%，held-out 模板也有 96.27%——学习本身没有问题；
- **闭环零提升**：同样 100 个 SAGE-3D episode、每 episode 4 条 rollout、50 调用预算下，最终导航 SR 13.25%，与不加增强持平——尽管导航中方向准确率保持 92% 以上；
- **真实分布反而受损**：对大脑真实生成的请求（456 个、其中 199 组同状态含左/右请求），配对航向准确率从无增强的 64.70% 降到增强后的 56.91%。

解剖发现 456 个大脑生成的 plan 里没有一个使用模板里的对角运动词汇——大脑说的是"Move forward towards the wall with the painting"这种场景化语言，不是模板的机械方向词。**动作专家可以完美学会人造语言-运动关联，却迁移不到大脑实际说话的方式**；更糟的是增强数据挤占了训练预算，真实分布上的表现反而被稀释。结论：监督必须跟随大脑的真实请求分布，这既是请求接地设计的动机，也是对整个"造数据教执行器"范式的警告——配对精度（95.9%）与分布对齐是两个独立维度，只有后者决定迁移。

GT-Route 锚定（自然请求 + 数据集专家轨迹标签，不同请求可共享同一轨迹标签——大脑在专家轨迹锚点上出题，但动作标签是那条轨迹的后续动作，与请求内容无关）对照同样支持这一点：最优 34.0% SR / 21.55% SPL，低于请求接地的 37.5% / 22.56%（该对照在 episode 子集、上下文、执行器与训练暴露上有差异，论文如实标注）。两条路各错一半：模板增强错在请求来源，GT-Route 错在动作标签与请求脱钩——请求接地同时修对了两者。

## 六、效果优势根源

把因果链串起来，ZeroVLN 的优势有四环，每一环都有实验背书：

**环一：接口保住了大脑的原生分布。** 语义工具调用让大脑在它擅长的语言空间里决策，导航学习不再要求输出分布搬家。命题 1 的梯度公式精确刻画了差别——q_y - p_y 永远在推（只要示范没被完全拟合），p_y(R_y - J) 只在回报有差异时推。语义接口的额外红利是灵活恢复：受阻、碰撞等执行反馈以自然语言回流，大脑可以用它本来就有的反馈驱动修正能力来修改请求、换视角侦察（论文引用的工具使用与自纠错文献所指出的原生能力）。案例研究里"受阻→转身→改请求→成功"的行为模式在 SFT 方法里几乎不可见——模仿示范分布的模型没有学过"失败后怎么表达"，而 ZeroVLN 的大脑从没丢掉这个能力。

值得强调的是这四环不是并列而是相互成就的：没有语义接口，请求接地无从定义（没有"请求"这个对象）；没有请求接地，动作专家听不懂大脑的话，RL 的 rollout 里全是失败、优势全负；没有联合 RL，大脑的决策上限锁死在基座水平；没有前三个环节的小位移，通用能力保留就不会发生。这是一个"设计一致性"的范本——每个组件的存在都以其他组件为前提。

**环二：特权规划器把"人话"翻译成"轨迹"，翻译对象是大脑自己的话。** 384,836 个锚点全部配对 originating request，动作专家学的是大脑实际会说的语言。模板增强实验（95.9% 配对准确率、闭环零提升）从反面证明了这一设计不是偏好而是必需；GT-Route 对照（自然请求 + 错配标签）证明了标签侧同样不能妥协；执行验证（0.035m/2° 阈值）保证了标签的物理可执行性。三组实验合起来把"请求-标签双向对齐"的必要性钉成了闭环证据。

**环三：联合 RL 让两个策略互相追赶而不是失配。** 单侧更新必然失配（brain-only 跌破初始化的曲线是最直观的证据），共享轨迹级优势 + 分离梯度路径让语义决策与连续执行朝同一个导航目标共同进化。四项奖励保证全失败的分组里也有梯度——这正是 agentic RL 在长视野稀疏任务上能跑起来的前提。轨迹级优势对照轮级的实验还揭示了一个一般性规律：**信用分配的粒度决定了策略优化偏向哪个子目标**——轮级偏向"制造到访"（OSR），轨迹级偏向"完成任务"（SR+SPL），选粒度就是选行为塑造方向。这个规律对任何多轮 agent 训练都成立，与任务无关。

**环四：小位移在功能上兑现为通用能力保留。** 0.01497% 位移 + 附录 C.3 的 Pinsker 界 → 十二基准 59.16 对 59.47 的实测保留 + 选项概率读出的 62.00 对 62.86。外部交叉验证：RL's Razor 从分布视角论证在线 RL 比离线/SFT 遗忘更少，本文命题 2 从参数范数视角给出互补解释——两条独立理论路线在同一结论上汇合；R1-Zero 在语言推理域的成功则是范式级先例，ZeroVLN 把它带进了连续控制域，并且补上了 R1-Zero 没有的"联合训练第二策略"维度。反过来，两个 SFT 基线的全零不是巧合而是结构必然：它们的大脑被搬进导航格式分布后，面对空间问答会输出运动命令（图 7 的定性示例里 DualVLN 与 NaVILA 对"哪个物体最近"答"The next action is turn left 45 degrees"）——分布搬家搬走了答题能力本身。

**代价也要如实说：SPL 权衡。** R2R/RxR 上 ZeroVLN 的 OSR（66.7/64.6）显著高于 NaVILA（51.8/55.6），但 SPL（29.2/28.1）明显低于 NaVILA（41.8/43.0）。拆开看这组数字的结构：SAGE-3D 上 ZeroVLN 的 SPL（32.0）与 NaVILA（22.1）相比并不落下风，说明 SPL 劣势集中在需要"停在目标"的 R2R/RxR——正是 stop 决策主导终局的基准。ZeroVLN 的 OSR-SR 差距（66.7-52.7=14 点）比 NaVILA（51.8-46.5=5.3 点）大得多，印证了"到了但探索过多/停得晚"的行为模式。机制不难理解：ZeroVLN 不模仿专家轨迹、靠交互学习，受阻后靠修改请求、探索替代路径恢复——图 10 的楼梯案例走了 25 轮调用。恢复能力买了"可达性"（OSR），探索多走的路卖了"效率"（SPL）。在救援、搜索等"到没到"比"快不快"更重要的场景这是净收益；在对路径长度敏感的部署里需要显式权衡。论文没有回避这一点，表 1 标题里就写明 reachability-efficiency trade-off，这种诚实反而增强了其余结论的可信度。

另一点局限：与大数据 SFT 方法（JanusVLN 60.5）的绝对差距仍存在，且 RL 阶段每步 512 条长视野 rollout 的采样成本不低——200 步 × 512 条 × 每条最多 50 轮交互的仿真量，是"数据少"叙事背后没细算的账。适配阶段的请求接地同样要跑大量在线 rollout（大脑出题）加规划器接地与仿真执行验证，34.4K episode 变成 384.8K 锚点的过程发生在仿真器里，计算成本并不为零。SAGE-3D 上的训练 episode 是仿真数据，真实机器人上的请求接地还需要真实感知与验证手段的替代方案。最后，理论命题的局部线性假设在大幅更新区间只是近似，零 SFT 路线在任务分布远离基座能力时的表现（比如需要全新运动技能的任务）仍是未知数——大脑"本来就有的 token 路径"如果根本不存在，RL 的 p_y 因子就无从放大。

## 七、必要知识反推

读通这篇论文需要预先掌握的知识模块，按依赖顺序反推——如果想沿着这条研究线做下去，这份清单就是补课地图：

1. **VLN-CE 任务设定**：R2R/RxR 基于 Matterport3D 扫描真实住宅（RxR 是多语言、更长更密的指令版本），VLN-CE 由 Krantz et al. 2020 提出，去掉 nav-graph 改为连续控制；SR/SPL/NE/OSR 的定义（SPL 按路径长度加权成功、OSR 只要经过目标就算）——不懂这些指标就读不出 reachability-efficiency 权衡的分量，也读不懂轨迹级 vs 轮级信用分配实验里 OSR-SR 差距的含义。SAGE-Bench 是 2026 年基于 3D Gaussian 的物理可执行新基准，与 R2R/RxR 的评测协议差异（到区即成功 vs 须停止）直接影响两个基准上的行为塑造。
2. **流匹配与动作分块**：flow matching 的速度场回归目标（从噪声到位移增量的流积分）、act-diffusion/π0 式的"预测 H 步执行 h 步"chunk 范式、Flow-SDE 如何把确定性流采样变成可算对数似然的随机路径（Flow-GRPO 的前处理：流时间网格上加高斯扰动）——这是动作专家架构与动作策略梯度的语言。不熟悉这一块也可以先把动作专家当黑盒读主线，回头再补。
3. **RLOO 与 agentic RL**：leave-one-out 基线的无偏性（组内其余 rollout 均值作基线、期望下与当前样本独立）、组内相对优势估计为什么不需要 critic、多轮 agent 轨迹的信用分配难题（GiGPO/PGPO/Agent Lightning 一脉的背景——"哪一轮贡献了成功"在导航里为何特别难归因）。理解"组内基线在全员失败时仍有区分力"这一点，是读懂四层奖励设计动机的钥匙。
4. **VLM 工具调用范式**：Qwen 系工具调用的 JSON 格式与预训练分布、可学习 query 拼接进 LLM 输入取末层隐状态作条件（BLIP-2 式 Q-Former 思想在 VLA 里的变体，DualVLN 的 contextual queries 是直接前身）。
5. **灾难性遗忘度量**：任务向量（Ilharco task arithmetic：微调前后权重差作为一个"任务方向"）与相对权重位移的定义、KL-TV-Pinsker 不等式链、Fisher 信息作为 KL 曲率在初始化处的取值——命题 3 与 0.01497% 数字的解读基础。这一块在 VLN 文献里几乎没人用，却是本文最有辨识度的实验设计。
6. **导航学习谱系**：从 nav-graph 时代（HAMT/DUET/ETPNav 的拓扑图与历史建模）到 VLN-CE 的演化、NaVILA 的两阶段（VLM 输出命令 + 腿足 locomotion 策略）、DualVLN 的像素目标接口与两阶段训练、特权蒸馏在机器人学里的传统（Loquercio 高速飞行先例、NavDP 的特权信息用法）——受控对比的参照系。谱系里每次接口变革（拓扑图→数值命令→像素目标→语义请求）都对应一次能力跃迁，本文是这条演化线的最新一环。
7. **仿真栈**：Habitat 仿真器的动作/观测接口、mesh 与导航网格的关系（请求接地要用它做几何验证）、VLMEvalKit（通用能力评测的统一协议）——复现工作的操作层前提。SAGE-Bench 的 3D Gaussian 场景渲染与物理执行判据也在此列。

## 八、通用性灵感

ZeroVLN 的贡献不止导航本身，其方法学骨架（语义接口、请求接地、联合 RL、前缀监督）都能在具身之外的领域找到对应物，以下逐条映射并标注迁移条件，避免过度泛化：

**"零 SFT + 可学习工具"是规避具身遗忘的通用解。** 核心转换是：把"教大脑输出域特定格式"改写成"教一个域特定工具听懂大脑的自然语言"。这个模式可以平移到操作（把 run_action_head 换成 run_manipulation_head，动作专家换成机械臂流策略）、移动操作、多任务具身智能体——大脑一个不动，每个物理技能配一个小专家。论文结论段自己点了这个方向：通向"共享 VLM 大脑 + 多个专用动作专家"的通用具身智能体。对做 Agent 系统的人还有一个直接启示：**大脑-工具接口应尽量靠近大脑的预训练分布**（自然语言工具调用），而不是靠近机器的表示（坐标、命令码）——接口越"说人话"，学习对大脑的侵入越小。迁移前提：该域的执行质量需要可验证的回报信号（仿真器、判据或评估器），否则 RL 无从选择；且基座在该域要有非零的初始能力（Direct Tool Use 39.5% SR 就是这个"非零"的量化），否则 RL 的探索无从起步。

**请求接地是"数据引擎"设计的新范式。** 与其收集人类示范，不如让策略自己出题、让特权仿真器判卷配答案——只要仿真器能验证执行，监督就能源源不断且永远在分布上。这个思路对一切"执行器需要配对数据、但配对数据来源与人造分布错位"的场景（指令跟随、code-action 对齐）都适用。模板增强 95.9%→闭环零提升的教训同样通用：**评估数据构造方案时，分布对齐比配对精度重要得多**——一个在人造测试集上逼近满分的执行器，可能在真实调用分布上毫无长进。迁移前提：存在可靠的"接地器"把请求翻译成可验证的目标（本文用 mesh 语义图 + A*，其他域可以是编译器、求解器、物理引擎）。

值得注意的是这套数据管线的可扩展性经济学：人类示范每条都要标注成本，请求接地的边际成本只有仿真器算力——大脑出题越多、接地器验证越多、监督越丰富，且全部严格在策略自己的分布上。当大脑升级换代，重跑一遍管线即可再生整个数据集（人类示范数据则要重新对齐标注规范）。这层"数据与策略共生演化"的性质，是它与静态数据集路线最本质的分歧。

**执行前缀监督是对一切 chunk 式策略的免费改进。** 训练损失只算会被执行的前缀，消除训练-执行错位。这个修正与具体任务无关，任何"预测长序列、执行短前缀、滚动重规划"的系统（VLA、自动驾驶轨迹预测、游戏宏操作）都能直接套用。它与 NavFoM 一系"预测多步、短视野执行"的共识形成互补——前者的训练目标终于和执行协议对齐了。

**特权信息的正确姿势是"翻译"而非"教学"。** ZeroVLN 里 mesh 几何、语义图、A* 规划器只做一件事：把策略自己的请求翻译成可验证的轨迹。特权信息从不直接定义策略"应该输出什么"，只验证"策略想做的事在物理上意味着什么"。这个姿态转换对 sim-to-real、数字孪生、合成数据生成都有启发：让特权者当翻译，学习者保持主体性——否则学到的只是特权者的行为克隆，而特权者的行为分布未必是学习者推理时会处的分布（模板增强实验正是这个失败模式的标本）。**过程奖励的分层密化是稀疏回报任务的通用配方。** 终奖/首到/进展/发现四层从难到易排布，保证任意水平的 rollout 组内都能产生非零梯度。这个设计的成本极低（只依赖环境反馈：成功判据、可通行距离、新可见实体），却直接决定了 200 步 RL 能否起步——对一切"成功稀有、失败常见"的 agent 任务（长程操作、多步工具调用）都有直接参考价值。四层的取舍原则也值得抄：每层都要"便宜可验证"（不引入学习型奖励模型）、"有界"（r_info 封顶 0.05、r_prog 有界势函数）、"不互斥"（可以同时触发）——这三条保证了奖励 hacking 的表面积很小。

**联合优化的失配诊断适用于一切分层 Agent。** "只训一侧先升后跌"的消融曲线是分层系统最便宜的健康检查：如果你的大脑-工具系统在单侧微调后出现性能回落，几乎一定是层间分布漂移。解法同样是本文的双梯度路径——共享优势信号（或共享损失）+ 分离参数更新，让两侧在同一个目标下共同进化。这个诊断-解法对偶在任何"语义层 + 执行层"架构（代码 agent 的规划器-执行器、GUI agent 的理解器-操作器）里都适用。

对研究选题的启示：这篇论文的引用地图里有几块明显的低垂果实。其一是把请求接地搬到真实机器人（用 SLAM 建图替代 mesh、用运动规划器替代 A*）；其二是多技能扩展（导航 + 操作共享一个大脑）；其三是把轨迹级优势换成更细粒度但避免轮级陷阱的方案（比如基于状态聚类的 GiGPO 式双层结构）。这三个方向各自的难度与回报都值得单独评估——ZeroVLN 提供的不只是结论，更是这些方向的可行性证明起点。

总而言之，ZeroVLN 用一个 41 页的完整证据链回答了具身智能的一个基本问题：任务专精不一定要以牺牲通用性为代价，前提是把"学什么"与"怎么学"都设计对——接口说人话、监督跟着策略走、更新只认回报。当具身基座模型的竞争进入"通用性即护城河"的阶段，这套方法论的分量会越来越重。

**理论-实证的互证方式值得学。** 命题 1/2 不是装饰：它们预测了"同回报增益下 SFT 参数位移严格更大"，0.01497% 对 3.21%/7.67% 的实测把抽象不等式变成了可感知的数字；命题 3 再把参数位移连接到功能保留的界。三者构成"梯度语义 → 参数几何 → 功能边界"的完整推导链，每一环都有对应实验（图 6 机制示意 / 图 7 权重位移 / 表 7+图 8 功能保留）。做 RL 系工作时，把"为什么我的训练信号更便宜"形式化成参数几何命题，是说服力的重要来源。当然也要看清理论的边界：命题 2 的局部线性假设在 SFT 大幅更新时不严格成立，论文自己也声明"不假设 RLOO 达到最小范数解"——理论刻画的是需求侧（需要多大更新）而非供给侧（实际发生多大更新），这个诚实的不对称让结论更可信。

**SPL 权衡指向一个更深的开放问题：探索税。** 靠交互恢复（修改请求、换路）买来的鲁棒性必然伴随路径变长，这与 offline RL 的保守性、模型基探索的乐观偏置是同一家族的现象。ZeroVLN 的奖励设计里 r_prog 按可通行距离度量已经部分内化了绕路成本，但没有显式的步数惩罚——未来在奖励里加入路径效率项（或对 SPL 直接可微的代理）是否能收窄与 NaVILA 的 SPL 差距而不牺牲 SR，是一个可以立刻动手的实验。另一个方向是分层奖励的时序安排：训练早期鼓励探索（高 OSR）、后期收紧效率——类似课程学习地在 r_prog 与 r_succ 之间调度权重。

最后是一个开放问题：ZeroVLN 的 RL 只跑了 200 步就从强初始化起飞——当任务更难、回报更稀疏时，零 SFT 路线还能否保持数据效率？多个动作专家共存时，大脑的工具选择本身能否也零 SFT 学出来？真实环境（无 mesh、无特权规划器）里请求接地用什么替代——真实 SLAM 建图、VLM 密集奖励、还是世界模型仿真？大脑的原生请求分布是否存在系统性盲区（比如它从不说"后退"，因为预训练数据里导航语言很少倒车）而需要最小 SFT 补齐？这篇论文留下的地图比它走过的路更值得探索。
