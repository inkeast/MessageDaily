## 一、论文背景

推理成本是大模型落地的核心瓶颈，而推理成本里最刺眼的两段分别是：自回归 LLM 的**长上下文 prefill**，和扩散语言模型（DLM）的**迭代去噪**。本组两篇论文恰好各攻一段。

### 1.1 TokenGate：长上下文 prefill 为什么贵

**Prefill（预填充）是什么？** 用户向 AI 助手上传一份 PDF、一个代码仓库或一堆检索文档再提问时，模型必须先把全部输入 token 逐层过一遍 transformer，计算每层的 Key/Value 并缓存（KV cache），然后才能吐出第一个字。这段「首 token 之前的全量阅读」就是 prefill，用户等待的 TTFT（time-to-first-token）延迟主要由它决定。

**贵在哪里？** 论文给出了清晰的复杂度账单：注意力计算随输入长度 N 二次增长（O(N²·N_L)），MLP 计算与 KV cache 显存随 N 线性增长（O(N·N_L)）。当输入从 2k 涨到 128k，这笔账按平方爆炸。

**已有两条路线的困境。** 第一条是 training-free token 剪枝（FastKV、SlimInfer、DASH、GemFilter 等）：在中间层用注意力启发式给 token 打分，只把高分 token 传给上层。部署零成本，但论文点出其两个结构性弱点：早期层注意力信号本身很弱（打分不准），且 backbone 无法与剪枝协同适应。第二条是改架构（线性注意力、混合架构、动态计算）：效果有潜力，但要么从头预训练、要么需要辅助损失锁定 token 预算、换个预算就要重训，与现有模型生态不兼容。

**人类的启示。** 论文用了一个漂亮的类比：专家读者处理大型代码库或长文档时，是先略读、再精读关键部分；而 transformer 是「每个 token 都平等地过每一层」。能不能让模型也学会略读？这就是 TokenGate 的出发点——给已训练好的模型插一个可学习的「略读门」。

### 1.2 T2Quant：扩散语言模型的量化为什么难

**扩散语言模型（DLM）是什么？** 与 GPT 式自回归模型逐词生成不同，LLaDA、Dream 这类 DLM 从一段全 mask 的草稿出发，每一步并行「揭面」（去噪）若干个 token，经几十到上百步迭代收敛成完整文本。优势是双向上下文与并行生成，代价是**同一模型要被反复前向几十上百次**，推理效率问题比 AR 模型更尖锐。

**量化为什么是标配解法又为什么失灵？** 量化（把权重/激活从 16 位压到 4 位）是省显存省算力的标准手段。但近年研究发现 DLM 量化有三重独有困难：激活离群值、分布随去噪步漂移、误差跨步累积（DLLMQuant、STaR-Quant、FAIR-Calib 等分别处理）。然而这些方法有一个共同盲区——**整条去噪轨迹上激活位宽固定不变**。

**被忽略的两个维度。** T2Quant 的核心观察是：量化敏感性的分布既随**时间**（去噪步）变，也随**任务**变。数学题（GSM8K）的损伤集中在最初几个去噪窗口，代码题（HumanEval）的损伤集中在中段，知识题（MMLU-Pro）则铺得很宽。既然如此，「一路 4-bit 到底」的均匀分配必然把精度花在不疼不痒的窗口、又在真正要命的窗口欠配。同时，图像扩散领域已出现按时间步分配精度的 TMPDiff，但 DLM 的生成是离散、常不可逆的 token 提交，与图像的连续潜变量去噪本质不同——精度该给哪一步，取决于**这一步提交了哪些任务相关的 token**，这需要一个全新的信号。

## 二、论文定位和关联工作

### 2.1 TokenGate 的研究谱系

**谱系一：training-free token 剪枝（最直接的对标）。**
- FastKV（arXiv:2502.01068）：在指定的 token 选择传播层，用近端查询窗口收到的注意力给 token 打分、max-pooling 后只传播 top-K 到深层。其论文自证了一个对 TokenGate 极为有利的观察：早期层（约 ≤15 层）注意力模式高度不稳定，某层 deemed 重要的 token 下层可能完全忽略——这正说明「早期层注意力打分信号弱」不是 TokenGate 的攻击性说辞，而是 baseline 阵营自己的诊断。
- SlimInfer：多阶段（第 8/17/25 层）渐进剪枝，按 64-token 块用最后 4 个查询的注意力打分。
- GemFilter：早期层跑全量，用最后一个查询的注意力选出 top-K 后**重新 prefill**一遍选中集合——丢弃早期层的整合信息，故在代码补全类任务上退化明显。
- DASH：按隐状态层间变化率 halt「已稳定」的 token。
- 共同局限（TokenGate 的定位点）：不可训练、backbone 不协同、打分靠启发式。

**谱系二：架构级改造。** Universal Transformers、Mixture-of-Depths、Mixture-of-Recursions、ColT5 等做 token 级动态计算，但需从头预训练；Learned Token Pruning（2021）、DynamicViT、Power-BERT 等可学习剪枝需要辅助损失固定 token 预算，换预算需重训。TokenGate 与之的区别：即插即用、一次微调跨预算跨长度泛化。

**谱系三：稀疏注意力。** FlexPrefill（查询自适应稀疏模式）、MInference（离线搜索 per-head 竖线/斜杠模式）不删 token 只跳注意力块，与 token 剪枝正交。同期可学习路线 SeerAttention（arXiv:2410.13276）用自蒸馏训练的 AttnGate 学习块级稀疏模式，证实「可学习门控优于手工启发式模式」在注意力稀疏化上同样成立。

**谱系四：MoE（灵感来源）。** Shazeer 2017 的 sparsely-gated MoE 用 router 权重乘以被选专家的输出来实现参数稀疏——TokenGate 把这一招原样迁移到 token 轴：gate 值乘进注意力 logits，实现「被处理 token 的稀疏」。

**定位结论**：TokenGate 站在「training-free 剪枝易部署但打分弱」与「架构改造效果好但训练贵」的两难夹缝中，用 MoE 式梯度技巧开辟第三条路——**可训练、且训练成本仅相当于标准 LoRA 微调**。

### 2.2 T2Quant 的研究谱系

**谱系一：DLM 量化（直接基线）。** DLLMQuant 首先提出扩散感知的校准与量化；FAIR-Calib 针对脆弱去噪状态做不稳定性重加权校准；STaR-Quant（arXiv:2606.04945）用状态引导激活变换（SGAT）+ 时间注意力补偿（TAC）处理 masked/unmasked token 激活分布差异与跨步误差累积；Quant-dLLM 探索基于敏感度的混合精度。共同盲区：**激活位宽在整条轨迹上固定**——T2Quant 恰好把「精度」当作可在时间轴上自由调配的资源，且不改动这些量化器本身，可叠加其上。

**谱系二：任务感知量化（空间轴先例）。** TAQ 从小任务校准集估计层重要性、给任务相关层更高权重精度；TaCQ 保护任务相关权重回路。它们在 AR 模型的**空间轴**（层/权重）做任务感知分配，T2Quant 把同一思想搬到 DLM 的**时间轴**（去噪窗口）。

**谱系三：时间精度调度（图像扩散先例）。** Q-Diffusion 用时间步感知校准应对激活漂移；TMPDiff（arXiv:2603.14062）为图像扩散模型按时间步分配精度，假设单步量化误差近似可加，用二分搜索选调度。T2Quant 与之的质差：DLM 的 token 提交离散且常不可逆、潜变量重建误差不直接反映下游正确性、某时间步的重要性取决于它提交了哪些任务相关 token——因此不能照搬「单一全局调度」，必须逐任务校准，并把「散度」与「下游影响」相乘。

**谱系四：DLM 解码动力学。** 关于逐步预测、token 提交决策如何影响生成行为的研究（step-wise dynamics、commit-order 等）为 T2Quant 的「提交位置」信号提供了土壤。

**定位结论**：T2Quant 是「任务×时间」二维混合精度在 DLM 上的首次系统化落地，贡献组合是：一个免标签代理信号 + 一个可证最优的整数规划调度器，且与现有 PTQ 方法即插即用。

### 2.3 合并定位对照表

| 维度 | 之前的主流路线 | 本组论文的突破 |
|---|---|---|
| prefill 加速 | training-free 剪枝（不可训练）或架构改造（训练贵） | TokenGate：可训练剪枝 + LoRA 级适配成本 |
| 梯度通路 | 辅助损失固定预算 / 直通估计器 | token-gated attention 借 MoE 门值载梯度 |
| DLM 量化 | 固定激活位宽跨全轨迹 | T2Quant：按任务×窗口分配激活精度 |
| 敏感度测量 | 需标注评测或全局单一调度 | 散度×影响免标签信号，16 条提示即可 |
| 预算求解 | 启发式或指数搜索 | 整数成本动态规划全局最优 |

## 三、问题定义

### 3.1 TokenGate：把「略读」形式化

**具体场景**：输入 x = [x_R, x_D]，x_R 是请求/问题（不可剪），x_D 是请求时才到来的文档（代码库、病历、法务文件、金融报表），长达数千至数十万 token，KV cache 无法预计算。目标双目标：最大化任务精度，同时最小化 TTFT 与 prefill 峰值显存（后者限制并发与吞吐）。

**抽象洞察**：文档中并非每个 token 对回答当前请求同等重要——重要性是「请求条件化」的函数。TokenGate 的类比是「可学习 token 剪枝 ≈ MoE 的 token 轴对偶」：

| MoE | TokenGate |
|---|---|
| 稀疏对象：激活的模型参数 | 稀疏对象：被处理的输入 token |
| router 给专家打分 | gate 给 token 打分 |
| top-K 选专家（不可微） | top-K 选 token（不可微） |
| 门值乘以专家输出 → 梯度可达 | 门值乘进注意力 logits → 梯度可达 |

**形式化**：给定已预训练 backbone 与每请求文档，求一个打分网络与保留集 S（|S|=K），使得在任务损失不退化的约束下最小化上层计算与 KV cache。精妙之处在于：不把「选哪些 token」当作离散优化问题求解，而是让它作为副产品从端到端梯度训练中自然涌现——top-K 保持不可微也无所谓，只要门值的梯度存在。

### 3.2 T2Quant：把「精度预算」形式化

**具体场景**：一个已量化的 DLM 在固定任务 τ 上生成，去噪轨迹被划成 K 个有序非重叠窗口（论文取 16 个 8 步窗口）。可用激活精度档 B = {3, 4, 6, 8} bit，均匀参考精度 b₀ = 4，平均预算固定为 4.00 bit。

**抽象洞察**：窗口 w 的量化伤害 = 它扰动了什么 × 扰动的后果多重。这是一个乘法结构——扰动大但无下游影响的窗口（如末段、后面没有可影响的位置）不该加精度；影响大但量化根本不改其决策的窗口也不需要。这与经典「扰动-敏感度」分解（Pinsker 不等式）同构。

**形式化**：求调度 b_τ = (b₁,…,b_K) ∈ B^K，最大化任务指标 M_τ(b)，约束 Σ c_k(b_k) = C₀（等预算与均匀档对比）。因真实 M_τ 需带标签闭环评测，转而构造免标签代理 g_τ,k(b) = ῑ_τ,k·[κ_τ,k(b₀) − κ_τ,k(b)]（散度降幅 × 下游影响），在代理上求最优。精妙之处：**用「理论分解 motivates 的代理」替代「不可观测的真值」，再用实证相关性检验代理质量**——理论不越位，实证不悬空。

## 四、问题解法

### 4.1 TokenGate：三段式前向 + 两个组件

**前向分解**（gate 放在第 L 层）：
1. 第 0…L-1 层：标准前向，全量 N 个 token；
2. 第 L 层 gate 模块：给每个 token 打分，选 top-K；
3. 第 L+1…N_L-1 层：只处理被保留的 K 个 token（pruned forward），用 token-gated attention。

被剪 token 从不进入上层、上层也从不为其生成 KV 条目——省算力也省显存，这是机制层面的「结构性节省」而非近似。

**组件一：Gate 模块**（输入：第 L 层归一化后 post-attention 残差；输出：保留集 S）。
- 打分网络：小 MLP 读每个可剪 token 的 ǎ_j^L，输出标量，经 RMSNorm 沿序列归一化为重要性分数 b_j。非可剪 token（指令、问题、解码中 token）分数固定为 0，天然豁免。
- 关键初始化：MLP 初始化为输出全零——训练开始时 gate 是恒等（全保留），模型从「无损状态」出发逐步学剪枝。
- Top-K 选择器：S = top-K(b_j) ∪ N。

**组件二：Token-gated attention**（解决 top-K 不可微）。
基本形式：注意力权重变为 α_ij = exp(z_ij)·g_j / Σ_{j'∈S} exp(z_ij')·g_j'，其中门值 g_j = softmax(b_j)。直觉：若某 token 的额外注意力质量能降低任务损失，它会获得更大分数；起干扰作用的 token 分数被压小——打分网络由此学到 token 重要性。这与 MoE router 通过「门值乘被选专家输出」获得梯度完全同构。

两个精修（附录 D 消融均验证必要）：
- **Head-wise 增益 γ**：每个（层，头）学一个 softplus(γ) 缩放门值——不同头对门控的依赖强度不同；初始化对齐该层 logits 的标准差。
- **温度缩放 τ**：剪枝让每个 query 看到的 key 数从原位置 p_i 缩到排名 m_i，softmax 因此被人为锐化；τ = softplus(σ)·log m_i / log max(2, p_i) 可学习地重校准，是长度泛化与跨预算泛化的关键。

**训练配方**：LoRA（r=16，query/value 投影）+ gate 参数联合训练，损失 L = ½(L_Kfull + L_Kprune)：
- K_full = |P| 全保留项：锚定全上下文精度，且给每个 token（包括被采样预算剪掉的）梯度；
- K_prune ~ LogUniform(1, |P|/2)：让 gate 暴露于各种剪枝率，一个模型覆盖多预算无需重训。
- 每步到 gate 层只跑一次全上下文前向，两个分支共享计算图，开销仅来自很小的 K_prune 分支。
- 无任何辅助损失、无负载均衡项，就是标准 next-token 交叉熵。

**工程落地**（附录 A/B）：patch FlashAttention-2 支持 per-key、per-head 的 bias 向量（biased 调用成本仅为普通调用的 1.0–1.1×）；同一 kernel 在反向时把 bias 梯度累加回打分网络；推理时 pruned forward 按填充长度捕获为 CUDA graph，解码期 gate 项折叠为加性注意力掩码。

**混合架构扩展**（Qwen3.5-2B，每 4 层一个全注意力层、其余为 Gated DeltaNet）：打分网络读第 L 层 mixer 输出残差（GDN 层亦可）；token-gated attention 只施加于 gate 之上的全注意力层；GDN 层对保留集从空状态重建递归状态。FastKV 只能剪注意力层，TokenGate 能放第 1、2 层（GDN 层）——这是混合架构上额外优势的来源。

### 4.2 T2Quant：校准信号 + 最优调度器

**第一步：时间敏感度诊断**（第 3 节，回答 RQ1/RQ2）。沿均匀 A_target=4bit 轨迹，把 128 步切成 16 个 8 步窗口，测每个窗口内**提交位置**上全精度与量化模型预测分布的 KL 散度（按任务评分函数读取的位置计）。结论：GSM8K 首窗口独占 27% 任务相关散度（均匀应为 6.25%，即 4.4×），前四分之一占 55%；HumanEval 步 32–71 的五个中段窗口占 52%；MMLU-Pro 最平但窗口间仍差近 2×。

**第二步：免标签代理信号**（回答 RQ3）。
- 理论骨架（Proposition 1）：|ΔM_w|² ≤ ½·E[J_w]·E[R_w²]。J_w 是窗口提交分布（token 值+位置）因升精度而改变的 KL，R_w 是窗口不同提交下最终得分的极差。证明走 TV 距离 + Pinsker + Cauchy-Schwarz。
- J_w 与 R_w 均不可从单条无标签轨迹观测，用两个代理：
  - **K_w**（扰动）：窗口内提交位置上，全精度与量化模型预测的 KL（按提交位置数归一化）——量化还能改变这一窗口多少决策；
  - **I_w**（影响）：窗口前后两个状态下，全精度模型对**仍被 mask 的位置**信念的 KL——这一窗口的提交对后续去噪有多大杠杆。
- 排序信号 **S_w = E[K_w]·E[I_w]**，两者都从 A_target 轨迹本身算出，零标签。
- 实证：S_w 与实测窗口增益的 Pearson 相关在 GSM8K/MMLU-Pro 达 0.98/0.96（HumanEval 0.63，受测量噪声限制）；反例证明影响项不可省——纯散度在 HumanEval 上 r = −0.08，会把精度错配给「承诺无法影响任何后续 token」的末段窗口。

**第三步：多档校准 + 动态规划调度**（第 4 节）。
- 对每个任务取少量无标注提示（如 GSM8K 256 条校准池，实测 16 条已够），先跑全精度参考轨迹并保存状态；再对每个精度档 b 重放同一状态（输入态固定，隔离局部量化效应），得每窗口每档位的 κ_τ,k(b)；影响 ῑ_τ,k 在参考轨迹上算。
- 档位收益：g_τ,k(b) = ῑ_τ,k·[κ_τ,k(b₀) − κ_τ,k(b)]，b=b₀ 时为零，正值 favors 升档、负值量化降档代价。
- 调度求解：整数加性成本下动态规划 F_k(z) = max_b [F_{k-1}(z−c_k(b)) + g_τ,k(b)]，Proposition 2 证明对代理目标全局最优（复杂度 O(K·C₀·|B|)）；估计收益不足时允许退回全 b₀。推理期仅做窗口查表，零额外前向。
- 明确的诚实边界声明：最优性是对「可加代理」而言，真实下游指标一般不可加；代理是 motivated proxy 而非正式界——论文把这一区分写进了正文与证明附录。

## 五、评估指标与实验证据

### 5.1 TokenGate 的证据体系

**指标设计**：核心是一组 Pareto 前沿——「任务精度 vs TTFT」与「任务精度 vs 峰值 prefill 显存」。这两个图直接对应论文主张（不掉精度地省时间省显存），且把「快但掉点」的方法自然挤出前沿。

**实验设置**：Qwen3-1.7B 主实验；5 个任务覆盖 5 种能力面：RepoBench-P（跨文件代码补全，edit similarity，500 样本均值 11.0k token）、2WikiMultihopQA（多跳 QA，token F1，均值 7.5k）、MultiNews（多文档摘要，ROUGE-L，均值 2.7k）、BioDEX（全文 biomedical 论文药物不良反应抽取，集合 F1，均值 4.5k）、NIAH 16k（大海捞针检索，EM）。所有 baseline（FastKV 默认层+层1、SlimInfer、GemFilter、DASH、FlexPrefill、MInference）跑在**同一 LoRA 收敛微调的底座**上——控制变量干净：唯一的差别是剪枝方法本身。

**主结果**（Qwen3-1.7B，A100，batch 1）：

| 对比对象 | TTFT 加速 | 峰值显存降低 |
|---|---|---|
| vs 标准 prefill（全上下文） | 1.4–11.3×，精度无退化 | 1.5–3.4× |
| vs 次优 baseline | 1.2–6.4× | 至 2.1×（摘要表述为 2×） |

- 图 1d 锚点：2WikiMultihopQA 上取 95% 全上下文质量，TTFT 快 3.0×、显存省 2.7×。
- 混合架构 Qwen3.5-2B（NIAH 32k）：L3（首个全注意力层）匹配全上下文精度下 3.8× 低 TTFT、较最优 FastKV 2.1×；放更低层（L1/L2，GatedDeltaNet）可达 7.8× 加速、精度差 <6%。
- 长度外推（表 3，16k 训练模型直测）：NIAH 16k/32k/64k/128k 分别 11.3×/12.8×/13.0×/13.0× 加速，显存稳定 3.42–3.43× 降低——一次训练跨长度成立，且上下文越长加速越大。
- 训练开销（表 2）：单步 1.3× 慢（双预算采样所致），但 5 任务中 4 个更早收敛，总时长均值 0.8×（SFT 2.2h vs 1.8h，A100 小时）。

**消融**（区分「指标好看」与「机制成立」）：
- **可训练选择器**：同预算下 trained selector 全面显著优于 Random-K 与 FastKV selector（尤其同层对比 FastKV@Layer1）——证明学到的选择任务自适应；
- **Co-adaptation**：给 TokenGate 模型套 Random-K 选择，仍高于 LoRA 基座 + Random-K——backbone 在联合训练中学会了把信息重新分布到 token 中，对剪枝更鲁棒；
- **设计项**：去掉全上下文损失项伤害最大（全上下文精度崩）；去温度缩放、去 head-wise 增益均致 Pareto 次优；
- **gate 层位**：Layer 0 的 post-attention 残差信号不足（Pareto 劣势），Layer 1/2 均在前沿——「第 1 层信息已足够」。
- **可解释性证据**（附录 E，首 8 个样本的定性模式）：保留 token 全局分布（每个十分位都有），不是 recency 窗口；NIAH 中 needle 句 24 个 token 有 21 个进入 64 个保留集（保留率仅 0.4%）；QA 保实体/年份、代码保语法结构 token（多数保留 token 不含字母，作结构锚点）、MultiNews 保功能词但欠保专名（对应其失败模式：事件对但人名地错）。

### 5.2 T2Quant 的证据体系

**指标设计**：W4A4（4-bit 权重 + 4.00 平均 bit 激活）下 6 基准精确匹配率/pass@1 的非加权均值；所有行同一 sampler（温度 0、每步 4 token 低置信度 remasking）、同一提示集——配对比较。控变量极严：DLLMQuant/FAIR-Calib/STaR-Quant 均重实现在同一旋转 W4 底座上，唯一差别是激活处理。

**主结果**（3 模型 × 6 基准，表 1；摘要均值列）：

| 模型 | 最强独立基线 | + T2Quant 后最佳 | 提升 | 距 FP16 |
|---|---|---|---|---|
| Dream-7B-Instruct | 38.55（STaR-Quant） | 42.10（STaR+T2Quant） | **+6.7 点**（DLLMQuant 33.99→40.69） | 2.0 点 |
| LLaDA-1.5-8B | 44.09（STaR） | 45.22 | +3.4 点 | 2.5 点 |
| LLaDA-8B-Instruct | 43.36（STaR） | 44.76 | +3.5 点 | 1.6 点 |

- 9 个「基线×模型」组合全部提升；42/54 基准级对比改善，GSM8K 与 ARC-C 在全部组合改善。
- 最大单项恢复：Dream GSM8K 从 35.55→53.52（DLLMQuant 上叠 T2Quant）、46.09→58.79（STaR 上叠）；GSM8K 在 LLaDA-1.5/8B 上分别 +9.6/+10.4 点。部分基准甚至追平或超过 FP16。
- **分配正确性反证**：同预算随机调度在 Dream 上比原基线还低 14–19 点——混合精度本身不保证收益，把精度给对窗口才有效。这是「随机对照」式的关键证据。

**消融**（LLaDA-8B GSM8K：uniform W4A4 44.1 → T2Quant 49.4，FP16 52.9）：
- 校准规模：16 条提示恢复约 75% 全量增益，且调度稳定优先早期窗口；代理与全量代理相关 r ≥ 0.96；
- 迁移：调度在 4→2 token/步下保持约 5 点优势；8 token/步时整体退化、增益消失（适用边界）；
- 预算：3.75 bit 的 T2Quant（48.4%）反超 4.00 bit 均匀 W4A4（44.1%）——**会分配比多给 bit 更值钱**；超过 4 bit 后边际收益可忽略；
- 窗口粒度：16 步/窗到单步/窗精度差在 1.7 点内（47.7→49.4）——调度只需少量决策；
- 8-bit 窗口数：分配自选 m=2 最优，强制 m=1/3 损失 1.0/3.5 点；
- 档位集：{3,4,6,8} 换成 {3,4,5,6,7,8}，36 格均值仅 45.7→46.3——对中间档位不敏感；
- 其他预算：W8A8 下均匀已饱和、调度近乎 no-op（唯一 +3.5）；W4A3 均匀崩溃（Dream ARC-C 46.9→5.3），T2Quant 用 {2,3,4} 档恢复至 77.5–78.9（最多 +32 点）——预算越紧，分配的价值越大；
- 代理变体（表 3）：纯散度 HumanEval r=−0.08；纯影响 0.98/0.93/0.66（排序能力大部分来自 I_w，但定价每个精度档需要散度项）——两因子乘积是「排序+定价」的完整结构；
- 跨模型稳定性（附录 A）：LLaDA-1.5 与 LLaDA-8B 的窗口 profile 相关 0.99/0.98/0.92——时间敏感度在偏好对齐后存活；Dream 架构不同，profile 峰值位置不同（HumanEval 峰在步 96–104），佐证「调度必须按模型×任务校准」。

**诚实的留白**：量化为模拟实现（量化整数值在 bf16 算术中运算，是 PTQ 研究的标准协议），硬件实测延迟/能耗与安全性影响明确列为未来工作。

## 六、效果优势的根源解释

### 6.1 TokenGate：为什么可训练剪枝在结构上必然更好

**因果链**（每步标注证据等级）：

1. **方法差异**：training-free 方法用早期层注意力启发式打分且 backbone 冻结；TokenGate 用端到端训练的打分网络 + 联合 LoRA 微调。【方法事实，论文实验已支持】
2. **机制变化 A——打分信号质量**：早期层注意力本身不稳定、信号弱（FastKV 自己的层位分析：过早剪枝导致 logit 大偏差，其 TSP 层要靠校准选在第 15 层左右避开早期层；CLAA arXiv:2602.16054 进一步显示单层注意力排名与跨层聚合/oracle 有稳定差距）。TokenGate 的打分网络直接以任务损失为监督，且读的是第 1 层 post-attention 残差并配合 backbone 重分布信息，学到的是「对任务有用的全局选择」——QA 保实体日期、代码保结构锚点、NIAH 以 0.4% 保留率锁住 needle 句 21/24 token。【前半句：baseline 侧外部证据支持；后半句：论文附录 E 实验已支持】
3. **机制变化 B——co-adaptation**：token-gated attention 提供的梯度通路让 backbone 在训练中主动适应剪枝后的输入分布（Random-K 对照：TokenGate backbone + 随机选择仍胜 LoRA backbone + 随机选择）——信息被重新分布到幸存 token 里，剪枝从「信息丢失」变成「信息压缩」。【论文实验已支持；「重新分布信息」的具体机制为阅读者推测，论文原文用 likely】
4. **指标提升**：同等精度约束下可用更小 K → 上层计算与 KV cache 更小 → TTFT 1.4–11.3× / 显存 1.5–3.4× 的结构性节省；相对次优基线 6.4×/2.1×。【论文实验已支持】

**反事实推理**：去掉可训练性（Random-K 或 FastKV selector 套在同一 backbone）精度大幅下滑；去掉 co-adaptation（LoRA backbone + 任意 selector）同样下滑；去掉双预算采样中的全上下文项则全上下文精度崩——三个部件的必要性都被消融钉死。

**外部相关工作对照**：

| 研究 | 相似尝试 | 相关结论 | 与本文差异与适用边界 | 对根源解释的影响 |
|---|---|---|---|---|
| FastKV（arXiv:2502.01068） | 注意力启发式 token 选择传播 | 自证早期层注意力不稳定，需校准选层避开；training-free 可达 1.82× prefill 加速 | 无训练；依赖注意力信号质量 | 支持「启发式信号弱」这一前提（来自对立阵营的佐证） |
| CLAA（arXiv:2602.16054） | 跨层注意力聚合改进 token 排名 | 单层排名不稳定是瓶颈，聚合逼近 oracle | 仍为 training-free 排名修正 | 补充支持：排名质量是 training-free 路线的根本天花板 |
| SeerAttention（arXiv:2410.13276） | 可学习门控预测块稀疏注意力（自蒸馏训练 AttnGate） | 可学习模式优于手工启发式（MInference 等），块级 kernel 7.3× 加速 | 稀疏化注意力块而非剪 token；蒸馏目标为自注意力图 | 方法相似+结论相近：另一轴（注意力稀疏）上独立验证「学习式门控 > 启发式」 |

| Mixture-of-Depths / ColT5 等 | token 级自适应计算 | 需从头预训练或辅助损失锁预算 | 训练成本高、预算不灵活 | 反向对照：界定 TokenGate「即插即用」定位的稀缺性 |

**综合判断**：①「早期层注意力启发式是弱信号」由对立方法（FastKV）与第三方改进（CLAA）共同支持，证据充分；②「可学习门控优于启发式」在 token 剪枝（本文）与块稀疏注意力（SeerAttention）两个轴上收敛，属多研究共同支持的机制；③「backbone 重分布信息」目前只有 Random-K 对照的间接证据，具体机制仍属合理推测；④优势的适用条件——任务有训练集可微调（5 任务均 10k–45k 训练样本）、输入呈「请求+文档」结构、文档请求时才到达；对无标注冷启动场景或前缀可缓存场景（如系统提示词复用）不适用，论文也明确将 KV cache 剪枝等正交优化排除在外。

### 6.2 T2Quant：为什么按任务×窗口分配精度必然优于均匀分配

**因果链**：

1. **方法差异**：现有 DLM 量化器（DLLMQuant/FAIR-Calib/STaR-Quant）整条轨迹固定激活位宽；T2Quant 用 S_w 信号在等预算下重分配。【方法事实】
2. **机制变化 A——预算投向**：任务相关散度高度非均匀（GSM8K 首窗 27% = 4.4× 均匀；HumanEval 中段 52%），而 4-bit 量化损伤恰恰集中在这些窗口（Dream GSM8K 从 FP 的 44.05 掉到 DLLMQuant 的 35.55，损伤即证据）；把 8-bit 给对窗口、3-bit 给不敏感窗口，等于在不增加平均预算的前提下把损伤按任务定制地买回来。【诊断实验 + 主表实验已支持；「买回损伤」的窗口级机制由图 3 的 r=0.98/0.96 相关支持】
3. **机制变化 B——两因子乘积的必要性**：纯散度会把精度错给末段窗口（HumanEval r=−0.08：末段散度大但其提交无法影响任何后续位置）；影响项补上「这些决策值多少钱」的维度。随机调度在 Dream 上反落后基线 14–19 点，证明混合精度是双刃剑、信号质量决定成败。【论文实验已支持】
4. **指标提升**：9/9 组合平均精度提升、最多 +6.7 点；3.75 bit 反超 4.00 bit 均匀——「分配 > 堆 bit」。【论文实验已支持】

**外部相关工作对照**：

| 研究 | 相似尝试 | 相关结论 | 与本文差异与适用边界 | 对根源解释的影响 |
|---|---|---|---|---|
| TMPDiff（arXiv:2603.14062） | 图像扩散按时间步分配精度 | 时间混合精度在同速下提升感知质量 10–20%；假设误差近似可加并实证 | 连续潜变量+全局单一调度+有参考图像可算 SSIM；DLM 提交离散不可逆、无像素参考 | 方法相似+结论相近：时间轴分配价值在另一模态独立成立；同时反衬 DLM 需任务条件化（TMPDiff 无任务维度） |
| STaR-Quant（arXiv:2606.04945） | DLM 状态-时间一致量化（SGAT+TAC） | masked/unmasked 激活分布不同、误差跨步累积需补偿；W4A4 比基线 +2.78（LLaDA-8B） | 空间/变换侧补偿，位宽仍固定 | 支持「时间维度重要」；且作为 T2Quant 的最强宿主之一，叠加增益（38.55→42.10）证明两轴正交互补 |
| DLLMQuant（arXiv:2508.14090） | 扩散感知校准 | 去噪状态采样校准优于静态校准 | 校准分布改进，不改变位宽分配 | 同上：正交可叠加（33.99→40.69） |
| TAQ / TaCQ（arXiv:2511.06516 / 2504.07389） | AR 模型任务感知量化（层/电路轴） | 量化预算最优分配依赖任务 | 空间轴、AR 模型 | 支持「任务感知分配」普适前提；T2Quant 是其在 DLM 时间轴的对偶 |
| Q-Diffusion（ICCV 2023） | 时间步感知校准（图像） | 激活分布随时间步漂移需分桶校准 | 校准侧而非调度侧 | 支持「时间步异质性」这一物理前提 |

**综合判断**：①「敏感度非均匀且任务依赖」由本文三模型诊断 + LLaDA-1.5/8B profile 相关 0.92–0.99 的一致性支持，且与 STaR-Quant/Q-Diffusion 对时间异质性的独立观察相容——多研究共同支持；②「散度×影响乘积是正确的分配信号」有 Proposition 1 的动机 + r=0.96–0.98 的实证 + 纯散度反例（−0.08）三重支撑，但 HumanEval 上 r=0.63 提示代理在代码任务上仍有噪声，属「机制成立、精度有限」；③适用条件：去噪窗口可清晰划分、任务有代表性无标注提示（少量即可）、预算紧张时收益最大（W4A3 恢复 32 点 vs W8A8 近乎 no-op）；可能失效条件——8 token/步等每步提交过多导致整体退化的采样配置、以及 Dream 所示不同架构 profile 不可迁移（必须逐模型校准）。④硬件延迟与能耗实测缺失，混合精度的真实加速比尚无端到端证据，这是当前证据链的最大缺口（论文自认）。

**两篇合并的共同根源**：两者都把推理预算从「均匀摊派的静态资源」改造成「以任务信号为导航的动态分配」——TokenGate 的导航信号靠端到端梯度学出来（哪个 token 值得算），T2Quant 的导航信号靠免标签诊断测出来（哪个窗口值得给精度）。指标提升都来自「同等预算下错误分配的消除」，且各自都有随机/均匀分配的对照实验直接量化了「错误分配的代价」（TokenGate 的 Random-K 消融、T2Quant 的随机调度落后 14–19 点）。

## 七、必要知识反推

假设一个完全没有背景的人要复现这两项工作，最少必须掌握什么？

### 7.1 领域知识层

- **Transformer 前向的逐层解剖**（TokenGate）：residual stream、post-attention 残差、LN 的位置——打分网络读的是第 L 层 post-attention 残差，不理解残差流结构就无法放置 gate；
- **Prefill/decode 两阶段与 KV cache 机制**（TokenGate）：不懂「被剪 token 不生成 KV 条目 = 省显存」这条物理因果，就无法论证收益来源，也不会理解为何排除 decode 侧 KV 剪枝变量；
- **注意力 softmax 的数值性质**（TokenGate）：剪枝改变 key 集合大小会锐化 softmax——没有这份敏感就设计不出温度缩放，长度外推（16k→128k）也不会成立；
- **扩散语言模型的去噪与 token 提交机制**（T2Quant）：并行揭面、低置信度 remasking、EOS 规则差异（Dream 的 EOS 处理三种方案对比）——「提交位置」「仍 mask 位置」这些信号定义完全建立在对采样器的理解上；
- **量化基础**（T2Quant）：per-token 动态激活量化、clip 比例、旋转（QuaRot）、GPTQ——不知道这些就无法搭建公共 W4 底座，也无法理解「模拟量化」的实验协议地位。

### 7.2 方法论知识层

- **MoE 的梯度载波技巧**（TokenGate）：Shazeer 2017 以降「top-K 不可微但门值可微」的成熟实践——这是 token-gated attention 的直接模板；不知道它的人会去发明辅助损失或 RL，成本高得多；
- **参数高效微调**（TokenGate）：LoRA 的配置惯例（r=16、目标投影层）与 Muon 优化器——训练配方的工程底座；
- **信息论分解**（T2Quant）：TV 距离、Pinsker 不等式、Cauchy-Schwarz——Proposition 1 的三行证明全部由这些经典工具拼装；
- **动态规划与最优性原理**（T2Quant）：整数背包的区间 DP 写法与回溯——Proposition 2 是教科书级应用，但必须知道「可加性是 DP 正确性的前提」才能诚实地把保证限定在代理目标上；
- **相关分析与采样噪声**（T2Quant）：Pearson r、bootstrap 置信区间、量化种子引起的方差（窗口实验按 1/5/10 个种子平均）——代理信号的可靠性检验全靠这些。

### 7.3 工程知识层

- **FlashAttention kernel 结构与 patch 能力**（TokenGate）：知道 fused kernel 不接受任意 score bias、如何在线 softmax 中插入 per-key bias、backward 如何累加 bias 梯度；CUDA graph 捕获、padding 对齐 64、−10⁹ 掩码——没有 kernel 级手艺，1.0–1.1× 的 biased call 成本无法兑现，方法会被实现开销吃掉；
- **对照实验的隔离设计**（两篇共用）：TokenGate 把所有 baseline 跑在同一微调底座、禁用双方都有的 KV 剪枝选项；T2Quant 把三个基线重实现在同一旋转底座、同一 sampler、同一提示集、配对显著性检验——「只让被测变量动」的纪律是全部结论可信的根基；
- **基准与任务构造**：LongBench 系任务的指标定义（edit similarity、token F1、ROUGE-L、集合 F1）、去污染（2Wiki 训练集用全维基重建并去污）、校准/评测池严格分离。

### 7.4 知识融合的关键节点

- **节点一（TokenGate）**：把「MoE 门值载梯度」与「prefill 成本结构（上层计算与 KV 均随保留集缩减）」在 token 轴上焊接——两个各自成熟的知识在「被处理 token 的稀疏」这一点上发生化学反应，产生了不需要辅助损失的可训练剪枝。
- **节点二（TokenGate）**：softmax 锐化（数值现象）× 温度缩放（校准工具）× 位置/排名对数比（SSMax 启发）——三者的组合是跨预算、跨长度泛化的隐藏支柱，缺一个都只能训练出单点模型。
- **节点三（T2Quant）**：把「量化扰动」（K_w）与「下游杠杆」（I_w）相乘——乘法结构来自 perturbation-sensitivity 分解的理论直觉，但真正让它落地的融合点是「两者都能在一条无标签轨迹上便宜地测出来」。理论给形状，可观测性给生命。
- **节点四（T2Quant）**：把「预算约束调度」识别为整数加性成本问题从而 DP 全局最优——若成本非整数或目标不可加，保证即失效；作者对这一边界的自觉标注，是方法论严谨性与工程可行性的融合点。

## 八、论文中可以提取的通用性灵感

### 灵感一：门值乘法——绕过不可微选择的通用梯度载波

- **核心思想**：对任何含离散选择（top-K/hard routing）的系统，把选择分数的（可微）变换乘进被选对象参与计算的通路，梯度即可穿过离散选择器，无需辅助损失或 RL。
- **论文证据**：token-gated attention 中 g_j = softmax(b_j) 乘进注意力 logits 后，标准交叉熵即可端到端训练打分网络；MoE 十年实践（Shazeer 2017→Fedus 2022）在参数轴上验证同一技巧。
- **推广场景**：(1) 检索增强系统中可学习的文档/片段选择；(2) 数据管道中学到的样本筛选（curriculum 的可微化）；(3) Agent 工具调用中学到的工具路由；(4) 视觉 token 剪枝（已有 DynamicViT 前身，可借 head-wise/温度技巧强化）；(5) 任意「先选子集再计算」的缓存策略学习。

### 灵感二：扰动 × 杠杆——资源分配的免标签双因子信号

- **核心思想**：给某环节加预算的收益 ≈ （该环节当前行为被预算改变的程度）×（该环节输出对最终结果的杠杆）。两因子都可在系统内部观测，不需要外部标签。
- **论文证据**：S_w = E[K_w]·E[I_w] 与实测增益 r=0.96–0.98；纯散度在 HumanEval 上 r=−0.08 的反例证明杠杆因子不可省。
- **推广场景**：(1) 推测解码中 draft 模型哪段的校验最值得花算力；(2) Agent 多步规划中哪一步值得调用更强模型/更多工具；(3) 主动学习/数据标注预算——「模型最犹豫且最影响下游」的样本优先；(4) 微服务链路的性能预算分配（哪一跳的延迟抖动最影响端到端 SLA）；(5) 缓存系统决定哪些内容值得预计算。

### 灵感三：均匀分配是懒惰的默认——错误分配的代价可被随机对照量化

- **核心思想**：当一个资源（算力、精度、注意力、标注预算）在异质环节间均匀摊派时，先做「随机等预算对照」：若随机重分配大幅劣于现状，说明现状已接近局部最优；若随机大幅波动，说明分配空间里埋着巨大收益。
- **论文证据**：T2Quant 的随机同预算调度在 Dream 上落后原基线 14–19 点（说明分配错误极其致命，正确分配的收益同样巨大）；TokenGate 的 Random-K 消融同理。
- **推广场景**：混合专家的容量因子设定、课程学习的数据配比、多 GPU 并行的负载切分、超参搜索的初始预算分布、时间序列预测中跨 horizon 的模型容量分配。

### 灵感四：先诊断后开方——把「测量协议」当作方法的一部分

- **核心思想**：先用可控小实验画出问题的地形图（敏感性在哪、随什么变），再让方法直接消费地形图；诊断协议本身可以零标签、零评测指标。
- **论文证据**：T2Quant 的第 3 节诊断（任务×窗口散度地图）直接定义了第 4 节方法的搜索空间；TokenGate 的附录 E「保留 token 解剖」（保什么、错在哪）把方法行为翻译成可核查的定性规律。
- **推广场景**：(1) 训练前的小规模损失地形扫描（learnability estimation）；(2) 模型合并/蒸馏前层的兼容性诊断；(3) 系统性能调优前的 trace 剖析文化；(4) 教育领域先诊断知识缺口再配练习（adaptive testing 的同构）。

### 灵感五：即插即用的适配层设计——「扩展现有资产」优于「替换现有资产」

- **核心思想**：让创新以「可叠加的小组件」形态存在：不重训 backbone、不改动宿主方法的内部、收益可单独消融、可与同类方法自由组合。
- **论文证据**：TokenGate 训练成本与标准 LoRA 持平（总时长 0.8×）且原生扩展到混合架构；T2Quant 明确 quantizer-agnostic，三种宿主量化器全部叠加增益。
- **推广场景**：数据库查询优化器 hint 的学习模块、编译器 pass 调度插件、已有评测框架的评分树外挂、开源模型的 adapter 生态。

### 灵感六：明确声明保证的边界——把「证明了什么」与「动机是什么」分开写

- **核心思想**：理论动机（motivated proxy）与形式保证（global optimality）分开陈述，并实证检验代理与真值的相关性；这比含糊的「理论上最优」更可信也更能被复用。
- **论文证据**：T2Quant 把 Proposition 1 写成 motivates-but-not-bounds，把 Proposition 2 的最优性限定在加性代理上，并用 r 值与反例完成代理的资格论证；TokenGate 对「co-adaptation 重分布信息」用 likely 措辞并配 Random-K 间接证据。
- **推广场景**：所有「代理指标↔真实目标」分离的领域——RL 的奖励设计、AutoML 的代理任务、线上 A/B 的离线预估、大模型评测的 benchmark 分数与真实能力。

## 附录：阅读提示与边界

- TokenGate 的全部实验在 1.7B/2B 量级模型上完成，更大规模模型的收益曲线论文未测；decode 阶段的 KV cache 剪枝被作者显式排除（正交优化），读者不应把显存收益外推到长生成场景。
- T2Quant 的量化为模拟实现，混合精度 kernel 的真实延迟切换开销（尤其 3/8bit 交替）未测；调度按「任务」定制，混合任务流场景需要每任务各查各的表。
- 两篇论文互为正交：TokenGate 针对 AR/混合架构的 prefill，T2Quant 针对 DLM 的去噪轨迹；一个 DLM 若同时采用（prefill 剪文档 token + 去噪窗口混合精度），两者理论上可叠乘，但尚无实验验证。
