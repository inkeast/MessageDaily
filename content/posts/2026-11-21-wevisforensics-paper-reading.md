## 一、论文背景

### 1.1 AI 生成视频检测为什么越来越难

Sora、Veo、可灵（Kling）这类视频生成模型在近两年里把合成视频的保真度推到了肉眼难辨的水平。这直接催生了对立的行业——AI 生成视频检测（AI-generated video detection）：给定一段视频，判断它是真实拍摄还是 AI 生成的。这个任务的难点不是『看出假』，而是『在别人看不出假的地方找出可验证的证据』：

- **证据转瞬即逝**：生成缺陷往往只出现在某个 1-2 秒的窗口、画面中一小块区域——比如文字的笔画中途融化、手指在快速运动时糊成一团、电缆突然打折进机身。整段视频看一遍的『一瞥式』判断很容易错过。
- **生成器迭代快**：训练时见过的伪影模式（比如某代模型的皮肤纹理特征），到下一代生成器就不存在了。检测器必须对没见过的生成器仍然有效，即 OOD（out-of-distribution）泛化。
- **证据维度分散**：判断一条视频真假可能靠视觉外观（皮肤过于平滑）、物理（水流颜色凭空变化）、常识（猫像人一样站着开车）、屏幕文字（招牌笔画变形）、音画一致性（画面是年轻女性、声音却是中年男性）五六个完全不同的维度。单一模型很难同时是所有这些方向的专家。

### 1.2 现有方法的两代范式与共同瓶颈

第一代是**二分类检测器**：训练一个分类网络输出真/假分数。它的问题是只给结论不给理由，且对未见生成器泛化差——论文表 4 里 NSG-VD、ReStraV 这类方法平均准确率仅在 50-57% 徘徊，接近瞎猜。

第二代是**基于多模态大模型（MLLM）的可解释检测**，又分两支：

- **单遍思维链（CoT）派**：BusterX/BusterX++、VideoVeritas、Skyra 等让 MLLM 对整个视频做一次推理、输出自然语言解释加判决。问题是『一个模型管所有伪影类型』的单遍推理容易被幻觉解释带偏——论文图 13 给了个扎心例子：某 CoT 检测器声称『人物在 3.5 秒突然切换姿势』，视频里根本没有这回事；而一条自由格式的推理链也没法逐条监督和审计。
- **多 agent 工作流派**：ARGUS、Deepfake-Agent 等把检测拆成『多个专家观测 + 裁判汇总』。ARGUS 用纹理、光照、运动、物理四个观测 agent 各写报告，再训练一个 Judge 汇总。但它的工作流是固定的——不管视频是什么，四个观测全部跑一遍；更关键的是**训练 Judge 时观测 agent 是冻结的**。论文点出了这类方法的根本瓶颈：*一个看不见细微线索的冻结检查器，是任何更高明的路由和汇总都无法弥补的证据瓶颈*。就好比侦探再会分配任务，法医化验不出毒物，案子还是破不了。

Tool-augmented 一支（TUE-Detector、OmniVL-Guard Pro 等）学会了按需调用工具，但工具后端同样固定，本质没变：**取证能力本身不随系统经验增长**。

### 1.3 这篇论文要解决的核心矛盾

把检测做成一个会自主调查的 agent 系统，需要同时学两样东西：调查者要学『问什么、看哪段、何时收网』（调查策略），检查器要学『把曾经放过的问题报出来』（取证能力）。但这两者是互相缠绕的——调查者决定检查器见到什么输入，检查器的回答又决定调查者后续怎么走。如果两边每个 batch 都同时更新，彼此就成了对方的移动靶标（non-stationarity），训练会震荡。这就是 DTPO（双时间尺度策略优化）要解决的核心矛盾，也是本文最深刻的贡献。

## 二、论文定位和关联工作

### 2.1 研究谱系

本文站在三条研究线的交汇点上：

**谱系一：MLLM 视频取证检测器（学习对象与对比基线）**

| 工作 | 发表 | 核心思想 | 与本文关系 |
|---|---|---|---|
| BusterX/BusterX++ | arXiv 2025 / NeurIPS'26 | MLLM 统一图+视频检测与解释，纯 RL 训练；提出 GenBuster-Bench/++ 基准 | 本文用其基准做 ID/OOD 评测；其单遍 CoT 范式是本文批评对象 |
| VideoVeritas | ICML'26 | 感知代理强化学习（PPRL），用时空定位、目标计数等前置任务提升细粒度感知；提出 MintVid 数据集 | 此前最强检测器（平均 86.2%），本文主要对比对象（95.2%，+9.0pp） |
| Skyra / VidGuard-R1 / VidForensics-M1 | CVPR'26 / ICLR'26 | 伪影定位、RL 推理、时序落地奖励 | CoT 派内部演化，仍是单模型单遍推理 |
| ARGUS | arXiv 2608.06865 | 四观测 agent + Judge 多智能体取证，Judge 用 GRPO 训练但观测者冻结 | 本文直接继承其多 agent 思想，核心区别在于让子 agent 也进化 |

**谱系二：agent 训练方法（方法论来源）**

- **GRPO**（DeepSeekMath 提出）：PPO 的免 critic 变体，同题采样一组回答、以组内平均为基线算优势。本文快尺度用它更新调查者。
- **特权信息蒸馏**（Privileged Information Distillation，ICML'26 π-Distill 一脉）：训练时教师模型可看额外信息（如答案位置），推理时学生模型没有——教师把『看过答案后怎么答』的能力蒸馏给学生。本文慢尺度的 OPD（特权蒸馏）直接引用了这条线。
- **Mean Teacher / EMA 教师**：半监督学习经典技巧，教师参数用学生参数的指数滑动平均，提供稳定的学习目标。本文用它稳住慢尺度的检查器蒸馏。
- **Voyager 的 skill card**：给 agent 挂一张可增长的经验规则卡。本文让每个检查器维护一张 Report/Ignore 规则卡并由反思器模型修订。

**谱系三：双时间尺度学习**

双时间尺度优化在控制论（奇异摄动）里是经典思想：两个耦合的变量用不同学习率/更新频率优化，快变量在慢变量构成的环境中近似平稳地收敛。2025-2026 年这条线在 LLM agent 领域集中涌现：TacoMAS 在测试时快更新能力、慢更新拓扑；ReMA 用 planner/executor 交替冻结更新；MetaSkill-Evolve 区分任务技能（快）与元技能（慢）。DTPO 把这一思想带进了取证 agent 的两级共演化。

## 三、问题定义

### 3.1 从具体场景到抽象问题

**具体场景**：怎么让一个多 agent 视频取证系统既能自适应地决定检查什么，又能让每个检查器越来越准？

**核心洞察**：调查者与检查器构成一对『教学相长』的共生系统——调查者发出的每一次调用，天然构成检查器的训练课程（curriculum）：它决定了检查器见到哪些输入、哪些时间窗、哪些难度。反过来，检查器的报告质量决定调查者能学到多好的路由策略。这不是两个独立的优化问题，而是一个**双层耦合优化问题**。

**类比**：像医院里主治医师（调查者）带着一群专科检查技师（检查器）会诊疑难病例。医师根据初步印象决定『先做心电图、再查血』，技师的水平决定了检查报告的质量；而技师见得最多的恰恰是医师最常开的那些检查——医师的处方习惯就是技师的病例谱。如果医师和技师每天互相根据对方调整（今天改处方、明天改手法），双方都无所适从；合理的方式是医师的诊疗策略每周微调（快尺度），技师团队则按季度根据『实际做过的检查』系统性进修（慢尺度）。

**形式化**：给定视频 x、标签 y、由主策略 πθ 和检查器库 {pϕs} 组成的系统，求

- 快变量 θ：调查策略，最大化轨迹奖励 R(τ)（判决正确性）+ 调用级反馈 + 工具覆盖 F1；
- 慢变量 ϕs：各检查器，最小化基于交互调用的蒸馏损失；
- 约束：两者共享同一批交互轨迹作为训练信号；更新节奏解耦（θ 每 batch 更新，ϕs 每 H=20 步更新一次），使得快变量在慢变量构成的『准平稳环境』中学习。

**精妙之处**在于形式化了『调用分布即课程』：DOPD（数据选择规则）规定只有落在标注伪影区间内的调用才进入检查器的训练池——调查者自然会把大量调用投向它认为可疑的区间，而这些恰好是检查器最该学会识别的地方。系统的探索本身成为数据引擎，这是单层优化在结构上做不到的。

## 四、问题解法

### 4.1 推理框架：调查协议（Investigation Protocol）

系统像侦探破案一样工作。开局先看全局概览：全片约 1 FPS 采样、最多 16 帧、带绝对时间戳，加上时长和有无音轨的标记。之后每一轮，主 agent 输出一条结构化消息：一段推理（当前假设、已有证据确立了什么/没确立什么、为什么下一步检查有价值）加一个动作。动作三选一：

1. **调哪个检查器**：从 FSL 六位成员中选一位；
2. **看哪段时间窗**：视觉检查器带 [ts, te] 窗口参数，OCR 带单个时间戳，音频工具全轨无参；
3. **是否收网**：发起 answer(real/fake)。

协议规则（论文式 3）：最多 4 次调用、不许重复同一调用、时间窗必须在视频内、无声视频禁调音频工具；至少成功调用一次才能给判决。格式错误或违规的轨迹直接记 0 分。系统还被要求选择**最小充分**的检查集——明显的局部伪影一次调用就够，而不是每次都打满预算。这样单次调查最多 5 轮，平均只用约 2.2 次调用。

### 4.2 取证子 agent 库（FSL）

| 成员 | 检查什么 | 输入 | 输出判决 | 是否进化 |
|---|---|---|---|---|
| 视觉外观 | 纹理稳定性、发丝/手指/牙齿等细节完整性、光照阴影反射的时空几何一致性 | 窗口内 2 FPS 帧 | issue / no_issue / inconcl. | 是（LoRA+技能卡） |
| 物理一致性 | 生物运动学、身体与刚性物体结构、遮挡下物体恒存性、接触与抓握、流体形变动力学 | 窗口内 2 FPS 帧 | issue / no_issue / inconcl. | 是 |
| 常识 | 因果关系、物体角色与情境一致性、可供性（affordance）、事件顺序 | 窗口内 2 FPS 帧 | issue / no_issue / inconcl. | 是 |
| OCR 一致性 | 屏幕文字字形完整性、笔画融合/断裂/漂移 | 单帧+文字裁剪 | text_ok / suspicious / no_text | 是 |
| 语音画像 | 说话人分离、年龄/性别/情绪估计 | 全音轨 | 描述性报告 | 否（固定测量工具） |
| ASR 分析 | 转写+词级时间戳，检查机器人式均匀节奏等异常 | 全音轨 | timing anomaly / natural | 否 |

三个设计原则贯穿其中：**(i) 规划与感知分离**——调查者决定查什么查哪里，检查器只判断自己专业内的伪影是否存在；**(ii) 证据角色分解**——每份报告只含判决+校准置信度+落在检查窗口内的时间戳引用，可独立审计、独立监督、独立记功；**(iii) 可进化组件与测量工具分离**——视觉伪影随生成器迭代变化最快，所以四个视觉检查器可进化；音频工具输出的是『测量值』（说话人属性、转写文本），含义不应漂移，保持冻结。

OCR 检查器值得一提：文字只占画面一小块，整帧缩放送进 VLM 会丢失笔画细节，所以它是三段流水线——PaddleOCR 定位候选文字行 → 模型判断哪些是真文字（防止 OCR 在纹理和人脸上误触发）并选最多 6 个区域 → 高像素预算裁剪逐个检查字形，判决必须落在至少一个『可见生成缺陷字形』的裁剪上才能报 text_suspicious。这条规则（论文式 7）防止凭空指控。

报告解读纪律也很讲究：inconclusive 被调查者视为『如实记录能力局限』的中性证据，绝不当暗中的判假信号；no_text、工具失败、纯描述性音频画像一律中性；一个窗口的 no_issue 不能推出全片为真，最终判决必须综合所有调用。

### 4.3 DTPO：双时间尺度策略优化

**类比先行**：DTPO 就像经济发展中『市场（快）与产业政策（慢）』的双轨调节。市场每个交易日都在出清价格（调查者每个 batch 用 GRPO 更新），产业结构则按季度根据市场实际交易数据规划调整（检查器每 20 步从真实调用中蒸馏进化）。市场为产业提供真实需求信号，产业升级又改善市场供给——两轨不同速，所以互不为对方的移动靶。

**快尺度：调查者 GRPO + CLUE**

每个视频采样 G=4 条调查轨迹，轨迹奖励只有对错（式 4）。GRPO 组内标准化得优势 Âg（式 9）。但结局奖励不告诉你**哪次调用**有贡献——就像球赛赢了不知道哪脚传球是关键。于是论文提出 **CLUE（Call-Level Utility Estimation，调用级效用估计）**：用一个冻结的基础 Qwen3.5-4B 参考模型，分别在每次调用的回答加入历史的前后，计算它对正确标签的支持度，CLUE 分数 cj 就是前后对数概率之比（式 10）。回答把参考模型推向正确标签则 c 为正，误导则为负。关键是参考模型既不是调查者也不是检查器，所以它衡量的是**证据本身的信息量**而非策略自己的信念。CLUE 在 GRPO 组内中心化后按权重 λ=0.2 加到调用动作 token 的优势上（式 11），最终答案 token 仍用结局优势。

此外还有**工具覆盖奖励**：每条训练视频带有验证过的『相关取证角色集』，轨迹实际调用的工具集与该集合的 F1 以 0.3 权重并入优势。防止系统靠无关检查碰对答案的捷径。

**慢尺度：检查器的三步进化**

1. **调用筛选与分诊**。训练中的每次检查器调用都是候选样本，先用 DOPD 规则落地（式 12）：只有调用窗口与该角色标注伪影区间有交集的才保留——在没伪影的窗口找不到伪影不是检查器的错。然后按判决×视频标签分诊：真视频上报 issue=误报，假视频报 no_issue=漏检；还有一类隐蔽失败叫 **hedge（含糊）**：判决碰巧正确但 CLUE 分数低于 κ=-0.05 且说得不确定——这种报告给调查者提供不了可用证据，也要改。
2. **特权蒸馏（OPD）**。EMA 教师比学生多看到『特权上下文』g：真视频 g 直接给标签；假视频 g 给出该窗口内标注的伪影区间，指示教师『在帧里找到这个异常』。教师在学生实际采集的回答前缀上给出 token 分布，学生用 KL 散度对齐（式 14），另加一个只对比两个相反判决 token 的标签校正项（β=1）——专门纠正误报/漏检的判决方向，而不压制 inconclusive 选项。教师的特权只当『往哪看的提示』，不当证据用，学生推理时依然看不到任何特权信息。EMA 率 ρ=0.001 保证教师缓慢跟随学生，蒸馏目标稳定。
3. **技能卡演化**。有些失败更适合写成明规则（『快速移动的手部动作模糊不是结构缺陷』），而不是改权重。每个可进化检查器带一张 Report/Ignore 规则卡，每轮蒸馏后由冻结的反思器 LLM 审查近期仍判错的调用、提出规则修改；候选卡只有在保留集上『多对不错』（不能牺牲任何一类的正确判决）才被接受——单调接受条件防止反思器拆东墙补西墙。

每 H=20 个调查者步，同步屏障检查各角色队列样本是否够量，够的角色执行蒸馏+改卡+发布新 FSL 快照，不够的留着下个周期。刷新后的检查器回到后续 rollout，闭环完成。工程上用 vLLM 多引擎异步服务调查者与检查器，音视频工具独立部署，整训一天内完成。

### 4.4 ForenCue-30K 数据集与 AgenticCue 基准

监督数据的结构性缺失是本文另一个动因：既有数据集只有视频级判决或整段解释（GenBuster-200K 甚至只有标签），既没有角色级证据也没有协作轨迹。ForenCue-30K 补齐三层监督：

| 组成 | 规模 | 内容 |
|---|---|---|
| 精选视频 | 30,000 条 | 覆盖 CogVideoX/Hunyuan/Wan/Kling/Veo3/Vidu 等 15+ 生成器 + OpenVid-1M/Koala-36M/Pexels 真实视频 |
| 角色级记录 | 117,552 条 | 外观 26,378 / 物理 32,348 / 常识 40,246 / OCR 18,580 / 音频两类；每条含判决+置信度+时间区间+帧落地解释 |
| 交互轨迹 | 33,896 条 | 由『轨迹规划器选角色选窗口 → 真实执行调用 → 基于真实返回写推理』组装，学生端消息剥离一切训练特权信息 |
| RL 池 | 7,500 行 | 3,750 真 + 3,180 假（加权重复），每条带伪影区间与相关角色集，支撑 DTPO |

质量上采用 rubric 条件化 VLM 标注 + 跨家族 VLM 交叉验证 + 人工抽检的流水线，340 条视频-角色标注人工审计 99.1% 有视觉证据支撑；100 条轨迹人工审计 96.0% 工具选择恰当。

**AgenticCue 基准**填补另一空白：既有基准只打最终判决分，一个靠无关检查碰对答案的 agent 完全暴露不出来。AgenticCue 按五类取证类别（视觉/物理/OCR/常识/音频）各组 500 条验证过含该类伪影的生成视频 + 共享 500 条真实视频，目标生成器全是训练没见过的最新商用模型（Veo 3.1、Kling 2.5/3.0、Sora 2 等）。除类别准确率外，还定义了**调用精度（invocation precision）**：agent 调用工具 s 的视频里有多大比例真的需要角色 s。这里有个反直觉的基率细节：对每个视频都调全部工具的固定流程，调用精度只有基率水平（外观 91.1%、物理 78.6%、OCR 49.2%、常识 24.0%、音频 21.5%）——ARGUS 的物理角色精度上限就被锁死在 78.6%。

## 五、评估指标与实验证据

### 5.1 指标体系

- **主指标**：四个基准上的二分类准确率——GenBuster（ID 域）、GenBuster++（OOD）、MintVid General 六个生成器类别均值（OOD）、AgenticCue 五类均值（OOD + 主动调用），四者再取平均。
- **证据质量指标**：子 agent 证据 F1——用角色级标注（两名跨家族 VLM 标注员独立标 + 盲判法官仲裁）给检查器的调用打分，直接衡量『证据本身』的好坏，绕过最终判决。
- **调用精度**：衡量调查者是否找对了专家。
- **消融指标**：快慢组件拆解、双层交叉组合、刷新节奏对比。

### 5.3 调用精度：找对专家

AgenticCue 调用精度（论文表 5）：DTPO 版物理 94.6%、OCR 95.4%、常识 99.7%、音频 94.3%，对比基率分别只有 78.6/49.2/24.0/21.5%——是基率的 1.2-4.4 倍。常识和音频两个低基率角色最能说明问题：盲目全调的精度上限只有 21.5%（音频），自适应路由把它拉到 94.3%。同时 DTPO 比 SFT 平均少调 12.4%（2.19 次 vs 2.50 次），且五类准确率全面提升——**更少的调用、更准的命中**。

### 5.4 消融：每个组件挣了多少分

**组件消融表**（平均准确率 %，论文表 6）：

| 配置 | 主 agent | FSL | GB | GB++ | MintVid | AgenticCue | 平均 |
|---|---|---|---|---|---|---|---|
| SFT 基线 | SFT | SFT | 93.9 | 94.2 | 83.0 | 94.3 | 91.3 |
| +GRPO（冻结库） | GRPO | 冻结 | 96.8 | 97.0 | 84.3 | 94.7 | 93.2 |
| +GRPO+CLUE（冻结库） | +CLUE | 冻结 | 96.5 | 96.9 | 84.5 | 96.8 | 93.7 |

三个观察（论文 5.3 节原文归纳）：**(1)** 只训主策略对冻结库 GRPO，收益集中在 ID 域（GB +2.9），OOD 提升微弱（MintVid +1.3、Agentic +0.4）——路由再好，冻结检查器是证据瓶颈；**(2)** CLUE 在冻结库下平均只 +0.5pp——调用级信用分配没有可进化的对象可作用时近乎空转；**(3)** 慢尺度进化打破瓶颈：GRPO → DTPO w/o CLUE 平均 +1.6pp，其中 OOD 贡献大头（MintVid +2.3、Agentic +2.7）；此时再加 CLUE 再 +0.4pp 达到 95.2。**CLUE 与进化库的搭配是乘法关系，不是加法关系**。

**刷新节奏消融**（表 7）：每 batch 都刷新检查器，六个未见生成器全面下滑（Hailuo -4.8、Kling -2.6、Sora2 -2.3，均值 -2.0pp）且训练更慢（DTPO 快 3.3 倍）；先进化后冻结的分段调度也差 2.4pp。这直接验证了双时间尺度的必要性——不是『两边都训』就行，而是要『按不同节奏训』。

### 5.5 双层交叉实验：共进化的互补性

论文表 9 的 2×2 交叉是理解本文最有说服力的实验：

| 调查者 \ 检查器 | SFT 检查器 | 进化后检查器 |
|---|---|---|
| SFT 调查者 | 91.3 | 92.0（仅进化检查器 +0.7） |
| DTPO 调查者 | 93.2（仅训练调查者 +1.9） | **95.2（双层 +3.9）** |

双层收益 3.9pp **超过两个单层收益之和**（0.7+1.9=2.6pp，超出 1.3pp）。这说明两级改进不是独立叠加，而是相互放大：训练过的调查者发出更精准的调用，进化过的检查器让每次调用更有信息量——1+1>2 的超加性（superadditivity）是共进化成立的直接证据。

### 5.6 证据本身变好了

表 8 用角色级标注给检查器调用打 F1（冻结库 vs 进化库，同样的匹配调用）：

| 角色 | GB 冻结→进化 | GB++ | MintVid | AgenticCue |
|---|---|---|---|---|
| 外观 | 97.3→98.1 | 97.1→97.5 | 79.4→86.4 (+7.0) | 95.4→98.7 |
| 物理 | 66.5→**97.8 (+31.3)** | 85.1→97.3 (+12.2) | 72.7→91.9 (+19.2) | 89.4→98.5 (+9.1) |
| OCR | 89.3→92.7 | 76.7→88.5 (+11.8) | 56.6→58.9 | 77.9→84.0 |

物理检查器是最大受益者：GB 上 F1 从 66.5% 飙到 97.8%，其 inconclusive 率从 26.9% 降到 0.3%——慢尺度的 hedge 重标注机制（把『碰巧对但含糊』的回答标记出来改）精确命中了它的病症。训练过程追踪（图 5）显示生成视频漏检率从 22.1% 降到 5.2%，判决 F1 从 80.3% 升到 93.7%。人工配对评审：200 对同调用同窗口的新旧检查器回答，进化版被偏好 65 对 vs 20 对，有缺陷回答占比从 30.5% 降到 8.0%。图 6 的定性案例最直观：一条手写文字逐渐扭曲的生成视频，SFT 检查器说『字形规则』，进化后的检查器标记出字形异常，但 SFT 主 agent 仍把它归为手绘风格判真——只有 DTPO 主 agent 把 OCR 调用移到 7 秒扭曲最明显的时刻、综合证据判假。**纠正一个错案需要两级同时进化**，这与表 9 的交叉结论互相印证。

## 六、效果优势的根源解释

### 6.1 根源机制与证据链

**因果链主线**（每步标注证据类型）：

1. **冻结子 agent 是证据瓶颈**【论文实验已支持：表 6 中 GRPO 对冻结库的 OOD 增益仅 0.4-1.3pp，而表 8 冻结物理检查器 GB F1 仅 66.5%、inconclusive 率 26.9%】。机制层面：调查者的策略优化只能重新分配『向谁提问』的概率，无法改变『回答质量』的分布上限。当关键证据（如物理伪影）恰落在最弱检查器的领域，任何路由都救不回来——这是信息源层面的硬约束，不是算法层面的次优。
2. **调查者的调用分布天然构成检查器的课程**【论文设计+实验支持：DOPD 只保留落在标注伪影区间内的调用；检查器恰在这些高价值区间上获得最密集的训练信号】。机制层面：这是把 agent 的探索行为转化为数据引擎——系统『好奇哪里』就在哪里变强。类比课程学习，但课程不是人工设计而是策略诱导出来的。
3. **特权蒸馏用『往哪看』的指针替代答案灌输**【论文机制+消融支持：教师看伪影区间后在自己找到异常的表述上给出分布，学生学习『从输入自身发现该异常』的表征；标签校正项只对相反判决 token，不压制 inconclusive】。机制层面：直接把答案当监督信号会教出『背标签』而非『看证据』；特权只改变训练时的信息结构，推理时学生仍只看输入。物理检查器 +31.3pp F1 与 inconclusive 26.9%→0.3% 是这条机制生效的直接读数。
4. **证据质量提升 → OOD 迁移提升**【论文实验已支持：表 6 慢尺度的增益集中在 OOD（MintVid +2.3、AgenticCue +2.7）而非 ID；表 8 未见生成器上物理 F1 +19.2】。机制层面的解释（部分为阅读者推测）：ID 域成绩可以靠记住训练生成器的分布特征获得，而 OOD 只能依靠更本质的取证能力（在任意窗口内识别物理异常的能力），后者恰是检查器蒸馏所训练的。换言之**慢尺度把系统从『认生成器』推向『认伪影』**——此推测与 DeCoF、SpecSem-Net 等外部工作『空间指纹脆弱、时序/物理线索更普适』的发现方向一致，但本文未直接做特征层面的归因实验。
5. **双时间尺度解耦让两级互为准平稳环境**【论文实验支持：表 7 每 batch 刷新全面掉点 2.0pp、分段调度掉 2.4pp；DTPO 快 3.3 倍】。机制层面：若两变量同频更新，检查器每 batch 变化会摧毁调查者价值估计的样本效率（刚学到的『物理检查器可信度』立刻过期），反之亦然；H=20 的节奏让调查者在固定环境中充分收敛后，检查器再吸收积累的调用经验。
6. **超加性收益证明互补**【论文实验支持：表 9 双层 3.9pp > 单层之和 2.6pp】。机制层面：更准的调用 → 调用落在伪影区间的比例更高（CLUE+覆盖奖励的作用）→ 检查器训练池的样本质量更高 → 检查器更可信 → 调查者更敢于依据单一强证据收网（平均调用数 2.50→2.19）。这是一个正向飞轮，两个单层实验各自只转动了半圈。

**反事实验证**：去掉 CLUE（表 6）平均 94.8，去掉慢尺度（GRPO 冻结）93.2，去掉两者（SFT）91.3——每个环节的移除都有可量化的退化，且退化方向与因果链预测一致（CLUE 的退化在进化库存在时才显著）。

| [Rethinking On-Policy Self-Distillation (ICML'26)](https://icml.cc/virtual/2026/77852) | 特权上下文自蒸馏对 thinking 模型的负面影响 | 特权教师会降低探索分叉率，最长预算下准确率最多掉 17% | 发现特权蒸馏在强思考模型+长推理预算下有害 | **限定**：提示特权蒸馏并非无条件有效；本文场景（结构化短报告、判决 token 校正、标签监督兜底）恰在其安全区，但推广到长链推理需谨慎【标注：此为阅读者基于其结论的推断】 |
| [DeCoF / SpecSem-Net 等 OOD 检测线](https://arxiv.org/abs/2605.17311) | 冻结编码器学时序/频谱特征以泛化到未见生成器 | 空间指纹脆弱，物理/时序线索更普适 | 无 agent 结构 | 补充：与本文『物理证据进化带来 OOD 提升』的机制解读方向一致 |

### 6.3 综合判断与未决问题

**多研究共同支持的机制**：(1) 多视角取证优于单模型（ARGUS、本文、ARGUS-Net 等）；(2) 感知/证据质量是检测瓶颈（VideoVeritas、BusterX++ 的解释性审计、本文表 8）；(3) 双时间尺度或交替更新是多 agent 共演化的稳定训练结构（TacoMAS、ReMA、MetaSkill-Evolve 与本文表 7 从三个独立场景一致支持）。

**仍属推测或未决的部分**：(1) 『认伪影而非认生成器』的表征层解释尚缺直接归因实验（本文 OOD 增益也可能部分来自 RL 池的生成器多样性）；(2) CLUE 依赖冻结参考模型的质量，若参考模型与任务严重失配其信号是否退化，论文未讨论；(3) 特权蒸馏在长链推理场景的外部反面证据提示，本文机制向更长调查轨迹扩展时需重新验证；(4) 音频工具因标注稀缺保持冻结，共演化范式对音频角色是否同样有效是开放问题。

## 七、必要知识反推

假设让一个完全没有相关知识的人从零完成这项工作，倒推其必备知识：

### 7.1 领域知识层

- **AI 视频生成与伪影 taxonomy**：必须知道生成器会在哪些维度留下可观测缺陷（纹理漂移、物理失真、字形融化、音画错位……），否则 FSL 的六个角色设计、ForenCue 的 117,552 条角色级标注体系都无从谈起。六角色划分本质上是把取证专家的领域直觉工程化。
- **取证鉴定的证据纪律**：『不指控看不到的东西』（issue 必须有帧内具体异常支撑）、『inconclusive 是合法输出』、『后期处理≠生成』——这些报告纪律直接来自法证实践，不理解它们就会做出把所有模糊都当伪影的玩具系统。
- **音视频基础**：说话人分离、词级时间戳转写、OCR 检测原理——决定音频工具与 OCR 三段流水线的设计边界。

### 7.2 方法论知识层

- **RLHF/GRPO 全家桶**：没有 GRPO（组内相对优势）就没有快尺度；不理解 PPO 式裁剪目标与 KL 约束就无法安全叠加 CLUE 信号。
- **蒸馏谱系**：Mean Teacher/EMA、on-policy 蒸馏、特权信息（LUPI）——慢尺度的 OPD 是三者的组合拳，缺一个概念都无法解释为什么教师看得到答案位置而学生学到的却是『看证据』。
- **双时间尺度优化思想**：控制论中的奇异摄动、交替训练——论文虽未展开理论，但 H=20 的选择与『每 batch 刷新失败』的对照说明作者理解快慢分离的本质。
- **课程学习与自监督**：识别出『调用分布=课程』这一结构，是 DOPD 数据选择规则的前提。

### 7.3 工程知识层

- **LoRA 多适配器部署**：一骨干+五 rank-64 插件的参数化，让两级五模型联合训练在显存上可行，这是 DTPO 能落地的物质基础。
- **大规模异步 rollout 基础设施**：vLLM 多引擎、异步 rollout worker、同步屏障、双 GPU lane 负载均衡——论文 4.3 节的工程细节（如 LoRA 热插拔数值不稳须整checkpoint发布）是踩坑换来的。
- **数据流水线与质检**：rubric 条件化标注、跨家族交叉验证、人工抽检回灌规则——99.1% 审计支持率不是免费的。

### 7.4 知识融合的关键节点

真正的创造性发生在三处融合点：**(1)** 把『法证会诊流程』翻译成 POMDP 式的『观察-动作-停止』协议——领域知识×RL 形式化；**(2)** 识别出『调查者的调用是检查器的天然课程』——把多 agent 系统的非平稳性难题反转为数据引擎——这个洞察同时调度了课程学习与共演化两条文献线；**(3)** CLUE 用第三方冻结模型做证据价值的裁判——把『信用分配』问题转化为『信息增量测量』问题，避开了自证循环。三处融合没有一处是单一线性知识的产物。

## 八、论文中可以提取的通用性灵感

**灵感一：瓶颈在工具，就进化工具，而不只是优化路由**。任何『调度器+专家池』系统（RAG 的检索器+阅读器、代码 agent 的规划器+工具集、医疗分诊系统）都存在同样结构：调度策略的优化收益受限于专家能力的上限。本文证明对专家本体做持续蒸馏的 OOD 收益（+1.6~2.7pp）远超继续打磨路由（+0.4pp）。推广场景：检索增强问答中让检索器从阅读器的实际使用中进化、多 agent 产品团队按真实工单回流微调各专员模型、机器人技能库从任务规划器的真实调用中更新。

**灵感二：调用分布即课程——系统的探索行为本身是数据引擎**。为一个 agent 设计学习信号时，先问『它运行时自然产生的数据是什么』，而不是另造训练集。本文检查器的高价值训练样本恰恰是调查者认为可疑而发起的调用。推广场景：客服 agent 的转人工记录成为 FAQ 生成课程、编译器优化 pass 的实际触发分布决定其再训练数据、推荐系统探索流量即 diversity 训练集。

**灵感三：耦合系统用节奏分离代替同步更新**。两个互相影响的组件需要共同提升时，让快变量在慢变量的准平稳环境中收敛，慢变量积累足够样本再更新——而非每步同步。表 7 显示同步更新不仅慢 3.3 倍还全面掉点。推广场景：在线学习中模型与特征管道的更新解耦、组织管理中战略（慢）与执行（快）的评审节奏、金融市场中做市商报价与风控限额的更新频率设计。

**灵感四：特权信息当『往哪看的指针』，不当答案**。训练时可用、推理时不可得的信息（标注区间、专家提示、模拟器真值）最有价值的用法是引导教师产出示范分布让学生内化发现过程，而非直接作为监督目标。同时要警惕其失效边界——外部反面证据表明在长链推理中它可能压制探索。推广场景：医疗 AI 用病理结果作特权训练影像模型、自动驾驶用仿真真值状态训练感知、教育 AI 用标准答案训练解题过程评分。

**灵感五：结论正确但报告含糊也是一种失败**。本文把『对但说不出可信证据』的回答标记为 hedge 并专门矫正——在所有需要可审计性的系统（司法、医疗、金融风控）中，判决质量不等于证据质量，两者的分别度量与分别优化至关重要。26.9%→0.3% 的 inconclusive 率下降直接换来了 31.3pp 的 F1 提升。

**灵感六：调用精度（是否找对了专家）应当与最终正确率一同考核**。AgenticCue 的设计思想：只考最终答案会掩盖『靠无关操作碰对』的捷径，尤其当基率悬殊时（常识角色基率 24%）盲目全调的『假精度』会骗过整体指标。推广场景：评估工具调用 agent、评估多专家路由系统、甚至评估人类组织的分工效率时，都应加入『专业匹配度』维度。

## 结语

这篇论文的价值不在 95.2% 这个数字本身，而在它把『agent 系统如何从自己的运行经验中系统性变强』这个泛 AI 问题，在视频取证这个证据链完整的领域里做了一次干净的实证：瓶颈定位（证据而非路由）→ 机制设计（双时间尺度共演化）→ 因果验证（交叉消融的超加性、证据 F1 的独立提升、刷新节奏对照）。对研究者，DTPO 是可迁移的训练范式；对从业者，ForenCue-30K 与 AgenticCue 填补了角色级监督与调用评估的工具空白；而对更广泛的观察者，南大×腾讯微信视觉这一『企业出题、一作驻场实习、双通讯联合指导』的产学研配置，也展示了前沿多模态系统工程如何在校企之间完成分工。
