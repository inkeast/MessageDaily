## 先说结论

这期视频把 Fable 5.2 与 Mythos 5.2 的发布读成了一件比「又刷榜」更大的事。第一，Wes Roth 的上手判断毫不含糊：这是「凡人可用」的世界最佳模型——Opus 5.5 会卡住的长程复杂难题它直接「速通」（speedrun），某些场景按任务计价甚至比 Opus 便宜。第二，也是本期真正的增量：他对照 METR 报告的图推断，今天发布的 Fable/Mythos 5.2 就是 Anthropic 内部的「Model Three（Early）」，与压着不发的秘密前沿 Model Four 之间距离「像剃刀一样薄」。第三，Anthropic 第一次没有把能做的最好模型发出来：Wes Roth 称其在**训练期**刻意把两类能力——加速器内核优化与改进 LLM 架构——钉在 Opus 5.5 的水平，因为再往上就等于「发放一台能自我复制的机器」；他预言此后所有前沿发布都会带上这种定向削弱。第四，他把 nanoGPT 速通榜上 Kimi K3 紧贴 Claude 家族的现象读作蒸馏的活证据，并给出一个可检验的观察方法：看开源模型的曲线「形状」会不会跟着 Claude 被限制的方向同步变形。对读者来说，「最强模型」的定义正在从「榜单最高」变成「离那条红线有多远」。

## 一、凡人能拿到的最强模型：Opus 会卡住的题，它「速通」

开场即下判断（Wes Roth 称）：Fable 5.2 与 Mythos 5.2 正式发布，「毫不夸张地说，这是世界上最好的模型——至少在『我们这些凡人』能拿到的模型里」，能速通人类做不到、连 Opus 5.5 这类顶级模型也做不到的事——「Opus 会卡住（stalls），而它直接速通」。顺带的能力标签还包括：机器人控制「不可思议」、称得上「世界级的硬件工程师」。

他给出的第一个「连物理学家都震惊」的例子是斯蒂芬·霍金与唐·佩奇（Don Page）合作风格的物理结果图（Wes Roth 转述画面）：图上注明「本结果由一个 Claude 内部研究模型获得」，物理学家检查并试图理解之后，紧接着写的是「另一次使用不同方法的 Claude 计算（未收录于此）给出了同样的结果」。他的调侃很直白：Claude 想出来的，一个人类试着理解了一下，然后另一个 Claude 说「数学上没问题」——「大家都在为这个模型有多强而失去理智」，而图注还写着「由 Anthropic 贡献」。他自己的体验类似：有一个困扰他两三周的问题，Astra 和上一代 Fable 都攻关过，Fable 5.2 接手后，「我感觉在我录完这期视频之前它就会解出来」。

最能说明「长程复杂任务」能力的官方演示（Wes Roth 转述一位 Anthropic 工程师的实验）：从空文件夹起步，模型协调超过 1,000 个 agent 昼夜运行八天，写码、测试、审查，产出一个能在笔记本上启动的操作系统——自带跑整机的内核，磁盘、键盘、网络驱动，持久文件存储、窗口、登录界面、安装器，还内置了 Claude 功能。他自己的演示则小而快：录影前他让 Fable 5.2 给他自建的一个游戏基准（转写为「游戏/大图像模型基准」，原文如此）「美化一下图形」，一小时内模型加上了自动挑最精彩瞬间的集锦回放、镜头推近与记分牌——全部 2D 图形、原游戏里没有；他同时开两个 Fable，一个做引擎底层、一个做图形，「不知道能这么快做得这么好」。定价侧本站已按 Berman 一期[记过](https://inkeast.github.io/MessageDaily/posts/2026-11-10-matt-berman-fable-52-software-dead-demos/) token 单价降两成；Wes Roth 补的增量是：因为任务完成得快，**按任务算的总价**某些情况下比 Opus 更低，另外 Anthropic 宣布随发布发放用量重置——最多三次、仅限高阶订阅、按订阅时长决定（Berman 只提到「本周发放重置」）。

## 二、Model Three Early：我们与秘密前沿的距离「像剃刀一样薄」

但这期的主线不是跑分，而是他对 METR 报告（本站 11 月 8 日已按 Matthew Berman 视频[专门拆解](https://inkeast.github.io/MessageDaily/posts/2026-11-08-matt-berman-metr-anthropic-rsi-12-months/)）的一份「谱系考证」。METR 即常驻 Anthropic 的独立嵌入式评估机构；Wes Roth 说他这次直接对着报告里的图讲：有些人担心就在 Mythos 发布前后出现了一次「相当突然的能力跳变」，Anthropic 起初解释为「一次性跳变、之后照旧」，而他看图认为「大概不是那样」。报告还透露 Anthropic 内部存在超出公开发布的模型序列：Model Two、Model Three、Model Four。其中 Model Four「碾压 Anthropic 的内部基准」，已经难以测量——他用的比喻是只能给大学生考高中卷子；在内部基准（转写为「AECI」，疑为 Anthropic 能力指数 ACI，见校正表）上 Model Four 的结果全部超过 50%。而 Model Three 与 Model Three Early，就是今天发布的 Mythos 5.2 与 Fable 5.2——这是 Wes Roth 据报告图点位做出的推断（他自己也称之为「野路子猜测」，欢迎评论区纠正）。

由此他纠正了自己此前的一个直觉：他本以为「我们手里有的」与「前沿」之间的差距在扩大，但图上看起来「像剃刀一样薄」——秘密武器几乎就是发布物本身。顺带把口径对齐：Fable 与 Mythos 基本上是同一个模型，Fable 只是护栏更多（与 AI Explained 那期[系统卡深读](https://inkeast.github.io/MessageDaily/posts/2026-11-14-ai-explained-fable-52-system-card-deep-dive/)一致：Mythos 5.2 护栏更少、普通用户不可用）。至于大家最关心的「Anthropic 到底发现了什么在加速 AI 发展」，他引 Anthropic 联合创始人 Sam McCandlish（转写误作 Sam McAnlis，已校正）的说法：报告删节了大量内容，因为「我们不分享到底是什么在驱动加速」；Anthropic 的口径是正在接近 RSI（递归自我改进），Model Four「或者那个附近的什么东西」可能已经越过或正在接近那个门槛。

## 三、训练期被「故意养残」：不许超过 Opus 5.5 的红线，与「自我复制的机器」

那么问题来了：既然手里有更强的东西，为什么还敢发布？Wes Roth 的答案分三层。第一层是机制澄清（他强调的重点）：这不是推理时压制输出——不是用户提问时系统临时「降智」——而是「在模型训练期间，我们采取了措施，限制那些最能直接加速 AI 发展的特定研究能力的进步」。被压制的就是上一节加速的中心领域：加速器内核优化（accelerator kernel optimization）与改进大语言模型架构；在这两个域，Fable 5.2 与 Mythos 5.2 的表现「大约就是 Opus 5.5 的水平」——「我们已经在这些领域见顶」。他同时安抚：大多数用户根本碰不到这些限制，这模型「绝对是一头野兽」。

第二层是这条红线为什么存在：**如果一个实验室在这些特定域发布超出这条线的能力，就等于发放能做自主 AI 研究的东西——「等于发放一台自我复制的机器」**。他的思想实验：假如我能用上 Mythos 6，我就可以说「嘿 Mythos 6，做一堆实验，直到你能复现 Mythos 6」。第三层是发布形态的预测：过去实验室的竞赛是谁把数十亿美元和 GPU 烧成刷爆基准的「世界最佳」，而从这个模型起，「我认为此后发布的所有前沿模型都会类似」——带着训练期定向削弱出厂；值得观察的是其他大厂会不会跟进画线，还是「把全部都放出来」。

给这个判断他配了一个文学比喻：《安德的游戏》及其平行续作《霸主的影子》（Ender's Shadow）里的 Bean——胚胎期被基因改造、架构被优化得极其聪明，幼年却流落街头、营养不良，大脑没能正常发育，「但仍比最聪明的人类更聪明、远超全书任何角色」。「这字面上差不多就是这些模型：它们是我们能接触到的最聪明的模型，而和 Bean 一样，它们在早期发育时被养残了（gimped），注定到不了真正的潜力。」

## 四、反蒸馏疑云：Kimi K3 是「出生时被分开的双胞胎」吗

红线之外，Wes Roth 用一整段讲反蒸馏（anti-distillation）。背景：如果能在大规模上「收割」前沿模型的推理轨迹（思维链），就能造出它的某种副本——「这就是为什么有时开源模型一出来，表现、行为、感觉都惊人类似当时榜单上的第一名」。相应地，他注意到有人抱怨 Claude 的推理轨迹「根本讲不通、犯愚蠢错误、调用不存在的工具」——像是被故意污染过的防蒸馏手段；他自己声明没遇到、无法验证。这段与他前面讲的红线互为表里：能力压制防的是「别人拿它加速 AI」，轨迹污染防的是「别人拿它蒸馏复制」。

证据侧，他展示了 nanoGPT 速通榜（衡量模型优化小型语言模型训练代码的能力，榜上之一「来自 Tier」，转写疑似、未核实）：Fable 大幅领先，Opus 其后，而以极微弱差距落后于 Opus 的是 Kimi K3。「为什么 Kimi K3 离 Opus、离 Claude 家族这么近？几乎像它们是同一个模型。它们会是出生时被分开的双胞胎吗？」由此他给出一个真正的可检验预测：如果 Anthropic 从此在这类基准上不再爬升，而 Kimi K3、DeepSeek 或其他中国开源模型冲过去反超，说明他们想通了西方实验室没想通的东西；但如果 Kimi 的曲线随时间「完全复刻 Claude 的形状」——在 Claude 继续扩张的方向继续扩张、在 Claude 停下的方向也停下——那就是蒸馏的指纹。观察曲线的形状，而不只是高度，是这期给读者最实用的一件工具。

## 五、Karpathy 的脚手架与「Claudification」：从「自主写码」到「自主实验」

最后是他自称「大胆瞎猜」的机制拼图：Anthropic 删节的「agent 脚手架」到底是什么。他的参照系是 Andrej Karpathy 的开源项目——nanoGPT 与其自动研究项目（auto research），思路是给 agent 一套真实的语言模型训练环境，让它整夜自主跑实验：试一个改动，指标改进就合入，不改进就记录结果继续搜更好的方案。他说 METR 报告里被删节的那个「agent 脚手架」「大概就是类似的东西」（他还提到训练代码「基本上是 NanoChat」，转写疑似、未核实）。时间线上他抓出一个措辞变化：Opus 4.5 之前 Claude 对自主写码没用，Opus 4.5 是第一个「对自主写码有用」的模型；而 **Mythos Preview 加上那个秘密脚手架，是第一次「对自主实验有用」**——注意，说的不再是 code，是 experiment。

配套的内部引语（Wes Roth 转述自 METR 报告相关材料）：「AI 加速比其他所有效应加起来都大」；一位研究员说「我明确认可一年之内取得超过两年的进步，而且我觉得四倍也不疯狂」；「我们现在同时尝试的实验多得多，因为 Claudification（克劳德化）」（转写误作 codification，已校正）。把这条链合起来就是第三节的答案：自主实验能力出现在 Model Three 前后、十月附近明显变陡，于是 Anthropic 在发布物上画线，防的就是这台「自我复制机器」流出到民间。结尾他留了个开放问题：如果 Anthropic 真在用自主方式激进测试不同模型架构，那对训练与推理效率可能意味着大事——「如果我们发现一直以来都做错了，其实存在简单得多、安全得多、高效得多的做法呢？那多好笑。」

## 机制 → 影响 → 启发

1. **红线链**：训练期定向压制内核优化/LLM 架构改进 → 直接原因：这两域越过 Opus 5.5 即等于可自主做 AI 研究、可自我复制的机器 → 获益方是 Anthropic 的安全叙事与监管位置；受损方是依赖这两域的极客用户，以及（若全线跟风）所有用户的能力上限 → 二阶影响：这些域的公开榜单从此被人为封顶，「最强」信号被截断，蒸馏源头也变弱 → 观察指标：OpenAI、Google 是否跟进画线；被压制域的榜单是否长期横盘 → 读者启发：读榜单先问一句「这个域被钉住没有」，否则比较的是被阉割的样本。
2. **蒸馏指纹链**：推理轨迹疑似被污染 + 反蒸馏努力 → 开源模型与榜首行为高度相似（Kimi K3 紧贴 Opus 的 nanoGPT 速通）→ 若 Anthropic 限域后 Kimi 曲线形状同步变形，即为蒸馏证据；若反超，则是中国实验室的独立突破 → 二阶影响：防蒸馏会让「思维链」越来越不可读，模型输出的可信参考价值下降 → 观察指标：Kimi/DeepSeek 在被压制域的曲线形状 → 启发：判断模型血缘看能力曲线的形状随时间的收缩与扩张，而不是单点分数。
3. **自主实验链**：Opus 4.5＝首个对自主写码有用的模型 → Mythos Preview＋秘密脚手架＝首个对自主实验有用 → 研究员产能被放大（「一年超过两年，四倍也不疯狂」「Claudification」）→ RSI 门槛逼近，发布物被迫画线 → 二阶影响：模型能力的一半藏在脚手架（harness）里，公开参数与跑分越来越不足以推断实验室真实水平 → 观察指标：下一版发布是否仍钉在 Opus 5.5 水平、删节材料是否被第三方还原 → 启发：评估前沿进展时把 harness 当一等公民，与模型本体并列跟踪。
4. **任务级成本链**：模型长程任务完成速度跃升（速通 vs 卡住）→ 按任务计价的总成本可低于 Opus，尽管 token 单价更高 → 选型逻辑从「每 token 多少钱」转向「这件事总共多少钱、多久」→ 观察指标：第三方任务级（per-task）成本评测是否出现 → 启发：个人与团队建立自己的「任务账本」，用自己的真实任务测，别只看 token 价目表。
