## 【论文精读】Reframe：把"观测状态"而非"输出分布"作为对齐对象的多教师在线蒸馏

> **论文标题**：Reframe: Observation-Aligned Multi-Teacher On-Policy Distillation for Agentic Visual Reasoning
> **作者机构**：南京大学（Haozhi Yuan，通讯）、中国科学院自动化所（Handong Li、Yifan Zhang、Qianshan Wei）
> **发布时间**：2026 年 11 月 9 日
> **arXiv**：2611.12886（cs.CV）
> **开源仓库**：https://github.com/EliYuan30/Reframe（代码/数据/模型）

### 一、 论文背景

**视觉智能体（visual agent）与"带工具的思考"是什么？** 视觉语言模型（VLM）在处理高分辨率图像或长视频时存在"证据稀疏瓶颈"：关键信息（车牌上的一个数字、两帧之间的细微变化）只占输入的一小部分，全局编码会把它淹没。近两年的主流解法是给 VLM 配上视觉工具——裁剪（crop）图像局部、选取（select）视频帧——让模型像人"凑近看、回放"一样主动获取细粒度证据，这就是"think with images / think with videos"研究线。

**但调用工具 ≠ 使用工具返回的东西。** 论文把核心病症命名为**观测忽视（observation neglect）**：模型调用了 crop 工具、拿到了放大后的局部图像，但后续推理基本不 受这张图影响——工具成了仪式性动作，答案其实还是凭原始输入"猜"出来的。想象一个学生举着放大镜却从不透过镜片看，只把它当道具挥舞。此前的 outcome-based RL（只按答案对错给奖励）无法惩罚这种行为：只要答案碰对了，绕过观测的捷径路径照样拿满分。

举一个具体的失败样例（据论文图 1 的场景）：问"骑手的号码是多少"，模型先调用 crop 裁了骑手区域——动作正确、观测返回了清晰的号码布——但下一步推理却绕开裁剪图，凭原图的模糊印象（或世界知识先验"常见号码范围"）给出答案。答案偶尔对，奖励照给，于是"裁了不看"的行为被反复强化。更糟的是，模型甚至可能学会"裁一个大概区域应付流程"——因为 outcome 奖励从不检查裁剪质量。

**为什么观测忽视值得单独研究，而不是"更大模型自然解决"？** 因为它是一个训练信号问题而非能力问题：模型有足够的感知能力读懂裁剪图（给对图时准确率 96.86），但训练从未强制"答案必须经由观测"这条因果路径。信号不改，参数再大也只是更高效地走捷径。

**第二个背景问题是"图像/视频统一模型落后于单模态专家"。** 大多数前作要么只做图像、要么只做视频；少数同时做两种模态的工作采用"混合数据 SFT → RL"范式，最终统一模型明显落后于单模态训练的专家。论文将其归因于两点叠加：off-policy SFT 的模式冲突（模仿别人的轨迹分布，图像/视频两种行为模式互相打架）+ RL 的监督稀疏（一条轨迹只有一个 0/1 奖励，信用分配太粗）。

**在线蒸馏（on-policy distillation, OPD）恰好同时解决这两点。** OPD 的做法是：学生模型自己采样轨迹，教师只做一次前向、对学生写下的每个 token 给出概率分布，学生最小化与教师的逐 token 反向 KL。它"既稠密（每个 token 都有信号）又在策略（监督发生在学生自己会到达的状态上）"。 Thinking Machines Lab 2025 年 10 月的博客将其推广为通用配方（AIME'24 上以 SFT 管线 1/9~1/30 的成本达到相近效果），DeepSeek、GLM 等前沿模型随后采用其多教师扩展 MOPD（multi-teacher on-policy distillation，按轨迹内容路由给领域专家教师）。

用教练类比理解 OPD 与 SFT/RL 的三方差异：SFT 像发给学生一本名家棋谱让他背（学的是别人的状态，自己下棋走偏一步就懵）；RL 像只公布最终输赢（一盘棋一个 0/1，错了不知道错在第几步）；OPD 像教练坐在学生身边看他实时下棋、每落一子都点评（学生自己的局面 + 每步都有反馈）。MOPD 则是"图像教练 + 视频教练"各管一段——学生自己下棋，两位教练按当前局面轮值点评。

**本文指出现有 MOPD 的盲区**：所有监督细化工作（路由、收敛、漂移）都只关心"如何传递监督"，从不干预 rollout 轨迹本身。但对 agentic 任务而言，**后续一切监督都以工具返回的观测为条件**——如果学生在第 2 步裁错了图，之后 token 级反馈再稠密，也是在"错误的画面"上做监督。这就是标题里"observation-aligned"的含义：把观测状态本身作为对齐对象。

**一句话总结背景三要素**：(1) 病症——观测忽视让视觉工具沦为仪式；(2) 并发症——混合模态统一模型落后单模态专家；(3) 药方谱系——OPD/MOPD 提供了"稠密 + 在策略"的监督通道，但没人管过"观测状态好不好"。Reframe 补上最后这块板。

**为什么这个问题现在重要？** 随着 agentic 范式从纯文本扩展到多模态，工具调用的"最后一公里"问题（返回的观测是否被消化）成为统一短板：2026 年发布的多个视觉 agent 模型在依赖度审计下纷纷现形（最高不过 41.93）。另一方面，OPD 在纯文本领域已成行业标配，向多模态 agent 迁移时"观测条件质量"这一新变量必然浮出水面——Reframe 是第一批正面处理该变量的工作，时机上是踩点准确的。

### 二、 论文定位和关联工作

本文位于**多模态 agentic 推理 × LLM 后训练（RL + 蒸馏）**的交叉点。相关工作的坐标图：

| 研究线 | 代表工作 | 与本文关系 |
|---|---|---|
| think with images | DeepEyes、Pixel-Reasoner、DeepEyesV2 等 | 提供"视觉工具 + RL"的基本范式，但无观测依赖的显式机制；本文在 14 基准全面领先且诊断出其依赖度极低（19.47~41.93） |
| think with videos | Thyme 及视频工具工作 | 同上，本文视频侧最强对手 Thyme 被超 8.86 分 |
| 混合模态统一训练 | SFT-then-RL 范式 | 本文的 Mix-RL 对照组：图像落后专家 1.17、视频落后 1.37，论证该范式不可取 |
| 在线蒸馏谱系 | GKD（2023）、MiniLLM、Thinking Machines OPD（2025）、MOPD 变体（路由/收敛/漂移/跨模态） | 本文继承 MOPD 的 token 级反向 KL 主干，但首次**干预 rollout**（观测门控修复），把对齐对象从输出分布扩展到观测状态 |
| 观测忽视相关 | IMAgent（多图 agent RL，发现"视觉遗忘"并设计反思工具）、ForeSight（CVPR 2026，低层视觉工具+掩码反馈缓解细粒度忽视） | 独立证实"模型逐渐忽视视觉输入"现象的普遍性；本文的不同在于用 dropout+grounding 奖励从训练机制上耦合"获取"与"依赖" |
| 提升工具调用时机 | 一批"何时调工具"的工作（论文引 [33][34][42]） | 与本文互补：它们管"什么时候调"，本文管"调完之后用不用" |

值得注意的分工细节：论文明确把自己与"改进工具调用时机"的研究线区分为**互补关系**——调用时机再优化，也解决不了"调了不看"的问题；反之，观测依赖再强，调用时机错误也拿不到好观测。Reframe 的门控修复顺带覆盖了一部分调用质量问题（IoU 低于阈值即修），但作者没有声称要取代时机优化研究。

**一句话定位**：Reframe = GD-GRPO（第一阶段，用证据感知奖励 + 随机丢原图训练图像/视频双专家）+ OG-MOPD（第二阶段，观测门控的多教师在线蒸馏统一到一个模型）。两个阶段都无需任务特定的 SFT 冷启动。基座是 Qwen3.5-9B，工具集刻意极简：CropImage 与 SelectFrames 两个。

从顶会评审视角预判（个人分析）：**新颖性高**。核心贡献在于把"对齐对象"从输出分布扩展到观测状态——首次在工具使用 MOPD 中主动干预并修复 rollout 轨迹（observation gating + 注入 token 的分支感知监督），配合 drop 条件化子组优势归一化，机制层面超出既有 MOPD 的路由/监督细化路线。诊断协议（依赖度/工具增益的因果审计）与 14 个 benchmark 的全面数字（领先外部 SOTA 11.71/8.86 分）支撑有力。可讨论的弱点：仅两个视觉工具、grounding 奖励依赖标注证据质量、向更多模态/工具的通用性待验证。

### 三、 问题定义

论文要同时解决两个相互纠缠的问题：

**问题一：观测忽视。** 形式化地，设模型在时刻 t 调用工具获得观测 o_t，若后续推理策略 P(答案 | 历史, o_t) 与 P(答案 | 历史) 几乎相同，则观测被忽视。outcome-based RL 无法区分"用了观测答对"与"无视观测碰对"，甚至可能奖励后者（捷径更省事）。

**问题二：统一模型的专家差距。** 用同一策略 π_θ 同时服务图像（空间证据：crop）与视频（时序证据：select frames），混合训练时两种模态的行为模式冲突，导致统一模型落后单模态专家。

由此，理想的训练范式应满足四个性质：(a) 监督稠密（token 级）；(b) 在策略（学生自己的轨迹）；(c) 迫使答案真正依赖工具观测；(d) 保证蒸馏时的观测状态本身是有效的（裁对地方、选对帧）。现有方法最多同时满足 (a)(b)，Reframe 的两个阶段分别补上 (c) 与 (d)。

用一张表格总结"现有范式 vs Reframe"在四性质上的覆盖：

| 范式 | (a) 稠密 | (b) 在策略 | (c) 逼观测依赖 | (d) 观测有效 |
|---|---|---|---|---|
| 混合数据 SFT | ✓ | ✗（模仿他人轨迹） | ✗ | ✗ |
| outcome-based RL / Mix-RL | ✗（轨迹级 0/1） | ✓ | ✗（捷径可得分） | ✗ |
| vanilla MOPD | ✓ | ✓ | ✗ | ✗ |
| Reframe（GD-GRPO + OG-MOPD） | ✓ | ✓（门控保住大部分） | ✓（dropout+R_obs） | ✓（IoU 门控修复） |

两个问题还有耦合关系：观测忽视（问题一）不仅让工具白用，还会拖累蒸馏——学生总是到达"坏观测"状态，教师的 token 级反馈再准，也只是在教学生"如何在错误画面下说话"；反之，若不先解决依赖问题（问题一），修复了观测（针对问题二的门控）学生也视而不见。这个耦合正是"两阶段"设计的根本理由。

### 四、 问题解法

#### 4.1 第一阶段 GD-GRPO：训练"真看图"的单模态专家

GD-GRPO（Ground-Drop-GRPO）在标准 GRPO 基础上做了三处关键改造：

**（1）证据感知的多项奖励。** 总奖励 R = R_ans + f(p)·R_call + λ_obs·R_obs − R_pen：

- **R_ans**：答案正确性（0/1）；
- **R_call**：基于标注的工具适用性奖励——动作与标注证据的 IoU 高则奖励高；随训练进度按 f(p)=exp(−κp)（κ=5）指数衰减，只在早期引导探索，后期退场避免依赖；
- **R_obs（核心创新之一）**：基于 IoU 的 grounding 奖励，奖励"裁到了/选到了信息性区域"这个动作本身，**与答案对错无关**。图像侧用"轨迹内全局一对一 IoU 匹配"防止模型反复定位同一区域刷分；视频侧只评最后一次尝试、多次尝试打 0.85 折扣（防止反复试探）。权重 λ_obs=0.4。
- **R_pen**：非法工具调用/非法答案惩罚（图像 1.4 / 视频 1.2）。

设计意图：R_ans + R_obs 的组合把"获取信息性观测"（过程）与"答对"（结果）解耦——即使答案错了，只要裁剪位置合理仍拿过程奖励，从而打破"碰对答案的捷径"与"认真看图的正路"之间的奖励混淆。

**（2）原始观测 dropout。** 首次成功工具调用后，以 p=0.5 的概率把原始视觉输入 o_0 从上下文中丢掉（保留问题、文本历史与工具返回观测）。这使答案在dropout 分支下**必须**依赖工具返回的观测——模型再也无处绕行。推理时始终保留原图，dropout 只是训练期的"逼依赖"手段。这与 dropout 经典思想（随机删输入防过拟合）神似，但目的相反：不是防依赖，而是**制造依赖**。

打个比方：教孩子用地图，最有效的办法之一是偶尔把 GPS 收走——只剩地图时还想到达目的地，就必须真的学会读图。原图 dropout 收走的是"GPS"（全局低分辨率视角），留下的工具观测是"地图"（局部高分辨率证据）。推理时 GPS 永远在线（原图保留），但孩子此时已经养成了看地图的习惯。

为什么是 p=0.5 而不是 1.0（永远丢掉）？因为完全移除原图会让"对照原始全局上下文"这一能力也失去训练机会（有些问题需要全局+局部结合判断），且训练分布与推理分布（原图在场）差距过大。0.5 是让两种条件各占一半、由 drop 条件化子组分别归一化的折中。

还有一个容易被忽略的细节：dropout 的触发条件是"首次成功工具调用之后"——不是"任意调用之后"。若在失败调用后也丢原图，模型在毫无有效观测的情况下被要求答题，只会产生噪声梯度。这个门槛保证了"丢 GPS 之前，手里必须已经有地图"。

**（3）Drop 条件化子组归一化。** GRPO 的优势 = (R_i − μ)/σ（组内标准化）。但如果同一组里有的样本被 drop 了原图、有的没有，组内均值方差就混合了两种条件，优势估计被条件噪声污染。Reframe 按**预采样的 drop 标志 d_i** 把样本分成两个子组分别归一化。关键细节：分组基于预采样标志而非"实际是否 drop"，保证分组与策略的工具决策统计独立（否则会引入选择偏差）。

这里展开解释"预采样标志 vs 实际 drop"的微妙差异：drop 标志 d_i 是在 rollout 开始前就从伯努利(0.5)采好的随机数，无论这条轨迹最终有没有成功的工具调用（成功调用才触发实际丢弃），分组关系已定。如果改用"实际是否 drop"分组，会发生什么？"实际 drop"还依赖"策略选择了成功调用工具"这一行为——策略强的样本更容易进入 drop 组，两组的优势基线就与策略能力相关，归一化会系统性偏置。预采样标志切断了这条相关性链，是一个小而关键的因果考量。

#### 4.1.1 GD-GRPO 的完整奖励信号一览

| 信号 | 评什么 | 何时生效 | 防什么弊 |
|---|---|---|---|
| R_ans | 答案对错 | 恒定 | ——（结果底线） |
| f(p)·R_call | 工具调用与标注证据的 IoU | 随训练指数衰减（κ=5） | 防止早期不敢调工具；后期退场防奖励依赖 |
| λ_obs·R_obs（λ=0.4） | grounding 质量，与答案无关 | 恒定 | 防止"碰对答案的捷径"与过程脱钩 |
| R_pen（图像1.4/视频1.2） | 非法调用/非法答案 | 恒定 | 防格式崩坏与刷分 |
| 原图 dropout（p=0.5） | （非奖励，上下文操纵） | 首次成功调用后 | 防观测忽视——制造依赖 |

#### 4.2 第二阶段 OG-MOPD：观测门控的多教师蒸馏

第一阶段产出图像专家（空间）与视频专家（时序），第二阶段把两者蒸馏进一个学生。为什么需要两个阶段、不能一步到位？因为 MOPD 的前提是"有教师"——教师必须先在单模态上足够强；而第一阶段的价值不止于造教师：它同时建立了"观测依赖"这个行为先验，使第二阶段的观测修复能被学生利用（后文因果链四）。两阶段不是简单的"先训教师再蒸馏"，而是能力互补的接力。

**（1）观测门控 rollout。** 学生自己采样工具动作 a_t；若动作缺失/非法/**与标注证据 IoU 低于阈值**（δ_crop=0.25、δ_select=0.15），则把该动作替换为从标注导出的规范动作 a*_t，并**从修复后的观测继续采样**后续轨迹。良构动作原样保留。这是一个精心权衡的设计：全量替换会破坏 on-policy 性质，完全不修则监督始终条件在坏观测上——门控只在"观测无效"的边界上动刀。

为什么阈值是 δ_crop=0.25 / δ_select=0.15 两档？裁剪 bbox 与选帧的 IoU 分布天然不同——bbox 稍偏仍可能覆盖目标（阈值可高些），帧索引则错一帧就是完全不同的画面（阈值必须严）。门控替换后，轨迹出现"学生动作 → 注入动作"的接缝，这正是分支感知损失要处理的结构。

**（2）分支感知蒸馏损失。** 轨迹被修复动作切成两段：

- 学生自采样 token 集合 S：走标准 MOPD——按执行的工具动作路由给对应专家教师，最小化 token 级反向 KL（稠密反馈）；
- 被注入的规范动作 token 集合 I：单独用 NLL 监督（λ_br=1）——教学生**自己学会产出正确动作**、主动到达信息性观测状态。

为什么要分两支、而不是统一都用反向 KL？一个技术性原因是：注入动作不是学生策略采出来的，学生分布在该位置可能概率极低，反向 KL 对低概率区域的梯度信号弱；NLL（交叉熵）直接把正确动作的概率拉上来，信号强且稳定。更深一层的设计意图：两支各司其职——S 分支教"在好观测状态下如何推理"（何时用教师），I 分支教"如何到达好观测状态"（如何自己走对路）。

推理时门控与教师全部退场，学生独立工作——训练期的脚手架不增加任何推理成本。

**（3）两阶段的互补性。** 论文的核心论点：先学会依赖工具观测（GD-GRPO），观测修复（OG-MOPD）的收益才可被利用——如果学生根本不看返回的观测，修好了观测也白修。反之，蒸馏阶段保证了学生能以高概率到达"好观测"状态，使第一阶段建立的依赖有用武之地。

#### 4.3 Reframe-100K 数据集

63K 图像 QA + 37K 视频 QA，五步级联清洗：去掉纯文本可答的 → Qwen3.8-27B 8 次采样审计（全输入 F vs 证据输入 E，剔除太易/太难/证据不支持的）→ GPT-5.6-Luna 终审。证据上下文做松弛处理：bbox 按 1.5 倍扩边、时序段两端各延 1 帧（给 grounding 奖励的 IoU 匹配留容差）。两阶段共用同一语料，**无需任务特定 SFT 冷启动**——这得益于蒸馏本身提供的稠密信号。

数据清洗中最有想法的一步是"8 次采样审计"：对每个样本分别测"给全输入"（F）与"只给标注证据区域"（E）的通过率。F 太高说明题目太易（基座闭眼能答，训练无增量）、F 太低说明太难（策略永远拿不到 R_ans，梯度消失）；E 与 F 差距异常则说明证据不支持答案或标注质量差。这一步把"可训练性"作为数据筛选标准，比单纯按难度过滤更贴近 RL 的实际需要——值得所有做 RL 数据工程的团队借鉴。

### 五、 评估指标与实验证据

#### 5.1 基准与主结果

14 个基准 = 7 图像（V*、HR-Bench-4K/8K、VisualProbe、ZoomBench、MME-RealWorld、PerceptionBench）+ 7 视频（Video-MME、Video-MME-v2、MVBench、MLVU、MME-VideoOCR、VSI-Bench、V-STaR）。

| 指标 | 基座 Qwen3.5-9B | Reframe | 提升 |
|---|---|---|---|
| Image Avg | 63.46 | **69.48** | +6.02 |
| Video Avg | 49.75 | **53.10** | +3.35 |

单项亮点：V* 91.62（+7.85）、VisualProbe 57.48（**+13.60**）、ZoomBench 59.88（+9.35）、HR-Bench-8K 83.50（+6.62）、MLVU 70.10（+6.27）、Video-MME 69.07（+4.07）。对最强外部模型 Thyme：图像平均超 **11.71** 分、视频平均超 **8.86** 分，14 个基准全部领先 Pixel-Reasoner/Thyme/DeepEyes/DeepEyesV2。

观察单项提升的分布可以读出方法的作用面：提升最大的 VisualProbe（+13.60）、ZoomBench（+9.35）、V*（+7.85）、HR-Bench-8K（+6.62）全部是**显式考察细粒度局部证据**的基准（小物体定位、放大后识别、高分辨率细节）；而偏全局理解的基准提升相对温和。这与"增益来自工具观测使用改善"的归因一致——越是需要凑近看的任务，越吃到观测依赖的红利。

#### 5.2 诊断指标：观察依赖度与工具增益（本文方法论亮点）

论文设计了两把"因果审计尺"，直接度量"模型是否真的在看"。这源于一个朴素的追问：准确率涨了，可能是工具的功劳，也可能是模型碰巧变强了——怎么区分？答案是做**对照实验式的评测**：把"工具返回的观测"这个变量单独替换掉，看模型成绩怎么变。

**依赖度（Dependence）的构造**（在 V* 上测量）：

- **GT 条件**：正常给真观测时的准确率；
- **Random 条件**：把工具观测换成随机区域的裁剪；
- **Blank 条件**：把工具观测换成空白图。

公式：Dependence = 100×[GT−(Random+Blank)/2]/[100−(Random+Blank)/2]。直觉读法：分子是"真观测比假观测多挣的分"，分母是"离满分还有的余量"——依赖度就是"真观测贡献占剩余空间的比重"。

**各模型实测结果**：

- **观察依赖度**（V* 上）：**Reframe 75.53** vs DeepEyesV2 41.93 / Thyme 34.20 / Pixel-Reasoner 23.25 / DeepEyes 19.47。GT 条件准确率 96.86 对 Random 85.86 / Blank 88.48——给真图 96.86 分、给假图掉到 86-88 分，差距就是"真看"的证明。换句话说，DeepEyes 只有 19.47 依赖度：把它的工具观测换成空白图，成绩几乎不动——工具基本是摆设。
- **工具增益**（7 图像基准平均）：有工具 vs 无工具的分数差。Reframe **+5.23**（64.25→69.48），Thyme +1.47 / DeepEyes +1.32 / Pixel-Reasoner +0.97 / DeepEyesV2 **−2.45**（工具反而是负担）。相对基座的总增益中 **87% 来自工具使用**。

这两个指标合起来构成一次严格的"因果审计"：依赖度证明"给了假观测模型会掉分"（真在看），工具增益证明"给了真工具模型会涨分"（看得有用）。对照外部模型的数字颇具揭示性——DeepEyesV2 的依赖度 41.93 看似不低，但工具增益是 −2.45：它的"依赖"是"有工具反而妨碍"意义上的依赖。Reframe 两项（75.53、+5.23）同时登顶，且无工具准确率仅 +0.22 排除了通用能力提升的混淆——这才是"真看图"的完整证据链。

#### 5.3 消融与对照

| 对比对象 | 结果 |
|---|---|
| Mix-RL（同奖励混合数据直接 RL） | 图像 66.75 / 视频 51.41，Reframe 超出 2.73/1.69；且 Mix-RL 落后单模态专家 1.17/1.37——"混合 RL 保留专家差距"的论断被复现 |
| vanilla MOPD（同教师、无观测修复） | 图像 68.19 / 视频 52.32，OG-MOPD 再 +1.29/+0.78；最大单项 VisualProbe +4.86 |
| outcome-based GRPO（第一阶段消融） | GD-GRPO 图像平均 +2.07（65.85→67.92）；依赖度 52.59→**69.03**；工具增益 +1.97→**+3.82**；而无工具准确率仅 +0.22——增益确实来自工具使用的改善而非通用能力提升 |
| MOPD 对专家的保留率 | Image-RL 增益的 106%、Video-RL 的 85% 被保留；14 项中 5 项反超教师 |

#### 5.4 消融数字的读法

这组消融的排列其实构成一条"拆积木"链，值得按顺序读：

1. **outcome GRPO → GD-GRPO**（+2.07 图像，依赖度 52.59→69.03）：单独验证"dropout + grounding 奖励"对观测依赖的因果作用；
2. **GD-GRPO 专家 → Mix-RL 统一**（专家被拉低 1.17/1.37）：单独验证"混合 RL"路线的失败，为 MOPD 的必要性背书；
3. **Mix-RL → vanilla MOPD**（图像 66.75→68.19）：单独验证"token 级多教师蒸馏"相对混合 RL 的增益；
4. **vanilla MOPD → OG-MOPD**（图像再 +1.29）：单独验证"观测门控修复"这最后一块积木。

每一块积木的边际贡献都被独立量化，且方向与第三部分的问题定义一一对应——这种"问题-解法-消融"三点对齐的实验设计，是本文说服力的主要来源。

### 六、 效果优势的根源解释

#### 6.1 因果链：方法差异 → 机制变化 → 指标提升

**因果链一：grounding 奖励 + 原图 dropout → 打破观测忽视。**
方法差异：R_obs 独立于答案对错奖励信息性裁剪/选帧；p=0.5 的 dropout 在训练中随机移除原始视觉输入。机制变化：dropout 分支下答案必须依赖工具观测才有得分路径 → 策略梯度把"使用观测"从可选行为变成必经行为；R_obs 则保证模型先学会"裁到哪里"。指标提升：依赖度 52.59→69.03（vs outcome GRPO），工具增益 +1.97→+3.82；同期无工具准确率只 +0.22——排除了"通用能力变强"的混淆解释，增益确实来自工具交互质量。

**因果链二：MOPD 的 token 级稠密反馈 → 消除混合训练的专家差距。**
方法差异：不用"混合数据轨迹级 RL"，而用学生自采样 + 双教师逐 token 反向 KL。机制变化：轨迹级优势把图像/视频两种模态的探索耦合在一个标量里（一次更新同时被两种模式的不一致梯度拉扯），且信用分配只到轨迹级；token 级路由让图像 token 只被图像专家纠正、视频 token 只被视频专家纠正——模态冲突被路由隔离。指标提升：Mix-RL 落后专家 1.17/1.37，Reframe 保留专家增益的 106%/85%，5 项反超教师。

一个补充的机制细节：为什么 MOPD 能"保留 106%"甚至反超？因为教师并非外部更强模型，而是与学生同基座的第一阶段专家——师生的表示空间天然亲近，蒸馏不至于引入分布撕裂；且第一阶段的 RL 探索已经撑开了"使用观测"的行为流形，蒸馏只需在这一流形上做密度重排（把图像专家与视频专家各自的高密度区拼进一个策略），难度远低于从零学新行为。这也部分回应了"学生为何能超教师"的疑问——学生继承的是两个专家的并集能力而非单教师上限。

**因果链三：观测门控修复 → 蒸馏不再条件于坏观测。**
方法差异：IoU<δ 的缺陷动作被替换为规范动作并从修复后观测续采；注入 token 单独 NLL 监督。机制变化：token 级反馈再稠密也无法追溯修复"已经返回的坏观测"——门控在工具动作边界介入，使后续所有蒸馏信号都条件在有效观测上；NLL 分支同时教学生自己产出正确动作（授人以渔）。指标提升：比 vanilla MOPD 图像 +1.29 / 视频 +0.78，VisualProbe 单项 +4.86。

这里可以用"考场类比"体会门控的必要性：vanilla MOPD 像一位好老师批改一份"抄错了题"的答卷——批注再细致，学生复习时对的也是"错题下的正确解法"；OG-MOPD 则是先把抄错的题目改正、再让学生在正确的题目下练习——同样 的批改精力，落到有用的地方。VisualProbe（考察空间关系推理、对裁剪质量极敏感）单项 +4.86 恰是这一机制作用的直接证据。

**因果链四：两阶段互补 → 87% 增益来自工具。**
方法差异：先 GD-GRPO 建立观测依赖，再 OG-MOPD 保证观测有效。机制变化：若学生不看观测，修复白修；若观测总坏，依赖无处安放——两阶段互为前提。指标提升：总增益 87% 归因工具交互、依赖度 75.53 领先第二名的近一倍（第二名 41.93）。

**因果链小结**：四条链分别对应"训练范式四性质"中的 (c)(a+b)(d)(互补性)。方法差异（dropout、门控、token 级路由）→ 机制变化（依赖被制造、模态冲突被隔离、监督条件被修复）→ 指标提升（依赖度 52.59→69.03→75.53 的两级跳、专家增益保留 106%/85%、vs vanilla MOPD +1.29/+0.78），每一环都有消融数字背书——这在因果论证的完整性上属于示范级。

#### 6.2 外部检索交叉验证

**（1）"观测忽视/视觉遗忘"现象的独立印证：**

- IMAgent（Training Multi-Image Vision Agents via End2End RL, arXiv 2512.8980, https://www.alphaxiv.org/abs/2512.8980）独立报告了同类现象并命名为 visual forgetting："推理链推进时，注意力从视觉 token 转移到自生成文本"，随生成上下文增长模型逐渐忽视初始视觉输入。其对策是为多图场景设计"视觉反思/重看"工具让模型主动重新聚焦——与 Reframe 的"训练机制强制依赖"路线不同，但现象学证据高度一致，说明观测忽视是 VLM 的普遍病灶而非本文孤例。
- ForeSight（CVPR 2026, https://openaccess.thecvf.com/content/CVPR2026/html/Wu_See_Further_Think_Deeper_Advancing_VLMs_Reasoning_Ability_with_Low-level_CVPR_2026_paper.html）同样以"细粒度视觉特征被忽视"为出发点，用低层视觉工具 + 掩码式视觉反馈（mask-based visual feedback）让模型在推理中"重新检查视觉证据并动态修改答案"。它与 Reframe 互补地证实：无论从工具侧还是反馈侧入手，"迫使模型回看视觉证据"都是 2026 年视觉推理改进的共识方向。

**（2）方法学根基（OPD/MOPD）的外部佐证：**

- VESSL 技术博客（How open models actually learn new abilities in 2026 — Part 1: the on-policy-distillation shift, https://vessl.ai/en/blog/on-policy-distillation-part-1）系统梳理了 OPD 谱系：GKD/MiniLLM（2023）→ Thinking Machines Lab（2025.10）推广 → 2026 年爆发式跟进，并给出与本文一致的动机分析——"混合 RL 把多领域探索耦合在一个稀疏标量奖励里互相拉扯"（引 LongCat-Flash-Thinking 的四域长度冲突证据），OPD 是唯一同时"dense + on-policy + 可并行"的方法。这为本文"用 MOPD 替代 Mix-RL"的选择提供了独立的行业级佐证。
- GKD 原论文（Agarwal et al., ICLR 2024，转引自 https://lacuna.tiptreesystems.com/work/gkd-generalized-knowledge-distillation-for-auto...）确立了"学生自采样 + 教师逐 token 反馈 + reverse KL（mode-seeking）"的技术主干，并被后续 OPSD、π-Distill、Skill-SD 等扩展到多轮 agent 与多模态——Reframe 的 OG-MOPD 正是这条谱系在"观测状态对齐"维度上的新一步。

**（3）相反/警示结论的呈现：**

- OPD 谱系综述（https://www.kevinf.site/topics-opd-survey-2026.html）与 HuggingFace 直播教程（https://www.vibeleaderboard.ai/intel/28e7250f-b115-4c74-b539-b1544ad8aafc）都指出 OPD 的理论天花板：**"学生难以超越教师"**（教师只打分不生成，学生的上限被教师的分布锁住）。Reframe 的"14 项中 5 项反超教师"与此形成有张力的对照——可能的解释是教师（第一阶段专家）与学生共享基座、且 RL 阶段的探索已把可达状态空间撑开，但这一点论文未深入讨论，读者应对"蒸馏超越教师"的机制保持审慎。
- 另一个值得注意的边界：closed API 模型不暴露 logits，logit 级 OPD 无法使用（vibeleaderboard 教程明确指出）——Reframe 的双教师均为自训专家，恰好绕开了这一限制，但也意味着本框架无法直接借用闭源前沿模型做教师。

**（4）本次检索范围内未发现**：其它在 MOPD 中主动修复 rollout 观测状态（observation gating + 注入 token 分支感知监督）的公开工作——现有 MOPD 细化路线（路由、收敛、漂移、跨模态）均不干预轨迹本身。这支持论文"首次把观测状态作为对齐对象"的新颖性主张。

**（5）对"反直觉数字"的交叉核对**：论文报告 DeepEyesV2 的工具增益为 −2.45（工具反而降分），这类"负增益"容易引起怀疑。检索到的 IMAgent 与 ForeSight 证据链可以解释其合理性：视觉遗忘/观测忽视现象下，工具调用挤占了推理预算与上下文位置，却不带来被使用的证据——净效应为负完全符合机制预期。Reframe 的贡献恰恰是把这一"行业暗病"量化并治好（+5.23）。

**（6）检索交叉验证的总体判断**：问题诊断（观测忽视）有两个独立来源印证，方法主干（OPD/MOPD）有坚实谱系与行业采用背书，核心创新（观测对齐）在检索范围内无先例；"学生反超教师"与 OPD 理论直觉的张力是最大的开放问题。另需指出：本论文所有对照数字均为论文自报，检索未发现独立第三方复现——对 11.71/8.86 这类大幅领先，等社区复现确认是合理的态度。

### 七、 必要知识反推

要真正读懂这篇论文，按依赖顺序需要以下知识模块：

1. **VLM 基础与"证据稀疏瓶颈"**：视觉编码器 + LLM 的架构、高分辨率/长视频输入下关键证据被 token 稀释的问题——理解"为什么要 crop/select 工具"。
2. **agentic 工具调用循环**：模型输出结构化工具动作（bbox、帧索引）→ 环境返回观测 → 观测拼回上下文继续生成。理解"观测状态"一词指什么。
3. **GRPO 与组相对优势**：同 prompt 采样一组、组内标准化计算优势的 RL 算法；为什么组内条件不均质会污染优势估计（理解 drop 条件化子组的必要性）。
4. **知识蒸馏的 KL 方向性**：forward KL（mode-covering，平均化）vs reverse KL（mode-seeking，锐化）的差异，以及 off-policy SFT 的曝光偏差（训练见到的状态与推理时自己到达的状态不一致）。
5. **OPD/MOPD 谱系**：GKD → MiniLLM → Thinking Machines 配方 → 多教师路由。理解"稠密 + 在策略 + 可并行"三位一体为什么关键。
6. **IoU / grounding 概念**：边界框交并比、时序段定位；理解 R_obs 的计算与防刷分设计（一对一匹配、0.85 折扣）。
7. **dropout 作为训练手段的一般原理**：经典 dropout 防过拟合 vs 本文"逼依赖"的反向用法；条件分组归一化与预采样标志的独立性考量。
8. **评测协议设计**：Random/Blank 对照的依赖度公式、工具增益的差分定义——理解为什么这两把尺子比裸准确率更能诊断"真看假看"。

**学习优先级建议**：若时间有限，按"2 → 4 → 3 → 5"顺序补课收益最大——工具调用循环（2）定义了"观测状态"这个全文核心概念；KL 方向性（4）解释了为什么选 reverse KL、为什么 OPD 稠密且在策略；GRPO 组归一化（3）是理解 drop 条件化子组的前提；OPD 谱系（5）则帮助把本文放进大图景。VLM 架构（1）与 IoU 细节（6）可在需要复现时再深入。

**推荐阅读路径**：GKD 论文（方法学根基）→ Thinking Machines 的 OPD 博客（工程配方与成本数字）→ 本文第三/四部分（问题定义与解法）→ 本文 5.2 节原文（诊断协议的正式定义）。掌握这四步后，读者应能独立判断：自己的场景里"观测忽视"是否存在、该用哪把尺子量、以及 dropout/门控哪种干预适用。

- 观测忽视与"工具调用不准确"是同一个问题吗？（不是——前者是"拿到了好观测也不用"，后者是"想用但拿不到好观测"，分别对应两阶段）

### 八、 通用性灵感

1. **"对齐对象"可以从输出扩展到状态。** Reframe 最大的思想增量是：训练信号不仅要对齐"模型说什么"（输出分布），还要对齐"模型处在什么状态"（观测、上下文、环境反馈）。这个原则可以迁移到任何 agent 训练场景：代码 agent 的执行结果、搜索 agent 的检索片段、GUI agent 的截图——监督若条件在坏状态上，再稠密也是精装修危房。2. **"制造依赖"是一种通用训练技术。** 原图 dropout 的本质是：随机移除信息通道，迫使模型使用你希望它使用的那条通道。对话系统不引用检索文档？训练时随机丢问题原文。代码助手不读测试输出？随机丢源码。凡是"模型绕过应有信息源走捷径"的地方，这个模式都适用。
3. **过程奖励与结果奖励解耦能治"碰巧对"。** R_obs 与答案对错无关、只评动作质量，这切断了"捷径碰对也得奖"的漏洞。任何存在"结果可碰巧对"的领域（医疗诊断、法律检索、数据分析）都值得引入"证据获取质量"的过程奖励。
4. **修复要在边界上做，且要教学生自己修。** OG-MOPD 的两个细节堪称范本：只在"无效观测"的边界介入（保 on-policy 性质）；注入的动作用 NLL 单独监督（不只借结果，还学动作）。类推：人类导师改作业时不是替学生重做，而是指出正确一步再让学生继续——并要求学生记住这一步是怎么想到的。
5. **诊断指标比排行榜更能定位真问题。** Random/Blank 依赖度审计暴露了 SOTA 模型"工具仪式化"的真相（DeepEyesV2 工具增益为负）。设计任何系统前先问：我的评测能否区分"真用了机制"与"绕过机制碰巧对"？
6. **两阶段互补 > 单阶段堆料。** "先建立依赖、再保证供给"的次序有普遍意义：推荐系统先让模型学会用特征、再保证特征质量；RAG 先让模型学会引用、再提升检索精度。次序颠倒则两头落空——先给好观测（模型不看）或先逼依赖（观测总坏）都只拿到一半收益。
7. **对极简工具集的启示。** 只用 crop + select 两个工具就拿到 14 基准全面提升，说明 agentic 能力的瓶颈常不在工具数量而在"用没用好"。先深挖两三个工具的观测依赖，可能胜过急着接一屋子工具。
8. **保持审慎的开放点。** 学生反超教师与 OPD 理论直觉的张力、grounding 奖励依赖标注证据质量、仅两个视觉工具的通用性——这三点是复用该框架前必须自己回答的问题。
9. **"标注依赖"是双刃剑。** R_obs 与观测门控都依赖标注的 grounding 证据（bbox、时序段），本文靠 Reframe-100K 的五步清洗保证质量；想迁移到没有标注证据的领域，需要先解决"规范动作从哪来"（弱监督、模型自标注、人工规则），这是框架落地的最大工程成本。
10. **读论文的方法论收获：诊断先于治疗。** 本文先定义并测量了"观测忽视"（依赖度审计暴露同行 SOTA 的工具仪式化），再针对病因设计 dropout 与门控——"先建立测量，再改进机制"的顺序使每个设计决策都有明确的病灶对应。做系统改进时，先问"我有没有一把能暴露真问题的尺子"，往往比先问"我该用什么新机制"更关键。
