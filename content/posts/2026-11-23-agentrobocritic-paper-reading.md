## 一、论文背景：episode 级成功率遮住了什么

先看一个具体场景：让机器人『打开盒子、取出橡皮、盖上盖子』。现有的评测方式是等整个 episode 跑完，给一个 0 或 1 的成功率。假设成功率是 60%，你能回答下面任何一个问题吗——它是怎么成功的（一次到位还是失败后自我纠正）？它败在哪里（没抓住橡皮？对不准盒子？碰倒了别的东西）？同一个 60%，可能意味着完全不同的能力画像。

这就是当前机器人评测的核心痛点：**episode 级二值分数只告诉你结果，不告诉你过程**。

与此同时，机器人基础模型本身正在经历范式更替。此前有两条主线：

- **VLA（Vision-Language-Action 模型）**：把视觉-语言模型适配成直接输出低层动作的策略，如 π0.5、OpenVLA。它们在训练分布内很强，但分布外泛化脆弱、长程记忆有限，部署到新任务通常要微调。
- **WAM（World-Action Model）**：基于视频生成世界模型构建的策略，先想象结果再行动，同样面临数据与泛化瓶颈。

第三条路线是本文的主角：**前沿多模态语言 agent 直接控制机器人**。以 GPT-6 Astra 为代表，这类 agent 不经过任何专门的动作头或策略解码器，直接以结构化文本形式输出 6-DoF 末端位姿、关节角、夹爪开度等低层数值动作，通过 tool call 下发给机器人。已有报告显示它们在多个基准上零样本超越了专门的 VLA 和 WAM——这引出一个诱人的设想：前沿语言 agent 能否直接充当通用机器人策略？

要回答这个问题，就必须把评测从 episode 级下沉到**动作级**。但动作级评价有个根本性的拦路虎：**操作任务天然是多模态的**（multiple valid trajectories）。机械臂向下移动三厘米，可能是在接近目标，也可能是在试探性触碰，还可能是失误——同一个动作，意图不同，成败判定完全不同。脱离意图孤立地评判一个动作，问题本身就是病态的（ill-posed）。

本文的破题思路由此而来：**让策略 agent 自己在每个动作旁边声明局部意图，用这个意图作为动作级评价的锚点**。评价问题从『这个动作对不对』变成『这个动作有没有达成它声明的意图』——后者是可验证的。

## 二、论文定位和关联工作：三条研究谱系的交汇

### 2.1 谱系一：语言模型上机器人——从间接指挥到直接控制

| 工作 | 核心思想 | 与本文的关键区别 |
|---|---|---|
| SayCan / Skill 规划（CoRL 2022） | LLM 在预训练技能库上做规划 | 执行委托给技能，不反映 agent 自身具身能力 |
| Code as Policies（ICRA 2023） | 生成调用感知/控制 API 的程序 | 同上，执行靠控制原语 |
| 前沿 agent 直接控制（2026 一批报告：RoboDojo 评测、RoboMME、Astranomy、RoboColiseum、GPT-GEAR 等） | 数值动作直接从观察生成 | **全部只在 episode 级打分**，本文补上动作级 |

这条谱系的演进逻辑很清晰：早期 LLM 只当『大脑』，小脑（技能、原语）另配；前沿 agent 出现后，大脑开始直接伸手。本文指出，只有直接控制才能反映 agent 与原语解耦的内在具身能力——而这正是需要动作级刻画的部分。

### 2.2 谱系二：机器人失败检测与推理

| 工作 | 核心思想 | 与本文的关键区别 |
|---|---|---|
| REFLECT（CoRL 2023） | 总结机器人经验做失败解释与修正 | episode 级经验总结，无动作级契约 |
| AHA（ICLR 2025） | 用程序化扰动示范合成失败数据，微调 VLM 做失败检测 | 失败是**人工制造**的，粒度在轨迹级，无意图锚定 |
| RoboFAC / ViFailback | 失败数据+分析+修正闭环 | 聚焦 VLA 失败与纠正指导 |
| FailBench | 评测 VLM 判任务成败的可靠性 | 只判任务级成败，不做失败模式归因 |

本文的差异点：分析的是前沿 agent 轨迹中**自然发生**的失败，且把动作级评价锚定在 agent 的局部意图上。

### 2.3 谱系三：诊断式具身评测（同期工作）

同期出现的 Mind2Act World（arXiv 2611.26444，本站此前已精读）把操作拆成记忆/执行/组合三个能力视角、用 21 个失败码归因，并把本文作为相关工作引用。两者的分工其实相当清晰：Mind2Act World 是**任务设计侧**的诊断基准——通过精心构造的任务分离能力；AgentRoboCritic 是**轨迹分析侧**的评价框架——对任意既有轨迹做动作级裁决。前者回答『哪种能力弱』，后者回答『每一步发生了什么、意图有没有兑现』。另外 Embodied First Exam 提供了开放 harness 但同样只有 episode 级验证；RoboMeter / LLM-as-a-Verifier 一系（第六部分详述）用轨迹级奖励模型做进度估计，粒度仍停在整条轨迹。

### 2.4 定位结论

AgentRoboCritic 站在三条谱系的交汇处：直接控制范式提供了研究对象（前沿 agent 的数值动作流），失败检测研究提供了评论器的雏形（但缺意图锚定），诊断式评测提供了动机（episode 分数不够用）。它填的坑是：**第一个经过人工验证的、意图锚定的动作级评价框架，外加一套 12,844 动作的开放数据资产**。

## 三、问题定义：用局部意图把病态问题变成良定义问题

### 3.1 从具体困难到抽象结构

具体困难：评判一个孤立动作的成败是歧义的——『同一动作可以是失败也可以是成功，取决于意图』。机械臂在杯子旁边闭合夹爪，如果意图是『抓起杯子』，这是失败；如果意图是『把杯子往左推一点』，这可能是成功。

抽象洞察：这本质上是一个**评价契约缺失**的问题。episode 级评价之所以可行，是因为全局目标 G 提供了唯一契约；动作级评价病态，是因为没有对应每个动作的局部契约。解法不是让评价器去猜意图，而是**让意图显式化、机器可读、逐动作绑定**。

### 3.2 形式化定义

直接控制范式：at ∼ π(·|G, O_pre_t, ht)，agent 从全局指令 G、当前观察、交互历史输出数值动作。

本文扩展为意图锚定轨迹：**(at, gt) ∼ π(·|G, O_pre_t, ht)**——每个动作 at 与一条自然语言局部意图 gt 联合生成，轨迹 τ = (O_pre_t, at, gt, O_post_t)×T。

动作级评论器定义为映射：**(ŷt, mt̂, êt) = C(G, gt, Ot)**，其中观察窗口 Ot = (O_pre_t, O_post_t, O_aux_t) 包含动作前后多视角帧与可选辅助帧（如闭合后的抬升检查帧）；输出三部分：

- ŷt ∈ {Achieved, Failed, Partial, Unverifiable}：动作级结果
- mt̂：失败时的失败模式（七类之一）
- êt：一段引用具体物理证据的诊断注释

### 3.3 这个抽象的精妙之处

意图 gt 由策略自己声明、在动作发出的同一 tool call 中提交——评价的锚点与被评对象同源且同时序，不存在事后编造意图的空间（harness 拒绝缺失意图的 tool call 并强制重发）。这相当于给每个动作建立了一个**可验证的局部合同**：合同内容是 agent 自己写的，评价只问一个问题——合同兑现了吗。Partial（有意增量移动）与 Unverifiable（遮挡/截断）两个类别进一步保证了标注的诚实性，避免把『看不清』硬判成成败。

## 四、问题解法：从轨迹采集到开源评论器

### 4.1 意图锚定轨迹采集

**类比**：像是给流水线上每个工位装了『工单联单』——工人每次操作必须随单声明本步要干什么，漏填单子直接退回。

前沿 agent 本来就通过结构化 tool call 行动，这给了天然的注入点：框架给每个 tool call 扩展一个**强制的 note 参数**，agent 在其中陈述该动作的局部意图（例如『再下降三毫米，夹住硬币露出的上半部分』）。缺失 note 的调用被 harness 自动拒绝并要求重发。对于 5 个已发布轨迹的基准（RoboDojo、StationeryBench、Astranomy、UniVTAC、OpenViTac），则通过统一对齐适配器把原生决策注记与动作前后帧配对。作者还验证了强制意图不伤害策略表现：在 76 个匹配实例上，GPT-6 Astra 带不带意图要求成功率完全一致（均为 55.3%）。

### 4.2 评论器与失败分类学

评论器输入 (G, gt, Ot)，输出结构化标注。标注协议遵循三条设计原则：

| 原则 | 内容 | 防的什么坑 |
|---|---|---|
| 接触感知时间窗 | 抓取闭合类动作必须看 O_aux_t（闭合后抬升帧）才能判断持有 | 只看闭合瞬间会漏掉『闭合了但没抓住』 |
| 局部有效性与 episode 结果解耦 | 严格按 gt 裁决；已被恢复的早期失败仍是动作级失败；故意的试探性松夹若达成 gt 则算 Achieved | 防止后见之明污染动作级标签 |
| 证据有界归因 | 失败注释必须写明手臂、目标物、接触几何、失败时机；不许臆测隐形的力/摩擦/标定缺陷 | 防 LLM 幻觉出看不见的失败原因 |

七类失败模式（附代码本 M1-M7，含定义/边界规则/示例）：

| 失败模式 | 含义 | 典型例子 |
|---|---|---|
| GRASP | 物体未被获取或未被保持 | 意图拿起碗，碗还在桌上 |
| ALIGNMENT | 持有物或接触偏离局部目标关系 | 插头停在插座旁边 |
| INTERFERENCE | 非预期碰撞/扰动毁掉意图 | 前臂撞倒旁边的积木堆 |
| EFFECT | 工具受控但未产生声明的效果 | 刮擦工具接触了但表面没变化 |
| INCOMPLETE MOTION | 动作未完成且无更具体机制 | 复位动作中途停在半空 |
| CHOICE | 执行与意图声明的物体/顺序/类别矛盾 | 意图按 3 键却按了 7 键 |
| UNRESOLVED | 失败但证据无法定位机制 | 关键接触被遮挡 |

GRASP 进一步细分为 14 个子类（S1-S14），覆盖闭合时（夹在物体上方/侧方、只夹到边/尖端、把物体推走等）、捕获后（首次抬升滑落、搬运滑落、交接失败等）与空爪动作等。

### 4.3 规模化标注与人工验证

用 GPT-6 Astra 作评论器，标注 12 个操作基准（RoboDojo 五维度、StationeryBench、Astranomy、UniVTAC、OpenViTac、ContactBench 1.0、LIBERO-MAX、Meta-World+、DexJoCo、RoboWits、RoboTwin 2.0、YAMLab），共 2,027 个 episode、约 12,844 个训练动作（成功:失败按 1:3 采样，3,211 成功 + 9,633 失败）。另建 **400 动作人工标注集**（34% 成功 / 66% 失败），标注员通过 web 界面看与评论器完全相同的输入，独立标注结果与失败模式。

### 4.4 开源评论器蒸馏

在 12,844 动作上 LoRA 微调开源 30B 模型 Muse-Glimmer-30B（rank 32、lr 5e-5、2 epochs、上下文 65,536），把前沿评论能力蒸馏到开源模型，episode 级切分保证测试集无泄漏。输入输出格式与 GPT-6 Astra 评论器一致：目标是 JSON（结果+失败模式+GRASP 子类+短注释），温度 0 解码，非法 JSON 记为错误。

## 五、评估指标与实验证据

### 5.1 指标体系

- **主指标（评论器可靠性）**：400 动作人工集上的 Outcome 准确率（全部动作）、失败模式准确率（264 个失败动作）、Overall（两者都对才算对），辅以 Cohen's κ。
- **消融指标**：去掉 gt 后评论器是否崩溃——直接检验意图锚定的必要性。
- **分析指标（能力刻画）**：恢复率（失败后被同 episode 内后续动作可验证解决的比例）、恢复率与官方成功率的 Pearson 相关、失败模式分布、GRASP 子类分布。
- **策略对比指标**：零样本 episode 成功率（对 π0.5 / InternW0-Δ）、决策时延。

### 5.2 评论器可靠性：GPT-6 Astra 第一，消融崩塌

| 评论器 | Outcome % | 失败模式 % | Overall % | 成本 $ |
|---|---|---|---|---|
| GPT-6 Astra | **79.25**（κ 0.497） | **80.68**（κ 0.600） | **71.25** | 26.06 |
| GPT-6 Astra 去掉意图 gt | 25.25 | 25.00 | 24.50 | 25.18 |
| Claude Fable 5.2 | 78.25 | 72.73 | 71.00 | 26.52 |
| GPT-6.1 Sol | 74.50 | 62.12 | 69.75 | 5.00 |
| Claude Sonnet 5.5 | 56.75 | 32.58 | 50.75 | 5.51 |
| Muse-Glimmer-30B 零样本 | 52.50 | 32.58 | 34.75 | 1.34 |
| **Muse-Glimmer-30B 微调（本文）** | 76.25 | **74.24** | 67.75 | **0.79** |

三个关键读数：

1. **GPT-6 Astra 三项全第一**；人复核与其不一致的样本后，多数接受了它的裁决（分歧多为复合失败——一次动作同时构成 GRASP 与 ALIGNMENT），接受后一致率超过 90%。
2. **去掉意图 gt 是毁灭性的**：79.25% → 25.25%，大量动作被标成 UNVERIFIABLE——没有意图锚点，同一动作无法裁决。这是全文最重要的消融。
3. **微调开源评论器**：失败模式 32.58% → 74.24%（+41.66），超过除 GPT-6 Astra 外的全部闭源模型；推理成本 0.79 美元，比 GPT-6 Astra 低 30 倍以上。

另一个漂亮的自偏好检验：GPT-6 Astra 既当策略又当评论器，会不会给自己放水？在 264 个人判失败的动作里，GPT-6 Astra 只把 19 个（7.2%）错标为 Achieved，是所有评论器中**最少**的（Claude Fable 5.2 反而标错 75 个/28.4%）——自评最严，跨模型家族的与人一致性成立。

### 5.3 动作级分析揭示了什么

**能力侧三大发现**：

- **闭环恢复**：49.8% 的成功 episode 含至少一次失败动作；含 1-2 次失败的 episode 仍有 40.3% 成功率（零失败为 75.1%）。12,163 个失败动作中，38.9% 在 10 个动作内被可验证恢复，57.7% 在 episode 结束前恢复（6,435 个直接修复 + 589 个绕道解决）；**恢复率与官方成功率的 Pearson r = 0.81**（p=0.001，Spearman ρ=0.86）——恢复能力与任务成功强关联。恢复率对加权方式稳健（按 episode 平均 60.7%，只看首个失败 76.2%）。
- **语义 grounding 可靠**：CHOICE（选错物体/顺序/类别）只占全部失败的 **0.2%**，任何单一基准至多 3.3%——即使面对新物体实例与视觉干扰，agent 行动跟随其声明的意图。
- **零样本强**：RoboTwin 2.0 上 GPT-6 Astra 91% vs π0.5 6% vs InternW0-Δ 0%；YAMLab 上 90 vs 0 vs 0。Embodied First Exam 五个套件的匹配任务上全面领先，且 π0.5 能完成的任务 GPT-6 Astra 全部也能完成。

**局限侧三大发现**：

- **失败集中在低层物理交互**：全量分布 GRASP 54.4%、INTERFERENCE 21.9%、ALIGNMENT 15.4%、INCOMPLETE 5.7%、EFFECT 2.4%、CHOICE 0.2%。GRASP 是 10 个非触觉基准中 9 个的首要瓶颈；在紧公差的视觉版 UniVTAC/OpenViTac 上瓶颈陡转为 ALIGNMENT（分别占 75%/86%）。
- **GRASP 失败六成发生在闭合瞬间**：夹爪闭合时的错误（只夹到边/尖端 25.7%、夹在物体侧方 18.8%、夹在上方 10.2% 等）合计约 60%，捕获后损失仅约 20%——且闭合时 agent 已选对物体、已把夹爪带到旁边，败在毫米级的深度/侧向偏移。**瓶颈不是『选哪个』而是『夹爪相对物体的精细 3D 定位』**。另有 9.5% 是空爪动作——物体早已丢失 agent 还在继续搬，评论器可充当在线监视器当场报警。
- **恢复在不同失败模式间不均衡**：INCOMPLETE 68.2%、GRASP 63.7%、INTERFERENCE 59.1% 多能恢复，但 ALIGNMENT 35.7%、EFFECT 29.6% 只有三成左右，且增加动作数也不收敛——闭环纠错救得了获取类失败，救不了精度受限类失败。

### 5.4 时延代价（诚实报告）

GPT-6 Astra 每次决策中位 31.9 秒，π0.5 只要 0.11 秒——直接控制范式目前不适用于需要实时反应的场景。附录还展示评论器反馈可以指导策略再尝试（DexJoCo 浇花任务：无反馈重试失败，带评论器反馈的重试成功）。

## 六、效果优势的根源解释

### 6.1 根源机制与证据链

**因果链一：局部意图消解轨迹多模态性 → 动作级评价从病态变良定义**

- 机制：操作的多解性使『动作对错』脱离意图不可判定 → gt 把判定标准从全局目标降维到局部子目标，且 gt 由策略在动作发出的同一 tool call 中声明、harness 强制不可缺省 → 评价器获得与被评对象同时序的裁决锚点。
- 证据：**论文实验已支持**——去 gt 消融使 GPT-6 Astra 从 79.25% 崩至 25.25%，失败模式从 80.68% 崩至 25.00%，大量 UNVERIFIABLE；同时带意图要求不改变策略成功率（55.3% vs 55.3%），说明锚点近乎免费。

**因果链二：接触感知时间窗使『持有』可验证**

- 机制：『夹爪闭合』与『抓住物体』是两个事件，后者只有抬升后才能确认 → 闭合类动作的观察窗必须延伸到 O_aux_t 抬升帧 → 持有类失败（首升滑落、搬运滑落）才可被标注而非猜测。
- 证据：**论文设计已内建**（标注协议原则一），GRASP 子类中首升滑落/搬运滑落/交接失败可分（S6-S10）是其直接体现；但论文未对『去掉抬升帧』单独消融——该机制的独立贡献属**阅读者推测**。

**因果链三：证据有界归因抑制幻觉 → 高 κ 的一致性**

- 机制：LLM 评论器的典型失败模式是编造看不见的原因（隐形力、标定缺陷）→ 代码本强制注释只写可见的物体/夹爪/接触/时机，UNRESOLVED 兜底 → 失败归因可被人复核。
- 证据：**论文实验已支持**——人复核接受后一致率 >90%，分歧集中于复合失败（双方各执一半正确）而非幻觉；κ=0.600 的失败模式一致性显著高于其他所有评论器。

**因果链四：蒸馏可迁移性——前沿评论能力可以平价复制**

- 机制：12,844 动作标注把 GPT-6 Astra 的裁决标准（含代码本边界规则）编码为监督信号 → LoRA 微调使 30B 模型内化该标准 → 便宜 30 倍的推理逼近教师。
- 证据：**论文实验已支持**——32.58%→74.24%，且微调后把人判失败错标为 Achieved 的比例从 25.4% 砍半到 12.9%（更严格而非更松）。

**反事实检验**：去掉 gt（链一）→ 全线崩至 25%；不微调（链四）→ 开源评论器只剩 32.58%。两条链的必要性都有直接反事实证据。

### 6.2 相关工作检索与对照

围绕上述机制做外部检索，区分『方法相似』与『结论相近』：

| 研究（可核验链接） | 相似尝试 | 相关结论 | 与本文的差异与适用边界 | 对根源解释的影响 |
|---|---|---|---|---|
| AHA（ICLR 2025，[arXiv:2410.00371](https://arxiv.org/abs/2410.00371)，NVIDIA 等） | 微调开源 VLM 做机器人失败检测与推理，微调后超过 GPT-4o 上下文学习 10.3% | **结论相近**：失败理解是可训练能力，适度微调的小模型可胜前沿模型 | 失败来自对成功示范的程序化扰动（人工合成），轨迹级自由文本，无意图锚定；本文失败自然发生、动作级、意图锚定 | **支持因果链四**：与本文微调 Muse-Glimmer 的跃升互相印证；同时其合成失败分布与本文自然失败分布互补 |
| π0.5（Physical Intelligence，[arXiv:2504.16054](https://arxiv.org/abs/2504.16054)） | 开放世界泛化 VLA，靠异构数据协同训练 | **结论互补**：官方也承认零样本到全新环境并非处处可靠 | 靠动作数据训练的泛化与本文测得其在 RoboTwin 2.0/YAMLab 零样本 6%/0% 相符；π0.5 的优势场景（家庭整理）与这些仿真基准不重叠 | **支持『CHOICE 稀少、瓶颈在物理执行』的对比解读**：语义理解可从网络数据迁移，毫米级伺服不行 |
| RoboTwin 2.0（ICML 2026，[arXiv:2506.18088](https://arxiv.org/abs/2506.18088)） | 强域随机化双臂数据生成器+基准 | 其 VLA 需要配套训练数据才能在自身基准上表现好 | 本文把它当作 GPT-6 Astra 零样本 91% 的舞台之一，凸显前沿 agent 免训练优势 | **补充**：说明 91% vs 6% 不全是基准太简单，域随机化基准本身就为测鲁棒性设计 |
| RoboMeter（CoRL 2025，轨迹对比缩放通用奖励模型） | 100 万轨迹对比训练的通用进度奖励模型，零样本失败检测 F1 0.81 | **方法相似（轨迹级奖励/评价）** | 粒度在轨迹级、无意图契约；承认 8 帧子采样可能漏掉接触细节 | **限定**：轨迹级信号有用但看不见单动作成败——反向衬托动作级+意图锚定的信息增益 |
| LLM-as-a-Verifier / ARS（[arXiv:2609.34484](https://arxiv.org/abs/2609.34484)） | LLM 轨迹级验证分数可作稠密奖励，机器人轨迹进度相关系数 0.966 | **结论相近**：验证器分数与任务进展强相关 | 本文的对应物是恢复率×成功率 r=0.81，且本文粒度更细 | **支持**：两个不同团队、不同粒度都发现『验证/恢复信号与成功强相关』 |
| REFLECT（CoRL 2023） | 总结 episode 经验解释失败 | 早期方法相似 | 无逐动作意图，解释生成而非结构化标注 | **补充**：意图锚定是其自然进化方向 |
| LIBERO-Plus / VLATest（arXiv:2510.13626 等） | VLA 鲁棒性压力测试 | **结论相近**：专门 VLA 在扰动下大幅掉点 | 本文 CHOICE 仅 0.2% 提供了对照组：前沿 agent 语义选择在扰动下依然可靠 | **支持**：语义能力与物理执行能力的薄弱环节不同 |

检索范围内未发现**另一项**同时满足『自然失败+动作级+意图锚定+人工验证』的工作；也未发现反驳『意图锚定提升动作级评价』的相反结论。需要说明的边界：RoboMeter/ARS 的任务设定（轨迹级进度估计）与本文不同，其结论不能直接当作本文因果链的证明，只能作旁证。

### 6.3 综合判断与未决问题

**多项研究共同支持**：(1) 失败检测/评论能力可被微调转移到小模型（AHA 与本文独立证实）；(2) 验证信号与任务成功强相关（LLM-as-a-Verifier 的 0.966 与本文恢复率×成功率的 0.81）。

**仍属本文自证/推测**：抬升辅助帧的独立贡献（无单独消融）；七类失败分类学的完备性（未在跨机器人形态上验证）。

**适用条件与失效条件**：框架依赖策略以 tool call 行动并强制声明意图——对输出连续动作流的端到端 VLA/WAM 不直接适用（作者也承认给 VLA 补可靠子目标声明并不平凡）；31.9 秒的决策时延意味着直接控制只适合低频长程任务；在观察被遮挡的场景 Unverifiable 占比会上升（LIBERO-MAX 达 15%），意图锚定救不了看不见的画面。

## 七、必要知识反推

假设一个零知识的人要复现这项工作，最少需要知道什么？

**领域知识层**：
- 机器人操作的闭环控制循环（观察→动作→新观察）与 6-DoF 末端位姿/关节配置/夹爪开度等控制量含义——不知道这些就无法定义『动作』的边界，更无法设计动作级标注。
- 操作多模态性（同一任务多条有效轨迹）与模仿学习的协变量偏移问题——这是理解『为什么 episode 级分数不够』『为什么恢复能力重要』的理论前提。
- 抓取的物理语义：闭合≠持有，持有需抬升验证。没有这条常识就不会有抬升辅助帧的设计。

**方法论知识层**：
- 评测方法论：Cohen's κ、人工标注协议、标注界面设计（人机同输入）、episode 级切分防泄漏。
- LLM 标注的陷阱与防御：提示注入（把源指令当证据而非指令）、幻觉归因（证据有界原则）、自偏好偏差（跨家族对照检验）。
- 失败分类学构造：边界规则（GRASP vs ALIGNMENT vs EFFECT 的邻接区分）、代码本工程（M1-M7 + S1-S14 两级）。
- 蒸馏与 LoRA 微调流程。

**工程知识层**：
- tool call harness 的强制参数注入与拒绝重发机制——意图采集的实现载体。
- 12 个异构基准的对齐适配器：统一动作单位定义（RoboDojo 按维度、Astranomy 按动作块、UniVTAC 按单意图原语块），这是跨基准分析成立的前提。
- 成本核算：每动作评论的 token 成本、1:3 正负采样平衡。

**知识融合的关键节点**：
1. 『操作多模态性』（机器人学）×『tool call 可强制携带参数』（agent 工程）→ 意图锚定的局部合同——两个领域知识在这一点上化学反应。
2. 『闭合≠持有』（抓取物理）×『LLM 只信所见』（标注方法论）→ 接触感知时间窗。
3. 『评论器要规模化』（成本约束）×『前沿模型标注质量最高』（模型能力分布）→ 用最好但最贵的标注最便宜的模型，蒸馏出平价评论器。

## 八、论文中可以提取的通用性灵感

**灵感一：用声明式局部契约把不可判定的问题变成可判定的**

- 核心思想：当一个评价对象的成败依赖于不可观测的内部意图时，强制行为者**在行为发生的同一条消息里**声明意图，评价问题立即良定义。
- 论文证据：去意图消融 79.25%→25.25%；意图要求不降低策略表现（55.3%=55.3%）。
- 推广场景：(1) 代码评审——要求 PR 描述逐 diff 声明意图，评审只判意图是否达成；(2) AI agent 安全审计——每个工具调用强制附『本次调用目的』字段，事后审计有了锚点（与 Intent Contracts 一系的思路相通）；(3) 人机协作流程管理——下属每个交付物附一条完成定义；(4) 自动驾驶决策日志——变道/刹车与声明的局部动机绑定后才能离线裁决。

**灵感二：恢复率是比成功率更灵敏的能力指标**

- 核心思想：只看终局会掩盖过程质量；度量『失败后被验证解决的比例』能分离『不犯错』与『犯错后能救』两种能力。
- 论文证据：49.8% 成功含失败、57.7% 失败被恢复、恢复率×成功率 r=0.81。
- 推广场景：(1) 软件工程——线上事故的 MTTR 与『事故后自愈率』比故障数更能反映系统韧性；(2) 教育——错题订正率比首答正确率更能预测长期能力；(3) 对话系统——用户投诉后的挽留成功率；(4) 强化学习——per-step 失败的恢复概率可作为稠密奖励设计。

**灵感三：瓶颈的层级定位直接决定改进路线**

- 核心思想：把失败按『语义选择/物理执行』分层归因后，改进资源的投向截然不同——CHOICE 占 0.2% 说明不用再堆语义理解，GRASP 六成败在闭合毫米级偏移说明该投空间精度。
- 论文证据：失败模式分布 + GRASP 子类分布 + 恢复不均衡（ALIGNMENT/EFFECT 只有三成恢复）。
- 推广场景：(1) 模型能力诊断——先归因到知识缺失/推理错误/工具调用错误再选训练数据；(2) 生产制造——缺陷按工序归因后定向改造对应工位；(3) 医疗质控——不良事件按诊断/手术/用药分层统计。

**灵感四：用最贵的教师标注、蒸馏出最便宜的学生**

- 核心思想：当评价能力本身稀缺时，用最强模型大规模标注 + 微调小模型复制标准，能把单位评价成本压低一个数量级以上。
- 论文证据：GPT-6 Astra 标注 12,844 动作 → Muse-Glimmer-30B 失败模式 32.58%→74.24%，单次推理成本从 26 美元级降到 0.79 美元。
- 推广场景：(1) 数据标注平台——专家标一小批、模型标一大批；(2) 代码评审 bot——用旗舰模型生成评审微调集，日常评审跑小模型；(3) 内容审核。

**灵感五：诚实的评价体系必须给『判不了』留出口**

- 核心思想：强制二值裁决会制造系统性噪声；显式设置 Partial/Unverifiable 类别并让兜底标签可追溯，反而提升整体可信度。
- 论文证据：四值结果标签 + UNRESOLVED 与 UNVERIFIABLE 严格区分（失败但机制不明 vs 结果不可知）+ 人复核接受率 >90%。
- 推广场景：(1) LLM-as-judge 评测——加『无法判断』选项降低伪准确率；(2) 医学影像 AI——疑似病灶的『不确定』输出通道；(3) 司法鉴定——证据不足与证据排除的分类。

---

**一句话收束**：AgentRoboCritic 的贡献不在于造出一个更强的机器人，而在于给『前沿 agent 能不能当通用机器人策略』这个新问题配上了第一把足够精细的尺子——尺子的刻度是 agent 自己声明的意图，而测量结果告诉我们：语义理解这道题基本做完了，毫米级的物理执行才刚刚开始。
