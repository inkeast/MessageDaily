## 先说结论

TWIML AI Podcast 主持人 Sam Charrington 这次请回老朋友 Dan Jeffries（依据英文转写整理，全部 27 段、0s–3211s 已完整读取；两人上次对话是 2024 年底谈 computer use agents）。过去六个月 Jeffries 在造 **Nautilo**——他自称「30 个产品合一」的开源组织级 harness，一句话定位是「翻转盖手机版的 Her，但面向团队与家庭」（本站查证：Nautilo 已于 9 月开源发布，仓库在 agentsea/nautilo，官方帖对「秘密守护者」「命名空间」「时间限定解密委托」等表述与访谈完全一致）。整场对话最有价值的是三层判断：其一，个人 agent 刚跨过易用性门槛（节目举例 Meta 的 Muse、OpenAI 的 Dot 开箱即用），但按创新扩散曲线我们仍在 2% 的「早期采用者」段——享受 agent 红利的主要是本就有五十件事待办的高能动性人群，多数人面对无限画布不知道该干什么；其二，大量精心设计的多 Agent 组织架构图在他看来「基本是角色扮演（cosplay/LARPing）」——让同一个底层模型扮演的邮件 bot 和 CEO bot 互相开会，不是在做工作；其三，真正的机会在「有主见的设计」：隐私、自主权、协作共创这些通用大厂产品不会做的取舍。节目名「造 agentic 产品的残酷现实」在结尾兑现：Jeffries 与圈内创业者把当下创业环境称为「那堵墙（The Wall）」——建东西从未如此容易、被看见从未如此困难。

## 「经理人时代」：2% 的早期采用者与 10%/90% 饼图

Jeffries 用计算史给当下定位：这是八十年代末、九十年代初的个人电脑——「你默认它会出毛病、得知道怎么把它装回去」，而不是 iPhone 时代「你只管用它、坏了不知道该找谁」。他写过一篇《Agency Problem》：多数人不知道拿 agent 干什么，受益者集中在高能动性人群——「手头永远压着五件想创的业、三十本想写的书、五十个想去的 trip」的人，无限画布对他们是解放；对其他人则是一头雾水外加一点失业恐惧。他转推过一张 2026 年饼图自嘲：10% 的扇区是自己真正干活，90% 是在伺候那些替你干活的 agent——编程、review、迭代。Sam 用自己的体验背书：自动化确实爽，但那些东西经常坏，corner case 一箩筐，你总得回到代码里。Jeffries 补了个扎心的对照：一个懂技术的老朋友问他「我怎么入门 agent」，他发现这个问题对自己这类人根本不成立——「你跟它说话，它搞砸了你就再跟它说，想想哪错了」；但很多人要的是模板、是「告诉我怎么做的那个东西」，而行业还没有到给模板的阶段[120–360s]。

他引了一篇文章《Tool-Shaped Objects》：日本匠人的木工刨（kanna）是艺术品、刨木头如天使般精准，但经济上完全不值钱——电动刨以零头成本和零头时间干同样的活。他以此讽刺大量 AI 演示视频：「90% 的内容在搭环境，搭完之后真正用它干活的那段，不存在」。他管那些「我搭了邮件 bot、税务 bot，再搭个 CEO bot 管它们」的架构叫 faceless toaster bot（无脸烤面包机）与「LARPing 当 CEO」——「你的 agent 们在互相说话？它们说什么？为什么需要说？底下不是同一个模型吗？」[360–480s]

## Nautilo 是什么：秘密守护者、命名空间与自主权

产品本体：Jeffries 把 agent 称为 Genie（精灵），定位是「老式意义上的 secretary——拉丁语 secretum，秘密守护者」：给每个用户一个深度人格化的超 agent，起名、配图、从三万个 ElevenLabs 音色里挑声音；它记住你的一切、从不 break character。团队重写了群聊：一个「魔法路由器」让人和 agent 在同一对话里自然说话、agent 被点名即醒，人机同为一等公民——之所以不直接接入 WhatsApp/Slack，是因为这些平台的条款诞生于「bot=垃圾信息」时代，接进去要么违规、要么只能挂一个没有人格连续性的单例 AI[600–720s]。

真正有主见的取舍在隐私。Jeffries 引 François Chollet 的判断「AI 将成为我们与世界的接口」，推到结论：十年后你可能都不记得怎么在手机上「打开一个应用」——而如果这个接口是一个 SaaS 应用，那就是「监控经济的平方」：你在它那里聊孩子在学校的问题、聊官司、聊体检结果，「社交媒体对社会造成的伤害，和这个相比不算什么」。他不指望立法解决，路线是赛博朋克式的自主权（self-sovereign）：开源全栈、自己控制服务端与客户端；端到端加密的变体——后端是分布式密钥，Genie 需要读明文，所以给它的是**时间限定的解密委托**：醒来、解密一条聊天或一段记忆、用完即停，没有常驻主密钥。另一层是**命名空间（namespaces）**：你跟自己的 Genie 一对一说的事，不会漏进有同事在的群聊——「节目举例 Muse 把某人的家庭住址说了出去，就是因为它什么都知道而没有命名空间」。他还给模型做隐私分级路由：敏感话题优先走 Venice 这类隐私通道[720–840s, 960–1080s, 2160–2280s]。

## 多 Agent 之争、记忆系统与「哑锤哲学」

Sam 直接唱反调：他用 Hermes（Nous Research 的个人 agent）单 agent 拉技能处理所有领域，「干得挺好」，凭什么要多 Agent？Jeffries 的回应值得整段记下：他也爱 Hermes 团队（转写提到 Teknium 等成员），而且**哲学其实相同**——他信的是一个无所不能的超强 Genie。「这是宠物 vs 牛群的问题：agent 可以自己去 spin up 牛群，但我不想认识牛的名字。」他反对的只是「烤面包机军团」；他说的多 Agent 是「人和 agent 在同一场对话里平起平坐」，这需要在后端造一堆小分类器和路由、共享哪些记忆等机制。一个具体场景：你让 agent 研究明年夏天的旅行，然后你变成「肉身信鸽」把结论复述给配偶——不如把带着记忆与报告的 agent 直接派去和你配偶聊，带回她的意见。Agent 的价值是「上下文守护者+秘密守护者」，人不该在没有完整上下文时当搬运工[840–1200s]。

记忆怎么做？「上下文窗口永远不够，它们全都是 Mr. Meeseeks（瑞克和莫蒂里任务完成即消失的临时角色）。」Nautilo 的方案是压缩哈希：每段记忆存元数据加一个「意义的线索」哈希，agent 先扫哈希、判断哪些值得展开，展开一小段再筛、选中才全文展开读，「读完再开口」；记忆随时间衰减；他称这套东西是记忆突破、打算写论文。一个他们自己也解释不了的观察：即便跑同一个模型，不同 Genie 在各自积累上下文后会呈现出「惊人的人格多样性」。而这套检索路线的底层逻辑是把计算机擅长的事还给计算机——「搜索、检索、规模化、暴力扫描」[1200–1440s]。

这就是他的「哑锤（dumb hammer）」工具哲学：**工具没有智能，锤子只管砸；如果 LLM 要搬运数据、造哈希结构、往数据库里塞东西，你的工具就设计砸了。Agent 负责模糊的智能决策，工具负责确定性地干活，像数据库一样。**「我用 Jev 清理桌面？兄弟，一个 shell 脚本就够了。」PII 清理同理：第一道防线是正则这类哑工具，Jev 只是纵深防御的第二层。Sam 给出同构的版本：Unix 哲学、窄工具——「开发票、改发票，一个工具一件事；而不是把 QuickBooks 的钥匙丢给 agent 让它自己看 schema 摸索」。Jeffries 还补了一个自我修正：新型决策模型（他点了 Jev，本站 10 月 8 日专访过其创始人 Diogo Almeida，两场互为印证）让「锤子开始有魔法」——快速小决策（PII 判定、发票红还是蓝）可以内建进工具；他正在攒一个「中脑」架构：本地快速反射的小模型+云端大规划慢模型，与 Sam 此前在播客里讨论的 fast/slow 思维呼应[1440–1680s]。

## 隐私实践与本地模型的真实瓶颈

具体用什么模型？Jeffries 的答案是分场景路由：工作营销类命名空间里 Claude、转写名 Saul、Astra（疑为 Astra，未确认）随便用；涉及健康、税务等敏感内容则几乎全走 Venice——Erik Voorhees 创办的「关心隐私的 OpenRouter / 模型界的 VPN」，自己跑开源模型、对请求做混捆去标识化、给模型标隐私等级（嘉宾称其年经常性收入已约一亿美元、比 OpenRouter 贵但值得；他催了很多次团队版）。他的隐私模型清单：Kimi K3、GLM-5.3、DeepSeek V4、Flash 4.1。他也坦白自己「被吸进去了」：Codex 天天用、常为自己分享过的信息后怕——「把报税单丢给 GPT 很诱人，我懂」。Nautilo 正在推 BYOK（自带 key）：社区版无法补贴两百万美元算力，用户插自己的 Venice key 即可解锁包括 Seedance 视频在内的全部 Genie 能力[1560–1680s, 2160–2400s]。

本地模型的判断很清醒：Nautilo 暂不支持本地模型，因为还没遇到让他兴奋的——瓶颈不是 GPU 而是**内存与量化**（他期待苹果下月发布的 512GB 内存新机）；现状是「五帧跑游戏」：重度量化、十 token 每秒、本地视频模型生成十秒片段要三十分钟。但企业侧自建（GB200/300 上起一个 OpenAI 风格端点）几天就能接；真正的规模化版本（容器+vLLM+监控+路由）才是企业要造的东西。他押一个六个月内兑现的路径：某个 27B 级、可本地微调的 Jev 类决策模型成为路由与守门层——在你把数据发给「天上那台受补贴的大算力」之前，本地小模型先把人脸、社保号这类 PII 洗掉[1680–2160s]。

对补贴算力他有一套完整的时间窗策略：当下是「八十年代第一口免费」的毒品经济学、Uber 三美元横穿城市的时代，「音乐椅总有停的一天」；所以**趁补贴期用 LLM 把确定性工具造出来——造一次、永远用，而且确定性工具本来就更好**。「太多人把不需要 LLM 的任务交给 LLM。」与他强调的共创（co-creativity）同源：他做站点视频时自己录音、Genie 转写成 MD 文件当场可改、试配音、出风格稿、他批脚本再分层合成——「省下几小时，但不是『请给我东西、吐出来啥都当金子』」。他引某位知名 VC 的话收尾：「别再给我发 AI 生成的 deck 了，一股没下过功夫的味道。」[2400–2760s]

## 「那堵墙」：SaaS 启示录认错与定制软件时代

被问「在今天的環境里造产品是什么体验」，Jeffries 说圈内创业者管它叫 The Wall（他顺势比了个 Pink Floyd）：变现、护城河、注意力、噪声四重困难——工具人人相同、东西都能建出来，于是「被看见」成了主要矛盾；「有时候你看一个东西爆了，完全不明白为什么，你自己试过的十个更好的工具无声无息」。他转述一位朋友的两个新原则：一、我有一个想法时，默认别人昨天就有且昨天已发布；二、不再从商业模式倒推，而是**从营销倒推**——什么能塞进一条带视频的推文、什么「沙丘遇上恐龙」式一句话能过 lizard brain 那一关。他自己的状态是「极度兴奋+极度疲惫并存」：「都说 AI 要把工作都拿走了，我这辈子从没这么拼命干过。」[2760–3000s]

他当众认了一个错：一年半前他说「SaaS 启示录是扯淡，没人会重写这些应用」——现在承认错了：一批高估值公司正在破产或以低估值九成的跳楼价甩卖（他点了 Miro），而他自己在 Nautilo 里用半周复刻了一块 Miro 白板，Genie 还能直接操控它；前阵子开源的 Photoshop 替代品 Compositor 也被设计师社区迅速围拢。他的推论是「定制软件时代」：微软的老笑话是「你只用了 Word 的 5%，而每个人用的 5% 都不一样」——现在你可以只造你要的那 5%；两三年内（时间线照例模糊）agent 能直接吐出可运行的字节码、随口重构，「那会是一个非常难卖软件的环境」。还剩下的护城河在监管、法律摩擦与软硬件结合处——他举 DeepMind 早年与英国眼科合作的教训（转写 Suleyman，应为 Mustafa Suleyman）：技术能检测眼疾，最终死于官僚体系与《卫报》的隐私报道，「他们如今还跑着那些老年系统」[3000–3211s]。

## 行业机制与读者启发

1. **补贴算力 → 建造归零、分发成为唯一瓶颈**。机制：免费/受补贴的智能让任何人一周末造出软件 → 产品数量爆炸、注意力稀缺 → 创业策略从「商业模式倒推」翻转为「营销倒推」；SaaS 的命运分化：无监管摩擦的通用工具被定制重写（Miro 式甩卖），有监管/硬件/法律摩擦的反而获得护城河。二阶影响：软件公司的估值逻辑从功能覆盖度迁移到摩擦占有量。观察指标：高估值 SaaS 的甩卖名单、开源替代品的社区成型速度、agent 直吐字节码何时可用。启发：个人与中小团队的机会恰在「有主见的取舍」——大厂通用产品不能做的事（隐私、自主权、人格连续性）就是差异化本身。
2. **个人 AI 成为世界接口 → 亲密数据入口 → 隐私变成产品维度**。机制：接口越贴心，分享的越是最私密的内容（孩子、官司、健康）→ SaaS 形态等于监控经济平方 → 自主权方案（开源+自托管+分布式密钥+时间限定解密委托+命名空间）与隐私路由（Venice，约一亿美元 run rate）崛起。启发：给「发给模型的内容」分级并路由，是当下就能落地的个人/企业实践；考察任何个人 AI 产品，先问密钥在谁手里、记忆能否按命名空间隔离。
3. **多 Agent 的实用主义边界**。同一个底层模型互相开会是角色扮演；有效形态是「一个全知的超 agent + 按需匿名子 agent（牛群）+ 人机同场协作」。上下文永远不够（Mr. Meeseeks），记忆的正解是压缩哈希+检索+衰减而非更大窗口。哑锤哲学给出工具设计的判据：凡 LLM 在搬运数据、就是工具设计失败——这条判据可以直接拿去 review 任何 agent 系统的工具层。
4. **用补贴造确定性资产**。补贴期把 LLM 当「工厂」而非「运行时」：造一次、永远用的确定性工具既省钱又更可靠；等音乐椅停下（Uber 从三美元涨到七十美元），你手里留下的是资产而不是账单。

## 转写原文（修正版）

[0s - 120s]
