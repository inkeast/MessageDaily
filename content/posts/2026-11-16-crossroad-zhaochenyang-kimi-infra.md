## 先说结论

这一期的十个 aha moments，是一个 AI infra 人写给自己的年终审计。赵晨阳的位置贴着行业最热的一层皮：他参与维护的开源推理引擎 SGLang，是 Kimi K3/K3.1 等国产开源模型上线背后的 serving 底座之一，而他做的事——「用 Kimi K3.1 帮 Kimi K3.1 写 B300 上的推理引擎」——被他本人当作第一个 aha moment 的证据：RSI（递归自我改进）不是预言，是已经在跑的循环。但整期最有分量的判断是第二个：RSI 的瓶颈不在智力，在评估。他信奉「我们能评估什么，就一定能优化什么」：给一个 80M 参数的 TTS 模型定义好指标，Claude Opus 5.5 一个周末把性能拉高 1700%（口述）；而流片、猴子上验证药物这类昂贵评估，模型再聪明也快不起来——所以「低成本、自动化的评估是 RSI 唯一的 bottleneck」。顺着这条主线，他解释了 computer use agent 为什么靠苹果无障碍树而不是截图、开源社区如何在端到端模型缺席时用「级联方案」搭出他每天四万字的语音输入工作流，也讲了从《大明王朝1566》《万历十五年》里读出的治理三课——组织自顶向下腐烂、权责对等、制度先于道德——并把这些直接写进开源社区的 merge 规则。对没听节目的读者，这一期给的是一个可操作的判断框架：把「能否自动化、低成本地评估」当作选择 AI 应用场景的第一过滤器，把「谁拍板、谁担责」当作判断组织与 AI 产品的第一直觉。

## 一、「用 Kimi 加速 Kimi」：RSI 不是预言，是已经在跑的循环

第一个 aha moment 的由头是录制当天上午 Anthropic 发布的 Claude Fable 5.2（经核实，2026 年 11 月 9 日发布；他称出于「商业利益上的矛盾」不便评价这个模型本身）。赵晨阳先给自己的 RSI 下定义：**当这一代模型能够极其 active 地参与自身的部署、或下一代模型的训练时，RSI 的雏形就出现了。**他构造了一个思想实验：假想一家叫 BAI 的公司训出了第七代模型，它会写 kernel、会做 pretrain、懂清理数据——那么第七代可以在自己的推理过程中优化自己的底层 kernel，越跑越快；在第八代训练时参与人类数据筛选（pretrain、midtrain、SFT、RL 全流程都有严格标准）；可以替第八代把推理写好，把每秒 100 token 卖到 200、300 token；甚至帮架构研究者在数十上百种参数排列组合里做初步验证。最极端的情形是第七代到第八代完全不需要人——但他自己划了边界：电要人管、GPU 要人管，「你是不可能把人完全挪出来的。当我们逐渐把人在模型自我迭代过程中的比例降低，这就是我说的 RSI。」

这个 loop 的现实版本就是他自己的工作：「前一段时间我尝试让 Kimi K3.1 帮我们去写 Kimi K3.1 在 B300 上面的推理引擎——用 Kimi K3.1 让 Kimi K3.1 变得更快。」他用阿拉丁神灯作比：聪明的许愿者第一个愿望就是「再给我三个愿望」，于是神灯变成无穷许愿机。时间点他锚定在今年年中 Kimi K3 发布：「这个 loop 已经有了非常明确的体现」，frontier lab 的研究者们已经大量用旧有模型去迭代新的模型；他参加的 OpenSI（口述，即将发布最初雏形，未能公开核实）是开源世界对这条路线的跟进；他还引述朋友的观点把账算到市值上：英伟达市值五万亿（口述，「当然可能今天跌了一些」）、AI 产业数十万亿市值——如果不信 RSI，「我们究竟要卖多少 token、卖多少算力、卖多少保险订单、做多少医疗订单才撑得起这样的市值」？反过来，如果 RSI 能攻克癌症、帕金森，其经济价值不可估量。主持人 Koji 补充：前两期嘉宾对 RSI 有几乎同款的判断——系列②谷雨篇的「RSI 的机会属于没有历史包袱的新实验室」与本期互为印证。赵晨阳自己也承认，信不信 RSI 是 mindset 而非实证命题，他给自己的定位是「激进的人里面很务实的一个」。

把这条链条写全：**旧模型的智力溢出到自身部署与下一代训练（K3.1 写 K3.1 的 B300 推理引擎）→ 模型研发迭代的边际成本骤降 → 支撑起「数万亿市值要靠 RSI 兑现」的经济叙事，也把「谁能把『用模型改模型』制度化」变成模型公司与 infra 公司之间的新分水岭 → 观察指标是开源侧 RSI 项目（OpenSI 等）的交付物，与公开的「用模型改模型」案例密度 → 对读者的启发：判断一家公司的研发壁垒，先看它有没有把模型改模型的循环跑成制度，而不是只看榜单名次。**

## 二、评估是唯一的瓶颈：「能评估什么，就能优化什么」

第二个 aha moment 直接咬合第一个：如果我们认为 RSI 是 AGI 的核心，那什么是 RSI 的核心？他的答案是**评估（evaluation）**。他本科时读过一位前辈的话——那位前辈转写作「钟瑞奇」，经核实为 Ruiqi Zhong（Thinking Machines Lab 成员、前 Anthropic 员工）——「what we cannot evaluate is what we cannot optimize」（不能评估的就不能优化）；今年他见到本人，给这句话补了下联：**「what we can evaluate is what we can optimize」**——只要评估脚本写得对、指标只能降不能升（或只能升不能降），AI 一定做得到，「它不可能把错的方法交给我」。他举的指标是语音模型的错字率 WER：一百个字错两个字就是 2%，要求 AI 在优化模型时 WER 不升、性能不降，就一定能优化下去。证据是刚过去的这个周末：他优化一个只有 80M 的原生 TTS 模型，在清晰的评估指标下用 Claude Opus 5.5（口述搭配「Ultra Code 加 Ultra Fast」的用法，未能核实具体所指），**两天之内性能提升 1700%**——「极其夸张，极其恐怖」。

第三个 aha moment 把「评估」本身拆开：**好的评估是自动化且低成本的。**反面是审美：《百年孤独》写得好不好、香奈儿的包美不美，主观评估众口难调。他给了一个很工程师的定义：「美感是把具有相同偏见的人聚在一起构造的事物。」他有很多朋友在顶尖 frontier lab 的评估部门：Gemini 想评估创意写作，要支付高昂成本请作家，而作家们彼此「文人相轻」；视频模型（口述「C dance」「MiniMax 的 H3」，疑为 Seedance 与海螺系视频模型，未能核实）要请专业影视人士甚至导演来评。工程上的缓解是把「美不美」拆成一棵评估树上的一百个、五百个「好不好」的二元小问题——但马上撞上 local minima：评估设置得不全面，模型会死磕某几个指标、让其他指标彻底崩溃，所以「WER 不回退、性能只升」之外还得补一堆约束（不许牺牲 A 模型的性能去换 B、不许塞进恶心的环境变量）。更硬的约束是成本：评一次 WER，一张 H200 跑一个小时，成本在十美元以下；而流片一次数以亿计——「我不敢让一个周末的 Claude 去流片上千次」。AI 制药同理：假设可以从十个变成一万个，但猴子没有那么多。于是他收束成本期最锋利的一句话：**低成本、自动化的评估是 RSI 唯一的 bottleneck**；反过来说，人类主观能动性所代表的那些昂贵评估，恰恰是人在这个循环里 remaining 的价值。

第二条链条：**评估的自动化程度与单位成本，决定 AI 可以无限试错的域（TTS 两天 +1700%，流片与临床前研究纹丝不动）→ RSI 沿着「评估便宜」的方向选择性渗透 → 观察指标是一个领域里自动评估器出现的速度（代码、数学快；审美、药物慢）→ 启发：个人与组织最值得积累的资产之一就是「自动化评估器」——把你在乎的质量变成机器可以廉价重复的判据；同时警惕指标不全被钻空，评估器本身就是新的攻击面。**

## 三、CUA 与交互式智能：无障碍树、级联方案与每天四万字

第五个 aha moment 关于多模态，入口却是他自己的「投降」。他以前猛烈批评 agents 领域「礼崩乐坏」：没有公正的评估标准，录十个 demo、cherry pick 几个最好的，就能宣称「agents 无敌了、可以从头到尾写一个全新的 Photoshop」。转折发生在一个晚上：他看见太太在跟他聊天，她的屏幕自己在动——是 ChatGPT 的 computer agent 在替她操作 Origin，一款做科学计算的人都知道的老软件：没有 SDK、很难自动化、甚至基本只有 Windows 版，GPT「拿着一个虚拟好看的鼠标点来点去就做完了」，更不用说 Excel、Word、Chrome、飞书。他去找人问 CUA 的原理，自认「一叶障目不识泰山」：对一个做推理的人，vision language model 的麻烦在于**图片不具有前缀性**——对 LLM 而言，string A+B 与 string A+C 的前缀 A 可以共享（这是 KV cache 的基本原理），但任意两帧图片几乎不能共享，鼠标挪一个位置严格意义上就要整图重算；而苹果为盲人（他口称「为盲人程序员设计」）的无障碍功能，要求软件把整个界面当作一个可以被读出来的文档——不再是图片、成了字符串，字符串就有前缀性。所以 computer agent 只在最糟糕的情况下才真的去截图操作屏幕。这是他认为「可以举的最平常的」想法，更天才的想法是商业机密，他不能说。

然后是战绩。换银行卡交房租失败，账单被罚 75 美元、过了一周才通知，他让 GPT 跟物管公司 argue「扣款失败你可以当天告诉我」，三封邮件点来点去，第二天 75 美元退回账上；本科的日记全在 Notion，而清华邮箱已经登不上，他让 computer agent 把每个页面逐一点击 Export、存成 Markdown/CSV/PDF，两个小时做完；最近又让 Codex 把印象笔记里几千条笔记一口气全部导出——「过去手动导这个可能我拖延了好几年」。它还替他在美国 argue 复杂的医保、预约体检和洗牙、跟一家家物管公司谈搬家——「更搞笑的是那些物管公司本身也是 AI，我看到两个 AI 对话了十几轮，一直从四点钟对话到下午七点」。这场 AI 对 AI 让他得出一个很刺的结论：AI 是没有决定权的，「大多数的 AI 都是宦官 AI——把所有的责任都推走，只保留权利」，不敢拍板任何事情，所以用 AI 代替人工客服很糟糕；他还提到 Muse 有个功能可以用 TTS 帮你打电话，你会听到两个 AI 互相对话，「非常抽象、啼笑皆非」（Muse/Hark 为口述产品名，未能核实；同期 Mac 上的 iPhone 镜像配合一批 Phone Use 类产品，让 agent 间接操作手机，「各显神通」）。多模态的行情波动他也不讳言：今年六月份很多人说「多模态是路边一条蛆」，这几个月 Muse、Hark、国内的豆包之类的多模态交互式助手兴盛，「市场又变好了，大家都涨薪了」——他真正想问的是：多模态发生什么本质变化了吗？顺带一提，他说这一轮 agents 评估的修复要归功于一批互通有无的华人研究者——转写作「oversword」的工作（疑为 OSWorld 基准）以及他点名的天宝、谷雨等人，「无论是天宝也好，无论是谷雨也好」，有的在 frontier lab、有的在创业。

第六个 aha moment 是他的本行：**交互式智能（Interactive Intelligence）**——他维护的 SGLang-Omni 就是做这个的（「我们做的最核心主要工作就是 Interactive Intelligence System」，开场第二问他就这么说）。定义很人文：人和人的对话是连续的——你一段时间没回复，我会想是不是背景信息没给好、补一点；你跑题了，我可以打断。有一种学术观点认为「人就是一个每两百毫秒有一次输入的 Thinking Machine」。产品侧有 GPT Live、Thinking Machines Lab 的 Interactive Model、豆包等（他还口述了「美国有 Hugging」，疑为人名或公司名，未能核实）。技术路线他分三种流派：**Native Duplex**（如 TML 的 Interactive Model，每 200ms 读取一次输入并决定接下来 200ms 的输出，语音视频文字俱全且聪明）、**Turn-Based**（输入输出都是音频的对话模型，但打断要生硬地按暂停键）、以及**开源社区主流的级联方案**（VAD 说话检测 + ASR + LLM + TTS）。前两种对模型要求太高——千问3-Omni 已经是去年发布的开源模型，此后没有新的开源 omni 模型可用；而级联方案的每一块都在出新的优秀开源模型：三周前 MiniMax M3.1 发布（口述 400B、「非常 elegant」），他和 MiniMax 的朋友们做了个 demo——SGLang-Omni 的 ASR 跑语音、MiniMax M3.1 的 API 当中间的 LLM、千问3-TTS 做合成，「感受起来就是个非常有灵性、很聪明、很快的模型」。级联的好处是无需训练、每一块可以独立升级；中间路线（级联 + 把 TTS 和 LLM 做得偏全双工的后训练）也存在，成本介于两者之间；他判断长期并存，直到技术收敛，「我很喜欢这种百花齐放的状态」。但级联立刻暴露新暗礁：现在的开源 LLM 都是为 coding 训练的，一吐就是成千上万的 token，「你真的希望每一个 token 都给你 TTS 朗读出来吗」？他夸 GPT app 查洛杉矶天气时不念「72 华氏度」、而是渲染出一整周的天气，是好的产品示范；TTS 读到表情符号直接乱码。理想方案是「TTS as a tool」——把 TTS 降级成 LLM 必须调用的一个工具、只朗读该读的部分——但他实测发现太理想：模型很聪明又不完全聪明，tool call 的零样本泛化仍不行（一年前他在 Amazon 的 SF AI Lab 就研究 tool call 训练），不开 thinking 参数调用就出错、开了 thinking 想十分钟才给用户读一段话，谁都接受不了。他的比喻值得全文引用：**「任何一个时代，模型的智力水平上升了，水面上升了，以前的暗礁就不用了，又会出现新的暗礁。水面一直上升，珠穆朗玛峰成了暗礁，我们还是要想办法解决这些暗礁问题。」**

第七个 aha moment 是以上一切在他自己身上的总和：**语音输入法**。他每天平均输出四万汉字——「我要是打字，这是不可能的」——语音输入让输出速度跟上了思想速度。方案就是去掉 TTS 的级联：ASR（他现在用千问3-ASR；长音频用邱锡鹏老师团队的模型，转写作「MoS TD」，经核实该团队开源有 MOSS-TTSD／MOSS-Transcribe 系列，未能确认具体所指）+ 负责纠错润色的 LLM（他自己部署的 Kimi K3.1）。纠错的关键招数是把先验写进 prompt：朋友名字「高逸飞」，「逸」是飘逸的逸、还是「俱怀逸兴壮思飞」的逸、还是「一飞冲天」的逸？把常见误识别统统列进映射就完美了；ASR 自带的 prompt 参数「不是特别强大」，主要工作还是 LLM 做；十秒钟的音频一秒钟识别完。他顺势「严重安利」自家前脚刚发布的开源软件 **Voxt 2.0**（口述「用了半年，昨天刚刚发布」；经核实为 sgl-project/sglang-omni 仓库下的开源 macOS 语音输入项目，Voxt 2.0 于 2026 年 11 月发布）：独立开发者关伟（口述）所作，他们把 ASR 换成 SGLang-Omni 系列的 MLX 运行时，「向关伟老师保证：正确性一致、性能更强、易用性更好」，还能在 Mac 上开 speculative decoding 出奇地快；本地 LLM 不能用 MLX 原生（prefix 处理做得不好），可以换 Ollama、买云服务或 SGLang 系 MLX——他最近用自己部署的 Kimi K3.1，「效果非常惊艳」；在意隐私、想掌握自己全部 context 的人，用 5090 推理自己的 LLM 也完全成立（他自称喜欢「古法编程」，也喜欢古法锻炼）。最后一层是产品洞察：**方便的产品入口是一个非常核心的事情。**读英文文献要翻译，每次复制粘贴打开 GPT，一次五六秒、一年下来浪费很多时间；豆包浏览器插件选中一段文字右键就能翻译/润色/转写，「入口比 ChatGPT 做得浅」；而 Voxt 的入口「无敌了」——选中一段话说「翻译为英文，朴素一点」即可（个别小语种如波斯语仍要进豆包设置里调）。他们最近录的 demo 展示三件事：语音输入、翻译、Any to Any 的语音助手。

第三条链条：**模态的缓存友好性（图片帧间无前缀共享 → 无障碍树把 GUI 变成字符串、恢复前缀性）→ CUA 的推理成本从「每一步重算整屏」降到「最糟才截图」→ 没有 SDK 的老企业软件（Origin）反而最先被攻下 → 观察指标是 agent 框架对 accessibility API 的利用程度 → 启发：给 AI 选「环境表示」时，字符串与结构化状态远比截图值钱；产品入口每浅一层（右键、快捷键、随口一说），价值就放大一截。**

## 四、便宜智能的冲击：优绩主义、UBI 与「活人味」

第四个 aha moment 讲完之后，对话拐进整期最不 infra 的一段。赵晨阳说他最喜欢的模型是 Claude Opus 5.5 和 Claude Fable 5.1，「这些模型的智力水平都非常强，远远超出于我，我不可能在智力水平和操作能力上面战胜他们」；当智能变得像水像电一样容易获得，人类社会会发生巨大的改变——这是他眼里 RSI 议题里最重要的 topic，「我自己其实也没有想清楚，但我很愿意把这个问题分享出来」。他最近常读 frontier lab 关于 AI 安全与社会影响的讨论，列举了口述的三件事：Hugging Face 的越狱事件、币安的「惊天大盗窃」（转写误作「必安」）、NVIDIA 一批显卡在美国境内被失窃。他对马斯克 UBI 论的态度经过一个很中国化的案例：江西一个低保户家庭的女孩去香港看演唱会，导致全家的低保被取消。他承认此事「至少没有一个特别大的矛盾」——当地政府屡次三番告知过出境游会触发审核；他真正想说的是后面那句：**「如果人类靠施舍过日子，人是一定不会有自由的。」**以后真靠 UBI 过日子，一定会有人来讨论你是不是不能喝依云矿泉水、不能买 PSP、不能用最新的 iPhone、只能买超市廉价食物——接受施舍的人必然受非议。他引刘慈欣《赡养人类》（转写误作《赡养地球》）里造物主拥有全部财富、人类呼吸空气都要申请的世界，担心不加以讨论，社会会滑向这个悲惨边缘；马斯克是人类第一个 trillionaire，他「展示着他的仁慈」说要发 UBI——如果极端的马太效应把所有财富集中到一个人身上，人类的未来会非常可悲。美国刚结束的中期选举里，两党的巨大争议正是 AI 数据中心与 AI 限制；他路过 OpenAI 总部门口的 Stop AI 人群，举了十分钟牌子——发现诉求就只是「Stop AI」之后他走了，但他坚持「对 AI 的深入思考，是每一个研究员、每一个人都需要认真思考的问题」。他还讲了 Anthropic 早期公开可查的内部分歧：在一些早期研究者看来，Anthropic 的使命是给 AI 加紧箍咒，与 OpenAI「左脚踩右脚」比谁更领先只会加速 AI；同时他批评有效利他主义者的「精英的傲慢」——已经成为精英、觉得自己比其他人聪明、具有替全人类做选择的权利。「替他人做决定是傲慢的，但不为自己做决定是不负责任的。」

「为自己做的决定」构成这一段的底色。他的微信名是「吉他，猫，LLM」四个并列的词（转写一度误作 LOM），灵感来自《爱死机》（转写误作「爱死鸡」）——他拒绝《赛博朋克 2077》式的极度资本主义与极度赛博化的世界。他在 LinkedIn 上有一段他自称很火的讨论，讽刺优绩主义：晒 OpenAI 的巨额薪资、晒财富自由、晒 xAI 有多少显卡、Google 的午餐特别好，「在我看来就是一只鸡在讨论要去肯德基还是德克士、麦当劳——对我而言没有区别，这些就是养鸡场的区别」；他决定不做优绩主义者、不粉饰自己糟糕的决定和糗事，「人的一个很重要的价值，就是为 AI 提供一个很好的 context，活人感太重要了」。年初至今他靠锻炼瘦了十公斤——他了解司美格鲁肽和替尔泊肽在美国非常火爆（转写为「斯美格鲁泰」「蒂尔伯泰」），但选择「古法锻炼」；每天雷打不动一个半小时，「我每天健康工作，活得更久，坚持到 RSI 彻底实现那一天，那么我会成为赢家」。他借播客向太太道歉——工作从早到晚、blur 了工作与生活——因为「很多事情 AI 出动都会解决，但如果我没有照顾好我的猫、我的太太、我的家人，很多的事情是不可逆的」。他戒掉了打了多年的英雄联盟手游：ELO 机制把胜率稳定在 50%、有时故意连输五轮再让你赢一轮留人，连续输掉六局之后他卸载了游戏——「不是我 在玩游戏，是游戏在玩我，太恐怖了」，一局里甚至不确定能匹配到几个活人（很多操作非常拟人的是 AI 玩家，也有很多人拿 AI 打游戏）；朋友做的内测 APP 把小红书锁成每天三次、每次五分钟，iPhone 灵动岛上跑倒计时，让人「重新拿回对生活的掌控感」。一位做了九年 AI infra 的朋友带狗去医院，九年过去医院没什么变化、狗变老了——「物理世界让人觉得很荒诞」；于是他每周刻意留时间陪太太爬山、去洛杉矶看展、吃好吃的川菜，把打游戏省下的时间换成读书、研究历史和写作。这些不是闲笔，它们共同回答「智能被无限供给之后人怎么办」：他的答案是保住活人味、身体与关系。

## 五、从《大明王朝1566》到 merge 规则：权责对等与制度

最后三个 aha moments 来自今年的另一条主线——读史，他自认「一气呵成」。第八个来自电视剧《大明王朝1566》（他称之为国产权谋剧第一剧，连「大明举重冠军」这样的梗和「两京一十三省担在肩上」的台词都信手拈来——后一句转写误作「两斤一石三指在我肩上担」），核心是一句管理学判断：**一个组织只会自顶向下烂掉。**如果我们觉得一个体系腐败、底层官僚和店员恶劣，问题一定不在他们，一定是这个系统从顶向下烂到尾；剧里百姓被宦官和官僚系统毁堤淹田、没了生计，还给锦衣卫说「当今圣上还是好的，只可惜严嵩和严世蕃这些奸臣蒙蔽了皇上的双眼」——看到最后才发现嘉靖才是大明朝唯一的混蛋，严氏父子只是他的白手套和背锅侠。第九、十个来自黄仁宇《万历十五年》和卜正民《挣扎的帝国：元与明》（哈佛中国史第五卷；作者转写误作「蒲振明」）。《万历十五年》把万历皇帝本人、张居正、申时行、海瑞、戚继光、李贽（转写误作「李直」）在万历十五年这个稀疏平常年份里的处境串起来，表达一句话：「万历十五年这一年没有任何事情发生，但是大明朝已经完蛋了。」完蛋的机制是三层递进：**腐败自顶向下；权责不对等滋生腐败；制度的模糊性（他并称道德的模糊性）给人权责不对等的空间。**嘉靖享受了大明朝最大的权力和收入——修宫殿修道观、万国来朝行跪拜之礼——却把所有责任推给严嵩：东南打仗不利是严嵩的责任、国库亏空是严嵩的责任、甚至他挪国库钱进私库的锅也要严嵩背，一背二十余年。而权责不对等的根源在制度模糊：嫡长子继承制「虽然叫做制度，但本质上是一种道德」，没有一个制度写明白必须传嫡长子——朱棣直接造反、清代九子夺嫡、元代「更是不可描述」；万历朝围绕皇长子朱常洛与宠子朱常洵的「争国本」拉锯十余年，直到 1601 年（万历二十九年；转写把年份误作「一九六零」）朱常洛才被立为太子。嘉宾口述「以至朱常洵先死，这个事情才得到结论」，与通行史实有出入（太子朱常洛卒于 1620 年，福王朱常洵卒于 1641 年），按嘉宾口径记录、并列注明。元代的继承更糟：「选择贤明的人继承皇位」——谁打仗最厉害、把兄弟都打服谁上——成吉思汗生前指定窝阔台尚算平稳（他口述此处有一个转写作「tendency」的英文词，疑为 tension／turmoil，未能确认），后代大汗多战死、来不及立遗嘱，蒙古帝国一死就分裂。朱元璋想推行法治——大明律与《大诰》，家里藏有这两本书甚至可以免死罪——却在公检法之外另设锦衣卫这样的特务机关，亲手践踏自己立的制度，所以明代既不是法治社会也不是制度社会。「以身作则」这四个字，他看完剧才理解分量有多重。

这组历史课的落点，也是第四个 aha moment（开源治理）的真正答案。他今年在 SGLang-Omni 社区严格履行「仁慈的独裁者」的角色（学名 BDFL，原典是 Linus 之于 Linux：首先他是仁慈的——初衷是让项目更好；但他可以拒绝任何不符合他偏见的事情）。他重复了一遍那个判断：**AI 是人类的放大器——顶尖工程师和顶尖 AI 写出顶尖代码，垃圾工程师和顶尖 AI 写出灾难性代码。**以前一个工程水平糟糕的人一周只能提两个 PR，看一眼就能拒掉；现在他能一周提一百个，逐个评估会淹死维护者，全部接受代码库会很快被毁掉——这是所有开源项目今天的困境。他的解法是把「偏见」制度化：写代码有 if 必须有 else，哪怕 if return 也要 else pass——「即便你觉得 else pass 很蠢，但这样一定可以减少很多 bug」；注释里不能有顿号——「顿号是 Markdown 语法，而 Python 不是 Markdown」；注释必须带人的名字。这些风格是双向筛选：接受不了他的标准的人可以不做这个项目；而每一条偏见都被写成一个 requirement，不通过 requirements 的 PR 不能被 merge，「我们大家一点一点改出来的」。「偏见本身就不存在正确，但只要这个偏见是 consistent 的，这个事情就可以被推动下去」——目标是让框架有两年、三年甚至十年的生命力。对照明史三课，他说得非常直白：他在 SGLang-Omni 拥有最高权限，「不是因为我加入早，不是因为我干了很多事情，而是因为我承担着巨大的责任，我建立起了这套制度，而且这套制度对我也是有约束的——我写代码不符合制度，我是第一个受到批判的人」；来做 SGLang-Omni 的人，有的想跳槽、有的想申请学校，社区的信任背书是他们的权利，与此同时他们也要为负责的部分担责。同一个框架他还拿来评 AI 产品：TTS 模型做客服很糟糕，因为它们不愿担责；他在推特和 LinkedIn 上批评这版 GPT「太喜欢推脱责任了」——百分之一的剩余概率都要缀上「不等于、不表明、不完全决定、还不能下决心」，「这就是典型的甩锅行为」；他能理解这种训练的初衷（嘉宾转述新闻：Amazon 一个被裁的程序员遵 GPT 之嘱停掉癫痫药准备面试，已经进入诉讼），但结论不变：**负责任的一定是人——你写的代码出了问题，你就得负起责任；与此同时，尽情享受与责任对等的权利。**

第四条链条：**AI 放大工程产出（坏工程师 × AI = 一百倍速的灾难代码）→ 代码库与组织的「贫民窟化」风险上升 → 治理手段从口头品味变成成文制度（requirements 化的偏见 + BDFL 的最终权责）→ 呼应明史三课：自顶向下腐烂、权责对等、制度先于道德 → 启发：AI 加速期，「谁拍板、谁担责、规则是否成文且约束制定者本人」是比效率更优先的组织设计变量；对 AI 产品同理——「宦官 AI」式的推责，是权责错位的产品化表现。**

收拢十个 moments：第 1–3 个说「RSI 已来，瓶颈在评估」，第 4 个与第 8–10 个说「用制度对冲放大器」，第 5–7 个是「infra 人把交互智能做进每个人的输入框」，中间夹着一段「在智力贬值的时代保住活人味」。对行业，这期对话的意味在于：当评估成本成为 RSI 的唯一瓶颈，评估基础设施（基准、验证器、评审自动化）会是下一个 infra 热点；当 AI 能自己写推理引擎，模型公司与 serving 框架的分工还会继续松动——SGLang 这样的开源底座正卡在中间。对个人，他给的观察清单很朴素：看开源 RSI 项目的交付物、看自动评估器在你所在领域出现的速度、看一个公司或社区有没有把权责写成制度——以及，每天留一个半小时锻炼，活到 RSI 实现的那一天。节目最后他照例给听众拜了个早年，顺带打了个广告：多支持 SGLang-Omni 的工作，「试试看语音输入法，非常强」。
