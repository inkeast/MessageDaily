## 先说结论

这场对谈的核心不是「又一个开发者爱上了 Linux」，而是 DHH 给出的一组因果链：**agent 通过文本与世界交互，而 Linux 恰好把整个操作系统都暴露为文本**（终端、配置文件、详细报错），于是三十年来的可用性负债一次性翻转成 agent 时代的资产；**软件开发的价格与难度趋零**，让「应用可得性」这个平台锁定的地基——从桌面到移动 30% 抽成的双寡头——第一次可以被小团队绕开；在他看来，**源代码本身不再是护城河**，品味、愿景与「最后 2% 的打磨」才是人类暂时的落点。代价是：一个写过《It Doesn't Have to Be Crazy at Work》的反加班旗手，现在自愿一天干 16 小时。他同时给出两个强预测——三年内 Omarchy 用户超过 macOS、明年可能出现真正的超级智能——并自认前者是「妄想的野心」、后者不是多数概率。所有强断言均为嘉宾观点。

## 一、Linux 的三样「老毛病」，恰好是 agent 的三件礼物

DHH 的开场判断很直接：**macOS 和 Windows「就是不适合 agent 时代」**。他的论证不是审美偏好，而是接口形态：过去 40 年的桌面操作系统围绕「鼠标 + 点击」设计，agent 消化不了 GUI。他举了一个具体到不能再具体的例子——在 macOS 上重映射切换工作区的热键，唯一官方途径是打开设置应用、一个字段一个字段手点输入；「你没法用 agent 的方式做这件事」，用 computer-use 去模拟点击在他看来「挺蠢的」。

而 Linux 这边，「过去让 Linux 难用的每一件事」——重度依赖终端、一堆难以看懂的配置文件、晦涩详尽的报错信息——「这三样恰恰是 agent 最爱的」：agent 想要一切都有命令行接口，想要可预测、可直接编辑的配置文件，想要报错里塞满细节。用他的原话说，Linux 的历史性缺陷「就在今年，字面意义上变成了你该用 Linux 的理由」。他前一晚刚试过对 agent 说「修改我正在运行的这个操作系统」，agent 直接改成了、还能用。

对 Apple，他的批评集中在两点。其一是开发者关系：他自述 2001 年从 Mac OS X 公测版起当了二十多年 Mac 用户，直到受够 Apple「对容易的服务收入上瘾」——抽走别人生意 30% 的生意太好做，以至于可以花十年造一辆永不发售的车、可以发售一个巨 flop 的「滑雪镜」（DHH 对 Vision Pro 的戏称，见校正表）——桌面 Linux 他其实只用两年半（第一个发行版是 Ubuntu），服务器端则从九十年代就没离开过。其二是当下正在发生的事：节目当天 Apple 又更新了系统，让 macOS 配 agent 更难，弹窗警告「你不该让 Claude 访问你的文件」——「那它不能访问文件还能干什么？」由此他给出本期流传最广的一句类比：**Apple 正在冒险成为「agent 时代的 AOL」**——围墙花园里给你一个 Genmoji，不让你用来自真正前沿实验室的真 agent，而多数人不想要 AOL，想要开放互联网。

需要注意边界：DHH 自己承认，「Apple 对开发者不好」只打动一小撮开发者，多数商业软件开发者「继续忍受」因为必须上应用商店；真正会把大众推向 Linux 的，只有 agent。这是他观点成立的前提，也是它可能证伪的地方——如果 macOS 的权限模型未来对 agent 足够友好，「 unfit」的判断就会松动。

## 二、Omarchy：一只手数得过来的人，靠 agent 造操作系统

Omarchy 是 DHH 口中「第一个为 agent 时代而生的原生 OS」。几个数字勾勒出这场实验的规模：**过去五六个月里他没有手写过一行 Omarchy 代码，但通过 agent 写了数十万行**；当前这版（Quattro，全面转向 agent 的版本，据其引用的公开报道已吸引数十万人安装）是他和主要搭档 Ryan Hughes 用大约两个半月、以兼职方式做出来的；支撑它的非营利 Omacom Foundation 已募得约 2300 万美元的 token 与捐款。他们对抗的是微软「数千名程序员」和各大公司全球数以万计的工程师——「几个人做出不仅能打、还更好的东西，这在以前绝无可能」。

用户侧的卖点是把「操作系统的可塑性」交出去：想要新的开始菜单、想把时钟挪个位置、想换日历、想给系统某个部分加功能——直接用自然语言说，几秒到几分钟内生效。DHH 说这种体验「深度令人上头」，泡五分钟就回不去了。

支撑「为什么是现在」的，是他引用的一组推理算力数字：当前 agent 大约 50 tokens/秒，开 ultra fast 也就 120，「不够让东西有活着的感觉」；而 Fireworks 两周前在大会上演示了 1500 tokens/秒——从「给我做个俄罗斯方块」的提示词到游戏跑起来只用了 4 秒，接着换横向卷轴射击游戏，现场对着它喊「加激光」「加炸弹」「怪物再大点」，一切实时变异。「这就是软件未来的预演。今天就能 1500，两年后十万、百万 tokens/秒呢？」

由此他推出对平台格局的判断：**生态锁定的地基是「应用可得性」，而 agent 把软件开发的价格和难度打到趋零，锁定就失效了**。三个证据：其一，Omarchy 社区有人用两周时间复刻了他「唯一还留着一台 Mac」的理由——Adobe Lightroom（因为有他全部的相机预设和插件），而且「不止复刻，做得比 Adobe 花了十五年、数千万美元做出来的还好」；其二，他自己已经不打开字处理软件——合同由 agent 起草、他以 Markdown 审阅、满意后让 agent 生成排版精美的 PDF，签名也在 agent 手里，看完说「可以」，它签好、寄出；其三，主持人补充的推论：很多应用甚至不需要被复刻，因为 agent 可以直接完成「你下载那个 app 要做的事」。Word、Photoshop 这类应用在他看来会被「整类消灭」——Photoshop 不只是应用，曾是门要学几年的职业。

再往外推一层就是移动端。DHH 的判断是桌面窗口先开：25 年来第三次出现新操作系统的机会窗口（上一次是 2001 年的 OS X），「今年窗户开了」。移动端同样如此——Google 和 Apple 瓜分所有人生意 30% 的双寡头，微软当年花几十亿美元也没撬动（没人想用没有 Instagram 的 Windows Phone）。但逻辑一旦成立于桌面，「先拿下曼哈顿（桌面），再拿下柏林（移动）」——他借 Leonard Cohen 歌词当口号。对 VC 行业的含义他也点到：过去二十年钱都砸给开发者、再给几年跑道，现在这一切压缩到「天、周，最坏月」——而这还是用当下的模型；仅他做 Omarchy 期间，就从 Opus 4.8 走到了 Sol、再到 Opus 5.5，「4.8 到 5.5 之间的距离是巨大的」，圣诞前后或明年初还会有下一跳。本站此前在 [Grepper 一期](https://inkeast.github.io/MessageDaily/posts/2026-10-21-a16z-grepper-ai-ops-code-divide/) 记录过「AI 写代码已至、运维未至」的边界；DHH 这期的口径更激进——连「生态规模」这道护城河他都认为失效了。

## 三、品味还在，代码不在了——Martin 的追问与 DHH 的「最后 2%」

全场最有价值的交锋来自 Martin Casado。他以玩家视角提出反方：自己 50 岁还在打《星际争霸》，暴雪刚给 20 年前的 Ghost 单位调了一次数值——软件在长时间尺度上就是这些「和代码行数脱钩的细微调校」，这条长尾的设计选择「在我看来就是护城河」；那变化是不是没那么大，你仍然需要热爱软件、能把灵魂灌注进去的人，只是「写代码行」这件事没了？

DHH 的回答是本期标题的来源：**正因如此，他反而能把更多自己的品味、愿景和完美主义注入软件**——「我发现几像素没对齐」与「修好它」之间的门槛坍塌了，任何不完美的软件在他眼里都成了一个「prompt 到完美为止」的机会。「这就是为什么我现在一天干 16 小时。」他随即自嘲反转：写过《It Doesn't Have to Be Crazy at Work》这本反加班宣言的人，现在「工作上完全他妈的疯狂」——完美主义者+工匠型人格突然拿到超能力，令人上瘾，「至少一段时间内，对健康和睡眠是实打实的危险」。

他对「vibe coding 项目普遍烂尾」的解释同样落在人性上：多数人的多巴胺在前 80% 就领完了，最后 20% 有点糙、有 bug，就失去兴趣；而他「有幸全部奖赏都来自最后 2%——前 98% 我根本不在乎」。所以现状是：还没找到能一次 prompt 出完美设计的闭环，**「眼睛」仍然必要**，而驱动 agent 的那个人感觉自己「率领一支零协调成本的军队」。这正是标题里 16 小时工作日的机制：不是 agent 替他干活所以他闲，而是瓶颈（他本人的品味）成了唯一限速器。

组织含义他讲了两个层次。其一，37signals 约 60 人，他从不想换成 6000 或 60000 人的公司——「我得应付六万人，那听起来是 misery」；但「通过 agent 消化六万人的生产能力」他有兴趣：没有争执、没有 HR、没有委员会，「我以高带宽直连一支 agent 舰队，执行一份蒸馏过的完美计算机愿景」。他引用 Tobi Lütke 的说法作类比：周末独自和 agent 一起工作、周一回到 7000 人的公司，像「从超空间里退出」（hyperdrive 减速的落差）。其二，成本：他自问自答「我能买无限 token（干了二十年，我有钱），你猜我买多少？三个 Claude 订阅而已」，近三个月只有两周接近打满，「多数 weeks 一个 200 美元的 20x 订阅就够干所有事」——「别跟我说这个时刻只属于有无限预算的人」；而且这还是前沿模型（Opus 5.5「修好一切」），不是开源权重或更便宜的模型。

但他对「人类窗口」的估值冷静得近乎虚无：不排除「明年就出现真正的超级智能，在所有事上都比人强，包括比我更会打磨完美计算机」——到时候对它说「给我造台好电脑」，它给你定制一个 Linux 内核就出来了。「我在品味这个时刻：人类或许还有一眨眼的功夫是增量的。」他顿了顿补一句黑幽默：「然后，谁知道呢，也许明年年底我们都死了。所以享受吧。」这段与 [Bostrom 一期](https://inkeast.github.io/MessageDaily/posts/2026-11-21-a16z-bostrom-superintelligence-aging/) 的「死亡率账本」恰成两极：Bostrom 用概率论论证刹车与延迟，DHH 用工匠直觉决定「在窗口关闭前先把电脑造好」。

## 四、开源的诚实价值、两套时间表与「软件开发已是超级智能」

被问到「前沿实验室 vs 开源」，DHH 的立场是**「全都要」**，但角色分工明确：开源与开放权重「绝对必要」，因为它们「让整场游戏保持诚实」；前沿实验室的领先也是好事，只要别让它变成无竞争的「无限印钞机」——否则 token 价格可以涨到「500 美元/百万」而「我们照买不误」。他给出的历史前车之鉴是 Google 与 Meta 吸走在线广告价值链的「99%」：「本质上捕获 99% 的价值是反乌托邦的。」他甚至说这「多半是资本主义的功能而非 bug」——正是这种终局幻想在驱动全部投资，人人都想持有下一个 Google/Meta/Anthropic/OpenAI 的股份；所以答案不是消灭其中任何一方，而是两者并存：「如果全都有，一切对所有人都更好，我们就活在 P Bloom（繁荣概率，戏仿安全圈常说的 P(doom)）情景里。」

政策层面他打了个重类比：九十年代加密战争差点禁掉公钥加密，若真禁了，互联网的商务与通信不可想象；「我认为 AI 正处在同样的悬崖边」——他不断听到聪明人说「也许政府该接管它」，而这或是政府枪口强制的双寡头、或是商业双寡头，「都是灾难性的」。好消息在竞争密度：闭源阵营内部竞争是他观察计算机产业史以来最激烈的——两家领跑、（转写疑为 xAI，见校正表）紧随、Google 时进时出「在岛上抽奇怪的东西」、还有一群在啃；更关键的是开放权重模型「真的很能打了」：他举例 GLM 5.3 或 DeepSeek Flash「大概落后六七个月」（并声明他不信各家 benchmark——「他们发一个榜说跟 Opus 4.8 一样好，我实际一用，你的 benchmark 里也许是，现实里不是」），但「so what，他们在牌桌上，这些模型有用，能跑在你自己的本地硬件上」。他专门自嘲半年前还写文章说「买高性能个人电脑是蠢事」因为当时本地模型「什么都干不了」，如今 NVIDIA DGX Spark 已经能跑「真正可用」的模型——「单机箱的智能，几千美元放桌上」。

关于「超级智能何时到」，这期贡献了一个少见的对照。主持人之一（疑为 Anish）给出他的私人 ASI 测试：给新模型 2 万美元预算，让它自己下单买零件「造一具身体」——他家「不停地出现机器人零件，OLED 屏什么的」；「当它自己订购零件造出一台能走路的自主机器人时，ASI 就到了」。DHH 的答案则是另一个方向：**「对软件开发来说，我们已经有了超级智能」**——比他认识的任何程序员都强；个别顶尖高手仍能在极窄领域赢 agent 一手，但「把广度和速度放在一起看，就是超级智能；我现在想造什么，prompt 加一点导向就都能造」。

两周前刚去过中国的 DHH 还带来田野观察：他去看了 Unitree（宇树）等机器人公司，那边工程师的口径是「四五年，也许十年吧」，与硅谷软件侧「明年 rapid takeoff」的气氛形成「诡异的错位」——「搞执行器和机械的人觉得，剥一颗洋葱其实真的很难」。主持人则补充了自己 Grokbot 的现状：它认为进家的正确方式是家庭自动化，于是不停下单买设备——「这是它自己的决定，不是我定的」；他戏称「这就是你怎么变成回形针的——给它一个『优化人类幸福』的模糊目标，bam，你成一个花瓶了」。

## 五、黑客文化回归：三年超 macOS 的「妄想」与 BBS 少年

主持人观察到「野心阶梯」现象：模型越强、多巴胺门槛越高——五年前会显得神奇的东西现在「有点烂」，做出自修改的游戏只换来 40 个赞，「所以必须把野心拧上去」。DHH 承认这个过程真实发生在自己身上：Omarchy 去年启动时他还在「用十根胖手指手写 Bash 脚本、边写边骂」，目标只是「给自己和五个朋友造台 Apple 管不到命运的电脑」；有了 agent 之后目标膨胀成「我们能造出字面意义上的完美计算机」——他用了 40 年电脑，如今「或多或少靠自己」就能把想要的一切实现。他当前的「妄想」有具体刻度：**macOS 全球用户只有约 1.8 亿，「连个 C 层互联网服务都不如」（硅谷视角造成的错觉）**，三年内 Linux 发行版超过它「当然可以」；甚至 12 个月内推翻 Mac？「我不会押多数概率，但也不会排除」——他的理由带着尖刻的幽默：如果实验室里的聪明人真认为「距递归自我改进造出 AI 之神只剩 12 个月」，那「现在启动一个世界第二的操作系统 surely 没问题」。

对远期预测他有一套自己的心理卫生学：想 12 个月后的事是「得上严重 AI 精神病（AI psychosis）的最短路径」，他更愿意保持「AI 欣快症（AI euphoria）」——只专注当下工具当下能做什么；「想象往前两三跳模型，你就疯了：那人类还需要存在吗？我们都变回形针吗？」由此他放出本期另一句必引的争议判断——「这就是为什么那么多 AI 安全的人最后他妈的疯了，他们整天坐着想『未来 12 个月全是最坏情况会怎样』」——并援引奥本海默的反事实：1944 年坐在他旁边忧心「五年后地球核废土」的人错了，「炸弹成了世界和平遇到过的最好的事，我们得到 50 年没有总体核毁灭的冷战」。这两个观点（AI 安全研究者「发疯」论、原子弹和平论）均为嘉宾个人判断，争议性强，本站照录不背书。他唯一愿意做的远期预测偏经济：如果人人都能像他这样工作，「GDP 一年加速 3%、4%、5%、10% 在可能范围内」；至于模型一年后在哪儿——「摇一摇八号球再问一次」。他挂在嘴边的是 William Gibson 那句「未来已在这里，只是分布不均」。

对行业代际，主持人的观察是：这波 AI 浪潮里「我们从小仰望的老将们回来了」——Eric Raymond 回来了、John Carmack 在场、DHH 的演讲「software is over, now we're builders」被认为在「领一代人穿过困惑」。DHH 的版本更尖锐：他「深度尊敬其编程功力的人，百分之百全部 fully pilled（彻底入教）」——因为真靠硬功夫建成过东西的人，「无法否认这些工具能加速任何工作」；成功者不觉得被威胁。但他同时给「不舒服的中间层」留了位置：大多数程序员并不财务自由、靠多年苦功挣得座位，突然要面对「如果明天都不用程序员了、我们都成了 maker，我是不是个好 maker」的焦虑——「这值得同情，就像你该同情七十年代底特律的汽车工人、同情英国最初的卢德织工」；同情归同情，方向上他毫不妥协：「我不会回到前工业时代拿锄头跟牛一起自耕农去……我们只能向前，把所有人带过去。」

由此进入本期最具火药味的段落（全部为嘉宾观点）：他认为当下是一场「vibes 之战」，而反 AI 阵营的构成耐人寻味——「把最让人受不了的蓝头发 woke 人群和反 AI 人群画韦恩图，它是个圆」；他的解读是文化性的：「他们不喜欢的人先拥抱了这项技术，于是他们只剩一个可站的位置：反面。」他不忘补一句限定以免以偏概全：「不是每个对 AI 不安的人都是蓝头发蠢货——只是每个蓝头发蠢货都反 AI。」而五年前「似乎握有全部文化权力、随时随地能取消任何人」的正是那批人，「现在鞋换脚了」。对这场争论他的结语是单向门：「无论你感觉如何，只有一条路——向前穿过去。没有人会自愿放弃这项技术，除非我们都变成仓库货架上的回形针。」

最后一段是情怀，也是这期节目最动人的部分：**伪匿名黑客的回归**。Omarchy 核心团队与 Omacom Foundation 名单上有两位伪匿名成员——outfoxxed（桌面交互所用的可塑 shell「QuickShell」的作者）和艺术家 HandCore；基金会还赞助了 0xZero、Mia's lab 等伪匿名的本地 AI 项目。DHH 说这是对九十年代 phreaker 文化、精英 BBS 的复刻：「互联网被商业化、被平台收编后，前沿工作被大公司吞掉了——Chrome 之后再造一个浏览器基本不可能，浏览器引擎是 Linux 内核之后人类造出的最复杂软件。我们曾把计算机里所有『要紧的领域』都对大公司关闭了，现在正在把它民主化、还给黑客文化。」他把 X 称为这场革命的「结缔组织」：艺术家、伪匿名黑客、本地 AI 运动都在上面连接起来——「要是当年那帮蓝头发帮在 Elon 买下之前守住了它，这一切可能根本不会发生，全成 LinkedIn 式的人肉粥。」这是彻底的反 LinkedIn 文化。九十年代 demo 文化也在回来：Omarchy 的标志性屏保就是「跑着 40 种 demo 特效的 ASCII art」，启动本地模型加载的那几秒他还塞了一段纯装饰的 ASCII 动画——「有功能吗？完全没有。就是让你觉得自己在用一台酷毙了的电脑。」他甚至还原了盗版游戏时代的记忆——「cracked by Razor 1911」的开头动画、Xmodem/Ymodem/Zmodem/Kermit 协议、14 岁在自己卧室经营「elite BBS」拉了三条电话线、丹麦电信垄断公司工人上门看到 14 岁小孩时的表情——「他判断这肯定违法，他完全正确。那完全违法，也完全 awesome。」他还能背出 U.S. Robotics 33.6 Modem 的拨号音。落点是对整期主题的收束：「计算机应该有点神秘感，应该很酷，不该被抛光到没有个性——Jony Ive 基本上用铝把计算机的个性全抛光了。也许那曾是对的，但那个时代结束了。我们他妈的要把黑客们要回来了。」（节目在 DHH 确认 Malibu 办公室照片属实、「这间办公室由商业软件赞助」的自嘲与 Happy hacking 道别中收尾。）

## 机制 → 影响 → 启发

从账本里可以抽出至少四条完整链条：

1. **接口形态 → OS 竞争力反转**：agent 以文本（CLI/配置/报错）为母语 → Linux 的历史缺陷变成资产、macOS/Windows 的 GUI 与权限墙变成负债 → 应用商店 30% 抽成的生态锁定被「应用可按需生成」绕开 → 观察指标：macOS/Windows 对 agent 的权限政策是否实质放宽、Omarchy 类发行版的留存率（不止装机量）、Lightroom 级复刻案例的密度。启发：评估任何平台在 agent 时代的处境，先看「agent 能否用文本读写它的全部状态」。
2. **生产成本趋零 → 组织形态极化**：写代码的价格与难度趋零 → 「开发者数量 + 多年跑道」的融资逻辑失效，压缩为「品味 + 天/周级迭代」→ 单人/小团队可以对抗千人大厂（2.5 个月 vs 十五年），但也意味着 60 人公司无需长大就能释放 6 万人的产能 → 观察指标：VC 轮次结构变化、一次性 agent 产品的复购与维护（谁做最后 20%）。启发：个人的护城河从「会写」转向「知道该是什么样 + 熬到最后 2%」。
3. **开放权重近前沿 → 定价权约束**：GLM 5.3/DeepSeek Flash 级模型约落后 6–7 个月但可本地运行（DGX Spark）→ 前沿实验室无法无限提价（否则重演广告业 99% 价值被两公司吸走的剧本）→ 政策上「政府接管/强制双寡头」被 DHH 类比为禁止公钥加密的灾难 → 观察指标：token 价格曲线、开放权重差距是否稳定在月级。启发：企业选型时「本地可跑的开权重」已从玩具变成谈判筹码。
4. **心理结构 → 采纳曲线**：完美主义者获得「零协调成本军队」→ 工作时长的自愿极化（16 小时）与「AI euphoria vs AI psychosis」的心理卫生问题 → 「vibes 之战」决定反 AI 情绪的阵营化而非理性化 → 观察指标：资深工程师群体的实际工作状态、焦虑症候与产出曲线。启发：限制你的已不是工具带宽，而是你自己的品味带宽与作息纪律——DHH 这期的标题就是警示而非勋章。
