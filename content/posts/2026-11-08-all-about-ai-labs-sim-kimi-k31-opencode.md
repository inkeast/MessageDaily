## 先说结论

一个不会（也不需要）写完整游戏的人，用 Kimi K3.1 Pro 跑在 OpenCode 编码代理里，把一个「经营自己的 AI 实验室」的模拟经营游戏从零建到可玩、再在一个视频里现场扩了两轮功能——这是本期 All About AI 的全部内容，也是它值得看的原因：**「造一个只有自己想玩的游戏」已经从一次性 Demo 演进成可持续迭代的个人软件工程**。与一个月前用 Opus 5.5 复刻交易游戏相比，这次的增量有三处：模型侧从 Opus 换成了性价比取向的 Kimi K3.1 Pro（频道主明说 Opus 也很好，但定价让他选 Kimi）；流程侧出现了「语音口述→模型整理成结构化需求→P1/M1/M2/H1/P2 分期路线图→夜间无人值守循环实现」的完整流水线；以及最有意思的一层——**游戏机制清单本身就是 2024-2026 年 AI 行业热点词的图鉴**：闲置算力按分钟出租、权重失窃（weight theft）、刷分（benchmark gaming）、出口管制、废热出售、明星研究员……频道主在用造模拟的方式把行业机制逐条枚举了一遍。

## 游戏机制：把 AI 产业的经济学逐条做进玩法

按频道主播放的内置宣传片（节目引用），AI Labs Sim 的核心设定是：你经营自己的 AI 实验室，建数据中心、优化算力、做研究、训模型、赚钱，同时有一个躲在战争迷雾里的竞对前沿实验室 Vanta Labs 在跟你赛跑；目标是「从车库长到 10 吉瓦，抢在 Vanta 之前完成 frontier run」。几个机制值得单独点名，因为它们各自对应一条真实行业逻辑：

- **闲置算力按分钟出租**：没用掉的算力自动租出去，租金按分钟计、价格全天波动，收入减去电费就是你的现金流——这几乎就是新云（neocloud）商业模式的玩家视角复刻。
- **每个「算力时代」解锁一个 AI agent 席位**：算力扩容不只带来收入，还带来管理层编制——agent 可以分管电力、算力、研究、模型等部门，授权程度从「顾问」到「全权代理」连续可调。频道主称这些 agent 会自己尝试、看分数、把有效的做法写进 playbook，「坏动作扣分，好动作留下来」。
- **agent 写的是真代码**：游戏内的 agent 会往一个 Git 仓库里写 Python 优化器，由游戏在隐藏测试集上跑分，「代码更好，赚的钱更多」。
- **机会成本显性化**：宣传片原话——「投给研究的每一份算力，都是你不赚的租金」；再加上「太阳能夜里归零」这类电力现实，游戏把研究、创收、电力稳定性放在同一个天平上。
- **对抗层**：可以间谍、挖角、价格战、游说其他实验室（频道主补充：「都特别贵」）。

频道主的存档进度也按这套逻辑展开（频道主称）：已到 1.5GW、4 个 agent 席位；训练过 5 个模型，最新一个 179B 参数；训练时有 log loss 曲线，算力越多表现越好；训好的模型可以选择「对外服务」赚钱，也可以把算力分配给研究。他给负责模型训练的 agent 取名 Ilya——「就像 Ilya Sutskever」，这个命名本身就是玩家对行业叙事的玩梗。

## 「游戏里住着一个真编码代理」：可插拔的 Claude Code / OpenCode / Codex

这个游戏最不寻常的设计，是它内嵌了一个**真实的编码代理**作为游戏机制：游戏里的助手位可以插 Claude Code、OpenCode 或 Codex（频道主演示时用的是他此前配置好的 Claude Code），玩家可以向它问「我们下一步最优动作是什么」，得到「招一个工人、做 dispatch batching、启动一个研究项目、攒钱建数据中心」这类建议；宣传片里则把游戏内置的编码代理称作「Unit Zero——你自己的 Claude Code」，它负责建造、招聘、交付代码。换句话说，「用 AI 造游戏」和「游戏里用 AI」被缝在了同一个循环里：外层的编码代理扩建游戏，内层的编码代理替你经营。

## 工作流复盘：从语音口述到夜间循环

频道主花了不少篇幅展示「怎么造」，这部分对想复刻的读者最有信息量：

1. **需求从语音开始**：他用语音输入把想要的游戏讲给 Kimi，由模型整理成结构化 prompt——「建一个 AI Labs Sim：等距视角实时策略游戏，灵感来自 Factorio；目标 10GW、完成 frontier run、打败竞对；以 C++ 为主便于在 Mac 上跑」（转写提及「C++ 20 加 SDL3」，疑为图形库组合，转写疑作）。
2. **模型自己排路线图**：他让 Kimi K3.1 Pro 建议扩展方向，得到一份带优先级的实现清单——P1/M1/M2/H1/P2 分期，条目包括芯片供货周期、电网排队与电力交易、硬件故障、废热出售、数据作为资源、API 客户、多模型产品线（而不是只有一个模型）、benchmark gaming、weight theft、出口管制与监管、明星研究员等。这份清单几乎可以直接当 AI 产业研究提纲用。
3. **跑一把就见效**：现场执行 P1+M1 后，游戏里出现了「数据作为资源、API 客户、芯片供应、可见的下一目标」等新系统；研究树新增了推理模型（reasoning models）与浸没式液冷（频道主：「2000 万，好贵」）；模型管理页新增了授权（license）选项——语料可选书籍、代码、科学论文（每项 3 亿，频道主咋舌）、训练配比可调 chat/coding/enterprise、可开关合成数据。
4. **夜间循环批量施工**：更大的一批功能（地图动画、明星研究员招聘体系、场地架构师、总部升级、金融层）是他让 Kimi 3.1 「像跑一个循环一样」（转写作 almost like a slash goal，具体机制存疑）整夜无人值守实现的。金融层包括公司估值、融资轮、季度财报、债务与租赁、合同与待售初创公司、新闻流（竞对 Vanta 会在新闻里攻击你，你可以回击——频道主演示回击失败）以及热度计量表。
5. **现场小改动验证**：他口头加需求「设置里加小地图开关、+号金额提示放大」，几分钟后在新开局「Sixth Intelligence」的教程流程里验证生效。

「雇人还是用 AI」也被做成了机制（频道主称）：岗位可以雇人类（约 40 美元/分钟、预付 10 分钟），也可以挂你自己训出的模型——模型越好，该岗位表现上限越高，最高可到 100%；演示中热浪来袭、散热吃紧，末尾服务器机柜起火直接烧掉了他的开局存档，频道主的反应是「也许该加个保险机制」——失败本身在为游戏生成新需求。

## 三个值得带走的观察

1. **个人软件的「为自己造」闭环成立了**（机制→影响→启发）：编码代理成本降到「夜间随便跑」的量级后，游戏开发从「立项-团队-发行」收缩成「口述需求→模型施工→自己玩→不满意继续改」的个人循环。频道主的原话是「这太解放了（liberating）」：他既享受玩，也享受开发，且明确表示暂时没有商业化计划。对普通开发者的启发是：**先做自己的第 0 号用户，需求-实现-反馈的延迟可以压到分钟级**。
2. **高频迭代的工具选择由单价决定**：频道主对模型的态度很务实——Opus 擅长这类任务，但 OpenCode 里跑 Kimi K3.1 Pro 的定价更适合「整夜循环+随手扩建」这种消耗量；他同时强调 Kimi「并没有为游戏开发专门优化，但效果出奇地好」（频道主称，未独立验证）。当能力差距不大时，单次迭代成本的微小差异会乘以迭代次数，决定工具归属。
3. **造模拟=强迫自己枚举机制**：AI Labs Sim 的功能清单——租金经济、算力即编制、权重失窃、刷榜、出口管制、废热、明星研究员、保险——本身就是一份行业机制地图；想检验自己是否真理解一个行业，试着把它做成游戏规则是个不错的方法。还有一个自指的细节：频道主提到游戏里已有「AI campus（AI 园区）」概念，因为「OpenAI 据新闻正试图把数据中心改名叫某种 AI 算力园区」——这个机制是 Kimi 做在线调研时自动抓进游戏素材里的（频道主称）。行业叙事在实时地变成游戏内容。

频道主预告的下一步：Kimi 在 3D 建模上评测数据不错，他打算试试用 Blender 生成游戏资产；散热与保险机制可能在后续视频补上。本文所有能力描述均来自其口播，游戏未发布、无法独立验证，读时请按演示性证据对待。
