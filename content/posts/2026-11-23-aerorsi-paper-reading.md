## 一、论文背景

### 1.1 无人机视觉-语言导航是什么

视觉-语言导航（Vision-Language Navigation，VLN）指的是：给智能体一句自然语言指令（比如『飞过操场，在红色屋顶的房子旁降落』），它要根据第一人称视觉观察，自主输出动作，一步步走到目标。无人机版 aVLN 最初由 AerialVLN（ICCV 2023）与 TravelUAV（ICVRV 2025）等基准确立，后续有 OpenFly、CityNav、SatNav 等扩展。近年来出现了直接用视觉-语言-动作（VLA）模型端到端映射观察和指令到飞行动作的轻量策略，如 AerialVLA 与 AeroDPO——一个 2B 参数的模型就能逼近更大模型的导航成功率。

和地面机器人相比，无人机导航更『脆』：三维空间里障碍密布，单个错误动作就足以撞机，而 episode 通常在第一次失败（碰撞、卡死、飞离目标、过早降落、超时）时直接终止。这让 aVLN 的闭环失败率成为制约实用的核心瓶颈——AeroRSI 出发点的那个 SFT 策略，测试碰撞率高达 38.6%。

### 1.2 模仿学习的固有裂缝：分布漂移

SFT 策略的失败根源是模仿学习的老问题：策略在飞行中会到达示范数据从未覆盖的状态，误差逐步累积。修正这种失败需要『修复』（repair）——在策略自己到达的状态上给出能避开失败的动作。问题在于：谁来提供这些动作？

- **人类专家**：交互式模仿学习（DAgger 一系）要求专家在学习者到达的每个状态上给标签，无人机场景下人力成本完全无法规模化；
- **规则规划器**：势场避障等经典方法不理解语言指令，给出的动作『不知道任务是什么』；
- **自动修正**：AeroDPO 用碰撞回滚合成偏好对，但裁决者不是策略本身；
- **强化学习**：episode 级奖励只告诉你这次飞失败了，不告诉你当时哪一步应该怎么改——时间信用分配问题在延迟后果的碰撞里尤其严重。

于是本文锁定的空缺是：**免人工标注、动作级、且策略自己执行得了的监督信号**。

### 1.3 从语言模型借来的递归自我改进

递归自我改进（RSI）近年在语言模型上大放异彩：STaR 保留答对的推理链再微调，ReST 用采样-过滤-训练循环提升数学与代码。语言任务的验证器是答案本身或测试套件——**答案可以独立验证**。但闭环飞行给 RSI 出了三道语言任务没有的难题：

1. **动作没有独立价值**：一步飞行动作的好坏取决于之后整段飞行由谁来飞——需要步级价值（类似过程监督），而非答案级验证；
2. **失败是逐步揭晓的**：episode 在首次失败即终止，后面的失败被前面的失败挡住看不见——监督集合不是静态的；
3. **策略采不出自己需要的动作**：语言模型 RSI 主要强化模型已能产出的答案，而失败策略往往连正确的动作都采不出来——但简单的物理先验（爬升、绕障）随手就能提议一个，恰如 STaR 的 rationalization。

这三道难题正好对应 AeroRSI 的三大设计。理解了这个『答案级自改进到动作级自改进』的断层，就读懂了本文的定位。

## 二、论文定位和关联工作

### 2.1 研究谱系一：aerial VLN 后训练

| 工作 | 核心思想 | 监督来源 | 与 AeroRSI 的关键区别 |
|---|---|---|---|
| TravelUAV（ICVRV 2025） | L1 助手引导 + VLA 基线 | 专家示范 | 纯 SFT，无失败学习 |
| AerialVLA | 轻量 VLA 逼近大模型 | 专家示范 | 架构改进，不修失败 |
| RefineFly | 在线强化学习后训练 | episode 级奖励 | 奖励不指明哪步错 |
| AeroDPO（arXiv 2608.07557） | 碰撞回滚抽取拒绝动作 + 特权干预合成偏好动作 + VLM 审查过滤 | 规则/特权合成对 | 由模拟器状态回滚与特权几何裁决，不检查策略能否执行 |
| **AeroRSI** | **失败策略续飞自裁** | **策略采样 + 规则提议，经策略续飞验证** | **裁决者是策略自身的后续飞行** |

AeroDPO 是最直接的对照：同为免人工的后训练、同用模拟器回滚，差别全在『谁说了算』——AeroDPO 的偏好对由确定性回滚与特权干预预先判定，AeroRSI 的标签由当前策略从恢复态真实续飞来判定。实验里两者还互补：从 AeroDPO 初始化再跑 AeroRSI 达到 69.85% 新 SOTA。

### 2.2 研究谱系二：从修正中学习

DAgger/AggreVaTe 一系交互式模仿学习要求专家标注学习者到达的状态；导航领域有从专家修正、崩溃与接管事件中学习的工作，以及 CorrectNav 的自纠错飞轮（把错误轨迹变成训练数据，用与真值轨迹的偏差点切分修正样本，同时修感知与动作两层，R2R-CE/RxR-CE 成功率提升 8.2%/16.4%）。免人工合成修正的代表正是 AeroDPO（碰撞回滚）、CorrectNav（参考路径）与辅助残差策略。这一谱系的共同盲点是：修正由专家、启发式或参考路径裁决，**没有一个考虑了当前策略能否真的执行这些修正**——AeroRSI 的 Fig.5(c) 证明同一个动作在 π0 手里坠机、在 π1 手里却能完成任务，价值不是动作的属性，而是（动作 × 续飞策略）的属性。

### 2.3 研究谱系三：递归自我改进

STaR 的 rationalization（给答案反推理由）、ReST 的采样-过滤-训练、expert iteration 构成语言模型 RSI 主线，近年的分析指出它主要强化模型已能产出的内容。在机器人与导航侧，agent 自产数据学习、残差策略修正、CorrectNav 的重复再训练、局部恢复监督（检查冻结学生能否从教师恢复态续飞）都是先声。最接近本文理论根基的是 rollout-based policy iteration 与 learning to search：用继续执行来评估动作。但这些方法要么对一小撮动作逐一 rollout，要么跟随参考策略；AeroRSI 把这种『续飞裁决』搬到拥有近百万动作空间（每分量 99 bins × 三维 + 降落）的 VLA 策略上，从恢复态做蒙特卡洛续飞验证策略采样与物理先验两类候选，无需参考路径或教师。

### 2.4 定位总结

| 维度 | 之前的路线 | 本论文的突破 |
|---|---|---|
| 裁决者 | 专家 / 规则 / 特权几何 / 参考路径 | 当前策略自己的续飞（Q^πk 估计） |
| 标签可信度来源 | 裁决者先验正确 | 通过复现检查 + 独立再飞的确认检查 |
| 监督集合 | 一次性合成（静态问题集） | 每轮重新锚定（失败随修复逐步揭晓） |
| 策略采不出的动作 | 无法进入监督 | 规则提议经续飞验证后成为最有效监督 |

**一句话定位**：AeroRSI 把 RSI 从『答案级可验证』的任务移植到『动作价值依赖后续闭环执行』的飞行任务，用近似策略迭代统一了 DAgger 式按需标注与 STaR 式自举标签两大思想的具身版本。

## 三、问题定义

### 3.1 从具体场景到抽象问题

具体问题：一个会撞机的无人机策略，怎么在不请人标注、不请专家的情况下，从自己的失败里学到能用的修复动作？

论文的抽象：每轮 k 从当前策略 πk 出发，对 πk 失败的每个状态 s，找到改进动作：

```
a*(s) = argmax_a Q^{πk}(s, a)
```

其中 Q^{πk}(s, a) 是在 s 执行 a 后**跟随 πk 继续飞行**的期望回报。这正是近似策略迭代（approximate policy iteration）的目标——关键在于 Q^{πk} 的定义本身就指定了裁判：**定义域是 πk 的后续行为，所以只有 πk 自己续飞才能估计它**。形式化后两个硬约束自然浮现：

1. **续飞结果是随机的**——单次 rollout 是 Q 的有噪声样本，需要复现/确认机制；
2. **需要修复的状态集合随策略改进而暴露**——首失败终止机制使后续失败被隐藏，目标集合每轮都在变。

### 3.2 这个抽象的精妙之处

| RL 经典概念 | AeroRSI 对应 | 说明 |
|---|---|---|
| Q^π(s,a) 估计 | CVR 从恢复态执行候选后 πk 续飞打分 | 有限视野蒙特卡洛估计 |
| 策略改进（improvement） | RRL 蒸馏验证修复 | 贪心改进，无惩罚项 |
| 策略评估（evaluation） | 每轮全量飞行收集新失败 | 随 πk 更新而重锚定 |
| on-policy 数据 | 策略采样候选 | 近策略迭代结构 |

精妙之一在于『裁判即被执行者』：因为每轮改进的是 πk 本身，下一轮的裁判 πk+1 也更强，循环因此是递归的。精妙之二在于把『修复动作标签生成』转成了一个蒙特卡洛值估计问题——两道随机性难题（续飞随机、失败隐藏）恰好被 CVR 的双重检查与 AFA 的每轮重锚定一一化解，模块与问题约束严丝合缝。

## 四、问题解法

AeroRSI 每轮循环三个模块：AFA 找失败在哪 → CVR 验证修复标签 → RRL 蒸馏且不遗忘。策略骨干是 Qwen3-VL-2B（前视 + 下视 RGB 拼成 384×768 马赛克，动作自回归输出），只训 LoRA（rank 64）与视觉合并器。

### 4.1 AFA 自适应失败锚定：失败发生在多个时间尺度上

类比：飞机事故调查不只看坠机前最后一秒，还要看几分钟前的航向决策。AFA 对每个失败 episode 在失败点前放置**指数间隔**的探针（偏移 1、2、4、8、16 步）——近端捕捉直接原因（撞向障碍的动作），远端捕捉早期决策（拐进死胡同的转向）。探针数量远超可验证预算，于是均匀采样固定预算（2,400 个/轮），使**锚点分布自动跟随当前策略的失败分布**：高频失败类型获得更多锚点，已被修复的失败自然出局。每个锚点记录（状态 s、观察 o、原动作 a⁻），并被赋予随偏移增长、越过原失败点的评估视野——合格候选必须带着飞行越过失败点，而不是只活两步。

输入：πk 飞完所有训练路线的失败日志。输出：锚点集合。作用：把『哪里需要监督』这个开放问题变成对策略失败分布的无参数估计。

### 4.2 CVR 续飞验证修复：用策略自己的行为估计 Q^πk

类比：换轮胎后不能只看轮胎装没装上，要开出去跑一圈才知道修没修好——而且要用『你自己的驾驶习惯』开。

**候选组**：对每个锚点 (s, o, a⁻)，候选 = 原动作 a⁻ ∪ 从 πk 采样的 M=4 个动作（温度 1.0）∪ 三个规则提议：势场避障动作（由深度图 + 目标位置计算）、保持前进的平移变体（限偏航 0.224 rad）、保持航向的爬升（+2m）。采样动作代表『策略产得出但不选』，规则提议补充『策略几乎采不出』的避障类动作。

**续飞打分**：恢复状态 s → 执行候选 c → πk 贪心续飞至视野终点，得分：

```
S_k(s,c) = Δd − λf·1[fail] + λs·1[success]
```

其中 Δd 是朝目标的推进距离，失败指碰撞/过早降落/无效输出，λf=100、λs=20、最低推进 4m。这是 Q^{πk}(s,c) 的有限视野估计——判据是策略自己的后续飞行，而非候选动作的直接后果。

**三重验证**（Algorithm S1）：
1. **输入检查**：恢复的观察必须仍让策略贪心输出 a⁻，否则丢弃（保证锚点可复现）；
2. **复现检查**：重放 a⁻ 必须再次失败，或最优合格候选领先其超过 4m 裕量（排除运气结局）；
3. **确认检查**：按分数序对前两名候选独立再飞，第一个再次合格的才被接受为修复 c*。

输入：锚点。输出：经验证的修复对 (o, c*) 或丢弃。作用：把不可靠的弱来源（策略采样、规则提议）过滤成可靠标签——消融显示未经此验证的规则标签直接模仿会把 SR 拉低到 39.75%，反而低于初始 46.4%；验证后升到 61.59%。

### 4.3 RRL 保持式修复学习：蒸馏而不漂移

只学修复的副产物是『修复统计量泄漏』：修复里转弯占比约 30%，策略会把爱转弯的习惯带到整段飞行。RRL 用三项设计对抗漂移：

1. **修复监督**：最大化 c* 的似然，**不加对原动作的惩罚**（原动作往往只是略差、且在别的状态仍然正确，显式压低会伤害别处飞行——与 DPO 的关键差异）；
2. **行为保持**：混入 1,990 个无需修复的状态（覆盖起飞、接近目标、降落），标签是**当前策略 πk 的贪心输出**而非示范或旧策略——保持锚定的是自己的行为；
3. **修复回放**：第二轮起以 ρ=30% 权重回放上一轮修复，防遗忘。

损失：`L_k = (1−λn)·CE(c*) + λn·CE(âk)`，λn=0.2。学生从 πk 初始化，训完即 πk+1。

### 4.4 全景对比表

| 模块 | 输入 | 输出 | 核心机制 | 拒绝什么 |
|---|---|---|---|---|
| AFA | πk 失败日志 | 2,400 锚点/轮 | 失败前 1/2/4/8/16 步指数探针均匀采样 | 手工锚点（只覆盖设计者预期的失败类型） |
| CVR | 锚点 | 验证修复 (o, c*) | 恢复态 + 续飞打分 + 三重验证 | 运气候选、不可复现锚点 |
| RRL | 修复 + 保持状态 | πk+1 | 只蒸馏 + πk 自标注保持 + 回放 | 对原动作的惩罚（DPO 式） |

成本上每轮约 100 GPU 小时（训练 7,611 条航线 17-20 小时、验证 6 小时、训练本身仅 11-23 分钟），部署时策略架构与推理开销与 π0 完全相同——所有特权（状态保存/恢复、深度图、目标位置）只在造数据时使用。

## 五、评估指标与实验证据

### 5.1 指标体系与基准

TravelUAV 测试集：3,005 条航线，分 Seen（1,418）/ Unseen Object（629）/ Unseen Map（958）。成功判定：200 步内降落在目标 20m 内。

| 指标 | 定义 | 方向 | 衡量的能力 |
|---|---|---|---|
| SR | 成功率（核心主指标） | ↑ | 闭环飞行任务完成的本质能力 |
| CR | 碰撞率 | ↓ | 论文动机的直接靶子（闭环主失败模式） |
| NE | 导航误差（米） | ↓ | 失败时离目标多近 |
| OSR | oracle 成功率（到过目标附近即算） | ↑ | 无终局判断折扣的到达能力 |
| SPL | 路径长度加权成功 | ↑ | 成功且高效 |

关键实验设计细节：闭环飞行是随机的——同一策略评两次约四分之一航线结局改变、SR 波动可达 2 分。因此所有对比按航线逐对进行，配对 McNemar 检验（|z|>1.96 即 p<0.05），小于噪声的差异不作主张。

### 5.2 主结果：与前人方法对比（三轮后）

| 方法 | Seen SR | Unseen Obj SR | Unseen Map SR | Overall SR |
|---|---|---|---|---|
| TravelUAV | 16.10 | 22.42 | 4.18 | 13.62 |
| NavFoM | 29.17 | 29.83 | 6.30 | 22.02 |
| LongFly | 36.39 | 43.87 | 11.27 | 29.95 |
| AerialVLA | 47.96 | 56.60 | 37.58 | 46.46 |
| RefineFly | 56.33 | 59.72 | 42.97 | 52.78 |
| AeroDPO | 60.01 | 66.45 | 45.93 | 56.87 |
| **AeroRSI (SFT init)** | **75.32** | **82.19** | 46.24 | **67.49** |
| **AeroRSI (DPO init)** | 76.52 | 79.65 | **53.55** | **69.85** |

- 同一 SFT 初始化，AeroRSI 超 AeroDPO 整整 10.6 分（z=10.2，逐航线配对显著）；航线级净胜：AeroRSI 在 649 条 AeroDPO 失败的航线成功、反向仅 330 条；
- 增益集中在循环收集过经验的场景：Seen +15.3、Unseen Object +15.7，NE 缩小近 40%；Unseen Map 上比 SFT +9.4 但只打平 AeroDPO（SPL 反而更低）——诚实呈现了方法边界：没见过的环境里，天花板主要由初始化策略决定（从 DPO 初始化时 Unseen Map 到 53.55）；
- SPL 涨幅小于 SR：很多修复是爬升或绕行，路径变长了。

| 轮次 | Seen | UO | UM | SR | CR |
|---|---|---|---|---|---|
| 0 (SFT) | 48.38 | 56.44 | 36.85 | 46.39 | 38.64 |
| 1 | 62.62 | 67.89 | 43.42 | 57.60 | 29.48 |
| 2 | 73.91 | 79.01 | 45.82 | 66.02 | 21.26 |

每轮增益 11.2 → 8.4 → 1.5（第三轮在噪声内），碰撞率近乎腰斩。失败类型结构性转移：碰撞 38.6%→19.1%、飞离 7.8%→2.1%，超时反而 1.2%→6.8%——瓶颈从『别撞』移到『按时到』。训练航线 SR 同步上升（45.2→70.9），修复泛化到了未锚定的状态。

### 5.4 消融：每个设计都被证明必要

**验证的价值（第一轮，SR）**：势场标签直接模仿 39.75（比初始还低 6.6 分！）；未验证规则提议 49.23；**验证后规则提议 61.59**——裁决方式本身值 12.4 分。策略采样验证增益小（+1.0），且来源离策略越远验证收益越大。去掉三重检查只做单飞（58.4）损失不大——真正不可缺的是『续飞』本身而非检查细节。但只看前 2 个动作打分会多留 4.2 分碰撞——短视判据系统性偏向后炸的候选。

**递归的必要性（第二轮对照，SR）**：陈旧标签重训 60.30、单轮双倍锚点 62.98，均低于真两轮 66.02——**失败在移动而不是修复会过期**：旧修复在后续策略下 87-89% 锚点仍合格，但旧失败动作在 π3 下 66.6% 锚点已能通过；连续两代策略的失败点中位距离 40m（π0→π1）/28m（π1→π2），同一策略飞两次仅 13m——失败点真的换了地方。

**RRL 的必要性（第一轮，SR）**：去保持项 57.46（CR 恶化到 32.0，转弯率 15.8%→19.6% 漂向修复统计量）；换成对 π0 保持 58.97（不依赖 AeroDPO）；GRPO 式优势加权 53.93（低于模仿最优候选 3.7 分——一个状态一个一致修复胜过多个竞争者）；加 DPO 损失 58.04 且单独 DPO 损失会让 SR 崩到 0.1%——增益来自验证修复本身而非目标函数形式。

**高度质疑**：修复偏爱爬升（飞行峰值中位高度 10m→36m），但把高度限制在 15m 内后 π3 仍保住 16.2 分增益中的 13.2 分——增益不全是『飞得高』。

## 六、效果优势的根源解释

### 6.1 根源机制与证据链

**对比对象**：AeroDPO——碰撞回滚 + 特权几何合成偏好对 + VLM 过滤。它为什么曾经有效？因为它以近零成本制造了 (chosen, rejected) 对，用偏好目标内化了避障边界。它的根本局限在**裁决者与执行者错位**：特权干预用真值几何算出的『最优避障动作』，其价值以一个不存在的执行策略为前提——AeroRSI 的 Fig.5(c) 显示，同一动作 π0 执行坠机、π1 执行成功。静态合成的标签没有理由恰好落在当前策略的可达行为流形上。

**因果链一：裁决者对齐 → 标签可执行性**（论文实验已支持）
CVR 用 πk 续飞估 Q^πk → 标签定义域与执行域重合 → 消融：验证规则标签 61.59 vs 未验证 39.75（差 21.8 分，z=-11.5）→ SR 提升。这不是『加了验证所以好』，而是验证改变了标签的信息来源：从『规则认为该做什么』变成『策略续飞能完成什么』。

**因果链二：续飞视野 → 时间信用分配**（论文实验已支持）
打分飞到越过原失败点的视野 → 捕捉延迟后果 → 只看前 2 动作的变体多留 4.2 分碰撞、约四分之一有修复的锚点上短期最优候选后来失败或停滞 → CR 减半。类比：AeroDPO 论文自己指出『碰撞是较早机动的延迟后果，惩罚碰撞帧天然无效』——续飞恰好是延迟后果的天然探测器。

**因果链三：失败重锚定 → 监督集合动态覆盖**（论文实验已支持）
首失败终止 → 修复 A 暴露 B → 失败点中位移动 40m/28m（vs 同策略重飞 13m）→ 单轮双倍锚点 62.98 < 两轮 66.02 → 每轮 +11.2/+8.4 增益。陈旧标签重训只有 60.3——监督要跟着失败走，不是跟着锚点走。

**因果链四：规则提议自举 → 扩大策略可达集**（论文实验已支持）
策略采不出的避障动作经续飞验证后蒸馏 → Table S7：只有规则提议能修的锚点上，策略采样 Pass@1 从 π0 的 11% 升到 π1 的 62%、π3 的 76.7%（held-out 航线组同样 13.7→57.7）→ 循环扩展了策略『产得出』的集合，而非仅强化既有行为——正面回应了『RSI 只是强化已有输出』的批评。爬升分量占比 12%→42%→57% 表明学到的修复确实内化成了采样分布。

**反事实推理**：把 CVR 换成 DAgger 式规则专家标签 → SR 跌破初始（39.75）；把 RRL 换成 DPO 目标 → 0.1% 崩溃；去掉保持项 → CR 反升。每个模块抽掉，系统都不只是退化回 baseline，而是各有各的塌法——组件必要性非常扎实。

### 6.3 综合判断与未决问题

**多项研究共同支持的机制**：① 验证/过滤环节决定自改进收益上限（RSI 综述、STaR 系、AeroRSI 消融三方一致）；② 增益随轮次递减、验证器可修的失败被耗尽（Terminal-RSI、CorrectNav 第四轮下降、AeroRSI 第三轮入噪声）；③ 接地信号（真实结果）是自举环不坍缩的前提（AlphaGo Zero 讲义、RSI 综述、AeroRSI 的物理续飞）。

**仍属论文内证据、待外部复验的机制**：规则提议经续飞验证后成为最有效监督（21.8 分差距只有本文一个消融支持）；失败点中位移动 40m/28m 作为『失败隐藏』的直接证据。

**适用条件与可能失效条件**：优势在训练分布内及近邻（Seen/Unseen Object 大涨）成立，Unseen Map 只打平 AeroDPO——环境泛化仍靠初始策略；SPL 增益小于 SR，修复以路径变长为代价；超时类失败随轮次增长，说明修完碰撞后时间效率是新瓶颈；推理零额外成本的前提是训练时有可精确保存/恢复状态的模拟器——真机或不可回滚环境无法直接套用（这是方法层面而非工程层面的边界）。另外第三轮增益已入噪声，『递归』到底能推多远，三轮数据尚不足以回答。

## 七、必要知识反推

假设一个零知识的人要复现这项工作，最少必须掌握什么？

### 7.1 领域知识层

- **aVLN 任务设定与失败语义**：五种失败类型、首失败终止、成功判据——不知道这些就无法定义『修复』；
- **模仿学习的分布漂移**：为什么 SFT 策略会到达示范外状态——这是整个问题的存在性证明；
- **无人机运动学离散化**：前飞/垂直/偏航三分量各 99 bins + 降落动作，规则提议（限偏航 0.224 rad 以保持平移而非原地转）的设计全依赖这层知识；
- **仿真器的特权接口**：状态保存/恢复、深度图、目标位置——不知道模拟器可回滚，就想不到续飞验证。

### 7.2 方法论知识层

- **近似策略迭代**：识别出 Q^πk 的定义域是 πk 的后续行为——这是全文最关键的抽象，来自 RL 理论；
- **RSI 在语言模型上的谱系**：知道 STaR 的 rationalization 与『RSI 只强化已有输出』的批评，才会想到引入规则提议做自举外源；
- **偏好优化的风险**：知道 DPO 会把概率推给非预期动作，才会刻意选择无惩罚蒸馏；
- **rollout 评估与 MCTS 直觉**：短视野 rollout 有偏（短期最优≠长期最优）——两动作打分消融正是这个直觉的实验化。

### 7.3 工程知识层

- **LoRA 微调与 VLA 训练管线**：冻结视觉编码器、只训 LoRA + 合并器，每轮 2 epochs、lr 2e-5；
- **统计显著性设计**：闭环随机性使 SR 有 ±2 分噪声——必须会做逐航线配对 McNemar 检验，否则满纸结论不可信；
- **预算工程**：探针远多于可验证锚点 → 固定预算均匀采样——把无限需求塞进有限算力的关键一步。

### 7.4 知识融合的关键节点

- **节点一（最关键的化学反应）**：RL 理论（Q^πk 定义域）× 仿真工程（状态可恢复）→ 『策略自己续飞裁决修复』。两个知识单独存在都不足以推出这个设计——知道 Q^πk 而不知道模拟器可回滚，只会觉得这是不可实现的理论目标；
- **节点二**：RSI 批评分析（采不出需要的动作）× 物理先验（爬升/绕障规则）→ 规则提议作为候选而非标签——必须同时懂『为什么需要它』和『为什么直接用它有害』；
- **节点三**：失败隐藏洞察（episode 首败终止）× 每轮重锚定 → 递归结构的必然性——把『循环』从工程选择升级为逻辑必需。

## 八、论文中可以提取的通用性灵感

### 灵感一：执行者应裁决自己的训练标签（裁决者-执行者对齐）

**核心思想**：任何『教执行者做 X』的监督信号，其可信度应由『执行者拿着 X 之后的表现』而非来源权威性决定。
**论文证据**：规则标签直接模仿 39.75%（低于初始），经策略续飞验证后 61.59%；同一动作 π0 坠机、π1 成功。
**推广场景**：① 代码 agent 的测试通过标准应包含『agent 能否续写完成』而非仅单测绿灯；② LLM 工具调用数据集按下游 agent 实际执行结果过滤；③ 医疗决策辅助系统的建议按临床工作流嵌入后的结局评估；④ 推荐系统的候选按用户真实后续行为（而非离线打分）筛选。

### 灵感二：弱来源 + 强验证 > 强来源（未验证）

**核心思想**：标签质量 = 来源质量 × 验证强度，验证环节的杠杆往往大于来源环节。
**论文证据**：势场规则是『弱来源』，直接用比不用还差 6.6 分；加上续飞验证反成最有效监督（+15.2 分对初始）。
**推广场景**：① 合成数据训练 LLM 时按可验证下游任务过滤而非按生成模型评分；② 知识蒸馏中助教答案经学生执行验证；③ 数据标注众包 + 自动一致性检查替代昂贵专家；④ 世界模型生成的轨迹经物理一致性校验后回灌训练。

### 灵感三：修复不掉过期，失败会移动——监督要跟着暴露走

**核心思想**：在『修复一处会暴露下一处』的级联系统里，监督集合必须每轮重新采集，静态数据集天然欠覆盖。
**论文证据**：旧修复 87-89% 仍有效，但失败点中位移动 40m/28m；单轮双倍锚点 62.98 < 两轮 66.02。
**推广场景**：① 软件测试修复后回归缺陷分布迁移，模糊测试应动态重播种；② 安全对抗修补后攻击面转移，红队需每轮重扫；③ 课程学习难度随掌握度重排；④ 多轮 agent 任务的错误分析按当前版本重新采样而非复用旧日志。

### 灵感四：外源动作做候选、自源行为做验证——绕开『采不出』的死锁

**核心思想**：当自改进循环受限于『策略采不出需要的动作』时，用廉价外部提议扩充候选池、用策略自身表现做过滤，能同时扩能力与保兼容。
**论文证据**：只有规则提议能修的锚点上，策略采样 Pass@1 从 11%（π0）→62%（π1）→76.7%（π3）；学到的爬升动作内化进采样分布（占比 12%→57%）。
**推广场景**：① 数学推理中用符号计算器提议步骤、模型自验推导；② 写作 agent 用检索到的范例做候选、按模型自评一致性过滤；③ 机器人操作用运动规划器提议抓取姿态、按策略 rollout 成功率筛选；④ 代码补全用静态分析提议 API、按测试执行采纳。

### 灵感五：只拉正向、不压负向的保守更新

**核心思想**：当『错误』动作仅是略差而非全错时，显式惩罚它会在其仍正确的状态上造成附带伤害；模仿正例 + 保留现状是更安全的更新。
**论文证据**：加 DPO 损失 58.04 ≈ 无保持项的 57.46，单独 DPO 损失崩溃至 0.1%；无惩罚蒸馏 + 行为保持 + 回放三件套达到 57.60 且每轮稳定。
**推广场景**：① 多任务模型的持续学习防遗忘正则；② RLHF 中避免过度惩罚被拒回答导致能力收缩；③ 知识编辑中『添加正确』优先于『删除错误』；④ 增量产品迭代中灰度保留策略。

### 灵感六：把评估噪声当一等公民

**核心思想**：闭环/开放系统的评测本身是随机的，不做逐对配对显著性检验的数字对比没有信息量。
**论文证据**：同一策略两次评测 SR 波动可达 2 分、四分之一航线换结局；论文所有主张均配 McNemar z 值。
**推广场景**：① LLM 评测多次采样方差报告；② A/B 测试的配对设计；③ 具身 benchmark 的多种子协议；④ 科研复现报告的标准误差文化。
