# In Situ Training of Optical Neural Networks by Coding Agents —— 精读

> **论文链接**：[In Situ Training of Optical Neural Networks by Coding Agents (arXiv:2611.23875)](https://arxiv.org/abs/2611.23875)（physics.optics，v1 2026-11-18，14 页）
> **机构与作者**：Stanford University 电气工程系（Ilker Oguz、Gordon Wetzstein，二位通讯）+ EPFL 工程学院（Colin Christian、Christophe Moser、Demetri Psaltis）。Wetzstein 是计算成像与 neural holography 的代表人物；Psaltis 则是光学神经计算方向四十年的元老，1980 年代全息光计算的开创者之一——这个作者组合意味着"光学硬件 + 计算成像 + 光学神经网络"三条血脉在一张实验台上汇合
> **领域标签**：physics.optics / AI for Science / LLM Agent / 光计算 / 仪器自动化
> **一句话**：把一台真实的光学神经网络处理器交给一个 headless 运行的 Claude Code 编码代理，只给它相机图像、测量预算和一本笔记本——它自己辨识系统、发现物理机制、用十几个可解释光学参数把网络调到超过校准模型反传的精度

## 一、论文背景

### 1.1 光学神经网络：原理与承诺

光学神经网络（Optical Neural Network, ONN）用光而不是电做神经网络的计算。先快速补齐原理骨架，供不熟悉光学的读者建立直觉：

- **衍射层即权重**：相干激光穿过一片相位调制结构（微加工衍射层、或 SLM 上显示的相位掩模）时，每个像素对光波施加一个可设计的相位延迟；光在自由空间中继续传播时发生衍射干涉——数学上，"相位调制 × 自由传播"的组合等价于一次矩阵乘法。堆叠多层衍射层，就得到一个 D2NN（diffractive deep neural network，Lin et al., Science 2018）；
- **为什么快且省能**：矩阵乘法以光速、零能耗（除激光与探测器外）完成，且整个二维波前是并行处理的——光传播损耗低、天然并行，承诺在规模扩展时给出高速度与低能耗；
- **参数是物理量**：可训练参数不是内存里的浮点数，而是衍射层的厚度分布或 SLM 像素的相位值，训练即"决定每个像素延迟多少相位"。

自 2017-2018 年硅基纳米光电路（Shen et al., Nat. Photon. 2017）与 D2NN 问世以来，这条路线已在推理、传感、加密等任务上反复验证，覆盖从太赫兹到可见光的多种载体。一个常被追问的基本问题——纯光学系统是线性的，怎么做神经网络的非线性计算？答案是：相位编码输入 + 相机平方律探测（强度是复振幅的模平方）+ 调制器非线性响应共同在输入-输出层面引入非线性，这正是本文实验设定的情形。

### 1.2 原位训练难题：sim-to-real 落差与两条昂贵的出路

但每台造出来的设备都会背叛它的设计图。制造误差、调制器响应偏差、光学平面之间的失准、像差——这些不完美让"在理想仿真模型里训练、再把参数搬到硬件上"的路线系统性地失效（该现象在衍射 ONN 文献中被统称为 simulation-to-reality gap，是领域的核心难题之一）。本文的实验里这个落差被量得很直白：相位掩模在理想角谱模型里分类 98%，搬到真实光路上只剩 35%，跟瞎猜三选一（约 33%）几乎没差别。

要在硬件上把精度找回来（原位训练，in situ training），传统上有两条路，而两条路都贵：

- **模型校准路线**：先用大量实测输入输出拟合一个可微分的设备数字孪生（校准角谱传播模型、digital twin 等），再对这个模型做反传训练。精度最高，但每台设备都要专家搭模型、数万张校准图、GPU 小时级的训练——设备造一万台就得校准一万次。本文的参考天花板正是这条路：校准用了 67,000 张相机图；
- **无梯度优化路线**：扰动、测分、统计学习。从 SPSA、进化策略、贝叶斯优化到前向训练（forward-forward、全前向模式）和强化学习（其中 PPO 是近期光学处理器对比中最优的方法）。不需要模型，但本质是试错：所需实验次数随参数维度陡增，而这里的参数是数十万个 SLM 像素。

无梯度方法什么时候变高效？当系统存在一个**紧凑的物理描述**时——波前整形和无传感器自适应光学就是先例：像差基、模式基是专家预先给好的低维参数化，传感器只需测量少数模式系数。问题是，对一台误差未知的光学神经网络，这个紧凑描述得先由专家找出来。

### 1.3 把"专家"换成代理

论文的动机正是把"专家"这一环替换掉：需要一个像实验物理学家一样的优化器——理解它所调的系统，主动选择信息量大的测量。而大语言模型的训练语料恰好覆盖光学教科书、器件手册、仪器文档与代码——把散落在许多专家脑中的知识打包进了一个可调用的模型；作为编码代理（coding agent），它能以程序的速度写代码、跑代码、改代码，无需人类干预地多步循环，此前已在算法发现（AlphaEvolve 等）、数学物理开放问题、实验室仪器操作（含光学台对准）上积累了实证。

更巧的是 2026 年 11 月刚被报告的"权重空间编程"（weight-space programming）能力：前沿 LLM 能读懂数字神经网络的权重、甚至直接改写权重实现功能——MIT CSAIL 的报告显示 GPT-6 Astra 仅编辑 0.016% 的权重就把 Qwen3.5-0.8B 的 MATH-500 从 7.9% 拉到 48.1%，且 Alan Turing 研究所独立复现成功。那么，参数只能"测"而不能"读"的物理网络，agent 能不能也理解并编程它？这就是 optics as code 的出发点。

## 二、定位与关联工作

把论文放进 AI for 实验物理的谱系里看，位置非常清晰。

**AI 代理这一侧的谱系**：

| 系统 | 领域 | 闭环内容 | 与本文的关键差异 |
|---|---|---|---|
| Coscientist（Boiko et al., Nature 2023） | 化学合成 | 文献检索+规划+云实验室执行钯催化偶联 | 优化的是实验流程，不是物理系统本身的参数 |
| ChemCrow（Bran et al., Nat. Mach. Intell. 2024） | 化学 | GPT-4 + 18 个专家工具规划执行合成，含驱虫剂、有机催化剂合成与新发色团发现 | 工具贡献正确性，模型只做编排；不涉及系统辨识 |
| A-Lab（Szymanski et al., Nature 2023） | 材料合成 | 机器学习规划+机器人固相合成+XRD 分析的闭环，17 天连续运行 | 后续因 XRD 物相鉴定可靠性引发更正与争议——反衬"人类可检查的诊断"之可贵 |
| AFM 代理（Mandal et al., Nat. Commun. 2025） | 显微表征 | LLM 自动操作原子力显微镜完成测量任务 | 任务是测量，不是训练一个高维物理网络 |
| VLM 光学实验室代理（Lopez et al., arXiv:2609.32918） | 光学对准 | VLM 看相机图像、直接发执行器指令，闭环对准迈克尔逊干涉仪、双镜腔与四镜中继光路，无预设标量目标 | 同样是光学+视觉闭环，但任务是"对准"而非"训练网络"，且未做参数空间重表示 |
| 权重空间编程（Takehi et al., MIT CSAIL 博客 2026-11；Goworek et al., Turing 研究所复现 2026-11） | 数字网络 | GPT-6 Astra 直接读/写数字网络权重（编辑 0.016% 权重把 Qwen3.5-0.8B 的 MATH-500 从 7.9 拉到 48.1） | 证明了"LLM 能理解参数空间"是涌现能力；本文把对象从可读写的数字权重换成只能测量的物理参数 |

两个值得单独点出的谱系观察。其一，化学领域率先跑通"文献知识 → 物理操作"闭环并非偶然——化学反应的机制描述高度文本化，正好命中 LLM 的语料分布；而光学实验的反馈是图像与干涉图样，此前被认为离语言模型太远。本文用"相机图像 + 文字化笔记"的 harness 绕开了这个障碍：图像进多模态模型、发现以文字沉淀，两个模态各司其职。其二，权重空间编程与本文构成一对漂亮的镜像——前者证明 LLM 能理解**可读**的参数空间（数字权重），后者证明它能理解**只可测量**的参数空间（光学相位），合起来指向一个更一般的命题：前沿 LLM 对"参数化系统"的理解能力可能不依赖于参数的物理载体。若该命题成立，其影响远超两篇论文各自的范围。

一句话定位：**这是第一个让编码代理在真实物理硬件上完成"系统辨识 + 机制发现 + 网络训练"全流程、并以严格对照实验证明其达到专家级校准路线精度的工作**。相对 Coscientist 谱系，它训练的是高维连续参数系统而非实验流程；相对权重空间编程，它处理参数不可直接读取、只能通过昂贵测量间接观察的物理现实；相对 Lopez et al.，它多出了"从测量中重建可解释参数化"这一步——而这恰恰是样本效率的来源。

还有一个易被忽略的定位维度：**评估的严格程度**。A-Lab 因 XRD 物相鉴定的可靠性问题遭遇更正与持续争议，给整个"AI 自主实验"方向提了个醒——声称越强，表征门槛越高。本文的评估设计明显吸收了教训：密封测试集、单次评分、交错块抗漂移、标准误报告、基线超参仿真搜优、消融在数字孪生上并行开展。它给出的是领域内罕见的、近乎临床试验级别的对照设计。

**光学这一侧的铺垫**同样重要：多反射 SLM 系统实现多层衍射网络来自作者团队自己的工作（Yildirim et al., Nat. Photon. 2024，用线性光学实现非线性处理）；校准模型来自 camera-in-the-loop 的 neural holography 谱系（Peng et al., ACM TOG 2020）；PPO 基线设定来自 Li et al.（Light Sci. Appl. 2026）对光学处理器上 in situ 强化学习的系统对比——这保证了基线不是稻草人。第一作者 Oguz 此前还有 forward-forward 光学训练（Opt. Lett. 2023）与多模态数字孪生（Nanophotonics 2025）的工作，团队在"训练光学网络"这件事上的积累横跨了本文对比的所有路线。

## 三、问题定义

剥掉光学术语，这篇论文处理的是一个抽象而普遍的问题：**高维物理系统的测量高效调参**。

形式化地：系统参数 θ 有数十万维（两个相位掩模 φ1、φ2 的全部像素）；你能做的只有"设置 θ、打入输入 x、拿到一次测量 y"（相机图像或分数）；∂y/∂θ 不可得（硬件上没有梯度）；可信的数值模拟器不存在（任务明令禁止）；测量预算 M 有限（分类任务 51,200 次）。目标是在预算内最大化任务指标。

形式化地：系统参数 θ 有数十万维（两个相位掩模 φ1、φ2 的全部像素，SLM 上合计数十万像素）；你能做的只有"设置 θ、打入输入 x、拿到一次测量 y"（相机图像或分数）；∂y/∂θ 不可得（硬件上没有梯度）；可信的数值模拟器不存在（任务明令禁止）；测量预算 M 有限（分类任务 51,200 次，编码任务 25,600 次）。目标是在预算内最大化任务指标。约束的苛刻程度值得逐条体会：既没有梯度（排除反传类方法）、又没有模型（排除数字孪生类方法）、还没有大预算（排除暴力搜索）——三条路同时堵死，只剩"聪明地选择每次测量"这一条缝。

- **纯无梯度方法的困境**：在数十万维上做随机扰动式搜索，单次扰动携带的关于"该往哪走"的信息近乎零，样本复杂度随维度爆炸——这是 PPO 在此只能从 35% 爬到约 52% 的结构性原因，不是调参不力。打个比方：在百万像素空间里随机扰动，好比蒙住眼睛在足球场上找一枚会移动的硬币，每次伸手（测量）几乎不提供方向信息。
- **破局的唯一出口**：把解约束到一个物理上有意义的低维流形上。若网络函数可以被 k 个可解释参数（透镜焦距、棱镜偏向、像差模式系数、平面偏移）生成，那么每次测量对这 k 个参数的后验约束就极强——一次测量顶得上上万次盲扰动。上面的比方随之改写：场上只剩十几个候选位置，且每次伸手能排除一整片区域。
- **传统上这一步由谁完成**：专家。波前整形的模式基、自适应光学的像差基，都是领域知识预先固化好的低维参数化。
- **本文的问题转化**：这个"找到紧凑参数化"的知识工作，能否由携带教科书级物理先验的 LLM 代理在线完成？注意这里同时捆绑了三个子问题——主动系统辨识（该测什么）、机制假设（为什么这么动）、参数化设计（用哪组变量调）——三者合起来恰恰是"实验物理学家的直觉"的操作性定义。

这个问题定义的价值在于其普适性：微波腔调谐、量子比特控制脉冲整形、等离子体参数优化、生物反应器条件搜索，全是同一抽象结构。论文用 ONN 做了最严格的实证，但问题本身远大于光学。

还应注意问题定义中一个容易被低估的细节：**测量的双重角色**。在本问题中测量既是优化信号（分数）又是认知对象（图像），传统方法只用它当信号，而代理把它当数据看——同一张相机图，PPO 读出的是一个标量，代理读出的是"类别使光斑位移"这样的关系。harness 设计的全部要义，就是把测量的认知维度完整地交还给优化器。

## 四、问题解法

解法分三层：实验系统、harness（代理与硬件之间唯一的接口）、以及代理自发形成的两段式策略。核心设计理念一句话可以概括：**给代理一个实验物理学家的工位，而不是一套优化算法的接口**。

### 4.1 实验系统：一台多次反射的衍射网络

硬件的核心构思是用一套器件折叠出多层网络。相位型 SLM（Meadowlark HSP1920-500-1200，1920×1152 像素）与一面镜子组成多反射腔：激光（HeNe，632.8 nm）在 SLM 上反射四次，每次打在 434×434 像素的不同区域——第一区保持平坦，第二区相位编码输入图像，后两区显示可训练掩模 φ1、φ2，相当于一个三层网络（层间"传播"由反射间隙的自由空间衍射完成）。CMOS 相机（384×384）记录输出光强。虽然层间传播是线性的，但相位调制 + 相机只测强度 + SLM 非线性响应，使输出对参数呈强非线性——训练是非凸问题。每次测量 = 平均 4 帧相机图（20 ms 稳定时间），耗时 0.107 s；分类预算 51,200 次约 1.5 小时——**运行时长由相机采集率而非语言模型决定**。

分类任务是 MNIST 数字 0/1/2（上采样到 200×200，以 π×像素值编码相位），相机上三个 48×48 探测区各自聚光，谁光多判谁；2,000 张练习数字、3,147 张密封测试数字。

硬件细节里藏着两个对结论有实质影响的设定。其一，"一次测量"的定义是**一张相机图对一组所显示相位掩模**——探针、评估、验证全部计入同一预算，这保证了后文所有对比的公平性锚点。其二，评分采用**交错块设计**：同一会话里所有方法的参数集在测试集上交错测量，若光学系统在评分期间漂移，每个方法被均等地波及——这是对实验科学里"时序混杂"这一经典陷阱的正面处理，很多 AI 论文的硬件评估都懒得做这一步。

### 4.2 Harness 设计：五件套

代理以 Claude Code 无头模式（headless）运行于隔离工作区，仅 CPU、断网、禁访问工作区外文件，高推理档位（high reasoning effort），任务文本明令**禁止数值光传播模型**——代理无法模拟光学，只能从测量中学习。这个禁令是整个设计的题眼：如果代理可以跑角谱传播仿真，它就会退化为"数字孪生 + 反传"的变体，测量的价值无从体现；禁令把代理逼回与人类实验者相同的认识论位置——关于这台设备的一切都必须来自观测。代理够得着硬件的唯一通道是 harness，五件套如下：

1. **probe 工具**：在 SLM 任意区域显示任意相位掩模，返回相机图像，成本记一次测量——让代理能"研究光学本身"而不只是从任务分数反推。这是整个 harness 中信息含量最高的通道：相机图像是系统的丰富输出（384×384 的强度分布），而任务分数只是它的三比特压缩；
2. **evaluation / validation 工具**：在练习数字上测候选掩模，返回各探测区的能量分布与正确率；
3. **假设强制**：每次请求必须写明假设与预期结果——把每次测量变成对代理理解力的检验；
4. **统一测量预算**：每张相机图像都计入公共预算，探针也不例外——杜绝"探针白嫖"，迫使代理像真正的实验者一样精打细算；
5. **notes 文件**：代理的发现记录，跨会话可传递，但按规则只含文字与代码、绝不含相位掩模或测试数据。

关键的公平性安排：PPO 与策略梯度基线**走同一 harness、同起点、同预算、同验证次数**（每 2,560 次测量验证一次，共 20 次），基线超参先在仿真中 22 组设置里搜优再上机；所有方法在密封测试集上只评分一次，且同一会话的所有参数集在交错块中一起评分，光学漂移对所有方法均等作用。

### 4.3 代理自发形成的两段式策略

论文最漂亮的发现是：没人教代理怎么做系统辨识，它自己走出了"先理解、再重参数化、最后调参"的路径。作者强调，语言模型既没在这个设备上训练过、也没为光学系统辨识做过专门训练——两段式策略是从任务文本与测量中自发涌现的。

**第一段：系统辨识。** 论文给出的三个探测实验值得逐一展开，因为它们展示了"教科书物理 × 三次测量"如何榨出整台设备的几何信息：

- **倾斜扫描**：把同一个线性相位斜坡（20 个相位周期）依次打到输入面、φ1、φ2，测相机上光强质心的位移量。输入面位移最大、φ2 最小——直接给出各平面对光束方向的控制权重的排序。这个探测的信息含量惊人：位移量 ∝ 平面到相机的有效传播距离 × 放大率，几次测量就锁定了系统的几何级联关系；
- **相位台阶干涉**：在 φ1 上打相位台阶，相机出现清晰干涉条纹；在 φ2 上打同样台阶，条纹对比度几乎为零。物理含义：光离开 φ2 后到相机距离太短、来不及扩散，菲涅尔衍射的传播核作用弱，所以 φ2 上的高频调制"写不到"相机平面上——这解释了为什么 φ2 适合做光斑路由（分块控制光斑落点）而不是波前精细整形，也提示 φ1 才是波前整形的主力平面；
- **圆盘定位**：在各平面放置圆盘相位图样，在相机上标记各平面的落点，发现平面相对标称位置偏移若干像素、光束带轻微像散。这两个看似微小的偏差正是"仿真 98% 的掩模上机只剩 35%"的物理原因——理想模型里的平面位置与真实装配差了几个像素，而波长只有 632.8 nm，几个像素的失准在相位上就是巨大的系统误差。

**总计仅用 48 次探测**，代理测出的放大率、像散、倾斜灵敏度与那个需要 67,000 张校准图拟合的数字模型一致——测量效率相差三个数量级以上。值得强调的是方法论的对比：校准模型用 67,000 张输入输出对做黑箱拟合，代理用 48 个"物理上知情"的探测（每次探测的设计本身就编码了假设——"如果平面倾斜灵敏度高，那么斜坡应该移动光斑"）。这就是主动实验与被动回归采样在信息效率上的差距。

**第二段：可解释重参数化。** 系统辨识完成后，各次运行走出两条路线之一，各自把数十万像素的问题换算成少数物理参数的问题：

- **微调路线**：保留起始掩模，只用平面平移、透镜、低阶像差等少数物理参数修正，达到 79.9%——花小钱救旧设计；
- **重新设计路线**：围绕测得的几何从零设计新光学。从任务文本冷启动的一次运行把 φ1 分成四个象限、每象限自带透镜与棱镜（"傅里叶路由器"，Fourier router），靠 13 个参数调到 91.1%；继承了早前会话笔记的运行则利用它发现的机制——**输入数字的类别会使聚焦光斑发生位移**（相位编码数字的局部相位梯度倾斜波前，透镜把倾斜转换成焦斑平移，每个类别往自己的方向推）——把 φ2 分成 49 块、逐块测焦斑、离线计算每块光斑应落的探测器位置（"光斑路由器"，spot router），拿到 96.8%。两个命名设计都是作者事后从代理行为中归纳的——论文里没有任何人类预先给定的设计模板，这一点在阅读 Methods 时值得反复确认。

两条路线的共同本质：**用十几个可解释光学参数替换数十万次像素更新**——agent 是把光学函数当程序写，透镜、棱镜、像差项是变量，在硬件上编辑、测试这个程序。optics as code 之名由此而来。值得指出的是，两条路线并非代理被规定的选择，而是不同运行根据各自辨识结果的自然分岔——发现起始掩模"没救"的运行转向重新设计，认为还有抢救价值的运行选择微调。这种策略级的自适应，正是"理解系统"与"优化目标函数"的分水岭。

**机制发现的完整故事**值得单独讲一遍，因为它是"理解"而非"搜索"的最好证据。带笔记的运行中，代理先用几次探测核验早前会话的记录（步骤 1），然后对比不同数字类别的相机图像，注意到一个此前没人写进笔记的现象：**输入类别改变聚焦光斑的位置，多于改变光斑的亮度**。它随即给出傅里叶光学的解释——相位编码数字的局部相位梯度倾斜了波前，透镜把每种倾斜转换成焦斑的平移，于是每个类别把光斑往自己的方向推。基于这个机制它设计了光斑路由器：φ2 分 49 块、逐块测焦斑位置、离线计算每块光斑应瞄准的探测器，再在硬件上校正。整个设计-验证-调参流程，与一位训练有素的光学工程师面对新系统的工作方式几乎无法区分——区别是它用了 1.5 小时和零工资。作者在正文中把这个设计称为 spot router 并强调其第一版在预算七分之一处即超越全部无梯度基线——一个"发现机制 → 直接写出好设计"而非"缓慢爬坡"的跳跃式改进，是搜索式优化在结构上不可能产生的行为特征。

冷启动运行的七步推理轨迹值得整表复现（这是理解"agent 在做什么"的最好证据）：

| 步 | 假设 | 探测/设计 | 发现 | 学到 | 累计测量 | 验证精度 |
|---|---|---|---|---|---|---|
| 1 | 圆盘可标记平面落点 | φ1 置圆盘 | 平面偏移、光束轻像散 | 各平面在相机上的位置 | 48 | 起点 |
| 2 | 失准毁掉起始掩模 | 平移后的起始掩模 | 最好 48%，放弃该路线 | 起始掩模携带信号很少 | 2,960 | 48% |
| 3 | φ1 能转向并聚焦光 | φ1 透镜贴片 | 尖锐光斑，约 5 px/周期 | φ1 负责路由光 | 8,643 | 48% |
| 4 | 陡光栅会把光倒掉 | φ1 光栅 | 57-67% 的光留在相机 | 光栅清不掉相机 | 8,653 | 48% |
| 5 | 透镜能显示数字频谱 | φ1 透镜 | 远场随类别不同 | 类别信息在远场 | 10,437 | 55% |
| 6 | 四透镜区可读远场 | 每象限透镜+棱镜 | 验证 77.5% | 焦距变化也移动瞄准点 | 11,894 | 78% |
| 7 | 调 13 个参数可改进 | 瞄准/活塞项/焦距 | 验证 91.0% | — | 43,846 | 91% |

注意第 2 步的"失败"：代理测试了微调假设、发现不值钱、果断放弃——这是优化算法不会做的**假设淘汰**。注意第 5 步：一次透镜探测同时是机制发现（类别在远场可分）与设计灵感来源。测量的信息密度来自假设，而不是来自扰动本身。

再对照两组"数值"看这条轨迹的陡峭程度：微调路线在第 43,846 次测量时拿到 91%；而带笔记的运行光斑路由器第一版在约 7,700 次测量（预算的七分之一）时已超过无梯度方法的终身成绩 52.5%。同是花测量，花在"检验机制"上的每一次都比花在"随机扰动"上的每一次值钱一个数量级以上。

## 五、评估指标与实验证据

### 5.1 分类主结果：摸到专家路线的天花板

MNIST 0/1/2 分类，测试集 3,147 张密封数字，预算 51,200 次测量，各方法取最佳运行：

| 方法 | 测试精度 | 备注 |
|---|---|---|
| 起始掩模（理想模型反传训练） | 35% | 仿真里 98%，硬件上崩塌 |
| 策略梯度（PG） | 52.3% | 抗对偶采样+归一化奖励 |
| PPO | 52.5% | 近期对比中最优 in situ 方法，22 组超参搜优 |
| 代理（仅任务文本，冷启动） | 91.1% | 傅里叶路由器，从零设计 |
| 代理（+早前会话笔记与代码） | **96.8%** | 光斑路由器；三次有笔记/经验运行 89.2/91.3/96.8（均值 92.4，标准差 3.9） |
| 校准模型反传（参考天花板） | 96.3% | 仅校准就用了 67,000 张相机图 + GPU 训练数小时 |

代理不但追平还略超天花板（96.8 vs 96.3），且不用逐台校准、不用 GPU。统计上，3,147 张测试数字的标准误最多 0.9 个百分点（50% 精度处），最好运行为 0.3 点。预算效率同样悬殊：光斑路由器的第一版设计在约七分之一预算（约 7,700 次测量）时就已超过两种无梯度方法的最终精度。

训练过程的曲线形态也值得一读（Fig.1e）：代理的验证精度不是平滑爬坡，而是台阶式跳升——每上一个台阶对应一次机制发现或设计切换（核验笔记 → 发现类别位移 → 分块测光斑 → 首版光斑路由器）；PPO 的曲线则是典型的缓慢对数爬升。两种曲线形状的差别就是"理解驱动"与"统计驱动"的可视化区别。

**结果证据链上有几处细节让这个对比比表面数字更硬：**

- **基线不是稻草人**。PPO 超参先在数字孪生上经 22 组设置搜索（探索宽度、学习率、批形状、PPO epoch 数），择优上机；策略梯度同样经仿真择优。它们卡在 52% 不是因为没调好，而是结构性的：数十万维像素空间 × 无先验的统计策略；
- **代理拿到的并不比基线多**。同 harness、同起点（对分类任务是理想模型反传的掩模）、同预算、同 20 次验证节奏；"带笔记"运行继承的只有文字与代码，绝无相位掩模——排除了答案泄题；
- **光学证据与数字互证**。最终设计的相机图像上，三个类别各自把最大光能份额送进自己的探测器，能量分布矩阵接近理想的对角结构，混淆矩阵近乎对角——精度数字背后有可检查的物理图像；
- **多次运行分布**。三个有笔记/经验的运行给出 89.2/91.3/96.8（均值 92.4、标准差 3.9 点），说明单次 96.8 有运行间波动，但整个分布稳定压制无梯度方法 40 个点以上。

### 5.2 编码器任务：能力随模型档位增长

第二个任务检验泛化性，同时把"任务变了、harness 不变"作为方法通用性的检验——同一套 harness 只换任务文本即可切换任务，这本身就是方法工程成熟度的信号。任务设计本身值得一提：两个相位掩模把 Fashion-MNIST 图像压缩到相机上 16 个探测器信号（类比自编码器的 latent space），一个**预先训练好的**数字 MLP 解码器（事先与 16 输出的线性数字编码器联合训练）从 16 个信号经仿射映射重建图像，指标是 300 张 held-out 测试图的 PSNR，预算 25,600 次测量、至多 20 次验证。注意解码器冻结——光学部分必须独自学会"把图像信息塞进 16 个通道"的表示，这正是光学前端为电子后端减负的应用场景（光学压缩、电子重建的混合架构，对应光计算界倡导的 hybrid optical-electronic 处理范式）。代理的解法与分类任务同构但物理不同：先在 φ1 上发现"放一个透镜把光聚焦到探测器网格"的物理设计，再调一小组低阶像差模式。

这个任务还带了一个周到的对照控制：同一组随机相位掩模在三个会话中重复测量，PSNR 为 13.84/13.82/13.87 dB——漂移可忽略，且每次运行都与自己会话的随机起点比较增益。

同一段任务文本跑三个档位的模型（相对各自会话随机起点 13.8 dB 的增益）：

| 运行 | 测试 PSNR 增益 (dB) |
|---|---|
| PPO | +1.11（绝对值 15.0 dB） |
| Claude Sonnet 5 | +1.55 |
| Claude Opus 5.5 | +1.62 |
| Claude Opus 5.5 + 笔记 | +1.79 |
| Claude Fable 5.2 | +1.98 |
| **Claude Fable 5.2 + 笔记** | **+2.22（绝对值 16.09 dB）** |
| 校准模型反传（参考） | +3.1（绝对值 16.9 dB） |

（各增益按论文图 3d 数据换算，与正文报告的绝对 PSNR 完全吻合：16.09 − 13.87 ≈ 2.22。）

两个结构性结论：其一，**增益严格随模型能力单调上升**（Fable 5.2 > Opus 5.5 > Sonnet 5，Fable 5.2 是撰写时 Artificial Analysis 智能指数榜首），意味着这条路线会随基础模型进步自动变强，无需重做方法——论文特意选了覆盖当前能力谱系三档的模型，并推断其他在档模型的表现应落在该区间内；其二，最好代理结果距反传天花板仅 0.8 dB，而后者依赖 67,000 张图的校准战役。重看各运行重建图像的逐图 PSNR（13.8-21.4 dB 区间分布），带笔记的运行在它改进最多的 50 张测试图上增益均匀而稳定——不是靠个别图拉均值，而是表示质量的系统性提升。

### 5.3 Harness 消融：信息有用，规则无用

消融实验回答的问题是：代理的超常表现，究竟来自语言模型的物理知识，还是来自 harness 给的额外信息？为了回答它，作者在校准数字模型上（可并行快速迭代、条件可控）逐一开关 harness 元件，得到本文最有工程价值的发现之一：

- 所有**提升精度的元件都是给代理更多光学信息的**：随评估返回的相机图像、成本仅一次测量的探针、假设强制、笔记文件——四条信息通道逐一拆除，精度逐一受损；
- **规定代理如何决策、如何花预算的规则一律没有帮助**——代理从更好的观察中获益，远多于从更多的指令中获益；
- 最严苛的消融：只给每个候选一个标量奖励（与 PPO 的信息完全对等），代理仍得 80.6%，明显甩开 PPO 的 71.3%——此时代理本身就是一个无梯度优化器，但它**用物理知识解释每一个结果**，而 PPO 只跟踪奖励统计量；移除相机图像、探针、假设要求等单通道后精度落在约 76.8-80.0 区间；
- **最大增益来自继承早前会话的笔记**（消融最高点 94.5%），且笔记在真实实验上也产出最佳运行——自然语言笔记是高效可迁移的设备知识载体，后续会话用几次探测即可核验。

顺带一个方法论细节：实验与校准模型上各设计的测试精度 Pearson 相关 0.88，说明数字模型足够忠实，消融结论可外推到硬件。

把消融数据整理成一张信息量对照表，结论会更醒目：

| harness 配置 | 代理得到的信息 | 校准模型上精度 |
|---|---|---|
| PPO（无语言模型） | 每候选一个标量奖励 | 71.3% |
| 代理 + 仅标量奖励 | 同上（与 PPO 完全对等） | **80.6%** |
| 代理 + 完整 harness | 相机图像 + 探针 + 假设 + 笔记 | 94.5%（+早前笔记） |
| 单通道缺失（无相机图/无探针/无假设） | 各缺一项 | 76.8-80.0% |
| 起点掩模 | — | 58.7% |

第二行是全表最值得盯的数字：**信息通道完全对等、只差"脑子里的物理知识"时，代理仍领先 PPO 9.3 个百分点**。这一格把"知识"这个常被含糊处理的变量单独隔离出来做了定量测量——它是对"LLM 代理只是套壳搜索"质疑的最硬反驳。

消融的另一半同样有信息量：作者还试过给 harness 加规则——规定代理该怎么决策、怎么花预算、怎么复查结果——一律不涨分。两者合起来读，设计教益完整浮现：**代理系统的杠杆在信息侧（观察通道），不在指令侧（行为规则）**。这与软件工程中"给程序员更好的日志胜过更多的流程规范"的直觉完全同构。

## 六、效果优势根源

为什么同一个预算下，代理比专门的无梯度优化算法强出 40 多个百分点？因果链可以拆得很干净——四环相扣，每一环都有论文中的直接证据支撑。

**第一环：预训练语料里的物理先验 → 机制假设。**"相位梯度倾斜波前、透镜把倾斜换成焦斑位移"是傅里叶光学的教科书内容。代理看到"类别改变光斑位置多于改变亮度"的相机图像时，能立刻给出机制解释并把它变成设计原理（光斑路由器）。PPO 看到同样的图像序列，只能把它折算成奖励标量。这一环的深层含义：语言模型在预训练中"读过"的几百万页科学文献不是死知识，而是可以在新情境中组合使用的生成性先验——本文是这一命题在真实物理系统上的首批严格证据之一。

**第二环：机制 → 可解释重参数化 → 参数空间压缩。** 数十万像素的搜索空间被压缩成十几个有物理含义的参数（13 个调参的傅里叶路由器、49 块光斑路由器的几何）。维度压掉四个数量级，优化问题从"大海捞针"变成"小空间精调"。值得强调"可解释"的额外红利：每个参数都有物理语义（焦距、棱镜角、像散系数），代理的调参决策因而可以被人类物理学家逐项审查——这是黑箱优化器永远给不了的透明度，也是笔记能够跨会话传递的前提（文字能描述透镜，不能描述数十万个像素值）。

**第三环：低维参数化 → 单次测量的约束强度暴涨。** 这是样本效率的形式化来源：一次随机像素扰动对后验几乎不提供信息；一次"把第 k 块光斑移到探测器 d"的设计测量，同时检验几何模型、机制假设与参数取值。七分之一预算超过基线终身精度，就是这环的实证。用优化理论的行话说：PPO 在 10^5 维空间里做无信息先验的探索，代理在 10^1 维流形上做物理约束下的验证——两者的样本复杂度差的不只是常数因子，而是随维度指数级拉开的结构性差距。

**第四环：harness 把理解循环闭合。** 富信息观察（相机图像）→ 假设强制（测量即检验）→ 笔记（知识固化与迁移）。消融证明这条信息链每一节都在贡献精度，而指令性规则不贡献——**代理缺的不是方法论指导，是眼睛**。

四环连起来才是完整答案：先验给机制（环一）、机制给参数化（环二）、参数化给测量效率（环三）、harness 给持续获取信息的通道（环四）。抽掉任何一环，优势都会塌陷——消融数据（无相机图 76.9%、无探针 80.0%、无假设 76.8%、仅标量 80.6%，对照完整 94.5%）就是四根支柱各自的承重测试。

**外部交叉验证：这不是孤证。** 三个独立方向给出同向证据：权重空间编程（Takehi et al. 2026；Turing 研究所独立复现）证明前沿 LLM 读、写、修数字网络权重是可复现的涌现能力——本文把它推广到"参数只能测量"的物理网络；MIT 的 VLM 光学实验室代理（arXiv:2609.32918）证明多模态模型能在光学台上做闭环主动感知、估计执行器响应关系、并在信号稀疏时主动制造信息（干预式观察）；Coscientist 以降的整条 AI 实验代理谱系证明"文献知识 → 物理操作"的通路工程上成立。本文补上谱系里缺的一块：**对高维连续参数物理系统的理解式训练**。模型能力序（Fable > Opus > Sonnet）则提示这个优势会随基础模型进步而扩大——它是"搭便车"于 LLM 能力曲线的方法。

还有一层反直觉的对照值得咀嚼：标量奖励消融里代理 80.6% vs PPO 71.3%，差距 9 个点纯粹来自"知识"而非"信息通道"；而完整信息再把差距拉开。**知识与信息是两个独立的生产要素**，这是对"agent = LLM + 工具"这类静态描述的一次定量反驳。而笔记带来的最大单项增益（91.1% → 96.8%）则补上第三个要素：**记忆**。知识（预训练里带来的物理先验）、信息（harness 通道里的观察）、记忆（笔记里的设备特异性发现）——三者对最终精度的贡献在本文中第一次被拆开来分别定价。

## 七、必要知识反推

要真正读懂这篇论文（而不是只看懂摘要），需要提前具备或补课的知识点，按依赖顺序（前四项是光学的"硬通货"，后三项是 AI 侧的"接口知识"；只缺其一不至于卡死，但缺前两项会完全看不懂第四节）：

1. **傅里叶光学基础**：相位调制与复振幅、角谱传播法（ASM）、透镜的傅里叶变换性质、波前倾斜与焦斑位移的关系——论文最核心的机制发现全建立在这上面；
2. **衍射 ONN 结构**：D2NN（Lin et al., Science 2018）的"衍射层=全连接层+自由传播"类比，SLM 多次反射如何用一台器件实现多层（Yildirim et al., Nat. Photon. 2024）；
3. **训练范式光谱**：in silico 训练 → hybrid/物理感知训练（Spall et al. 2022; Wright et al., Nature 2022）→ in situ 反传（Hughes 2018; Pai, Science 2023）→ 前向训练（Xue, Nature 2024; Bandyopadhyay, Nat. Photon. 2024）→ 无梯度/强化学习（Li et al., Light Sci. Appl. 2026）——明白每条路线为什么贵，才能明白本文靶心在哪；
4. **无梯度优化常识**：SPSA、CMA-ES、贝叶斯优化的样本复杂度直觉，以及策略梯度/PPO 的机制（高斯策略、裁剪代理目标）——用来理解基线为何卡在 52%；
5. **LLM 代理工程**：工具调用循环、harness 概念、Claude Code 无头模式（headless，无人值守运行于隔离工作区）、推理档位（reasoning effort）设定——论文的 agent 侧全部依赖这套基础设施。可以补充一个背景：Claude Code 的无头模式（`claude -p`）正是为脚本化、无人值守场景设计的，天然适合充当实验代理的运行时，本文是这一工程设施切入实验科学的一个示范；
6. **实验方法论**：系统辨识、消融设计、密封测试集、交错评分抗漂移、标准误报告——本文的实验设计比多数 AI 论文严谨，值得按 checklist 精读；
7. **一点样本复杂度/信息论直觉**：参数维度 vs 测量预算的矛盾、单次测量的后验信息量——这是把论文结论推广到其他领域的思想接口。

若想用最小代价复现论文的理解曲线，建议的阅读顺序是：先读 Fig.1（整体框架图，十分钟看懂全貌）→ 正文 Results 前两节（实验与 harness）→ Fig.4f 的七步推理轨迹表（本文最独特的证据）→ Methods 的 Baselines 与 Scoring 小节（评估公平性设计）→ 最后回读 Discussion。对照阅读的材料按亲缘排序：Li et al. 2026 给出 PPO 基线的完整语境；Yildirim et al. 2024 是实验硬件本身；Takehi et al. 与 Goworek et al. 补齐"参数空间可理解"的数字侧证据；对 AI 实验代理谱系有兴趣的读者再补 Boiko et al. 2023 与 Lopez et al. 2026。

## 八、通用性灵感

这篇论文最大的价值不在光学，而在它验证了一个可迁移的模式——对于不做光学的读者，下面这些条目才是正片。逐条展开：

（一个总的阅读建议：第一、二、四条是给所有领域设计者的，第三、五条是给 agent 工程师的，第六、七条是给所有关心这项技术边界的人的。）

**1. 领域先验压缩搜索空间——实验科学的通用杠杆。** 任何"参数高维、测量昂贵、梯度不可得、模拟器不可信"的系统（微波腔阵列、量子比特控制脉冲、等离子体位形、组合化学、生物工艺参数）都是同一抽象结构。传统方案二选一：要么专家手工给低维参数化，要么无梯度算法在维数灾难里挣扎。本文展示了第三条路：**让携带领域先验的代理在线发现紧凑参数化**。前提条件其实很温和——该领域要有足够多的教科书与文献语料（LaTeX 公式、器件手册、实验规程），这正是 LLM 先验的来源。反过来也划出了边界：若一个领域的知识几乎不存在于文本中（例如某台独一无二的装置的全部 know-how 都在一位老师傅的肌肉记忆里），代理的起点优势会相应缩水——但请注意，一旦代理开始测量，它就在自己生产文本化的领域知识（notes），这个冷启动劣势会随使用衰减。

**2. Harness 设计哲学：喂观察，不喂指令。**"规则无用、信息有用"的消融结论对所有代理系统设计者都是一记警钟。给 agent 更好的传感器回报（这里是相机图像），胜过给它更详细的行为守则。推论：设计 harness 时应该问"实验物理学家在这个工位上能看到什么"，而不是"我应该怎么指挥它"。这与近期 agent 工程社区的经验共识（观察丰富 > 指令堆积）形成了来自物理实验的第一个受控证据。

**3. 假设强制 = 把测量变成实验。** 每次请求必须附假设与预期，使每次测量自动成为可评分的理解力检验，也使推理轨迹天然可审计。对照 A-Lab 的教训（自主合成声明因表征可靠性被质疑并更正）：可核验的中间假设是对"自主科学发现"声明的最好防御。笔记用平实语言记录发现、后续会话用几次探测即可复核——这是人类可审查的自主性。工程视角的翻译：harness 强制输出的"假设+预期"就是 agent 工作流的内置单元测试，预期不符即自动暴露理解错误，而不是让错误在奖励曲线上沉默地累积。对长期运行的科学 agent 而言，这个机制可能是从"演示"走向"可信工具"的分水岭。

**4. 笔记是组织级资产。** 设备知识以自然语言+代码形式沉淀，跨会话、跨同型设备共享，产出最大单项增益（冷启动 91.1% → 带笔记 96.8%；消融中同为最大项）。这为"每台设备一个 agent"的部署形态给出了知识管理方案：不是每台设备从零学，而是知识在设备群之间流转——论文明确指出 notes 可在同型或相似设备间共享。这与知识管理的一般规律吻合：专家的隐性知识（这台仪器哪里漂、那个信号意味着什么）最难传承，而代理的笔记恰好把隐性知识显性化为可验证的文本——一次写成、反复复用、几次探测即可复核。

**5. 测量与推理的预算旋钮。** 运行时长由相机采集率决定（0.107 s/测量），语言模型不是瓶颈；测量贵就让代理多想少测，测量便宜就多测少想。这个权衡作为 harness 参数显式存在，为不同成本结构的实验平台提供了直接的工程适配接口。顺带推翻一个直觉：人们默认"LLM 推理很贵所以 agent 实验会慢"，本文的数据说恰恰相反——瓶颈从来在物理世界的读取速度上，思考几乎免费。

**6. 冷静的边界。** 任务规模仍是三分类与 16 维编码（作者自己把它定位为更大网络的"单层"）；系统是单点实验装置，长期漂移只通过交错评分部分缓解；效果依赖前沿档模型（Sonnet 5 档位的增益已明显缩水），能力曲线的底座在别人手里；Fable/Opus/Sonnet 均为闭源商用模型，复现成本与供应链风险真实存在；三分类上 96.8% 与反传 96.3% 的差距在单次运行标准差（3.9 点）之内，"超过反传"宜读作"追平"。另一个应追问的问题是安全性外推：本文的任务是良性的光学调参，但同一模式（agent 主动探测系统、建立模型、施加控制）若指向未加防护的物理系统，风险面完全不同——harness 作为唯一通道的价值此时才真正凸显，它是审计与急停的天然卡点。
**7. 对光计算领域的具体意义。** ONN 规模化部署的死结是"每台设备都要专家伺候"。若训练可以由软件代理以 1.5 小时/台、零校准图完成，部署十万台处理器的经济学就完全改写了——论文的展望里明确描绘了这一图景：代理并行探测与训练大量设备，为每台返回训练参数加一份"它发现了什么"的解释。更进一步，作者指出多模态光纤非线性、光反馈激光器、复杂散射介质这些"太复杂而无法精确建模、梯度不可得"的系统，恰恰是这种方法的主场——代理从自身测量中学到的系统理解，可能让一批此前不可用的非线性光物理系统变成可编程计算 substrate。这也回应了光计算领域一个长期尴尬：许多有趣的光学现象（散射、混沌、非线性传播）在计算上潜力巨大，却因为"无法建模所以无法编程"被搁置——现在"无法建模"这一条有了绕行方案。

方法论上最后的启示：这篇论文把"优化器"从算法换成了"理解系统的实体"，于是实验科学里最贵的东西——专家的理解——第一次显示出被软件规模化复制的可能。optics as code 的名字起得准确：当代码代理开始把透镜当变量、把光斑当 print 语句，实验物理的调试循环就有了光速的版本。
